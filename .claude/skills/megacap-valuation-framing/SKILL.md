# 巨头估值框架重定向 v1.0

> **核心价值**: 对$1T+巨头，传统估值框架产出"假精度"——三锚收敛于市价±6%，评级取决于WACC而非分析。本Skill强制将报告价值从"点估值"转向"条件洞见"。
> **来源验证**: MSFT v1.0 (+4.4%期望回报完全由WACC 9.5% vs 9.0%决定) | AMAT v1.1 (-2.1%零容忍，单一信念失败即翻转)

## 触发条件

Phase 5开始前，当目标公司市值>$500B时**自动触发**。

适用范围: AAPL/MSFT/GOOGL/AMZN/META/NVDA/TSM/BRK等。

## 问题诊断: 为什么巨头估值是"假精度"

### MSFT的数学证明

```
WACC 8.5% → DCF $3,800B → 期望回报 +19% → "关注"评级
WACC 9.5% → DCF $3,489B → 期望回报 +4.4% → "中性关注"评级
WACC 10.0% → DCF $3,096B → 期望回报 -8.7% → 接近"审慎关注"

结论: WACC±100bps跨越三个评级区间
      8项信念分析 + 4场景 + 3锚估值 < WACC选择的信息贡献
```

### 结构性原因

1. **基数效应**: $3T公司的±10%就是$300B，超过大多数中型公司的全部市值
2. **WACC不可知**: 合理WACC区间(8-10%)对应$600B+估值波动
3. **效率市场假说在巨头最有效**: $3T市值由数千机构投资者定价，"发现错误定价"的概率远低于中小盘
4. **三锚收敛是必然的**: 内生锚(DCF/SOTP/RevDCF)共享假设，情景锚的概率被校准到接近市价

## 执行流程

### Step 1: 巨头检测与声明

Phase 5开始时，在Ch29开头写入:

```markdown
### 估值框架声明

本公司市值${MARKET_CAP}B，属于超大市值($500B+)类别。基于以下结构性原因，
传统点估值的信息贡献有限:

1. WACC合理区间(X%-Y%)对应EV波动$ZB(±W%)
2. 三锚估值必然收敛于市价附近(效率市场+共享假设)
3. 评级结论对WACC选择的敏感性远大于对业务分析的敏感性

因此，本章的估值分析采用**条件框架**: 不追求单一"正确"EV，
而是回答"在什么条件下MSFT变得便宜/贵"。
```

### Step 2: 三问强制回答

Phase 5 Agent C在写完DCF/SOTP/场景分析后，必须显式回答:

#### Q1: 你的估值与市价偏差多少？

```markdown
## Q1: 市价偏差诊断

| 方法 | EV ($B) | vs 市价 | 偏差 |
|------|---------|---------|------|
| M1 DCF | $3,489 | $2,995 | +16.5% |
| M2 SOTP | $2,338 | $2,995 | -21.9% |
| M4 外部可比 | $3,180 | $2,995 | +6.2% |
| M5 情景加权 | $3,185 | $2,995 | +6.3% |
| 三锚加权 | $3,071 | $2,995 | +2.5% |

**诊断**: 三锚加权结果与市价偏差仅+2.5%。
→ ⚠️ 这可能意味着:
  (a) 市场定价高效，我们的分析确认了市场共识; 或
  (b) 我们的模型被市价锚定，三锚的"独立性"不如预期

**诚实标注**: [选择(a)或(b)或"无法区分"]
```

**规则**: 如果三锚加权与市价偏差<±10%，必须触发这一诊断。不允许跳过。

#### Q2: 哪个单一参数变化能翻转评级？

```markdown
## Q2: 参数主导性检测

| 参数 | 当前值 | 翻转值 | 所需变化 | 翻转方向 |
|------|--------|--------|---------|---------|
| WACC | 9.5% | 9.0% | -50bps | → 关注 |
| WACC | 9.5% | 10.2% | +70bps | → 审慎关注 |
| S1概率 | 12% | 22% | +10pp | → 审慎关注 |
| 终端g | 3.0% | 2.0% | -100bps | → 审慎关注 |
| OPM FY30 | 44.5% | 40% | -450bps | → 中性关注(不变) |

**主导参数**: WACC (仅需±50-70bps即翻转)
**次要参数**: S1概率 (需±10pp)
**非敏感参数**: OPM (单独变化不翻转)

**结论**: 评级主要由[WACC]决定，业务分析参数对评级影响[有限/中等/显著]。
```

**规则**: 如果任何参数在其"合理区间"内即可翻转评级，必须在报告中显式标注**"本评级对[参数]高度敏感"**。

#### Q3: 不依赖估值的决策价值

```markdown
## Q3: 三条不依赖估值的可操作洞见

无论MSFT"值"$2.5T还是$3.5T，以下发现对投资决策均有帮助:

1. **CapEx/Revenue的季度趋势是最有信息量的单一指标**
   - 连续两季度下降 = D&A峰值确认 + FCF恢复信号 → 正面
   - FY28仍>25% = CapEx纪律缺失 → 负面
   - 来源: Ch13 CapEx传导链 + RT-1承重墙W3

2. **OpenAI的财务依赖远小于叙事依赖**
   - 去OpenAI后Azure仍32-34%(vs当前39%)
   - 真实暴露: CRPO中$9-12B/年(~2%收入)，不是市场叙事的"存亡威胁"
   - 来源: Ch18五维双向审计

3. **FY28是多信念同步验证窗口**
   - B2(OPM恢复)、B4(CapEx降速)、B6(FCF恢复)在FY28同时可验证
   - 如果FY28 Q4: CapEx/Rev<22% + OPM>43% + FCF>$70B → 信念集稳固
   - 如果FY28 Q4: CapEx/Rev>25% + OPM<40% → 至少2信念失败 → 降档
   - 来源: RT-6时间框架 + Ch12承重墙

**这三条洞见的决策价值不受WACC选择影响。**
```

**规则**: 三条洞见必须满足:
- 每条引用具体章节/数据来源
- 每条包含可观测的触发条件(不是模糊的"关注趋势")
- 三条整体不依赖于任何估值参数(WACC/g/概率)

### Step 3: 评级表述调整

对于巨头($500B+)，评级表述从:

> **评级: 中性关注 | 期望回报: +4.4%**

调整为:

> **评级: 中性关注(条件性) | 期望回报: +4.4% (WACC 9.5%条件下)**
> **敏感性: WACC 9.0%→关注(+19%) | WACC 10.0%→审慎关注边界(-8.7%)**

## 不适用场景

- 市值<$500B的公司: 使用标准估值框架
- 可能性宽度≥7(发现系统): 本身就不给单一评级，不需要本Skill
- Pre-revenue公司: OVM框架优先
