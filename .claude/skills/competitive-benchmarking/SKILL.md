# 竞争对标深度分析 v1.0

> **来源**: VRT 英维克对标(§7.2.7, 4K字/5 DM) + ANET Cisco 1998类比(Ch11, 4.5/5)
> **核心价值**: 将竞争分析从"列举竞争者"升级为"通过对标公司的镜子看清被分析公司"
> **冠军案例**: 英维克对标揭示GB300开放化=液冷份额命门 | Cisco类比预警ANET估值极端

## 触发条件

以下**任一**条件满足时强制执行:

| 条件 | 检测方法 | 对标类型 |
|------|---------|---------|
| 被分析公司有直接中国竞争对手 | Phase 0行业扫描/CQ讨论 | **M1 中国对标** |
| 公司当前状态有清晰历史前例 | Phase 1业务分析中识别 | **M2 历史类比** |
| 公司面临结构性份额迁移风险 | Phase 2/3估值中识别 | M1或M2 |

## Mode M1: 中国对标深度分析

> **模板来源**: VRT报告§7.2.7 英维克对标 (4K字符, 5个DM锚点, 1个Mermaid)
> **核心输出**: 通过中国竞争者的视角揭示被分析公司的结构性弱点和市场演进方向

### M1.1 对标公司选择

**筛选标准** (满足≥3条):
- 同一细分市场直接竞争
- 中国A股/港股上市(有公开财务数据)
- 市值≥¥100亿(具有行业代表性)
- 近3年营收增速≥20%(活跃竞争者)
- 在关键技术或客户维度与被分析公司有直接交集

**数据获取优先级**:
1. MCP `baggers_search` 搜索中文公司名
2. WebSearch `{中国公司} 年报 营收 净利润 {YEAR}`
3. WebSearch `{中国公司} vs {被分析公司} 竞争`
4. 如有同花顺/东方财富公开数据，优先使用

### M1.2 核心财务对比表 (必须)

```markdown
**核心财务对比 — {被分析公司} vs {中国对标}**:

| 维度 | {被分析公司} ({FY}) | {中国对标} ({FY}) | 倍数/差异 | 趋势 |
|------|:----------:|:----------:|:--------:|------|
| 营收 | ${X}亿(¥{Y}亿) | ¥{Z}亿 | **{N}x** | [谁领先] |
| 净利润 | ${X}亿(¥{Y}亿) | ¥{Z}亿 | **{N}x** | [利润率对比] |
| 市值 | ¥{X}亿(${Y}亿) | ¥{Z}亿 | **{N}x** | [市值差距vs营收差距] |
| 毛利率 | {X}% | {Y}% | +/-{Z}pp | [结构性还是周期性] |
| 营收增速 | +{X}% | +{Y}% | [谁更快] | [驱动因素] |
| 研发/营收 | {X}% | {Y}% | [对比] | [追赶者vs领先者特征] |
| PE(TTM) | {X}x | {Y}x | [倍数] | [估值溢价来源] |
```

**规则**:
- 货币统一为人民币对比(便于直观感受规模差距)
- 增长率对比要标注驱动因素差异
- PE差异要归因(A股溢价/行业溢价/增长溢价)

### M1.3 技术/产品矩阵对比 (必须)

```markdown
**{核心技术}矩阵对比**:

| 维度 | {被分析公司} | {中国对标} | 对{被分析公司}含义 |
|------|------------|----------|-----------------|
| 技术路径 | | | |
| 关键客户关系 | | | **[最重要的发现]** |
| 全链条能力 | | | |
| 成本结构 | | | |
| 产能布局 | | | |
| 锁定订单 | | | |
```

**规则**:
- "对{被分析公司}含义"列是关键——每行都必须回答"这对投资论文意味着什么"
- 至少1行要触发**加粗标注**，代表最重要的竞争发现

### M1.4 投资论文含义 (必须, ≥3条)

**{中国对标}对{被分析公司}投资论文的{N}重含义**:

每条含义必须:
1. **有标题** — 一句话概括发现
2. **有论证** — 引用具体数据(DM锚点)
3. **连接CQ** — 明确与哪个CQ相关
4. **可证伪** — 什么未来数据能验证/推翻这个判断

**经典含义模式** (从VRT英维克提炼):

| 模式 | VRT英维克实例 | 泛化描述 |
|------|-------------|---------|
| 供应链开放化实证 | GB300取消排他→英维克获50%份额 | 上游客户多元化策略的实际证据 |
| 路线之争 | 垂直整合(英维克) vs 平台模式(VRT) | 商业模式演进方向的对照实验 |
| 区域直接威胁 | 英维克泰国工厂进入VRT亚太腹地 | 产能全球化带来的区域竞争加剧 |
| 估值泡沫镜鉴 | A股PE 214x vs 美股PE 46x | 概念炒作→价格战→全球定价基准下移 |

### M1.5 竞争力定位可视化 (推荐)

```mermaid
quadrantChart
    title {被分析公司} vs {中国对标}: {核心维度}竞争力定位
    x-axis "{弱}" --> "{强}"
    y-axis "{低}" --> "{高}"
    quadrant-1 "[领导者象限]"
    quadrant-2 "[技术象限]"
    quadrant-3 "[挑战者象限]"
    quadrant-4 "[追赶者象限]"

    "{中国对标}(中国)": [X, Y]
    "[其他竞争者]": [X, Y]
```

### M1.6 DM锚点要求

| 推断(投资论文含义) | DM-INF-0xx 或 DM-SUB-0xx | ≥1 |
| **总计** | | **≥4** |

## Mode M2: 历史类比深度分析

> **模板来源**: ANET报告Ch11 Cisco 1998类比 (4.5/5, excellence_catalog冠军)
> **核心输出**: 通过历史前例的镜子评估当前公司是否"历史重演"

### M2.1 类比识别与验证

**类比候选来源**:
- Phase -1 知识检索(同行业历史案例)
- Phase 0.5 CQ讨论中浮现
- 分析师/卖方报告中频繁引用的类比
- 编排器行业知识库

**类比有效性三问**:
1. **因果相似**: 类比公司面临的因果机制是否与当前公司相同(而非仅表面相似)?
2. **结构可比**: 行业结构、技术周期、竞争格局是否具有可比性?
3. **时间对齐**: 类比公司处于周期的哪个阶段?当前公司对应哪个阶段?

### M2.2 多维度匹配分析 (必须)

```markdown
## {当前公司} vs {历史类比}: {N}维度匹配分析

| 维度 | {历史公司}({年份}) | {当前公司}({年份}) | 匹配度 |
|------|:---------:|:---------:|:-----:|
| 技术垄断 | [描述] | [描述] | ★★★★★ |
| 客户集中 | [描述] | [描述] | ★★★★☆ |
| 管理层行为 | [描述] | [描述] | ★★★☆☆ |
| 估值水平 | [描述] | [描述] | ★★★★★ |
| 竞争格局 | [描述] | [描述] | ★★★★☆ |
```

**规则**:
- ≥4个维度
- 每维度1-5星评分
- 平均≥3★才认为类比有效

### M2.3 结构差异识别 (必须, 防止类比陷阱)

```markdown
## 结构差异: 为什么这次可能不同

| # | 差异维度 | {历史公司}({年份}) | {当前公司}({年份}) | 对结论影响 |
|---|---------|:---------:|:---------:|:--------:|
| 1 | [差异] | [描述] | [描述] | [削弱/增强类比] |
| 2 | [差异] | [描述] | [描述] | [削弱/增强类比] |
| 3 | [差异] | [描述] | [描述] | [削弱/增强类比] |
```

**ANET实例的3个结构差异**:
1. SaaS化(Cisco无→ANET 20%经常性收入)→削弱崩溃类比
2. AI需求(Cisco纯互联网→ANET AI基础设施需求实质)→削弱泡沫类比
3. 回购(Cisco无→ANET $5B回购)→支撑估值底线

**规则**: ≥2个结构差异。任何类比分析不列结构差异=不完整。

### M2.4 定量映射 (推荐)

将历史公司的关键财务轨迹映射到当前公司:

```markdown
| 指标 | {历史公司}(T=0) | {历史公司}(T+2) | {历史公司}(T+5) | {当前公司}(T=0) | 映射预测 |
|------|:-------------:|:-------------:|:-------------:|:-------------:|:-------:|
| 收入增速 | X% | Y% | Z% | X'% | [预测] |
| 利润率 | X% | Y% | Z% | X'% | [预测] |
| PE | Xx | Yx | Zx | X'x | [预测] |
| 股价(指数化) | 100 | Y | Z | 100 | [预测] |
```

### M2.5 投资论文含义

输出结构同M1.4，但额外要求:
- **明确"类比有效概率"**: 基于匹配度和结构差异，给出类比成立的概率估计(如60%)
- **条件化结论**: "如果类比成立(60%概率)，则[影响]；如果结构差异主导(40%概率)，则[影响]"
