# Content Voice Audit v1.0 — 声音校准

> **设计原因**: SBUX和HLT都迭代了4个版本，NVDA迭代了3个。主要扣分反复集中在同样的模式：脚手架句、散文腔、数字不够人话化、数据过密。这些都是已知问题，但每篇初稿还是犯。
>
> **目标**: 把迭代从4轮→2轮。不是打分（P层量化就死了），是找"这篇和标杆最大的差距在哪3个地方"。

---

## 触发条件

文章初稿完成后，品味Agent审读之前（或同时）执行。

## 检测维度 (7个已知反复犯的问题)

从`content_engine_lessons.md`的9次错误和4轮迭代中归纳。按历史犯错频率排序:

### 高频 (几乎每篇初稿都犯)

**V-01: 脚手架句残留**
```
标杆: 直接列数字，读者自己感受到"在算"
初稿常见: "核心问题很简单" / "这说明了..." / "我脑子里算的是另一笔账"
检测: 找所有"替读者思考"的句子。删掉后如果读者仍能理解 → 删
```

**V-02: 数字不够人话化**
```
标杆: "贵了快三分之一" / "产能只用了一半多一点"
初稿常见: "35%" / "56%" / "ε=7.04"
检测: 找所有百分比和小数。朋友吃饭时会这么说吗？不会 → 改
例外: 关键引用数字可精确 ("$189一晚" / "$6.75一杯")
```

**V-03: 数据段无呼吸**
```
标杆: 数据段之间有场景/感受/停顿
初稿常见: 连续3段以上都在列数字
检测: 找连续数据段。超过2段 → 中间插入呼吸
```

### 中频 (约一半初稿会犯)

**V-04: 散文腔泄漏**
```
标杆: "逻辑上挑不出毛病" / "走了"
初稿常见: "漂亮、优雅、自洽" / "干净利落" / 三连修饰
检测: 找形容词堆砌(≥2个连续修饰词) → 最多留一个
```

**V-05: 解释过度（并置后加"所以"）**
```
标杆: "涨不动价，市场选择不看这个，只看开店速度。" (句号结束)
初稿常见: 并置后跟"这意味着..." / "所以..."
检测: 找所有"所以/因此/这意味着/这说明"。删掉后如果并置已经说清 → 删
```

### 低频但致命

**V-06: 疏离术语**
```
标杆: "报表" / "财报"
初稿常见: "10-K" / "Annual Report" / "DCF" / "WACC"
检测: 中文文章里的英文专业术语。有增值的保留(not being stupid)，纯术语删
```

**V-07: 合规越线**
```
标杆: 只摆矛盾，不给结论
初稿常见: 偶尔溜出目标价/百分比/评级
检测: E-01~E-04硬约束快速扫描
```

## 执行流程

### Step 1: 读标杆建立感觉

根据待审文章的类型，选1-2篇最相关的标杆快速重读:
- 消费者日记类 → `sbux_4min_paradox_v4.md`
- 名人操作类 → `ackman_hlt_248_v4.md`
- CEO/管理层类 → `niccol_same_person_v1.md`
- 结构分析类 → `rcl_waterline_v2.md`
- 金融/市场类 → `nvda_fifth_row_v3.md`
- 英文文章 → `rcl_waterline_en_v1.md`

### Step 2: 读初稿找差距

带着标杆的"感觉"读初稿。不是逐条检查规则，是找"哪里读着不对"。

然后用V-01到V-07作为归因工具——"读着不对"的原因通常是这7个之一。

### Step 3: 输出Top 3差距

```
## 声音校准报告
文章: {文件名}
参考标杆: {标杆文件名}

### Top 3差距 (按影响排序)

1. **V-0X: {问题名}**
   位置: 第X段 / 第X-X段
   原文: "..."
   标杆对照: {标杆中类似场景的处理方式}
   建议方向: {不重写，只指方向}

2. **V-0X: {问题名}**
   ...

3. **V-0X: {问题名}**
   ...

### 亮点 (标杆级表现)
- 第X段的{什么}做得和标杆一样好/更好
```

**为什么只找3个**: 一次改3个地方是人能消化的极限。改完再跑一轮，通常就到位了。所以v1→v2→done，不再需要v3v4。

---

## 不做的事

- **不打分** — 分数是P层死亡的开始。"这篇87分"没有任何指导价值
- **不重写** — 写是写作者的事。审计只说"哪里不对"和"标杆怎么处理的"
- **不检查事实** — 那是`content-fact-check`的活
- **不做全面审计** — 只找Top 3。完美主义是迭代的敌人
