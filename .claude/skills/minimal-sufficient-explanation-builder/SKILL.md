# Minimal Sufficient Explanation Builder

## What this skill does
This skill forces clarity.

Use it after the core work is done.

The point is not to make the output short for its own sake.
The point is to remove everything that is not essential.

## Default workflow
Compress the thesis into a few essential lines:

- What is forcing the demand?
- What node is constrained?
- Who owns the economics?
- Why is the market not fully there yet?
- What is the action now?
- What breaks the thesis?

## Key reminder
Do not use this skill too early.
First discover.
Then compress.

## Flexibility
If the situation is genuinely complex, keep nuance.
Compression should improve clarity, not remove truth.
