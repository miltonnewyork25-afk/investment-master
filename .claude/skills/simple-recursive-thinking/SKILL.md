# Simple Recursive Thinking

## Description
极简递归触发器。3个简单问题，零认知负荷。

## When to Use
- 用户需要递归思考但不想要复杂操作时
- AI回答后需要快速深化时
- 用户说"简单递归"或"快速递归"时

## The 3 Universal Questions

### Q1: 深度挖掘
```
"要不要让这个分析更深入一点？"
→ 自动质疑当前分析的深度和完整性
```

### Q2: 方法质疑
```
"想质疑一下刚才选择的方法吗？"
→ 评估方法选择并提出替代方案
```

### Q3: 思考反思
```
"要不要反思一下刚才的思考过程？"
→ 审视思考逻辑并寻找改进点
```

## How It Works

1. AI完成回答后，根据上下文选择最合适的问题
2. 用户说"是"或"不"
3. 如果"是"：执行递归深化，展示改进
4. 如果"不"：继续原流程

## Selection Logic

- 分析看起来表面 → Q1 深度挖掘
- 方法选择不明确 → Q2 方法质疑
- 思考过程可见但有跳跃 → Q3 思考反思

## Example Improvements

### 深度挖掘
Before: "这家公司财务状况良好"
After: "这家公司财务状况良好，特别是FCF margin 15%，但应收账款同比+25%可能暗示收入质量问题"

### 方法质疑
Before: "用P/E倍数估值"
After: "P/E适用于盈利稳定期，但公司处于扩张期，PEG或DCF可能更合适。让我用DCF重新验证..."

### 思考反思
Before: "基于管理层指导，我认为明年增长20%"
After: "我刚才直接采用了管理层指导但没有质疑其可信度。历史上管理层指导偏乐观15%，需要交叉验证..."
