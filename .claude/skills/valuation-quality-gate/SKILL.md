# 估值质量门控 v2.0

> **整合自**: dispersion-honesty-check v1.0 + megacap-valuation-framing v1.0
> **核心职责**: Phase 5估值完成后的元审查——确保离散度标注诚实+巨头估值有条件框架。

## 触发条件

Phase 5 Agent C完成多方法估值**之后**，在写最终评级章节(Ch29/Ch30)之前执行。

**自动模式选择**:
- 市值>$500B → 执行 G1(离散度) + G2(巨头框架)
- 市值≤$500B → 仅执行 G1(离散度)

## Gate G1: 离散度诚实性 (原 dispersion-honesty-check)

> **核心价值**: 离散度是不确定性的量化。用错误的离散度指标就是误导读者。
> **来源**: MSFT v1.0 报告标题2.57x实际方法1.49x

### G1.1 提取三种离散度

```markdown
## 离散度三维拆解

### 方法级
| 方法 | EV ($B) |
|------|---------|
| M1 DCF | $ |
| M2 SOTP | $ |
| M3 Reverse DCF | $ (= 当前市价) |
| M4 外部可比 | $ |
| M5 情景加权 | $ |

**方法离散度**: max/min = **X.Xx** (剔除M3)

### 锚点级
| 锚点 | EV ($B) | 组成 |
|------|---------|------|
| 内生锚 | $ | M1+M2加权 |
| 外部锚 | $ | M4 |
| 情景锚 | $ | M5 |

**锚点离散度**: max/min = **X.Xx**

### 情景级
| 情景 | EV ($B) | 概率 |
|------|---------|------|
| S1 | $ | X% |
| S2 | $ | X% |
| S3 | $ | X% |
| S4 | $ | X% |

**情景离散度**: S_max/S_min = **X.Xx**
```

### G1.2 诚实标注

| 指标 | 数值 | 用途 | 读者应理解为 |
|------|------|------|-----------|
| 方法离散度 | X.Xx | CG14门控指标 | "不同方法给出的估值范围" |
| 锚点离散度 | X.Xx | 独立性诊断 | "独立视角的收敛/分歧程度" |
| 情景离散度 | X.Xx | 可能性范围 | "极端假设下的想象力边界" |

**禁止**: 用情景离散度作为CG14"方法离散度"。
**禁止**: 报告摘要中只报一个离散度不说明类型。

### G1.3 异常诊断

#### 锚点离散度<1.2x时

```markdown
### ⚠️ 锚点收敛诊断

可能原因:
1. ✅ 市场定价高效: 三独立视角确认市价合理
2. ⚠️ 价格锚定: 参数被无意识校准到接近市价
3. ⚠️ 假独立: 锚点共享假设

检验: 内生锚和情景锚是否共享信念集? 外部锚的"质量调整"是否参考市价?
```

#### 方法离散度>3x时

识别最高/最低方法的核心假设差异 → 判断哪个更接近现实 → 考虑调整权重

### G1.4 写入报告

Ch29/Ch30中必须三维呈现:

```markdown
| 离散度类型 | 数值 | 含义 |
|-----------|:----:|------|
| 方法离散度 | X.Xx | [最高方法]与[最低方法]的分歧 |
| 锚点离散度 | X.Xx | 三锚收敛/分歧程度 |
| 情景离散度 | X.Xx | 极端情景范围 |

*注: CG14使用方法离散度(X.Xx)而非情景离散度(Y.Yx)。*
```

Ch1 Protocol Header更新: `| **方法离散度** | X.Xx (方法级) / Y.Yx (情景极端) |`

## Gate G2: 巨头估值框架 (原 megacap-valuation-framing)

> **仅当市值>$500B时执行**
> **核心价值**: 对$1T+巨头，传统估值产出"假精度"——三锚收敛于市价±6%，评级取决于WACC而非分析。
> **来源**: MSFT v1.0 WACC±100bps跨越三个评级区间

### G2.1 巨头声明

Phase 5 Ch29开头写入:

```markdown
### 估值框架声明

本公司市值${MARKET_CAP}B，属于超大市值($500B+)。传统点估值信息贡献有限:
1. WACC合理区间(X%-Y%)对应EV波动$ZB(±W%)
2. 三锚估值必然收敛于市价附近
3. 评级对WACC敏感性远大于业务分析

本章采用**条件框架**: 回答"什么条件下变便宜/贵"。
```

### G2.2 三问强制回答

#### Q1: 市价偏差诊断

三锚加权与市价偏差<±10%时必须触发 → 诊断是"市场高效"还是"模型被锚定"

#### Q2: 参数主导性检测

```markdown
| 参数 | 当前值 | 翻转值 | 所需变化 | 翻转方向 |
|------|--------|--------|---------|---------|
| WACC | X% | Y% | ±Zbps | → [评级] |
| S1概率 | X% | Y% | ±Zpp | → [评级] |
| 终端g | X% | Y% | ±Zbps | → [评级] |

**主导参数**: [哪个参数在合理区间内即可翻转]
**结论**: 评级主要由[参数]决定，业务分析参数对评级影响[有限/中等/显著]
```

**规则**: 任何参数在合理区间内即可翻转 → 报告显式标注**"本评级对[参数]高度敏感"**

#### Q3: 三条不依赖估值的可操作洞见

```markdown
无论{TICKER}"值"$XB还是$YB，以下发现对投资决策均有帮助:

1. **[洞见1]** — [触发条件] — 来源: [章节]
2. **[洞见2]** — [触发条件] — 来源: [章节]
3. **[洞见3]** — [触发条件] — 来源: [章节]

**这三条洞见的决策价值不受WACC选择影响。**
```

每条要求: 引用具体章节 + 可观测触发条件 + 不依赖估值参数

### G2.3 评级表述调整

从: `评级: 中性关注 | 期望回报: +4.4%`
调整为: `评级: 中性关注(条件性) | 期望回报: +4.4% (WACC X%条件下)`
附加: `敏感性: WACC Y%→[评级A] | WACC Z%→[评级B]`

### G2 不适用场景

- 市值<$500B → 标准估值框架
- 可能性宽度≥7(发现系统) → 本身不给单一评级
- Pre-revenue → OVM框架优先

## Gate G3: 三点估值并列模式 (v3.0新增, PDD v2.0教训, P1 升级)

> **核心**: 复杂标的下,单点目标价 = 偷偷做不可知的预测 = 知识不诚实。三点估值并列 = 让读者自己挑选世界观。
> **源自**: PDD v2.0 (黑箱 37% / 治理事件不可预测) → 三点 +6%/+13%/+23% 替代单点。验证有效。

### G3.1 触发条件 (任一即触发)

- **黑箱比例 ≥30%** (R-4 输出, 来自 cognitive-boundary-assessor)
- **现金占 EV ≥40%** (现金主导型, 折扣率不确定性大)
- **治理事件占折价 ≥50%** (治理黑箱主导)
- **多业务段且段间赔率不对称** (M0+M2 同时触发, 段间 odds 差 ≥3x)
- **核心变量是不可观测的政策/事件概率** (PDD reset / M&A 审批 / 监管裁决)

### G3.2 三点估值结构 (强制模板)

```
**三点估值并列** (此报告不提供单点公允价值, 因 [触发条件])

| 锚 | 期望回报 | 来源 | 隐含世界观 |
|---|---|---|---|
| 悲观锚 | +X% | 圆桌 [安全边际派/Too Hard派] | [一句话: 当 X 不发生时] |
| 中性锚 | +Y% | P4 base case (三方法加权) | [一句话: 中性假设] |
| 乐观锚 | +Z% | 圆桌 [反身性派/护城河派] | [一句话: 当 X 发生且超预期时] |

**这三个数字不是"敏感性区间"——是三种不同世界观的入场票。**
- 如果你相信 [乐观条件], 选 +Z%
- 如果你相信 [悲观条件], 选 +X%
- 中间 +Y% 是算术中点, 但 [N/5 圆桌视角真正落在这个数字上]
```

### G3.3 禁止的表达模式

- ❌ "目标价 $X" (单点)
- ❌ "目标价 $X (区间 $X-$Y)" — 区间是装饰, 中点是结论 = 假装区间
- ❌ 三点估值后又给"建议买入价 $X" — 把三点合并成单点 = 自我背叛
- ❌ "概率加权后期望回报 +Y%" 作为唯一结论 — 隐藏赔率结构

### G3.4 正确的表达模式 (PDD v2.0 标杆)

- ✅ 执行摘要前 5 行明确出现 "+X% / +Y% / +Z%" 三个数字
- ✅ 每个数字后跟"何时这个数字是对的" (前提条件)
- ✅ 每个数字标注来源 (圆桌哪派 / P4 base / SOTP 上限)
- ✅ 加权期望值标注"此为算术加权,赔率结构是 [非对称]"

### G3.5 与 R-4 的硬连接

- R-4 输出黑箱 ≥30% → G3 强制触发 → 评级表达"区间 + 条件"
- R-4 输出黑箱 <20% → G3 不触发 → 可单点 (传统模式)
- 中间 20-30% → G3 软触发 → 单点 + 显式信心度标注

### G3.6 与 R-3 (圆桌异议) 的协同

- 圆桌 ≥3/5 异议 → G3 三点估值的"悲观锚"和"乐观锚"必须分别来自异议派和支持派
- 让读者看到"三点估值的两端是真正有支持者的, 不是分析师手算"
