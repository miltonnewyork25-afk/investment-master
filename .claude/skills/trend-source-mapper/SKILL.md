# Trend Source Mapper

## What this skill does
This skill identifies the real source of a trend.

It is used to stop the agent from starting too late at the company result layer.

Do not start from:
- EPS growth
- gross margin expansion
- valuation multiples
- stock price strength

Start from:
- forced demand
- mandatory replacement
- budget increases
- regulatory requirements
- platform shifts
- infrastructure shortages
- standards changes

## Default workflow
1. Identify the upstream demand driver.
2. Decide whether it is forced, semi-forced, or discretionary.
3. Identify who is paying.
4. Check whether the source is one-off, cyclical, or structural.
5. Explain how this source should propagate into the value chain.
6. Note what is still unknown.

## What good use looks like
A good output should make it obvious:
- what is really causing the trend
- why that cause matters
- why it should continue
- why it should affect downstream economics

## Key reminder
Do not confuse company performance with source variables.
The source is upstream.
Revenue and margin are downstream.

## Flexibility
This is a default way to think, not a rigid template.
If a better causal entry point appears, use it and explain why.
