# 离散度诚实性检查 v1.0

> **核心价值**: 离散度是不确定性的量化。用错误的离散度指标就是误导读者对不确定性的感知。
> **来源验证**: MSFT v1.0 (报告标题离散度2.57x = S4$4500/S1$1750, 实际方法离散度1.49x = DCF/SOTP, 锚点离散度1.10x ≈ 无信息)

## 触发条件

Phase 5 Agent C完成五方法/多锚估值**之后**，在写Ch30(评级)之前执行。

## 问题诊断

### MSFT的离散度误导

```
报告声称: 方法离散度 2.57x
实际来源: S4($4,500B) / S1($1,750B) = 2.57x ← 这是情景端点，不是方法

真实的方法离散度:
  DCF:  $3,489B
  SOTP: $2,338B
  外部可比: $3,180B
  → max/min = $3,489/$2,338 = 1.49x

真实的锚点离散度:
  内生锚: $2,902B
  外部锚: $3,180B
  情景锚: $3,185B
  → max/min = $3,185/$2,902 = 1.10x
```

**问题**: 2.57x给读者一种"不确定性很大"的感觉，但三锚实际收敛到±5%以内。真实的分析不确定性远低于2.57x所暗示的。

### 三种离散度的含义

| 类型 | 计算方式 | 含义 | 误用风险 |
|------|---------|------|---------|
| **方法离散度** | max(method_EV) / min(method_EV) | 不同估值方法的分歧程度 | 如果方法共享假设，低离散度不代表高确信 |
| **锚点离散度** | max(anchor_EV) / min(anchor_EV) | 独立锚点间的分歧 | <1.2x = 实质收敛 → 可能是价格锚定 |
| **情景离散度** | S_max / S_min | 极端假设下的可能范围 | 不是"不确定性"——是"想象力边界" |

## 执行流程

### Step 1: 提取三种离散度

从Agent C的估值产出中提取:

```markdown
## 离散度三维拆解

### 方法级
| 方法 | EV ($B) |
|------|---------|
| M1 DCF | $3,489 |
| M2 SOTP | $2,338 |
| M3 Reverse DCF | $3,025 (= 当前市价, 设计如此) |
| M4 外部可比 | $3,180 |
| M5 情景加权 | $3,185 |

**方法离散度**: $3,489 / $2,338 = **1.49x**
**剔除M3后** (RevDCF不是独立方法): $3,489 / $2,338 = **1.49x** (不变)

### 锚点级
| 锚点 | EV ($B) | 组成 |
|------|---------|------|
| 内生锚 | $2,902 | M1+M2加权 |
| 外部锚 | $3,180 | M4 |
| 情景锚 | $3,185 | M5 |

**锚点离散度**: $3,185 / $2,902 = **1.10x**

### 情景级
| 情景 | EV ($B) | 概率 |
|------|---------|------|
| S1 (AI冬天) | $1,750 | 12% |
| S2 (CapEx正常化) | $2,750 | 38% |
| S3 (Azure追赶) | $3,500 | 32% |
| S4 (Agent爆发) | $4,500 | 18% |

**情景离散度**: $4,500 / $1,750 = **2.57x**
```

### Step 2: 诚实标注

```markdown
## 离散度诚实标注

**报告应使用的离散度指标**:

| 指标 | 数值 | 用途 | 读者应理解为 |
|------|------|------|-----------|
| 方法离散度 | 1.49x | CG14门控指标 | "不同方法给出的估值范围" |
| 锚点离散度 | 1.10x | 独立性诊断 | "独立视角的收敛/分歧程度" |
| 情景离散度 | 2.57x | 可能性范围参考 | "极端假设下的想象力边界" |

**禁止**: 用情景离散度作为CG14"方法离散度"门控指标。
**禁止**: 在报告摘要中只报一个离散度数字而不说明是哪种。
```

### Step 3: 异常诊断

#### 锚点离散度<1.2x时触发

```markdown
### ⚠️ 锚点收敛诊断

锚点离散度 = 1.10x (< 1.2x阈值)

**可能原因**:
1. ✅ 市场定价高效: 三个独立视角确认市价合理
2. ⚠️ 价格锚定: 模型参数被无意识校准到接近市价
3. ⚠️ 假独立: 锚点间共享假设导致表面独立实际收敛

**检验方法**: 回答以下问题:
- 内生锚(DCF)和情景锚(S加权)是否共享信念集B1-B8? → [是/否]
- 外部锚(可比)的"质量调整"是否参考了当前市价? → [是/否]
- 如果去掉所有与当前市价相关的校准，三锚是否仍然收敛? → [是/否/未知]

**诊断结论**: [选择原因1/2/3，或组合]
```

#### 方法离散度>3x时触发

```markdown
### ⚠️ 高离散度诊断

方法离散度 = X.Xx (> 3x阈值)

**含义**: 不同方法对公司估值存在根本性分歧。

**要求**:
1. 识别最高和最低方法的核心假设差异
2. 判断哪个方法的假设更接近当前现实
3. 考虑是否应降低异常方法的权重
```

### Step 4: 写入报告

在Ch29/Ch30中，离散度必须以三维方式呈现:

```markdown
### 方法离散度摘要

| 离散度类型 | 数值 | 含义 |
|-----------|:----:|------|
| 方法离散度 | 1.49x | DCF($3,489B)与SOTP($2,338B)的分歧 |
| 锚点离散度 | 1.10x | 三锚实质收敛(±5%)，参见§锚点收敛诊断 |
| 情景离散度 | 2.57x | 极端情景范围$1,750B-$4,500B |

*注: CG14使用方法离散度(1.49x)而非情景离散度(2.57x)。*
```

## Ch1 Protocol Header更新

如果Ch1中有"方法离散度"字段，确保:

| **方法离散度** | 1.49x (方法级) / 2.57x (情景极端) |
