## Tier 3: 评级标准 (三维状态标签)

| 评级 | 期望回报 | 三维状态典型组合 |
|------|---------|----------------|
| **深度关注** | >+30%且有反转信号 | [低估×改善×有催化] |
| **关注** | +10%~+30% | [低估×改善×可能] |
| **低估观察** | >+10%但无反转信号 | [低估×恶化/未确认×无催化] |
| **中性关注** | -10%~+10% | [合理×稳定×—] |
| **审慎关注** | <-10% | [贵×恶化×—] |

好投资 = **低估值安全边际 × 高速发展 × 强护城河**。三维缺一不可。
