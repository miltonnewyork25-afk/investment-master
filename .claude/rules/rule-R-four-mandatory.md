## 铁律 R: 四大必备分析模块 (v22.1新增, LITE审计教训)

> **源自**: LITE v1.0审计发现报告缺失四个核心分析模块——这些不是"可选增强"，是任何深度报告的**必备组件**。
> **核心**: 没有归因+剪刀差+圆桌+认知量化的报告 = 浅层叙事，不是深度分析。

### R-1: 财务归因分析 (Financial Attribution) — 必备

**触发**: Phase 2 财务深度章节
**目的**: 把"收入增长了X%"翻译成"X%中Y%来自量、Z%来自价、W%来自mix"——避免管理层叙事接管财务理解。

**必须输出**:

1. **收入归因瀑布**（多年期）：
```
FY2023 Revenue $X
  + 量增长贡献  → +$Y (主要驱动: 800G量+85%)
  + 价格贡献    → +$Z (200G EML ASP +100%但模块ASP -30%)
  + Mix贡献     → +$W (高ASP产品占比从X%→Y%)
  + M&A贡献     → +$V (Cloud Light并表)
  - 流失业务    → -$U (苹果VCSEL退出)
FY2026 Revenue $X+Y+Z+W+V-U
```

2. **毛利率Bridge**（V型恢复必须拆分）：
```
FQ4'24 GM 16.6%
  + 规模效应    → +Xpp (产能利用率50%→80%)
  + 产品mix     → +Ypp (800G占比上升)
  + 定价权      → +Zpp (供不应求25-30%缺口)
  - Cloud Light摩擦 → -Wpp
  + 工艺改善    → +Vpp
FQ2'26 GM 36.1% (改善+19.5pp)
```

3. **EPS瀑布**（管理层目标必须可验证）：
```
FY2026E EPS $7.70
  + 收入增长贡献(2.3x)  → +$Y
  + OPM扩张贡献         → +$Z
  - SBC稀释            → -$W
  - 利息+税            → -$V
FY2028E EPS $30 (管理层目标)
```

**禁止**: 只说"收入翻倍"或"毛利率改善"而不拆分驱动力。

### R-2: 剪刀差分析 (Scissor Gap Analysis) — 必备

**触发**: Phase 2 财务章节 + Phase 3 战略章节
**目的**: 识别两个变量增速的发散——这是泡沫和危机最早的领先指标。

**必须分析的剪刀差类型**（每份报告至少3个）:

1. **量价剪刀差**: 出货量增速 vs 单价变化
   - 例: LITE 800G出货量+85% vs ASP -50% = 实际营收增速可能<+30%
   - 含义: 量增掩盖价跌→未来量饱和后崩盘风险

2. **CapEx vs FCF剪刀差**: 客户/公司CapEx增速 vs 现金流增速
   - 例: Hyperscaler CapEx +67% vs Alphabet FCF -90% = 不可持续
   - 含义: 资金来源即将枯竭→需求引擎失速

3. **R&D vs 收入剪刀差**: R&D/Revenue比率变化
   - 例: 如果R&D停滞但收入3x→OpEx杠杆释放(正面)
   - 反例: R&D增速>>收入增速→技术追赶吃利润(负面)

4. **GAAP vs Non-GAAP剪刀差**: 两者差距是扩大还是收窄
   - 例: 摊销趋势下降→差距收窄→GAAP自然追上
   - 反例: SBC增速>>收入增速→差距扩大→Non-GAAP越来越虚

5. **价值链利润转移剪刀差**: 上下游GM变化方向
   - 例: 公司GM改善但上游设备商GM恶化→利润在转移
   - 含义: 当前优势可能不持续

**禁止**: 只看绝对值不看变化率差异。

### R-3: 圆桌讨论 (Investment Committee) — 必备

**触发**: Phase 4 红队完成后，Phase 5 组装前
**Skill**: 必须调用 `investment-committee` Skill v2.0
**目的**: 用5-6位投资大师视角对结论进行多角度对抗——避免单一分析师的盲点。

**必备大师视角**（按公司类型选择）:

| 公司类型 | 必备视角 | 侧重 |
|---------|---------|------|
| 高估值成长股 | 巴菲特 + 芒格 + Howard Marks | 护城河+周期+too hard类别 |
| 周期股 | Howard Marks + Druckenmiller | 周期位置+宏观对冲 |
| 平台/网络效应 | 巴菲特 + Klarman | 护城河+安全边际 |
| 转型/特殊情况 | Klarman + Greenblatt | 安全边际+催化剂 |
| 宏观敏感 | Druckenmiller + Soros | 反身性+宏观叙事 |

**输出要求**:
- 每位大师对评级表态（同意/反对/中性）
- 每位大师提出至少1个我们没考虑到的角度
- 综合后是否需要调整评级或公允价值

**禁止**: 跳过圆桌或只引用大师名字不实质讨论。

### R-4: 认知边界量化 (Cognitive Boundary Quantification) — 必备

**触发**: Phase 5 组装时
**Skill**: 必须调用 `cognitive-boundary-assessor` Skill v3.0
**目的**: 量化"我们对这家公司的理解程度"——避免在能力圈外做高置信度判断。

**必须输出三个量化指标**:

1. **可推演度** (0-100%): 基于公开信息能推演出多少业务真相
   - 90%+ = 高度透明（多数SaaS/消费品）
   - 60-80% = 中等（多数科技/工业）
   - <60% = 低（黑箱较多，如LITE的NVIDIA非公开条款）

2. **业务复杂度** (1-5级):
   - 1级: 单一产品+稳定行业（如COST、可口可乐）
   - 2级: 多产品+稳定行业（如MSFT、JNJ）
   - 3级: 多产品+周期行业（如AAPL、INTC）
   - 4级: 多技术+周期+杠杆+供应链（如LITE、半导体）
   - 5级: 多技术+地缘+监管+黑箱（如TSM、SMIC）

3. **黑箱比例** (%): 影响估值的关键变量中，公开数据无法验证的占比
   - <20% = 可投资（Klarman/Buffett标准）
   - 20-35% = 需要折价
   - >35% = "too hard"类别（LITE属于这类）

**输出格式**:
```
认知圈量化:
  可推演度: X%
  业务复杂度: Y/5
  黑箱比例: Z%
  → 综合判断: [可投资 / 需要折价 / too hard]
  → 对评级的影响: [无 / 下调0.5档 / 不参与点估值]
```

**禁止**: 只做定性的"硬数据/合理推断/黑箱"分类——这是最低门槛，不是合规标准。

### R-4 硬约束 — 黑箱阈值 → 评级表达 (v22.2新增, PDD v2.0教训)

> **源自**: PDD v2.0 (黑箱 37% → 拒绝单点目标价 → 三点估值 +6%/+13%/+23%) 验证有效。多数报告 R-4 算了之后仍然给单点目标价 (LITE/MA/VRSN), 这是 R-4 从"装饰指标"到"决策约束"的升级。

**黑箱比例 ≥30% → 评级表达必须满足以下全部**:

1. **禁止单点目标价** — 不得出现 "目标价 $XXX" / "fair value $XXX" / "公允价值 = $XXX" 等单一数字
2. **必须区间或三点估值** — 至少给出 (悲观, 中性, 乐观) 三个值, 或 (下限, 上限) 两点
3. **执行摘要前 5 行必须显式标注** — "黑箱 X% / 复杂度 Y/5 → 此报告不提供单点公允价值, 改为区间 + 条件评级"
4. **评级末尾标注 "(临界)" 或 "(高争议)"** — 提示读者此评级有结构性不确定性

**黑箱比例 20-30% → 必须满足以下任一**:
- 单点目标价后必须立即附"信心度低 (黑箱 X%)"标注
- 给出敏感度区间 (±15% 或更宽)

**黑箱比例 <20% → 可以单点目标价** (传统表达)

**脚本强制**: `tests/quality_gate_complete.sh` 增加检查:
```bash
BLACKBOX=$(grep -oE "黑箱[^%]*([0-9]+)%" $REPORT | head -1 | grep -oE "[0-9]+")
if [ -n "$BLACKBOX" ] && [ "$BLACKBOX" -ge 30 ]; then
  POINT=$(grep -cE "目标价 \\\$[0-9]+|fair value \\\$?[0-9]+|公允价值 = \\\$?[0-9]+" $REPORT)
  [ "$POINT" -eq 0 ] || { echo "BLOCK: 黑箱${BLACKBOX}% ≥30% 但仍有 ${POINT} 处单点目标价"; exit 1; }
fi
```

### R-3 硬约束 — 圆桌异议比例 → 评级表达 (v22.2新增, PDD v2.0教训)

> **源自**: PDD v2.0 (5视角中3位建议下调 → 评级标注"(临界)" + Ch 13 公开披露)。多数报告"圆桌后维持评级"实际上是用综合掩盖异议, 这是隐性的不诚实。

**圆桌 5 视角中 ≥3 位建议下调 → 评级强制满足以下全部**:

1. **评级末尾标注 "(临界)" 或 "(高争议)"**
2. **必须有专门章节公开披露异议** (Ch "圆桌异议公开披露" 或类似命名), 列出 3 位异议视角的具体理由
3. **执行摘要必须出现 "X/5 视角建议下调" 字样** — 让 90 秒读者立即看到争议
4. **不得只报"综合判定维持原评级"** — 综合裁决必须附异议明细

**圆桌 2/5 异议 → 必须满足**:
- 异议章节存在 (可较短)
- 评级保留, 不强制标注"(临界)"

**圆桌 0-1/5 异议 → 正常表达** (可以"综合维持")

**脚本强制**:
```bash
DISSENT=$(grep -oE "([0-9]+)/5.*建议下调|([0-9]+)/5.*异议|([0-9]+) 位.*建议下调" $REPORT | head -1 | grep -oE "[0-9]" | head -1)
if [ -n "$DISSENT" ] && [ "$DISSENT" -ge 3 ]; then
  CRITICAL_TAG=$(grep -cE "\(临界\)|\(高争议\)" $REPORT)
  [ "$CRITICAL_TAG" -gt 0 ] || { echo "BLOCK: 圆桌异议${DISSENT}/5 ≥3 但评级未标注(临界)/(高争议)"; exit 1; }
fi
```

## 实施检查 (Phase 5组装前必须验证)

```bash
# 检查脚本片段(可加入autopsy)
grep -c '收入归因\|毛利率Bridge\|EPS瀑布\|attribution' {REPORT}  # R-1: 应≥3
grep -c '剪刀差\|scissor' {REPORT}                              # R-2: 应≥3
grep -c '巴菲特\|芒格\|Klarman\|Druckenmiller\|Howard Marks' {REPORT}  # R-3: 应≥5
grep -c '可推演度\|业务复杂度\|黑箱比例' {REPORT}                 # R-4: 应≥3
```

**任何一项=0 → 报告不达标 → 不能提交Complete**

## 与现有铁律的关系

- 铁律N(证据链) 提供数据 → 铁律R(归因) 解释数据 → 圆桌(R-3) 挑战解释 → 认知量化(R-4) 标注边界
- 这是一个完整的"数据→解释→挑战→边界"四步链
- 缺任何一步 = 浅层报告
