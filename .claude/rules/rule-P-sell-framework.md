## 铁律 P: 卖出框架标准化 (v19.8新增, 55份报告蒸馏)

> **源自**: 55张digest card蒸馏, PE上限纪律出现59次(所有卖出教训中最高频)
> **核心诊断**: 报告中有KS(Kill Switch)但没有系统的卖出框架 — 投资者知道什么时候买但不知道什么时候卖

### 每份Tier 3报告的执行摘要必须包含卖出框架

```yaml
sell_framework:
  pe_ceiling:         # PE>Xx → 减仓Y% (59次验证, 最强信号)
    threshold: ""     # 具体PE上限
    action: ""        # 减仓比例
    reasoning: ""     # 为什么这个PE是上限

  cycle_peak:         # 周期高点信号 (20次验证)
    signal: ""        # 什么指标到什么水平
    action: ""

  insider_signal:     # 内部人行为信号 (14次验证)
    signal: ""        # CEO卖出/零买入/言行矛盾
    action: ""

  buyback_waste:      # 回购效率信号 (10次验证)
    signal: ""        # eta<0.8
    action: ""

  thesis_break:       # 核心论点断裂 (Kill Switch)
    signal: ""        # 哪个承重墙断裂
    action: ""        # 通常是全部卖出
```

### 卖出信号的三级响应

| 级别 | 含义 | 行动 | 典型信号 |
|------|------|------|---------|
| **Warning** | 需要关注但不紧急 | 重新评估, 不立即行动 | 内部人开始卖出/PE接近上限 |
| **Action** | 需要执行减仓 | 减仓25-50% | PE突破上限/周期高点确认/eta<0.7 |
| **Emergency** | 核心论点被颠覆 | 全部卖出 | 承重墙断裂/监管颠覆/会计欺诈 |

### 五大卖出教训 (跨55份报告验证)

1. **PE上限纪律** (59次): 垄断型公司的卖出纪律=PE上限。品质不随PE变化，但回报随PE急剧变化
2. **周期高点减仓** (20次): 含大量周期性收入的公司，在利率/周期高点应review仓位
3. **内部人跟随** (14次): CEO说看好+CEO在卖→矛盾信号。零买入>12月=强负面
4. **回购毁灭** (10次): 高PE回购=用$1买<$1的价值。eta<0.8时应质疑
5. **创新者机会成本** (2次但洞察力强): 长期持有守成者的机会成本=错过创新者超额回报(CBOE+208% vs CME+91%)
