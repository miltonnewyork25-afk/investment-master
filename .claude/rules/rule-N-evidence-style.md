## 铁律 N: 证据链完整性 (v19.2新增, 质量下降核心根因)

> **源自**: KLAC因果推理密度9.28/万字(4.5分) vs ADBE仅2.94/万字(~3.0分) — 因果推理密度下降68%
> **核心诊断**: 近期报告质量下降的根因不是字数少或DM少, 而是**每个观点背后的证据链从4层变成了0层, 断言替代了推理**

### 什么是完整的证据链

```
KLAC标杆 (每个论点4层):
  观点: "KLA在下行周期中有定价权保护"
  ├── 证据1(数据): 检测设备占fab CapEx仅5-7% [DM-BIZ-001]
  ├── 证据2(逻辑): 不买检测的代价(良率崩塌) >> 检测成本 → 经济不对称
  ├── 证据3(历史): WFE下行周期中检测削减幅度 < 沉积/刻蚀
  └── 推理: 经济不对称 → 客户不敢砍 → 定价权 → 下行Beta<1

ADBE反例 (0层):
  观点: "护城河迁移进度约25%"
  └── (无证据, 无推理, 无来源, 25%从哪来?)
```

### 证据链最低标准 (每个核心论点)

**每个影响估值的核心论点必须包含:**
1. **≥1个硬数据** — 来自10-K/10-Q/行业报告的具体数字, 带DM锚点
2. **≥1个因果推理** — "因为X→所以Y"的逻辑链, 不是"X，并且Y"的并列
3. **≥1个反面考量** — 这个论点在什么条件下不成立？(防止单边论证)

**核心论点定义**: 直接影响估值结论的论点。通常包括:
- 增长假设的每个关键驱动因素
- 护城河强度的每个维度判断
- 风险评估的每个概率赋值
- 竞争格局的每个市占率判断

### 因果推理密度门控

| 密度 | 判定 | 标杆 |
|------|------|------|
| ≥ 8.0/万字 | 优秀 | KLAC (9.28) |
| 5.0-8.0 | 合格 | |
| 3.0-5.0 | 警告(证据链偏弱) | MCO (4.27) |
| **< 3.0** | **证据链断裂** | ADBE (2.94), MSCI v1.0 (2.20→v3.0 9.93) |

**检查方法**: `grep -c '因为\|因此\|这意味着\|这解释了\|这一' {REPORT}` / `wc -m {REPORT}` × 10000

### 禁止的写作模式

1. **断言型**: "X的护城河很强" — 没有证据，没有推理，读者凭什么信你？
2. **并列型**: "X有A、B、C三个优势" — 列清单不是分析，每个优势需要独立论证
3. **概率凭空型**: "X有30-40%概率" — 概率从哪来？基准率是什么？可比案例？
4. **结论先行型**: 先写结论再找证据 → 确认偏差 → 只看到支持结论的证据

### 正确的写作模式

```
论点 → 证据(数据+来源) → 推理(因为→所以) → 反面(什么条件下不成立) → 结论
```

这不是"更多字数"，是**更诚实的分析**。投资者的钱依赖这些推理链的质量。

### 降认知负荷写作 (v3.2新增, Phase 1-4写作时遵守)

> **目标**: 不降低分析深度，只降低理解成本。有投资经验但不熟悉本行业的读者也能快速看懂。

**规则A — 一段只做一件事**:
每段只承担一个功能: 解释商业模式 / 论证护城河 / 分析增长 / 评估风险 / 说明估值含义。
不要一段混多个任务——读者需要在段落间"切换思维"时认知负荷最高。

**规则B — 先结论后展开**(段落内部):
```
1. 本段核心判断(一句话)
2. 1-2个最关键证据(有DM锚点)
3. 这说明了什么(因果链)
4. 对投资判断有什么影响
5. 什么会证伪
```
禁止: 先铺2段背景再给结论。读者在看到结论前读的每个字都是"猜这段在说什么"的认知开销。

**规则C — 抽象词必须翻译成投资语言**:
如果写了这些词——必须立刻翻译:

| 抽象词 | 必须落到 |
|--------|---------|
| 平台/生态 | 定价权 或 转换成本 或 网络效应 |
| 协同 | 交叉销售收入增量(具体$) |
| 差异化 | 客户为什么不选替代品(具体原因) |
| 创新 | R&D投入→产出了什么产品→带来多少收入 |
| 可选性 | 如果成功值$X，概率Y%，期权价值$Z |

```
❌ "公司拥有强大的平台生态和差异化优势"
✅ "QuickBooks的62-80%市占率+46,000家CPA推荐网络构成了转换成本壁垒——
    迁移需要重建3-7年会计数据，成本$2-5M"
```

**规则D — 句子要短**:
一句一个意思。少用长从句、嵌套句、连续转折。能删就删。

```
❌ "尽管公司在过去几年中通过一系列战略举措和产品创新，在多个垂直行业建立了
    较强的竞争优势，但考虑到宏观经济不确定性和行业竞争加剧的趋势，我们认为
    其未来增长可能面临一定的挑战。"
✅ "过去5年公司在3个垂直行业建立了份额优势。但宏观放缓+竞争加剧可能让增速
    从12%降至7-8%。关键变量是企业IT预算增速——如果<5%就会直接冲击新签约。"
```

**规则E — 多用比较和因果，少下定义**:
```
✅ "更像Costco(会员费模式)而不像Walmart(商品差价模式)"
✅ "这是量的故事,不是价的故事——客户数+15%但ARPU持平"
✅ "真正关键变量是NRR——如果<100%说明老客户在流失"
❌ "NRR是衡量企业SaaS业务中存量客户年度收入变化的指标..."(教科书定义)
```

**规则F — 只写影响判断的信息**:
不影响当前投资判断的信息——删。有趣但无助于判断的——删。
每个段落问自己: "如果删掉这段，投资结论会变吗？" 不会变=删。

### 写作风格: 专业友好型 (Professional-Friendly)

> **读者画像**: 专业投资者，财务基础扎实，但不一定熟悉每个行业。把他们当成"聪明的外行"——不需要解释PE是什么，但需要解释NRR为什么重要。
> **风格锚**: Howard Marks备忘录(机制解释) × Economist杂志(首提定义) = 既不科普也不堆术语

### 写作时自检——每段落3秒检验 (v3.0新增, MA教训)

> **MA教训**: 报告中大量"X很强""Y优秀""Z领先"的断言，但没有一个有数据支撑。
> **根因**: AI在context压力下优先"写完"而非"写对"——断言比论证省3倍token。
> **解决**: 每写完一个段落，执行3秒检验——不通过就当场补。

**3秒检验**(写每个段落后立即执行):
```
问自己: 这段话是断言还是论证?

断言(❌): "X的护城河很强"
论证(✅): "X的护城河强度体现在转换成本——5年平均客户留存率94.3%[DM-BIZ-012]，
          因为迁移需要重建3-7年的历史数据(平均成本$2.5M)，
          但如果竞品推出免费迁移工具(如2024年Competitor Y的Migration Suite)，
          这个壁垒可能在2-3年内减弱50%"

检验标准:
  ✅ 有≥1个具体数字(94.3%/$2.5M)
  ✅ 有DM锚点[DM-xxx]
  ✅ 有因果链(因为X→所以Y)
  ✅ 有反面(什么条件下不成立)
  ❌ 缺任何一项=当场补，不要"先写完再补"——写完就忘了
```

**为什么"当场补"比"事后补"好**:
- 当场补: 你正在写这个话题，上下文在脑中→补证据只需1分钟
- 事后补: 你已经忘了为什么写这个结论→需要重新查数据→5分钟
- "先写完"心态=铁律#6"禁止骨架扩写"的违反——骨架就是没有证据的断言集合

**脚本强制**(无法绕过): `phase_sentinel.sh Layer 3.3`自动检测断言密度。
断言/证据占比>50%=FAIL→必须回补DM锚点后才能继续。

**规则2 — 公式说人话**: 首次出现的公式解释"在衡量什么"

✗ 错误: 独立章节"关键术语: NRR=净收入留存率..."

### DM密度/因果密度互补规则 (v3.1新增, EVO-NOW-03)

> **来源**: NOW v1.0 — 因果密度13.9/万字(全报告最高)但DM密度0.95/千字(全报告最低)
> **问题**: D1评分6.5严重拖累总分, 但分析深度实际最高
> **根因**: DM是"引用纪律"(可通过backfill提升), 因果是"思维深度"(不可事后补)

**互补评分规则**:
```
标准情况: DM≥1.5且因果≥5.0 → D1和D3独立评分
补偿情况: DM<1.5但因果≥10.0 → "分析深度补偿":
  D1最低分=6.5(非0), 因为分析深度证明数据基础存在(只是标注不足)
  建议: 优先DM backfill提升D1, 不惩罚D3
反向情况: DM≥2.0但因果<5.0 → "数据堆砌警告":
  D3 cap at 6.0, 因为大量引用但无推理=清单型报告
```

**核心理念**: DM标注是"引用纪律"问题——数据存在但未标注DM锚点=可修复。因果推理是"思维深度"问题——没有因果链=不可事后补。两者都重要但因果>DM(因果不可补, DM可以backfill)。
