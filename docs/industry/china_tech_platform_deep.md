### CT01: VIE结构风险定价 (VIE Structure Risk Pricing)

**适用**: 全部在美上市中概股
**核心问题**: VIE合同权利vs实际资产所有权的折价应该是多少？折价是收窄还是扩大？

#### 1. VIE架构三层风险分解

```
Layer 1: 法律风险 — VIE合同在中国法院从未被测试过
  ├── 中国政府从未正式承认或否认VIE合法性
  ├── MOFCOM容忍但不背书(行政默许≠法律保护)
  └── 评分: 0-10 (10=法律明确保护, 0=可能随时失效)

Layer 2: 执行风险 — 即使合同有效，跨境执行能力
  ├── 中国法院vs开曼法院管辖权冲突
  ├── 资产冻结/资金回流限制可能性
  └── 评分: 0-10

Layer 3: 政策风险 — 监管态度变化风险
  ├── 新VIE上市几乎停滞(2024年仅5家, 2025年初2家)
  ├── 现存大型VIE被取缔的概率极低但非零
  └── 评分: 0-10
```

#### 2. VIE折价量化模型

```python
def vie_discount_rate(legal_score, execution_score, policy_score,
                      dual_listing=False, market_cap_bn=0):
    """
    VIE折价率计算
    - 三层风险评分各0-10，10=最安全
    - dual_listing=True 如有港股双重主要上市(提供退路)
    - market_cap_bn: 市值越大，被取缔概率越低(too-big-to-fail)
    """
    # 基础折价 = 30分满分距离 × 单位折价
    base_risk = (30 - legal_score - execution_score - policy_score) / 30
    base_discount = base_risk * 0.25  # 最大折价25%

    # 双重上市对冲: 港股主要上市可减少折价
    listing_hedge = 0.40 if dual_listing else 0.0  # 最多减少40%折价

    # 规模对冲: 市值>$100B的VIE被取缔概率极低
    size_hedge = min(market_cap_bn / 500, 0.30)  # 最多减少30%折价

    effective_discount = base_discount * (1 - listing_hedge) * (1 - size_hedge)
    return round(effective_discount, 4)

# BABA示例:
# legal=4, execution=5, policy=6, dual_listing=True, market_cap=355
# base_discount = (30-15)/30 * 0.25 = 12.5%
# after listing hedge: 12.5% * 0.60 = 7.5%
# after size hedge: 7.5% * (1 - 355/500) = 7.5% * 0.71 = 5.3%
```

#### 3. VIE折价趋势判断

| 信号 | 收窄(+) | 扩大(-) |
|------|---------|---------|
| PCAOB审计 | 连续合规 | 任何受阻信号 |
| 新VIE上市 | 恢复 | 继续停滞 |
| 中美关系 | 贸易协议/缓和 | 新制裁/关税 |
| 港股机制 | Stock Connect扩大 | 限制南向资金 |
| 监管信号 | 明确承认VIE合法 | 出台限制性法规 |

**输出工件**: VIE三层风险评分 + 折价率计算 + 趋势方向判断

### CT02: 中国监管周期框架 (China Regulatory Cycle)

**适用**: 全部中国科技公司
**核心问题**: 监管周期处于什么位置？当前是紧缩、稳定还是宽松？

#### 1. 监管温度计 (Regulatory Temperature Gauge)

```yaml
监管温度: -5(极度紧缩) 到 +5(极度宽松)

量化信号:
  政策信号:
    - 最高领导层对科技企业家态度: [-5 to +5]
    - 反垄断罚款频率和规模: [-5 to +5]
    - 新审批(IPO/牌照/业务扩展): [-5 to +5]
    - 数据安全法执行强度: [-5 to +5]

  市场信号:
    - 中概股vs美股大盘相对表现: [-5 to +5]
    - 科技板块资金流向: [-5 to +5]
    - 新VIE上市数量: [-5 to +5]

  综合温度 = 各信号加权平均
```

#### 2. 中国科技监管周期定位

| 阶段 | 时期 | 温度 | 关键事件 |
|------|------|------|----------|
| 黄金时代 | 2014-2020.10 | +3~+5 | 鼓励创新，宽松监管 |
| **急冻** | 2020.11-2021.12 | -4~-5 | 蚂蚁IPO叫停，反垄断风暴，教培清零 |
| 寒冬 | 2022.01-2023.06 | -2~-3 | 持续罚款，数据安全法，游戏版号暂停 |
| 解冻 | 2023.07-2024.08 | 0~+1 | 罚款减少，游戏版号恢复，平台经济鼓励 |
| **回暖** | 2024.09-现在 | +2~+3 | 阿里整改完成，习近平会见马云，蚂蚁上市推进 |

#### 3. 监管传导链

```
中央政策信号 → SAMR/网信办执行 → 公司合规成本变化
                                     ↓
                               业务调整(收缩/扩张)
                                     ↓
                               收入/利润影响(6-18个月滞后)
                                     ↓
                               估值重定价(市场预期调整)
```

#### 4. 监管风险矩阵（中国特化版）

| 监管维度 | 当前状态 | 影响评估 | 概率 |
|----------|---------|---------|------|
| 反垄断(SAMR) | 整改完成,宽松 | 罚款/业务限制 | 低 |
| 数据安全(网信办) | 合规要求稳定 | 合规成本增加 | 中 |
| 金融监管(人行/金监) | 蚂蚁去风险化完成 | 业务范围限制 | 中低 |
| 平台用工(人社部) | 外卖/快递用工规范 | 人力成本上升 | 中 |
| 内容监管(广电) | 常态化 | 内容审核成本 | 低 |
| 跨境监管(商务部) | Temu受美国监管风险 | 跨境业务调整 | 中高 |
| AI监管 | 2026.1生效新规 | 合规+算法备案 | 中 |

**输出工件**: 监管温度计读数 + 周期定位 + 监管风险矩阵 + 传导链影响量化

### CT04: 双币双市估值框架 (Dual-Currency Dual-Market Valuation)

**适用**: 所有ADR+港股双重上市中概股
**核心问题**: 如何在两个市场、两种货币之间建立统一估值锚？

#### 1. ADR-港股价差分析

```yaml
价差组成拆解:
  理论平价: ADR价格 = 港股价格 × ADS比率 × 汇率
  # BABA: 1 ADS = 8普通股
  # 价差 = (ADR实际价 - 理论平价) / 理论平价

  价差驱动因素:
    - 流动性溢价/折价: 美股流动性更好 → ADR通常小幅溢价
    - 投资者结构差异: 美股机构+散户 vs 港股+Stock Connect
    - 交易时段差异: 非重叠时段信息冲击
    - 套利成本: 转换费用+时间+资本管制
    - 地缘风险定价差异: 美国投资者vs亚洲投资者对中国风险的感知差异

  套利机会评估:
    - 价差>3%且持续>5个交易日 → 可能存在结构性因素
    - 价差<1% → 套利机制有效运作
```

#### 2. 汇率敏感性框架

```yaml
BABA汇率暴露分析:
  收入端:
    - 中国电商: ~80%收入, CNY计价 → 高CNY暴露
    - 国际电商: ~15%收入, 多币种(EUR/SGD/TRY/BRL)
    - 云服务: ~5%收入, 主要CNY

  成本端:
    - 人力: 主要CNY
    - 数据中心: CNY + USD(进口设备)
    - 内容/营销: 主要CNY

  净暴露: 收入和成本均CNY主导 → 天然对冲
  ADR投资者额外暴露: CNY/USD汇率影响ADR价格

  敏感性测试:
    CNY贬值10%:
      - CNY收入不变, USD折算减少10%
      - 短期: ADR价格承压
      - 长期: 出口竞争力提升(跨境电商受益)
```

#### 3. Stock Connect影响评估

```yaml
Stock Connect效应:
  开放时间: 2024年8月BABA获港股主要上市地位后生效
  影响维度:
    - 新增投资者池: 大陆投资者首次可买阿里
    - 资金流向追踪: 南向资金净买入/卖出趋势
    - 估值效应: 大陆投资者通常给中国科技更高估值(本土偏好)
    - 波动性影响: 散户占比提高 → 短期波动可能增大
```

**输出工件**: ADR-港股价差分析 + 汇率敏感性矩阵 + Stock Connect资金流追踪

#### 3. 集团折价/溢价评估

```python
def conglomerate_discount_assessment(sotp_value, market_cap,
                                      hidden_assets_value,
                                      governance_score):
    """
    集团折价评估
    - sotp_value: 各业务线独立估值之和
    - market_cap: 当前市值
    - hidden_assets_value: 隐藏资产估值(中值)
    - governance_score: 治理评分(0-10, 10=最佳)
    """
    total_intrinsic = sotp_value + hidden_assets_value
    current_discount = 1 - (market_cap / total_intrinsic)

    # 合理集团折价范围(中国科技)
    # 基础折价10-15% + VIE折价5-10% + 治理折价0-10%
    governance_penalty = max(0, (5 - governance_score)) * 0.02
    fair_discount = 0.12 + 0.07 + governance_penalty  # ~19-29%

    return {
        'current_discount': current_discount,
        'fair_discount_range': (0.15, 0.30),
        'mispricing': current_discount - fair_discount,
        'hidden_assets_contribution': hidden_assets_value / total_intrinsic
    }
```

| Kill Switch | 触发条件 | 严重度 | 特有性 |
|------------|----------|--------|--------|
| VIE失效 | 中国政府明确否定VIE合法性 | **Fatal** | 中国独有 |
| ADR强制退市 | PCAOB审计受阻+HFCAA启动 | Hard | 中国独有 |
| 监管急冻重演 | 监管温度降至-3以下 | Hard | 中国独有 |
| 资本管制收紧 | 跨境资金回流限制 | Hard | 中国独有 |
| 电商份额崩溃 | 核心电商GMV连续2季负增长 | Hard | 电商公司 |
| 云客户流失 | 云收入增速降至<10%连续2季 | Soft | 云业务 |
| AI投资打水漂 | CapEx/Revenue>15%且云增速<15%持续4季 | Soft | AI投资公司 |
| 台海冲突升级 | 实际军事行动或全面制裁 | **Fatal** | 全部中概 |
| 宏观衰退 | 中国GDP增速<3%连续2季 | Hard | 全部中概 |
| 管理层信任危机 | 重大治理丑闻或高管集体离职 | Hard | 通用 |

> **Fatal级**: 出现即终止分析，不存在估值讨论空间
> **表述规范**: "台海冲突"而非其他措辞(遵循发布合规第零律)

## Phase执行指南 (中国科技适配)

### Phase 0: 数据预取 + 中国维度校准

标准data-prefetch流程外，**必须新增**:
1. **监管温度计校准**: WebSearch最近3个月监管信号 → CT02温度计评分
2. **VIE风险基线**: 最新PCAOB状态 + 新VIE上市数量 → CT01基线
3. **汇率快照**: CNY/USD当前+12个月趋势 → CT04基线
4. **竞对快报**: PDD/JD最新季报关键数字 → CT03基线

### Phase 1: 基础分析 + CT01-CT06全部启动

CT模块与标准模块并行执行:
- **TP01(平台经济学) + CT03(电商竞争)** → 合并为"平台与竞争"章
- **TP03(云基础设施) + CT05(AI生态)** → 合并为"云与AI"章
- **CT01(VIE) + CT02(监管)** → 合并为"制度风险"章
- **CT04(双币估值)** → Phase 3估值时使用
- **CT06(集团结构)** → Phase 3 SOTP时使用

### Phase 3: 发现系统适配 (PW=7)

标准发现系统Parts 1-7外，**中国科技额外要求**:
- **Part 2 不确定性类型**: BABA = A型(类别不确定) + C型(转型不确定)混合
  - A型: 电商→云→AI→金融科技 多条独立业务线可能组合
  - C型: 核心电商面临PDD/抖音范式转换威胁
- **Reverse DCF必须双币**: 同时用CNY和USD做隐含假设分析
- **条件评级必须含VIE条件**: "在VIE结构维持有效的前提下..."
- **Kill Switch必须含CT专用**: Fatal级KS(VIE失效/台海冲突)单独标注

### Phase 5: 估值特殊处理

- **SOTP + CT06**: 四板块独立估值 + 隐藏资产 + 集团折价
- **VIE折价叠加**: CT01折价率应用于SOTP总值
- **发现系统不给目标价**: 但需给出条件估值范围(含VIE/监管/AI回报三维条件)
- **巨头估值框架触发**: 市值$355B > $500B阈值? → 当前未触发，但蚂蚁上市后可能触发
