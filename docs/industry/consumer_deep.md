## 品牌双轴 B×M 详细维度

### B轴: 品牌强度评估 (Brand Strength)
- **B1 认知度**: 品牌知名度，消费者第一提及率
- **B2 偏好度**: 品牌偏好，购买意愿相对竞品
- **B3 忠诚度**: 复购率，价格容忍度，推荐意愿
- **B4 差异化**: 独特卖点，难以替代程度
- **B5 情感度**: 品牌情感连接，文化符号价值

### M轴: 货币化能力评估 (Monetization Power)
- **M1 定价权**: 提价能力，价格弹性系数
- **M2 渗透率**: 市场份额增长潜力，渠道覆盖
- **M3 延展性**: 品牌延伸能力，新品类成功率
- **M4 效率化**: 营销ROI，渠道效率，规模经济
- **M5 平台化**: 生态系统能力，网络效应强度

### 品牌溢价系数计算
```python
def consumer_brand_premium(B_score, M_score):
    base_premium = B_score * M_score / 25  # 归一化到0-1

    if B_score >= 4 and M_score >= 4:  # 顶级品牌
        return 1.3 + base_premium * 0.5  # 30-80%溢价
    elif B_score >= 3 and M_score >= 3:  # 强势品牌
        return 1.15 + base_premium * 0.3  # 15-45%溢价
    elif B_score >= 2 and M_score >= 2:  # 区域品牌
        return 1.05 + base_premium * 0.15  # 5-20%溢价
    else:  # 弱品牌/商品化
        return 1.0  # 无品牌溢价
```

> Phase 0公司分类时必须先确定零售子类型，再选择对应分析模块。

| 子类型 | 代表公司 | 核心逻辑 | SGI预判 | 关键差异化 |

## 大众综合零售专用框架 (WMT/TGT型)

### 核心经济学: EDLP vs Hi-Lo

```markdown
【EDLP (Every Day Low Price) — WMT模式】
原理: 持续低价 → 稳定客流 → 高周转 → 供应商议价 → 更低成本 → 更低价格
核心飞轮: 价格领导力 → 客流量 → 采购规模 → 成本优势 → 价格领导力
关键指标:
- 价格差距(vs竞争对手): 目标维持5-15%价格优势
- 库存周转率: WMT ~8-9x vs 行业5-6x
- EDLP执行一致性: 促销收入占比应<15%

【Hi-Lo (高低价策略) — TGT/传统超市模式】
原理: 常规高价+频繁促销 → 刺激购买 → 利润率较高
关键指标:
- 促销收入占比: 通常30-50%
- 促销ROI: 增量销售/促销成本
- 毛利率: 通常高于EDLP 200-400bps
```

### 全渠道转型分析模块

| 维度 | 核心指标 | WMT基准参考 |
|------|---------|------------|
| **电商渗透率** | 线上GMV / 总收入 | ~15-18% (FY2025) |
| **履约成本** | 每单履约成本(store fulfillment vs DC) | 门店拣货$3-5 vs DC发货$8-12 |
| **全渠道客户价值** | 全渠道客户LTV / 纯线下客户LTV | 通常1.5-2.0x |
| **广告业务** | Walmart Connect收入+增速+利润率 | 高毛利(~70%)增量收入 |
| **会员渗透** | Walmart+会员数/总客户数 | 渗透率提升是关键观察点 |

### 杂货主导地位分析

```markdown
为什么杂货重要(WMT ~60%收入来自杂货):
1. 高频刚需 → 持续客流 → 交叉销售一般商品(GM)
2. 杂货利润率低(~25%毛利) → 但GM利润率高(~35%毛利)
3. 杂货市场份额 → 供应商议价力 → 成本优势护城河

分析要点:
- 杂货vs GM收入拆分趋势 (杂货占比上升=利润率承压信号)
- 杂货市场份额 (WMT ~25-26% US grocery market)
- 自有品牌渗透: Great Value/Sam's Choice vs 品牌商品
- 食品通胀传导能力: 提价幅度 vs CPI食品分项
```

### 大众零售专用KPI仪表盘

| KPI | 公式/定义 | 健康基准 | 预警信号 |
|-----|----------|---------|---------|
| 同店销售增长(comp) | 开业≥1年门店销售YoY | +2-5% | <0%连续2季 |
| 客流量(traffic) | 门店交易笔数YoY | >0% | 连续负增长 |

## 专业垂直零售专用框架 (HD/LOW型)

### 核心经济学: Pro客户飞轮

```markdown
【Pro客户 (专业承包商) — HD收入~50%】
飞轮: Pro专业服务 → 高频大单 → 品类深度投资 → 更强专业性 → 更多Pro客户
关键特征:
- 客单价: Pro ~$1000+ vs DIY ~$75
- 购买频率: Pro 每周多次 vs DIY 每月1-2次
- 品牌忠诚度: Pro极高(时间成本+信任) vs DIY低(价格敏感)
- 数字化: Pro在线下单+门店取货(BOPIS) → 效率驱动

【DIY客户 (自助房主)】
驱动力: 房屋维护+改善项目+季节性+灵感驱动
周期性: 与住房市场强相关(购房→装修→维护)
特征: 低频高客单价项目 + 高频低客单价维护

【Pro vs DIY分析框架】
核心问题: Pro占比趋势 → 反映护城河强度
- Pro占比上升 = HD专业化壁垒加深 ✓
- Pro占比下降 = 可能被专业分销商(如SRS Distribution)抢份额 ⚠
- 拆分方法: 管理层披露 + $1000+交易笔数占比推算
```

### 住房周期分析模块 (HD/LOW必需)

```markdown
【住房周期四因子模型】

Factor 1: 住房存量年龄 (结构性利好)
- 美国住房中位年龄 ~44年 (持续老化)
- 老化 → R&R(修缮翻新)支出 → HD核心需求
- 长期结构性支撑, 与短期周期脱钩
- 数据源: Census Bureau, NAHB

Factor 2: 房屋交易量 (周期性驱动)
- 房屋交易 → 买方装修支出 (交易后12个月内)
- 典型交易后支出: $10K-30K
- 利率↑ → 交易量↓ → HD短期承压
- 但"锁定效应"(低利率房贷持有者不愿搬家) → 就地翻新 → 部分对冲
- 数据源: NAR existing home sales, MBA purchase index

Factor 3: 房价走势 (财富效应)
- 房价↑ → 房主财富感↑ → R&R意愿↑
- 房价↓ → 紧缩, 但基础维护不可推迟
- Case-Shiller指数作为领先指标(6-12个月)

Factor 4: 利率环境 (资金成本)
- 影响路径: 利率 → 房贷可负担性 → 交易量 → HD客流
- HELOC利率 → 大项目融资成本 → 高客单价项目数量
- 当前环境评估: [分析时实时填入]

【周期位置判断矩阵】
| 组合 | 对HD影响 | 历史类比 |
|------|---------|---------|
| 低利率+高房价+高交易量 | 极利好 | 2020-2021 |
| 高利率+高房价+低交易量 | 中性偏负(锁定效应部分对冲) | 2023-2024 |
| 低利率+低房价+高交易量 | 利好(恢复期) | 2012-2015 |
| 高利率+低房价+低交易量 | 不利 | 2008-2009 |
```

## 特许经营/瓶装商经济学专用框架 (KO/MCD型)

### 核心经济学: 浓缩液模式 vs 成品模式

```markdown
【KO的双层架构】

Layer 1: 浓缩液/糖浆业务 (Concentrate Operations)
- KO生产浓缩液 → 出售给瓶装商
- 毛利率: ~60-65% (极高, 近乎纯品牌授权)
- 资本密集度: 极低 (无需灌装线/分销车队)
- 收入占比: ~70%+ 来自浓缩液销售

Layer 2: 成品业务 (Finished Products)
- KO直接完成灌装+分销 (自有瓶装业务)
- 毛利率: ~30-40% (资产较重)
- 资本密集度: 中高 (灌装厂+冷链+配送)
- 近年趋势: KO持续"再特许化"(refranchising) → 向纯浓缩液转型

【估值含义】
- 浓缩液业务 → 轻资产高ROIC → 值更高倍数
- 成品业务 → 重资产低ROIC → 值较低倍数
- 再特许化进度 → 直接影响整体利润率趋势和估值倍数
- SOTP思路: 分开估值浓缩液(高倍数) vs 成品(低倍数)
```

### 瓶装商关系分析

```markdown
【瓶装商体系核心问题】

1. 利益一致性
   - KO希望: 投资品牌+扩品类+提价
   - 瓶装商希望: 控制成本+优化路线+利润率
   - 潜在冲突: KO涨浓缩液价格 vs 瓶装商利润率
   - 观察指标: 瓶装商资本支出趋势, 冷饮设备投放量

2. 主要瓶装合作伙伴
   - Coca-Cola Europacific Partners (CCEP) — 欧洲+亚太
   - Coca-Cola FEMSA (KOF) — 拉美
   - Coca-Cola Consolidated (COKE) — 美国部分
   - 分析: 各合作伙伴的利润率趋势+再投资意愿

3. 再特许化风险/机遇
   - 机遇: 卖出重资产 → 提升ROIC + 聚焦品牌
   - 风险: 失去终端控制力 → 品牌执行一致性下降
   - 衡量: 再特许化后同区域销量增速变化
```

### 品牌组合管理 (200+品牌)

```markdown
【KO品牌矩阵分析】

Tier 1 — 全球旗舰 (~5个品牌, ~70%收入)
  Coca-Cola, Sprite, Fanta, Minute Maid, Dasani
  策略: 最大化渗透+品牌投资+创新变体

Tier 2 — 区域强势 (~15-20个品牌, ~20%收入)
  各区域本地强势品牌
  策略: 区域深耕+选择性全球扩张

Tier 3 — 长尾品牌 (~175+品牌, ~10%收入)
  近年收购/孵化的新品类品牌
  策略: 定期评估→保留/整合/剥离

【组合分析要点】
1. 含糖饮料 vs 无糖/低糖/功能饮料占比趋势
   - 健康趋势 → 含糖品类结构性下滑(发达市场)
   - 但: 新兴市场含糖品类仍在增长
2. 品类多元化进度: 咖啡(Costa)+运动饮料(BodyArmor)+酒精饮料
3. 收入增长归因: 价格 vs 销量 vs 品类结构 (price/mix vs volume)
```

## SGI速判参考值 (消费品行业) (v27.0新增)

> A-Score v2.0 Phase 0, Step 10要求。以下为消费品常见公司的SGI预判参考。

| 公司 | SGI预判 | HHI_rev | R&D_conc | MarketPos | SwitchCost | BrandClarity | 路由 |
|------|--------|---------|---------|-----------|-----------|-------------|------|
| **KO** | 4-5 | 中(饮料为主,但多品类) | 低(品牌驱动非R&D) | 高(碳酸饮料#1) | 低(消费者易切换) | 高(全球最强品牌之一) | 混合模式 |
| **WMT** | 2-3 | 低(SKU极广) | 极低 | 高(零售#1) | 低-中(便利性+Walmart+) | 中(功能性认知) | 通才模式 |
| **HD** | 6-7 | 中高(家居改善聚焦) | 低 | 高(品类#1) | 中高(Pro客户高切换成本) | 高(品类=品牌) | 偏专才模式 |
| **COST** | 4-5 | 低-中(SKU少但品类广) | 极低 | 中(会员仓储#1) | 中(会员锁定) | 高(会员制认知) | 混合模式 |
| **NKE** | 5-6 | 中(运动用品为主) | 中(产品创新) | 高(运动品牌#1) | 低(品牌切换容易) | 极高(全球情感品牌) | 混合偏专才 |

**路由含义**:
- **通才模式** (SGI≤3): 重点分析资源分配效率、跨品类协同、通才陷阱(是否在任何领域都不突出)
- **混合模式** (SGI 4-6): 兼顾品类深度和组合宽度, 分析核心品类护城河+非核心品类价值
- **偏专才模式** (SGI≥7): 聚焦单点失败风险、品类天花板、专才溢价是否被市场充分定价
