## 品牌双轴 B×M 详细维度

### B轴: 品牌强度评估 (Brand Strength)
- **B1 认知度**: 品牌知名度，消费者第一提及率
- **B2 偏好度**: 品牌偏好，购买意愿相对竞品
- **B3 忠诚度**: 复购率，价格容忍度，推荐意愿
- **B4 差异化**: 独特卖点，难以替代程度
- **B5 情感度**: 品牌情感连接，文化符号价值

### M轴: 货币化能力评估 (Monetization Power)
- **M1 定价权**: 提价能力，价格弹性系数
- **M2 渗透率**: 市场份额增长潜力，渠道覆盖
- **M3 延展性**: 品牌延伸能力，新品类成功率
- **M4 效率化**: 营销ROI，渠道效率，规模经济
- **M5 平台化**: 生态系统能力，网络效应强度

### 品牌溢价系数计算
```python
def consumer_brand_premium(B_score, M_score):
    base_premium = B_score * M_score / 25  # 归一化到0-1

    if B_score >= 4 and M_score >= 4:  # 顶级品牌
        return 1.3 + base_premium * 0.5  # 30-80%溢价
    elif B_score >= 3 and M_score >= 3:  # 强势品牌
        return 1.15 + base_premium * 0.3  # 15-45%溢价
    elif B_score >= 2 and M_score >= 2:  # 区域品牌
        return 1.05 + base_premium * 0.15  # 5-20%溢价
    else:  # 弱品牌/商品化
        return 1.0  # 无品牌溢价
```

## 零售子类型分类框架 (v27.0新增)

> 消费品中"零售"不是单一类型。不同零售模式的核心KPI、估值逻辑、周期敏感性完全不同。
> Phase 0公司分类时必须先确定零售子类型，再选择对应分析模块。

### 子类型速判矩阵

|--------|---------|---------|---------|-----------|:----------:|
| **大众综合零售** | WMT, TGT | 规模经济+EDLP+全渠道 | 2-3 (通才) | 价格领导力+供应链效率+杂货主导 | **强制** |

| **会员制仓储** | COST, BJ | 会员费+低SKU+高周转 | 4-5 (混合) | 会员续费率+自有品牌+坪效极致 | **强制** |

## 大众综合零售专用框架 (WMT/TGT型)

### 核心经济学: EDLP vs Hi-Lo

```markdown
【EDLP (Every Day Low Price) — WMT模式】
原理: 持续低价 → 稳定客流 → 高周转 → 供应商议价 → 更低成本 → 更低价格
核心飞轮: 价格领导力 → 客流量 → 采购规模 → 成本优势 → 价格领导力
关键指标:
- 价格差距(vs竞争对手): 目标维持5-15%价格优势
- 库存周转率: WMT ~8-9x vs 行业5-6x
- EDLP执行一致性: 促销收入占比应<15%

【Hi-Lo (高低价策略) — TGT/传统超市模式】
原理: 常规高价+频繁促销 → 刺激购买 → 利润率较高
关键指标:
- 促销收入占比: 通常30-50%
- 促销ROI: 增量销售/促销成本
- 毛利率: 通常高于EDLP 200-400bps
```

### 全渠道转型分析模块

| 维度 | 核心指标 | WMT基准参考 |
|------|---------|------------|
| **电商渗透率** | 线上GMV / 总收入 | ~15-18% (FY2025) |
| **履约成本** | 每单履约成本(store fulfillment vs DC) | 门店拣货$3-5 vs DC发货$8-12 |
| **全渠道客户价值** | 全渠道客户LTV / 纯线下客户LTV | 通常1.5-2.0x |
| **广告业务** | Walmart Connect收入+增速+利润率 | 高毛利(~70%)增量收入 |
| **会员渗透** | Walmart+会员数/总客户数 | 渗透率提升是关键观察点 |

### 杂货主导地位分析

```markdown
为什么杂货重要(WMT ~60%收入来自杂货):
1. 高频刚需 → 持续客流 → 交叉销售一般商品(GM)
2. 杂货利润率低(~25%毛利) → 但GM利润率高(~35%毛利)
3. 杂货市场份额 → 供应商议价力 → 成本优势护城河

分析要点:
- 杂货vs GM收入拆分趋势 (杂货占比上升=利润率承压信号)
- 杂货市场份额 (WMT ~25-26% US grocery market)
- 自有品牌渗透: Great Value/Sam's Choice vs 品牌商品
- 食品通胀传导能力: 提价幅度 vs CPI食品分项
```

### 大众零售专用KPI仪表盘

| KPI | 公式/定义 | 健康基准 | 预警信号 |
|-----|----------|---------|---------|
| 同店销售增长(comp) | 开业≥1年门店销售YoY | +2-5% | <0%连续2季 |
| 客流量(traffic) | 门店交易笔数YoY | >0% | 连续负增长 |

## 专业垂直零售专用框架 (HD/LOW型)

### 核心经济学: Pro客户飞轮

```markdown
【Pro客户 (专业承包商) — HD收入~50%】
飞轮: Pro专业服务 → 高频大单 → 品类深度投资 → 更强专业性 → 更多Pro客户
关键特征:
- 客单价: Pro ~$1000+ vs DIY ~$75
- 购买频率: Pro 每周多次 vs DIY 每月1-2次
- 品牌忠诚度: Pro极高(时间成本+信任) vs DIY低(价格敏感)
- 数字化: Pro在线下单+门店取货(BOPIS) → 效率驱动

【DIY客户 (自助房主)】
驱动力: 房屋维护+改善项目+季节性+灵感驱动
周期性: 与住房市场强相关(购房→装修→维护)
特征: 低频高客单价项目 + 高频低客单价维护

【Pro vs DIY分析框架】
核心问题: Pro占比趋势 → 反映护城河强度
- Pro占比上升 = HD专业化壁垒加深 ✓
- Pro占比下降 = 可能被专业分销商(如SRS Distribution)抢份额 ⚠
- 拆分方法: 管理层披露 + $1000+交易笔数占比推算
```

### 住房周期分析模块 (HD/LOW必需)

```markdown
【住房周期四因子模型】

Factor 1: 住房存量年龄 (结构性利好)
- 美国住房中位年龄 ~44年 (持续老化)
- 老化 → R&R(修缮翻新)支出 → HD核心需求
- 长期结构性支撑, 与短期周期脱钩
- 数据源: Census Bureau, NAHB

Factor 2: 房屋交易量 (周期性驱动)
- 房屋交易 → 买方装修支出 (交易后12个月内)
- 典型交易后支出: $10K-30K
- 利率↑ → 交易量↓ → HD短期承压
- 但"锁定效应"(低利率房贷持有者不愿搬家) → 就地翻新 → 部分对冲
- 数据源: NAR existing home sales, MBA purchase index

Factor 3: 房价走势 (财富效应)
- 房价↑ → 房主财富感↑ → R&R意愿↑
- 房价↓ → 紧缩, 但基础维护不可推迟
- Case-Shiller指数作为领先指标(6-12个月)

Factor 4: 利率环境 (资金成本)
- 影响路径: 利率 → 房贷可负担性 → 交易量 → HD客流
- HELOC利率 → 大项目融资成本 → 高客单价项目数量
- 当前环境评估: [分析时实时填入]

【周期位置判断矩阵】
| 组合 | 对HD影响 | 历史类比 |
|------|---------|---------|
| 低利率+高房价+高交易量 | 极利好 | 2020-2021 |
| 高利率+高房价+低交易量 | 中性偏负(锁定效应部分对冲) | 2023-2024 |
| 低利率+低房价+高交易量 | 利好(恢复期) | 2012-2015 |
| 高利率+低房价+低交易量 | 不利 | 2008-2009 |
```

## 特许经营/瓶装商经济学专用框架 (KO/MCD型)

### 核心经济学: 浓缩液模式 vs 成品模式

```markdown
【KO的双层架构】

Layer 1: 浓缩液/糖浆业务 (Concentrate Operations)
- KO生产浓缩液 → 出售给瓶装商
- 毛利率: ~60-65% (极高, 近乎纯品牌授权)
- 资本密集度: 极低 (无需灌装线/分销车队)
- 收入占比: ~70%+ 来自浓缩液销售

Layer 2: 成品业务 (Finished Products)
- KO直接完成灌装+分销 (自有瓶装业务)
- 毛利率: ~30-40% (资产较重)
- 资本密集度: 中高 (灌装厂+冷链+配送)
- 近年趋势: KO持续"再特许化"(refranchising) → 向纯浓缩液转型

【估值含义】
- 浓缩液业务 → 轻资产高ROIC → 值更高倍数
- 成品业务 → 重资产低ROIC → 值较低倍数
- 再特许化进度 → 直接影响整体利润率趋势和估值倍数
- SOTP思路: 分开估值浓缩液(高倍数) vs 成品(低倍数)
```

## 跨类型分析模块 (v28.0新增)

> **来源**: Costco商业模式研究 × SBUX v2.0深度分析的跨案例范化。
> **适用**: 所有消费品子类型(零售/餐饮/品牌/会员制)。Phase 1必选模块A+D，Phase 3必选模块B。
> **核心理念**: 消费品公司的持久竞争优势不来自单一维度，而来自"意愿-能力-文化-取舍-信任"五者的系统性配合。

### 模块A: 战略意愿×运营能力双轴 (W×C Matrix)

```markdown
【原理】
大多数分析只问"公司能不能做到"(能力)，不问"公司愿不愿意做到"(意愿)。
但消费品的持久竞争优势往往来自一个反商业直觉的选择：有能力赚更多，却选择让利。
Costco有能力用会员数据提价，但选择用数据压价；SBUX有能力削减员工福利提升OPM，但Niccol选择投资员工体验。
意愿和能力是两个独立维度——缺一则护城河不可持续。

【双轴评分 (各1-5分)】

意愿轴 (W) — "公司愿不愿意把省下的钱让给消费者/员工"
  W1: 定价克制度 — 毛利率vs行业均值的差距(低于均值=高克制)
  W2: 员工投资度 — 薪资福利vs行业均值(高于均值=高意愿)
  W3: 股东让利度 — 利润增速是否系统性低于收入增速(是=让利)
  W4: 长期主义度 — 管理层薪酬中长期激励占比(>60%=高)
  W5: 透明承诺度 — 是否有公开、可验证的让利承诺(如Costco 14%毛利上限)

能力轴 (C) — "公司有没有能力把成本做到最低"
  C1: 采购规模优势 — 单SKU采购量vs竞争对手
  C2: 运营效率优势 — SG&A率/库存周转vs行业
  C3: 供应链深度 — 自有品牌渗透率+垂直整合度
  C4: 技术赋能度 — 数字化对成本结构的改善幅度
  C5: 规模飞轮强度 — 规模扩大是否自动降低单位成本

【象限解读】
┌────────────────────┬────────────────────┐
│  高意愿 + 低能力    │  高意愿 + 高能力    │
│  "善意但无力"       │  ★ "稳健比率王者"   │
│  胖东来(区域局限)    │  Costco / Amazon    │
│  风险: 被规模对手挤压│  护城河自我强化      │
├────────────────────┼────────────────────┤
│  低意愿 + 低能力    │  低意愿 + 高能力    │
│  "平庸"             │  "利润最大化者"     │
│  传统超市            │  便利店 / 奢侈品    │
│  无竞争优势          │  护城河可能被侵蚀    │
└────────────────────┴────────────────────┘

【执行时机】: Phase 1品牌分析时，与B×M双轴同时评分
【输出格式】: W分/C分 + 象限定位 + 1-2句判断

【案例速查】
| 公司 | W | C | 象限 | 判断 |
|------|:-:|:-:|------|------|
| COST | 5 | 5 | 王者 | 14%毛利上限=可验证承诺+全球最强采购规模 |
| SBUX | 3 | 3 | 中间 | 意愿方向正确(Niccol)但未证明+OPM恢复中 |
| WMT  | 3 | 5 | 偏能力 | EDLP有让利但也追求利润率提升+供应链极强 |
| MCD  | 2 | 4 | 偏能力 | 特许模式利润最大化+数字化能力强 |
| HD   | 2 | 4 | 偏能力 | Pro定价权强+不追求最低价 |
| DG   | 3 | 3 | 中间 | 下沉市场让利+但品质受限 |
```

### 模块B: 稳健比率 (Robustness Ratio)

```markdown
【原理 — 源自Nomad Investment Partnership】
传统护城河分析问"公司赚了多少"，稳健比率问"消费者和员工获得了多少"。
  稳健比率 = (客户节省 + 员工超额获得) / 股东获得
比率越高，护城河越自我强化——竞争对手要匹配你的价格和薪资，代价越来越大。

【计算方法】

Step 1: 客户节省
  客户节省/会员 = 会员年均消费 × (行业平均毛利率 - 公司毛利率)
  注意: 用可比渠道的毛利率(零售vs零售，不要拿餐饮比零售)

Step 2: 员工超额获得
  超额薪资/会员 = (公司均薪 - 行业均薪) × 员工数 / 会员数(或客户数)
  注意: 含福利(医保、退休金)，不只是时薪

Step 3: 股东获得
  股东获得/会员 = 税前利润 / 会员数(或客户数)

Step 4: 稳健比率
  RR = (客户节省/会员 + 员工超额/会员) / (股东获得/会员)

【基准解读】
| 稳健比率 | 含义 | 护城河自我强化性 | 代表 |
|:--------:|------|:---------------:|------|
| >5:1 | 绝大部分价值给了消费者和员工 | 极强(竞争对手几乎无法匹配) | Costco |
| 3-5:1 | 价值分配偏向消费者 | 强(需要大量资本才能挑战) | Amazon, WMT |
| 1-3:1 | 价值分配较均衡 | 中等(可被有决心的竞争者挑战) | HD, Target |
| <1:1 | 大部分价值留给股东 | 弱(品牌溢价型，可被替代) | SBUX, NKE, 奢侈品 |

【重要警告】
- 稳健比率<1:1不意味着"坏公司"——奢侈品/情感品牌的护城河来自品牌而非价格
- 但稳健比率<1:1的公司面临品类替代风险更高(瑞幸对SBUX, Shein对NKE)
- 高稳健比率=抗侵蚀型护城河; 低稳健比率=品牌依赖型护城河

【与A-Score整合】
- 纳入A-Score"护城河"维度的子指标(权重20%)
- RR>3:1 → 护城河+1.0分; RR 1-3:1 → +0分; RR<1:1 → -0.5分
- 适用范围: 有可比毛利率数据的零售/餐饮公司

【执行时机】: Phase 3估值建模时计算
【数据来源】: 年报(收入/利润/员工数) + Glassdoor/BLS(薪资) + 行业报告(毛利率对比)

【竞争者匹配成本估算(附加)】
  匹配价格的利润损失 = 竞争者客户数 × 客户节省/会员
  匹配薪资的额外成本 = 竞争者员工数 × (目标均薪 - 当前均薪)
  总匹配成本/年 = 价格匹配损失 + 薪资匹配成本
  → 占竞争者年利润的比例 = 总匹配成本 / 竞争者净利润
  → 比例>50% = 几乎不可能匹配 = 极强护城河

【横向对比模板 — 同子类型必须输出】
当一份报告涉及RR"强制"子类型时，Phase 3必须输出以下横向对比表:

| 公司 | 毛利率 | 客户节省/客户 | 均薪溢价 | 员工超额/客户 | 税前利润/客户 | **RR** | 护城河类型 |
|------|:------:|:-----------:|:-------:|:-----------:|:-----------:|:------:|----------|
| [目标公司] | X% | $X | +X% | $X | $X | X:1 | [类型] |
| [可比公司1] | X% | $X | +X% | $X | $X | X:1 | [类型] |
| [可比公司2] | X% | $X | +X% | $X | $X | X:1 | [类型] |
| 行业均值 | X% | — | — | — | — | — | — |

横向对比规则:
- 同子类型内至少对比2家可比公司
- 跨子类型仅作参考注释，不作RR直接对比
- 餐饮(SBUX/MCD/CMG)的"客户节省"用同品类均价作锚点(如咖啡均价)
- 电商(AMZN)的"客户节省"用Prime会员年均节省的配送费+价格差作估算

【RR适用性边界(v28.0明确)】
适用: 大众零售 + 会员仓储 + 折扣零售 + 电商 → Phase 3强制
推荐: 餐饮连锁 → Phase 3推荐(以咖啡/快餐均价为锚点)
仅标品: 专业垂直零售(HD/LOW) → 仅对标准化商品(工具/建材)计算部分RR
不适用: 奢侈品(溢价=价值) + 纯B2B + 金融服务

路由方式: Phase 0子类型判定时自动确定RR适用性(见零售子类型速判矩阵)
```

### 模块C: 文化可衡量性评分 (Culture Measurability Score)

```markdown
【原理】
"好文化"人人想要，但有些文化是可衡量的尺子(每个决策可用它判断对错)，
有些文化是不可衡量的感受(依赖特定领导者的个人魅力)。
可衡量的文化可以制度化传承; 不可衡量的文化随创始人离开而衰退。
这直接影响: CEO继任风险、扩张可持续性、估值倍数稳定性。

【评分维度 (各1-5分, 总分5-25)】

CM1: 规则清晰度 — 文化是否可转化为具体决策规则?
  5分: "毛利不超过14%" (Costco) — 任何采购经理都能执行
  3分: "顾客第一" (Amazon) — 方向明确但执行因人而异
  1分: "将心注入" (SBUX under Schultz) — 感受而非规则

CM2: 可验证性 — 外部人能否验证文化是否在执行?
  5分: 从财报可直接验证(毛利率、薪资水平、扩张速度)
  3分: 需要内部数据但可通过Glassdoor/NPS间接验证
  1分: 完全依赖管理层自述，无外部验证渠道

CM3: 继任韧性 — 创始人/核心领导离开后文化是否存续?
  5分: 3任+ CEO都维持了文化(Costco: Sinegal→Jelinek→Vachris)
  3分: 继任者部分维持(沃尔玛: Sam Walton→后续CEO方向微调)
  1分: 创始人离开文化立即稀释(Schultz两度离开SBUX两度衰退)

CM4: 优先级排序 — 文化是否明确了利益冲突时的排序?
  5分: 清晰排序且不可逆(Costco: 法律>会员>员工>供应商>股东)
  3分: 有排序但在压力下会妥协
  1分: 无明确排序，靠具体情况判断

CM5: 一致性 — 文化承诺与实际行为是否一致?
  5分: 20年+财务数据验证承诺一致(Costco毛利率40年未超14%)
  3分: 大部分一致但偶有例外
  1分: 经常性言行不一

【总分解读】
| 分数区间 | 文化类型 | CEO继任风险 | 估值含义 |
|:--------:|---------|:----------:|---------|
| 20-25 | 制度化文化 | 低 | 支持高倍数(可预测性高) |
| 13-19 | 混合文化 | 中 | 需case-by-case评估CEO |
| 5-12 | 领袖文化 | 高 | CEO溢价/折价显著 |

【执行时机】: Phase 1 CEO/管理层分析时
【应用场景】:
- CEO变更时评估文化断裂风险
- 跨公司对比(同行业不同文化模式的估值差异)
- 评估"空降CEO"(如SBUX Niccol)vs"内部培养"的风险

【案例速查】
| 公司 | CM1 | CM2 | CM3 | CM4 | CM5 | 总分 | 类型 |
|------|:---:|:---:|:---:|:---:|:---:|:----:|------|
| COST | 5 | 5 | 5 | 5 | 5 | 25 | 制度化(标杆) |
| WMT  | 3 | 4 | 3 | 3 | 3 | 16 | 混合偏制度 |
| MCD  | 4 | 4 | 4 | 3 | 3 | 18 | 混合偏制度 |
| SBUX | 2 | 3 | 1 | 2 | 2 | 10 | 领袖依赖 |
```

### 模块D: 战略放弃清单 (Strategic Trade-off Audit)

```markdown
【原理】
任何商业模式的"选择了什么"只是冰山一角——"放弃了什么"才揭示真正的战略纪律。
放弃清单的分析价值:
  1. 验证战略一致性 — 声称的战略与实际放弃的东西是否匹配?
  2. 识别战略漂移 — 过去放弃的东西现在开始尝试=战略漂移信号
  3. 评估竞争壁垒 — 竞争对手能否"不放弃"这些东西同时匹配你?

【放弃清单模板】

对于每家消费品公司，Phase 1必须填写以下表格:

| # | 为了... | 放弃了... | 放弃代价 | 可逆性 | 竞争者能否两者兼得? |
|---|---------|----------|---------|:------:|:------------------:|
| 1 | [核心战略选择1] | [具体放弃项] | [量化代价] | 高/中/低 | 能/不能/部分 |
| 2 | [核心战略选择2] | [具体放弃项] | [量化代价] | 高/中/低 | 能/不能/部分 |
| ... | | | | | |

【分析规则】
Rule 1: 每家公司至少识别5项放弃
Rule 2: 至少2项必须有量化代价(放弃的收入/客户/增速)
Rule 3: "竞争者能否两者兼得"=No的项目，才是真正的护城河来源
Rule 4: 放弃清单中出现"开始尝试"的项目 → 标记为战略漂移预警

【案例: Costco放弃清单】
| # | 为了... | 放弃了... | 放弃代价 | 可逆性 | 兼得? |
|---|---------|----------|---------|:------:|:----:|
| 1 | 最低价格 | 随机客流(仅会员可消费) | 潜在~30%客群 | 低 | 否(会员制是系统性设计) |
| 2 | 精选SKU议价力 | 品类宽度(3,600 SKU vs WMT 100K) | 长尾需求 | 中 | 否(SKU多=议价弱) |
| 3 | 全部直营品控 | 扩张速度(年开25-30店) | 5年+国际亏损 | 低 | 部分(WMT也直营但接受更快开店) |
| 4 | 低刷卡成本 | 支付便利(限定合作银行) | 部分客户体验 | 高 | 能(但每笔多付1-2%) |
| 5 | 极低毛利(11%) | 短期利润最大化 | ~$30B+年收入机会成本 | 中 | 否(组织意愿不可复制) |
| 6 | 高员工薪资留存 | SG&A率优化空间 | ~$2B/年超额人力成本 | 中 | 能(但需文化支撑) |

→ 6项放弃中3项"不可兼得" = 护城河核心来源

【战略漂移预警信号】
如果一家公司开始"收回"之前放弃的东西，通常意味着:
- 管理层战略纪律下降
- 短期业绩压力导致战略妥协
- 新CEO不认同前任的放弃逻辑

例: 如果Costco开始大幅增加SKU数量或加快开店速度 → 战略漂移 → 降低护城河评分

【执行时机】: Phase 1公司分析(与身份诊断同步)
【输出】: 放弃清单表格 + 不可兼得项计数 + 战略漂移预警(如有)
```

### 模块E: 品牌弹性半径 (Brand Elasticity Radius)

```markdown
【原理】
品牌弹性半径衡量: 消费者对品牌的信任能延伸到多远的品类?
Costco从鸡肉延伸到钻石(成功)，但可乐失败(Kirkland可乐下架)。
SBUX从咖啡延伸到食品(部分成功)，但商品(杯子/豆)增长平平。
弹性半径决定了品牌的增长天花板和自有品牌的扩展潜力。

【评估框架: 三圈模型】

核心圈 (R1): 品牌原生品类
  定义: 消费者提到品牌时第一联想的品类
  特征: 极高信任, 极高溢价, 极高复购
  例: Costco→仓储批发, SBUX→咖啡, NKE→运动鞋

延伸圈 (R2): 信任可自然延伸的品类
  定义: 与核心品类共享关键属性(品质/价格/体验)的品类
  特征: 中高信任, 中等溢价, 需要时间建立
  例: Costco→汽油/药房, SBUX→茶/食品, NKE→运动服/配件
  判断标准: 消费者说"既然在这里买X很好，也可以试试Y"

外围圈 (R3): 需要额外信任构建的品类
  定义: 与核心品类共享品牌名但属性差异大
  特征: 低信任, 可能为零溢价, 高失败率
  例: Costco→钻石(低频高价)/旅行, SBUX→周边商品, NKE→数字健身
  判断标准: 消费者说"这个品牌也做这个？有点意外"

禁区 (R4): 品牌无法延伸的品类
  定义: 品牌属性与品类需求矛盾
  特征: 信任为零或负, 尝试会损害品牌
  例: Costco→可乐(已失败), SBUX→快餐, NKE→正装皮鞋

【弹性半径评分 (1-10)】
评分 = R1收入占比 × 1 + R2收入占比 × 3 + R3收入占比 × 5
  (归一化到1-10)
逻辑: R2/R3收入占比越高 → 品牌弹性越大 → 增长天花板越高

| 弹性半径 | 含义 | 估值含义 | 代表 |
|:--------:|------|---------|------|
| 8-10 | 超强弹性(品类跨度极大) | 支持平台级估值倍数 | Amazon, Costco |
| 5-7 | 中等弹性(已成功延伸2-3个品类) | 支持行业高端倍数 | Disney, NKE |
| 3-4 | 有限弹性(1-2个延伸品类) | 行业平均倍数 | SBUX, MCD |
| 1-2 | 极窄(品牌=单一品类) | 品类天花板=公司天花板 | Red Bull, Lululemon |

【延伸成功条件(判断R2/R3能否成功)】
1. 核心信任属性可迁移? (Costco"低价高质"→可迁移到几乎所有品类)
2. 品类需要的专业知识是否可获取? (Costco做不了剃须刀=工艺壁垒)
3. 品类消费频率是否与核心圈匹配? (Costco钻石虽成功但低频→对飞轮贡献有限)
4. 现有客群与品类目标客群是否重叠? (SBUX食品成功因为咖啡客=早餐客)

【执行时机】: Phase 1品牌分析时
【输出】: 三圈图 + 弹性半径评分 + 延伸成功/失败案例
【估值应用】: 弹性半径>7 → 增长假设可用行业高端; ≤3 → 增长假设受品类天花板约束
```

### 五模块整合: Phase执行路由

```markdown
【Phase 1必选】
  ① W×C双轴评分 (模块A) — 与B×M同时评
  ② 战略放弃清单 (模块D) — 与身份诊断同步
  ③ 文化可衡量性 (模块C) — 与CEO分析同步
  ④ 品牌弹性半径 (模块E) — 与品牌分析同步

【Phase 3必选】
  ⑤ 稳健比率 (模块B) — 与估值建模同步，纳入A-Score

【跨模块联动】
- W×C高意愿(W≥4) + 稳健比率>3:1 → "规模经济共享"护城河确认
- W×C低意愿(W≤2) + 稳健比率<1:1 → "品牌溢价依赖型"护城河，需额外关注替代风险
- 文化可衡量性<12 + CEO变更 → 强制触发"CEO继任风险"附加分析
- 放弃清单中"开始收回"项 ≥2 → 战略漂移预警 → Phase 4红队必须挑战
- 品牌弹性半径≤3 + 核心品类增速<GDP → 增长天花板预警
```

> A-Score v2.0 Phase 0, Step 10要求。以下为消费品常见公司的SGI预判参考。

| 公司 | SGI预判 | HHI_rev | R&D_conc | MarketPos | SwitchCost | BrandClarity | 路由 |
|------|--------|---------|---------|-----------|-----------|-------------|------|
| **KO** | 4-5 | 中(饮料为主,但多品类) | 低(品牌驱动非R&D) | 高(碳酸饮料#1) | 低(消费者易切换) | 高(全球最强品牌之一) | 混合模式 |

| **COST** | 4-5 | 低-中(SKU少但品类广) | 极低 | 中(会员仓储#1) | 中(会员锁定) | 高(会员制认知) | 混合模式 |

**路由含义**:
- **通才模式** (SGI≤3): 重点分析资源分配效率、跨品类协同、通才陷阱(是否在任何领域都不突出)
- **混合模式** (SGI 4-6): 兼顾品类深度和组合宽度, 分析核心品类护城河+非核心品类价值
- **偏专才模式** (SGI≥7): 聚焦单点失败风险、品类天花板、专才溢价是否被市场充分定价
