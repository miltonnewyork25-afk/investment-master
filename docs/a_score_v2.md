# A-Score 护城河评分框架 v2.0

> 通用版 -- 行业中性定义 + 可替换适配层
> 升级自: SEMI_EQUIPMENT_COMPARATIVE 报告中的 A-Score v1.0 (11维度, 半导体设备专用)
> 创建日期: 2026-02-24

---

## 1. 框架概览

### 1.1 设计哲学

A-Score 是一套**结构化护城河评分框架**, 旨在用统一标尺量化不同行业、不同商业模式的公司竞争优势深度与持久性。

**三层架构**:

```
┌─────────────────────────────────────────────────┐
│  扩展层 (Extension Layer)                        │
│  趋势向量 ↑/→/↓ | 置信度加权 | 形状分析 | SGI速判  │
├─────────────────────────────────────────────────┤
│  可替换层 (Adaptable Layer)                       │
│  代理指标 | 评分锚点 | 权重配置                     │
│  → 按行业替换, 按公司微调                          │
├─────────────────────────────────────────────────┤
│  不变层 (Universal Layer)                         │
│  12维度定义 | 0-10评分尺度 | H/M/L置信度 | 加权总分 │
│  → 跨行业通用, 不需修改                           │
└─────────────────────────────────────────────────┘
```

**核心原则**:
- **行业中性定义**: 每个维度的定义使用通用商业语言, 不绑定特定行业术语
- **可审计**: 每个评分有明确锚点, 不同评估者对同一公司的评分差异应控制在1分以内
- **可比较**: 同一行业内的公司使用相同的代理指标、锚点和权重, 确保横向可比
- **攻守兼备**: 既评估"壁垒有多强"(进攻维度A1-A7), 也评估"壁垒被突破的风险"(防御维度A8-A9)

### 1.2 v1.0 到 v2.0 变化清单

| 变化项 | v1.0 | v2.0 |
|--------|------|------|
| 维度数量 | 11 (A1-A11) | **12** (新增A12管理层-战略一致性) |
| 维度定义 | 半导体设备锚点硬编码 | 不变层(通用定义) + 可替换层(行业锚点) |
| 权重 | 固定(半导体设备专用) | 基准权重 + 动态校准(可选) |
| 趋势标注 | 无 | 每个维度增加 **趋势向量** (上升/平稳/下降) |
| 置信度 | 仅标注, 不影响分数 | **加权入分**: H=1.0x, M=0.85x, L=0.7x |
| 形状分析 | Ch9 实验性探索 | **标准模块**: 四种形状 + 概率加权A-Score |
| 行业覆盖 | 半导体设备 | 四行业预设(半导体/消费品/科技平台/金融) |

### 1.3 通用性分类

v1.0 的 11 个维度经过跨行业泛化验证, 分类结果如下:

| 分类 | 维度 | 数量 | 含义 |
|------|------|------|------|
| **通用内核** | A1, A2, A3, A4, A8 | 5 | 定义和评估逻辑无需修改即可跨行业使用 |
| **可适配** | A5, A6, A7, A9, A10, A11 | 6 | 维度概念通用, 但代理指标和锚点需行业校准 |
| **行业专属** | (无) | 0 | v1.0设计时已遵循"可复用骨架"原则, 无行业专属维度 |

**关键发现**: 0 个行业专属维度。框架的行业专化仅体现在三个可替换层: (1) 代理指标, (2) 评分锚点, (3) 权重分配。这使得泛化基础非常坚实。

## 2. 12维度定义 (A1-A12)

### 评分通用规则

- **尺度**: 0-10 整数, 满分 10
- **置信度**: 每个评分附带 [H] / [M] / [L]
  - **H (High)**: 有硬数据支撑, 2个以上独立来源交叉验证
  - **M (Medium)**: 有数据支撑但来源单一, 或需逻辑推导
  - **L (Low)**: 主要依赖定性判断, 数据支撑不足
- **趋势向量**: 每个评分附带趋势标注
  - 上升: 护城河正在加深
  - 平稳: 护城河维持现状
  - 下降: 护城河正在衰减

---

### A1: 输入要素自主权 (Supply Chain Autonomy)

**通用定义**: 核心投入要素(原材料、关键组件、IP、数据、人才等)的自主可控程度。公司被上游"卡脖子"的风险有多大?

**通用性**: 通用内核 (5/5)

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 核心要素严重依赖单一供应商/来源, 供应中断将导致业务停摆, 无替代方案 |
| 3-4 | 多数要素有替代来源, 但1-2个关键要素存在单源依赖或高集中度 |
| 5-6 | 关键要素有双源/多源策略, 自主比例30-50%, 供应链韧性中等 |
| 7-8 | 核心要素大部分自研/自有, 供应链冗余充足, 能在6个月内切换来源 |
| 9-10 | 完全自主可控, 或作为唯一供应方反向"卡脖子"下游/同行 |

**行业适配示例**:

| 行业 | "输入要素"的具体含义 | 代理指标 | 锚点示例 |
|------|-------------------|---------|---------|
| **半导体设备** | 零部件、精密光学、特种材料、IP | CR3供应商集中度, 单源组件数, 自研比例 | 9-10: KLAC软件/算法100%自研; 5: ASML Zeiss/Trumpf单源依赖 |
| **消费品** | 品牌资产、渠道关系、原材料/配方 | 原材料自有率, 品牌IP自有率, 渠道自主度 | 9-10: 可口可乐配方100%自有且不可复制; 5-6: NIKE依赖特定渠道但有替代 |
| **科技平台** | 数据、算法、内容、基础设施 | 数据自生成比例, 算法自研率, 内容自有率 | 9-10: Google搜索数据完全自有且自生成; 3-4: Netflix依赖第三方内容供给 |
| **金融** | 资本来源、牌照、人才、风控系统 | 存款/负债自给率, 牌照自有度, 人才留存率 | 9-10: JPM存款基础深厚且分散; 3-4: SVB高度依赖批发资金市场 |

**半导体设备验证区分度**: 3分 (KLAC 8分 - ASML 5分)。ASML因Zeiss/Trumpf单源依赖获得意外低分, 产出反直觉洞见: 市值最高的公司在此维度得分最低。

### A2: 切换成本 / 数据重力 (Switching Cost / Data Gravity)

**通用定义**: 客户从本公司产品/服务切换到竞品的全口径迁移代价。包括直接经济成本、时间成本、风险成本、习惯惯性和数据迁移成本。

**通用性**: 通用内核 (5/5) -- Porter五力中最经典的护城河维度之一, 天然跨行业。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 切换几乎无摩擦, 竞品可直接替代, 客户迁移周期 < 1个月 |
| 3-4 | 存在轻度迁移成本(数据导出、习惯调整), 但客户愿意切换 |
| 5-6 | 中度切换成本, 迁移周期3-12个月, 需重新适配/培训, 存在效率损失风险 |
| 7-8 | 高切换成本, 迁移周期12-18个月, 涉及深度系统集成或长期数据依赖 |
| 9-10 | 实质不可切换: 迁移成本极高, 或物理上没有可替代方案 |

**行业适配示例**:

| 行业 | 切换成本的核心机制 | 代理指标 | 锚点示例 |
|------|-----------------|---------|---------|
| **半导体设备** | 设备替换+重新认证+良率爬坡+配方迁移 | $/fab切换成本, 认证周期(月), 配方迁移复杂度 | 9: ASML EUV物理不可切换; 8: KLAC 15年零切换记录(数据连续性恐惧) |
| **消费品** | 品牌忠诚度+习惯惯性+心理转换成本 | NPS, 复购率, 品牌偏好强度 | 9-10: 可口可乐品牌认知+味觉记忆; 3-4: 低差异化日用品(通用纸巾) |
| **科技平台** | 数据迁移+生态锁定+用户习惯 | 数据迁移成本, 生态锁定深度, 用户习惯强度 | 9-10: Apple全生态锁定(设备+iCloud+App购买); 5-6: Spotify到Apple Music有习惯成本但可迁移 |
| **金融** | 账户迁移+自动付款重设+信用记录+关系深度 | 账户迁移摩擦, 关系切换周期, 信贷关系连续性 | 7-8: 企业银行关系(贷款+现金管理+外汇, 切换6-12个月); 3-4: 零售银行账户(转账便利化) |

**半导体设备验证区分度**: 3分 (ASML 9分 - AMAT 6分)。值得注意: KLAC和LRCX同为8分但切换机制完全不同 -- LRCX是"技术迁移代价高"(硬壁垒), KLAC是"数据连续性中断恐惧"(软壁垒)。

### A3: 边际盈利杠杆 (Marginal Profit Leverage)

**通用定义**: 增量收入转化为增量利润的效率。规模经济与经营杠杆的强度。

**通用性**: 通用内核 (5/5) -- 纯财务概念, 不依赖行业特性。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 增量毛利率 <= 公司平均水平, 无规模经济, 变动成本主导 |
| 3-4 | 轻微规模经济, 经营杠杆倍数 < 1.2x |
| 5-6 | 经营杠杆 1.2-1.5x, 存在高毛利业务线但占比有限 |
| 7-8 | 经营杠杆 > 1.5x, 增量毛利率显著高于均值, 高毛利业务占比 > 30% |
| 9-10 | 极强规模经济(如软件/IP/平台模式), 增量毛利率 > 80%, 边际成本趋近零 |

**行业适配示例**:

| 行业 | 杠杆的核心来源 | 代理指标 |
|------|-------------|---------|
| **半导体设备** | 固定研发摊薄, 高毛利服务占比 | 增量毛利率, 经营杠杆倍数, 服务收入占比 |
| **消费品** | 品牌溢价随规模放大, 渠道杠杆 | 品类扩展边际成本, 渠道杠杆系数, 品牌溢价率 |
| **科技平台** | 用户增量边际成本趋近零, 数据飞轮 | 用户增量边际成本, 平台经营杠杆, 毛利率扩张趋势 |
| **金融** | 贷款增量资本成本, 运营杠杆, AUM规模效应 | 贷款增量资本成本, 成本收入比变化, AUM边际管理成本 |

**半导体设备验证区分度**: 4分 (KLAC 8分 - AMAT 4分), 高区分度。有效区分了"轻资产高杠杆"(KLAC软件/算法模式, 增量毛利率>80%)和"重资产低杠杆"(AMAT 8线分散, 无规模聚焦点)。

### A4: 壁垒-利润池匹配度 (Barrier-Profit Pool Alignment)

**通用定义**: 公司的竞争壁垒是否恰好保护了价值链中ROI最高的环节? 壁垒的"位置"比壁垒的"高度"更重要 -- 在低价值环节拥有高壁垒, 不如在高价值环节拥有中等壁垒。

**通用性**: 通用内核 (4/5) -- 概念完全通用, 但"利润池"的定义高度行业相关, 需要分析师具备行业知识来识别"最肥的利润池在哪里"。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 主要在边缘/低价值环节竞争, 利润池薄且壁垒低 |
| 3-4 | 在某些高价值环节有存在, 但份额不稳定或面临蚕食 |
| 5-6 | 在1-2个高价值环节有稳固份额, 但非"必须有"定位 |
| 7-8 | 在多个高价值环节领先, 客户/市场将其视为关键供应方 |
| 9-10 | 垄断最高价值环节, 壁垒与利润池完美对齐, 100%渗透率, 无替代 |

**行业适配示例**:

| 行业 | "利润池"的具体含义 | 锚点示例 |
|------|-----------------|---------|
| **半导体设备** | 高端节点(<=5nm)收入占比, 高价值工序份额 | 10: ASML EUV="唯一通道"; 6: AMAT三堡垒极强但在最大利润池(刻蚀$28B+)中壁垒不足 |
| **消费品** | 品牌溢价+渠道控制+消费者心智份额 | 9-10: 爱马仕在超高端皮具(壁垒保护最高溢价品类); 5-6: 中端品牌有认知但利润被渠道分走 |
| **科技平台** | 广告/云/交易佣金/订阅利润率 | 9-10: Google搜索广告(数据壁垒保护毛利率>80%的业务); 5-6: 微软多业务线壁垒分散 |
| **金融** | 利差+手续费+资管费 | 9-10: Visa/MA支付网络(牌照壁垒保护$14T+交易量的take rate); 3-4: 中小券商经纪业务利润被竞争压缩 |

**框架原创性说明**: A4是A-Score框架相对传统护城河分析(如Morningstar)的核心创新。传统分析只问"壁垒有多强", A4追问"壁垒保护的东西有多值钱"。在半导体设备验证中, A4揭示了AMAT的"通才陷阱"(壁垒广但不对齐最肥利润池)和KLAC的"小利润池高匹配"悖论(壁垒完美但利润池规模受限)。

**半导体设备验证区分度**: 4分 (ASML 10分 - AMAT 6分), 高区分度。

### A5: 核心资产半衰期 / 可复制性 (Core Asset Durability / Replicability)

**通用定义**: 核心竞争资产(技术、品牌、数据、专利、制度性能力等)的领先优势能维持多久? 竞争对手追赶需要多少时间和资本?

**通用性**: 可适配 (3/5) -- v1.0中的"技术半衰期"需泛化为"核心资产半衰期", 以涵盖品牌、数据、制度性能力等非技术类核心资产。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 核心资产领先 < 2年, 竞品已有可替代方案, 追赶路径清晰 |
| 3-4 | 领先2-5年, 可被模仿但需一定投入 |
| 5-6 | 领先5-8年, 追赶需大量资本(行业内>$1B量级), 成功概率中等 |
| 7-8 | 领先8-15年, 需巨额投入且高度依赖隐性知识/时间积累 |
| 9-10 | 领先 > 15年, 实质不可复制 -- 即使投入无限资本也无法在合理时间内追平 |

**行业适配示例**:

| 行业 | "核心资产"的具体含义 | 锚点示例 |
|------|------------------|---------|
| **半导体设备** | 技术代差(年), 累积专利, 隐性知识 | 10: ASML EUV >25年代差, $10B+不可复制; 5: AMAT分产品线1-10年, 加权4-6年可追赶 |
| **消费品** | 品牌资产半衰期, 配方/工艺可复制性 | 9-10: 可口可乐品牌认知>50年, 深度嵌入文化; 3-4: 新消费品牌差异化半衰期仅3-5年(元气森林) |
| **科技平台** | 数据/算法半衰期, 网络效应持久性 | 9-10: Google搜索数据壁垒>15年; 3-4: 多数SaaS功能领先仅1-2年 |
| **金融** | 制度性能力半衰期, 关系网络深度 | 9-10: JPM百年积累的风控系统+全球网络; 3-4: Fintech算法优势2-3年可被复制 |

**半导体设备验证区分度**: 5分 (ASML 10分 - AMAT 5分), **最高区分度**, 是11维中最强的区分器。有效区分了"不可复制"(ASML EUV)和"可追赶"(AMAT多线分散)两种竞争格局。

### A6: 经常性收入质量 (Recurring Revenue Quality)

**通用定义**: 持续"收租"的能力。核心交易之外, 有多少可预测、可持续的经常性收入? 收入流的稳定性和可预测性如何?

**通用性**: 可适配 (4/5) -- 概念高度通用(SaaS行业已有ARR/NRR等成熟指标), 但不同商业模式对"经常性"的定义差异较大。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 经常性/可预测收入 < 15%, 客户按需采购, 无黏性 |
| 3-4 | 经常性收入15-25%, 有基本服务但合同短期, 续约不确定 |
| 5-6 | 经常性收入25-40%, 有长期合同, 续约率中等(70-85%) |
| 7-8 | 经常性收入40-60%, 续约率高(85-95%), 客户价值(ARPU)稳步增长 |
| 9-10 | 经常性收入 > 60%, 类订阅模式, 续约率 > 95%, 装机/用户基数飞轮成熟 |

**行业适配示例**:

| 行业 | "经常性收入"的核心形态 | 代理指标 |
|------|-------------------|---------|
| **半导体设备** | 服务合同+备件+升级 | 服务/订阅占比, ARPU, 续约率, LTSA覆盖率 |
| **消费品** | 复购+订阅+品类渗透 | 复购率, 订阅占比, CLV, 品类复购频率 |
| **科技平台** | 订阅+广告+交易佣金 | ARR, NRR, 月活留存率, 流失率 |
| **金融** | 存款黏性+保费续约+AUM管理费 | 存款留存率, 保费续约率, AUM留存率, 管理费率稳定性 |

**半导体设备验证区分度**: 2分 (LRCX 7分 - AMAT 5分), 低区分度。行业整体经常性收入占比都在20-38%区间, 没有极端分化。

### A7: 网络效应 / 生态厚度 (Network Effect / Ecosystem Thickness)

**通用定义**: 用户/参与者越多, 产品/服务越好用的正反馈循环。包括直接网络效应(同侧)、间接网络效应(跨边)和数据网络效应。

**通用性**: 可适配 (3/5) -- 概念通用, 但行业间差异最大的维度。在半导体设备中天然受限(客户间不直接互益, 上限约8分), 在消费互联网/支付中可能是最核心维度(权重应大幅提升)。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 无网络效应, 产品价值不随用户/参与者增加而增长 |
| 3-4 | 轻微规模效应(成本分摊)但用户间不直接互益 |
| 5-6 | 存在单边网络效应或弱数据飞轮, 生态合作伙伴数量有限 |
| 7-8 | 强生态网络, 双边或多边网络效应初步形成, 有标准制定权 |
| 9-10 | 极强跨边网络效应 + 数据飞轮 + 生态锁定, 赢者通吃动态明显 |

**行业适配示例**:

| 行业 | 网络效应的核心形态 | 权重建议 | 锚点示例 |
|------|-----------------|---------|---------|
| **半导体设备** | 供应链生态+JDP合作+配方库 | 6% | 8: ASML供应链生态极厚+标准制定权; 5: AMAT理论上有交叉销售但实际有限 |
| **消费品** | 社交信号+分销网络密度+文化嵌入 | 6-8% | 7-8: 奢侈品社交网络效应(LV使用者越多品牌辨识度越高); 3-4: 功能性消费品无网络效应 |
| **科技平台** | 双边/多边网络效应+数据飞轮+API生态 | **15-18%** | 9-10: Apple iOS(开发者->App->用户->开发者); 5-6: AWS(用户越多成本越低但非多边) |
| **金融** | 支付网络密度+存贷双边效应+交易流动性 | 10-12% | 9-10: Visa/MA(商户越多->持卡人越多->商户越多); 5-6: 银行存贷双边效应 |

**半导体设备验证区分度**: 3分 (ASML 8分 - AMAT 5分), 中等区分度。

### A8: 跨界吞噬 / 平台包抄风险 (Cross-Border Encroachment Risk)

**通用定义**: 被竞争对手通过bundling、平台扩张、相邻品类入侵而蚕食的风险。分数越高 = 风险越低 = 越好。

**通用性**: 通用内核 (5/5) -- 平台竞争、品类入侵和bundling威胁是所有行业共有的竞争动态。

**通用锚点** (0-10, **反向指标: 分数高=风险低**):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 核心品类被多个竞争对手积极入侵, 市场份额持续流失 |
| 3-4 | 面临1-2个强劲竞争对手的品类扩张威胁, 防御手段有限 |
| 5-6 | 竞争格局基本稳定, 偶有小规模份额波动 |
| 7-8 | 核心能力具有结构性独立性, 竞品难以通过bundling入侵 |
| 9-10 | 垄断或准垄断地位, 无有效竞争者, 反而主动入侵他人领域 |

**行业适配示例**:

| 行业 | 包抄风险的核心形态 | 代理指标 |
|------|-----------------|---------|
| **半导体设备** | 竞品品类扩张, bundling/suite selling | 竞争事件时间线, 产品线重叠度, 份额变动 |
| **消费品** | 品类替代, 渠道脱媒, 自有品牌入侵 | 品类替代威胁度, 渠道商自有品牌份额, DTC渠道占比 |
| **科技平台** | 平台迁移, super-app整合, AI替代 | 平台迁移威胁, super-app覆盖范围, AI替代路径 |
| **金融** | BigTech入金融, Fintech颠覆, 跨界牌照 | 跨界竞争者数量, Fintech渗透率, 监管护城河 |

**框架设计说明**: A8与A9同为反向指标 -- 分数越高意味着风险越低。这一设计使护城河评估同时涵盖"进攻能力"(A1-A7)和"防御能力"(A8-A9), 而非仅评估壁垒强度。

**半导体设备验证区分度**: 4分 (ASML 9分 - AMAT 5分), 高区分度。

### A9: 范式迁移风险 (Paradigm Shift Risk)

**通用定义**: 底层商业/技术/消费范式发生根本性变化, 导致现有护城河失效的风险。分数越高 = 风险越低 = 范式免疫力越强。

**通用性**: 可适配 (3/5) -- 泛化难度最高的维度, 因为"范式"在不同行业中的含义和时间尺度差异最大。

**通用锚点** (0-10, **反向指标: 分数高=风险低**):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 单一路线/模式, 如果范式变化将完全失效, 历史上已有被颠覆先例 |
| 3-4 | 主要依赖一条路线/模式, 有初步探索替代方向但投入不足 |
| 5-6 | 覆盖2-3条可能路线, 新模式收入占比10-20%, 有一定适应弹性 |
| 7-8 | 多路线覆盖, 新模式贡献 > 20%, 历史范式转变中适应记录良好 |
| 9-10 | "范式不可知论者": 无论行业如何变化都需要其产品/服务, 超越特定范式 |

**行业适配示例**:

| 行业 | "范式迁移"的具体含义 | 锚点示例 |
|------|------------------|---------|
| **半导体设备** | 制造技术路线变化(平面->3D->GAA等) | 9: KLAC"范式不可知"(无论如何制造都需检测); 6: AMAT广度=保险但深度不足 |
| **消费品** | 消费习惯根本性变化, 渠道范式迁移 | 9-10: 水/食品类基础消费(消费方式不影响需求); 1-2: 被新范式替代(功能手机->智能手机时代的诺基亚) |
| **科技平台** | 计算平台范式跃迁, AI颠覆路径 | 9-10: 存储/网络基础设施(计算范式不可知); 5-6: 搜索广告(面临AI助手颠覆) |
| **金融** | 金融中介模式变化, DeFi/数字货币 | 9-10: Visa(支付中间层, 无论支付方式如何变化); 3-4: 传统中介被DeFi颠覆 |

**半导体设备验证区分度**: 3分 (KLAC 9分 - AMAT 6分), 中等区分度。产出全框架最反直觉发现: KLAC(9分)超过ASML(8分), 因为"检测"比"光刻"在范式维度上更具根本性 -- 对长期投资者的终值计算有实质意义。

### A10: 分销 / GTM复利 (Distribution / Go-to-Market Compounding)

**通用定义**: 获客成本是否随规模下降? 存量客户扩张是否形成飞轮? 分销网络是否产生复利效应?

**通用性**: 通用内核, 微调权重 (4/5) -- 概念完全通用, 但在不同行业中的重要性差异大: 消费品/科技平台的GTM复利远比B2B设备行业关键。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 获客成本随规模上升, 无交叉销售, 市场拓展边际成本不递减 |
| 3-4 | 获客成本基本稳定, 服务/附加品渗透率 < 30% |
| 5-6 | 获客成本轻微下降, 存量客户有初步扩张(交叉销售/向上销售) |
| 7-8 | 明显飞轮: 存量客户持续扩张, LTV/CAC比率 > 3x, 有机增长占比高 |
| 9-10 | 极强分销复利, "一次进入, 终身扩张"模式成熟, 病毒式增长或网络分销 |

**行业适配示例**:

| 行业 | GTM复利的核心来源 | 权重建议 | 代理指标 |
|------|-----------------|---------|---------|
| **半导体设备** | 装机飞轮, 服务attach率, 钱包份额 | 6% | SG&A/收入, attach率, 存量客户收入增速 |
| **消费品** | 渠道效率, 品牌病毒传播, DTC复利 | **10-12%** | 获客成本, CLV/CAC, 渠道效率, 有机增长% |
| **科技平台** | 病毒系数, 平台飞轮, 内容自生成 | 4-6% | 病毒系数, LTV/CAC, 有机增长% |
| **金融** | 交叉销售, 钱包份额, AUM增速 | 8-10% | 交叉销售率, 钱包份额, AUM有机增速 |

**半导体设备验证区分度**: 2分 (ASML/LRCX 7分 - AMAT 5分), 低区分度。行业客户高度集中(仅数十家fab), GTM模式差异不大。

### A11: 合规 / 可靠性门槛 (Compliance / Reliability Threshold)

**通用定义**: 认证要求、监管合规和可靠性标准构成的隐性进入壁垒有多高? 新进入者需要跨越多少非市场化的门槛?

**通用性**: 可适配 (3/5) -- 合规壁垒在所有受监管行业中都是核心维度, 但形式差异极大(FDA vs BIS vs 金融监管 vs GDPR)。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 准入门槛极低, 认证周期 < 3个月, 故障/违规成本低 |
| 3-4 | 有基本合规要求, 认证周期3-6个月, 中等监管强度 |
| 5-6 | 认证周期6-12个月, 故障/违规成本显著, 需专业合规团队 |
| 7-8 | 认证周期12-18个月, 故障成本极高(单事件损失>$10M), 强监管行业 |
| 9-10 | 认证周期 > 18个月 + 政府级管制(出口管制/牌照限制) + 寡头认证, 新进入近乎不可能 |

**行业适配示例**:

| 行业 | 合规壁垒的核心形态 | 锚点示例 |
|------|-----------------|---------|
| **半导体设备** | 设备认证周期+故障成本+出口管制 | 10: ASML(认证18-24月+荷兰/美国双重管制); 6: AMAT(产品线间参差, PVD 9分但ECD 5分) |
| **消费品** | FDA/NMPA认证+品质标准+环保法规 | 9-10: 婴幼儿食品/药品级保健品(认证2-5年); 3-4: 一般食品安全(认证<6个月) |
| **科技平台** | 数据隐私(GDPR/CCPA)+反垄断+内容审核 | 7-8: Meta/Google(合规团队数千人, 跨国数据合规); 3-4: 轻监管SaaS |
| **金融** | 银行牌照+资本充足率+反洗钱 | 9-10: G-SIB(全球系统重要性银行, 数十年合规基建); 1-2: 不受监管的Fintech |

**半导体设备验证区分度**: 4分 (ASML 10分 - AMAT 6分), 高区分度。ASML获得唯一的A11满分(10分), 源于"政府级壁垒" -- 出口管制构成了技术壁垒之外的第二道墙。

### A12: 管理层-战略一致性 (Management-Strategy Alignment) [v2.0 新增]

**通用定义**: 管理团队是否具备维护和加深护城河的能力与意愿? 管理层的战略决策是否与公司的核心竞争优势方向一致?

**新增理由**: v1.0 的 11 个维度全部聚焦"业务壁垒"和"竞争结构", 完全没有评估"人"的因素。在半导体设备验证中, AMAT的 EPIC Center($5B管理层赌注)高度依赖CEO执行力, KLAC的"范式不可知"策略依赖管理层的战略定力 -- 但框架无法捕捉这些变量。

**通用锚点** (0-10):

| 分数 | 通用特征 |
|------|---------|
| 1-2 | 管理层频繁更换战略方向, 资源分配与核心壁垒不一致, 治理结构有重大缺陷 |
| 3-4 | 战略方向基本明确但执行力不足, 或管理层与股东利益存在轻度错位 |
| 5-6 | 管理层能力合格, 战略方向与壁垒基本一致, 执行记录中等 |
| 7-8 | 管理层战略清晰, 资本配置纪律性强, 有可验证的壁垒加深记录, 治理结构健全 |
| 9-10 | 管理层是护城河的"软性基础设施": 长期战略定力 + 卓越资本配置 + 利益深度绑定 + 接班计划明确 |

**代理指标** (通用):
- 管理层任期与战略一致性(是否频繁变更方向)
- 资本配置纪律(回购/并购/有机投资的ROI记录)
- 管理层持股比例与激励结构
- 治理结构(独董比例, 股东权利, 反收购条款)
- 接班计划清晰度
- 核心壁垒维度的多年趋势(管理层是在加深还是消耗护城河?)

**权重建议**: 4-6%, 根据公司特性浮动。当存在大额战略赌注(如AMAT EPIC Center $5B)或管理层更迭时, 可临时提升至8%。

## 3. 权重校准系统

### 3.1 四条校准原则

适用于所有行业的权重设定, 从半导体设备验证中提炼:

**原则一: 战略瓶颈原则**
> 在行业竞争中起决定性作用的维度应获得最高权重。

半导体设备中 A2(切换成本)和 A4(壁垒-利润池匹配)权重最高(各12%), 因为它们是行业竞争的决定性因素。科技平台中 A7(网络效应)应升至15-18%, 因为网络效应是平台竞争的核心。

**原则二: 差异化因子原则**
> 在行业内公司间差异最大的维度应获得更高权重。

A5 在半导体设备中区分度最高(5分差距), 权重12%合理。如果在某行业中 A6(经常性收入)的区分度更高, 则 A6 权重应上调。

**原则三: 不对称风险原则**
> 对投资回报产生非线性影响的维度应确保最低权重门槛。

A9(范式迁移)虽然概率低但影响可能是毁灭性的(如ASML EUV被替代的极端情景), 权重不宜低于6%。

**原则四: 行业天花板原则**
> 某些维度在特定行业中天然受限, 权重应相应降低。

半导体设备的 A7(网络效应)上限约8分, 权重仅6%。科技平台的 A11(合规门槛)在轻监管行业天然低分, 权重可降至2-4%。

### 3.3 动态权重校准 (可选)

在完成数据收集后, 可根据实际区分度动态调整权重:

```
W_adjusted(i) = W_base(i) x (range_i / avg_range) / normalization_factor

其中:
- W_base(i) = 行业预设基准权重
- range_i = 该维度在被评公司组中的分差(最高分 - 最低分)
- avg_range = 所有维度分差的平均值
- normalization_factor = 确保所有W_adjusted之和 = 100%
```

**使用场景**: 横向对比分析中, 某维度区分度极高(如A5的5分差距)或极低(如A6的2分差距)时, 动态校准可让权重更好地反映实际信息量。

**使用限制**: 仅适用于2家以上公司的横向对比。单公司分析使用行业预设权重即可。

## 4. 扩展模块 (v2.0 新增)

### 4.1 趋势向量

**设计目的**: v1.0 的 A-Score 是时点快照, 不区分"正在加深"和"正在衰减"的护城河。v2.0 为每个维度增加趋势标注。

**标注规则**:
- **上升**: 过去3-5年该维度评分有实质性改善的证据(如份额扩张、壁垒加深)
- **平稳**: 维持现状, 无明显方向性变化
- **下降**: 过去3-5年该维度评分有实质性恶化的证据(如份额流失、壁垒被侵蚀)

**输出格式示例**:
```
KLAC A4 = 9 [H] 上升  (过程控制份额 50%->63%, 15年持续扩张)
AMAT A4 = 6 [M] 下降  (PVD份额 85%->被Naura以2-5pp/年蚕食)
```

**应用**: 趋势向量不直接改变加权总分, 但在投资决策中提供关键增量信息。两家总分相同但趋势方向相反的公司, 投资含义完全不同。

### 4.2 置信度加权

**设计目的**: v1.0 的 H/M/L 置信度仅作为标注, 不影响加权总分。但一个 M 置信度的 7 分和一个 H 置信度的 7 分, 在投资决策中的信息价值完全不同。

**加权系数**:

| 置信度 | 系数 | 含义 |
|--------|------|------|
| H (High) | 1.0x | 有硬数据支撑, 评分可信度高 |
| M (Medium) | 0.85x | 数据支撑有限, 评分存在一定不确定性 |
| L (Low) | 0.7x | 主要依赖定性判断, 评分不确定性较高 |

**计算方式**:
```
置信度调整分 = 原始分数 x 置信度系数

示例:
A5 = 10 [H] -> 10 x 1.0 = 10.00
A1 = 5 [M] -> 5 x 0.85 = 4.25
```

**应用**: 置信度加权A-Score惩罚"高分低置信"的评估(可能是过度乐观), 奖励有硬数据支撑的评分。可与原始A-Score并列展示, 为投资者提供风险调整后的护城河评估。

### 4.3 护城河形状分析

**设计目的**: 加权总分是一维数字, 无法捕捉护城河的结构特征。两家总分相近但"形状"截然不同的公司, 风险特征和投资含义差异巨大。

**四种标准形状**:

| 形状 | 特征 | 风险特征 | 典型案例 |
|------|------|---------|---------|
| **尖峰型** | 1-2个维度极高(9-10), 其余中等 | 高分维度一旦被突破, 总分崩塌式下降 | ASML (A4=10, A5=10 拉动整体) |
| **平台型** | 大部分维度在6-9分, 无明显短板 | 抗冲击能力强, 难以被单点突破 | KLAC (所有维度6-9分) |
| **偏科型** | 部分维度极高, 部分极低, 标准差大 | 极高维度和极低维度可能交互放大风险 | AMAT (三堡垒PVD极强但多线稀释) |
| **扁平型** | 所有维度在4-6分, 无突出优势 | 缺乏核心护城河, 竞争中容易被替代 | 多元化工业集团 |

**概率加权A-Score计算**:

为每个维度的评分引入压力测试下的概率分布, 计算"最坏情况下的A-Score":

```
概率加权A-Score = Sum[ A_i x W_i x P(维持当前分数的概率) ]

其中P的估计:
- 9-10分维度: P = 85-95% (高分难以长期维持)
- 7-8分维度: P = 90-95%
- 5-6分维度: P = 95-100% (低分反而稳定)
- 1-4分维度: P = 100% (已经是底部)
```

**半导体设备验证数据**:
- ASML: 原始A-Score 8.12 -> 概率加权 7.80 (降幅-0.32, 尖峰型脆弱性暴露)
- KLAC: 原始A-Score 7.66 -> 概率加权 7.55 (降幅-0.11, 平台型抗冲击)

概率加权后 ASML 与 KLAC 的差距从 0.46 缩小到 0.25 -- 量化了尖峰型护城河的结构性风险。

### 4.4 SGI速判 (Specialist-Generalist Index)

**设计目的**: 在 Phase 0 数据预取阶段, 用2分钟快速判断公司属于"专才"还是"通才", 为后续A-Score评估和估值分析提供方向性指引。

**SGI公式**:

```
SGI = 0.30 x HHI_rev + 0.25 x R&D_conc + 0.20 x MarketPos + 0.15 x SwitchCost + 0.10 x BrandClarity

其中 (均归一化到0-10):
- HHI_rev: 收入集中度(按业务线的HHI指数)
- R&D_conc: R&D集中度(核心品类R&D占比)
- MarketPos: 核心品类市场地位(#1=10, #2=7, #3=5, 其他=3)
- SwitchCost: 切换成本感知(快速定性判断)
- BrandClarity: 品牌/投资故事清晰度(投资者能否一句话描述)
```

**SGI与A-Score的关系**: 在半导体设备验证中, SGI与A-Score的相关系数为 **0.98**。SGI可作为A-Score的前置预测器。

**SGI对估值的映射**:

| SGI范围 | 公司类型 | 预期P/E溢价(vs行业中位数) | 分析重点 |
|---------|---------|------------------------|---------|
| 8-10 | 极致专才 | +30%~+60% | 单点故障风险, 品类天花板 |
| 5-7 | 混合模型 | +0%~+20% | 品类间协同是否真实 |
| 1-4 | 通才模型 | -0%~-25% | 通才陷阱, 资源分配纪律 |

**交叉引用**: SGI评估的详细执行流程见 `docs/deep_dive_protocol.md` Phase 0 段。

### 4.5 护城河迁移分析 (Moat Migration Analysis)

> **来源**: EVO-INTC-001, INTC报告v2.1 (2026-02-25) — 护城河制度迁移分析首创
> **适用**: 壁垒类型发生结构性转变的公司 (政策保护型/监管壁垒兴起型/技术→制度迁移型)

**核心问题**: 护城河不是在"消失"，而是在"搬家"——从一种壁垒类型迁移到另一种。传统A-Score静态评分会误判这类公司。

**迁移向量定义**:

对每个维度 A_i, 除了评分和趋势向量(↑/→/↓)外, 增加**壁垒类型标注**:

| 壁垒类型 | 代码 | 特征 | 典型持久性 |
|----------|:----:|------|-----------|
| 技术壁垒 | T | 专利/工艺/研发积累 | 可被追赶(5-15年) |
| 规模壁垒 | S | 规模经济/成本优势 | 可被匹敌(10-20年) |
| 网络壁垒 | N | 网络效应/生态锁定 | 自我强化(持久) |
| 制度壁垒 | I | 政策/监管/许可/安全审查 | 政策依赖(不确定) |
| 品牌壁垒 | B | 品牌认知/文化嵌入 | 文化依赖(持久) |

**迁移检测**: 当≥3个维度的壁垒类型在5年内发生变化时, 触发迁移分析:

```
迁移方向 = 主导壁垒类型(5年前) → 主导壁垒类型(当前)
迁移速率 = 类型变化维度数 / 总维度数 × 100%
迁移完成度 = 新类型壁垒强度加权均值 / 旧类型壁垒强度加权均值
```

**迁移分析输出模板**:

```markdown
### 护城河迁移地图

| 维度 | 5年前类型 | 当前类型 | 迁移? | 新壁垒强度 |
|------|:--------:|:-------:|:----:|:---------:|
| A1   | T        | T→I     | ✓    | 6/10      |
| A2   | T        | I       | ✓    | 7/10      |
| ...  | ...      | ...     | ...  | ...       |

**迁移诊断**:
- 迁移方向: 技术(70%) → 制度(70%)
- 迁移速率: X/12 = Y%
- 迁移完成度: Z%
- 估值含义: 可比公司锚从[科技同业]转向[政策受益型同业]
```

**INTC验证案例**: 技术壁垒70%→30%, 制度壁垒30%→70%, 迁移速率高, 估值锚应从TSMC/AMD转向Lockheed/Raytheon(政策依赖型)。

**触发场景**:
- 政府补贴/CHIPS Act类政策介入 → 技术→制度迁移
- 反垄断裁决/监管牌照 → 规模→制度迁移
- 开源替代兴起 → 技术→品牌/生态迁移(如ARM vs RISC-V)
- 平台化转型 → 技术→网络迁移

## 5. 使用指南

### 5.1 单公司 Tier 3 分析

**使用场景**: 对单一公司进行深度研究, A-Score作为Phase 2护城河评估的核心框架。

**执行步骤**:

1. **Phase 0**: 运行SGI速判(2分钟), 确定公司在专才-通才光谱上的位置
2. **Phase 0**: 确定行业归属, 加载对应的行业预设权重
3. **Phase 2**: 逐一评估12个维度(A1-A12), 每个维度:
   - 收集代理指标数据
   - 对照行业锚点评分(0-10)
   - 标注置信度[H/M/L]
   - 标注趋势向量(上升/平稳/下降)
4. **计算输出**:
   - 加权总分 (A-Score = Sum(A_i x W_i))
   - 置信度加权A-Score
   - 形状分析(判断四种形状之一)
   - 概率加权A-Score(可选)
5. **交叉验证**: A-Score与B-Score的一致性检查

**A-Score与B-Score一致性矩阵**:

| 组合 | 含义 | 行动建议 |
|------|------|---------|
| 高A-Score + 高估值 | 优质资产溢价, 合理 | 评估溢价是否充分 |
| 高A-Score + 低估值 | 可能被错杀, **机会** | 深入分析低估原因 |
| 低A-Score + 高估值 | 可能过度乐观, **危险** | 评估下行风险 |
| 低A-Score + 低估值 | 估值匹配, 中性 | 关注边际改善信号 |

### 5.2 横向对比分析

**使用场景**: 对2-4家同行业公司进行横向对比, A-Score作为统一评分标尺。

**关键原则**:
- 所有公司使用**相同的**行业预设权重、代理指标和锚点
- 评分者在评估每个维度时应同时考虑所有被评公司, 确保相对排名合理

**额外分析模块**:

1. **区分度热力图**: 按维度统计分差, 识别哪些维度最有区分力
2. **动态权重校准**: 用 3.3 节的公式, 根据实际区分度调整权重
3. **排名稳定性测试**: 在三种不同权重配置下(原始/科技平台/金融)测试排名是否稳定
   - 排名第一和最后的公司通常在所有配置下稳定
   - 中间排名对权重敏感的维度需要重点关注
4. **形状对比**: 将多家公司的形状并列, 识别结构性差异

**半导体设备验证结果**:
- 排名第一(ASML 8.12)和第四(AMAT 5.42)在所有权重配置下都稳定
- 排名二三(KLAC 7.66 / LRCX 7.02)的相对位置对A6/A7/A9权重敏感

### 5.3 与 B-Score 的整合

B-Score (经济与估值评估) 包含 B1-B5 五个维度(周期位置/单位经济学/资本强度/估值/风险地图), 评估公司的经济质量和估值合理性。

**综合评分框架**:

```
综合分数 = A-Score x W_A + B-Score x W_B

默认权重:
- W_A = 50% (护城河深度)
- W_B = 50% (经济质量+估值)
```

**行业调整建议**:

| 行业 | A-Score权重 | B-Score权重 | 调整理由 |
|------|-----------|-----------|---------|
| 半导体设备 | 50% | 50% | 技术壁垒与周期性同等重要 |
| 消费品 | 55% | 45% | 品牌护城河是长期回报的核心驱动力 |
| 科技平台 | 55% | 45% | 网络效应和生态壁垒比短期估值更重要 |
| 金融 | 45% | 55% | 资本质量和监管合规对金融股更关键 |
