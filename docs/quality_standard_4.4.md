# 深度报告评测框架（最高标准版）

> **定位**: 深度研究资产评分表，不是文章评分表。
> **评测对象**: 深度、广度、因果推演能力、验证能力、持续跟踪能力、可压缩/可复用/可工程化特征。
> **两层架构**: A.门控层(Gate) → B.评分层(Scorecard)。门控不通过则不进入评分。

---

## A. 门控层（Gate）

任一核心项不达标，报告不得进入高评级。

---

### G0 过程门控

> 产出质量在过程中就可能注定失败。高密度的错误方向比低密度的正确方向更危险。

| 过程项 | 阈值 | 防止什么 |
|--------|------|---------|
| Reverse DCF在P1 Ch1完成 | **必须** | 结论先行偏差 — P1预设方向→后续Phase全部被锚定→红队纠偏代价过大 |
| 最相似可比公司P0对标 | **必须** | 外部锚缺失 — 无同行业参照→无法校验"是否真的便宜/贵" |
| Tier 3跨≥3个独立session | **必须** | 偏差传导 — 单日rush消除Phase间纠偏窗口→P1动量一路传导 |
| 每Phase字符≥目标50% | **必须** | 骨架扩写 — 低于50%的Phase产出不可能达到最低质量标准 |
| Checkpoint每Phase更新 | **必须** | 跨session数据断裂 — 估值结论变化未同步→恢复session拿到错误基准 |

**判定**: 5项全PASS → 通过 | 任1项FAIL → 报告过程存在结构性风险，需修复后重新评估

---

### G1 高密度分析单元密度

* **阈值: ≥1.5 / 千字**
* 每千字必须包含足够数量的高价值分析单元
* 不允许以大段背景、低信息密度叙述、泛泛总结稀释内容质量

---

### G2 高密度分析单元总数

* **阈值: ≥450**
* 报告必须由大量可识别、可计数、可追踪的高价值分析单元组成
* 防止少数长段落撑起整体篇幅

---

### G3 可视化结构图数量

* **阈值: ≥35**
* 必须有足够数量的结构图、流程图、因果图、框架图、依赖图、追踪图
* Mermaid为主要载体(文本化语法、可维护、可版本控制、与Markdown兼容)
* 辅以表格和少量普通图表

---

### G4 因果密度

* **阈值: ≥5.0 / 万字**（门控线）
* **4.4目标: ≥8.0 / 万字**（D3满分线）
* 报告不能只是事实罗列或观点堆叠
* 必须高密度呈现"变量 → 机制 → 结果 → 反馈"的因果链条
* 检查方法: `grep -c '因为\|因此\|这意味着\|这解释了' {REPORT}` / 总字符 × 10000

---

### G5 程序化验证

* **阈值: 必须具备**
* 关键数据、估值框架(DCF/FCFF/敏感性矩阵)、统计关系、覆盖率、关键结论，必须有Python或等价程序化验证
* LLM不能做算术 — 手算的DCF/敏感性矩阵不可信

---

### G6 结论收敛度 / 估值离散度

* **阈值: ≤30%**
* 多方法输出不能高度发散
* 若存在显著分歧，必须明确解释分歧来源与条件边界
* 计算: (最高估值 - 最低估值) / 中位数

---

### G7 问题结构标记体系

* **阈值: 完整覆盖 CQ1–CQ8**
* 必须具备明确的问题编号、论证闭环、结论沉淀体系
* 每个CQ必须在报告中有对应章节回答（不能定义了8个只回答5个）
* 每个CQ必须有最终方向判定（概率化表达，如"55:45偏正面"）

---

### G8 发布合规

* **阈值: 全部PASS**

| 检查项 | 标准 |
|--------|------|
| 敏感表述 | 零敏感地缘政治表述（中性化处理） |
| Phase痕迹 | 零Phase编号/标题残留 |
| Agent引用 | 零Agent/研究员内部引用 |
| 报告连贯性 | 读起来像一次性撰写的连贯文档，非研究过程拼接记录 |
| 数据时效 | 市值/股价/关键指标统一为同一时间快照 |

---

## B. 评分层（Scorecard）— 4.4级目标

通过门控后，11维评分判断是否达到4.4级目标标准。
**总分计算**: 11维 × 0-10分，总分≥88/110 = 4.4分。

---

### D1 数据基础 — 目标≥8

**评什么**: 高密度分析单元总数 + A级证据占比 + 口径统一性

| 分档 | 条件 |
|------|------|
| 9-10 | DM≥500 + A级证据≥70% + 关键口径全统一 + 多源交叉验证覆盖率≥90% |
| 7-8 | DM≥400 + A级证据≥50% + 关键口径基本统一 |
| 5-6 | DM≥200 + A级证据≥30% |
| <5 | DM<200 或 A级证据<30% 或 存在口径混乱 → **致命缺陷触发** |

**A级证据定义**: 高可信、高相关、可复核、可直接支撑关键结论的证据（10-K/10-Q原文、官方财报数据、监管文件）

---

### D2 问题定义 — 目标≥8

**评什么**: CQ标记 + 闭环 + thesis结晶 + 核心矛盾清晰度

| 分档 | 条件 |
|------|------|
| 9-10 | CQ1-CQ8全闭环 + thesis结晶≥1500字 + 核心矛盾一句话可复述 + CQ置信度演化表 |
| 7-8 | CQ1-CQ8全闭环 + thesis结晶存在 + 核心矛盾清晰 |
| 5-6 | CQ存在但闭环不完整 或 thesis模糊 |
| <5 | CQ缺失 或 无thesis结晶 |

**闭环定义**: 每个CQ有(定义→证据收集→方向判定→估值影响量化→最终概率化结论)

---

### D3 分析深度 — 目标≥7

**评什么**: 因果密度 + 原创框架(CI标记) + 证据链3层 + 二阶效应

| 分档 | 条件 |
|------|------|
| 9-10 | 因果≥8/万字 + CI≥5个(每个≥5K论证) + 每个核心论点3层证据链 + ≥2个论点有二阶效应分析 + ≥1个CI可迁移到其他公司 |
| 7-8 | 因果≥6/万字 + CI≥3个 + 核心论点多数有3层证据链 |
| 5-6 | 因果≥4/万字 + CI≥1个 + 部分论点有完整证据链 |
| <5 | 因果<4/万字 或 CI=0 或 核心论点多为断言无证据 → **致命缺陷触发** |

**证据链3层**: 每个核心论点至少覆盖:
1. **数据事实层** — 来自10-K/行业报告的硬数据，带DM锚点
2. **因果机制层** — "因为X→所以Y"的逻辑链，不是"X，并且Y"的并列
3. **反面解释/反证层** — 这个论点在什么条件下不成立

**二阶效应**: 不止直接因果(A→B)，还需考虑传导链(A→B→C重新评估→D变化)。对范式变革类分析(AI/自动驾驶等)必须包含

**CI定义**: Contrarian Insight / Core Insight — 非共识洞见，对主结论有实质贡献，论证充分，不是"故意唱反调"

---

### D4 风险认知 — 目标≥7

**评什么**: 风险节点数 + KS + 慢变量识别 + 红队有效性

| 分档 | 条件 |
|------|------|
| 9-10 | KS≥8个(12字段标准) + 慢变量≥3个 + 红队有效性≥10% + 风险拓扑(协同/反协同映射) |
| 7-8 | KS≥5个 + 慢变量识别 + 红队有效性≥5% |
| 5-6 | KS存在但不完整 + 红队存在但边际有效(<5%) |
| <5 | KS缺失 或 红队有效性<3%(表演性) |

**KS定义(12字段)**: 条件 / 阈值 / 数据源 / 检查频率 / 当前值 / 触发距离 / 依赖KS / 触发动作 / 置信度 / 最后检查日期 / 历史记录 / 备注

**红队有效性**: |P2估值 - P4估值| / P2估值
- ≥10% = 有效（红队发现了实质偏差）
- 3-10% = 边际有效
- <3% = 可能表演性（要么P1-P2完美，要么红队没下功夫）

**慢变量**: 不会在单季度触发KS但持续恶化的趋势性风险（如增速逐年下台阶、NRR缓慢恶化、护城河渐进侵蚀）

---

### D5 判断/估值框架 — 目标≥8

**评什么**: 方法数 + 离散度 + Python验证 + 估值统一性 + 假设透明度

| 分档 | 条件 |
|------|------|
| 9-10 | ≥4种独立方法 + 离散度≤25% + Python验证全覆盖 + 估值统一性PASS + 假设透明度PASS + 敏感性矩阵覆盖Top 2变量交叉 |
| 7-8 | ≥3种方法 + 离散度≤30% + Python验证关键模型 + 估值统一性PASS |
| 5-6 | ≥2种方法 + 离散度≤40% + 部分Python验证 |
| <5 | 方法<2 或 离散度>40% 或 无Python 或 估值统一性FAIL → **致命缺陷触发** |

**独立估值方法**: Reverse DCF / SOTP / 正向DCF / 可比公司 / 概率加权情景

**估值统一性检查清单**:
- [ ] 报告中同一个公允价值只有一个版本
- [ ] ≥60%方法方向一致
- [ ] 概率加权使用偏差修正后概率（非红队前原始概率）
- [ ] 区分"当前公允价值"和"5年退出价"— 年化≠累计
- [ ] 温度计/评级/执行摘要数字与估值章节完全一致

**假设透明度检查清单**:
- [ ] 关键假设显式列表（≥5个: 增速/OPM/WACC/终端g/概率权重）
- [ ] 每个假设有合理性论证+反面
- [ ] 敏感性矩阵覆盖Top 2变量交叉
- [ ] 读者可从假设表反推任意估值结果

**跨报告校准**: 新报告评级后运行行业校准检查，同行业估值假设不自相矛盾，如发现矛盾需在报告中显式解释

---

### D6 数据验证 — 目标≥8

**评什么**: 审计摘要 + 覆盖率 + 双源交叉 + 异常值解释

| 分档 | 条件 |
|------|------|
| 9-10 | 关键字段覆盖率≥95% + 双源交叉≥80%关键数字 + 异常值全部解释 + 前后文一致性PASS + 口径变化检测PASS |
| 7-8 | 覆盖率≥80% + 双源交叉≥60% + 主要异常值解释 |
| 5-6 | 覆盖率≥60% + 部分双源交叉 |
| <5 | 覆盖率<60% 或 双源交叉<30% 或 关键数字无源 |

**口径变化检测**: 收入/利润YoY>25%且非并购驱动 → 触发口径审查（防止会计重分类导致虚假增速）

### D7 非共识洞见 — 目标≥7

**评什么**: CI标记数 + 论证充分度 + 可迁移性

| 分档 | 条件 |
|------|------|
| 9-10 | CI≥5个 + 每个≥5K字论证 + ≥2个可迁移到其他公司 + 对主结论有实质影响 |
| 7-8 | CI≥3个 + 每个有充分论证 + ≥1个可迁移 |
| 5-6 | CI≥1个 + 论证基本充分 |
| <5 | CI=0 或 CI存在但论证不足(断言式) |

**可迁移性标准**: 该洞见的方法论/框架可应用于同行业或类似特征的其他公司，不是仅对本公司成立的特殊观察

### D8 可视化 — 目标≥8

**评什么**: Mermaid数量 + 表格 + 每章覆盖 + 服务于推理

| 分档 | 条件 |
|------|------|
| 9-10 | Mermaid≥40 + 每章≥1个结构化表达单元 + 可视化直接服务于因果/比较/依赖/追踪 + 无装饰性图表 |
| 7-8 | Mermaid≥30 + 80%章节有可视化 + 多数服务于推理 |
| 5-6 | Mermaid≥15 + 50%章节有可视化 |

### D9 追踪体系 — 目标≥7

**评什么**: KS + TS标记 + 条件依赖 + 更新触发器

| 分档 | 条件 |
|------|------|
| 9-10 | KS≥8个(12字段) + TS≥10个 + 条件依赖网络(KS间关联) + 更新触发器日历 + 后续观察字段表 |
| 7-8 | KS≥5个 + TS≥5个 + 条件依赖存在 + 升级/降级路径明确 |
| 5-6 | KS存在但字段不完整 + TS少量 |
| <5 | KS缺失 或 无TS 或 无条件依赖 |

**TS定义**: Tracking Signal — 后续持续跟踪thesis的关键观察点、先行指标和触发器

**条件依赖**: KS之间的逻辑关系（如"KS-3触发 AND KS-5未触发 → 情景B概率上升"）

| 9-10 | CG全PASS + 评分表完整 + 覆盖完整性PASS(见下) + A/B分离(对外报告无评级目标价) + 标准附录齐全 |
| 7-8 | CG通过(允许少量WARN) + 评分表存在 + 覆盖完整性基本达标 |

### D11 正交度 + 叙事一致性 — 目标≥8

**评什么**: 章节独立性 + 零重复 + 反膨胀 + 叙事方向一致性

| 分档 | 条件 |
|------|------|
| 9-10 | 零重复 + 每章独立论点 + 单章≤15%总字符 + P1叙事方向与P4结论方向完全一致 + 估值数字全报告单一版本 |
| 7-8 | 重复率<5% + 多数章节独立 + 单章≤20% + 叙事基本一致 |
| 5-6 | 重复率5-10% + 部分章节有重叠 + 叙事方向基本一致 |
| <5 | 重复率>10% 或 单章>25% → 膨胀 |
| **<3** | **P1叙事方向与P4结论方向矛盾** → **致命缺陷触发**（叙事断裂） |

**叙事一致性检查清单**:
- [ ] P1叙事方向与Reverse DCF暗示的方向偏离≤1档
- [ ] P4最终估值与P1叙事方向不矛盾
- [ ] 评级与≥60%估值方法方向一致
- [ ] 报告中同一估值数字只有一个版本（红队修正后全报告统一）

**反膨胀检查**:
- [ ] 单章占比 = MAX(章节字符/总字符) ≤ 15%
- [ ] 每章核心结论未在前章出现过（重复内容=零信息量）

## C. 致命缺陷熔断规则

无论其他维度得分多高，以下任一条件触发 → 总分自动降至≤3.5:

| 熔断条件 | 触发阈值 | 为什么致命 |
|----------|---------|-----------|
| D5 估值 | <5 | 投资报告的核心产出不可信 |
| D1 数据 | <5 | 分析建立在不可靠的数据基础上 |
| D3 分析 | <5 | 断言替代推理，投资者无法验证 |
| D11 叙事断裂 | <3 | P1与P4方向矛盾，报告自相矛盾 |
| 方向偏差 | P2→P4校准>25pp | 系统性偏差过大，分析起点严重偏离 |

## D. 附加检查维度（嵌入评分，不单独打分）

### 方向偏差检测

嵌入G0过程门控和D11叙事一致性:

```
P1完成后检查:
  Reverse DCF隐含假设 vs P1叙事方向 → 偏离>1档 = WARN → 修正后继续

P4完成后检查:
  P2→P4校准幅度:
    ≤10% = 正常校准
    10-20% = 显著校准（记录但不扣分）
    >20% = 系统性偏差信号 → 审查P1起点是否有结论先行偏差
    >25% = 致命偏差 → 熔断
```

### 红队有效性

嵌入D4风险认知:

```
红队有效性 = |P2估值 - P4估值| / P2估值
  ≥10% = 有效（红队发现实质偏差）  → D4 +1
  3-10% = 边际有效                  → D4 不加不减
  <3% = 可能表演性                  → D4 -1（除非能证明P1-P2已经非常准确）
```

## E. 统一术语定义

### 高密度分析单元（DM）

最小可计数的高价值研究单元，至少具备以下之一:
- 一个明确问题
- 一个明确因果链
- 一个可验证判断
- 一个对结论有贡献的结构化比较
- 一个可追踪的关键变量定义

格式: `DM-{类别}-{编号}`，如DM-FIN-001、DM-BIZ-023

### A级证据

高可信、高相关、可复核、可直接支撑关键结论的证据:
- **H(Hard)**: 10-K/10-Q原文、官方财报、监管文件
- **R(Reasoned)**: 基于H类数据的逻辑推导，推导过程透明
- **S(Soft)**: 行业估算、类比推断、专家观点 — 需标注可信度

### 因果链

至少包含:
- 驱动变量（X发生了什么变化）
- 作用机制（为什么X会导致Y）
- 结果变量（Y的具体变化）
- 条件边界（在什么条件下这个因果关系不成立）
- 高质量因果链还应包含反馈回路或反向压力

### CQ — Core Question

问题树主骨架编号体系。每个CQ是一个影响估值结论的核心问题，要求:
- 明确定义（一句话可复述）
- 证据收集（Phase 1-2）
- 红队挑战（Phase 3-4）
- 方向判定（概率化，如"55:45偏正面"）
- 估值影响量化
- 最终闭环

### CI — Core Insight / Contrarian Insight

非共识洞见标记。要求:
- 对重要问题有新解释
- 对主结论有实质贡献
- 论证充分（≥5K字符独立论证为满分标准）
- 最佳CI可迁移到其他公司

### KS — Kill Switch

thesis击穿条件。12字段标准:
条件 / 阈值 / 数据源 / 检查频率 / 当前值 / 触发距离 / 依赖KS / 触发动作 / 置信度 / 最后检查日期 / 历史记录 / 备注

### TS — Tracking Signal

后续持续跟踪thesis的关键观察点、先行指标和触发器

### CG — Control Gate

质量通过门。报告完成后的自动化检查脚本输出

## F. 核心精神

这套标准的本质，不是让agent机械凑指标，而是满足5个特征:

### 1. 不是长，而是高密度

核心约束: DM密度 + DM总数 + 正交度 + 零重复 + 单章≤15%

### 2. 不是有观点，而是有因果

核心约束: 因果密度 + 证据链3层 + 二阶效应 + 原创框架 + 问题闭环

### 3. 不是会讲故事，而是会验证

核心约束: Python验证 + 双源交叉 + 覆盖率 + 审计摘要 + 口径变化检测

### 4. 不是一次性交付，而是持续研究资产

核心约束: KS(12字段) + TS + 条件依赖网络 + 更新触发器 + 升级/降级路径

### 5. 不是散文，而是工程化研究产品

核心约束: CQ体系 + Phase结构 + 评分表 + CG通过 + Mermaid结构图体系 + 叙事一致性
