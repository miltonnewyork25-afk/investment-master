# 公司品质量化评估框架 v1.0

> **定位**: 通用评估框架，适用于所有行业worktree。Tier 1/2/3分析均可选用。
> **来源**: 12家公司实证回测(FICO/CPRT/CTAS/ROL/IDXX/Visa/FAST/IHG + HEI/DHR/CSU/GE)
> **用法**: Phase 0数据预取后执行 → 生成评分卡 → 指导估值框架选择

---

## 一、评估总览

```
总分 = A品质门控(Pass/Fail) + B商业模型(40分) + C护城河(30分) + D回报修正因子(乘数)

最终评级:
  A全通过 + B≥32 + C≥20 + D≥0.8 → 强偏好 (预期回报: 10x+)
  A≥5/7 + B≥25 + C≥15 + D≥0.6 → 偏好 (预期回报: 5-10x)
  A≥5/7 + B≥20 + C≥10 + D≥0.4 → 中性 (预期回报: 3-5x)
  其他 → 审慎 (预期回报: <3x 或高不确定性)
```

## 二、A — 品质门控 (7项 Pass/Fail)

> 品质门控是最低标准。全通过只是"入场券"，不代表值得投资。

| # | 指标 | 通过标准 | 数据来源 | 修正规则 |
|---|------|---------|----------|----------|
| QG-1 | CapEx/Rev | <15% | CashFlow | **CapEx质量修正**: 若CapEx创造不可替代物理资产(如CPRT土地银行)，阈值放宽至25% |
| QG-2 | FCF/NI (5Y均值) | >80% | CashFlow÷Income | 排除一次性项目年份 |
| QG-3 | Rev CAGR | >7% (11Y或5Y) | Income | **收入纯度修正**: 若纯度<50%，用费用收入计算 |
| QG-4 | Rev下降次数 (11Y) | ≤1次 | Income | **下降原因区分**: 资产剥离/会计口径≠有机下降，标注但不自动判FAIL |
| QG-5 | ROIC | >15% | KeyMetrics | 负权益公司用ROCE或FCF/Invested Capital替代 |
| QG-6 | 流动比率 | >1.0 | Balance | 特许商/平台型可豁免(运营负债≠流动性危机) |
| QG-7 | 净债务/EBITDA | <3.0x | Balance÷Income | 反周期型公司(CPRT)允许至3.5x |

## 三、B — 商业模型评分 (8维度, 40分)

> 这是决定长期回报的核心。品质相同(7/7)的公司，商业模型评分差距可导致20x回报差异。

### 评分标准

| # | 维度 | 满分 | 5分标准 | 3分标准 | 1分标准 | 0分标准 |
|---|------|------|---------|---------|---------|---------|
| B1 | **收入引擎清晰度** | 5 | 有机增长>10%+引擎可追踪(如售货机/客房/许可数) | 有机增长7-10%+引擎清晰 | 有机增长<7%或引擎模糊 | 依赖并购或不可预测 |
| B2 | **客户锁定深度** | 5 | 标准/制度锁定(无替代品) | 运营/生态锁定(切换成本极高) | 网络锁定(去别处价更低) | 渠道/习惯锁定(可比价) |
| B3 | **收入经常性** | 5 | 合同/订阅型(月度自动) | 消耗品复购(季度) | 项目型但可预测(年度) | 一次性/不可预测 |
| B4 | **定价权证据** | 5 | 连续5年+超通胀提价+客户无流失 | 跟随通胀提价+低流失 | 成本加成定价 | 市场价格接受者/竞标 |

**B4定价权类型标注(v1.3)**: B4≥3的公司评分时标注来源类型(影响天花板和反身性):
- **市场定价权**: 客户替代成本高→天花板=替代成本(FICO Stage 2.3, ASML)
- **合同定价权**: 合同条款规定提价上限→天花板=合同条款(VRSN 7%/年, CME)
- **制度定价权**: 监管结构保护→天花板=监管容忍度(MCO/SPGI评级费)
| B5 | **利润弹性 (OPM)** | 5 | OPM扩张>500bps(10Y)+趋势持续 | OPM扩张200-500bps | OPM稳定(±100bps) | OPM收缩或高度波动 |
| B6 | **资本配置纪律** | 5 | 回购+股息>80%FCF+SBC/Rev<1%+零稀释 | 回购+股息>60%FCF+SBC<2% | 合理分配但SBC>2% | 大额并购/高SBC/稀释 |
| B7 | **TAM与增长跑道** | 5 | TAM>$100B+渗透率<20%+结构性增长 | TAM大+渗透率中等 | TAM中等或增速放缓 | TAM饱和/萎缩 |
| B8 | **管理层质量** | 5 | 创始人/长期CEO+内部人持股>5%+文化传承 | 职业CEO+合理激励+稳定团队 | 管理层过渡期/激励一般 | 管理层动荡/利益冲突 |

## 四、C — 护城河深度 (6维度, 30分)

### 评分标准

| # | 维度 | 满分 | 5分标准 | 3分标准 | 1分标准 |
|---|------|------|---------|---------|---------|

| C2 | **网络效应** | 5 | 强双边/多边网络(Visa支付网络) | 单边网络或中等双边 | 弱网络效应或仅规模效应 |

## 五、D — 回报修正因子

> B+C决定"公司有多好"，D决定"好公司能否转化为好投资"。

### D1: 周期性评估 (乘数)

| 等级 | 定义 | 乘数 | 代表 |
|------|------|------|------|
| **反脆弱** | 极端事件/波动性越大, 收入越高 | ×1.15-1.20 | CME(波动率→交易量暴增) |
| **反周期** | 需求在衰退期反升 | ×1.1 | CPRT(事故车增加) |
| **非周期** | 需求与经济周期脱钩 | ×1.0 | FICO(信用评分), IDXX(宠物医疗) |
| **弱周期** | 需求温和波动, 无亏损年 | ×0.85 | CTAS(制服), ROL(害虫), FAST(紧固件), Visa(支付) |
| **混合周期** | 多业务线加权, 部分对冲 | ×0.7-0.85 | AVGO(×0.76), NVDA(×0.70, 无软件缓冲) |
| **监管压缩** | 定价权被监管预先抑制，利润率受政策约束 | ×0.50-0.65 | UNH(MCR精算约束), 公用事业(费率审批) |
| **强周期** | 需求大幅波动, 可能亏损 | ×0.5 | IHG(酒店/旅游), 半导体设备, 航空 |

**反脆弱 vs 反周期的区别** (v3.1新增):
- **反周期**(CPRT): 衰退→事故车温和增多→收入+5-15%。需求方向与经济相反, 但幅度有限
- **反脆弱**(CME): 任何方向的剧烈波动→交易量可能+50-100%。不在乎经济方向, 只需要"波动性"
- **判断标准**: 过去20年中≥2次市场危机期间, 收入增速>正常年份2倍 → 反脆弱。仅需求不降→非周期。需求温和上升→反周期
- **候选公司**: CME(已确认), CBOE(待验证), 可能的再保险公司(灾难→需求↑)

### D2: 收入纯度评估

| 等级 | 定义 | 处理方式 |
|------|------|----------|
| **高纯度 (>70%)** | 报告收入≈真实收入 | 直接使用报告数据 |
| **中纯度 (50-70%)** | 含部分过手收入 | 标注, B5用费用收入计算 |
| **低纯度 (<50%)** | 过手收入占主导 | **必须还原**: 计算真实OPM, B5/QG-3用费用收入 |

| 公司 | 收入纯度 | 报告OPM | 真实OPM | 差异 |
|------|----------|---------|---------|------|
| FICO | >95% | 68% | 68% | 0 |
| CTAS | >95% | 22% | 22% | 0 |
| CPRT | >95% | 37% | 37% | 0 |
| FAST | >95% | 20% | 20% | 0 |
| NVDA | >95% | 60.2% | 60.2% | 0 |
| AVGO | >95% | 39.9%(GAAP) | 52.9%(Owner)/65.6%(Non-GAAP) | **+13-26pp*** |
| IHG | ~35% | 23% | **65%** | **+42pp** |
| MAR* | ~40% | ~25% | ~60% | ~+35pp |
| MCD* | ~70% | ~45% | ~55% | ~+10pp |

*AVGO收入纯度>95%(Fabless)，但存在三层OPM：GAAP 39.9%/Owner 52.9%(扣SBC)/Non-GAAP 65.6%——22pp差距来自SBC而非收入纯度
*MAR/MCD为估算值, 待验证

### D3: 被忽视度

| 等级 | 标准 | 加分 |
|------|------|------|
| 显著忽视 | 市值<$5B + 分析师<5 | +3分(加入B合计) |
| 轻度忽视 | 市值$5-20B + 覆盖一般 | +1.5分 |
| 充分覆盖 | 市值>$20B + 广泛覆盖 | +0分 |
| 过度关注 | 散户热门 + 估值溢价 | -1.5分 |

### D4: 护城河趋势乘数 T (v1.3新增, moat v3.2/cqi_scoring_formula v2.0同步)

> 静态评分回答"护城河有多深"，T回答"护城河在变深还是变浅"。当前CQI只看绝对值，T补充方向性。

| T值 | 趋势 | 标准 | 代表 |
|:---:|------|------|------|
| 1.10 | ↑结构性加宽 | 物理定律/行业结构不可逆加深护城河(管理层无关) | KLAC, ETN, ANET |
| 1.05 | ↗执行性强化 | 公司主动通过份额/生态/产品加深(依赖执行力) | CPRT, COST, AMZN |
| 1.00 | →稳定 | 护城河牢固无重大变化 | VRSN, CME, MSFT, ASML |
| 0.95 | ↘结构性收窄 | 监管/替代品在结构性侵蚀(管理层难逆转) | V, ADBE, INTU, CRM, PTC |
| 0.90 | ↓主动侵蚀 | 具体竞争对手在主动打开护城河 | FICO, LULU, PYPL, ARM |
| 0.85 | ⇊全面崩塌 | 护城河多线同时蒸发 | INTC |

**应用**: `加权分 = (B + C + D3) × D1 × T`。T每季度重评——趋势变化时CQI自动调整。
**↑与↗的核心区别**: ↑的驱动力与管理层无关(换CEO趋势不变)，↗依赖执行力(执行力下降则逆转)。

### 加权分 vs 回报 校准

```
加权分 >50: 预期10x+ (FICO 53→68x, CPRT 55.6→10x)
加权分 35-50: 预期7-15x (CTAS 39.9→14x, IDXX 45.5→9x, Visa 41.7→8x, NVDA 37.8→~40x‡, AVGO 36.1→~45x†)
加权分 25-35: 预期5-7x (ROL 31.9→7x, FAST 27.2→5x)
加权分 <25: 预期<5x (IHG 18.5→4x)

†AVGO 36.1→45x严重偏离校准线(应为7-15x区间)
→ 原因: 11Y回报含两次重大并购(Broadcom+VMware)的非有机增长
→ 教训: 加权分只捕捉"有机品质", 并购驱动回报需独立评估
→ 若仅看有机增长(~6.4% CAGR), 11Y有机回报约5-8x, 与36.1加权分基本吻合

‡NVDA 37.8→~40x同样偏离校准线(应为7-15x区间)
→ 原因: AI革命创造了前所未有的非线性爆发(Rev从$27B→$216B/3年)
→ 教训: 加权分无法捕捉范式转换期的爆发回报——B3=3(非经常性)严重拖低了加权分
→ 但回报的可持续性存疑: 分析师自己预期FY2030收入下降(-2.8%), 回归均值后加权分可能更准确

注意: CPRT加权分最高(55.6)但回报(10x)不及FICO(53→68x)
→ 加权分预测的是"回报区间"而非精确排名
→ FICO的68x包含了"定价权期权"的非线性释放, 加权分无法完全捕捉
```

## 九、关键决策规则

### 规则1: 品质是入场券, 商业模型决定回报
```
FAST: 品质7/7 + B=22/40 → 5x
FICO: 品质7/7 + B=35/40 → 68x
→ 同样品质, B差13分 → 回报差13.6倍
```

### 规则2: 非周期性比高OPM更重要
```
IHG: 真实OPM 65% + 强周期 → 4x
FAST: 报告OPM 20% + 弱周期 → 5x
→ OPM高3.25倍, 但回报反而低 — 周期性税消灭了OPM优势
```

### 规则3: 锁定类型决定定价权, 锁定强度只决定留存率
```
标准/制度锁定 (FICO): 客户没替代品 → 定价权极强 → B4=5
运营/生态锁定 (CTAS): 切换成本极高 → 定价权强 → B4=4
网络锁定 (CPRT): 去别处价更低 → 中等定价权 → B4=3
渠道/习惯锁定 (FAST): 采购经理可比价 → 弱定价权 → B4=1.5
```

### 规则4: 收入纯度<50%时必须还原真实OPM
```
IHG报告OPM 23% → 看起来和ROL/FAST同级(20-22%)
IHG真实OPM 65% → 实际和FICO同级(68%)
→ 不做纯度还原 → 错误归类 → 错误估值
```

### 规则5: SBC是跨维度隐性税(AVGO教训)
```
AVGO Non-GAAP PE ~30x → 看起来合理
AVGO Owner PE 80.5x → 真实成本远高
→ SBC 11.8%跨越B1(-0.5)/B5(-0.75)/B6(-1.0)/B7(-1.0) = 合计-3.25分
→ 如果SBC正常化至7%, B总分29.5→32.75, 触碰"强偏好"门槛
→ 教训: SBC不是单一维度问题, 它同时侵蚀增速(B1)/利润(B5)/回报(B6)/TAM效率(B7)
```

### 规则6: 负权益需区分来源
```
返还过多(IHG/MCD): 累计回报>累计利润 → 好信号(FCF强劲+资本纪律)
亏损过多(WeWork): 累计亏损>累计融资 → 坏信号(商业模型不成立)
→ 负权益公司用EV指标(EV/EBITDA, EV/FCF), 不用ROE/P/B
```
