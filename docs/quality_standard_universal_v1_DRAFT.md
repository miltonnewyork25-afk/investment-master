## 二、10维度下限 (每个维度≥3.0, 三个致命维度≥5.0)

> **无固定权重。** AI根据公司特性自主分配深度。
> 唯一约束: 每个维度不能太差(≥3.0), 三个核心维度不能弱(≥5.0)。

| 维度 | 定义 | 下限 | 致命? |
|------|------|:----:|:-----:|
| **D1 数据基础** | 财务数据完整性+来源质量+交叉验证 | **5.0** | **致命** |
| D2 竞争格局 | 竞品覆盖+份额趋势+替代/分流分析 | 3.0 | |
| **D3 分析深度** | 因果链层数+证据链完整性+独立论证 | **5.0** | **致命** |
| D4 财务分析 | 趋势+杠杆+FCF质量+同行对标 | 3.0 | |
| **D5 估值质量** | 方法数量+收敛+逆向验证+Python | **5.0** | **致命** |
| D6 红队有效性 | 改变概率/估值的红队占比 | 3.0 | |
| D7 原创洞见 | 非共识框架+可迁移方法论+CI注册 | 3.0 | |
| D8 数据锚定 | DM密度+A级占比+交叉验证声明 | 3.0 | |
| D9 可视化/结构 | Mermaid+表格+阅读指南+章节连贯 | 3.0 | |

**致命规则**: D1<5 或 D3<5 或 D5<5 → 总分自动封顶3.5, 无论其他维度多高。

**总分计算**: 10个维度简单平均(不加权)。AI把精力花在哪里, 自然反映在分数分布中。

## 三、D10覆盖完整性: 13项清单

> 每项标记: ✅已覆盖 / ⚠️提及但不深入 / ❌缺失
> 达标率 = ✅数量/13。≥10/13 = D10≥4.0

| # | 维度 | 说明 | 必须? |
|---|------|------|:-----:|
| 1 | 业务模型理解 | 收入拆分+客户分层+定价 | ✅必须 |
| 2 | 竞争格局 | ≥3个竞品+份额+趋势 | ✅必须 |
| 3 | 护城河/品质 | CQI或定性评估+迁移分析 | ✅必须 |
| 4 | 财务趋势 | ≥3年P&L+BS核心指标 | ✅必须 |
| 5 | 估值 | ≥2种独立方法+收敛 | ✅必须 |
| 6 | 风险/红队 | ≥3个核心风险+概率量化 | ✅必须 |
| 7 | 管理层评估 | CEO能力+激励+继任 | 建议 |
| 8 | 资本配置 | 回购/分红/M&A效率 | 建议 |

## 四、各维度的水平描述 (3.0/4.0/4.5)

> 不是固定要求, 是**参考标杆**。AI用来自评。

## 七、AI自主性空间

**本标准不规定的(AI自主决定)**:
- 每个维度的深度分配(可以D7=9分, D2=4分 → 只要均分达标)
- 章节数量和结构(20章/15章/30章都可以)
- 字符在各Part间的分配
- 使用哪些skill/工具(按需加载)
- Mermaid图的数量和类型(G4取消固定数量要求)
- 证据链的具体层数(只要因果密度≥5.0)
- 红队的具体方法(只要净效果改变了概率/估值)

**本标准规定的(AI不可逾越)**:
- 8个硬性门控(G1-G8): 达标才能提交
- 3个致命维度(D1/D3/D5): ≥5.0
- 7个非致命维度: ≥3.0
- 6项必须覆盖(D10前6项)

**精简公式**: 8个门控 + 3个致命 + 7个下限 + 6个必须覆盖 = **24条约束, 其余自由。**
