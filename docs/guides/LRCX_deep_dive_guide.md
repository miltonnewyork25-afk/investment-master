## 二、前作v2.0解剖 — 5个必须修复的问题

### 问题1: 体量膨胀 (470K → 目标300-400K)

**诊断**: Phase 1行业概述占~100K，大量半导体基础知识(什么是刻蚀、什么是EUV)对读者无价值。
**修复**:
- 删除基础行业科普，假设读者已了解半导体设备行业
- 行业背景压缩至10-15K(仅含与LRCX直接相关的周期定位和竞争格局)
- 已有TSM/KLAC/AMAT报告的行业知识不再重复，用交叉引用替代
- **铁律**: 每写一段问自己"删掉这段，投资决策会改变吗？"不会 → 删

### 问题2: 中国风险处理 (EV加权 → 情景分析)

**诊断**: 旧版用单一期望值(概率×影响)处理出口管制风险，无法捕捉二元/跳跃性特征。
**修复**:
- **三情景模型**: S-China1(管制放松, 15%概率) / S-China2(现状维持, 55%) / S-China3(全面限制, 30%)
- 每个情景: 独立收入影响 + 独立利润率影响 + 独立估值倍数
- 参考TSM教训: 地缘风险"不适合概率×影响简单相乘，用条件估值"
- **关键数据**: 最新出口管制政策(2025-2026), LRCX中国收入季度趋势, 国产替代进度(AMEC/北方华创)

### 问题3: 方法伪独立 (5方法 → 审计后真正独立)

**诊断**: 旧版未运行独立性审计。AMAT教训: 5方法中3个共享核心假设=实际2.5方法。
**修复**:
- Phase 5前**强制运行** `/valuation-independence-audit`
- 预期: DCF和SOTP可能共享WFE增长假设 → 合并为"内生价值锚"
- 真正独立: Reverse DCF(价格→假设) + 可比公司(市场定价同行) + 条件估值(情景概率)
- **AB-007会检测**: phase_sentinel v2.1自动验证独立性审计已执行

### 问题4: 缺少杀手级洞见

**诊断**: 旧版有扎实的数据(44.4/万DM密度=记录)但缺乏改变框架的发现。
**修复 — 三个候选杀手级洞见方向**:
1. **CSBG隐性价值**: 安装基数8万+台设备 × 服务合同 = 类SaaS经常性收入流。独立估值CSBG可能揭示"设备+服务"二元结构中被低估的服务价值(参考AMAT AGS独立估值$31.9B发现)
2. **刻蚀工艺复杂度的结构性需求增长**: 3D NAND层数增加(200→300+层)和GAA晶体管对刻蚀步骤的需求不是线性增长，可能是超线性的。如果量化"每代制程刻蚀步骤增长曲线"，这是结构性增长vs周期性增长的关键区分
3. **信念反演**: Reverse DCF反推市场隐含WFE增长+份额假设 → 与行业共识对比 → 发现市场在赌什么/赌错什么(KLAC最强洞见方法)

### 问题5: 周期定位不够精确

**诊断**: 旧版周期分析偏定性，缺乏6层雷达量化定位。
**修复**:
- 执行6层雷达信号量化(DRAM/NAND价格趋势20% + Fab CapEx指引20% + BB Ratio 15% + 库存天数15% + 产能利用率15% + AI/DC终端需求15%)
- 明确标注"P几"阶段(P1复苏/P2扩张/P3峰值/P4减速/P5衰退)
- 与KLAC/AMAT/TSM报告时的周期定位对比: 时间推移了多少，周期阶段变化了吗？
