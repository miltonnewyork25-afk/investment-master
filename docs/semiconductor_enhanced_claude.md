## 🎯 行业特定分析要点

### 技术壁垒量化 (必须包含)
```yaml
制程代差分析:
- 技术节点领先性(几代)
- 良率优势量化(vs竞争对手)
- 产能爬坡时间对比
- 客户认证锁定程度

专利护城河:
- 关键专利数量+质量
- 专利诉讼风险评估
- 交叉授权依赖关系
- 专利到期风险分析
```

### 地缘风险量化 (强制要求)
```yaml
出口管制影响:
- 中国收入占比
- 受限产品/技术清单
- 许可证依赖程度
- 替代路线可行性

台海冲突情景:
- 基准情景(40%概率): 正常运行
- 收紧情景(35%概率): 部分制裁
- 极端情景(25%概率): 全面切断

供应链韧性:
- 关键供应商地理分布
- 生产基地分散程度
- 库存缓冲能力
- 应急方案成熟度
```

### AI需求结构性分析 (重点强化)
```yaml
AI vs传统需求分离:
- HBM: 结构性刚需，量价齐升
- 先进制程: AI驱动，挤出传统
- 传统DRAM: 受挤压，周期性
- 消费芯片: AI冲击，需求下滑

复杂度红利评估:
- 工艺步骤增加倍数
- 设备强度提升(CapEx/wafer)
- 测试复杂度上升
- 良率挑战加剧
```
