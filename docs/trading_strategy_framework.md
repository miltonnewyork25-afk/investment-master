# 交易策略框架 v2.0 — OEY体系 × 量化政体

> **目的**: 报告系统回答"值多少钱"。本框架回答"什么时候买、买多少、和什么搭配"。
> **v2.0核心升级**: 用OEY(Owner Earnings Yield)替代DCF公允价值作为交易锚点。用5个可观测指标替代主观政体判断。消除CAS假精度。
> **数据来源**: 完全复用报告系统产出(Moat DataCard + Complete报告 + Kill Switch) + FMP实时数据。
> **集成点**: Phase 5 Complete后生成策略卡 v3.0，存入 `reports/{TICKER}/{TICKER}_Strategy_Card_INTERNAL.md`。

## 一、资产DNA分类 (6种原型)

每只股票基于报告数据自动归类。分类依据来自 Moat DataCard 的 `d1_category`、`drawdown_dna`、`cqi_score` 等已有字段。

| 原型 | 判定规则 | 核心特征 | 代表公司 |
|------|---------|---------|---------|
| **反脆弱型** | D1>1.0 或 危机收入逆增 | 波动率多头，业务在危机中加速 | CME |
| **防御复利型** | D1非周期, CQI≥60, 收入14年+零下降 | 时间是盟友，缓慢但确定 | MSCI, SPGI, CPRT |
| **周期品质型** | D1半周期/全周期, CQI≥50 | 高品质但受周期驱动，低谷是入场点 | MCO, AMAT, LRCX, ETN |
| **成长利率敏感型** | 高增速(>20%), PE>35x, 利率敏感 | 低利率=估值扩张，高利率=压缩 | NVDA, META, GOOGL |
| **消费信心型** | 消费可选, 收入与消费信心高相关 | 消费繁荣=爆发，消费退缩=重压 | RCL, NKE, SBUX, HLT |
| **转折催化型** | 特定事件驱动, CQI<50或处于转型期 | 需要具体催化剂，不靠时间治愈 | INTC, SOFI |

### 分类流程

```
报告Complete → Moat DataCard已有
                    ↓
           读取d1_category + drawdown_dna + cqi_score
                    ↓
           匹配6种原型 (可能跨类: MCO = 周期品质 + 部分防御)
                    ↓
           写入策略卡 §0: 资产DNA
```

**多原型处理**: 许多公司跨类(如MCO = 64%防御复利 + 36%周期品质)。策略卡中注明主原型和副原型，按收入结构加权。

## 二、宏观政体分类 (6种政体) + 量化政体评分

将复杂的宏观环境简化为6种可识别政体。**v2.0升级: 用5个可观测指标的加权评分替代主观判断。**

| 政体 | GDP增速 | 利率方向 | VIX均值 | 历史实例 | 典型持续 |
|------|:-------:|:-------:|:-------:|---------|:-------:|
| **① 金发姑娘** | >2% | 稳定/温和 | <18 | 2017, 2024H1 | 12-24月 |
| **② 过热/紧缩** | >2% | ↑快速加息 | 18-28 | 2022H1, 2025关税战 | 6-18月 |
| **③ 冲击/恐慌** | 急跌 | 任何 | >30 | 2008.09, 2020.03 | 1-6月 |
| **④ 衰退** | <0% | ↓降息中 | 22-35 | 2008-09, 2020.Q2 | 6-18月 |
| **⑤ 复苏早期** | 转正 | 低位/缓升 | 15-22 | 2010-11, 2020.H2 | 12-24月 |
| **⑥ ZIRP停滞** | ~0-1% | ≈0% | <15 | 2012-15, 2019 | 24-60月 |

### 量化政体评分 (Quantitative Regime Score, QRS)

> **设计原则**: 5个指标、固定权重、机械计算。消除"我觉得现在是②还是③"的主观判断。

**5个指标 + 权重**:

| # | 指标 | 权重 | 数据源 | 频率 | 评分规则 |
|---|------|:----:|--------|:----:|---------|
| 1 | VIX月均值 | 25% | CBOE | 日 | <18→+2, 18-22→+1, 22-28→0, 28-35→-1, >35→-2 |
| 2 | FFR方向(3月变化) | 20% | Fed | 月 | 降息>50bp→+2, 降息25-50→+1, 持平→0, 加息25-50→-1, 加息>50→-2 |
| 3 | ISM PMI | 20% | ISM | 月 | >55→+2, 52-55→+1, 49-52→0, 46-49→-1, <46→-2 |
| 4 | HY利差方向(3月) | 20% | ICE/ML | 日 | 收窄>50bp→+2, 收窄20-50→+1, 稳定→0, 走阔20-50→-1, 走阔>50→-2 |
| 5 | 收益率曲线(10Y-2Y) | 15% | Treasury | 日 | >100bp→+2, 50-100→+1, 0-50→0, -50-0→-1, <-50→-2 |

**QRS计算**:

```
QRS = Σ(指标评分 × 权重)

范围: -2.0 到 +2.0
```

**QRS → 政体信号映射**:

| QRS范围 | 政体信号 | 含义 |
|:-------:|:-------:|------|
| +1.5 ~ +2.0 | +2 (甜蜜) | 宏观极度有利 |
| +0.5 ~ +1.4 | +1 (有利) | 顺风环境 |
| -0.4 ~ +0.4 | 0 (中性) | 无方向性偏好 |
| -1.4 ~ -0.5 | -1 (逆风) | 不利环境 |
| -2.0 ~ -1.5 | -2 (天敌) | 宏观极度不利 |

**资产特定调整**: QRS是通用宏观评分。每种资产原型对同一宏观环境的反应不同，通过§三的核心矩阵将QRS翻译为资产特定信号。

### 政体转换矩阵

```
① 金发姑娘 ──(加息+通胀)──→ ② 过热
② 过热 ──(黑天鹅/信用事件)──→ ③ 冲击
③ 冲击 ──(Fed放水/稳定)──→ ④ 衰退 或 ⑤ 复苏(V型)
④ 衰退 ──(政策刺激见效)──→ ⑤ 复苏
⑤ 复苏 ──(增长持续)──→ ① 金发姑娘
① 或 ⑤ ──(增长停滞+零利率)──→ ⑥ ZIRP停滞
⑥ ZIRP ──(通胀回归)──→ ② 过热
```

## 三、核心矩阵: 政体 × 原型 → 配置信号

**读法**: 行=当前政体，列=资产原型。格中数字=配置信号(-2到+2)。

| 政体 \ 原型 | 反脆弱 | 防御复利 | 周期品质 | 成长利率敏感 | 消费信心 | 转折催化 |
|:-----------:|:------:|:-------:|:-------:|:----------:|:-------:|:-------:|
| **① 金发姑娘** | -1 | +1 | +1 | **+2** | **+2** | 0 |
| **② 过热/紧缩** | +1 | +1 | 0 | **-2** | -1 | 0 |
| **③ 冲击/恐慌** | **+2**★ | 0 | -1 | -1 | **-2** | +1 |
| **④ 衰退** | 0 | +1 | **+2**★ | +1 | -1 | +1 |
| **⑤ 复苏早期** | -1 | +1 | **+2** | **+2** | +1 | +1 |
| **⑥ ZIRP停滞** | **-2** | +1 | 0 | +1 | 0 | 0 |

**信号定义**:
- **+2** = 甜蜜点，积极建仓(如估值也配合)
- **+1** = 有利，正常配置
- **0** = 中性，持有但不主动加仓
- **-1** = 逆风，减仓或不新建仓
- **-2** = 天敌，回避或极小仓位
- **★** = 最佳买点窗口(政体+估值双重有利时)

### 矩阵背后的逻辑

**反脆弱型(CME)**:
- 冲击/恐慌(+2★): 业务爆发(ADV+30~50%)但股价被砸(金融板块无差别抛售)→最大错杀机会
- ZIRP停滞(-2): 利息收入蒸发+低波动率=双杀(CME的天敌)

**周期品质型(MCO/AMAT)**:
- 衰退(+2★): 盈利已下滑至低谷、PE压缩→以周期底部估值买入永续垄断者
- 复苏早期(+2): 盈利拐点向上+PE扩张=双击

**成长利率敏感型(NVDA/META)**:
- 金发姑娘(+2): 低利率+增长=估值最友好
- 过热/紧缩(-2): 利率上行压缩久期最长的资产

**消费信心型(RCL/SBUX)**:
- 金发姑娘(+2): 消费信心高位+可选消费景气
- 冲击/恐慌(-2): 消费信心崩溃→收入断崖

**防御复利型(MSCI/SPGI)**:
- 全场+1: 不依赖特定政体，时间本身就是回报驱动力
- 唯一弱点: 估值泡沫(PE>40x时任何政体都不该追)

## 四、低风险高回报的核心策略: 政体错杀

> **核心洞察**: 最佳交易机会 = 市场按政体抛售，但公司基本面不受该政体伤害(甚至受益)。

### 4.1 三种错杀模式

| 错杀模式 | 机制 | 实例 | 预期超额收益 |
|---------|------|------|:-----------:|
| **板块错杀** | 恐慌中整个板块被砸，但公司基本面逆行 | 2008 CME(金融板块-70%，CME收入+12%) | +30~80% |
| **周期错杀** | 衰退恐惧压低估值，但公司收入其实非周期 | 2022 MSCI(-38%，收入实际+7%) | +20~40% |
| **利率错杀** | 加息恐慌砸成长股，但公司现金流实际不依赖低利率 | 2022 META(-65%，FCF实际$27B) | +50~100% |

### 4.2 错杀检测公式 (v2.0: OEY版)

```
错杀信号 = (OEY spread > 历史75分位) AND (Kill Switch未触发) AND (政体矩阵信号 ≥ +1)
```

具体化:
- OEY spread 进入历史10年"便宜区"(75分位以上)
- 12个Kill Switch中0个处于"已触发"状态
- 当前政体对该原型的配置信号 ≥+1
- FCF同比未下降>15%(排除基本面真实恶化)

**满足以上4条 = 强错杀信号 → 策略卡标记为"主动建仓窗口"**

### 4.3 仓位管理规则

| 条件 | 仓位 | 理由 |
|------|:----:|------|
| 政体信号+2 + OEY spread >75分位 | **满仓**(核心+弹性) | 双重有利，一辈子几次 |
| 政体信号+2 + OEY spread 50-75分位 | **核心仓位** | 政体对但估值不够便宜 |
| 政体信号+1 + OEY spread >75分位 | **核心仓位** | 估值够便宜补偿政体非最优 |
| 政体信号0 + OEY spread >75分位 | **试探仓位**(1-2%) | 估值便宜但政体中性 |
| 政体信号≤-1 | **不建仓** | 逆风环境，等政体转换 |

## 五、跨资产配对规则

### 5.1 相关性分组

将已覆盖公司按原型+行业分组，同组内不宜同时重仓:

| 组 | 成员 | 相关性 | 规则 |
|----|------|:------:|------|
| 信用评级双寡头 | MCO, SPGI | ρ>0.9 | **二选一** |
| 金融基础设施 | CME, ICE(如覆盖), MSCI | ρ~0.5-0.7 | 最多2/3 |
| 半导体设备 | AMAT, LRCX, KLAC | ρ>0.8 | **最多选2** |
| 半导体制造/设计 | TSM, NVDA, AMD, MU | ρ~0.6-0.8 | 注意周期同步 |
| 科技平台 | GOOGL, META, MSFT, AMZN | ρ~0.5-0.7 | 分散持有OK |
| 消费可选 | RCL, HLT, SBUX, NKE | ρ~0.6-0.8 | 消费信心同方向 |

### 5.2 互补配对 (对冲效果)

| 配对 | 逻辑 | 政体对冲效果 |
|------|------|-------------|
| CME + MSCI | 反脆弱+防御复利 | CME补冲击/恐慌，MSCI补ZIRP停滞 |
| 半导体 + 消费品 | 周期品质+消费信心 | 周期错位(半导体领先消费6-12月) |
| 成长股 + MCO | 利率敏感+反利率 | 加息伤成长但利于MCO发行(对冲失效于衰退) |
| CPRT + RCL | 非周期+强周期 | CPRT在衰退中稳定(事故率不降)，对冲RCL衰退风险 |

### 5.3 组合浓度限制

| 维度 | 上限 | 理由 |
|------|:----:|------|
| 单一原型 | ≤40% | 防单一政体逆转时全组合受损 |
| 单一行业 | ≤30% | 行业特有风险分散 |
| 单一公司 | ≤10% | 个股风险上限 |
| 高相关组(ρ>0.8) | ≤20% | 实质等于一个头寸 |

## 十、跨公司估值对齐标准 v2.0 — OEY体系

> **v1.1问题**: CAS = 品质×估值×政体 = 三个不确定数字相乘，假精度。QA-PE未经回测的发明公式。主观政体信号无固定标准。
> **v2.0解决**: 5个新指标，每个都基于可观测数据，每个都可独立解读，不相乘。

### 10.1 核心概念: OEY+g

```
OEY = FCFF / EV
    = (Operating Cash Flow - CapEx) / Enterprise Value

OEY+g = OEY + 可持续增长率
      = 你作为整个公司的所有者，每年拿到的总回报率
      (OEY = 今天能拿走的现金 / g = 明天会增长的现金)

OEY Spread = (OEY + g) - 无风险收益率
           = 你承担股权风险获得的超额补偿
```

**为什么用OEY而非DCF公允价值?**

| 维度 | DCF公允价值 | OEY+g |
|------|-----------|-------|
| 输入 | 增长率+WACC+终端倍数(三个假设) | 今天的FCF(事实) + 增长率(一个假设) |
| 失败模式 | WACC差0.5%→价值差20% | g差2%→结论只差2% |
| 可验证性 | 无法验证"公允价值"对不对 | FCF每季度公布，OEY可实时追踪 |
| 决策价值 | "市价低于公允价值→买" (但公允价值本身不确定) | "OEY spread>历史75分位→便宜" (可回测验证) |

### 10.2 五个标准化指标 (v2.0)

#### 指标①: OEY Spread (核心锚点)

```
OEY Spread = (OEY + g) - T-bill yield
```

- **正数** = 股票比国债值得买(补偿了风险)
- **负数** = 不如买国债(风险补偿不足)
- **越大越好**: OEY spread 9%远好于3%
- **注意**: g(可持续增长率)是唯一主观输入。取报告中的保守估计(正常化5年CAGR)，不用管理层指引

#### 指标②: 历史OEY Spread百分位

```
Percentile = 当前OEY spread在该公司自身10年OEY spread分布中的位置
```

- **>75分位** = 便宜档(历史上只有25%的时间比现在更便宜)
- **25-75分位** = 合理档
- **<25分位** = 贵档(历史上75%的时间比现在便宜)
- **替代了PE三档**: PE分档在跨公司比较时失效(MSCI "便宜"28x > MCO "贵"30x)，OEY spread百分位是每家公司用自己的历史说话

#### 指标③: 量化政体评分 (QRS)

```
QRS = VIX(25%) + FFR方向(20%) + ISM PMI(20%) + HY利差(20%) + 收益率曲线(15%)
范围: -2.0 ~ +2.0
```

- 完全取代主观判断
- 5个指标全部公开可得、日/月频更新
- 详见§二

#### 指标④: 永久资本损失价格

```
永久损失价格 = 10年累计Bear Case FCFF / 流通股数
```

- **含义**: "即使一切都糟糕，10年累计现金流还能覆盖我的买入成本"
- Bear Case = 报告中最悲观情景(不是末日情景，是可发生的坏情景)
- **用法**: 股价跌到永久损失价格以下 = 几乎不可能亏钱(用时间换空间)
- **与安全边际价的区别**: 安全边际价基于"多大折扣你愿意买"(主观)，永久损失价格基于"多低你不会亏"(客观)

#### 指标⑤: 风险调整利差 (Risk-Adjusted Spread, RAS)

```
RAS = OEY Spread / 最大预期回撤%
```

- **替代CAS**: CAS把三个维度乘在一起，RAS只做一个除法
- **含义**: 每承担1%的最大回撤风险，你获得多少%的超额利差
- **RAS > 0.25** = 优秀(每1%回撤风险换来>0.25%利差)
- **RAS < 0.10** = 差(风险补偿不足)
- 最大预期回撤 = 历史最大回撤或报告Bear Case回撤(取较大者)
