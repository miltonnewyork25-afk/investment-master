# 交易策略框架 v1.0 — 宏观政体×资产原型

> **目的**: 报告系统回答"值多少钱"。本框架回答"什么时候买、买多少、和什么搭配"。
> **数据来源**: 完全复用报告系统产出(Moat DataCard + Complete报告 + Kill Switch)，零额外数据采集。
> **集成点**: Phase 5 Complete后生成策略卡 v2.0，替代原入场纪律卡 v1.0。

---

## 一、资产DNA分类 (6种原型)

每只股票基于报告数据自动归类。分类依据来自 Moat DataCard 的 `d1_category`、`drawdown_dna`、`cqi_score` 等已有字段。

| 原型 | 判定规则 | 核心特征 | 代表公司 |
|------|---------|---------|---------|
| **反脆弱型** | D1>1.0 或 危机收入逆增 | 波动率多头，业务在危机中加速 | CME |
| **防御复利型** | D1非周期, CQI≥60, 收入14年+零下降 | 时间是盟友，缓慢但确定 | MSCI, SPGI, CPRT |
| **周期品质型** | D1半周期/全周期, CQI≥50 | 高品质但受周期驱动，低谷是入场点 | MCO, AMAT, LRCX, ETN |
| **成长利率敏感型** | 高增速(>20%), PE>35x, 利率敏感 | 低利率=估值扩张，高利率=压缩 | NVDA, META, GOOGL |
| **消费信心型** | 消费可选, 收入与消费信心高相关 | 消费繁荣=爆发，消费退缩=重压 | RCL, NKE, SBUX, HLT |
| **转折催化型** | 特定事件驱动, CQI<50或处于转型期 | 需要具体催化剂，不靠时间治愈 | INTC, SOFI |

### 分类流程

```
报告Complete → Moat DataCard已有
                    ↓
           读取d1_category + drawdown_dna + cqi_score
                    ↓
           匹配6种原型 (可能跨类: MCO = 周期品质 + 部分防御)
                    ↓
           写入策略卡 §0: 资产DNA
```

**多原型处理**: 许多公司跨类(如MCO = 64%防御复利 + 36%周期品质)。策略卡中注明主原型和副原型，按收入结构加权。

## 二、宏观政体分类 (6种政体)

将复杂的宏观环境简化为6种可识别政体。每种政体用3个可观测指标定义，不依赖预测。

| 政体 | GDP增速 | 利率方向 | VIX均值 | 历史实例 | 典型持续 |
|------|:-------:|:-------:|:-------:|---------|:-------:|
| **① 金发姑娘** | >2% | 稳定/温和 | <18 | 2017, 2024H1 | 12-24月 |
| **② 过热/紧缩** | >2% | ↑快速加息 | 18-28 | 2022H1, 2025关税战 | 6-18月 |
| **③ 冲击/恐慌** | 急跌 | 任何 | >30 | 2008.09, 2020.03 | 1-6月 |
| **④ 衰退** | <0% | ↓降息中 | 22-35 | 2008-09, 2020.Q2 | 6-18月 |
| **⑤ 复苏早期** | 转正 | 低位/缓升 | 15-22 | 2010-11, 2020.H2 | 12-24月 |
| **⑥ ZIRP停滞** | ~0-1% | ≈0% | <15 | 2012-15, 2019 | 24-60月 |

### 政体识别信号 (实时可观测)

| 信号 | 数据源 | 频率 |
|------|--------|:----:|
| VIX月均值 | CBOE | 日 |
| FFR / 2Y UST | Fed/Treasury | 日 |
| ISM PMI | ISM | 月 |
| 失业率变化方向 | BLS | 月 |
| 收益率曲线斜率(10Y-2Y) | Treasury | 日 |
| 信用利差(HY OAS) | ICE/ML | 日 |

### 政体转换矩阵

```
① 金发姑娘 ──(加息+通胀)──→ ② 过热
② 过热 ──(黑天鹅/信用事件)──→ ③ 冲击
③ 冲击 ──(Fed放水/稳定)──→ ④ 衰退 或 ⑤ 复苏(V型)
④ 衰退 ──(政策刺激见效)──→ ⑤ 复苏
⑤ 复苏 ──(增长持续)──→ ① 金发姑娘
① 或 ⑤ ──(增长停滞+零利率)──→ ⑥ ZIRP停滞
⑥ ZIRP ──(通胀回归)──→ ② 过热
```

## 三、核心矩阵: 政体 × 原型 → 配置信号

**读法**: 行=当前政体，列=资产原型。格中数字=配置信号(-2到+2)。

| 政体 \ 原型 | 反脆弱 | 防御复利 | 周期品质 | 成长利率敏感 | 消费信心 | 转折催化 |
|:-----------:|:------:|:-------:|:-------:|:----------:|:-------:|:-------:|
| **① 金发姑娘** | -1 | +1 | +1 | **+2** | **+2** | 0 |
| **② 过热/紧缩** | +1 | +1 | 0 | **-2** | -1 | 0 |
| **③ 冲击/恐慌** | **+2**★ | 0 | -1 | -1 | **-2** | +1 |
| **④ 衰退** | 0 | +1 | **+2**★ | +1 | -1 | +1 |
| **⑤ 复苏早期** | -1 | +1 | **+2** | **+2** | +1 | +1 |
| **⑥ ZIRP停滞** | **-2** | +1 | 0 | +1 | 0 | 0 |

**信号定义**:
- **+2** = 甜蜜点，积极建仓(如估值也配合)
- **+1** = 有利，正常配置
- **0** = 中性，持有但不主动加仓
- **-1** = 逆风，减仓或不新建仓
- **-2** = 天敌，回避或极小仓位
- **★** = 最佳买点窗口(政体+估值双重有利时)

### 矩阵背后的逻辑

**反脆弱型(CME)**:
- 冲击/恐慌(+2★): 业务爆发(ADV+30~50%)但股价被砸(金融板块无差别抛售)→最大错杀机会
- ZIRP停滞(-2): 利息收入蒸发+低波动率=双杀(CME的天敌)

**周期品质型(MCO/AMAT)**:
- 衰退(+2★): 盈利已下滑至低谷、PE压缩→以周期底部估值买入永续垄断者
- 复苏早期(+2): 盈利拐点向上+PE扩张=双击

**成长利率敏感型(NVDA/META)**:
- 金发姑娘(+2): 低利率+增长=估值最友好
- 过热/紧缩(-2): 利率上行压缩久期最长的资产

**消费信心型(RCL/SBUX)**:
- 金发姑娘(+2): 消费信心高位+可选消费景气
- 冲击/恐慌(-2): 消费信心崩溃→收入断崖

**防御复利型(MSCI/SPGI)**:
- 全场+1: 不依赖特定政体，时间本身就是回报驱动力
- 唯一弱点: 估值泡沫(PE>40x时任何政体都不该追)

## 四、低风险高回报的核心策略: 政体错杀

> **核心洞察**: 最佳交易机会 = 市场按政体抛售，但公司基本面不受该政体伤害(甚至受益)。

### 4.1 三种错杀模式

| 错杀模式 | 机制 | 实例 | 预期超额收益 |
|---------|------|------|:-----------:|
| **板块错杀** | 恐慌中整个板块被砸，但公司基本面逆行 | 2008 CME(金融板块-70%，CME收入+12%) | +30~80% |
| **周期错杀** | 衰退恐惧压低估值，但公司收入其实非周期 | 2022 MSCI(-38%，收入实际+7%) | +20~40% |
| **利率错杀** | 加息恐慌砸成长股，但公司现金流实际不依赖低利率 | 2022 META(-65%，FCF实际$27B) | +50~100% |

### 4.2 错杀检测公式

```
错杀信号 = (股价跌幅 > 同期收入跌幅 × 3) AND (Kill Switch未触发)
```

具体化:
- 股价YTD <-20%
- 收入YoY ≥0% 或 跌幅<5%
- 12个Kill Switch中0个处于"已触发"状态
- 当前政体对该原型的配置信号 ≥+1

**满足以上4条 = 强错杀信号 → 策略卡标记为"主动建仓窗口"**

### 4.3 仓位管理规则

| 条件 | 仓位 | 理由 |
|------|:----:|------|
| 政体信号+2 + 估值便宜档 | **满仓**(核心+弹性) | 双重有利，一辈子几次 |
| 政体信号+2 + 估值合理档 | **核心仓位** | 政体对但估值不够便宜 |
| 政体信号+1 + 估值便宜档 | **核心仓位** | 估值够便宜补偿政体非最优 |
| 政体信号0 + 估值便宜档 | **试探仓位**(1-2%) | 估值便宜但政体中性 |
| 政体信号≤-1 | **不建仓** | 逆风环境，等政体转换 |

## 五、跨资产配对规则

### 5.1 相关性分组

将已覆盖公司按原型+行业分组，同组内不宜同时重仓:

| 组 | 成员 | 相关性 | 规则 |
|----|------|:------:|------|
| 信用评级双寡头 | MCO, SPGI | ρ>0.9 | **二选一** |
| 金融基础设施 | CME, ICE(如覆盖), MSCI | ρ~0.5-0.7 | 最多2/3 |
| 半导体设备 | AMAT, LRCX, KLAC | ρ>0.8 | **最多选2** |
| 半导体制造/设计 | TSM, NVDA, AMD, MU | ρ~0.6-0.8 | 注意周期同步 |
| 科技平台 | GOOGL, META, MSFT, AMZN | ρ~0.5-0.7 | 分散持有OK |
| 消费可选 | RCL, HLT, SBUX, NKE | ρ~0.6-0.8 | 消费信心同方向 |

### 5.2 互补配对 (对冲效果)

| 配对 | 逻辑 | 政体对冲效果 |
|------|------|-------------|
| CME + MSCI | 反脆弱+防御复利 | CME补冲击/恐慌，MSCI补ZIRP停滞 |
| 半导体 + 消费品 | 周期品质+消费信心 | 周期错位(半导体领先消费6-12月) |
| 成长股 + MCO | 利率敏感+反利率 | 加息伤成长但利于MCO发行(对冲失效于衰退) |
| CPRT + RCL | 非周期+强周期 | CPRT在衰退中稳定(事故率不降)，对冲RCL衰退风险 |

### 5.3 组合浓度限制

| 维度 | 上限 | 理由 |
|------|:----:|------|
| 单一原型 | ≤40% | 防单一政体逆转时全组合受损 |
| 单一行业 | ≤30% | 行业特有风险分散 |
| 单一公司 | ≤10% | 个股风险上限 |
| 高相关组(ρ>0.8) | ≤20% | 实质等于一个头寸 |

## 十、跨公司估值对齐标准 (v1.1新增)

> **问题**: 三张策略卡用了三种不同的安全边际计算方法、PE分档标准、期望回报格式, 导致无法跨公司比较"先买哪个"。
> **解决**: 定义5个标准化指标, 每张策略卡必须包含, 使用统一公式。

### 10.1 五个标准化指标

#### 指标①: 公允价值折价率 (DFV%)

```
DFV% = (概率加权公允价值 - 当前股价) / 概率加权公允价值 × 100
```

- 正数 = 低估(有安全边际)
- 负数 = 高估
- 所有公司用同一公式, 公允价值来自各自报告的概率加权估值
- **注意**: 不同公司的公允价值置信度不同, 需要结合指标④一起看

#### 指标②: 品质调整PE (QA-PE)

```
QA-PE = 当前Forward PE / (CQI / 50)
```

- CQI/50 = 品质乘数: CQI 100→2.0x, CQI 50→1.0x, CQI 25→0.5x
- 含义: 高品质公司"值得"更高PE, QA-PE剥离品质溢价后比较"纯估值贵贱"
- QA-PE越低 = 品质调整后越便宜

| 公司 | PE | CQI | 品质乘数 | QA-PE | 排名 |
|------|:--:|:---:|:-------:|:-----:|:----:|
| CME | 28x | 93 | 1.86 | **15.1x** | 1 (最便宜) |
| MCO | 31.5x | 73.5 | 1.47 | **21.4x** | 2 |
| MSCI | 34.1x | 66 | 1.32 | **25.8x** | 3 (最贵) |

**发现**: CME表面PE(28x)看起来最便宜, QA-PE确认它品质调整后仍然最便宜。但这不代表"现在该买CME"——还需要看政体信号。

#### 指标③: 政体调整期望回报 (RAER)

```
RAER = 基础期望回报% × 政体乘数

政体乘数:
  +2 → 1.3  (甜蜜点: 放大预期)
  +1 → 1.1
   0 → 1.0
  -1 → 0.8  (逆风: 折扣预期)
  -2 → 0.5  (天敌: 大幅折扣)
```

- 基础期望回报 = DFV%的年化版(或报告中的概率加权期望回报)
- 政体乘数反映"当前环境是否有利于实现这个回报"
- **这是跨公司排序的核心指标**

#### 指标④: 安全边际价 (统一公式)

```
安全边际价 = min(
  PE方法: 历史10年PE 25分位数 × 正常化EPS,
  CQI方法: 概率加权公允价值 × (1 - CQI折扣率)
)

CQI折扣率:
  CQI ≥ 70 → 15% (高品质, 小折扣)
  CQI 50-69 → 20%
  CQI 30-49 → 30%
  CQI < 30 → 40% (低品质, 大折扣)
```

- 两种方法取**更保守者**(更低价格)
- PE方法捕获"周期底部"的估值
- CQI方法捕获"品质折扣"的估值
- 每张卡需列出两种方法的结果和最终取值

#### 指标⑤: 综合吸引力评分 (CAS)

```
CAS = 品质分 × 估值分 × 政体分

品质分 = CQI / 100                    (0~1, 越高越好)
估值分 = max(0, DFV% + 30) / 60       (0~1, DFV=-30%→0, DFV=+30%→1)
政体分 = (当前政体信号 + 2) / 4       (0~1, -2→0, +2→1)

CAS范围: 0~1, 越高 = 当前买入吸引力越大
```

- CAS是**单一排序数字**, 回答"所有股票中, 现在最该买哪个"
- 三个维度缺一不可: 品质差(CQI低)、估值贵(DFV负)、政体不利(信号低) 都会拉低CAS
- CAS > 0.4 = 值得关注, CAS > 0.6 = 强烈关注, CAS > 0.8 = 罕见机会

### 10.3 对齐表解读

**CAS排序**: CME(0.21) > MCO(0.13) > MSCI(0.12) — 但**全部低于0.4门槛**, 意味着当前没有一个是"立即买入"的。

**为什么三个都低?**
- CME: 品质极高(0.93)、政体有利(0.75), 但**估值太贵**(DFV=-12% → 估值分仅0.30)
- MCO: 品质好(0.74)、估值合理(0.72), 但**政体逆风**(②过热=-1 → 政体分0.25)
- MSCI: 与MCO类似, 品质+估值OK但政体逆风

**什么情况CAS能>0.6?**

| 假设情景 | CME | MCO | MSCI |
|---------|:---:|:---:|:----:|
| ③冲击 + 股价跌20% | **0.72** ✅ | 0.19 | 0.17 |
| ④衰退 + MCO PE→22x | 0.24 | **0.62** ✅ | 0.39 |
| ⑤复苏 + MSCI PE→28x | 0.10 | **0.52** | **0.55** ✅ |

→ 每种资产有自己的"CAS>0.6窗口", 与资产DNA吻合: CME等冲击, MCO等衰退, MSCI等复苏。

### 10.4 PE分档标准化规则

**问题**: MSCI "便宜"28x > MCO "贵"30x, 绝对PE不可比。

**解决**: PE分档必须基于**每家公司自身的历史PE分布**, 不用绝对数字:

```
便宜档 = 历史10年 PE 25分位数以下
合理档 = 历史10年 PE 25-75分位数
贵档   = 历史10年 PE 75分位数以上
```

同时保留绝对PE数字供单公司使用, 但跨公司比较一律用QA-PE(指标②)。

### 10.5 期望回报格式标准化

每张策略卡的§1估值快照必须包含:

```
| 指标 | 值 |
|------|-----|
| 概率加权公允价值 | ${X} (点估计, 不是范围) |
| 期望回报 | +X.X% (= (FV-P)/P) |
| RAER(政体调整) | +X.X% (= 期望回报 × 政体乘数) |
| DFV% | +X.X% (= (FV-P)/FV) |
| QA-PE | X.Xx (= PE/(CQI/50)) |
| CAS | 0.XX (= 品质×估值×政体) |
```

**禁止**: 期望回报用范围表示(如"-10~13%")。必须给概率加权点估计。范围信息放在5年路径概率分布表中。
