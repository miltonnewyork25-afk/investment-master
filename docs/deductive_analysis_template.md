# 演绎法5步分析模板 v1.0
# 源自: CRM v2.0 Ch26(演绎法分析) + ADBE v2.0 Part 3(演绎分析)
# 适用: AIAS Split Index>15 或 公司面临技术范式变革(AI/区块链/量子)
# 触发: CLAUDE.md "演绎+归纳双轨" 中的演绎路径

---

## 何时使用演绎法(而非归纳法)

| 条件 | 归纳法 | 演绎法 |
|------|--------|--------|
| 业务成熟,历史可外推 | ✅ | — |
| 范式变革(AI/新技术/监管巨变) | — | ✅ |
| AIAS Split Index>15 | — | ✅ |
| 行业PE中枢正在结构性移动 | — | ✅ |
| 历史案例可直接类比 | ✅ | — |

**规则**: 如果公司的核心业务模式可能在5年内被技术变革根本改变 → 必须用演绎法补充归纳法。两者不互斥。

## 5步执行模板

### Step 1: 触发事件识别

```
请识别【{公司}】面临的范式变革触发事件。

输出:
1. 触发事件名称 + 发生时间
2. 触发强度评估(1-5):
   - 1=边际影响 → 5=行业重构
3. 3个"为什么这次不一样"的证据(vs过去类似技术周期)
4. 1个"为什么这次可能一样"的反面(防止新技术过度乐观)

关键检验: 公司自己是否在"dog-fooding"(用自家新产品替代自家旧流程)?
如果是 → 触发强度+1(最强验证信号)
```

### Step 2: 因果链构建(三阶效应)

```
从触发事件出发,构建3层因果链:

一阶效应(0-2年): 直接可观测的变化
  → 哪些岗位/功能被替代?
  → 收入单元(seat/license/订阅)如何变化?

二阶效应(2-5年): 间接但可推理的变化
  → 定价模式是否需要转型?(per-seat→consumption)
  → 竞争格局如何重组?(新进入者/平台巨头)

三阶效应(5-10年): 行业级重估
  → PE中枢是否移动?(25x→15x?)
  → 行业TAM是扩大还是缩小?

每层输出:
- 因果链(A→B→C,明确因为/所以)
- 概率(该效应发生的概率)
- 对公司的收入/利润影响(定量)
```

### Step 3: 跨行业传导

```
该范式变革是否影响其他行业?传导路径是什么?

3条标准传导路径检查:
1. 功能链传导: 同一客户的不同职能(客服→销售→营销)
2. 平台链传导: 同一技术栈的不同层(CRM→ERP→HCM)
3. 宏观传导: IT支出→GDP→VC投资→行业创新

对每条路径:
- 是否活跃?(Y/N + 证据)
- 对目标公司是正面/负面/中性?
- 传导时间(月/年)?
```

### Step 4: 时间线标定

```
将Step 2+3的效应映射到具体时间线:

| 阶段 | 时间 | 公司影响 | 概率 | 关键里程碑 |
|------|------|---------|------|-----------|
| POC/试用 | 20XX-20XX | ... | ...% | ... |
| 早期采纳 | 20XX-20XX | ... | ...% | ... |
| 规模化 | 20XX-20XX | ... | ...% | ... |
| 新均衡 | 20XX-20XX | ... | ...% | ... |

输出:
1. 公司的"窗口期"(必须完成转型的时间): X年
2. 窗口期内的关键里程碑(可验证)
3. 窗口关闭后的终态(成功/失败各什么样)
```

### Step 5: 证伪条件

```
列出3-5个证伪条件——如果发生,演绎链断裂:

| 证伪条件 | 如果发生→链断裂处 | 对AIAS影响 | 对估值影响 | 可验证时间 |
|---------|-------------------|-----------|-----------|-----------|
| ... | 一阶/二阶/三阶 | ±X | ±$Y | FY20XX QN |

关键规则:
- 每个证伪条件必须有明确的数字阈值(非"显著下降")
- 必须有可验证的时间窗口(<12个月)
- 至少1个条件是"演绎法完全错误→回到归纳法"的全面证伪
```
