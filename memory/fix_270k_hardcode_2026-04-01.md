# 270K硬编码错误修复记录

> **发现日期**: 2026-04-01
> **问题根源**: 用户反馈每次报告字数要求应该不同，但系统错误地硬编码为≥270K
> **影响范围**: CLAUDE.md + 491个历史引用文件

## 问题诊断

### 错误来源
1. **主要根源**: `/CLAUDE.md` 第45行 G1字符门控硬编码 `≥270K`
2. **传播范围**: 491次历史引用，主要在`memory/`反思文件中
3. **系统矛盾**: 脚本层`quality_gate_complete.sh`已实现正确的动态基准

### 正确机制 (已存在于脚本中)
```bash
# 基于可能性宽度的动态基准
if [ "$POSSIBILITY_WIDTH" -le 3 ]; then
    BENCHMARK_CHARS=250000  # 传统框架
elif [ "$POSSIBILITY_WIDTH" -le 6 ]; then
    BENCHMARK_CHARS=200000  # 混合模式
else
    BENCHMARK_CHARS=350000  # 发现系统
fi
FLOOR_COMPLETE=$((BENCHMARK_CHARS * 80 / 100))
```
