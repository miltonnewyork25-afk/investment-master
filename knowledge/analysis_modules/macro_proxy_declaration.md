# 宏观代理标的声明协议 v1.0
# 触发条件: WACC弹性 > 15%
# 来源: EVO-V-03 (V Complete反思 — M10 kill_switch)
# 执行时机: Phase 5组装时

> **问题**: 当一家公司的估值对WACC高度敏感(弹性>15%)，个股研究的"边际价值"存疑——投资者花时间深度研究公司基本面，但估值主要由宏观因子(利率/风险溢价)驱动。此时需要诚实声明。

## WACC弹性计算方法

```
WACC弹性 = |DCF(WACC-100bps) - DCF(WACC+100bps)| / DCF(WACC_base)

示例:
  WACC=9.0%时 DCF=$350
  WACC=8.0%时 DCF=$420
  WACC=10.0%时 DCF=$295
  弹性 = |420-295|/350 = 35.7% → 远超15%阈值
```

**弹性分档**:

| WACC弹性 | 判定 | 含义 |
|----------|------|------|
| <10% | 低敏感 | 公司特有因素主导估值，个股研究价值高 |
| 10-15% | 中等 | 宏观和公司因素共同驱动，正常 |
| 15-25% | **高敏感** | 宏观因素显著影响估值，需声明 |
| >25% | **宏观代理** | 个股选择边际价值有限，考虑ETF替代 |

## ETF对比

Phase 5声明时，必须对比持有个股vs持有行业ETF的边际收益:

```
对比表:
| 指标 | {TICKER} | 行业ETF |
|------|---------|---------|
| 5年年化回报(预期) | X% | Y% |
| WACC弹性 | Z% | — |
| 分散化程度 | 单一公司 | N家公司 |
| 研究成本(时间) | 高 | 低 |
| 个股Alpha来源 | {列出} | 无 |
```

**个股Alpha来源**: 只有当个股有ETF无法捕捉的特异性因素(如管理层变革、产品周期、监管豁免)时，个股研究才有边际价值。

## 声明模板

Phase 5组装时，WACC弹性>15%的公司在估值章节加入:

```
**宏观敏感度声明**: 本公司WACC弹性为{X}%（WACC±100bps导致估值变化{X}%），
属于{高敏感/宏观代理}标的。估值结论对利率环境高度敏感。

**个股边际价值评估**: 相比持有{ETF名称}，个股选择的边际Alpha来源为:
{列出1-3个特异性因素}。如果投资者无法持续监控这些因素，
行业ETF可能是风险调整后更优的选择。
```

## 与M10 Kill Switch的关系

本协议是M10(宏观敏感度)模块kill_switch的执行层:
- M10 kill_switch阈值: WACC弹性>25%
- 本协议触发阈值: WACC弹性>15%(更早预警)
- M10说"评估个股选择边际价值"→本协议提供具体的评估方法和声明模板
