# 回购效率分析模块 v1.0

> **触发条件**: 公司年回购金额 > 0 **且** 回购/FCF > 20%
> **来源**: MCO v2.0 Ch2.4(eta量化+价值摧毁) + HLT v1.0 Ch12(边际递减函数+杠杆回购)
> **可迁移**: 任何有回购行为的公司(UNH/AAPL/META/GOOGL/V/MA等)

---

## 一、何时触发

在以下**任一**条件满足时，Phase 1或Phase 2的资本配置分析中必须包含本模块:

| 触发条件 | 阈值 | 示例 |
|---------|------|------|
| 年回购金额 | > $500M | MCO $1.7B, HLT $3.25B |
| 回购/FCF比 | > 50% | HLT 160%(举债回购!) |
| 连续回购 | ≥ 3年 | MCO 5年累计$8.5B |
| 负权益/TBV | Book Value < 0 | HLT -$5.4B, SBUX负权益 |
| PE > 25x 且回购 | PE在回购价上方 | MCO 33x, HLT 50x |

**不触发**: 偶尔小额回购(<$200M/年) 或 回购/FCF<20% 的公司

## 二、核心分析框架 (5步)

### Step 1: η(eta)效率计算

```
η = earnings yield / 资本机会成本
  = (1/回购PE) / WACC

η > 1.0 → 回购创造价值(每$1回购>$1经济价值)
η = 1.0 → 盈亏平衡
η < 1.0 → 回购摧毁价值(每$1回购<$1经济价值)
```

**必须输出**:
- 当前η值(基于当前PE和WACC)
- η=1.0对应的"盈亏平衡PE" = 1/WACC (e.g., WACC 9% → 盈亏平衡PE = 11.1x)
- 管理层是否有PE门槛纪律(多数没有)

**标杆**:
| 公司 | 回购PE | WACC | η | 判定 |
|------|:------:|:----:|:---:|------|
| MCO | 33x | 9% | 0.34x | 价值摧毁 |
| HLT | 50x | ~8% | 0.25x | 严重价值摧毁 |
| AAPL(参考) | 28x | ~9% | 0.40x | 价值摧毁 |
| 低PE公司(<15x) | 12x | 10% | 0.83x | 接近创造价值 |

### Step 2: 累计价值摧毁量化

```
累计摧毁 = Σ(年回购金额 × (1 - η))

5年回购$8.5B × (1 - 0.5均值) = $4.3B价值摧毁 (MCO案例)
```

**必须输出**:
- N年累计回购金额
- 平均η
- 累计价值摧毁额 + 占当前市值的百分比

### Step 3: 回购 vs 替代用途对比

| 替代选项 | 预期回报 | vs 回购η | 判定 |
|---------|---------|---------|------|
| 有机投资(CapEx/R&D) | 公司历史ROIC | >η → 应投资 | |
| 收购(M&A) | 历史收购IRR | >η → 应收购 | |
| 减债 | 债务成本(利率) | >回购yield → 应减债 | |
| 特别股息 | 股东自行配置 | — | 最后选择 |

**MCO案例**: BvD收购IRR 12-15% vs 回购η=3% → 收购效率是回购的4-5倍
**HLT案例**: 减债(利率4-5%) vs 回购(2%回报) → 减债效率是回购的2倍+

### Step 4: 回购陷阱(Buyback Trap)检测

**信号清单**:

| 信号 | 含义 | 检查方式 |
|------|------|---------|
| 回购/FCF > 100% | 举债回购 | FCF vs 回购+分红 |
| 负权益且加速回购 | 资产负债表恶化 | Book Value趋势 |
| 管理层减持+公司回购 | 利益冲突 | insider trading数据 |
| 回购无PE门槛 | 缺资本纪律 | 财报指引/Q&A |
| EPS增速>收入增速主要因回购 | 回购驱动假增长 | 有机EPS vs 报告EPS |

**HLT案例**: 5/5信号全中 → 典型回购陷阱

### Step 5: "在什么PE下应该停止回购"

```
停止回购的PE阈值 = 1 / max(WACC, 债务成本)

如果WACC=9% → PE>11x时回购开始摧毁价值
如果WACC=8% → PE>12.5x时
```

**但**: 多数公司在PE 25-50x仍在回购 → 因为停止回购的**信号成本**(市场解读为看空)大于回购的**经济成本**(η<1)。这是一个理性的囚徒困境。

## 四、与现有框架的集成

### 触发位置

| Phase | 触发点 | 说明 |
|-------|--------|------|
| **Phase 0** | `data-prefetch` | 获取回购历史数据(FMP cashflow) |
| **Phase 1** | 资本配置章节 | 如果触发条件满足 → 计算η |
| **Phase 2** | 护城河/品质评估 | η<0.5 → A-Score资本配置维度扣分 |
| **Phase 3** | 红队 | 回购陷阱信号≥3 → 作为红队攻击点 |

### 与D10覆盖完整性的关系

D10第8项"资本配置"→ 如果公司有回购行为但报告中没有η分析 → D10不能给满分

### 与估值的关系

- η<0.5 → 估值中应扣除"回购隐性税"(累计摧毁额/市值)
- 回购/FCF>100% → 加杠杆风险溢价(提高WACC 50-100bps)

## 五、不需要单独skill的理由

**不做成skill的原因**:
1. 这是一个**分析模块**(5步计算)，不是一个**工作流**(需要多步编排)
2. 计算简单(η=一行公式)，不需要复杂的prompt工程
3. 触发条件清晰(回购>$500M或回购/FCF>50%)，嵌入现有Phase 1流程即可

**保证不遗漏的机制**:
1. **Phase 0数据预取**: `data-prefetch`获取cashflow statement时，自动检查回购金额
2. **Phase 1门控**: 如果回购金额>$500M → staging/phase1产出中必须有"回购效率"小节
3. **D10覆盖检查**: Complete组装时，D10第8项"资本配置"检查η是否已计算
4. **本文件**: 放在`knowledge/analysis_modules/` → `find_relevant_knowledge.sh`会在Phase -1发现并提醒
