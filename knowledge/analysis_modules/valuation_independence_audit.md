# 估值方法独立性审计 v1.0
# 触发条件: 市值 > $500B
# 来源: EVO-V-01 (V Complete反思)
# 执行时机: Phase 5组装前

> **问题**: 巨头公司多种估值方法可能共享核心输入(如长期增速、WACC)，导致"4种方法收敛"实际只有1-2个独立信号。方法数量≠信息量。

## 审计清单

### Step 1: 列出每种方法的核心输入

| 方法 | 核心输入 | 输入来源 |
|------|---------|---------|
| DCF | 长期增速g, WACC, OPM, CapEx率 | 分析师假设 |
| Reverse DCF | 当前股价, WACC, OPM | 市场价格+分析师假设 |
| SOTP | 各分部增速, 各分部倍数 | 可比公司+分析师假设 |
| 可比估值(PE/EV) | EPS/EBITDA, 可比公司倍数 | 市场数据+筛选标准 |
| 概率加权 | 各情景概率, 各情景估值 | 上述方法+主观概率 |
| GGM/DDM | 股息, g, 折现率 | 财务数据+分析师假设 |

### Step 2: 计算输入间相关性矩阵

对每对方法，检查共享输入:

```
相关性判定规则:
- 两种方法共享同一关键假设(如都用同一个g) → 相关性=1.0
- 共享同一数据但不同角度(如DCF用g, Reverse DCF用股价反推g) → 相关性=0.5
- 无共享输入 → 相关性=0.0
- 加权相关性 = Σ(共享输入权重 × 该输入对结果的敏感度)
```

**常见高相关对**:
- DCF ↔ Reverse DCF: 共享WACC+OPM → 相关性通常>0.8
- DCF ↔ GGM: 共享g+折现率 → 相关性通常>0.8
- 概率加权 ↔ 所有子方法: 概率加权是子方法的线性组合 → 非独立

### Step 3: 独立性判定

| 相关性 | 判定 | 行动 |
|--------|------|------|
| >0.8 | **非独立** | 合并为一种方法计数，不能算"方法收敛" |
| 0.5-0.8 | **部分独立** | 可分别计数但需注明共享假设 |
| <0.5 | **独立** | 有效的独立验证 |

### Step 4: 确保至少3种真独立方法

**真独立方法组合示例**:
1. **Reverse DCF**(输入=市场价格) — 市场信号
2. **可比估值**(输入=同业倍数) — 相对定价信号
3. **FCF Yield / 股息率**(输入=历史现金流) — 现金回报信号

**常见伪独立陷阱**:
- DCF + Reverse DCF + GGM = 看似3种，实际共享WACC/g → 真独立≈1种
- 概率加权永远不是独立方法(它是子方法的加权平均)

### Step 5: 报告中的声明

Phase 5组装时，在估值章节开头加入:

```
**方法独立性审计**: 本报告使用{N}种估值方法，经独立性审计，{M}种为真独立方法
(相关性<0.5)。共享假设: {列出}。收敛结论的信息含量等价于{M}个独立信号，而非{N}个。
```

## 为什么巨头需要这个审计

市值>$500B的公司通常:
- 增长已减速→估值高度敏感于g和WACC→所有方法共享这两个假设
- 可比公司少(同级别巨头3-5家)→可比估值的独立性也有限
- 市场定价效率高→Reverse DCF和正向DCF趋同是正常的，不代表"验证"

不做独立性审计→"4种方法都说合理"可能只是"同一个假设说了4遍"。
