## 一、研报系统升级 (7项)

### 升级R1: 三PE并列展示 (强制)
**来源**: AMD/DDOG/AVGO/AAPL/CME等16份报告独立发现GAAP PE幻觉
**现状**: 报告中PE指标不统一，有时用GAAP，有时用Non-GAAP
**升级**: Phase 1执行摘要必须并列三个PE：

```
| PE类型 | 值 | 含义 |
|--------|-----|------|
| GAAP PE | 28x | 含SBC/非经营性收入/一次性 |
| Owner PE | 34x | 剥离SBC后的真实股东回报 |
| Core PE | 33.8x | 剥离非经营性收入后的核心运营 |
```

**触发条件**: SBC/Revenue>5% 或 非经营性收入/EPS>10%
**验证报告**: CME(Core PE), DDOG(Owner PE 188x vs Non-GAAP 49x), AVGO(Owner PE 80x vs headline 33x)

### 升级R2: 方法独立性审计 (Phase 5强制)
**来源**: AMAT发现DCF/SOTP/产品线法共享90%+假设→三方法"收敛"是幻觉
**现状**: 多方法估值后简单计算离散度，未检查假设共享
**升级**: Phase 5组装时运行独立性审计：

```
步骤:
1. 列出每种估值方法的核心假设(增速/margin/WACC/终端值)
2. 构建假设共享矩阵(方法×假设)
3. 共享假设>50%的方法组合→标记为"非独立"
4. 真独立方法数 = 去除非独立后的方法数
5. 如果真独立<2 → 离散度无效，需增加真独立方法
```

**验证报告**: AMAT(5方法→2.5独立), ARM(联合概率仅2%)

### 升级R3: 卖出框架标准化 (每份报告必含)
**来源**: 161条sell_lessons, PE上限纪律出现59次(最高频)
**现状**: 报告中有KS(Kill Switch)但没有系统的卖出框架
**升级**: 每份报告的执行摘要必须包含：

```yaml
sell_framework:
  pe_ceiling: "PE>Xx → 减仓Y%"     # 59次验证
  cycle_peak: "利息/周期指标Z → 减仓"  # 20次验证
  insider_signal: "内部人行为 → 跟随" # 14次验证
  buyback_waste: "eta<0.8 → 质疑资本配置" # 10次验证
  thesis_break: "承重墙W断裂 → 全部卖出"
```

### 升级R4: SBC影响标准化分析 (SaaS强制)
**来源**: DDOG/RBLX/PLTR/CRM/NOW等19份报告发现SBC隐性稀释
**现状**: 偶尔提及SBC，无标准化分析
**升级**: 所有SaaS/科技公司Phase 1必须包含：
- SBC/Revenue比率 + 3年趋势
- SBC增速 vs Revenue增速 (>1.5x = 恶化信号)
- Owner PE vs Non-GAAP PE差距
- Buyback/SBC比率(回购是否真实还原还是SBC对冲)

### 升级R5: 内部人行为分析标准化
**来源**: 14份报告验证"内部人行为>言辞"
**现状**: 有时提及insider trading，无标准化
**升级**: Phase 1必须包含：
- 6个月A/D比率(买入次数/卖出次数)
- **零买入信号**(比净卖出更有价值, COST发现)
- CEO个人交易 vs 公司行为矛盾检测(HLT/ANET发现)
- 信息不对称窗口: CEO 12月减持预测力>卖方(ANET发现)

### 升级R6: 巨头估值框架 ($500B+)
**来源**: AMZN/GOOGL/MSFT/META/AAPL/NVDA/TSLA 7份报告
**现状**: 已有巨头框架概念但执行不够标准化
**升级**: 市值>$500B时：
- **禁止给精确目标价** → 给条件映射("什么条件下变便宜/贵")
- **WACC±100bps影响测试** → 如果>所有业务分析累计影响 → DCF点估值降权
- **P/FCF vs PE分裂检测** → CapEx重投资期两者可能方向相反(GOOGL/AMZN)

### 升级R7: 概率赋值三重锚定 (强制)
**来源**: 43份报告验证概率三重锚定
**现状**: 铁律提及但无检查清单
**升级**: 每次赋概率必须注明三个锚：
1. **历史基准率**: 类似事件历史上发生过多少次？
2. **反例条件**: 历史反例需要什么特殊条件？当前是否具备？
3. **自然实验**: 有没有已发生的压力测试可以验证？

## 二、护城河分析框架升级 (6项)

### 升级M1: 护城河类型二分法 — 进攻型 vs 防御型
**来源**: AMD/NVDA对比 + ADBE/CRM对比
**现状**: 44因子CQI不区分护城河类型
**升级**: C1-C7评分后增加类型标注：

```
进攻型护城河(执行依赖): 每一代需重新证明→估值折价
  代表: AMD(Zen架构, 每代竞争), DDOG(产品网格, 需持续创新)
  特征: 停止投入→2-3年消失 | C7自维持性<2

防御型护城河(存量锁定): 不需持续投入→估值溢价
  代表: CME(制度嵌入), FICO(监管垄断), TSM(制程领先)
  特征: 停止投入→5-10年仍存在 | C7自维持性≥4

混合型: 核心防御+增量进攻
  代表: MSFT(Office防御+Azure进攻), AAPL(生态防御+芯片进攻)
```

**估值含义**: 进攻型给PE折价10-15%(执行风险), 防御型给PE溢价

### 升级M2: 多引擎半衰期 (替代单一半衰期)
**来源**: CME(清算>30年/数据>15年/利息<5年), MSCI(双半衰期), 27份报告
**现状**: moat_datacard给单一composite半衰期
**升级**: 按收入引擎拆分半衰期：

```yaml
half_life:
  engine_1: {name: "清算", revenue_pct: 81%, half_life: ">30年"}
  engine_2: {name: "数据", revenue_pct: 11%, half_life: ">15年"}
  engine_3: {name: "利息", revenue_pct: 8%, half_life: "<5年"}
  weighted: ">25年"
  warning: "利息引擎半衰期<5年但贡献20%利润→Core PE需剥离"
```

**触发**: 任何公司有≥2个收入引擎且半衰期差>2x

### 升级M3: C1制度嵌入五层深度 (从FICO/CME提炼)
**来源**: FICO(C1五层), CME(制度嵌入反脆弱), 12份报告
**现状**: C1只有一个0-5分，标注"偏好/标准/封锁/定义/独占"
**升级**: C1拆为五层独立评估：

```
L1 制度型(法律/监管强制使用): 半衰期>25年, 危机中加深
   例: CME(Dodd-Frank), FICO(GSE/ECOA), SPGI(SEC/NRSRO)

L2 操作习惯型(嵌入工作流程): 半衰期15-20年
   例: MSFT(Office), INTU(QuickBooks+CPA网络)

L3 偏好型(品牌/惯性选择): 半衰期5-10年
   例: ADBE(Creative Cloud偏好), SBUX(品牌忠诚度)

L4 合同型(多年合约锁定): 半衰期=合同期
   例: NOW(3-5年SaaS合约), ORCL(数据库迁移成本)

L5 网络/数据型(用户量/数据量锁定): 半衰期取决于替代品
   例: META(社交图谱), GOOGL(搜索数据飞轮)
```

**C1评分修正**: L1存在→最低4分 | L1+L2→5分 | 仅L3-L5→≤3分

### 升级M4: 飞轮净强度增强 — 增加"过载点"检测
**来源**: AMZN(飞轮过载), CME(飞轮摩擦力45%), 13份报告
**现状**: 飞轮摩擦力分析已有，但无过载检测
**升级**: 增加飞轮过载检测：

```
过载指标: CapEx/OCF > 80% → 飞轮"投资→利润"环节可能断裂
  AMZN: CapEx/OCF 91% → 飞轮过载确认
  META: CapEx/OCF ~85% → 飞轮过载边缘
  GOOGL: CapEx/OCF ~75% → 飞轮健康

过载的因果链:
  飞轮加速 → 需要更多投资 → CapEx飙升
  → 如果投资回报延迟(AI CapEx 3-5年回收)
  → 飞轮暂时"空转"(投入>产出)
  → 如果持续>2年 → 市场重新定价为"资本消耗者"而非"飞轮"
```

### 升级M5: 护城河AI冲击分层评估
**来源**: GOOGL/ADBE/INTU/CRM/NOW等6份报告
**现状**: AI冲击分析器存在但未与护城河评分整合
**升级**: 每个护城河维度增加"AI耐受度"标注：

```
| 护城河类型 | AI耐受度 | 逻辑 |
|-----------|---------|------|
| 制度嵌入(C1) | 极高 | AI不改变监管要求 |
| 物理壁垒(C6) | 极高 | AI不替代物理资产 |
| 规模经济(C5) | 高 | AI强化规模优势 |
| 数据飞轮(C4) | 中 | AI可能让数据壁垒贬值(合成数据) |
| 生态锁定(C3) | 中 | AI可能降低迁移成本 |
| 网络效应(C2) | 低-中 | AI可能创造替代网络 |
```

### 升级M6: 估值/护城河比率 (PE÷A-Score)
**来源**: ARM(比率19.8x最高), 跨报告比较
**现状**: CQI和PE分开评估
**升级**: 新增标准化指标——估值/护城河比率：

```
比率 = PE ÷ (A-Score × 10)
含义: 市场为每单位护城河支付多少PE

低(<1.5x): 市场低估护城河 → 潜在机会
合理(1.5-2.5x): 市场公平定价护城河
高(2.5-4.0x): 市场为护城河扩展预期付费 → 需要增速验证
极高(>4.0x): 护城河无法支撑估值 → 品质陷阱

标杆:
  ARM: 19.8x (极端——141x PE ÷ 7.17 A-Score)
  NVDA: ~5x
  CME: ~3.0x
  IHG: ~2.1x (低估信号)
```

## 三、选股筛选系统升级 (8项)

### 升级S1: PEG替代PE作为主估值筛选 (权重调整)
**来源**: 48份报告验证PEG>PE, CME是最强案例(PE最低28x但PEG最高3.7x)
**现状**: L1用PE<15筛选
**升级**: L1改为双重筛选：
- PE<25 **且** PEG<2.0 → 可能便宜
- PE<15但PEG>3.0 → **标记"低增速陷阱"**而非自动通过
- PEG<1.5 → 高优先级(增速被低估)

### 升级S2: 品质陷阱过滤器 (新增硬否决)
**来源**: 14份报告验证"品质≠回报", CME/KLAC/ASML/COST是案例
**现状**: L2只检查盈利质量，不检查品质陷阱
**升级**: 新增L2过滤器：
```
品质陷阱检测:
  CQI > 80 且 有机增速 < 7% 且 PE > 25x
  → 标记"品质陷阱"(好公司在差价格)
  → L2分数上限6.0(无论其他指标多好)
```

### 升级S3: 内部人零买入信号 (新增L1信号)
**来源**: COST发现, 10份报告验证
**现状**: L1只看insider买入金额
**升级**: 增加"零买入"检测：
```
6个月内insider交易:
  - 有买入(>$100K) → L1加分(已有)
  - 零买入 + 净卖出>$5M → 新增负面信号(-0.5分)
  - 全管理层零买入>12个月 → 强负面信号(-1.0分)
```

### 升级S4: SBC稀释检测 (新增L2信号)
**来源**: 19份报告验证SBC隐性稀释
**现状**: L2不检查SBC
**升级**: 新增L2信号：
```
SBC/Revenue > 15% → 警告
SBC增速/Revenue增速 > 1.5x → 加速稀释警告
Owner PE / Non-GAAP PE > 2x → "估值幻觉"标记
Buyback/SBC < 0.5 → 回购无法覆盖稀释
```

### 升级S5: 回购效率η检测 (新增L2信号)
**来源**: 30份报告验证回购@高PE毁灭价值
**现状**: L1用shareholder yield(含回购)但不检查回购效率
**升级**: 新增L2检测：
```
η值 = 1 - (PE - Fair_PE) / PE
  η > 1.0 → 价值创造(PE<公允值)
  η 0.8-1.0 → 中性
  η < 0.8 → 价值毁灭 → L2减分(-0.5)

简化版(不需要Fair PE):
  PE>30x + 年回购>FCF 30% → 标记"回购毁灭价值"
```

### 升级S6: Reverse DCF隐含增速 vs 历史增速 (新增L1信号)
**来源**: 37份报告验证Reverse DCF前置
**现状**: L1不做Reverse DCF
**升级**: Phase 4深度验证时增加简化Reverse DCF：
```
隐含CAGR = 从当前PE反推所需的EPS增速(5年)
历史CAGR = 过去5年实际EPS CAGR
差距 = 隐含CAGR - 历史CAGR

差距 > 5pp → "市场预期过高"(-1分)
差距 < -3pp → "市场预期过低"(+1分)
差距 ±3pp → 合理定价
```

### 升级S7: 周期位置检测 (新增L2信号)
**来源**: MU/LRCX/AMAT/NVDA等4份报告验证周期识别
**现状**: L2不检测周期位置
**升级**: 对半导体/工业/金融周期股增加：
```
Forward PE / Trailing PE < 0.6 → 可能在周期峰值(利润最高点)
  → MU案例: Forward PE 8.7x 看似便宜，但正常化PE 24-32x
  → 标记"周期峰值陷阱"
```

### 升级S8: 管理层行为-言辞一致性 (新增L3信号)
**来源**: HLT/ANET/ORCL等14份报告
**现状**: L3只看盈利超预期和分析师修正
**升级**: 新增L3行为信号：
```
CEO说看好 + CEO在卖股票 → 矛盾信号(-0.5分)
CEO说困难期 + CEO在买股票 → 正面信号(+1分)
全管理层方向一致(言行合一) → 中性(0分)
```
