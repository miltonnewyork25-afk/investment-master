## 12条核心原则 (P1-P12)

| # | 原则 | 实操含义 |
|---|------|---------|
| P1 | 先看税前再看税后 | 净利润最容易被扭曲(税率/一次性/递延)，税前利润更真实 |
| P2 | 收入增长≠利润质量 | 必须对比成本增速和利润率趋势，增收不增利=警告 |
| P3 | 先找利润基座再讲增长故事 | 哪个分部/产品线在供养公司？增长故事建立在什么基础上？ |
| P4 | 第二曲线需要利润验证 | 规模+增速+利润率+资本配置，四项全过才算真第二曲线 |
| P5 | 现金流是验证页 | FCF确认或否定利润——但必须先正常化(营运资金时点/CapEx分类) |
| P6 | 商誉不是护城河 | 是过去收购的溢价+未来减值风险，商誉/总资产>30%=高风险 |
| P7 | 递延收入可能是好负债 | 预付/订阅/高可见性=正面信号，区分运营负债vs融资负债 |
| P8 | 分部优先合并 | 合并报表趋势分叉时先看分部，分部拆解是诊断的入口 |
| P9 | 资本配置是财务质量的一部分 | 现金去哪里(回购/分红/M&A/再投资)直接影响长期价值 |
| P10 | 回报率比规模重要 | ROIC>WACC=创造价值，反之摧毁价值，增量ROIC尤其关键 |
| P11 | 反复出现的"一次性"不是一次性 | 连续3年有"重组费用"=业务模式的一部分，不应调整 |
| P12 | 每个结论必须可证伪 | Kill Switch注册表：什么数据出现→推翻当前判断 |

## 正常化层 (N1-N7)

在得出任何结论前，先剥离以下扭曲：

| 编号 | 扭曲类型 | 检查方法 |
|------|---------|---------|
| N1 | 税款时点 | 现金税vs报表税差异>30%→标记 |
| N2 | 内容/生产/采购成本时点 | 运营现金流出是否移入本季(预付/递延) |
| N3 | 增长CapEx vs 维持CapEx | D&A/CapEx比率+管理层披露拆分 |
| N4 | 一次性税务 | 税率调节项中>2pp来自非经常→当期税率不可持续 |
| N5 | 同比基数可比性 | 对比期是否有重组/减值/异常基数效应 |
| N6 | 反复Non-GAAP调整 | "非经常性"调整连续≥3期→重分类为经常性 |
| N7 | 资本化扭曲 | 资本化费用/总研发>30%→可能美化利润 |

## 执行流程 (7步)

```
S1: 导入财务数据（当期+同比+趋势）
S2: 构建报告视图（正常化前）
S3: 构建正常化视图（剥离N1-N7噪音）
S4: 核心模块分析（M1-M6）
S5: 扩展模块分析（E1-E6）
S6: 交叉验证（矛盾引擎C1-C7）
S7: 评分+总结（12维度×1-5分）
```

**路径路由** (继承ISDD，量化触发):
- `profit_lag = 收入增速 - 营业利润增速`
- profit_lag > 5pp连续2季 OR margin_delta < -200bps → 触发M1 β路径(逆向溯源)
- 并购整合/会计变更/税务结构变化 → α路径(正向分解)
- 稳态复检 → γ路径(快速扫描，仅M1/M3/M5)

## 核心模块（M1-M6）

### M1: 利润表诊断

**目标**: 报告增长是真实业务改善还是成本压力/税务扭曲/mix shift/会计噪音？

**ISDD β路径保留**(逆向溯源6步):
1. **利润脱钩检测**: 净利润增速 vs 收入增速 → profit_lag量化(>10pp严重/5-10中度)
2. **费用归因**: 逐行费用增速与收入增速对比 → 定位利润吞噬者(增速差>+10pp=强吞噬)
3. **成本分类**: 吞噬者是结构性(议价权弱)/战略性(主动投入)/周期性(商品波动)/临时性(一次性)
4. **单元经济验证**: 总量增长+单元利润率下降→"规模稀释经济性"；成熟单元也下降→核心恶化(最严重)
5. **引擎识别**: 核心盈利引擎(利润率最高+贡献最大) vs 扩张放大器(增速快但亏损) vs 摆动因子
6. **现金验证**: FCF/NI比率确认或否定利润真实性

**ISDD α路径**(正向分解): 经营杠杆分解(引用cycle_exposure_module)→盈利质量清洗(三版盈利GAAP/管理层/归一化)→EPS四因素分解(经营/税务/利息/回购，Python验证)

**嵌入检查**: 收入-费用同步性(5年数据) — 同步=盈利可预测/不同步=当期OPM≠稳态

**盈利质量清洗规则**:
- SBC/Rev > 5% → 不应剔除(实质性成本)
- SBC/Rev < 2% → 可剔除
- 持续并购公司的并购摊销 → 不应剔除(业务模式一部分)
- GAAP vs Non-GAAP差距: <10%高质量 / 10-25%中 / >25%低

**产出**: reported_profit_quality / normalized_profit_quality / margin_diagnosis / cost_classification

### M2: 资产负债表诊断

**目标**: 资产是否有经济价值，负债是否可管理？

**分析维度**:
- **硬资产vs软资产占比**: 现金/PPE/运营资产 vs 商誉/无形资产。商誉/总资产>30%=高减值风险
- **营运资产健康度**: 应收/存货/预付趋势——DSO增速>收入=付款恶化信号
- **负债性质**: 运营性(应付/递延收入=正常) vs 融资风险(高杠杆/短期到期集中)
- **递延收入**: 增长=预付/订阅健康；下降=需求转弱或合同结构变化

**产出**: asset_mix / liability_mix / watch_items

### M3: 现金流诊断

**目标**: 报告利润是否被现金验证或否定？

**核心指标**:
- OCF/NI(>1.0=现金确认盈利，<0.5=强制追因)
- FCF结构: 维持CapEx后的真实自由现金流 vs 一次性CapEx膨胀
- 融资依赖度: FCF为负时靠发债/增发维持运营=危险信号

**嵌入检查**(ISDD S8升级):
- (净利润-CFO)/总资产 > 10% → "应计膨胀警告：利润远超现金"
- (净利润-CFO)/总资产 < -5% → "现金超利润：盈利保守，质量高"
- 应收增速超收入增速>10pp连续2季 → 强制追因(渠道塞货？提前确认？)

**判定矩阵**:

| 利润质量(M1) | 现金转换 | 综合判定 |
|:-----------:|:-------:|---------|
| 高 | 强(>80%) | 高度可信 |
| 高 | 弱(<50%) | 存疑——深挖营运资金 |
| 低 | 强(>80%) | 谨慎乐观——会计扰动但现金健康 |
| 低 | 弱(<50%) | 高度担忧——双弱 |

**产出**: cash_conversion / normalized_cash / fcf_quality

### M4: 分部分析

**目标**: 找到真正的利润基座，验证第二曲线是否真实。

**分析逻辑**:
- **利润基座**: 利润率最高+贡献最大+趋势稳定的分部=公司的真正价值来源
- **第二曲线验证**: P4要求——规模(收入占比>10%)+增速(>公司平均)+利润率(>0或改善趋势)+资本配置(获得投入)四项全过
- **分部间蚕食**: 新业务成功是否蚕食核心(飞轮悖论检测——CRM教训)
- **集中度**: 单分部贡献>80%利润 → "单引擎依赖"
- 核心引擎增速<总增速 → 增长依赖扩张而非核心 → 质量警告

**产出**: profit_base / second_curve / divergence_map

### M5: 税务与调整

**目标**: 剥离税务和一次性扭曲，还原可持续盈利能力。

- **有效税率**: 取3-5年中位数(排除极端年份)=归一化税率
- **一次性判断**: 连续≥3年出现的"一次性"=经常性(P11铁律)
- **EPS四因素分解**(Python验证必须):
  - 经营贡献 = (ΔOI × (1-tax)) / shares_prior
  - 税务贡献 = pretax × (prior_ETR - current_ETR) / shares_prior
  - 利息贡献 = (Δinterest × (1-tax)) / shares_prior
  - 回购贡献 = EPS × (shares_prior - shares_current) / shares_prior
  - 四项之和≈总EPS变化(允许±2%舍入差)

**产出**: tax_distortion / one_time_assessment / eps_decomposition

### M6: 行业上下文

**目标**: 用行业经济学解读，不用通用会计逻辑。

**行业KPI集成点**(加载对应行业模块):
- **SaaS**: ARR/NRR/CAC/LTV/Magic Number/Rule of 40 → `enterprise_saas_modules.md`
- **消费品**: 同店增长/客单价/品牌力/私有品牌占比 → `consumer_modules.md`
- **半导体**: 库存周转/产能利用率/ASP×Volume/良率 → 半导体worktree
- **金融**: NIM/CET1/NCO/效率比率/综合比率 → 金融worktree
- **B2B平台**: 交易量/Take Rate/I×L双轴 → B2B worktree

**集成方法**: M6分析时加载对应行业KPI模块，将北极星指标嵌入M1-M5分析。行业决定哪些负债是正常/健康的、哪些资产类别最重要、什么现金流形态是正常的。

**产出**: industry_anchor / industry_red_flags

## 扩展模块（E1-E6）

### E1: 资本配置

**目标**: 现金去了哪里，是否创造或摧毁股东价值？

- **部署优先级**: 回购/分红/收购/偿债/再投资——排序反映管理层对未来的判断
- **η回购效率**(引用buyback_efficiency_module): η = FCF Yield / WACC。η<0.75=低效回购(资金应投入更高回报项目)
- **收购质量**: 扩大护城河(好) vs 增加商誉(待验证) vs 分散注意力(差)
- **红旗**: CA_RF1现金弱时回购 / CA_RF2商誉密集M&A / CA_RF3核心业务投入不足

**产出**: deployment_map / allocation_effectiveness / red_flags

### E2: 回报框架

**目标**: 投入资本是否赚到有吸引力的回报？

- ROIC/ROE/ROA趋势(≥5年)
- **增量ROIC**: 新投资是否仍然高产？增量ROIC<历史ROIC=回报衰减
- ROIC vs WACC: 持续>WACC=创造价值；差距收窄=竞争侵蚀
- **商誉密集型公司**: 区分GAAP ROIC(含商誉) vs 运营ROIC(剔除商誉)——差距大=ROIC幻觉(SPGI教训)
- **红旗**: RET_RF1 ROIC<WACC / RET_RF2 增量ROIC<历史ROIC

**产出**: return_profile / incremental_return / value_creation

### E3: 营运资本效率

**目标**: 应收/存货/应付变化是运营强度还是压力信号？

- DSO/DIO/DPO趋势 + 现金转换周期(CCC)
- 资产周转率趋势
- **红旗**: WC_RF1 DSO增速>收入 / WC_RF2 存货堆积 / WC_RF3 应付拉伸=现金压力

**产出**: wc_health / cycle_efficiency / conversion_quality

### E4: 会计质量

**目标**: 会计是否美化了经济现实？

- GAAP vs Non-GAAP差距(桥接+可信度)——差距大且持续=依赖调整
- "一次性"调整是否反复出现(P11检验)
- 资本化/摊销/拨备政策是否激进
- SBC是否被诚实对待(SBC/Rev比率趋势)
- **红旗**: AQ_RF1 GAAP/Non-GAAP差距持续>25% / AQ_RF2 资本化美化 / AQ_RF3 拨备释放

**产出**: accounting_cleanliness / adjustment_credibility / non_gaap_dependency

### E5: 多期趋势

**目标**: 当期是持久趋势、周期扭曲还是一次性异常？

- 1年/3年/5年对比——单季改善如果不被多年趋势支持=噪音
- 周期位置(扩张/谷底/复苏/峰值)——影响利润率/估值倍数的合理区间
- 管理层指引vs实际的一致性——多次miss=指引不可信
- **红旗**: MPT_RF1 单季改善无趋势支持 / MPT_RF2 利润率/ROIC多年衰减

**产出**: trend_persistence / cycle_context / guidance_credibility

### E6: Kill Switch注册表

**目标**: 每条财务结论→可证伪的监控规则+阈值+降级触发(P12铁律)。

每条论点登记：
- 当前判断(如"OPM可持续扩张")
- 证伪触发(如"OPM连续2季收缩")
- 阈值(如"OPM<22%")
- 监控频率(季度/年度)
- 降级动作(如"从'改善'降级为'稳定'")

**产出**: kill_switch_registry / monitoring_dashboard

## 矛盾引擎 (C1-C7)

强制检查叙事与经济现实的冲突——每条矛盾必须解释或修正判断：

| 编号 | 矛盾 | 追问 |
|------|------|------|
| C1 | 收入增长但利润未转化 | 成本结构性恶化？战略投入？周期? |
| C2 | 利润率改善但现金未确认 | 应计膨胀？营运资金吞噬？CapEx激增？ |
| C3 | 增长故事但回报不支持 | ROIC<WACC？增量回报衰减？ |
| C4 | Non-GAAP强但GAAP弱 | SBC过高？频繁重组？商誉减值？ |
| C5 | 营运资本变化 | 是运营强度(正面)还是压力(负面)？ |
| C6 | 单季vs多年 | 一致(趋势确认)还是矛盾(噪音)？ |
| C7 | 资产负债表"强"但软资产重 | 剔除商誉后还强吗？ |

## 评分框架 (12维度×1-5分)

**核心6维**(每维度≥3条证据):

| 维度 | 3分基线 | +1条件 | -1条件 |
|------|---------|--------|--------|
| 盈利质量 | GAAP/Non-GAAP差距<25% | <10%且稳定 | >25%或恶化 |
| 资产质量 | 硬资产占比>50% | 无商誉减值风险 | 商誉/总资产>30% |
| 负债质量 | 利息覆盖>3x | 运营负债为主 | 短期到期集中 |
| 现金质量 | FCF/NI 50-80% | >80%且稳定 | <50%或恶化 |
| 增长质量 | 有机增速>0 | 核心引擎驱动 | 并购/价格驱动 |
| 风险强度 | 无重大红旗 | Kill Switch全绿 | ≥2个红旗触发 |

**扩展6维**(每维度≥2条证据):

| 维度 | 3分基线 | +1条件 | -1条件 |
|------|---------|--------|--------|
| 资本配置质量 | 有明确部署逻辑 | η>1.0+M&A扩护城河 | η<0.75或CA_RF触发 |
| 回报质量 | ROIC>WACC | 增量ROIC≥历史 | 增量ROIC<WACC |
| 营运资本质量 | CCC稳定 | DSO/DIO改善 | WC_RF触发 |
| 会计质量 | 无激进政策 | 保守+透明 | AQ_RF触发 |
| 趋势质量 | 当期与多年一致 | 5年趋势正向 | MPT_RF触发 |
| 论点韧性 | Kill Switch<50%近阈值 | 全部远离阈值 | ≥2个近阈值 |

**总分**: 60分满分。≥42分=财务健康 / 30-42=中等 / <30=财务压力

## 行业优先级路由

| 行业 | 优先模块(3个) | 原因 |
|------|-------------|------|
| 消费品 | M1β(利润脱钩)→M4(单店)→E3(营运资本) | 扩张期最易增收不增利 |
| SaaS | M1(SBC争议)→M4(NRR/单元经济)→M3(递延收入) | SBC是最大争议，NRR是核心 |
| 半导体 | M1α(经营杠杆)→M4(终端市场)→E5(周期位置) | 高固定成本→杠杆极大 |
| 金融 | M5(拨备/税率)→M4(分部混合)→E2(ROIC vs WACC) | 拨备可大幅扭曲利润 |
| B2B平台 | M1(有机增速)→M4(核心引擎)→E1(M&A质量) | 并购驱动增长常见 |
