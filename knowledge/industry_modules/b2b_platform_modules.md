## 核心模块 M1-M10

modules:

### M1: 基础设施嵌入度评估
- **定义**: 衡量平台在客户核心业务流程中的不可绕过性
- **必问3问**:
  - Q1: 客户能否在不使用该平台的情况下完成核心业务流程? 成本倍数是多少?
  - Q2: 是否有法规/制度/行业惯例将该平台"硬编码"进业务流程?
  - Q3: 已知的最成功客户"脱离"案例是什么? 脱离后的成本/效率损失多大?
- **必填KPI**:
  - KPI1: I轴评分(I1-I5加总, /25) — 基准范围: ICE 22, MCO 18, CPRT 20
  - KPI2: 客户自建成本倍数(vs使用平台) — 基准: 2-10x
  - KPI3: 客户合同续签率(或隐性锁定率) — 基准: >90%
- **一致性检验**: I轴评分 × 合同续签率应>1800 (20×90%), 否则"嵌入"与"留存"矛盾
- **Kill Switch**: 续签率<85%连续2年 或 Top 3客户中有1家完全脱离 → 重新评估I轴

### M2: 流动性壁垒与网络效应
- **定义**: 衡量双边市场的流动性护城河深度
- **必问3问**:
  - Q1: 买方/卖方的规模比竞争者领先多少? 这个差距在扩大还是缩小?
  - Q2: 新进入者达到"最低可行流动性"需要多少时间和资金?
  - Q3: 网络效应是否有边际递减? 当前是否已在流动性曲线的平坦段?
- **必填KPI**:
  - KPI1: L轴评分(L1-L5加总, /25) — 基准: ICE 23, MCO 22, CPRT 24
  - KPI2: 买方规模vs最大竞争者(倍数) — 基准: 1.5-5x
  - KPI3: 价格溢价(vs次优平台, 衡量流动性变现) — 基准: 5-20%
- **一致性检验**: 价格溢价应与买方规模优势正相关(r>0.5), 否则流动性未有效变现
- **Kill Switch**: 价格溢价<5%连续4季 或 买方活跃率下降>10%连续3季 → 网络效应减弱

### M3: 寡头博弈均衡
- **定义**: 分析2-3家寡头之间的竞争动态和均衡稳定性
- **必问3问**:
  - Q1: 当前寡头均衡是合作博弈还是竞争博弈? 有无价格战历史?
  - Q2: 均衡稳定的前提条件是什么? 哪些事件可能打破均衡?
  - Q3: 有无"第三方"(监管/技术变革/新进入者)可能改变博弈结构?
- **必填KPI**:
  - KPI1: HHI(市场集中度指数) — 基准: >3000为高集中度寡头
  - KPI2: 利润率差距(寡头间OPM差, pp) — 基准: <5pp为均势, >10pp为不对称
  - KPI3: 份额稳定性(Top 3份额3年变动, pp) — 基准: <3pp为稳定
- **一致性检验**: HHI>4000但利润率差距<5pp暗示价格竞争; HHI>4000且差距>15pp暗示差异化/效率差
- **Kill Switch**: Top 3中任一份额单年变动>5pp → 均衡被打破, 需重新评估

### M4: 资产结构与隐含价值
- **定义**: 分析平台的有形/无形资产及其市场未定价的隐含价值
- **必问3问**:
  - Q1: 平台拥有哪些不可复制的有形资产? 账面vs公允价值差距多大?
  - Q2: 无形资产(数据/品牌/牌照/关系)的独立估值是否可行?
  - Q3: 隐含租金/隐含授权费等未反映在P&L中的价值有多少?
- **必填KPI**:
  - KPI1: PP&E账面vs公允价值估计比 — 基准: 1.2-3x(资产密集型B2B)
  - KPI2: 隐含租金/隐含授权费占OPM的提升(pp) — 基准: 3-15pp
  - KPI3: 替代成本/市值比 — 基准: 0.3-0.8x
- **一致性检验**: PropCo估值+OpCo估值应收敛于±15%的单一公司估值, 否则SOTP有内部矛盾
- **Kill Switch**: 资产公允价值大幅减记(>20%) 或 NIMBY/监管壁垒松动 → 重估资产溢价

### M5: 定价权与费率结构
- **定义**: 评估平台对买卖双方的定价权强度和可持续性
- **必问3问**:
  - Q1: 服务费率过去5年的趋势? 有无压缩信号?
  - Q2: 定价权的来源是什么? (垄断/锁定/增值服务/信息不对称)
  - Q3: 客户对费率提升的弹性如何? 有无公开的费率纠纷?
- **必填KPI**:
  - KPI1: 服务费率/Take Rate(%) — 基准: 因行业而异(拍卖8-12%, 交易所0.01-0.1%, 评级2-5bp)
  - KPI2: 费率5年CAGR(%) — 基准: 正增长=定价权存在
  - KPI3: Rev/单位(或Rev/交易)趋势 — 基准: 正增长=ASP提升或增值服务有效
- **一致性检验**: 费率增长+量增长应≈收入增长(±2pp), 否则有口径问题
- **Kill Switch**: 费率连续2季下降>50bps 或 大客户公开谈判降费 → 定价权被挑战

### M6: 客户集中度与锁定
- **定义**: 评估客户结构的健康度和锁定机制的真实强度
- **必问3问**:
  - Q1: Top 5/10客户占收入比? 是否过度集中?
  - Q2: 客户切换的实际案例有多少? 切换后的结果如何?
  - Q3: IT集成深度(系统对接/数据迁移)构成的真实切换成本是多少?
- **必填KPI**:
  - KPI1: Top 5客户收入占比(%) — 基准: <30%健康, 30-50%中度集中, >50%高风险
  - KPI2: 客户流失率(年化) — 基准: <5%优秀, 5-10%正常, >10%预警
  - KPI3: 平均合同期限(年) — 基准: >3年=强锁定, 1-3年=中等, <1年=弱
- **一致性检验**: 低流失率+短合同期=真实锁定; 低流失率+长合同期=合同锁定(到期风险)
- **Kill Switch**: Top 3客户中有1家年内合同到期且有竞争者接触 → 高优监控

### M7: 国际化与地域扩展
- **定义**: 评估平台的国际化能力和跨地域复制性
- **必问3问**:
  - Q1: 国际收入占比? 增速vs国内?
  - Q2: 国际市场的竞争格局是否与国内不同? 有无本土壁垒?
  - Q3: 平台模式的跨境复制成本多高? (监管/文化/物流/牌照)
- **必填KPI**:
  - KPI1: 国际收入占比(%) — 基准: >30%为全球化平台
  - KPI2: 国际收入增速(%) vs 国内增速 — 基准: 国际>国内=扩张有效
  - KPI3: 国际OPM vs 国内OPM — 基准: 差距<5pp为高效复制
- **一致性检验**: 国际收入高增速+国际OPM低=扩张期(可接受); 国际收入低增速+国际OPM低=失败信号
- **Kill Switch**: 国际OPM<0%连续4季 或 退出任一主要市场 → 国际化策略失败

### M8: 技术平台与数据资产
- **定义**: 评估平台的技术基础和数据资产的独立价值
- **必问3问**:
  - Q1: 技术平台是否是竞争优势来源? 还是只是运营工具?
  - Q2: 数据积累是否创造了竞争壁垒? (历史数据深度/独占性/AI应用)
  - Q3: 技术投入水平是否适当? (R&D/Rev, 与行业对比)
- **必填KPI**:
  - KPI1: R&D/Rev(%) — 基准: 因子类型而异(交易所5-10%, 信息平台10-15%)
  - KPI2: 技术平台年龄/更新周期 — 基准: <5年为现代, >10年为遗留风险
  - KPI3: 数据独占性评分(1-5) — 基准: 5=完全独占(FICO评分), 1=公开数据
- **一致性检验**: 高R&D+低数据独占性=低效投入; 低R&D+高数据独占性=搭便车(可持续但脆弱)
- **Kill Switch**: 技术平台重大故障(>24h停机) 或 数据泄露事件 → 信任危机

### M9: 资本配置与股东回报
- **定义**: 评估管理层的资本配置能力和股东回报策略
- **必问3问**:
  - Q1: FCF分配策略(回购/股息/CapEx/并购)是否与公司阶段匹配?
  - Q2: 管理层回购历史——是否在低估时买入? η(回购效率)如何?
  - Q3: 并购历史——成功率多少? 是否有过度收购的风险?
- **必填KPI**:
  - KPI1: FCF Yield(%) — 基准: 3-5%为健康B2B平台
  - KPI2: 回购η(回购后12M回报) — 基准: >0%为有效, >20%为优秀
  - KPI3: 净债务/EBITDA — 基准: <1x保守, 1-3x正常, >3x激进
- **一致性检验**: 零债务+高现金+不回购=资本效率低; 高债务+高回购=激进信号
- **Kill Switch**: 净债务/EBITDA>3x 或 回购η连续3年为负 → 资本配置失当

### M10: 监管与法律环境
- **定义**: 评估监管对平台的影响——保护vs威胁
- **必问3问**:
  - Q1: 当前监管框架是保护(进入壁垒)还是威胁(反垄断/合规)?
  - Q2: 有无进行中的监管调查/诉讼? 可能的结果范围?
  - Q3: 监管变化(环保/反洗钱/数据隐私)是否改变竞争格局?
- **必填KPI**:
  - KPI1: 法律费用/Rev(%) — 基准: <2%正常, >3%预警
  - KPI2: 未决诉讼计提金额/净利(%) — 基准: <5%可控, >10%重大
  - KPI3: 合规成本增速(%) vs 收入增速 — 基准: 合规增速<收入增速=可吸收
- **一致性检验**: 高计提+管理层否认=信息不对称风险; 零计提+已知调查=可能低估风险
- **Kill Switch**: 监管限制核心运营(限制买方/卖方访问, 强制拆分) → 业务模型威胁

## 扩展模块 E1-E5

### E1: 反周期性验证 (物理基础设施平台)
- **触发条件**: 公司声称具有反周期性或防御性
- **必问3问**:
  - Q1: 过去3次经济衰退中实际表现(收入增速)? 是真反周期还是叙事?
  - Q2: 反周期机制是什么? 在当前环境下是否仍然成立?
  - Q3: 消费者/企业行为变化(如放弃保险/减少投资)是否抵消了反周期性?
- **KPI**: 衰退期间Rev增速 vs S&P 500 Rev增速; D1调整系数(×0.9-1.1)
- **Kill Switch**: 衰退期间Rev<-5%连续2季 → 反周期叙事证伪

### E2: 物理资产NIMBY壁垒 (土地密集型)
- **触发条件**: 公司竞争优势依赖物理设施(码场/仓库/数据中心)
- **必问3问**:
  - Q1: NIMBY拒绝率多少? 新设施审批周期多长?
  - Q2: 竞争者的设施扩张速度能否追上?
  - Q3: 环保法规趋势对设施运营是保护还是威胁?
- **KPI**: NIMBY拒绝率(%); 竞争者土地面积增速(% YoY); 环保合规成本/Rev(%)
- **Kill Switch**: NIMBY拒绝率下降至<50% 或 竞争者土地面积3年CAGR>20% → 壁垒松动

### E3: 双边市场飞轮效率 (交易/拍卖平台)
- **触发条件**: 公司商业模式依赖双边市场匹配
- **必问3问**:
  - Q1: 飞轮处于加速/稳态/减速哪个阶段? 边际买方对卖方吸引力是否衰减?
  - Q2: 跨边外部性的强度如何量化? (多1%买方→ASP提升多少?)
  - Q3: 是否有"负飞轮"风险? (流动性流失→ASP下降→卖方离开→更多流动性流失)
- **KPI**: 跨边弹性(1%买方→X% ASP); 飞轮阶段评分(1-5); 负飞轮触发概率
- **Kill Switch**: 跨边弹性<0.1% 且 买方增速<0% → 飞轮进入衰减

### E4: 并购整合追踪 (近3年有重大并购)
- **触发条件**: 公司或竞争者近3年完成重大并购
- **必问3问**:
  - Q1: 整合进度如何? 客户流失/系统统一/文化冲突?
  - Q2: 协同效应是否兑现? 合并前承诺vs实际?
  - Q3: 并购后竞争格局如何变化? 是加强还是削弱了寡头均衡?
- **KPI**: 整合年限vs计划; 客户流失率(并购后 vs 并购前); 协同效应兑现率(%)
- **Kill Switch**: 并购后客户流失>10% 或 协同效应<承诺50% → 并购失败信号

### E5: AI/自动化颠覆风险 (所有B2B平台)
- **触发条件**: 行业存在AI/自动化替代可能性
- **必问3问**:
  - Q1: AI/自动化在多长时间内可能改变行业结构? 交叉点在哪年?
  - Q2: 公司是AI受益者还是受害者? 还是两者兼有?
  - Q3: 公司有无AI战略? 投资是否充分?
- **KPI**: AI交叉年份估计; AI投入/Rev(%); AI对核心业务的影响方向(+/-)
- **Kill Switch**: 行业AI替代产品市占率>10% → 颠覆风险实质化
