## 核心模块 M1-M10

modules:

### M1: 基础设施嵌入度评估
- **定义**: 衡量平台在客户核心业务流程中的不可绕过性
- **必问3问**:
  - Q1: 客户能否在不使用该平台的情况下完成核心业务流程? 成本倍数是多少?
  - Q2: 是否有法规/制度/行业惯例将该平台"硬编码"进业务流程?
  - Q3: 已知的最成功客户"脱离"案例是什么? 脱离后的成本/效率损失多大?
- **必填KPI**:
  - KPI1: I轴评分(I1-I5加总, /25) — 基准范围: ICE 22, MCO 18, CPRT 20
  - KPI2: 客户自建成本倍数(vs使用平台) — 基准: 2-10x
  - KPI3: 客户合同续签率(或隐性锁定率) — 基准: >90%
- **一致性检验**: I轴评分 × 合同续签率应>1800 (20×90%), 否则"嵌入"与"留存"矛盾
- **Kill Switch**: 续签率<85%连续2年 或 Top 3客户中有1家完全脱离 → 重新评估I轴

### M2: 流动性壁垒与网络效应
- **定义**: 衡量双边市场的流动性护城河深度
- **必问3问**:
  - Q1: 买方/卖方的规模比竞争者领先多少? 这个差距在扩大还是缩小?
  - Q2: 新进入者达到"最低可行流动性"需要多少时间和资金?
  - Q3: 网络效应是否有边际递减? 当前是否已在流动性曲线的平坦段?
- **必填KPI**:
  - KPI1: L轴评分(L1-L5加总, /25) — 基准: ICE 23, MCO 22, CPRT 24
  - KPI2: 买方规模vs最大竞争者(倍数) — 基准: 1.5-5x
  - KPI3: 价格溢价(vs次优平台, 衡量流动性变现) — 基准: 5-20%
- **一致性检验**: 价格溢价应与买方规模优势正相关(r>0.5), 否则流动性未有效变现
- **Kill Switch**: 价格溢价<5%连续4季 或 买方活跃率下降>10%连续3季 → 网络效应减弱

### M3: 寡头博弈均衡
- **定义**: 分析2-3家寡头之间的竞争动态和均衡稳定性
- **必问3问**:
  - Q1: 当前寡头均衡是合作博弈还是竞争博弈? 有无价格战历史?
  - Q2: 均衡稳定的前提条件是什么? 哪些事件可能打破均衡?
  - Q3: 有无"第三方"(监管/技术变革/新进入者)可能改变博弈结构?
- **必填KPI**:
  - KPI1: HHI(市场集中度指数) — 基准: >3000为高集中度寡头
  - KPI2: 利润率差距(寡头间OPM差, pp) — 基准: <5pp为均势, >10pp为不对称
  - KPI3: 份额稳定性(Top 3份额3年变动, pp) — 基准: <3pp为稳定
- **一致性检验**: HHI>4000但利润率差距<5pp暗示价格竞争; HHI>4000且差距>15pp暗示差异化/效率差
- **Kill Switch**: Top 3中任一份额单年变动>5pp → 均衡被打破, 需重新评估

### M4: 资产结构与隐含价值
- **定义**: 分析平台的有形/无形资产及其市场未定价的隐含价值
- **必问3问**:
  - Q1: 平台拥有哪些不可复制的有形资产? 账面vs公允价值差距多大?
  - Q2: 无形资产(数据/品牌/牌照/关系)的独立估值是否可行?
  - Q3: 隐含租金/隐含授权费等未反映在P&L中的价值有多少?
- **必填KPI**:
  - KPI1: PP&E账面vs公允价值估计比 — 基准: 1.2-3x(资产密集型B2B)
  - KPI2: 隐含租金/隐含授权费占OPM的提升(pp) — 基准: 3-15pp
  - KPI3: 替代成本/市值比 — 基准: 0.3-0.8x
- **一致性检验**: PropCo估值+OpCo估值应收敛于±15%的单一公司估值, 否则SOTP有内部矛盾
- **Kill Switch**: 资产公允价值大幅减记(>20%) 或 NIMBY/监管壁垒松动 → 重估资产溢价

### M5: 定价权与收入质量分层 (v2.0升级)
- **定义**: 评估平台定价权强度 + 不同收入层的质量和应享估值倍数
- **必问3问**:
  - Q1: 服务费率过去5年的趋势? 费率变化是定价权体现还是mix变化结果?
  - Q2: 定价权的来源是什么? (垄断/锁定/增值服务/信息不对称/资本效率)
  - Q3: 客户对费率提升的弹性如何? 有无公开的费率纠纷?
- **v2.0新增 — 收入质量分层** (金融交易所/基础设施平台必填):
  - Q4: 收入应如何MECE拆分? 每层的驱动变量是什么?
  - Q5: 哪些收入层与成交量强相关(周期性)? 哪些弱相关(结构性)?
  - Q6: 不同收入层应享受何种估值倍数? 哪一层最容易被市场错价?
- **收入质量四象限**:
  ```
  定价权强 + 量弱相关 = 最高质量 (数据订阅/牌照费 → 高倍数)
  定价权强 + 量强相关 = 高质量    (清算费/基准产品交易费 → 中高倍数)
  定价权弱 + 量弱相关 = 中等质量  (利息收入/投资收益 → 按周期定价)
  定价权弱 + 量强相关 = 最低质量  (非基准产品交易费/零售流量 → 低倍数)
  ```
- **必填KPI**:
  - KPI1: 服务费率/Take Rate(%) — 基准: 因行业而异(拍卖8-12%, 交易所0.01-0.1%, 评级2-5bp)
  - KPI2: 费率5年CAGR(%) — 基准: 正增长=定价权存在
  - KPI3: Rev/单位(RPC/交易)趋势 — 基准: 正增长=ASP提升或增值服务有效
  - KPI4 (v2.0): 高质量收入占比(%) — 定价权强+量弱相关的收入占总收入比 — 基准: >30%为健康
  - KPI5 (v2.0): 收入分层估值隐含价值 — 各层分别估值后加总 vs 统一倍数差距
- **一致性检验**: 费率增长+量增长应≈收入增长(±2pp), 否则有口径问题; 高质量收入占比应与P/E溢价正相关
- **Kill Switch**: 费率连续2季下降>50bps 或 大客户公开谈判降费 → 定价权被挑战; 高质量收入占比下降>5pp/年 → 收入结构恶化

### M6: 客户集中度与锁定
- **定义**: 评估客户结构的健康度和锁定机制的真实强度
- **必问3问**:
  - Q1: Top 5/10客户占收入比? 是否过度集中?
  - Q2: 客户切换的实际案例有多少? 切换后的结果如何?
  - Q3: IT集成深度(系统对接/数据迁移)构成的真实切换成本是多少?
- **必填KPI**:
  - KPI1: Top 5客户收入占比(%) — 基准: <30%健康, 30-50%中度集中, >50%高风险
  - KPI2: 客户流失率(年化) — 基准: <5%优秀, 5-10%正常, >10%预警
  - KPI3: 平均合同期限(年) — 基准: >3年=强锁定, 1-3年=中等, <1年=弱
- **一致性检验**: 低流失率+短合同期=真实锁定; 低流失率+长合同期=合同锁定(到期风险)
- **Kill Switch**: Top 3客户中有1家年内合同到期且有竞争者接触 → 高优监控

### M7: 国际化与地域扩展
- **定义**: 评估平台的国际化能力和跨地域复制性
- **必问3问**:
  - Q1: 国际收入占比? 增速vs国内?
  - Q2: 国际市场的竞争格局是否与国内不同? 有无本土壁垒?
  - Q3: 平台模式的跨境复制成本多高? (监管/文化/物流/牌照)
- **必填KPI**:
  - KPI1: 国际收入占比(%) — 基准: >30%为全球化平台
  - KPI2: 国际收入增速(%) vs 国内增速 — 基准: 国际>国内=扩张有效
  - KPI3: 国际OPM vs 国内OPM — 基准: 差距<5pp为高效复制
- **一致性检验**: 国际收入高增速+国际OPM低=扩张期(可接受); 国际收入低增速+国际OPM低=失败信号
- **Kill Switch**: 国际OPM<0%连续4季 或 退出任一主要市场 → 国际化策略失败

### M8: 技术平台与数据资产
- **定义**: 评估平台的技术基础和数据资产的独立价值
- **必问3问**:
  - Q1: 技术平台是否是竞争优势来源? 还是只是运营工具?
  - Q2: 数据积累是否创造了竞争壁垒? (历史数据深度/独占性/AI应用)
  - Q3: 技术投入水平是否适当? (R&D/Rev, 与行业对比)
- **必填KPI**:
  - KPI1: R&D/Rev(%) — 基准: 因子类型而异(交易所5-10%, 信息平台10-15%)
  - KPI2: 技术平台年龄/更新周期 — 基准: <5年为现代, >10年为遗留风险
  - KPI3: 数据独占性评分(1-5) — 基准: 5=完全独占(FICO评分), 1=公开数据
- **一致性检验**: 高R&D+低数据独占性=低效投入; 低R&D+高数据独占性=搭便车(可持续但脆弱)
- **Kill Switch**: 技术平台重大故障(>24h停机) 或 数据泄露事件 → 信任危机

### M9: 资本配置与股东回报
- **定义**: 评估管理层的资本配置能力和股东回报策略
- **必问3问**:
  - Q1: FCF分配策略(回购/股息/CapEx/并购)是否与公司阶段匹配?
  - Q2: 管理层回购历史——是否在低估时买入? η(回购效率)如何?
  - Q3: 并购历史——成功率多少? 是否有过度收购的风险?
- **必填KPI**:
  - KPI1: FCF Yield(%) — 基准: 3-5%为健康B2B平台
  - KPI2: 回购η(回购后12M回报) — 基准: >0%为有效, >20%为优秀
  - KPI3: 净债务/EBITDA — 基准: <1x保守, 1-3x正常, >3x激进
- **一致性检验**: 零债务+高现金+不回购=资本效率低; 高债务+高回购=激进信号
- **Kill Switch**: 净债务/EBITDA>3x 或 回购η连续3年为负 → 资本配置失当

### M10: 监管与法律环境
- **定义**: 评估监管对平台的影响——保护vs威胁
- **必问3问**:
  - Q1: 当前监管框架是保护(进入壁垒)还是威胁(反垄断/合规)?
  - Q2: 有无进行中的监管调查/诉讼? 可能的结果范围?
  - Q3: 监管变化(环保/反洗钱/数据隐私)是否改变竞争格局?
- **必填KPI**:
  - KPI1: 法律费用/Rev(%) — 基准: <2%正常, >3%预警
  - KPI2: 未决诉讼计提金额/净利(%) — 基准: <5%可控, >10%重大
  - KPI3: 合规成本增速(%) vs 收入增速 — 基准: 合规增速<收入增速=可吸收
- **一致性检验**: 高计提+管理层否认=信息不对称风险; 零计提+已知调查=可能低估风险
- **Kill Switch**: 监管限制核心运营(限制买方/卖方访问, 强制拆分) → 业务模型威胁

## 扩展模块 E1-E5

### E1: 反周期性验证 (物理基础设施平台)
- **触发条件**: 公司声称具有反周期性或防御性
- **必问3问**:
  - Q1: 过去3次经济衰退中实际表现(收入增速)? 是真反周期还是叙事?
  - Q2: 反周期机制是什么? 在当前环境下是否仍然成立?
  - Q3: 消费者/企业行为变化(如放弃保险/减少投资)是否抵消了反周期性?
- **KPI**: 衰退期间Rev增速 vs S&P 500 Rev增速; D1调整系数(×0.9-1.1)
- **Kill Switch**: 衰退期间Rev<-5%连续2季 → 反周期叙事证伪

### E2: 物理资产NIMBY壁垒 (土地密集型)
- **触发条件**: 公司竞争优势依赖物理设施(码场/仓库/数据中心)
- **必问3问**:
  - Q1: NIMBY拒绝率多少? 新设施审批周期多长?
  - Q2: 竞争者的设施扩张速度能否追上?
  - Q3: 环保法规趋势对设施运营是保护还是威胁?
- **KPI**: NIMBY拒绝率(%); 竞争者土地面积增速(% YoY); 环保合规成本/Rev(%)
- **Kill Switch**: NIMBY拒绝率下降至<50% 或 竞争者土地面积3年CAGR>20% → 壁垒松动

### E3: 双边市场飞轮效率 (交易/拍卖平台)
- **触发条件**: 公司商业模式依赖双边市场匹配
- **必问3问**:
  - Q1: 飞轮处于加速/稳态/减速哪个阶段? 边际买方对卖方吸引力是否衰减?
  - Q2: 跨边外部性的强度如何量化? (多1%买方→ASP提升多少?)
  - Q3: 是否有"负飞轮"风险? (流动性流失→ASP下降→卖方离开→更多流动性流失)
- **KPI**: 跨边弹性(1%买方→X% ASP); 飞轮阶段评分(1-5); 负飞轮触发概率
- **Kill Switch**: 跨边弹性<0.1% 且 买方增速<0% → 飞轮进入衰减

### E4: 并购整合追踪 (近3年有重大并购)
- **触发条件**: 公司或竞争者近3年完成重大并购
- **必问3问**:
  - Q1: 整合进度如何? 客户流失/系统统一/文化冲突?
  - Q2: 协同效应是否兑现? 合并前承诺vs实际?
  - Q3: 并购后竞争格局如何变化? 是加强还是削弱了寡头均衡?
- **KPI**: 整合年限vs计划; 客户流失率(并购后 vs 并购前); 协同效应兑现率(%)
- **Kill Switch**: 并购后客户流失>10% 或 协同效应<承诺50% → 并购失败信号

### E5: AI/自动化颠覆风险 (所有B2B平台)
- **触发条件**: 行业存在AI/自动化替代可能性
- **必问3问**:
  - Q1: AI/自动化在多长时间内可能改变行业结构? 交叉点在哪年?
  - Q2: 公司是AI受益者还是受害者? 还是两者兼有?
  - Q3: 公司有无AI战略? 投资是否充分?
- **KPI**: AI交叉年份估计; AI投入/Rev(%); AI对核心业务的影响方向(+/-)
- **Kill Switch**: 行业AI替代产品市占率>10% → 颠覆风险实质化

## v2.0 新增模块 E6-E8 (金融交易所适配器)

> **触发条件**: B2B平台子类型为"双边拍卖/交易所"且涉及金融产品清算
> **适用公司**: CME, ICE, CBOE, Eurex, LSEG, DB1
> **设计来源**: CME深度调研问题树(2026-03-15) — 用户提出的16章机制链问题
> **核心理念**: 金融交易所不按业务分部分析，按**机制链条**分析:
> 基准合约 → 流动性网络 → 清算资本效率 → 数据货币化 → 定价权 → 资本回报

### E6: 清算经济学 (Clearing Economics)
- **触发条件**: 公司运营中央对手方清算(CCP)或提供清算服务
- **核心论点**: 清算可能是交易所中最容易被低估的护城河层——它提供的不仅是履约保障，更是资本效率
- **必问5问**:
  - Q1: 清算提供的客户价值到底是什么? 履约保障/净额结算/保证金效率/客户黏性，哪个最重要?
  - Q2: 保证金offset与跨产品组合保证金能力有多重要? 客户因资本效率而多难离开?
  - Q3: 清算层的经济模型是什么? 清算费/净利息收入/违约基金收益如何构成?
  - Q4: 清算作为护城河的同时，是否也是风险集中点? 极端波动/会员违约时的脆弱点在哪里?
  - Q5: 清算能力的复制难点到底在技术、规则、资本、客户信任还是监管批准?
- **必填KPI**:
  - KPI1: 日均清算名义金额($T) — 基准: CME~$3T+
  - KPI2: 保证金节约(margin offset)日均金额($B) — 基准: CME~$80B+(2025 Q4)
  - KPI3: 客户资金余额($B) + 净利息收益率(bps) — 清算所持有客户资金的隐含收入
  - KPI4: 违约基金规模/日均清算名义(%) — 系统性风险缓冲厚度
  - KPI5: 清算收入/总收入(%) — 清算层在收入结构中的权重
- **一致性检验**: 保证金节约金额 × 客户资金成本 ≈ 客户留在平台的隐含经济价值; 应>清算费用
- **Kill Switch**: 清算会员违约事件 → 声誉+资本冲击; 保证金节约/客户资金余额比值下降>20% → 资本效率优势减弱; 监管要求清算互操作性(open access) → 护城河被制度削弱
- **ClearingCo估值法**: 将清算业务独立估值(净利息收入×利率敏感性 + 清算费×量弹性 + 违约基金资本成本)，与TradingCo和DataCo分开

### E7: 量的质量 (Volume Quality Analysis)
- **触发条件**: 公司收入>50%由交易量驱动
- **核心论点**: 不能只看ADV(日均成交量)——必须区分"高质量量"和"噪音量"
- **必问5问**:
  - Q1: 成交量增长来自更多客户、更高频交易、更多事件驱动，还是更多产品渗透?
  - Q2: 哪种成交量更可持续? 哪种更容易转化为长期OI(未平仓合约)、数据需求和客户黏性?
  - Q3: OI vs ADV哪个更能反映产品生命力? 在哪些产品里OI比ADV更关键?
  - Q4: RPC(每手合约收入)的变化代表什么? 是定价权还是产品mix变化?
  - Q5: 零售vs机构流量对平台生态是强化还是稀释?
- **量的质量三维矩阵**:
  ```
  维度1: ADV (规模) — 日均成交手数/合约数
  维度2: OI  (深度) — 未平仓合约量, 反映持仓承诺而非短期噪音
  维度3: RPC (价值) — 每手收入, 反映产品mix和定价权

  高质量量 = ADV↑ + OI↑ + RPC稳定/上升 (真实需求增长)
  低质量量 = ADV↑ + OI平/↓ + RPC↓ (投机/事件驱动的一次性量)
  ```
- **必填KPI**:
  - KPI1: ADV及YoY增速(按资产类别拆分) — 基准: CME 2810万手(2025创纪录)
  - KPI2: OI/ADV比值(持仓质量指标) — 基准: >1x为高质量(持仓>日交易), <0.5x为投机主导
  - KPI3: RPC(每手收入)5年趋势 — 基准: 稳定或上升=定价权/mix改善
  - KPI4: 非美国ADV占比及趋势 — 基准: >20%=全球化有效, 增速>美国=全球化加速
  - KPI5: 客户构成(FCM/做市商/资管/对冲基金/企业套保/零售)— 多样性=稳定性
- **一致性检验**: ADV×RPC应≈交易收入(±3%); OI增速应与ADV增速正相关(r>0.3), 否则ADV是短期噪音
- **Kill Switch**: OI连续4季负增长 → 产品生命力衰退; RPC下降>10%/年(非mix因素) → 定价权被侵蚀; 单一客户类型占ADV>50% → 集中度风险

### E8: 基准产品/合约形成机制 (Benchmark Product Formation)
- **触发条件**: 公司拥有被行业公认为"基准"的产品/合约/标准
- **核心论点**: 理解为什么一个合约/产品会成为全球基准，是理解交易所护城河根源的关键
- **必问5问**:
  - Q1: 基准产品的形成到底依赖历史路径、现货锚定、客户习惯、做市深度还是清算便利?
  - Q2: 公司哪些产品是真正不可替代的benchmark? 哪些看起来强但实际面临替代压力?
  - Q3: 基准地位是监管推动、市场选择，还是两者共同作用?
  - Q4: 产品组合之间是否存在交易联动、保证金联动、客户联动? (独立拼盘 vs 互相强化)
  - Q5: 哪些产品是流量入口(吸引客户到平台), 哪些是利润中心(贡献主要收入)?
- **基准产品护城河5维评估**:
  ```
  B1 历史路径锁定 (1-5): 合约存在多久? 历史数据系列价值?
  B2 现货锚定强度 (1-5): 合约是否锚定核心现货基准? (SOFR/WTI/S&P 500)
  B3 做市深度     (1-5): bid-ask spread多窄? 大单冲击成本多低?
  B4 监管嵌入     (1-5): 合约是否被监管/会计准则引用?
  B5 清算便利     (1-5): 合约是否享受跨品种保证金offset?

  总分≥20/25: 真正不可替代的基准 (如CME的Eurodollar/SOFR/E-mini S&P)
  总分15-19:  强基准但面临竞争 (如CME的WTI vs ICE的Brent)
  总分<15:    基准地位脆弱
  ```
- **必填KPI**:
  - KPI1: Top 3基准产品ADV占总ADV的比例(%) — 基准: 30-60%为健康集中, >70%为过度依赖
  - KPI2: Top 3基准产品全球市场份额(%) — 基准: >80%=不可替代, 50-80%=强但有竞争
  - KPI3: 基准产品5维评分加总(/25) — 基准: ≥20不可替代, 15-19强, <15脆弱
  - KPI4: 近5年是否有基准迁移事件(如LIBOR→SOFR) — 迁移成功=护城河转移, 失败=护城河消失
- **一致性检验**: 基准产品全球份额>80%但OI增速<0% → 行业本身在萎缩(不是份额问题是TAM问题)
- **Kill Switch**: 基准产品全球份额单年下降>5pp → 替代品正在成功; 监管要求基准合约可互操作/可替代 → 制度性护城河被拆除

## v2.1 新增: 完全垄断适配器 (EVO-VRSN-01/02/03, 2026-03-24审批)

> **触发条件**: HHI≥9000 或 市场份额>95% 的完全垄断公司
> **适用公司**: VRSN(.com注册表100%), FICO(信用评分制度垄断), 部分公用事业
> **源自**: VRSN v1.2反思 — M2/M3/M6在完全垄断下范式失效

### 模块改造 (EVO-VRSN-01)

**当HHI≥9000时, 以下模块自动切换为改造版本:**

**M2' 垄断纯度评估** (替代M2流动性壁垒)
- **定义**: 衡量垄断的"纯度"——是否存在任何削弱垄断的力量
- **三维评估**:
  - 政治纯度(1-5): 政治施压/反垄断调查是否威胁垄断地位
  - 技术纯度(1-5): 技术替代品(区块链/AI/开源)是否可行
  - 制度纯度(1-5): 授权合同/法规嵌入是否有到期/修改风险
- **必填KPI**:
  - KPI1: 垄断纯度总分(/15) — 基准: ≥12纯粹, 9-11有裂隙, <9受威胁
  - KPI2: 年度纯度变化(pp) — 下降>1pp/年=侵蚀信号
  - KPI3: 最脆弱维度的触发距离(当前值vs触发阈值)
- **一致性检验**: 纯度总分应与PE溢价正相关——纯度每降1分, PE应降1-2x
- **Kill Switch**: 纯度总分<9 或 单维度<2 → 垄断地位实质受威胁, 重估估值基础

**M3' 政治对手方博弈** (替代M3寡头博弈)
- **定义**: 分析监管者/国会/NGO作为"竞争替代"的博弈对手
- **必问3问**:
  - Q1: 政治对手方(监管者/国会)的激励结构是什么? 限价对谁有利?
  - Q2: 垄断者的政治防御策略(游说/分红/自限/就业)效果如何?
  - Q3: 制度捕获生命周期处于哪个阶段?(0授权→1自由→2关注→3约束→4公用事业化)
- **必填KPI**:
  - KPI1: 制度捕获阶段(0-4) — VRSN=2.5, FICO=2.0
  - KPI2: 政治施压频率(国会/监管行动次数/年) — 基准: <2次/年=安全
  - KPI3: 自限行动得分(1-5, 企业主动让步的程度) — VRSN首次分红=3/5
- **一致性检验**: 制度阶段应与OPM趋势负相关——阶段>3时OPM应开始下降
- **Kill Switch**: 制度阶段进入3(正式约束) → PE应从"成长型"切换至"公用事业型"(通常-30~-40%)

**M6' 渠道商+制度客户双层分析** (替代M6客户集中度)
- **定义**: 对完全垄断公司, "客户"应分两层——制度客户(授权方)+渠道客户(分销商)
- **Layer 1 制度客户**:
  - Q1: 授权方(ICANN/NTIA/政府)的利益与垄断者是否一致?
  - Q2: 授权续约的条件和不确定性?
  - KPI: 制度客户利益一致度(1-5); 授权到期年限; 续约概率(%)
- **Layer 2 渠道客户(EVO-VRSN-03)**:
  - Q1: Top 5渠道商的收入集中度? 利润率受提价挤压多少?
  - Q2: 渠道商是否有动力推广替代品?
  - Q3: 自有域名/直销渠道对传统渠道的替代趋势?
  - KPI: 渠道Top5收入占比(%); 渠道利润率提价敏感性(提价1%→渠道利润率-Xpp); 替代渠道占新增比(%)
- **一致性检验**: 渠道集中度×提价敏感性=政治反弹概率——如果Top1渠道利润率被提价挤压>3pp/年, 渠道可能成为限价运动的推手
- **Kill Switch**: Top 1渠道公开反对提价 或 替代渠道占新增>15% → 定价权通过渠道侧被间接削弱

### 定价权反身性临界点 (EVO-VRSN-02)

> **适用**: 任何有"提价权→政治/客户反弹"循环的公司

**弹性恶化曲线方法论**:
1. 收集历史"提价-需求"配对数据(≥5年)
2. 拟合弹性ε随累计价格P的关系: ε(P) = α + β·ln(P/P₀)
3. 找到"弹性恶化拐点": ε(P*) = -0.20(经验阈值, 超过此值提价净效应可能转负)
4. 计算"安全提价空间": 从当前价格到P*的距离

**必填字段**:
- F1: 弹性恶化曲线参数(α, β)
- F2: 当前弹性ε₀和趋势
- F3: 临界价格P*和距离(年数)
- F4: 政治反馈循环强度(提价→OPM↑→政治关注↑→限价概率↑的传导系数)

**Kill Switch**: ε<-0.20 → 提价净效应可能为负; 或 距P*<3年提价空间 → 进入"定价权消耗区"

### 渠道商视角标准化 (EVO-VRSN-03)

> **适用**: 所有B2B基础设施/平台公司的Phase 1

**强制包含**(Phase 1, 嵌入M6'或独立章节):
1. 渠道商Top 5识别+收入占比
2. 至少1家渠道商的利润率分析(提价对其P&L的影响)
3. 替代渠道/直销趋势评估
4. 渠道商作为"政治代理人"的风险(渠道商推动限价的激励)

**检查方式**: Phase 1 sentinel检查是否包含"渠道商"/"注册商"/"分销商"/"FCM"等关键词, 缺失则发出WARNING
