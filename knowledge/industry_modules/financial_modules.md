# 适用公司示例: JPM, SPGI, MSCI, V, BRK, SOFI

## 核心模块 M1-M10

modules:

### M1: 收入结构与利差/费率经济学
- **定义**: 解剖收入来源的构成——利息收入vs非息收入vs订阅/交易费——判断收入质量与利率敏感性
- **必问3问**:
  - Q1: 利息收入vs非息收入(或经常性订阅vs交易性收入)的占比各多少? 趋势是向高质量迁移还是恶化?
  - Q2: 核心利差(NIM)或核心费率(Take Rate/订阅ARPU)过去5年的趋势? 驱动因素是什么?
  - Q3: 收入中有多少比例是"睡后收入"(无需主动交付即可收取)? 占比是否在扩大?
- **必填KPI**:
  - KPI1: 非息收入占比(%) — 银行基准30-50%, 支付/信息服务>90%
  - KPI2: NIM(银行/保险)或ARPU/Take Rate(支付/信息服务) — 银行NIM基准2.5-3.5%
  - KPI3: 经常性收入占比(%) — 基准: >70%为高质量, <50%为交易依赖型
- **一致性检验**: 经常性收入占比高(>70%)但收入波动率高(σ>15%) → 经常性收入定义可能有水分, 需穿透合同条款
- **Kill Switch**: NIM连续4季收窄>20bps 或 核心费率连续2季下降>5% → 定价权/利差被压缩, 需重估盈利中枢

### M2: 信用风险与资产质量
- **定义**: 评估资产负债表中承担的信用风险暴露及管理质量(银行/保险核心, 信息服务/支付用轻量版)
- **必问3问**:
  - Q1: 信用风险暴露的规模和结构? (贷款组合/投资组合/应收账款/担保) 集中度如何?
  - Q2: 过去两轮衰退中实际损失率vs拨备覆盖率? 管理层是保守还是激进?
  - Q3: 信用风险是"自承担"还是"中介/评估"? (银行=自承担, MCO=评估, V=转嫁)
- **必填KPI**:
  - KPI1: NCO率(银行) 或 坏账率(Fintech) 或 N/A(纯信息/支付) — 银行基准0.3-0.8%
  - KPI2: 拨备覆盖率(准备金/NPL) — 银行基准120-200%
  - KPI3: 信用风险暴露/总资产(%) — 银行>60%, 支付<5%, 信息服务<2%
- **一致性检验**: NCO率下降+拨备覆盖率下降+贷款增速>GDP增速2x → 信用标准放松信号, 三者必须联合阅读
- **Kill Switch**: NCO率同比恶化>50bps 或 单季拨备/贷款>年度均值2x → 信用周期拐点, 需压力测试

### M3: 资本充足与杠杆管理
- **定义**: 评估资本结构的稳健性——监管资本(银行/保险)vs财务杠杆(非银金融)——判断安全边际
- **必问3问**:
  - Q1: 当前资本水平vs监管最低要求的缓冲有多大? (CET1缓冲/RBC比率/净债务EBITDA)
  - Q2: 压力情景下(失业率+3pp/利率±200bps)资本是否仍达标? CCAR/DFAST结果如何?
  - Q3: 杠杆是"生产工具"(银行/保险)还是"财务选择"(信息服务/支付)? 当前杠杆率是否最优?
- **必填KPI**:
  - KPI1: CET1比率(银行) 或 RBC比率(保险) 或 净债务/EBITDA(非银) — 银行CET1基准>11%
  - KPI2: 资本缓冲(vs监管最低, bps) — 基准>200bps
  - KPI3: 有形杠杆倍数(总资产/TBV) — 银行基准10-12x, 信息服务<3x
- **一致性检验**: ROAE>15%但CET1缓冲<100bps → 高回报可能来自过度杠杆而非运营效率, 需分离杠杆贡献
- **Kill Switch**: CET1缓冲<100bps 或 净债务/EBITDA>4x(非银) → 资本安全降级, 分红/回购能力受限

### M4: 监管环境与牌照壁垒
- **定义**: 评估监管对公司的双重作用——作为护城河(牌照/准入壁垒)vs作为成本/约束(合规/资本要求)
- **必问3问**:
  - Q1: 公司持有哪些稀缺牌照/资质? 新进入者获取同等牌照的时间和成本?
  - Q2: 监管趋势是收紧(更高资本要求/更严合规)还是放松(Fintech牌照/跨境互认)?
  - Q3: 监管变化中有哪些可能颠覆现有竞争格局? (开放银行/嵌入式金融/NRSRO改革)
- **必填KPI**:
  - KPI1: 合规成本/Rev(%) — 银行基准5-8%, 支付2-4%, 信息服务<2%
  - KPI2: 牌照稀缺度评分(1-5) — 5=全球仅3家(NRSRO), 1=注册即可
  - KPI3: 监管变化影响方向(+1保护/0中性/-1威胁) — 需定性打分并记录依据
- **一致性检验**: 牌照稀缺度≥4但OPM<同业中位 → 牌照价值未有效变现, 需检查运营效率或定价权
- **Kill Switch**: 重大监管处罚(>年净利10%) 或 核心牌照被限制/吊销 → 业务模型根基动摇

### M5: 客户粘性与转换成本
- **定义**: 衡量客户留存的真实机制——IT嵌入/工作流依赖/数据锁定/品牌信任——区分"懒惰"vs"锁定"
- **必问3问**:
  - Q1: 客户切换的实际总成本(直接+间接+机会成本)占客户在平台年支出的倍数?
  - Q2: 客户留存是"主动选择"(产品优势)还是"被动锁定"(切换成本)? 比例各多少?
  - Q3: 数字化/AI是否正在降低切换成本? 哪类客户最容易被撬动?
- **必填KPI**:
  - KPI1: 客户留存率/续约率(%) — 基准: >95%优秀, 90-95%正常, <90%预警
  - KPI2: 切换成本/年费比(x) — 基准: >3x=强锁定, 1-3x=中等, <1x=弱
  - KPI3: NRR(净收入留存率, %) — 基准: >110%=扩展型, 100-110%=稳定, <100%=收缩
- **一致性检验**: 留存率>95%但NRR<100% → 客户在减少用量但未离开, 可能是满意度下降的先行信号
- **Kill Switch**: 留存率<90%连续2季 或 NRR<95%连续4季 → 客户锁定机制失效

### M6: 规模经济与运营杠杆
- **定义**: 评估业务的边际成本结构——增量收入中多少比例转化为增量利润(运营杠杆)
- **必问3问**:
  - Q1: 增量利润率(Incremental Margin)是多少? 是否显著高于当前OPM?
  - Q2: 固定成本vs变动成本的比例? 收入下降10%时利润下降多少? (DOL)
  - Q3: 规模经济是否有上限? 在什么收入水平后OPM扩张将趋缓?
- **必填KPI**:
  - KPI1: OPM(%) — 银行基准30-40%(效率比率60-70%), 支付55-65%, 信息服务40-55%
  - KPI2: 增量OPM(过去3年, %) — 基准: >60%为强运营杠杆, <40%为弱
  - KPI3: DOL(营业杠杆系数) — 基准: 1.5-2.5x为健康, >3x为高波动
- **一致性检验**: OPM扩张+Rev增速放缓+员工增速>Rev增速 → OPM扩张可能来自削减投资而非真实杠杆
- **Kill Switch**: OPM连续3年收缩>100bps/年 或 增量OPM<0%(收入增长但利润不增) → 规模经济失效

### M7: 数字化/技术能力与数据资产
- **定义**: 评估技术投入的有效性和数据资产的独立价值——是竞争武器还是运营成本
- **必问3问**:
  - Q1: 技术平台是自建还是外购? 核心系统的年龄和现代化进度?
  - Q2: 数据资产是否构成独立壁垒? (独占数据/历史深度/AI应用/数据变现)
  - Q3: 技术投入是否转化为可衡量的业务成果? (成本降低/新产品收入/客户体验提升)
- **必填KPI**:
  - KPI1: 技术投入/Rev(%) — 银行基准8-12%, 支付10-15%, 信息服务15-25%
  - KPI2: 数据独占性评分(1-5) — 5=不可替代(评级历史/支付网络数据), 1=公开数据
  - KPI3: 数字渗透率(%) — 银行: 数字活跃用户/总客户; 信息服务: API/平台收入占比
- **一致性检验**: 高技术投入(>15%)+低数据独占性(≤2)+低数字渗透率(<50%) → 技术投入可能低效, 需审计ROI
- **Kill Switch**: 核心系统重大故障(>24h) 或 数据泄露影响>10万客户 → 信任危机+监管审查

### M8: 周期性与宏观敏感性
- **定义**: 量化公司盈利对宏观变量(利率/GDP/信贷周期/资本市场活跃度)的敏感度
- **必问3问**:
  - Q1: 哪个宏观变量对盈利影响最大? 弹性系数多少? (利率+100bps→盈利+X%)
  - Q2: 公司处于宏观周期的哪个位置? (利率见顶/信贷扩张尾声/资本市场回暖初期)
  - Q3: 管理层有哪些对冲宏观风险的工具? (资产负债匹配/业务多元化/对冲衍生品)
- **必填KPI**:
  - KPI1: 利率敏感性(NII变化/利率变动100bps, $M) — 银行/保险必填
  - KPI2: 收入Beta(公司Rev增速/名义GDP增速) — 基准: >1.5=强周期, 0.7-1.5=中等, <0.7=防御
  - KPI3: 过去3次衰退中最大盈利下滑(%) — 银行基准-30~-60%, 支付-5~-15%, 信息服务-5~-20%
- **一致性检验**: 自称"防御性"但衰退最大跌幅>-25% → 防御叙事证伪, 需按周期股估值
- **Kill Switch**: 收益率曲线持续倒挂>6个月(银行) 或 资本市场发行量同比-40%(信息服务) → 行业级逆风

### M9: 资本配置与股东回报
- **定义**: 评估管理层FCF分配的能力——增长投资vs回购vs分红vs并购——判断资本效率
- **必问3问**:
  - Q1: 过去5年FCF的分配比例(回购/分红/并购/有机投资)? 是否与公司阶段匹配?
  - Q2: 并购历史的成功率? ROIC vs WACC在并购后2-3年的趋势?
  - Q3: 回购时机选择——是否在低估时买入? η(回购效率: 回购后12M超额收益)如何?
- **必填KPI**:
  - KPI1: ROAE(银行/保险) 或 ROIC(非银) — 银行ROAE基准12-18%, 信息服务ROIC 15-30%
  - KPI2: FCF Yield(%) — 基准: 银行用分红Yield 2-4%, 非银FCF Yield 3-6%
  - KPI3: 回购η(回购后12M超额收益, %) — 基准: >0%有效, >10%优秀, <-10%价值毁灭
- **一致性检验**: 高ROAE(>15%)+低有机增长(<5%)+高回购比例(>50% FCF) → 成熟期信号, 需验证回购vs增长投资的取舍是否合理
- **Kill Switch**: ROIC<WACC连续3年 或 并购后3年客户流失>15% → 资本配置失当

### M10: 竞争格局与护城河持久性
- **定义**: 评估竞争格局的稳定性和护城河的侵蚀/强化趋势——未来5-10年结构是否改变
- **必问3问**:
  - Q1: 行业结构是寡头(银行/评级/支付网络)还是分散(Fintech/资管)? HHI多少?
  - Q2: 最大的颠覆威胁来自哪里? (Fintech/BigTech/监管开放/AI) 威胁时间线?
  - Q3: 护城河是在加宽(网络效应/数据积累/监管壁垒加高)还是收窄(技术降低壁垒/监管开放)?
- **必填KPI**:
  - KPI1: Top 3市场份额(%) — 基准: >60%=寡头, 30-60%=集中, <30%=竞争
  - KPI2: 新进入者5年内获得>5%份额的概率(定性, %) — 基准: <10%=壁垒坚固
  - KPI3: 护城河趋势评分(-2到+2, 年度) — +2=显著加宽, -2=显著收窄
- **一致性检验**: 护城河趋势评分为正但市场份额在流失 → 护城河评估可能有偏, 需检查份额流失原因
- **Kill Switch**: 新进入者3年内份额>10% 或 BigTech宣布进入核心业务 → 护城河受到实质性威胁

## 扩展模块 E1-E5

### E1: 利率环境深度分析 (利率敏感型)
- **触发条件**: 利息收入占比>30% 或 NIM为核心盈利驱动因素(银行/保险/部分Fintech)
- **必问3问**:
  - Q1: 资产负债久期缺口多大? 利率+100bps/-100bps对NII的12个月影响?
  - Q2: 存款Beta(存款成本随市场利率上升的比例)是多少? 与同业比较?
  - Q3: 收益率曲线形态变化(陡峭化/平坦化/倒挂)对盈利的差异化影响?
- **KPI**: 久期缺口(年); 存款Beta(%); NII敏感性($M/100bps); 固定vs浮动资产比
- **Kill Switch**: 存款Beta>80%(利率上行时成本侵蚀NIM) 或 久期缺口>3年(SVB类风险) → 利率风险集中

### E2: 支付网络经济学 (支付/清算平台)
- **触发条件**: 商业模式依赖交易量×费率结构(V/MA/ICE/交易所)
- **必问3问**:
  - Q1: 支付量/交易量增速vs GDP增速的倍数(渗透率驱动 vs 经济驱动)?
  - Q2: 监管对费率的压力趋势? (Durbin修正案/欧盟IFR/中国清算开放) 压缩幅度?
  - Q3: 新兴支付方式(A2A/RTP/CBDC/稳定币)在5-10年内对现有网络的替代率?
- **KPI**: 支付量增速/GDP增速倍数; 费率5年CAGR(%); 新兴支付替代率估计(%); 跨境交易占比(%)
- **Kill Switch**: 核心费率被监管强制下调>20% 或 A2A/RTP交易量占比>15% → 网络经济学被重构

### E3: 保险精算与准备金评估 (保险公司)
- **触发条件**: 公司以保费收入+投资收益为核心模式(BRK/PGR/AIG/保险科技)
- **必问3问**:
  - Q1: 综合成本率(Combined Ratio)趋势? 拆分承保利润vs投资收益的贡献?
  - Q2: 准备金充足性——过去5年准备金发展(Reserve Development)是利好还是利空?
  - Q3: 再保险策略和巨灾风险暴露? 气候变化对损失率的长期影响?
- **KPI**: Combined Ratio(%); 准备金发展(有利/不利, $M); 投资组合久期(年); 保费增速vs损失增速
- **Kill Switch**: Combined Ratio>105%连续4季 或 准备金不利发展>年净利20% → 承保纪律失控

### E4: 金融信息垄断与指数/基准嵌入 (信息服务)
- **触发条件**: 公司提供评级/指数/数据/分析等金融信息产品(SPGI/MCO/MSCI/ICE/Verisk/FICO)
- **必问3问**:
  - Q1: 产品是否被"硬编码"进监管/合同/投资流程? (如NRSRO评级/MSCI指数/LIBOR→ICE)
  - Q2: 订阅vs交易性收入的比例? 合同期限和自动续约条款?
  - Q3: 数据/方法论的独占性多强? 有无开源/公共替代方案正在获得份额?
- **KPI**: 监管嵌入深度评分(1-5); 订阅收入占比(%); 合同平均剩余期限(年); ACV增速(%)
- **Kill Switch**: 监管改革取消强制使用(如取消NRSRO要求) 或 开源替代方案市占率>10% → 制度租金被侵蚀

### E5: Fintech颠覆与嵌入式金融 (全行业)
- **触发条件**: 任何金融子行业——Fintech/BigTech/嵌入式金融正在改变竞争格局
- **必问3问**:
  - Q1: Fintech在公司核心业务领域的渗透率? 增速? 最大的Fintech竞争者是谁?
  - Q2: 公司是Fintech"受害者"(被颠覆)还是"受益者"(赋能Fintech)还是"参与者"(自建)?
  - Q3: 嵌入式金融(BaaS/API银行/BNPL)是否正在绕过传统分销渠道? 规模和速度?
- **KPI**: Fintech渗透率(%); 公司数字渠道获客占比(%); API/合作收入增速(%); 传统渠道萎缩速度(%)
- **Kill Switch**: Fintech在核心业务渗透率>20%且公司数字转型落后同业>2年 → 被颠覆风险实质化

## MECE覆盖验证

```
M1 收入结构        → "赚什么钱" (收入质量)
M2 信用风险        → "承担什么风险" (资产侧)
M3 资本充足        → "用什么本钱" (负债侧+权益)
M4 监管环境        → "谁定规则" (外部约束/保护)
M5 客户粘性        → "客户为什么留下" (需求侧锁定)
M6 规模经济        → "增长如何变利润" (供给侧效率)
M7 技术/数据       → "技术是武器还是成本" (能力层)
M8 周期敏感性      → "宏观怎么影响" (外部环境)
M9 资本配置        → "利润怎么分" (管理层决策)
M10 竞争/护城河    → "优势能持续多久" (结构层)

穷尽性: M1-M3覆盖财务三表核心 | M4-M5覆盖外部约束+需求侧 |
       M6-M7覆盖供给侧效率 | M8覆盖宏观环境 | M9覆盖管理层 | M10覆盖长期结构
互斥性: M2(信用风险)vs M3(资本)= 风险暴露 vs 风险缓冲, 不重叠
       M4(监管)vs M10(竞争)= 规则制定者 vs 玩家博弈, 不重叠
```
