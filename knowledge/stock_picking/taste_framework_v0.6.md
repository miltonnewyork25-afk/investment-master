# 选股品味框架 v0.6

> **起源**: 6成功案例(HEI/DHR/CSU/GE/FICO/Visa) + 5失败案例(Valeant/WU/Xerox/IBM/Kodak) + MSCI对标
> **v0.6核心升级**: 支付网络原型 + 定价权二维化(嵌入深度x定价自由度) + 攻击面力量分类(市场vs国家) + 吸收式防御
> **触发**: Visa分析揭示——嵌入最深(21/25)的公司定价权反而受限; 国家力量可绕过最强商业护城河

---

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.3: 增长引擎必须可观察、可追踪、可预测
v0.4: 增长≠收入增长。利润增长率可以是收入增长率的2-3倍
v0.5: 护城河≠永恒。定价权有来源、阶段和有效期。框架必须同时回答"为什么能赢"和"怎样会输"
v0.6: **嵌入深度≠定价自由度。最深的护城河(Visa 21/25)可能定价权反而受限。投资含义取决于"能不能加价"而非"护城河多深"。**

### 增长来源的偏好光谱

```
强烈偏好              可接受               回避
<---------------------------------------------->
纯有机增长      核心有机+补充性并购      纯并购驱动

IDXX CPRT FICO    ROL CTAS DCI         CSU HEI DHR
```

### v0.6的认知升级

```
v0.5思维: "Visa嵌入深度21/25(最高) → 好公司 → 应有定价权"
v0.6思维: "Visa嵌入21/25 → 但定价自由度受限(Durbin/EU cap) → 利润弹性空间有限
          → OPM已60-66%(天花板附近) → 增长只能靠全球交易量 → 好公司但非利润弹性型"

v0.5思维: "UPI/PIX是Visa的竞争对手"
v0.6思维: "UPI/PIX是国家力量支持的零费率替代品 → 市场竞争逻辑不适用
          → 这不是'更好的产品'打败'差的产品', 而是政府直接绕过基础设施
          → 攻击面分析必须区分市场力量vs国家力量"

v0.5思维: "Stripe是Visa的威胁"
v0.6思维: "Stripe跑在Visa的rails上 → 吸收式防御: 攻击者变成分销商
          → 比'筑墙'更弹性, 但允许缓慢侵蚀(价值链份额被压缩)"
```

## 第二层: 品味判断 (v0.6: 正面信号 + 假阳性防御, FP1升级)

### 2A. 正面信号 (10项, 20分)

| # | 信号 | 检查方法 | 权重 |
|---|------|---------|------|
| T1 | **有机增长引擎清晰** | 能用1句话说清为什么收入会持续增长? | **最高** |
| T2 | **原子化垄断/转换成本** | 产品/服务在细分市场形成小垄断或高粘性? | 高 |
| T3 | **经常性收入占比** | 订阅/维护/服务合同占比>50%? | 高 |
| T4 | **定价权证据** | 5年ASP持续上升 或 毛利率稳定>40%? | 高 |
| T5 | **利润弹性** | EPS CAGR > Revenue CAGR * 1.5? | 高 |

### FP1 v0.6升级: 嵌入深度 × 定价自由度二维评分

> **v0.5问题**: FP1只看"定价权来源是否持久"。但Visa揭示了一个盲区——嵌入最深的公司(法律/制度强制, 深度21/25)定价权反而受监管约束(EU cap, Durbin修正案)。嵌入深度≠定价自由度。

**二维矩阵**:

```
                    定价自由度
                低(受限)        高(自由)
嵌入深度  高  │ Visa(2,1)    │ FICO(2,2)   │  ← 嵌入深但定价受限 vs 嵌入深且定价自由
(制度/法律)   │ 稳定但无弹性   │ 利润弹性型   │
              ├──────────────┼─────────────┤
嵌入深度  低  │ WU(0,0)      │ Valeant(0,2)│  ← 嵌入浅+定价受限=最差 vs 嵌入浅+滥用=崩塌
(脆弱)        │ 双重风险       │ 滥用→崩塌   │
              └──────────────┴─────────────┘
```

**FP1评分规则 v0.6**:

| 嵌入深度 | 定价自由度 | FP1得分 | 投资含义 |
|---------|----------|---------|---------|
| 高(法律/制度/标准) | 高(无实质监管约束) | **2分** | **最优**: 嵌入深+可加价 = FICO/MCO/MSCI |
| 高 | 低(监管约束/政治敏感) | **1.5分** | **稳定但有限**: 嵌入深但利润弹性受限 = Visa/MA |
| 中(品牌/物理网络) | 高 | **1分** | **有风险**: 嵌入可被替代 |
| 中 | 低 | **0.5分** | **高风险**: 嵌入弱+定价受限 |
| 低(信息不对称/专利) | 任何 | **0分** | **红旗**: 嵌入可消失 |

**定价自由度判断标准**:

```
高(自由) = 以下全满足:
  - 无法定价格上限(无EU cap类监管)
  - 提价不引发政治关注(客户价值/价格比<1%)
  - 历史上成功提价且无反弹

低(受限) = 以下任一:
  - 存在监管定价上限(Visa: EU interchange cap 0.3%)
  - 提价引发政治/法律反弹(Visa: Durbin修正案)
  - 政府可直接创建零费率替代品(UPI/PIX)
  - 虽然理论上可提价, 但政治环境不允许
```

**Visa的FP1教训**:
- v0.5: Visa嵌入深 → FP1=2 → 看起来和FICO一样好
- v0.6: Visa嵌入深(2) × 定价受限(低) → FP1=1.5 → 正确区分: 稳定但无利润弹性

### FP1: 定价权耐久性光谱 (v0.5沿用, 覆盖嵌入深度维度)

```
脆弱 <---------------------------------------------> 持久
0分                    1分                         2分

信息不对称    专利/许可    品牌忠诚    物理网络    行业标准    法律/监管强制
(WU早期)     (Xerox)     (Kodak)    (WU网点)   (MSCI指数)  (FICO+MCO+Visa)

可被:         到期/撤销    可被范式    可被数字     极难替代    需要立法
透明化消除                 替代       化替代                   才能改变
```

### FP3: 技术替代三问检测 (v0.6扩展: 增加力量类型)

```
问题1: 能否想象一种完全不同的技术实现同样的功能?
  FICO → 需要同等统计预测力+制度接受度 → 极难 → 2分
  Kodak → 数码摄影(1975年已发明) → 0分
  Visa → 区块链/实时支付可替代卡网络 → 理论可行 → 1分

问题2: 替代技术处于什么阶段?
  实验室 → 5-10年窗口(可投资但监控) → 1分
  已商业化/已规模化 → 0分
  Visa → UPI/PIX已规模化但限于单国 → 1分(区域商业化, 未全球化)

问题3: 替代是否需要同时改变多个制度/系统?
  FICO: 需改联邦法规+GSE政策+银行系统+历史数据 → 多制度依赖 → 2分
  胶卷: 只需更好硬件 → 单点突破 → 0分
  Visa: 需改商户受理+银行合约+消费者习惯 → 多方但非不可能 → 1分

v0.6新增 — 问题3b: 替代力量来源是什么?
  市场力量(Stripe/BNPL) → 受商业逻辑约束, 通常被吸收 → 威胁较低
  国家力量(UPI/PIX) → 不受成本约束, 可强制零费率 → 威胁较高
  范式力量(区块链) → 需要基础设施范式转换 → 威胁不确定

  判断: 如果最大威胁来自国家力量 → FP3减0.5分(因为无法被吸收防御)
```

## 第三层: 估值框架

### 3.1 基础估值 (沿用v0.4)

| 指标 | "好价格" | "合理" | "贵" |
|------|---------|--------|------|
| FCF Yield | > 5% | 3-5% | < 3% |
| EV/EBITDA vs 增长 | < CAGR*2 | CAGR*2-3 | > CAGR*3 |

### 3.2 PEG计算 (沿用v0.4)

```
纯收入增长型: PEG = P/E / Revenue CAGR (IDXX, CPRT)
利润弹性型:   PEG = P/E / EPS CAGR    (FICO, CTAS, 回购+提价型)
不确定时:     PEG = P/E / max(RevCAGR, EPS_CAGR*0.7)
```

### 3.3 定价权阶段判断系统 (v0.5, 沿用)

**适用: 所有定价权驱动型公司(算法垄断/平台型)**
**v0.6注意: 受限定价权公司(Visa/MA)不适用此系统 — OPM位置比/提价加速度指标无意义**

5个量化指标:

| 指标 | 公式 | 阶段1(买) | 阶段1.5(可买) | 阶段2(谨慎) |
|------|------|----------|-------------|-----------|
| **OPM位置比** | (当前OPM-行业均)/(天花板-行业均) | <30% | 30-60% | >70% |
| **市场认知度** | 当前EV/EBITDA / 5年均值 | <0.8x | 0.8-1.1x | >1.2x |
| **提价加速度** | 近3年有机CAGR / 前5年有机CAGR | <1.0x | 1.0-1.5x | >1.5x |
| **回购强度** | 年回购/年FCF | <50% | 50-100% | >100% |
| **监管关注度** | 定性0-10 | <2 | 2-5 | >5 |

**阶段-行动矩阵**:

| 综合阶段 | 估值要求 | 行动 |
|---------|---------|------|
| **阶段1** (<1.3) | 合理即可(PEG<2.5) | **重仓** — 极罕见的机会 |
| **阶段1.5** (1.3-1.7) | 需要"好价格"(PEG<1.5) | **建仓** — 但别期望10倍 |
| **阶段2** (1.7-2.3) | 只在大幅回调时(EV/EBITDA<5年均值*0.7) | **观察** — 等回调 |
| **阶段2.5** (>2.3) | — | **回避** — 上行空间有限 |

**验证**:

| 公司/时点 | OPM位置 | 认知度 | 提价加速 | 回购强度 | 监管 | 综合阶段 | 实际结果 |
|----------|---------|--------|---------|---------|------|---------|---------|
| FICO 2014 | 15% | 0.80x | 0.8x | 131% | 1 | **1.0** | 68x回报 |
| MSCI 2026 | 71% | 0.87x | 1.1x | 161% | 1 | **1.7** | 待观察 |
| FICO 2025 | 80% | 1.4x+ | 2.0x | 184% | 7 | **2.3** | 已充分定价 |

### 3.4 定价权类型矩阵 (v0.6新增)

> 不同类型的定价权 → 不同的投资逻辑。不能用同一套框架。

```
类型1: 未行使定价权 (Unexercised Pricing Power)
  特征: OPM远低于天花板, 可以大幅提价
  代表: FICO 2014 (OPM 32% → 天花板65%+)
  投资逻辑: 利润弹性 = 收入增长被OPM扩张放大 → 用EPS CAGR算PEG
  阶段判断: 适用3.3阶段系统

类型2: 受限定价权 (Constrained Pricing Power)
  特征: 嵌入深+市场地位强, 但定价被监管/政治约束
  代表: Visa/MA (OPM 60-66%, 受EU cap + Durbin约束)
  投资逻辑: 增长 ≈ 全球交易量增长 + 新市场渗透 → 用Revenue CAGR算PEG
  阶段判断: 不适用3.3 — OPM已在天花板, 定价权不是增长引擎

类型3: 已释放定价权 (Exercised Pricing Power)
  特征: OPM已接近天花板, 定价权已被市场认知
  代表: FICO 2025 (OPM 65%+, 监管关注度升高)
  投资逻辑: 利润弹性耗尽 → 增长回归Revenue CAGR → 高估值=高风险
  阶段判断: 3.3阶段2.3+

类型4: 滥用定价权 (Abused Pricing Power)
  特征: 激进提价引发政治/法律反弹
  代表: Valeant, 可能的未来FICO
  投资逻辑: 红旗 → FP4=0 → 排除
```

## 第四层: 三重增长引擎分解 (沿用v0.4)

```
EPS增长 = 收入增长 * OPM杠杆 * 回购效应

分析每家公司时必须分解:
  引擎1: Revenue CAGR → 来源(量增/价增/新市场)
  引擎2: OPM趋势 → 在扩张/稳定/趋平？距天花板多远？
  引擎3: 回购 → 年回购/FCF比例，股数缩减速度

三引擎同时发力 + 低估值 = 利润弹性型复利机器

v0.6补充: Visa型公司只有引擎1(量增)在发力
  引擎2(OPM): 已在天花板(66%), 无空间
  引擎3(回购): 活跃但非决定性
  → 增长上限 ≈ 全球支付数字化增速(~8-10%)
  → 对比FICO: 三引擎发力时EPS CAGR可达23%
```

## 第五层: 护城河深度量化体系 (v0.5建立, v0.6扩展)

### 5.1 护城河的五种底层机制

```
机制1: 制度嵌入 (Institutional Embedding)
  法律/监管/标准强制使用 → 替换需要修法或改制度
  代表: FICO(信贷法规), MCO(SEC NRSRO), MSCI(被动投资标准), Visa(全球支付标准)

机制2: 网络效应 (Network Effects)
  用户越多越有价值 → 替换需要所有人同时迁移
  代表: 微信(社交图谱), Meta(广告双边), Google(搜索+广告), Visa(40亿卡×1亿商户)

机制3: 生态锁定 (Ecosystem Lock-in)
  多层技术栈/工具/习惯叠加 → 替换需要重写代码+重新学习
  代表: NVIDIA(CUDA 7层生态), Apple(iOS生态), Visa(VisaNet全栈)

机制4: 数据飞轮 (Data Flywheel)
  更多使用→更好产品→更多使用 → 替换需要同等数据量
  代表: Google(20年搜索数据), Meta(30亿用户行为数据)

机制5: 规模经济 (Scale Economics)
  成本随规模下降 → 替换需要同等投资规模
  代表: 台积电(3nm晶圆厂$200亿+), NVIDIA(R&D $120亿/年), Visa(每笔交易边际成本趋零)
```

**护城河深度 = 拥有的机制数量 x 每种机制的强度。机制可以叠加。**

### 5.2 五维度量化评分 (每维度0-5分, 总分25)

| 维度 | 0分 | 1分 | 2分 | 3分 | 4分 | 5分 |
|------|-----|-----|-----|-----|-----|-----|
| **制度嵌入** | 无 | 文化习惯 | 行业惯例 | 合同绑定 | 行业标准 | 法律强制 |
| **网络效应** | 无 | 内容网络 | 单边规模 | 交易网络 | 身份网络 | 身份+交易+标准 |
| **生态锁定** | 无 | 1层(单产品) | 2-3层 | 4-5层 | 6-7层 | 7层+开发者生态 |
| **数据飞轮** | 无 | 有数据但不排他 | 数据改善产品 | 数据壁垒明显 | 20年+独占数据 | 数据+制度双锁 |
| **规模经济** | 无 | 成本优势<10% | 10-30%优势 | R&D壁垒 | 产能壁垒 | 成本+产能+R&D |

### 5.3 网络效应子分类 (精细化评分)

```
类型A: 身份网络 (Identity Network) — 最强, 5分
  你的真实身份+关系链在这里, 迁移需要所有人同时行动
  微信, WhatsApp, LinkedIn
  历史上只被范式替代打破(PC→移动: MSN→微信)

类型B: 内容网络 (Content Network) — 中等, 1-2分
  好内容在这里, 但不需要你的朋友也在
  TikTok, YouTube, Twitter/X
  可被新内容格式替代(Vine→TikTok, Blog→Twitter)

类型C: 交易网络 (Transaction Network) — 强, 3-4分
  买家和卖家都在这里, 双边市场
  淘宝, Amazon Marketplace, Uber
  很少被替代, 但可以被垂直化蚕食

类型D: 标准网络 (Standard Network) — 最持久, 5分
  行业标准/规则嵌入, 迁移需要改变整个行业的规则
  FICO, MSCI, SWIFT, Windows(早期), Visa(支付标准)
  几乎不被替代

v0.6新增:

  底层管道型双边网络, 所有参与者都在上面运行
  Visa/MA(卡网络), SWIFT(银行间通信), AWS(云基础设施)
```

### 5.4 生态锁定层数分析 (以NVIDIA为例)

```
NVIDIA CUDA生态 = 7层叠加:

  第7层: AI框架       PyTorch/TensorFlow默认CUDA后端
  第6层: 应用库       cuDNN(深度学习), cuBLAS(线性代数), TensorRT
  第5层: 中间件       NCCL(多GPU通信), Triton(推理服务)
  第4层: 编译器       nvcc, PTX中间代码
  第3层: 驱动/运行时  CUDA Runtime, Driver API
  第2层: 硬件架构     SM, Tensor Core, NVLink
  第1层: 芯片制造     台积电代工

  AMD ROCm要替代CUDA = 需同时复制第2-7层
  每层需要数年, 且层与层之间有依赖关系

  CUDA开发者400万+ vs ROCm <10万 = 40:1的生态差距
```

**生态锁定的特殊机制: 硬件→软件→硬件闭环**

```
传统硬件: 卖硬件 → 下一代重新竞争 → 护城河浅
传统软件: 卖软件 → 转换成本锁定 → 护城河深
NVIDIA:   卖GPU → 用户写CUDA代码 → 代码不兼容AMD → 必须继续买GPU
         (硬件是入口)     (软件是锁)         (反向锁定硬件购买)

打破需要三个条件同时满足:
  1. 竞品硬件性能足够 (正在发生: AMD MI300X)
  2. 软件兼容层完善 (正在发生: 但bug多)
  3. 开发者愿意迁移 (还没发生: "能跑就不动")
```

### 5.6 攻击面分析 — v0.6: 市场力量 vs 国家力量

**护城河耐久性 = 深度 - 攻击面可行性**

> **v0.6升级**: 攻击面不仅看"几个攻击点"和"攻击成本"，还必须区分攻击力量的来源。

```
攻击力量分类:

市场力量 (Market Force)
  - 受商业逻辑约束: 需要盈利、需要规模、受时间限制
  - 可被吸收: 攻击者可能变成生态内参与者(Stripe→Visa的分销商)
  - 代表: Stripe, BNPL提供商, Apple Pay, AMD ROCm
  - 防御: 吸收式防御 + 技术迭代

国家力量 (State Force)
  - 不受成本约束: 政府可补贴零费率、强制推广
  - 无法被吸收: 政府不会成为你的分销商
  - 代表: UPI(印度), PIX(巴西), 数字人民币
  - 防御: 只能靠全球分散化(单国损失可控)

范式力量 (Paradigm Force)
  - 技术范式根本转变: 整个行业逻辑重写
  - 不确定性极高: 可能永远不发生, 也可能突然发生
  - 代表: 区块链/DeFi, AI搜索替代Google, 量子计算
  - 防御: 参与新范式(Google做AI搜索, Visa做区块链结算)
```

**防御模式分类 (v0.6新增)**:

```
模式1: 筑墙防御 (Wall Defense)
  策略: 加高进入壁垒, 让竞争者无法进入
  代表: FICO(法律壁垒), 台积电(资本壁垒)
  优势: 清晰、可量化
  劣势: 如果墙被绕过(而非翻过), 则失效
  → 适合: 制度嵌入型护城河

模式2: 吸收式防御 (Absorptive Defense) — v0.6新概念
  策略: 让攻击者在你的基础设施上运行, 把竞争者变成分销商
  代表: Visa(Stripe/BNPL/Apple Pay都跑在Visa rails上)
  优势: 比筑墙更弹性, 攻击者越多反而网络效应越强
  劣势: 价值链份额被压缩(Visa从3%→可能2%→1%), 缓慢侵蚀
  → 适合: 基础设施型网络护城河
  → 失效条件: 国家力量绕过(UPI/PIX不跑在Visa上)

模式3: 迭代防御 (Iteration Defense)
  策略: 持续技术领先, 让竞争者永远追赶
  代表: NVIDIA(每代GPU领先1-2年), Google(AI投入>$100B)
  优势: 动态护城河, 不依赖静态壁垒
  劣势: 需要持续投入, 一旦停止迭代就被追上
  → 适合: 技术驱动型护城河
```

### 5.8 核心洞察: 深度 vs 耐久性矩阵 (v0.6更新)

```
              耐久性低          耐久性高
            (可被攻破)        (几乎永久)
深度高    │  Google(18)  │              │  ← 深但脆弱
(>15)     │  微信(17)    │  Visa(21)    │  ← v0.6: Visa最深但受限
          │  Meta(15)    │  NVIDIA(16)  │
          ├──────────────┼──────────────┤
深度低    │              │  FICO(12)    │  ← 浅但永固
(<15)     │              │  MCO(13)     │
          │              │  MSCI(14)    │
          └──────────────┴──────────────┘

v0.6投资含义更新:
  市场通常为"深度"付费(高P/E) → Google/NVIDIA/Visa估值高
  市场低估"耐久性" → FICO 2014年P/E只有20x(S级耐久性被忽视)

  v0.6新增洞察:
  - 深度最高(Visa 21) ≠ 投资回报最高
    → Visa 10年回报~8x(好), FICO 10年回报68x(惊人)
    → 因为FICO有未行使定价权(利润弹性), Visa没有(受限定价权)
  - 选股框架应该:
    1. 寻找"深度中等但耐久性极高"(右下角) → 最容易被低估
    2. 在右下角中优先找"未行使定价权"型 → 利润弹性=超额回报来源
    3. 警惕"深度高但定价权受限"(右上角Visa型) → 好公司但非超额回报来源
    4. 避开"深度高但耐久性低"(左上角) → 最容易被高估
```

### 支付网络型: 特征 + 投资注意事项 (v0.6新增)

```
增长特征:
  1. 基础设施级双边网络(卡×商户)
  2. 交易量驱动(非定价驱动)
  3. OPM极高但已在天花板(60-66%)
  4. 边际成本趋零 + 经常性交易流
  5. 全球渗透率仍有空间(新兴市场现金→数字化)

与算法垄断型的关键区别:
  算法垄断型: 嵌入深+定价自由 → 利润弹性 → EPS CAGR >> Revenue CAGR
  支付网络型: 嵌入深+定价受限 → 无利润弹性 → EPS CAGR ≈ Revenue CAGR

投资注意事项:
  - 好公司但非超额回报来源(Visa 10年~8x vs FICO 10年68x)
  - 适合稳健配置, 不适合寻找10倍股
  - 主要风险: 国家力量(UPI/PIX), 不是市场竞争
  - 吸收式防御让市场攻击者几乎无威胁, 但允许价值链份额缓慢压缩
```

### 算法垄断型: 增长特征 + 安全性双重检查

```
增长特征 (必须全部满足):
  1. 零边际成本
  2. 制度嵌入 (监管/标准强制使用)
  3. 定价权期权
  4. OPM天花板极高 (理论60-70%)
  5. 利润弹性极强

安全性检查 (v0.5新增, 必须全部满足):
  6. FP1>=2 (定价权来自法律/监管/行业标准, 且定价自由)
  7. FP2: 客户价值/价格比 <1%
  8. FP3>=1 (无已商业化的技术替代品)
  9. 底层市场增长或稳定 (非结构性萎缩)

  通过1-5但不通过6-9 = 类FICO陷阱 (WU/IBM就是这类)
  通过1-5但定价受限 = 支付网络型(Visa), 不是算法垄断型
```

## 实筛校准发现 (v0.5附录, 沿用)

> 首次用v0.4框架筛选9家候选公司, 发现3个硬指标需要校准

### 校准1: Q1 CapEx/Rev阈值对"增长性CapEx"公司失效

```
问题: CPRT CapEx/Rev=12% → Q1不通过 → 被排除
但: CPRT的CapEx是买地扩产(增长投资), 不是维护性支出
    净现金、零借贷、ROIC 15%, P/E 28x(全池最低)

修正: Q1判断时区分增长性CapEx vs 维护性CapEx
  - 维护性CapEx/Rev < 5% → 通过(核心标准不变)
  - 增长性CapEx导致总比例>5%但<15%, 且有对应资产增值 → 可豁免
  - 判断方法: CapEx中"买地/建厂/扩产"占比>50% + FCF/NI仍>70% → 豁免
```

### 校准2: Q3 Revenue CAGR被周期性高基数扭曲

```
问题: MCO 4Y Rev CAGR=5.6% → Q3不通过
但: 2021年是全球债券发行创纪录年(低利率驱动), 高基数压低CAGR
    正常化(2022-2025) Rev CAGR ~12%, 远超8%门槛

修正: Q3应看通过完整商业周期的CAGR
  - 优先用>=5年CAGR(覆盖一个完整周期)
  - 如果起点或终点是明显的周期极端值, 使用正常化CAGR
  - 判断方法: 如果单年数据导致CAGR偏差>30%, 检查是否有周期因素
```

### 校准3: 利润弹性(T5)实战验证成功

```
实筛确认T5有效区分了两类公司:
  有弹性: FICO(1.7x), CTAS(1.5x), IDXX(1.5x) — 三引擎发力
  无弹性: ROL(0.9x), CPRT(0.9x) — 单引擎(纯收入)

同样P/E 50x, 有弹性的实际"更便宜"(EPS增速更快)
T5是v0.4新增信号, 首次实战即验证有效, 保持不变
```

### 校准4: 当前市场估值现实

```
9家候选无一处于"好价格"区间(FCF Yield>5%, PEG<1.5)
最便宜: CPRT(PEG 2.2), DCI(FCF Yield 4.0%)
最贵: ROL(PEG 5.1), FICO(PEG 3.0)

框架此刻的最大价值 = 等待, 不是买入
好公司+好价格的窗口需要: 大盘回调20%+ 或 公司特定利空
```
