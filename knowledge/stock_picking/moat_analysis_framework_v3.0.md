| 旧术语 | 新术语 | 原因 |
|--------|--------|------|
| 垄断性排行榜 | 护城河排行榜/CQI | "垄断"太窄(COST/PG不是垄断但有强护城河) |

## 二、C1制度嵌入五层结构 (FICO报告核心创新)

### 2.1 五层模型

C1不再是一个0-5的单一打分, 而是分解为5个嵌入层:

| 层 | 名称 | 含义 | 评估问题 | 替换时间 |
|----|------|------|---------|---------|
| **L1** | 基础设施嵌入 | 产品嵌入技术基础设施(API/接口/系统) | 客户系统中有多少组件依赖? | 1-2年 |
| **L2** | 监管嵌入 | 监管法规/合规要求中直接引用 | 有无法规条文点名要求使用? | 3-5年 |
| **L3** | 合约嵌入 | 嵌入长期合同/证券化文件/行业协议 | 存量合约中引用的深度? | 5-10年 |
| **L4** | 运营嵌入 | 嵌入客户的日常运营/风控/决策流程 | 替换需重新校准多少年积累? | 5-15年 |
| **L5** | 认知嵌入 | 嵌入消费者/行业的心智模型 | 品牌名=品类名? (如"FICO分"=信用) | 10-20年 |

### 2.2 评分方法

```
C1 = Σ(Layer_i × Weight_i)  i=1..5

默认权重:
L1=15%, L2=25%, L3=20%, L4=25%, L5=15%

行业调整:
- 金融/信息基础设施: L2权重↑至30%, L1↓至10% (监管是核心嵌入点)
- 消费品: L5权重↑至30%, L2↓至10% (品牌认知是核心)
- 半导体设备: L4权重↑至30%, L2↓至15% (运营嵌入是核心)
```

### 2.3 核心嵌入层判断 (关键增量)

**每家公司必须识别其"核心嵌入层" — 最核心的嵌入点:**

| 公司 | 核心嵌入层 | 被突破风险 | C1趋势 |
|------|-----------|----------|--------|
| FICO | L2监管+L4运营 | FHFA打开L2(中) | ↓衰减中 |
| S&P Global | L2监管+L3合约 | Basel III锁定L2(极低) | →稳定 |
| ASML | L4运营+L6物理(≈C6) | 无替代技术(极低) | →稳定 |
| MSFT | L4运营+L3合约 | 企业IT替换成本极高(低) | →稳定 |
| Visa | L1基础设施+L5认知 | 监管限制费率(中) | ↓微弱衰减 |

### 2.4 C1应用范围

**C1五层分析适用条件**: C1≥3.0的公司 (约8-10家)
**C1<3.0**: 仍用单一C1评分即可 (制度嵌入不是护城河核心来源)

### 2.5 跨公司C1五层对比 (FICO报告原始数据)

| 公司 | L1基础设施 | L2监管 | L3合约 | L4运营 | L5认知 | C1总分 |
|------|:---------:|:-----:|:-----:|:-----:|:-----:|:------:|
| FICO | 4.5 | 4.0 | 4.5 | 5.0 | 4.0 | **4.5** |

## 三、B4定价权双维拆分

### 3.1 问题发现

FICO 2014: B4=5.0 (强度5.0 × 持久性5.0)
FICO 2026: B4=4.5 (强度5.0 × 持久性3.5)

**单一B4分数掩盖了"强度不变但持久性衰减"这个关键信号。**

### 3.2 新框架

| 维度 | 衡量 | 评估问题 |
|------|------|---------|
| **B4a 定价权强度** | 当前提价多少不丢客户? | 过去3年提价幅度 vs 客户流失率 |
| **B4b 定价权持久性** | 定价权还能维持多久? | 政治/竞争/监管压力趋势 |

```
B4 = (B4a + B4b) / 2  (各0-5分)

报表中展示: B4: X.X (强度X.X / 持久性X.X)
```

### 3.3 定价权阶段模型 v1.0 (可迁移框架)

| 阶段 | 名称 | OPM特征 | 市场反应 |
|------|------|---------|---------|
| 1.0 | 休眠 | 定价权未释放, OPM低位 | 无关注 |
| 1.5 | 觉醒 | 首次实质提价 | 轻微关注 |
| 2.0 | 加速 | 大幅提价, OPM快速扩张 | 分析师追踪 |
| 2.5 | 激进释放 | 单年+30%+提价 | 监管/诉讼介入 |
| 3.0 | 天花板 | 提价导致客户实际流失 | 竞争替代出现 |

**5个量化指标**:
1. OPM位置比 (当前OPM / 理论天花板)
2. 市场认知度 (提价是否被广泛讨论)
3. 提价加速度 (近3年提价CAGR)
4. 监管热度 (诉讼/调查/立法数量)
5. 竞争替代进展 (替代品份额变化)

**适用范围**: B4≥3.5的公司。跨行业定位:
- S&P Global: Stage 1.0-1.5 (定价权几乎未释放)
- MSCI: Stage 1.5-2.0
- ASML: Stage 2.0 (EUV价格持续上升)
- FICO: Stage 2.3 (接近天花板)

### 3.4 C1×B4反身性循环 (CI-01迁移)

```
高C1保护高B4 → B4释放 → OPM扩张 → 政治反弹 → C1侵蚀 → B4衰减

关键洞见: 制度垄断最危险的时刻是定价权释放到足以引起政治注意的时候
```

**适用条件**: C1≥3.0 且 B4a≥4.0 的公司 (FICO, S&P Global, ASML, 潜在的Visa)

## 四、护城河半衰期分析

### 4.1 历史先例库

| 公司/标准 | 制度类型 | 持续时间 | 如何被替换 |
|----------|---------|:-------:|----------|
| AT&T | 电话垄断 | 71年 | 反垄断拆分 |
| SWIFT | 支付标准 | 53+年 | 尚未被替代 |
| S&P/Moody's | 信用评级 | 51+年 | 2008后反而加强 |
| LIBOR | 利率基准 | ~50年 | 强制SOFR替换(历时9年) |
| Bloomberg Terminal | 金融数据 | 45+年 | 尚未被替代 |
| FICO Score | 信用评分 | 37+年 | 正在被VantageScore侵蚀 |

### 4.2 半衰期对估值的影响

| 假设半衰期 | WACC调整 | 估值影响 |
|-----------|---------|---------|
| 20+年 | 基准WACC | 基准 |
| 15年 | WACC +1% | -12%至-15% |
| 10年 | WACC +2% | -22%至-27% |
| 7年 | WACC +3% | -30%至-38% |

**关键洞见**: 半衰期同时压缩分子(未来现金流↓)和分母(折现率↑) — **双重打击**。

### 4.3 适用场景

制度嵌入型公司(C1≥3.5)在Tier 3报告Phase 3中应执行半衰期分析。包括:
- 识别最相似的历史先例
- 估算当前半衰期(年)
- 计算半衰期对估值的影响
- 纳入情景分析(不同半衰期假设)

## 五、护城河趋势仪表盘 (Moat Trend Dashboard)

### 5.1 设计原理

静态评分回答"护城河有多深"。趋势仪表盘回答"护城河在变深还是变浅"。

**FICO的核心教训**: 2018-2022年护城河实际在**加强**(定价权释放), 2022年是拐点, 之后开始衰减。单看当前C1=4.5看不出这个动态。

### 5.2 仪表盘模板

```markdown
### 护城河趋势仪表盘 — {公司}

| 维度 | 2018 | 2020 | 2022 | 2024 | 2026E | 趋势 | 驱动因素 |
|------|:----:|:----:|:----:|:----:|:-----:|:----:|---------|
| C1制度嵌入 | | | | | | | |
| C2网络效应 | | | | | | | |
| C3生态锁定 | | | | | | | |
| C4数据飞轮 | | | | | | | |
| C5规模经济 | | | | | | | |
| C6物理壁垒 | | | | | | | |
| **综合** | | | | | | | |
| B4定价权 | | | | | | | |

趋势符号 (v5.0细化):
↑ 结构性加宽 — 行业结构/物理定律在不可逆地加深护城河(管理层无关)
↗ 执行性强化 — 公司主动通过份额/生态/产品加深护城河(依赖执行力)
→ 稳定 — 护城河牢固，无重大变化
↘ 结构性收窄 — 监管/替代品/竞争在结构性侵蚀(管理层难逆转)
↓ 主动侵蚀 — 具体竞争对手/替代品在主动打开护城河
⇊ 全面崩塌 — 护城河多线同时蒸发

↑与↗的核心区别: ↑的驱动力与管理层无关(换CEO趋势不变), ↗依赖管理层执行(执行力下降则逆转)

三种趋势情景:
- 情景A — 再强化 (X%): [描述条件]
- 情景B — 缓慢侵蚀 (X%, 基准): [描述条件]
- 情景C — 加速崩塌 (X%): [描述条件]
```

### 5.3 执行时机

| 场景 | 是否执行趋势仪表盘 | 原因 |
|------|:---------------:|------|
| Tier 3深度报告 | **必须** | 有足够数据支撑时间序列 |
| CQI季度更新 | 选择性 | 只更新有重大变化的公司 |
| Tier 2标准分析 | 不需要 | 深度不够支撑趋势判断 |

### 5.4 核心洞见 (FICO报告原创)

1. **强化是渐进的(+0.1-0.2/年), 衰减可能非线性(慢然后突然)** — 类似Hemingway的"how did you go bankrupt"
2. **拐点识别比当前分数更重要** — FICO在C1=4.5时拐点已出现, 而不是等到C1=3.0
3. **政治/监管是C1变化的主要驱动力, 不是竞争** — FHFA打开VantageScore不是因为VS更好, 而是政治压力

## 七、CPRT报告准备 — 框架预适配

### 7.1 CPRT的预期C1五层分析

CPRT不是制度垄断(C1在v2.0=2.0), 但其护城河来源非常独特:

| 层 | CPRT可能评分 | 假说 |
|----|:----------:|------|
| L1 | 3.0 | 保险公司系统集成(理赔→拍卖自动化) |
| L2 | 2.0 | 非监管强制, 但保险业采购流程准制度化 |
| L3 | 3.0 | 保险合同中指定Copart作为处置渠道 |
| L4 | 4.0 | 保险理赔流程20+年围绕Copart设计 |
| L5 | 2.0 | 消费者不太了解Copart(B2B为主) |

### 7.2 CPRT的核心护城河源 — 需要验证的假说

CPRT的护城河类型和FICO完全不同:
- **FICO**: 制度嵌入(C1) → 定价权(B4) → OPM扩张
- **CPRT**: 物理资产(C6=土地银行) + 网络效应(C2=双边拍卖) + 反周期(D1=1.10)

CPRT报告应重点验证:
1. **土地银行不可复制性**: 200+个场地, 总面积多少? 城市扩张是否挤压新场地?
2. **双边拍卖网络效应强度**: 买家数量 vs 卖家数量 → 流动性优势可量化?
3. **反周期机制深度**: 衰退→更多total loss→更多拍卖量, 历史数据验证?
4. **IAA竞争威胁**: RB Global收购IAA后整合效果? 市场份额变化?
5. **电动车/自动驾驶对total loss rate的长期影响**

### 7.3 CPRT应适用的新框架

| 框架 | 适用? | 原因 |
|------|:----:|------|
| C1五层结构 | **否** | C1<3.0, 不需要五层分解 |
| B4双维拆分 | **是** | B4需评估提价强度 vs 持久性 |
| 护城河趋势仪表盘 | **是** | 作为#1公司, 趋势分析极其重要 |
| 半衰期分析 | **否** | 非制度嵌入型, 不适用 |
| 定价权阶段模型 | **条件** | 需先确认CPRT的B4是否≥3.5 |

### 7.4 CPRT报告的特殊关注点

1. **D1=1.10的验证**: CPRT是27家中唯一反周期公司, 需要2008/2020/2022的数据严格验证
2. **土地银行估值**: C6物理壁垒的量化 — 土地市值 vs 重置成本
3. **双边市场动态**: C2网络效应的量化 — 买家数/卖家数/成交率趋势
4. **CQI=82的合理性检验**: 作为#1, 需要最严格的红队审查
