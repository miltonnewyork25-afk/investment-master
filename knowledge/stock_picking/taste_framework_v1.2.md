# 选股品味框架 v1.2

> **起源**: 10成功案例(HEI/DHR/CSU/GE/FICO/Visa/IDXX/ROL/CTAS/CPRT) + 1平庸案例(FAST) + 1隐藏品质案例(IHG) + 5失败案例 + MSCI对标
> **v1.2核心升级**: IHG"真实OPM 65%但周期性拖累回报至~4x" + 收入纯度概念 + 周期性税收框架 + 特许权品牌复利路径(Path F)
> **触发**: IHG品质5/7(周期性导致收入下降4次+流动比率<1), 品味20.5/28, 回报~4x(含股息)。FICO级真实OPM(~65%)却产出FAST级回报(~4x)。核心教训: 单位经济优越 ≠ 投资回报优越, 周期性是最强回报杀手。

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.3-v1.1: (沿用)
v1.2: **报告OPM会骗人, 真实OPM才是经济实质。IHG报告OPM 23%, 但收入中~65%是系统基金过手收入(零利润率); 剥离后真实费用OPM高达~65%, 与FICO同级。然而11年回报仅~4x(含股息), 与品味最低的FAST(~5x)相当。原因: 周期性。2020亏损$260M, 2020-2021零回购零股息, 复利时钟被重置2年。框架新规则: 真实OPM是必要条件但非充分条件, 必须叠加"非周期性需求"才能产出超额回报。FICO(非周期×垄断×OPM 68%)=68x; IHG(周期×寡头×真实OPM 65%)=4x。差距=周期性税。**

## 收入纯度 (v1.2核心框架升级)

```
定义: 收入纯度 = 费用收入(有利润率的收入) / 总报告收入

IHG收入构成:
  费用收入: ~$1,850M (特许费+管理费+忠诚度费) — 利润率~65%
  系统基金: ~$3,340M (代收代付: 营销/技术/忠诚度) — 利润率~0%
  总报告收入: $5,189M
  收入纯度: ~35.6%

影响:
  报告OPM: $1,198M / $5,189M = 23.1% → 看起来像ROL/FAST级别
  真实OPM: $1,198M / $1,850M = 64.8% → 实际是FICO/Visa级别!

  误差: 报告OPM低估真实经济42个百分点

框架规则 (v1.2):
  当收入纯度<50%时:
  ① 计算"真实OPM" = OI / 费用收入
  ② T5a使用费用收入计算, 不使用总收入
  ③ Q3(收入增长)标注"含过手收入膨胀"
  ④ 品味判断以真实OPM为基础

受影响的公司类型:
  酒店特许商: IHG(35%), MAR(~40%), HLT(~40%), WH(~45%)
  餐饮特许商: MCD(~70%), YUM(~65%) — 纯度更高
  地产管理: 部分REIT
  平台GMV报告: 部分电商

收入纯度光谱:
  >90%: FICO, FAST, CTAS — 报告即真实
  70-90%: MCD, YUM — 特许为主+少量自营
  40-60%: MAR, HLT, WH — 特许+管理+系统基金
  <40%: IHG — 系统基金占比最高, 报告OPM失真最严重

框架影响: 高收入纯度(>70%)的公司, 报告数据可直接使用
          低收入纯度(<50%)的公司, 必须做"真实OPM"还原
```

## 周期性税收 (v1.2核心框架升级)

```
定义: 周期性税 = 因需求波动导致的投资回报系统性损失

IHG证据:
  真实OPM ~65% (与FICO的68%相当)
  但11Y总回报 ~4x (vs FICO的~70x)
  差距: ~17倍 → 大部分来自周期性税

三重税收机制:

  ① 复利中断 (最直接)
     2020: 净亏损$260M, OCF仅$137M
     2020-2021: 零回购, 零股息
     → 复利时钟暂停2年
     → 11年投资中有2年零产出 = 有效复利期缩短18%

  ② 倍数压缩 (最持久)
     IHG: 17x P/E (市场认为收益不稳定)
     FICO: 60x+ P/E (市场认为收益像公用事业)
     → 相同EPS增长, 非周期公司享受3-4x更高倍数
     → 这不是"市场错误", 是对波动性的合理定价

  ③ 资本保全优先 (最隐蔽)
     危机时: 被迫举债保全(2020年净举债$613M)
     恢复初期: 先还债, 后回报股东(2021年仍零分配)
     → 资本配置从"进攻"切换到"防守"→"修复"→"进攻"
     → FICO/FAST: 即使2020也保持分红/回购(非周期优势)

周期性回报影响量化:
  假设IHG的真实OPM(65%)在非周期场景下:
  → P/E应为40-50x (介于FICO和Visa之间)
  → 当前P/E 17x → 周期性折价 ~60%
  → 加上复利中断: 总回报损失 ~75-80%

非周期性谱系 (从框架案例):
  强非周期: FICO(信用评分), MSCI(指数) → 60x+
  弱非周期: CTAS(制服), FAST(紧固件) → 14x, 5x
  反周期: CPRT(事故车) → 10x
  弱周期: ROL(害虫防治) → 7x
  强周期: IHG(酒店/旅游) → 4x

框架规则 (v1.2):
  周期性评估是品味判断的前置条件:
  ① 非周期: 品味得分 → 回报 (正常映射)
  ② 弱周期: 品味得分 → 回报 × 0.7-0.8 (温和折扣)
  ③ 强周期: 品味得分 → 回报 × 0.3-0.5 (严重折扣)
  → IHG品味20.5/28 × 周期性折扣 ≈ FAST(19/28)的回报水平

  至关重要的教训:
  真实OPM 65% + 强周期 ≈ 真实OPM 20% + 非周期
  → 周期性消灭了OPM优势
  → 选股时, "非周期"比"高OPM"更重要
```

## 负权益复利者 (v1.2新概念)

```
定义: 因累计资本返还超过累计利润, 导致账面权益为负的公司

IHG: 股东权益 = -$2,741M
  原因: 11年返还$8,504M(股息$5,343M+回购$3,161M) > 累计利润~$5,300M
  差额通过举债弥补(净债务从$1,533M→$3,490M)

传统指标失效:
  ROE = -27.6% → 无意义(分母为负)
  P/B = -8.3x → 无意义
  → 必须使用EV基指标: EV/EBITDA(20.8x), EV/FCF(29.2x), FCF Yield(4.0%)

判断"好的负权益" vs "坏的负权益":
  好的(IHG/MCD/DPZ):
    → 累计回购+股息 > 累计利润 → 返还太多, 权益转负
    → 底层业务FCF强劲(FCF/NI>100%)
    → 债务可控(Net Debt/EBITDA<3x)

  坏的(WeWork等):
    → 累计亏损 > 累计融资 → 亏钱亏到权益为负
    → FCF持续为负
    → 无法偿还债务

框架规则: 遇到负权益公司, 先判断是"返还过多"还是"亏损过多"
  → 前者可能是优秀特许商, 后者回避
```

```

路径B: 资本效率型 (ROL) — 低CapEx+并购循环 → 7x

路径D: 网络效应+物理壁垒型 (CPRT) — OPM先扩后稳+Rev增长 → 10x
路径E: 股息复利型 (FAST) — OPM平坦+高派息 → 3.4x(+股息≈5x总)
路径F: 特许权品牌型 (IHG) — 真实OPM极高+周期性约束 → ~4x(含股息)

路径F特征:
  真实OPM: 55-70% (FICO级, 被报告OPM 20-25%掩盖)
  收入纯度: <50% (系统基金/过手收入膨胀分母)
  CapEx/Rev: <1% (极致资产轻, 加盟商承担实体投资)
  资本配置: 高回购+高股息(总返还>FCF, 用杠杆弥补)
  周期性: 强周期(旅游/酒店/消费)
  回报构成: 客房增长3-4% + RevPAR增长2-3% + 回购2-3% + 股息2%
  总年化: ~12-14% → 11Y约4-5x
  局限: 周期性中断+倍数压缩, 与路径A相同OPM但回报差17x

路径F vs 路径A对比(核心):
  路径A(FICO): 真实OPM 68% × 非周期 × 垄断 = 68x
  路径F(IHG): 真实OPM 65% × 强周期 × 寡头 = 4x

  差距分解:
  ① 周期性: 复利中断+倍数压缩 → 回报×0.3
  ② 竞争: 5大品牌(MAR/HLT/IHG/H/Accor) vs FICO垄断 → 回报×0.5
  ③ 定价权: 受竞争限制 vs FICO自由定价 → 回报×0.8
  总折扣: 0.3 × 0.5 × 0.8 ≈ 0.12 → 68x × 0.12 ≈ 8x (实际~4x, 还有其他折扣)

路径F vs 路径E对比:
  同为~4-5x总回报, 但来源不同:
  路径E(FAST): 非周期 + 低OPM(20%) + 高股息 → 稳定的平庸
  路径F(IHG): 强周期 + 高真实OPM(65%) + 高回购 → 波动的平庸
  → 结果相同, 但风险特征完全不同
  → FAST: 像存款(稳定低回报)
  → IHG: 像杠杆债券(波动, 下行风险更大)
```
