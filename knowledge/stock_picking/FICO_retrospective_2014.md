# FICO (Fair Isaac) 回溯分析: 站在2014年的视角

> **目的**: 假设你是2014年底的投资者，只有当时可获取的信息。
> **结果验证**: 2014→2025股价约68倍 (CAGR ~35%)
> **框架价值**: 验证v0.3"定价权增长"这一全新增长机制

## 二、2014年的核心竞争力

### 2.1 制度化垄断 (护城河1号)

FICO Score不仅是"好产品"，而是被**制度性嵌入**了美国信贷基础设施:

1. **监管强制**: Fannie Mae和Freddie Mac（美国房贷75%份额）强制要求使用FICO Score
2. **征信局依赖**: Equifax/Experian/TransUnion都必须向FICO付版税
3. **行业标准**: 90%以上贷方使用FICO，所有风控模型基于FICO校准
4. **30年数据**: 覆盖完整信贷周期的回测数据，任何竞品无法复制
5. **消费者品牌**: "FICO分"已成为信用评分的代名词

**转换成本**: 字面意义上的无穷大——要替代FICO需要修改联邦法规+重建所有银行风控模型+说服所有消费者。

### 2.2 未兑现的定价权 (护城河2号 — 最关键)

2014年的核心洞察:

```
价值/价格比:
  FICO评分对一笔$300K房贷的价值: 关键决策输入 → 价值>$100
  FICO每次评分收取的版税: $0.30-0.50
  价值/价格比: >200:1

  → 25年几乎没涨过价
  → 这是一个巨大的、未兑现的定价权期权
```

Will Lansing (2012年上任的CEO) 在FY2014电话会议中开始提到"Scores业务的货币化机会"——这是即将行使定价权的信号。

### 2.3 三重增长引擎 (护城河3号)

```
EPS增长 = 收入增长 × OPM扩张 × 股数缩减
         ~8%/年      潜力巨大    ~3-5%/年
                   (20%→46%+)

→ 复合EPS增长潜力: 15-25%
→ 但市场按"8%收入增长"给P/E 20x
```

## 四、从FICO提取的品味原则

### 原则1: 定价权是最强的有机增长引擎

不同于安装基数增长(GE/IDXX)或路径密度(ROL)，FICO的增长来自**同一个产品卖更贵**。

关键特征:
- 收入增长可能看起来"平庸"(8%)
- 但OPM扩张可以持续10年+(20%→46%)
- 利润增长率 = 收入增长率的2-3倍
- **市场系统性低估"定价权型"公司的利润弹性**

### 原则2: "未兑现定价权"是一个投资期权

定价权的两个阶段:
- **阶段1(潜伏期)**: 定价权存在但未行使 → 估值=当前利润×平凡倍数 → **最佳买点**
- **阶段2(释放期)**: 年年提价+OPM扩张 → 估值=增长利润×溢价倍数

**2014年的FICO处于阶段1→阶段2的转折点。** 识别"阶段1"公司是最高价值的投资技能。

### 原则3: PEG应按EPS增长率计算

对于积极回购+OPM扩张的公司:
- 按收入增长率算PEG → 高估(FICO PEG=2.5，看起来贵)
- 按EPS增长率算PEG → 合理(FICO PEG=1.3，实际便宜)

**框架修正**: v0.3的PEG计算应使用"预期EPS增长率"(含回购+OPM效应)。

### 原则4: "平台垄断型"是第七种复利原型

| 原型 | 代表 | 增长引擎 | FICO对比 |
|------|------|---------|---------|
| 密度型 | ROL | 服务密度 | 不同 |
| 平台型 | FICO/VRSK | **定价权+制度嵌入** | **FICO** |
| 耗材型 | IDXX | 安装基数→耗材 | 不同 |
| 服务扩展型 | CTAS | 客户×品类 | 不同 |
| **算法垄断型** | **FICO/MSCI/MCO** | **无实体产品，纯规则/标准垄断** | **新原型** |

## 五、验证: 2014→2025

| 指标 | FY2014 | FY2025 | 倍数 |
|------|--------|--------|------|
| 收入 | $789M | $1,991M | 2.5x |
| 净利润 | $95M | $652M | 6.9x |
| FCF | $162M | $770M | 4.8x |
| EPS | $2.72 | $26.54 | 9.8x |
| OPM | 20.5% | 46.5% | +26pp |
| 股数 | 33.9M | 24.2M | -29% |
| 市值 | $1.87B | $36.3B | 19.4x |
| P/E | 20x | 56x | 2.8x |

**分解68倍股价回报**:
- 收入增长贡献: 2.5x
- OPM扩张贡献: 2.8x (20.5%→46.5%)
- 回购贡献: 1.4x (股数缩减29%)
- P/E扩张贡献: 2.8x (20x→56x)
- 复合: 2.5 × 2.8 × 1.4 × 2.8 ≈ **27x**（加上再投资复利≈68x）

**核心教训**: 定价权垄断+积极回购+P/E重估 = 一代投资机会。收入只涨了2.5倍，但股价涨了68倍。
