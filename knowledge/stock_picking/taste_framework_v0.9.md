# 选股品味框架 v0.9

> **起源**: 8成功案例(HEI/DHR/CSU/GE/FICO/Visa/IDXX/ROL) + 5失败案例 + MSCI对标 + CTAS密度×交叉销售
> **v0.9核心升级**: CTAS"密度×交叉销售"复合增长模型 + 服务扩展型原型重定义 + OPM天花板第三通道(交叉销售提升) + 复利路径三分法
> **触发**: CTAS 12年14x(25% CAGR), 远超ROL的7x。关键差异: ROL只有密度(T5≈1.0x), CTAS有密度×交叉销售(T5≈1.7x)。交叉销售渗透率<20%=巨大跑道。

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.3-v0.7: (沿用)
v0.8: 复利不只一条路。ROL(资本效率型)和FICO(OPM弹性型)是两条独立路径。
v0.9: **密度×交叉销售是第三条复利路径, 而且可能是最强的。CTAS 12年14x(25% CAGR) > ROL 7x(18%) > IDXX 9x(22%)。原因: 密度降低每站成本 + 交叉销售提升每站收入 = 双向挤压创造OPM扩张空间。OPM从14.5%→22.8%(+810bps), 交叉销售渗透率仍<20% = 10年+跑道。**

### v0.9的认知升级

```
v0.8思维: "CTAS和ROL都是密度型, 归同一原型"
v0.9思维: "ROL=纯密度型(降成本), CTAS=密度×交叉销售型(降成本+提收入)
          → 密度只创造成本优势, 交叉销售创造收入增长
          → 两者组合=OPM扩张(ROL做不到的事)
          → CTAS的OPM从14.5%→22.8%(+810bps), ROL十年原地踏步
          → 12年回报: CTAS 14x vs ROL 7x, 差2倍
          → 密度是'基础设施', 交叉销售是'增长引擎'"

v0.8思维: "OPM天花板由成本结构决定"
v0.9思维: "OPM天花板由成本结构+收入密度共同决定
          → ROL: 每站收入固定(害虫控制$50-100/次) → 天花板~21%
          → CTAS: 每站收入可扩展(制服+地垫+急救箱+消防+...) → 天花板~25-26%
          → 同样的密度基础, 但CTAS的'收入天花板'更高
          → 交叉销售是打破OPM天花板的关键: 每增加一个服务品类, 边际成本≈0(卡车已经停在门口)"

v0.8思维: "v0.5实筛CTAS T5=1.5x, 勉强有操作杠杆"
v0.9思维: "CTAS T5a=1.71x(8年OI CAGR 14.9% / Rev CAGR 8.7%)
          → 这不是'勉强', 这是'显著'的操作杠杆
          → 源自: G&K并购整合+交叉销售提收入+密度降成本三重叠加
          → 但天花板~25-26%(不是FICO的65%), 所以回报14x(不是68x)"
```

## CTAS vs ROL: 密度型内部分化

| 维度 | ROL (纯密度) | CTAS (密度×交叉销售) | 差异原因 |
|------|-------------|---------------------|---------|
| **12年回报** | 7x (18% CAGR) | **14x (25% CAGR)** | CTAS有OPM扩张 |
| **Rev CAGR** | 10.1% | 8.7% | ROL收入增长更快 |
| **OI CAGR** | 9.9% | **14.9%** | CTAS OPM在扩张 |
| **EPS CAGR** | 13.8% | **18.9%** | CTAS=利润增长型 |
| **T5a(操作杠杆)** | 1.0x | **1.71x** | 密度×交叉销售的威力 |
| **OPM趋势** | 19.7%→19.4%(平) | **14.5%→22.8%(+810bps)** | 根本性差异 |
| **OPM天花板** | ~21-22% | **~25-26%** | 交叉销售提升收入天花板 |
| **CapEx/Rev** | **0.7%** | 4.0% | ROL资本极轻 |
| **FCF/NI** | **123%** | 97% | ROL现金转化更优 |

**核心洞察**: CTAS收入增长慢于ROL(8.7% vs 10.1%), 但回报高1倍(14x vs 7x)。差距100%来自OPM扩张——CTAS的利润增速远超收入增速。**ROL是"收入复利机器", CTAS是"利润复利机器"。**

### T5详细分析

```
T5a(操作杠杆): OI CAGR 14.9% / Rev CAGR 8.7% = 1.71x → 得分=2分

OPM扩张分解 (FY2018→FY2025, +810bps):
  G&K并购协同: ~200-250bps (路线密度+重复G&A消除)
  路线密度持续优化: ~150-200bps (更多客户/路线 → 更低单站成本)
  交叉销售mix提升: ~100-150bps (急救/消防高毛利品类增速>制服)
  定价权: ~100-150bps (3-5%/年提价, 90%+保留率)
  固定成本杠杆: ~100-150bps (SG&A/Rev从29.6%→27.2%)
  COVID成本纪律: ~50bps (永久保留)

剩余弹性空间 (v0.7框架):
  当前OPM: 22.8%
  天花板: ~25-26%
  剩余弹性: (25.5-22.8)/22.8 = 11.8%
  天花板<45% → ×0.7折扣 → 调整后8.3%
  → 有限弹性(10-40%区间) → T5不加分不减分

T5b(资本效率):
  CapEx/Rev=4.0% → +0分(正常)
  FCF/NI=97% → +0分(正常)
  Rev下降0次 → +1分
  T5b=1.0分 → 正常

T5最终 = max(T5a→2分, T5b→1分) = 2分

CTAS的T5=2分, 与FICO相同, 但原因完全不同:
  FICO: 零边际成本 → OPM天花板65% → 巨大弹性空间
  CTAS: 密度×交叉销售 → OPM天花板25% → 有限弹性空间但正在释放中
  → CTAS的OPM弹性"剩余空间"更小, 但"正在快速释放"
  → 投资含义: CTAS当前的OPM扩张速度(每年+100bps)可持续3-5年
```

## 复利路径三分法 (v0.9: 从二分法升级)

```
             路径A:               路径B:               路径C:
           OPM弹性型           资本效率型          密度×交叉销售型
          (利润驱动)           (增长驱动)          (利润+增长双驱)

典型代表    FICO 2014           ROL                  CTAS
T5a         > 1.5x              ≈ 1.0x               ~1.5-1.8x
OPM天花板   60-70%              20-22%               25-28%
CapEx强度   3-5%                < 1%                 3-5%
FCF/NI      80-100%             > 120%               90-100%
增长来源    提价>>量增           量增+并购>>提价       交叉销售+密度+提价
OPM趋势    大幅扩张             平坦                  温和但持续扩张
回报潜力    极高(68x)           中高(7x)             **高(14x)**
可预测性    中(何时提价?)       高(极稳)             **高(交叉渗透率可追踪)**
下行风险    中(监管)            低(刚需)             **低(多服务锁定)**
最优买点    市场未认知时          P/E压缩时             持续配置(长青型)

路径C的独特优势:
  1. OPM扩张给了T5>1.5x (利润增速>收入增速) — 不逊于FICO型
  2. 物理基底+密度经济 → 极低下行风险 — 不逊于ROL型
  3. 交叉销售渗透率<20% → 可量化的10年+跑道
  4. 多服务锁定 → 客户越用越难走 → 护城河随时间加深
  → 路径C = 路径A的利润弹性 + 路径B的稳定性 + 独有的可扩展收入
  → 但天花板25%(不是65%) → 回报14x(不是68x)

最佳组合配置:
  路径A(FICO型): 高赔率 — 找到下一个"未认知定价权期权"
  路径B(ROL型): 高胜率 — 极低风险的稳定复利
  路径C(CTAS型): 赔率+胜率均高 — 最优风险调整后回报
```

### 密度×交叉销售型: 完整模型 (v0.9新增)

```
增长特征:
  1. 四重引擎:
     a. 有机新客户 (~3-4%/年) — 密度填充
     b. 交叉销售 (~2-3%/年) — 每站收入提升 ← 核心引擎
     c. 定价 (~3-5%/年) — 温和但持续
     d. 补充性并购 (~1-2%/年) — tuck-in为主
     合成: 8-9% Rev CAGR + 1.7x操作杠杆 = 14-16% EPS CAGR

  2. 交叉销售飞轮:
     制服租赁(入口) → 技师每周上门1-2次 → 顺带推荐地垫/急救箱/消防检查
     → 每增一个品类: 边际成本≈0(卡车已停门口) + 切换成本×2
     → 渗透率<20% = 5-10年+跑道
     → UniFirst收购如完成 → 100万→130万客户基数 → 交叉销售TAM扩大30%

  3. 物理基底五层防御:
     L1: 物理必须(制服要洗)
     L2: 路线锁定(卡车已停)
     L3: 运营嵌入(员工周一要干净制服)
     L4: 资本壁垒(数百洗衣厂+3000卡车)
     L5: 规模经济(密度→低成本→赢客户→更密)

OPM扩张引擎 (v0.7框架适配):
  天花板~25-26% (高于ROL的21%, 低于FICO的65%)
  原因: 交叉销售提升每站收入(分子变大), 密度降低每站成本(分母变小)
  → 双向挤压 = OPM扩张
  → ROL只有一个方向(降成本), 所以OPM天花板更低
  当前OPM: 22.8% → 剩余空间: ~2-3pp → 可持续3-5年

  OPM天花板四级分类更新 (v0.9):
    零边际成本(FICO/MSCI): 60-70%
    低边际成本(IDXX/DCI): 35-42%
    中边际成本-可扩展收入(CTAS): 25-28% ← v0.9: 收入可扩展所以高于ROL
    中边际成本-固定收入(ROL): 20-22% ← v0.9: 收入固定所以天花板更低
    高边际成本(传统制造): 15-20%

  关键区分: ROL和CTAS同为"中边际成本", 但天花板差4-6pp
  原因: ROL每站只卖一个服务(害虫控制), CTAS可卖4-6个
  → 每增加一个服务品类, 边际成本≈0但边际收入>0 → 天花板上移

投资节奏:
  CTAS不像IDXX有投资/收获期, 也不像ROL完全平滑
  CTAS有"并购整合期":
    G&K (2017): OPM暂降(14.5%) → 整合完成后加速扩张(→22.8%)
    UniFirst (如完成): 预期类似模式 → OPM暂降2-3pp → 2-3年整合→天花板上移至27-28%?
  最佳买点: 并购宣布后(市场担忧整合风险) 或 宏观恐慌导致P/E压缩至30-35x
```
