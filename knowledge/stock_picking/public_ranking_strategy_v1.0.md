# 公开排行榜策略 v1.0

> **目标**: 排行榜 → 社交媒体传播 → 深度研报引流
> **核心矛盾**: 展示足够干货吸引关注 vs 保护核心方法论IP
> **设计原则**: 三层信息架构 — 公开层(钩子) / 半公开层(干货) / 内部层(核心)

---

## 一、品牌命名

**推荐: "复利品质指数" (Compounding Quality Index, CQI)**

理由:
- "垄断"二字在中国社媒容易引发负面联想(反垄断), "品质"更正面
- "复利"直击长期投资者心理 — 不是找涨最快的, 是找复利最久的
- "指数"暗示系统化方法论, 非随便排名
- 英文缩写CQI简洁, 便于跨语言传播

备选: "护城河指数" / "定价权排行榜" / "永续增长榜"

---

## 二、三层信息架构

### 公开层 (社交媒体发布)

**展示内容**:
- 总排名 + CQI总分(百分制, 非原始分)
- 6个维度名称(合并后的, 非14个原始维度)
- 每家公司一句话"标签"(最吸引眼球的洞见)
- 雷达图(视觉冲击)

**公开的6个维度** (由14个内部维度合并):

| 公开维度名 | 内部来源 | 公开定义(一句话) |
|-----------|---------|-----------------|
| **定价权** | B4 | 能否持续超通胀提价且客户不走 |
| **客户粘性** | B2+B3 | 客户锁定深度 × 收入经常性 |
| **护城河** | C1+C2+C3 | 制度嵌入+网络效应+生态锁定的综合壁垒 |
| **增长跑道** | B1+B7 | 收入引擎清晰度 × TAM剩余空间 |
| **资本纪律** | B5+B6 | 利润弹性 + 资本配置效率 |
| **竞争壁垒** | C4+C5+C6 | 数据飞轮+规模经济+物理壁垒的防御厚度 |

→ 6个维度直觉易懂, 投资者一看就知道在评估什么
→ 内部14维度 + 42子因子的拆解逻辑不公开

**不公开的内容**:
- 42个子因子的定义和评分标准
- D1周期性修正系数和计算方法
- 子因子权重(a/2 + b/1.5 + c/1.5)
- 收入纯度修正、周期性税收等独创框架
- 具体公司的子因子逐项得分

### 半公开层 (深度文章/Newsletter引流)

**展示内容**:
- 每家公司2-3个"亮点/暗点"洞见(从子因子中提炼)
- 排名变化的原因概述(不含公式)
- 跨公司对比的关键发现(如"FICO vs NVDA定价权差异")
- 框架升级的方向性说明

**示例内容**(用于引流文章):

```
为什么FICO排在NVDA前面?

两家公司的品质裸分几乎一样(51 vs 52), 但FICO有一个NVDA永远追不上的东西:
收入经常性。

FICO每天收到数百万次信用查询费, 不需要说服任何人下单。
NVDA每卖一批GPU, 都需要客户做一个新的资本支出决策。

这个差别在繁荣时看不出来。但等AI CapEx放缓的那一天...

[完整分析见我们的NVDA深度研报 →]
```

→ 给出结论和核心逻辑, 但不给公式和子因子
→ 每个洞见都是研报的"预告片"

### 内部层 (完整方法论, 不公开)

- 42个子因子完整定义和评分标准
- D1/D2/D3修正系数
- 收入纯度、周期性税收、负权益复利者等框架
- 子因子权重体系
- quality_scoring_benchmark.md 和 monopoly_ranking_detailed_v1.0.md 完整内容

## 四、框架微调策略 — "进化, 不是纠错"

### 核心原则: 框架升级 = 内容机会

**绝对不要**:
- 悄悄改分数假装从没变过
- 频繁大改(每季度最多微调一次)
- 用"我们之前错了"的口吻

**应该做的**:
- 每次微调都包装成"框架进化"内容
- 用版本号管理: CQI v1.0 → v1.1 → v2.0
- 分数变化本身就是一篇文章的素材

### 版本管理规则

| 变化类型 | 版本号 | 公开说明 | 频率 |
|---------|--------|---------|------|
| 数据更新(季报出来) | v1.0.x | "基于最新财报更新" | 每季度 |
| 权重微调(±1分以内) | v1.x | "优化了XX维度的评估方法" | 每半年 |
| 新增维度/重大调整 | vX.0 | "框架重大升级"(单独一篇文章) | 每年 |
| 新增公司 | 不改版本 | "新增XX进入排行榜" | 随时 |

### 微调时的公开话术模板

```
CQI v1.0 → v1.1 升级说明

本次更新:
- NVDA: 52→55分(+3) — 原因: Software ARR突破$5B,
  收入经常性维度上调
- AVGO: 48→46分(-2) — 原因: VMware客户流失数据显示
  客户粘性维度需下调

框架优化:
- "客户粘性"维度增加了对合同续约率的量化考察
- 这使得长期合同型公司(IHG)的评分更精确

→ 完整分析: [链接到深度文章]
```

→ **每次变化都是3件事: 排名变了 + 为什么变了(概述) + 详细分析看研报**
→ 变化本身就是传播内容, 不是"纠错"

### 应对质疑的预案

| 质疑 | 回应 |
|------|------|
| "你们的分数凭什么?" | "基于42项量化因子的系统评估, 覆盖11年数据" |
| "为什么不公开全部方法?" | "核心方法论是我们的研究成果, 但6个维度和评估逻辑完全透明" |
| "分数改了是不是之前错了?" | "市场在变, 公司在变, 我们的评估也应该进化。每次变化我们都会解释原因" |
| "NVDA排第六不合理" | "NVDA品质裸分其实排第一, 但我们考虑了周期性风险。详见研报" |

## 五、引流漏斗设计

```
Level 1: 社交媒体排行榜卡片 (免费, 广传播)
    ↓  "FICO凭什么排第二? 10年涨价7倍..."
Level 2: 维度对比深度文章 (免费, 建信任)
    ↓  "为什么定价权是最重要的单一因子?"
Level 3: 单公司深度研报 (核心资产)
    ↓  "NVDA 21万字深度研报, 覆盖所有子因子"
Level 4: 框架方法论 (不公开, 核心IP)
    "42子因子+权重+修正系数完整体系"
```

每个Level都引向下一个Level:
- L1的标签句引发好奇 → 点进L2文章
- L2文章给出框架但不给细节 → 引向L3研报
- L3研报展示研究深度 → 建立"这个团队靠谱"的信任

### 内容日历建议

| 月份 | 内容类型 | 标题方向 |
|------|---------|---------|
| 每季度 | 排行榜更新 | "CQI v1.0.x — 最新季报后排名变化" |
| 新增公司时 | 深度文章 | "XX加入复利品质指数, 排名第几?" |
| 框架升级时 | 方法论文章 | "我们升级了评估框架, 这是原因" |
| 争议话题时 | 对比文章 | "NVDA vs FICO: 谁才是真正的垄断?" |
| 市场波动时 | 验证文章 | "暴跌之后, CQI排名靠前的公司表现如何?" |
