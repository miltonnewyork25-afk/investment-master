# 选股品味框架 v0.4

> **起源**: HEI/DHR/CSU/GE Aviation/FICO 五案例回溯
> **v0.4核心升级**: FICO教训整合 — 利润弹性估值+算法垄断原型+定价权期权
> **触发**: FICO回溯揭示"收入只涨2.5倍但股价涨68倍" — 框架严重低估利润弹性型公司

---

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.2: 寻找"被错误定价的复利机器"(含并购型)
v0.3: 增长引擎必须可观察、可追踪、可预测
v0.4: **增长≠收入增长。利润增长率可以是收入增长率的2-3倍。框架必须识别这种弹性。**

### 增长来源的偏好光谱

```
强烈偏好              可接受               回避
<---------------------------------------------->
纯有机增长      核心有机+补充性并购      纯并购驱动

IDXX CPRT FICO    ROL CTAS DCI         CSU HEI DHR
```

### v0.4新增: 利润弹性意识

```
市场常见错误:
  "FICO收入增长只有8%, 给P/E 20x"

实际:
  收入增长 8% + OPM扩张(20%->46%) + 回购(股数-5%/年)
  = EPS增长 21% → P/E 20x = PEG 0.95 → 严重低估

教训: 收入增速平庸的公司可能是利润增速优秀的公司。
      框架必须看穿收入表面, 评估利润弹性。
```

## 第零层: 增长质量门控 (v0.4校准)

| # | 指标 | 要求 | 逻辑 |
|---|------|------|------|
| G0 | **有机收入增长占比** | > 50% of 总增长 | 增长不依赖并购的不确定性 |
| G1 | **商誉/总资产** | < 40% (当前并购依赖); **例外: 历史遗留商誉+已停止并购** | 区分"正在并购"vs"曾经并购" |
| G2 | **增长可追踪性** | 能识别2-3个可量化的增长驱动力 | 增长逻辑必须可观察 |

**不通过G0 -> 直接排除，不进入品质筛选。**

**v0.4变化 — G1商誉规则精细化**:
- v0.3: 商誉>40%一律扣分
- v0.4: 区分"活跃并购商誉"vs"历史遗留商誉"
- FICO商誉65%但来自2000年代收购, 之后几乎不再并购, 增长完全靠有机提价
- **判断标准**: 近5年并购支出/FCF < 20% → 商誉属于历史遗留, G1豁免

可追踪的增长驱动力示例:
- 客户数量增长 (IDXX: 兽医诊所渗透率)
- 路径密度 (ROL: 每城市服务密度)
- **定价权行使** (FICO: 每次评分版税从$0.30→$3.50+)
- 安装基数扩大 (CPRT: 事故车辆处理量; GE: LEAP发动机交付量)
- 单客户钱包份额 (CTAS: 每客户服务品类扩展)
- **OPM扩张** (定价权型公司: 20%→46%的利润率爬坡)

## 第二层: 品味判断 (v0.4升级, 9→10项)

| # | 信号 | 检查方法 | 权重 |
|---|------|---------|------|
| T1 | **有机增长引擎清晰** | 能用1句话说清为什么收入会持续增长? | **最高** |
| T2 | **原子化垄断/转换成本** | 产品/服务在细分市场形成小垄断或高粘性? | 高 |
| T3 | **经常性收入占比** | 订阅/维护/服务合同占比>50%? | 高 |
| T4 | **定价权证据** | 5年ASP持续上升 或 毛利率稳定>40%? | 高 |
| T5 | **利润弹性** | EPS CAGR > Revenue CAGR × 1.5? (含OPM扩张+回购) | **高 (v0.4新增)** |
| T6 | **被忽视** | 分析师<15? 非热门板块? | 中 |
| T7 | **OPM稳定或扩张** | 5年OPM波动<5pp 或持续上升? | 中 |
| T8 | **TAM扩张逻辑** | 市场本身在增长, 不是只靠抢份额? | 中 |
| T9 | **管理层利益一致** | 内部人持股>3% 或 制度化的资本纪律? | 中 |
| T10 | **零稀释文化** | SBC占收入<3%? 无增发? | 中 |

**评分**: 每项0-2分，总分20分。>=12分 = 值得深入研究

**v0.3->v0.4的关键变化**:
- **新增T5"利润弹性"(高权重)** — FICO核心教训: 收入8%增长+OPM扩张+回购=EPS 21%增长。市场系统性低估这类公司
- 门槛从11/18调整为12/20 (比例一致, 60%)

## 第三层: 估值框架 (v0.4重大升级)

### 3.1 基础估值 (沿用)

| 指标 | "好价格" | "合理" | "贵" |
|------|---------|--------|------|
| FCF Yield | > 5% | 3-5% | < 3% |
| EV/EBITDA vs 增长 | < CAGR*2 | CAGR*2-3 | > CAGR*3 |

### 3.2 PEG计算修正 (v0.4新增)

**v0.3问题**: PEG使用收入增长率 -> 对FICO类公司严重失真

```
PEG计算规则 (v0.4):

情况1: 纯收入增长型 (OPM稳定, 无显著回购)
  PEG = P/E / Revenue CAGR
  适用: IDXX, CPRT

情况2: 利润弹性型 (OPM扩张中 或 年回购>3%股数)
  PEG = P/E / EPS CAGR
  适用: FICO, CTAS, 任何积极回购+提价的公司

情况3: 不确定时
  PEG = P/E / max(Revenue CAGR, EPS CAGR × 0.7)
  取保守值, 但不完全忽视利润弹性
```

| PEG (按EPS算) | "好价格" | "合理" | "贵" |
|---------------|---------|--------|------|
| 利润弹性型 | < 1.5 | 1.5-2.5 | > 2.5 |

**FICO验证**: 2014年 P/E 20x / EPS CAGR 21% = PEG 0.95 → "好价格" ✓
vs v0.3: P/E 20x / Revenue CAGR 8% = PEG 2.5 → "贵" ✗ (严重误判)

### 3.3 未兑现定价权期权 (v0.4新增概念)

```
定价权的两个阶段:

阶段1(潜伏期) — 最佳买点
  特征: 定价权存在但未行使
  估值: 当前利润 * 平凡倍数 = 低估
  信号: 价值/价格比>>10:1, CEO开始提及"货币化机会"
  案例: FICO 2014 (版税$0.30 vs 贷款价值$300K)

阶段2(释放期)
  特征: 年年提价, OPM持续扩张
  估值: 增长利润 * 溢价倍数 = 合理到偏贵
  信号: 每次评分/交易的平均收入持续上升
  案例: FICO 2018-2025 (版税$0.30→$3.50+)
```

**识别阶段1公司的检查清单**:
1. 产品对客户的经济价值远超价格 (价值/价格 > 10:1)
2. 转换成本极高 (制度性嵌入/监管强制/行业标准)
3. 历史上几乎没涨过价 (说明定价权是"未开封的")
4. 新CEO上任 或 管理层开始提"货币化" (行使信号)
5. 当前OPM偏低但毛利率很高 (说明提价空间大, 费用可杠杆)

## 复利机器原型 (v0.4更新: 6→7种)

| 原型 | 代表 | 核心引擎 | 可研究性 | 偏好 |
|------|------|---------|---------|------|
| **密度型** | ROL | 服务密度+经常性收入 | 高 -- 追踪路径数/城市 | **强偏好** |
| **平台型** | FICO/VRSK | 数据垄断+定价权 | 高 -- 追踪客户数*单价 | **强偏好** |
| **算法垄断型** | FICO/MSCI/MCO | 无实体产品, 纯规则/标准垄断 | **极高** -- 追踪评分量*单价 | **强偏好** |
| **耗材型** | IDXX/DCI | 安装基数->耗材复购 | 高 -- 追踪装机量*消耗率 | **强偏好** |
| **安装基数型** | GE Avi | 设备交付->长期服务收入 | 高 -- 追踪发动机交付量 | **强偏好** |
| **服务扩展型** | CTAS | 客户基数*服务品类 | 中高 -- 追踪cross-sell率 | **偏好** |
| **纯并购型** | CSU/HEI/DHR | 并购系统的统计性质 | 低 -- 黑箱 | **回避** |

**v0.4变化**:
- 新增"算法垄断型" — FICO回溯发现: 无实体产品、无边际成本、纯标准/规则垄断是独特的商业模型
- 新增"安装基数型" — GE Aviation回溯发现: 设备交付->30年服务合同是可追踪的长周期复利
- "核心+补充并购"合并入其他原型(ROL/CTAS本身就是有机为主+bolt-on)
- 算法垄断型 vs 平台型区别: 平台型需要网络效应(VRSK), 算法垄断型靠制度嵌入(FICO/MCO评级)

### 算法垄断型的独特特征

```
1. 零边际成本: 每多一次评分/评级, 成本趋近于零
2. 制度嵌入: 监管/行业标准强制使用, 不是"选择"使用
3. 定价权期权: 历史低定价 → 提价空间巨大
4. OPM天花板极高: 理论上可达60-70% (MSCI已达55%+)
5. 利润弹性极强: 收入增长8% → EPS增长20%+ 完全可能

代表公司:
  FICO — 信用评分标准 (美国信贷制度嵌入)
  MSCI — ESG/指数标准 (被动投资制度嵌入)
  MCO  — 信用评级标准 (债券发行制度嵌入)
  SPGI — 指数+评级 (与MCO类似)
```

## 三重增长引擎分析框架 (v0.4新增)

FICO教训的核心方法论贡献:

```
EPS增长 = 收入增长 * OPM杠杆 * 回购效应

示例 (FICO 2014-2025):
  收入 CAGR:  8.4%   → 贡献 2.5x (11年)
  OPM扩张:    20%→46% → 贡献 2.8x
  回购:       股数-29% → 贡献 1.4x
  ---------------------------------
  EPS增长:              → 复合 ~9.8x (CAGR ~23%)

  再叠加P/E扩张 (20x→56x) → 2.8x
  总回报: 2.5 * 2.8 * 1.4 * 2.8 ≈ 27x (加再投资复利≈68x)
```

**分析每家公司时, 必须分解这三个引擎**:

| 引擎 | 信号 | 数据来源 |
|------|------|---------|
| 收入增长 | Revenue CAGR | 季报/年报 |
| OPM杠杆 | OPM趋势, 毛利率vs运营费用率 | 季报 |
| 回购效应 | 稀释后股数变化, 回购金额/FCF占比 | 季报/现金流量表 |

**关键: 三引擎同时发力 = 利润弹性型复利机器**
- 收入增长8% + OPM扩张3pp/年 + 回购3-5%/年 → EPS CAGR 18-25%
- 市场只看到8%收入增长 → 给平凡估值 → 严重低估
