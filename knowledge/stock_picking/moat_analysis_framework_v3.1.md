| 旧术语 | 新术语 | 原因 |
|--------|--------|------|
| 垄断性排行榜 | 护城河排行榜/CQI | "垄断"太窄(COST/PG不是垄断但有强护城河) |

## 二、C1制度嵌入五层结构 (FICO报告核心创新)

### 2.1 五层模型

C1不再是一个0-5的单一打分, 而是分解为5个嵌入层:

| 层 | 名称 | 含义 | 评估问题 | 替换时间 |
|----|------|------|---------|---------|
| **L1** | 基础设施嵌入 | 产品嵌入技术基础设施(API/接口/系统) | 客户系统中有多少组件依赖? | 1-2年 |
| **L2** | 监管嵌入 | 监管法规/合规要求中直接引用 | 有无法规条文点名要求使用? | 3-5年 |
| **L3** | 合约嵌入 | 嵌入长期合同/证券化文件/行业协议 | 存量合约中引用的深度? | 5-10年 |
| **L4** | 运营嵌入 | 嵌入客户的日常运营/风控/决策流程 | 替换需重新校准多少年积累? | 5-15年 |
| **L5** | 认知嵌入 | 嵌入消费者/行业的心智模型 | 品牌名=品类名? (如"FICO分"=信用) | 10-20年 |

### 2.2 评分方法

```
C1 = Σ(Layer_i × Weight_i)  i=1..5

默认权重:
L1=15%, L2=25%, L3=20%, L4=25%, L5=15%

行业调整:
- 金融/信息基础设施: L2权重↑至30%, L1↓至10% (监管是核心嵌入点)
- 消费品: L5权重↑至30%, L2↓至10% (品牌认知是核心)
- 半导体设备: L4权重↑至30%, L2↓至15% (运营嵌入是核心)
```

### 2.3 核心嵌入层判断 (关键增量)

**每家公司必须识别其"核心嵌入层" — 最核心的嵌入点:**

| 公司 | 核心嵌入层 | 被突破风险 | C1趋势 |
|------|-----------|----------|--------|
| FICO | L2监管+L4运营 | FHFA打开L2(中) | ↓衰减中 |
| S&P Global | L2监管+L3合约 | Basel III锁定L2(极低) | →稳定 |
| ASML | L4运营+L6物理(≈C6) | 无替代技术(极低) | →稳定 |
| MSFT | L4运营+L3合约 | 企业IT替换成本极高(低) | →稳定 |
| Visa | L1基础设施+L5认知 | 监管限制费率(中) | ↓微弱衰减 |

### 2.4 C1嵌入性质四分类 (v3.1新增)

> **核心洞见**: C1五层回答"嵌入多深", 嵌入性质回答"嵌入的本质是什么"。性质不同→半衰期不同→衰减模式不同。

| 性质 | 定义 | 替换机制 | 半衰期特征 | 代表公司 |
|------|------|---------|-----------|---------|
| **偏好型** | 监管/行业偏好使用, 但替代品合法存在 | 替代品获批即开始侵蚀 | 最短(10-20年), 一旦拐点出现衰减加速 | FICO(VantageScore获FHFA批准) |
| **标准型** | 行业事实标准, 嵌入合同/法规/流程 | 需要行业集体迁移(类似LIBOR→SOFR) | 长(30-50年), 但一旦启动迁移不可逆 | SPGI/MCO(Basel III), Bloomberg |
| **封锁型** | 法律/认证禁止替换, 替换=违法/违规 | 需要监管机构重新认证(年+百万$) | 极长(=产品生命周期, 20-30年) | TDG(FAA认证), 医疗器械(FDA 510k) |
| **定义型** | 不是嵌入市场, 而是定义市场本身 | 需要另一个实体获得"定义权"(极罕见) | 最长(可能无限, 除非被动投资范式终结) | MSCI(定义什么是"新兴市场"), S&P(定义什么是"大盘股") |

**评分影响**: 嵌入性质不改变C1数值评分(仍用L1-L5加权), 但影响以下分析:

1. **半衰期估算** — 偏好型用10-20年基准, 标准型用30-50年, 封锁型用产品周期, 定义型用>50年
2. **趋势仪表盘解读** — 偏好型的↓比标准型的↓更紧急(衰减更快)
3. **C1×B4反身性循环** — 定义型几乎免疫反身性(定价权释放不会引发"寻找替代品"的政治反弹, 因为没有替代品的概念)

**报告中标注方式**:
```
C1制度嵌入: 4.5/5 (性质: 偏好型 → 半衰期15-20年)
C1制度嵌入: 4.8/5 (性质: 定义型 → 半衰期>50年)
```

**适用条件**: C1≥2.0的公司必须标注嵌入性质。C1<2.0的公司制度嵌入不是核心护城河, 不需要标注。

### 2.5 C1应用范围

**C1五层分析适用条件**: C1≥3.0的公司 (约8-10家)
**C1<3.0**: 仍用单一C1评分即可 (制度嵌入不是护城河核心来源)

## 三、B4定价权双维拆分

### 3.1 问题发现

FICO 2014: B4=5.0 (强度5.0 × 持久性5.0)
FICO 2026: B4=4.5 (强度5.0 × 持久性3.5)

**单一B4分数掩盖了"强度不变但持久性衰减"这个关键信号。**

### 3.2 新框架

| 维度 | 衡量 | 评估问题 |
|------|------|---------|
| **B4a 定价权强度** | 当前提价多少不丢客户? | 过去3年提价幅度 vs 客户流失率 |
| **B4b 定价权持久性** | 定价权还能维持多久? | 政治/竞争/监管压力趋势 |

```
B4 = (B4a + B4b) / 2  (各0-5分)

报表中展示: B4: X.X (强度X.X / 持久性X.X)
```

### 3.3 定价权阶段模型 v1.0 (可迁移框架)

| 阶段 | 名称 | OPM特征 | 市场反应 |
|------|------|---------|---------|
| 1.0 | 休眠 | 定价权未释放, OPM低位 | 无关注 |
| 1.5 | 觉醒 | 首次实质提价 | 轻微关注 |
| 2.0 | 加速 | 大幅提价, OPM快速扩张 | 分析师追踪 |
| 2.5 | 激进释放 | 单年+30%+提价 | 监管/诉讼介入 |
| 3.0 | 天花板 | 提价导致客户实际流失 | 竞争替代出现 |

**5个量化指标**:
1. OPM位置比 (当前OPM / 理论天花板)
2. 市场认知度 (提价是否被广泛讨论)
3. 提价加速度 (近3年提价CAGR)
4. 监管热度 (诉讼/调查/立法数量)
5. 竞争替代进展 (替代品份额变化)

**适用范围**: B4≥3.5的公司。跨行业定位:
- S&P Global: Stage 1.0-1.5 (定价权几乎未释放)
- MSCI: Stage 1.5-2.0
- ASML: Stage 2.0 (EUV价格持续上升)
- FICO: Stage 2.3 (接近天花板)

### 3.4 C1×B4反身性循环 (CI-01迁移)

```
高C1保护高B4 → B4释放 → OPM扩张 → 政治反弹 → C1侵蚀 → B4衰减

关键洞见: 制度垄断最危险的时刻是定价权释放到足以引起政治注意的时候
```

**适用条件**: C1≥3.0 且 B4a≥4.0 的公司 (FICO, S&P Global, ASML, 潜在的Visa)

**v3.1补充 — 嵌入性质对反身性的影响**:
- **偏好型**(FICO): 反身性循环最活跃 — 政治反弹直接打开替代品通道
- **标准型**(SPGI): 反身性存在但迟缓 — 需要Basel级别的制度变革才能启动
- **封锁型**(TDG): 反身性几乎不存在 — 定价权释放不会触发"重新认证"
- **定义型**(MSCI): 反身性免疫 — 没有"替代品"的概念, 只有"另起炉灶"的可能(如中国A50指数试图绕过MSCI)

## 三A、C3锁定载体标注 (v3.1新增)

> **问题**: 现有C3只衡量"锁定多深", 不区分"锁定在哪里"。但锁定载体决定了持久性和代际更替风险。

| 锁定载体 | 定义 | 切换成本在于 | 代际更替风险 | 代表公司 |
|----------|------|-----------|:----------:|---------|
| **系统锁定** | 嵌入IT基础设施/API/数据流 | 重建系统集成 | 低(系统不会退休) | MSFT(Office), NOW, INTU |
| **数据锁定** | 历史数据积累=切换代价 | 迁移/重建数据资产 | 低(数据不会过期) | VRSK(ISO数据库), ADBE(项目文件) |
| **流程锁定** | 嵌入客户日常运营流程 | 重新设计工作流 | 中(流程可渐进替换) | CTAS(制服更换节奏), VEEV(临床流程) |
| **人力锁定** | 用户投入年数学习/培训 | 重新培训人员(肌肉记忆) | **高**(新一代可能直接学竞品) | ISRG(外科医生), SNPS/CDNS(芯片设计师) |

**评分影响**: 锁定载体不改变C3数值评分, 但影响趋势判断:
- 人力锁定: C3趋势需额外评估"新一代用户是否仍选择本产品" — 如果竞品在教育领域渗透(如大学课程改用竞品), 是C3衰减的早期信号
- 系统锁定 + 数据锁定组合: 最持久(双重切换成本), 如INTU(QuickBooks会计数据+IRS历史报税)

**报告中标注方式**:
```
C3生态锁定: 4.0/5 (载体: 人力锁定 — 外科医生da Vinci培训, 代际风险中等)
C3生态锁定: 4.5/5 (载体: 系统+数据双锁定 — IT集成+历史数据, 代际风险低)
```

## 四、护城河半衰期分析

### 4.1 历史先例库 (v3.1: 增加嵌入性质标注)

| 公司/标准 | 嵌入性质 | 持续时间 | 如何被替换 |
|----------|:-------:|:-------:|----------|
| AT&T | 封锁型 | 71年 | 反垄断拆分(政府主动打破) |
| SWIFT | 标准型 | 53+年 | 尚未被替代(CIPS/SPFS试图绕过) |
| S&P/Moody's | 标准型 | 51+年 | 2008后反而加强(Basel III锁定) |
| MSCI指数 | 定义型 | 55+年 | 尚未被替代(被动投资趋势反而加强) |
| LIBOR | 标准型 | ~50年 | 强制SOFR替换(历时9年, 需监管主导) |
| Bloomberg Terminal | 标准型 | 45+年 | 尚未被替代 |
| FICO Score | 偏好型 | 37+年 | 正在被VantageScore侵蚀(FHFA打开通道) |
| FAA零部件认证 | 封锁型 | 50+年 | 从未被系统性替代(单件认证=终身垄断) |

**v3.1洞见**: 嵌入性质与半衰期高度相关——偏好型最先被侵蚀(FICO), 标准型需要制度级迁移(LIBOR→SOFR历时9年), 封锁型和定义型几乎只能被政府/反垄断打破(AT&T)。

### 4.2 半衰期对估值的影响

| 假设半衰期 | WACC调整 | 估值影响 |
|-----------|---------|---------|
| 20+年 | 基准WACC | 基准 |
| 15年 | WACC +1% | -12%至-15% |
| 10年 | WACC +2% | -22%至-27% |
| 7年 | WACC +3% | -30%至-38% |

**关键洞见**: 半衰期同时压缩分子(未来现金流↓)和分母(折现率↑) — **双重打击**。

### 4.3 适用场景

制度嵌入型公司(C1≥3.5)在Tier 3报告Phase 3中应执行半衰期分析。包括:
- 识别最相似的历史先例
- 估算当前半衰期(年)
- 计算半衰期对估值的影响
- 纳入情景分析(不同半衰期假设)

## 五、护城河趋势仪表盘 (Moat Trend Dashboard)

### 5.1 设计原理

静态评分回答"护城河有多深"。趋势仪表盘回答"护城河在变深还是变浅"。

**FICO的核心教训**: 2018-2022年护城河实际在**加强**(定价权释放), 2022年是拐点, 之后开始衰减。单看当前C1=4.5看不出这个动态。

### 5.2 仪表盘模板

```markdown
### 护城河趋势仪表盘 — {公司}

| 维度 | 2018 | 2020 | 2022 | 2024 | 2026E | 趋势 | 驱动因素 |
|------|:----:|:----:|:----:|:----:|:-----:|:----:|---------|
| C1制度嵌入 | | | | | | | |
| C2网络效应 | | | | | | | |
| C3生态锁定 | | | | | | | |
| C4数据飞轮 | | | | | | | |
| C5规模经济 | | | | | | | |
| C6物理壁垒 | | | | | | | |
| **综合** | | | | | | | |
| B4定价权 | | | | | | | |

趋势符号 (v5.0细化):
↑ 结构性加宽 — 行业结构/物理定律在不可逆地加深护城河(管理层无关)
↗ 执行性强化 — 公司主动通过份额/生态/产品加深护城河(依赖执行力)
→ 稳定 — 护城河牢固，无重大变化
↘ 结构性收窄 — 监管/替代品/竞争在结构性侵蚀(管理层难逆转)
↓ 主动侵蚀 — 具体竞争对手/替代品在主动打开护城河
⇊ 全面崩塌 — 护城河多线同时蒸发

↑与↗的核心区别: ↑的驱动力与管理层无关(换CEO趋势不变), ↗依赖管理层执行(执行力下降则逆转)

三种趋势情景:
- 情景A — 再强化 (X%): [描述条件]
- 情景B — 缓慢侵蚀 (X%, 基准): [描述条件]
- 情景C — 加速崩塌 (X%): [描述条件]
```

### 5.3 执行时机

| 场景 | 是否执行趋势仪表盘 | 原因 |
|------|:---------------:|------|
| Tier 3深度报告 | **必须** | 有足够数据支撑时间序列 |
| CQI季度更新 | 选择性 | 只更新有重大变化的公司 |
| Tier 2标准分析 | 不需要 | 深度不够支撑趋势判断 |

### 5.4 核心洞见 (FICO报告原创)

1. **强化是渐进的(+0.1-0.2/年), 衰减可能非线性(慢然后突然)** — 类似Hemingway的"how did you go bankrupt"
2. **拐点识别比当前分数更重要** — FICO在C1=4.5时拐点已出现, 而不是等到C1=3.0
3. **政治/监管是C1变化的主要驱动力, 不是竞争** — FHFA打开VantageScore不是因为VS更好, 而是政治压力

## 七、CPRT报告准备 — 框架预适配

### 7.1 CPRT的预期C1五层分析

CPRT不是制度垄断(C1在v2.0=2.0), 但其护城河来源非常独特:

| 层 | CPRT可能评分 | 假说 |
|----|:----------:|------|
| L1 | 3.0 | 保险公司系统集成(理赔→拍卖自动化) |
| L2 | 2.0 | 非监管强制, 但保险业采购流程准制度化 |
| L3 | 3.0 | 保险合同中指定Copart作为处置渠道 |
| L4 | 4.0 | 保险理赔流程20+年围绕Copart设计 |
| L5 | 2.0 | 消费者不太了解Copart(B2B为主) |

### 7.2 CPRT的核心护城河源 — 需要验证的假说

CPRT的护城河类型和FICO完全不同:
- **FICO**: 制度嵌入(C1) → 定价权(B4) → OPM扩张
- **CPRT**: 物理资产(C6=土地银行) + 网络效应(C2=双边拍卖) + 反周期(D1=1.10)

CPRT报告应重点验证:
1. **土地银行不可复制性**: 200+个场地, 总面积多少? 城市扩张是否挤压新场地?
2. **双边拍卖网络效应强度**: 买家数量 vs 卖家数量 → 流动性优势可量化?
3. **反周期机制深度**: 衰退→更多total loss→更多拍卖量, 历史数据验证?
4. **IAA竞争威胁**: RB Global收购IAA后整合效果? 市场份额变化?
5. **电动车/自动驾驶对total loss rate的长期影响**

### 7.3 CPRT应适用的新框架

| 框架 | 适用? | 原因 |
|------|:----:|------|
| C1五层结构 | **否** | C1<3.0, 不需要五层分解 |
| B4双维拆分 | **是** | B4需评估提价强度 vs 持久性 |
| 护城河趋势仪表盘 | **是** | 作为#1公司, 趋势分析极其重要 |
| 半衰期分析 | **否** | 非制度嵌入型, 不适用 |
| 定价权阶段模型 | **条件** | 需先确认CPRT的B4是否≥3.5 |

### 7.4 CPRT报告的特殊关注点

1. **D1=1.10的验证**: CPRT是27家中唯一反周期公司, 需要2008/2020/2022的数据严格验证
2. **土地银行估值**: C6物理壁垒的量化 — 土地市值 vs 重置成本
3. **双边市场动态**: C2网络效应的量化 — 买家数/卖家数/成交率趋势
4. **CQI=82的合理性检验**: 作为#1, 需要最严格的红队审查

## 八、v3.2新增 (VRSN/V/LULU/UNH/ADBE/CRM/PTC/PYPL 8份报告驱动)

### 8.0 C1嵌入性质扩展 — 新增"独占型"

v3.1定义了偏好/标准/封锁/定义四种嵌入性质。VRSN报告发现第五种:

| 性质 | 定义 | 替换机制 | 半衰期 | 代表公司 |
|------|------|---------|--------|---------|
| **独占型**(新) | 合同/协议赋予唯一运营权，替换需要协议方同意 | 需要ICANN/政府重新招标或废除合同 | 合同期(VRSN: 推定续约≈∞) | **VRSN**(ICANN协议), 港口/机场特许权 |

**与"封锁型"的区别**: 封锁型(TDG)是认证制度锁定(每个零件单独认证)；独占型(VRSN)是合同排他权(只有一家被允许运营)。封锁型有替代品但替代需要重新认证；独占型连替代品的合法资格都不存在。

**VRSN的护城河=独占型C1 + 路径依赖C5**: 1.61亿.com域名=1.61亿实体同时迁移的协调问题（类似"所有人同时从英语切换到另一种语言"）。替换成本非线性——涉及全球DNS重构+数十亿设备缓存+数百万网站重定向。

### 8.1 B4定价权新类型 — "合同定价权"

v3.0的定价权阶段模型(Stage 1-3)适用于通过市场力量获取的定价权(FICO/ASML)。VRSN和CME发现了一种不同的定价权:

| 定价权类型 | 机制 | 天花板 | 政治风险 | 代表 |
|-----------|------|--------|---------|------|
| **市场定价权** | 客户替代成本高→提价不流失 | 客户替代成本 | 中高(随释放加速) | FICO(Stage 2.3), ASML |
| **合同定价权**(新) | 合同/协议规定提价权限 | 合同条款(VRSN: 7%/年) | 合同续约时(VRSN: 推定续约) | **VRSN**(ICANN协议), **CME**(交易费) |
| **制度定价权** | 监管结构保护定价 | 监管容忍度 | 政治周期 | MCO/SPGI(评级费) |

**合同定价权的独特性**: 天花板是合同条款定义的(VRSN最高7%/年)，而非市场竞争决定的。这意味着Stage模型不完全适用——VRSN不存在"觉醒→加速→天花板"的渐进过程，而是"合同允许多少就提多少"的确定性提价。

**反身性在合同定价权下的表现**: VRSN提价100次不会触发客户"寻找替代品"（因为没有替代品），但会触发"修改合同条款"的政治压力。反身性循环的终点不是"替代品出现"而是"合同被修改"。AELP诉讼就是这个反身性的表现。

### 8.2 护城河侵蚀模式分类 (LULU/PYPL/ADBE教训)

v3.0-v3.1主要关注"高护城河"公司。LULU/PYPL/ADBE三份报告揭示了一个框架盲区: **护城河正在被侵蚀的公司如何分类**。

| 侵蚀模式 | 表现 | 速度 | 可逆性 | 案例 |
|---------|------|------|--------|------|
| **品牌侵蚀** | 品牌不再代表品类→替代品崛起 | 慢(2-5年) | 可逆(NKE 2024→恢复) 或不可逆(Gap) | **LULU**(Alo/Vuori蚕食), SBUX(第三波精品) |
| **技术替代侵蚀** | 新技术使原有壁垒贬值 | 快(1-3年) | 通常不可逆 | **ADBE**(Canva/AI生成), **PYPL**(Apple Pay/BNPL) |
| **结构性蚕食** | 竞争对手系统性瓦解份额 | 极慢(5-10年) | 不可逆但温和 | **PTC**(Siemens PLM年流失$20-40M), **CRM**(SMB被HubSpot蚕食) |

**"低估观察"评级的护城河前提**: v19.7新增的"低估观察"评级(LULU/PYPL)本质上是"护城河侵蚀中但估值已过度惩罚"。关键判断: 侵蚀是可逆(→最终修复→买入)还是不可逆(→价值陷阱→回避)。

**检验方法**:
- 可逆信号: 核心用户NPS止跌 / 新品全价售罄率恢复 / 管理层换人后指标改善
- 不可逆信号: 核心用户群迁移完成(>30%) / 替代技术成本优势>50% / 行业结构已变

### 8.3 护城河×资本配置交互 (PTC/CRM/V教训)

PTC报告发现回购效率η=0.51(低效回购——FCF Yield < WACC)。CRM和V报告发现类似模式。新增框架:

**η判断标准(嵌入E1资本配置模块)**:

| η值 | 判定 | 行动含义 |
|-----|------|---------|
| >1.0 | 回购创造价值 | 支持管理层回购决策 |
| 0.75-1.0 | 中性 | 可回购也可再投资 |
| **<0.75** | **回购摧毁价值** | 应优先再投资R&D/偿债 |

**跨报告发现**: PTC(η=0.51), V(η≈0.6), CRM(η≈0.7)——三家公司都在η<0.75时大量回购。共同原因: **管理层激励绑定TSR→回购推高EPS→LTIP兑现**。这不是个案而是系统性模式——高FCF公司在估值偏高时的回购可能是"管理层价值转移"而非"股东价值创造"。

### 8.4 UNH: 护城河框架对"医疗基础设施"的适配

UNH暴露了框架的一个盲区: **被监管限制定价权的基础设施公司**。UNH的护城河结构:

- C1制度嵌入极高(Optum覆盖1.5亿美国人健康记录)
- 但B4定价权受监管严格限制(MCR有精算约束+政治压力)
- 结果: 高C1低B4的"监管收费站"——护城河深但变现受限

**框架扩展**: 现有C1×B4反身性循环假设"高C1→释放B4→政治反弹"。但UNH模式是"高C1+低B4"——反身性被监管预先抑制。需要增加一条路径:

```
C1高+B4被抑制 → 通过垂直整合绕过B4限制(Optum) → 引发反垄断调查 → C1受威胁
```

这是UNH DOJ调查的本质: 当正面定价权(B4)被限制时，公司通过纵向整合来"偷取"定价权——但这会引发更大的政治反弹。
