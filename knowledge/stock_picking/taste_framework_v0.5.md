# 选股品味框架 v0.5

> **起源**: 5成功案例(HEI/DHR/CSU/GE/FICO) + 5失败案例(Valeant/WU/Xerox/IBM/Kodak) + MSCI对标
> **v0.5核心升级**: 假阳性防御层 + 定价权阶段判断 — 从"只学赢家"到"也学输家"
> **触发**: WU/Kodak在v0.4框架中完美通过所有筛选却失败 — 框架对假阳性无防御

---

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.3: 增长引擎必须可观察、可追踪、可预测
v0.4: 增长≠收入增长。利润增长率可以是收入增长率的2-3倍
v0.5: **护城河≠永恒。定价权有来源、阶段和有效期。框架必须同时回答"为什么能赢"和"怎样会输"。**

### 增长来源的偏好光谱

```
强烈偏好              可接受               回避
<---------------------------------------------->
纯有机增长      核心有机+补充性并购      纯并购驱动

IDXX CPRT FICO    ROL CTAS DCI         CSU HEI DHR
```

### v0.5的认知升级

```
v0.4思维: "FICO有定价权 → 好公司"
v0.5思维: "FICO有定价权 → 定价权来自哪里？法律强制 → 能被技术替代吗？不能
          → 客户价格/价值比？<0.01% → 政治风险？极低 → OPM在什么阶段？
          → 综合判断: 真正的持久垄断"

v0.4思维: "WU有定价权 → 好公司"
v0.5思维: "WU有定价权 → 定价权来自哪里？替代品缺乏 → 能被技术替代吗？
          Wise已经做到了 → 假阳性，排除"
```

## 第二层: 品味判断 (v0.5重构: 正面信号 + 假阳性防御)

### 2A. 正面信号 (沿用v0.4, 10项, 20分)

| # | 信号 | 检查方法 | 权重 |
|---|------|---------|------|
| T1 | **有机增长引擎清晰** | 能用1句话说清为什么收入会持续增长? | **最高** |
| T2 | **原子化垄断/转换成本** | 产品/服务在细分市场形成小垄断或高粘性? | 高 |
| T3 | **经常性收入占比** | 订阅/维护/服务合同占比>50%? | 高 |
| T4 | **定价权证据** | 5年ASP持续上升 或 毛利率稳定>40%? | 高 |
| T5 | **利润弹性** | EPS CAGR > Revenue CAGR * 1.5? | 高 |
| T6 | **被忽视** | 分析师<15? 非热门板块? | 中 |
| T7 | **OPM稳定或扩张** | 5年OPM波动<5pp 或持续上升? | 中 |
| T8 | **TAM扩张逻辑** | 市场本身在增长, 不是只靠抢份额? | 中 |
| T9 | **管理层利益一致** | 内部人持股>3% 或 制度化的资本纪律? | 中 |
| T10 | **零稀释文化** | SBC占收入<3%? 无增发? | 中 |

### 2B. 假阳性防御 (v0.5新增, 4项, 8分)

| # | 检查项 | 检查方法 | 防御对象 | 权重 |
|---|--------|---------|---------|------|
| FP1 | **定价权来源分类** | 来自(a)法律强制(b)行业标准=2分; (c)品牌(d)物理网络=1分; (e)信息不对称(f)专利=0分 | WU/Xerox | **最高** |
| FP2 | **客户价值/价格比** | 产品价格占客户决策总价值: <1%=2分, 1-5%=1分, >5%=0分 | Valeant | 高 |
| FP3 | **技术替代可能性** | 三问检测(见下): 无法想象替代=2分, 实验室阶段=1分, 已商业化=0分 | Kodak/WU | **最高** |
| FP4 | **定价权行使节制** | 历史最大单次提价: <20%/年=2分, 20-50%=1分, >50%=0分 | Valeant | 中 |

**v0.5评分体系**:
- 正面信号: T1-T10, 20分
- 防御信号: FP1-FP4, 8分
- **总分28分, 门槛>=17分 (61%)**
- **但FP1=0分 → 无论总分多高, 标记"定价权来源脆弱"红旗**
- **但FP3=0分 → 无论总分多高, 标记"技术替代风险"红旗**

### FP1: 定价权耐久性光谱

```
脆弱 <---------------------------------------------> 持久
0分                    1分                         2分

信息不对称    专利/许可    品牌忠诚    物理网络    行业标准    法律/监管强制
(WU早期)     (Xerox)     (Kodak)    (WU网点)   (MSCI指数)  (FICO+MCO)

可被:         到期/撤销    可被范式    可被数字     极难替代    需要立法
透明化消除                 替代       化替代                   才能改变
```

### FP3: 技术替代三问检测

```
问题1: 能否想象一种完全不同的技术实现同样的功能?
  FICO → 需要同等统计预测力+制度接受度 → 极难 → 2分
  Kodak → 数码摄影(1975年已发明) → 0分

问题2: 替代技术处于什么阶段?
  实验室 → 5-10年窗口(可投资但监控) → 1分
  已商业化/已规模化 → 0分

问题3: 替代是否需要同时改变多个制度/系统?
  FICO: 需改联邦法规+GSE政策+银行系统+历史数据 → 多制度依赖 → 2分
  胶卷: 只需更好硬件 → 单点突破 → 0分
```

## 第三层: 估值框架

### 3.1 基础估值 (沿用v0.4)

| 指标 | "好价格" | "合理" | "贵" |
|------|---------|--------|------|
| FCF Yield | > 5% | 3-5% | < 3% |
| EV/EBITDA vs 增长 | < CAGR*2 | CAGR*2-3 | > CAGR*3 |

### 3.2 PEG计算 (沿用v0.4)

```
纯收入增长型: PEG = P/E / Revenue CAGR (IDXX, CPRT)
利润弹性型:   PEG = P/E / EPS CAGR    (FICO, CTAS, 回购+提价型)
不确定时:     PEG = P/E / max(RevCAGR, EPS_CAGR*0.7)
```

### 3.3 定价权阶段判断系统 (v0.5新增)

**适用: 所有定价权驱动型公司(算法垄断/平台型)**

5个量化指标:

| 指标 | 公式 | 阶段1(买) | 阶段1.5(可买) | 阶段2(谨慎) |
|------|------|----------|-------------|-----------|
| **OPM位置比** | (当前OPM-行业均)/(天花板-行业均) | <30% | 30-60% | >70% |
| **市场认知度** | 当前EV/EBITDA / 5年均值 | <0.8x | 0.8-1.1x | >1.2x |
| **提价加速度** | 近3年有机CAGR / 前5年有机CAGR | <1.0x | 1.0-1.5x | >1.5x |
| **回购强度** | 年回购/年FCF | <50% | 50-100% | >100% |
| **监管关注度** | 定性0-10 | <2 | 2-5 | >5 |

**阶段-行动矩阵**:

| 综合阶段 | 估值要求 | 行动 |
|---------|---------|------|
| **阶段1** (<1.3) | 合理即可(PEG<2.5) | **重仓** — 极罕见的机会 |
| **阶段1.5** (1.3-1.7) | 需要"好价格"(PEG<1.5) | **建仓** — 但别期望10倍 |
| **阶段2** (1.7-2.3) | 只在大幅回调时(EV/EBITDA<5年均值*0.7) | **观察** — 等回调 |
| **阶段2.5** (>2.3) | — | **回避** — 上行空间有限 |

**验证**:

| 公司/时点 | OPM位置 | 认知度 | 提价加速 | 回购强度 | 监管 | 综合阶段 | 实际结果 |
|----------|---------|--------|---------|---------|------|---------|---------|
| FICO 2014 | 15% | 0.80x | 0.8x | 131% | 1 | **1.0** | 68x回报 ✓ |
| MSCI 2026 | 71% | 0.87x | 1.1x | 161% | 1 | **1.7** | 待观察 |
| FICO 2025 | 80% | 1.4x+ | 2.0x | 184% | 7 | **2.3** | 已充分定价 |

## 第四层: 三重增长引擎分解 (沿用v0.4)

```
EPS增长 = 收入增长 * OPM杠杆 * 回购效应

分析每家公司时必须分解:
  引擎1: Revenue CAGR → 来源(量增/价增/新市场)
  引擎2: OPM趋势 → 在扩张/稳定/趋平？距天花板多远？
  引擎3: 回购 → 年回购/FCF比例，股数缩减速度

三引擎同时发力 + 低估值 = 利润弹性型复利机器
```

## 复利机器原型 (v0.5: 7种 + 安全性检查)

| 原型 | 代表 | 核心引擎 | 可研究性 | 偏好 |
|------|------|---------|---------|------|
| **密度型** | ROL | 服务密度+经常性收入 | 高 | **强偏好** |
| **算法垄断型** | FICO/MSCI/MCO | 制度嵌入+定价权 | **极高** | **强偏好** |
| **耗材型** | IDXX/DCI | 安装基数->耗材复购 | 高 | **强偏好** |
| **安装基数型** | GE Avi | 设备交付->长期服务 | 高 | **强偏好** |
| **平台型** | VRSK | 数据垄断+网络效应 | 高 | **强偏好** |
| **服务扩展型** | CTAS | 客户基数*服务品类 | 中高 | **偏好** |
| **纯并购型** | CSU/HEI/DHR | 并购系统统计性质 | 低 | **回避** |

### 算法垄断型: 增长特征 + 安全性双重检查

```
增长特征 (必须全部满足):
  1. 零边际成本
  2. 制度嵌入 (监管/标准强制使用)
  3. 定价权期权
  4. OPM天花板极高 (理论60-70%)
  5. 利润弹性极强

安全性检查 (v0.5新增, 必须全部满足):
  6. FP1>=2 (定价权来自法律/监管/行业标准)
  7. FP2: 客户价值/价格比 <1%
  8. FP3>=1 (无已商业化的技术替代品)
  9. 底层市场增长或稳定 (非结构性萎缩)

  通过1-5但不通过6-9 = 类FICO陷阱 (WU/IBM就是这类)
```

### 五种失败模式速查

```
模式1: 定价权滥用 (Valeant) → FP4拦截
  信号: 单次提价>50%, 政治/媒体反弹

模式2: 制度嵌入被技术替代 (WU) → FP1+FP3拦截
  信号: 嵌入基于物理网络/信息不对称(非法律), 数字替代品已出现

模式3: 法律垄断到期 (Xerox) → FP1拦截
  信号: 定价权基于专利(有到期日), 非永久制度嵌入

模式4: 锁定但不增长 (IBM) → Q3+FP3拦截
  信号: 收入持续下降, 转换成本正在被新技术(AI)降低

模式5: 技术范式替代 (Kodak) → FP3拦截
  信号: 完全不同的技术路径已存在且在规模化
```
