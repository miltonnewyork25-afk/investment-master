# 选股品味框架 v0.4 — 假阳性案例研究

> **目的**: 识别"看起来像FICO但失败了"的公司，防止框架过拟合于成功案例
> **方法**: 反向验证——找到拥有定价权/制度嵌入但投资回报极差的公司，分析v0.4框架会在哪里被骗
> **日期**: 2026-03-06

---

|---|------|-----------|---------|---------|

## 案例 1: Valeant Pharmaceuticals — "定价权滥用陷阱"

### 鼎盛期画像 (2013-2015)

| v0.4指标 | Valeant表现 | 是否通过? |
|----------|------------|----------|
| G0 有机增长占比 | 并购驱动为主，但提价贡献大 | 边缘(模糊) |
| G1 商誉/总资产 | 极高(连续大型并购) | 不通过 |
| Q1 CapEx/Revenue | <5% (轻资产制药) | 通过 |
| Q3 Revenue CAGR | >30% (2011-2015爆发增长) | 通过 |
| Q5 ROIC | 4% (2013, GAAP) | 不通过 |
| Q7 净债务/EBITDA | >6x (高杠杆并购) | 不通过 |
| T2 转换成本 | 药品无替代品(sole-source) = 强制使用 | 通过(2分) |
| T4 定价权 | 极端：单药提价300%-1200% | 通过(2分) |
| T5 利润弹性 | EPS CAGR >> Revenue CAGR | 通过(2分) |
| T7 OPM扩张 | EBITDA margin表面极强 | 通过(2分) |

### 为什么失败?

1. **定价权≠可持续定价权**: Valeant的定价权来自"sole-source药品无替代品"，表面上像FICO(制度嵌入，客户必须用)。但FICO提价幅度温和(每年5-10%)，Valeant单次提价800%。**定价权的行使速度和幅度决定了它是资产还是负债。**

2. **政治反噬**: 药价暴涨引发国会听证、媒体风暴、监管介入。定价权被政治力量强制收回。FICO之所以安全，是因为评分费用对贷款总额微不足道($3.50 vs $300K贷款)，不会触发政治反弹。

3. **债务+并购=脆弱性**: 30亿美元债务用于支撑并购模型。当Philidor丑闻爆发，信用评级下调，再融资成本飙升，现金流无法覆盖利息。

4. **GAAP vs Non-GAAP操纵**: GAAP亏损$866M(2013)，Non-GAAP盈利$2B。三重引擎分析如果用Non-GAAP数据，会被严重误导。

### v0.4框架被骗的环节

- **T2(转换成本)和T4(定价权)会给满分**，因为sole-source药品确实具有极高粘性和定价权
- **T5(利润弹性)会给高分**，因为提价直接转化为利润
- **但G1(商誉)和Q7(杠杆)会阻断** — v0.4的硬指标在这里有效

### 关键教训

> **v0.4对Valeant的防御是有效的**(G1/Q7会拦截)，但如果遇到一个低杠杆版本的Valeant——有机增长+温和提价+低商誉——框架就会被骗。**缺失的检查项是"定价权行使的政治风险"和"客户价值/价格比"。**

## 案例 2: Western Union — "制度嵌入缓慢腐蚀陷阱"

### 鼎盛期画像 (2008-2015)

| v0.4指标 | WU表现 | 是否通过? |
|----------|--------|----------|
| G0 有机增长占比 | >90%有机 | 通过 |
| G1 商誉/总资产 | 可控 | 通过 |
| Q1 CapEx/Revenue | <5% (轻资产网络) | 通过 |
| Q2 FCF/NI | >100% | 通过 |
| Q3 Revenue CAGR | ~5-8% (2008-2015) | 边缘通过 |
| Q5 ROIC | 23% (顶级水平) | 通过 |
| Q7 净债务/EBITDA | 可控 | 通过 |
| T1 增长引擎 | 全球移民汇款量增长 | 通过(2分) |
| T2 转换成本 | 代理网点网络=物理嵌入 | 通过(2分) |
| T3 经常性收入 | 汇款是高频重复行为 | 通过(2分) |
| T4 定价权 | 比竞争对手贵15%仍保持市占 | 通过(2分) |
| T5 利润弹性 | 温和(OPM稳定) | 中等(1分) |
| T7 OPM | ~25%稳定 | 通过(1分) |

**品味评分预估: ~14-15/20 — 会通过v0.4筛选门槛(12分)**

### 为什么失败?

1. **制度嵌入的物理属性被数字化瓦解**: WU的护城河是55万个物理代理网点(便利店、邮局等)。这种"物理嵌入"看起来像FICO的"制度嵌入"，但本质不同——FICO嵌入的是监管规则(法律强制)，WU嵌入的是物理便利性(可被替代)。

2. **Wise/Remitly用10x更低费用+即时到账颠覆**: WU平均收费约10%，Wise收费<1%。当替代品的价值/价格比是10:1时，即使有转换成本，客户也会迁移。**WU的定价权不是来自不可替代性，而是来自信息不对称和替代品缺乏——这两者都是暂时的。**

3. **收入从2020年起每年下降3%**: 市占率从11%跌至8%，Wise市占率翻倍。过去5年总回报-40%，同期S&P 500 +92%，跑输132个百分点。

4. **2019年关闭旧金山数字办公室**: 在最需要数字化转型时削减数字团队。组织惯性杀死了转型可能。

### v0.4框架被骗的环节

- **所有硬指标(G0/G1/Q1-Q7)都会通过** — 这是最危险的案例
- **T2(转换成本)给高分**，但WU的转换成本是"物理便利"而非"制度强制"
- **T4(定价权)给高分**，但定价权来源是"替代品缺乏"而非"不可替代性"
- **T8(TAM扩张)会通过**，因为全球汇款市场确实在增长——但WU在增长的市场中萎缩

### 关键教训

> **v0.4对WU完全无防御。** 框架的致命盲点是：不区分定价权的来源类型。FICO的定价权来自监管强制(法律规定必须用FICO分数)，WU的定价权来自替代品缺乏(一旦出现更好的替代品就崩塌)。框架需要新增"定价权来源分类"检查。

## 案例 3: Xerox — "专利垄断到期陷阱"

### 鼎盛期画像 (1965-1975)

| v0.4指标 | Xerox表现 | 是否通过? |
|----------|----------|----------|
| G0 有机增长 | 100%有机 | 通过 |
| Q3 Revenue CAGR | 收入每10个月翻倍(1960s) | 通过 |
| Q5 ROIC | 极高(垄断定价) | 通过 |
| T2 转换成本 | 专利保护=法律垄断 | 通过(2分) |
| T4 定价权 | 84%市占率，无竞争对手 | 通过(2分) |
| T7 OPM | 极高 | 通过(2分) |
| 算法垄断原型 | 不适用(有物理产品) | 不匹配 |

### 为什么失败?

1. **1975年FTC强制许可专利**: 定价权的法律基础(专利)被监管行为直接摧毁。这与Valeant不同(政治反噬)，更接近"制度本身改变了规则"。

2. **日本竞争对手从低端切入**: Canon/Ricoh生产低成本、高质量复印机。Xerox的内部文化只与自己比较——"我们用旧Xerox的标准衡量新Xerox"——完全忽视外部竞争。市占率从96%→45%。

3. **成功的诅咒**: "Xerox核心业务的巨大盈利能力阻碍了公司开发周边机会。" Xerox PARC发明了GUI、鼠标、以太网——但全部被Apple和其他公司商业化。

### v0.4框架被骗的环节

- **鼎盛期的所有指标都会通过**，因为Xerox当时确实是完美的垄断企业
- **但框架没有检查"垄断的法律基础是否可被撤销"** — 专利会到期，监管会变化
- **框架没有检查"低端颠覆风险"** — 当竞争对手用50%的价格提供80%的功能时，定价权会从高端开始侵蚀

### 关键教训

> **Xerox揭示了一个框架盲点：定价权的时间维度。** FICO的制度嵌入理论上是永久的(只要美国信贷体系存在)。Xerox的专利保护有明确到期日。框架需要评估"定价权的有效期限"——是永久性制度嵌入，还是有时限的法律保护?

## 案例 4: IBM (主机业务) — "僵尸锁定陷阱"

### 鼎盛期画像 (2005-2012)

| v0.4指标 | IBM主机表现 | 是否通过? |
|----------|-----------|----------|
| T2 转换成本 | 极高：COBOL代码迁移成本$数十亿 | 通过(2分) |
| T4 定价权 | 每年MLC(月度许可费)涨价 | 通过(2分) |
| T5 利润弹性 | 收入下降但利润率维持(提价弥补量缩) | 表面通过 |
| 制度嵌入 | 操作系统绑定硬件=单一供应商生态 | 通过 |

**IBM主机在v0.4的"算法垄断型"原型检查中得分极高**: 零边际成本(软件授权)、制度嵌入(数十年COBOL代码)、定价权(每年涨价)。

### 为什么失败?

1. **收入衰退的定价权 = 慢性死亡**: IBM收入从$107B(2011)→$57B(2021)，下降47%。22个季度连续收入同比下降。即使有定价权(每年涨价)，也无法抵消客户基数的流失。**定价权 x 萎缩的客户基数 = 不增长。**

2. **锁定≠增长**: IBM的转换成本极高(迁移COBOL代码可能需要数年和数十亿美元)，但这只是"延缓流失"而非"驱动增长"。FICO的嵌入驱动增长(信贷市场扩大→评分量增加)，IBM的锁定只阻止现有客户离开。

3. **2026年新威胁——AI代码迁移**: Anthropic的COBOL现代化工具在2026年2月23日演示后，IBM股价单日下跌7.4%。数十年来被认为"不可颠覆"的锁定，可能被AI工具在几年内瓦解。**技术变革可以降低转换成本。**

4. **股价表现**: 2012-2022年IBM下跌34%，同期S&P 500上涨175%。跑输近210个百分点。

### v0.4框架被骗的环节

- **算法垄断型原型检查会给高分**: 零边际成本、制度嵌入、定价权——全部符合
- **T2(转换成本)和T4(定价权)满分**
- **但Q3(Revenue CAGR >8%)不会通过** — IBM收入连年下降，这是硬拦截
- **v0.4的T8(TAM扩张)也不会通过** — 主机市场在萎缩

### 关键教训

> **IBM暴露了"定价权+制度嵌入"公式的第二个必要条件：底层市场必须增长或至少稳定。** FICO成功是因为美国信贷市场持续扩大(评分量增长)。IBM失败是因为主机市场在萎缩(新工作负载选择云而非主机)。**v0.4的Q3(Revenue CAGR)和T8(TAM扩张)可以拦截IBM，但如果一家公司暂时还在增长、TAM表面还在扩张，框架就可能遗漏"TAM见顶"的信号。**

## 案例 5: Kodak — "技术范式替代陷阱"

### 鼎盛期画像 (1975-1995)

| v0.4指标 | Kodak表现 | 是否通过? |
|----------|----------|----------|
| G0 有机增长 | >90%有机 | 通过 |
| T2 转换成本 | 品牌忠诚度极高(50%只买Kodak，40%偏好Kodak) | 通过(2分) |
| T4 定价权 | 定价是边际成本的2倍，Fuji便宜10%仍抢不走份额 | 通过(2分) |
| T3 经常性收入 | 胶卷=耗材模型(高频复购) | 通过(2分) |
| OPM | 高利润率 | 通过 |
| 市占率 | 彩色胶卷>90% | 通过 |

**Kodak在v0.4的耗材型原型中得分极高**: 安装基数(相机)→耗材复购(胶卷)→冲印服务，完美的三级复利引擎。

### 为什么失败?

1. **数字摄影消灭了整个产品类别**: 不是竞争对手抢份额，而是底层技术范式替代。Kodak自己1975年就发明了数码相机，但因为"胶卷业务太赚钱"而压制数字化。

2. **定价权在范式替代面前毫无意义**: Kodak能对Fuji维持10%溢价——但当iPhone拍照免费时，10%溢价就是个笑话。**定价权只在同一技术范式内有效。跨范式时，定价权=零。**

3. **2012年破产**: 从全球最有价值品牌之一到破产，用了不到15年。

### v0.4框架被骗的环节

- **耗材型原型满分**: 安装基数+高频复购+品牌溢价——与IDXX完美匹配
- **T4(定价权)满分**: 需求弹性仅2(非常强的定价权)
- **T8(TAM扩张)在1990年代仍会通过**: 全球摄影市场还在增长(数码相机增长掩盖了胶卷见顶)
- **框架完全没有"技术范式替代风险"检查**

### 关键教训

> **Kodak是最极端的假阳性: 在被颠覆前的每一个时刻，它都完美通过v0.4所有筛选。** 定价权极强、制度嵌入(冲印网络)、耗材复购、品牌垄断——全部勾选。失败原因不在任何现有检查项的范围内，而是技术范式的非连续变化。FICO安全是因为"信用评分"这个概念没有技术替代品(至少目前没有)。Kodak不安全是因为"胶卷摄影"有明确的技术替代品。

## 假阳性模式提炼

### 五种失败模式

```
模式1: 定价权滥用 (Valeant)
  特征: 定价权真实存在，但行使速度/幅度触发政治/监管反噬
  v0.4拦截能力: 中等 (G1/Q7可拦截高杠杆版本，但低杠杆版本会通过)

模式2: 制度嵌入被技术替代 (Western Union)
  特征: 嵌入基于物理网络/信息不对称，而非法律强制
  v0.4拦截能力: 极低 (所有硬指标通过，品味评分14-15/20)

模式3: 法律垄断到期 (Xerox)
  特征: 定价权基于有时限的法律保护(专利/独占许可)
  v0.4拦截能力: 低 (鼎盛期全部通过，框架不检查垄断有效期)

模式4: 锁定但不增长 (IBM主机)
  特征: 转换成本极高但底层市场萎缩，定价权只延缓死亡
  v0.4拦截能力: 中高 (Q3 Revenue CAGR会拦截，但仅在收入已经下降后)

模式5: 技术范式替代 (Kodak)
  特征: 整个产品类别被新技术消灭，定价权在跨范式时失效
  v0.4拦截能力: 极低 (在被颠覆前所有指标完美通过)
```

### 核心发现: 定价权来源分类

v0.4框架把所有"定价权"同等对待，但实际上定价权有完全不同的来源和持久性:

```
定价权耐久性光谱 (从弱到强):

脆弱 ←————————————————————————→ 持久

信息不对称   专利/许可    品牌忠诚    物理网络    行业标准    法律/监管强制
(WU早期)    (Xerox)     (Kodak)    (WU网点)   (FICO分数)  (FICO+MCO)

可被:        到期/撤销    可被范式     可被数字     极难替代     需要立法
透明化消除               替代        化替代                   才能改变
```

**FICO处于光谱最右端**: 美国信贷法规、巴塞尔协议、Fannie Mae/Freddie Mac政策全部嵌入FICO分数。替代FICO需要同时改变联邦法规+GSE政策+银行风控系统+数十年的模型校准数据。这不是单一公司或技术能颠覆的。

## 假阳性防御清单 (v0.5建议新增)

### 新增检查项

| # | 检查项 | 检查方法 | 防御的失败模式 | 权重 |
|---|--------|---------|---------------|------|
| **FP1** | **定价权来源分类** | 定价权来自: (a)法律/监管强制 (b)行业标准 (c)品牌 (d)物理网络 (e)信息不对称 (f)专利? 只有(a)(b)是高持久性。 | WU/Xerox/Kodak | **最高** |
| **FP2** | **客户价值/价格比** | 产品价格占客户决策总价值的比例。<1%=安全(FICO)，>5%=政治风险(Valeant) | Valeant | 高 |
| **FP3** | **定价权行使节制度** | 历史最大单次提价幅度。<20%/年=温和，>50%=滥用风险 | Valeant | 高 |
| **FP4** | **技术替代可能性** | 是否存在能用完全不同技术实现相同功能的路径? "无法想象替代品"=安全，"已有早期替代品"=危险 | Kodak/WU |  高 |
| **FP5** | **TAM是否有结构性天花板** | 底层市场是否在萎缩或面临范式替代? 区分"市场增长"vs"公司在增长的市场中增长" | IBM/Kodak | 中 |
| **FP6** | **垄断有效期限** | 垄断基础是永久性的(制度嵌入)还是有时限的(专利20年/独占许可可撤销)? | Xerox | 中 |
| **FP7** | **转换成本是否可被技术降低** | AI/自动化/开源工具是否正在降低客户的迁移成本? (IBM COBOL→AI迁移案例) | IBM | 中 |

### FP1 定价权来源分类 — 详细评分框架

```
评分: 0-2分

2分(强持久): 法律/监管强制 + 行业标准双重嵌入
  - FICO: 联邦法规+GSE政策+巴塞尔协议 = 三重制度嵌入
  - MCO/SPGI: SEC认证NRSRO + 债券发行惯例 = 双重制度嵌入

1分(中等持久): 单一来源，但根深蒂固
  - 品牌垄断(需30年+行业标准地位)
  - 物理网络(需数万节点的规模效应)

0分(脆弱): 信息不对称 / 专利(有到期日) / 替代品暂时缺乏
  - WU: 替代品缺乏 → Wise出现后定价权崩塌
  - Xerox: 专利 → FTC强制许可后市占率腰斩
  - Valeant: sole-source但无制度嵌入 → 政治反噬
```

### FP2 客户价值/价格比 — 安全区判断

```
安全区 (价格占客户决策总价值 <1%):
  - FICO: $3.50评分费 / $300,000贷款 = 0.001% → 极安全
  - MSCI: 指数授权费 / 管理资产规模 = <0.1% → 安全
  - MCO: 评级费 / 债券发行总额 = <0.1% → 安全

警戒区 (1%-5%):
  - 需要关注但不一定危险

危险区 (>5%):
  - Valeant: 药价 / 患者收入 = 可能>10% → 政治不可持续
  - WU: 汇款费 / 汇款金额 = ~10% → 被低价替代品颠覆
```

### FP4 技术替代可能性 — 三问检测

```
问题1: 能否想象一种完全不同的技术实现同样的功能?
  - FICO评分 → 替代品? 需要同等统计预测力+制度接受度 → 极难
  - 胶卷摄影 → 数码摄影 → 显然可以，且1975年已发明
  - 物理汇款网点 → 数字转账 → 显然可以

问题2: 如果存在替代技术，它目前处于什么阶段?
  - 实验室阶段 → 5-10年窗口(可投资但需监控)
  - 商业化早期 → 3-5年窗口(高度警惕)
  - 规模化阶段 → 已经太迟

问题3: 替代品是否需要同时改变多个制度/系统才能生效?
  - FICO: 需改变联邦法规+GSE政策+银行系统+历史数据 → 多制度依赖=高壁垒
  - Kodak胶卷: 只需要更好的硬件 → 单一技术突破即可替代=低壁垒
```

## 对v0.4框架的修订建议

### 修改优先级

| 优先级 | 修改 | 理由 |
|--------|------|------|
| **P0** | 新增FP1(定价权来源分类)到第二层品味判断，权重=最高 | WU案例证明不区分来源会导致严重假阳性 |
| **P0** | 新增FP4(技术替代可能性)到第二层 | Kodak案例证明所有现有指标对范式替代完全无防御 |
| **P1** | 新增FP2(客户价值/价格比)到第二层 | Valeant案例证明高价值/价格比=政治风险 |
| **P1** | 新增FP3(定价权行使节制度)到第二层 | 区分温和提价(可持续)vs激进提价(触发反噬) |
| **P2** | 新增FP5-FP7作为附加检查 | IBM/Xerox案例的次要教训 |

### 修改后的品味评分体系 (建议)

```
现有T1-T10 (20分) + 新增FP1-FP4 (8分) = 总分28分
门槛: >=17/28 (61%)

关键变化:
- FP1-FP4是"否决票"性质: FP1=0分 → 即使总分>=17也标记高风险
- 这模拟了真实世界中"一个致命缺陷可以否定所有优势"的投资逻辑
```

### 算法垄断型原型 — 增加安全性检查

```
现有描述:
  1. 零边际成本 ✓
  2. 制度嵌入 ✓
  3. 定价权期权 ✓
  4. OPM天花板极高 ✓
  5. 利润弹性极强 ✓

新增安全性检查:
  6. 定价权来源 = 法律/监管强制 (FP1≥2)
  7. 客户价值/价格比 <1% (FP2=安全区)
  8. 无可见技术替代路径 (FP4问题1="极难想象")
  9. 底层市场增长或稳定 (FP5=无结构性天花板)

  只有同时满足1-5(增长特征)和6-9(安全特征)的公司
  才是真正的"FICO型"算法垄断。

  满足1-5但不满足6-9的公司 = 类FICO陷阱。
```
