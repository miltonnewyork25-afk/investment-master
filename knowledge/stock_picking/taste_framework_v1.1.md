# 选股品味框架 v1.1

> **起源**: 10成功案例(HEI/DHR/CSU/GE/FICO/Visa/IDXX/ROL/CTAS/CPRT) + 1平庸案例(FAST) + 5失败案例 + MSCI对标
> **v1.1核心升级**: FAST"品质满分但品味平庸"反面教材 + "锁定不等于定价权"四象限 + 分销业OPM天花板~20% + 股息复利路径
> **触发**: FAST品质筛选7/7但品味仅19/28(框架最低)。13万台售货机创造了客户锁定但零定价权→11年OPM完全平坦(20%)→T5a=0.95x。关键教训: 好公司不等于好投资, 锁定不等于定价权。

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.3-v1.0: (沿用)
v1.1: **品质筛选全通过的公司不一定是好投资。FAST品质7/7(零商誉、零SBC、零收入下降、ROIC 28%)但品味仅19/28, 11年回报~3.4x(不含股息)。差距来自T4/T5/T7: 无定价权、无操作杠杆、OPM零扩张。更深层: 售货机锁定了"渠道"但没锁定"定价" — 锁定创造留存率, 但只有锁定标准/制度/运营才创造定价权。品质是门票, 品味才是回报的决定因素。**

### v1.1的认知升级

```
v1.0思维: "售货机在客户现场 → 深度锁定 → 定价权 → OPM扩张"
v1.1思维: "售货机锁定的是渠道(从哪买), 不是产品(买什么)
          → 紧固件是标准品, 价格透明, B2B采购经理可比价
          → 售货机让员工'习惯性'从FAST取货, 但采购经理仍能切换供应商
          → 结果: 客户留存率高(防守), 但无法超额涨价(进攻)
          → 11年OPM平坦(20%)是铁证 — 售货机 ≠ 定价权"

v1.0思维: "品质筛选全通过 = 值得投资"
v1.1思维: "品质是必要条件, 品味才是充分条件
          → FAST: 品质7/7 + 品味19/28 → 回报3.4x(平庸)
          → FICO: 品质7/7 + 品味25/28 → 回报68x(卓越)
          → 差距完全来自品味(T4/T5/T7: 定价权+利润弹性+OPM扩张)
          → 框架的价值不在品质筛选(只是过滤), 而在品味判断(真正选股)"

v1.0思维: "锁定越强 → 定价权越强"
v1.1思维: "锁定类型决定是否有定价权, 锁定强度只决定留存率
          → 锁定标准/制度(FICO): 客户没有替代品 → 定价权极强
          → 锁定运营(CTAS): 切换成本指数增长 → 定价权强
          → 锁定网络(CPRT): 去别处卖=价格更低 → 中等定价权
          → 锁定渠道/习惯(FAST): 采购经理仍可比价 → 弱定价权
          → 锁定≠定价权, 关键看锁定的是什么"
```

### T5详细分析

```
T5a(操作杠杆):
  Rev CAGR 7.4%, OI CAGR 7.0% → T5a = 0.95x → 得分=0.5分(有惩罚)

  OPM分解:
    毛利率: 50.8%(2014) → 45.0%(2025) → -580bps!
    SG&A/Rev: 29.8%(2014) → 24.8%(2025) → -500bps
    → 毛利率下降被SG&A效率提升几乎完全抵消 → OPM平坦

  毛利率为什么下降?
    产品结构变化: 从高毛利紧固件 → 更多低毛利工业品(安全用品等)
    售货机推广: 售货机增加了低毛利标准品的占比
    → 矛盾的发现: 售货机扩展了收入但降低了毛利率!

  SG&A为什么下降?
    运营效率: 售货机替代了部分人力配送
    规模杠杆: 更多收入摊薄固定SG&A
    → 售货机的真实价值在这里: 降低运营成本, 不是提高定价

  OPM天花板分析:
    当前OPM: 20.2%
    毛利率趋势: 继续温和下降(产品结构变化)
    SG&A趋势: 继续温和下降(数字化+售货机)
    → OPM天花板: ~21-22% (毛利率下降 ≈ SG&A下降 → 净效果≈0)
    → 与ROL(20-22%)相同区间 → 分销业结构性天花板

T5b(资本效率):
  CapEx/Rev=3.0% → +0分
  FCF/NI=82% → +0分
  Rev下降0次 → +1分
  T5b=1.0分

T5最终 = max(T5a→0.5分, T5b→1.0分) = 1.0分
(T5b救了FAST — 资本效率尚可, 但操作杠杆确实为负)
```

## 锁定类型四象限 (v1.1核心框架升级)

```
                    定价权强
                      |
          ②制度/标准锁定     ①运营/生态锁定
          (FICO, MSCI)       (CTAS, IDXX)
          T5a>2.0x            T5a 1.5-1.7x
          OPM持续扩张          OPM温和扩张
          回报: 68x            回报: 9-14x
                      |
    锁定弱 ————————————+———————————— 锁定强
                      |
          ④无锁定/弱锁定       ③渠道/习惯锁定
          (一般消费品)          (FAST)
          T5a视行业而定         T5a≈1.0x
          OPM取决于品牌         OPM平坦
          回报: 不确定           回报: ~3.4x(+股息)
                      |
                    定价权弱

关键洞察:
  象限①②: 锁定创造定价权 → OPM扩张 → 超额回报
  象限③: 锁定创造留存率但不创造定价权 → OPM平坦 → 平庸回报
  象限④: 无锁定 → 取决于其他因素(品牌/成本优势等)

FAST位于象限③: 有锁定(13万售货机)但无定价权(标准品, 价格透明)
→ 售货机是"渠道锁定"而非"标准锁定"
→ 渠道锁定只防守(留存), 不进攻(涨价)

框架规则: 评估锁定时, 必须区分"锁定类型":
  标准锁定(①②): 客户没有替代选择 → 可涨价
  运营锁定(①②): 切换成本极高 → 可涨价
  网络锁定(①②): 去别处卖价更低 → 可适度涨价
  渠道锁定(③): 采购经理仍可比价 → 不可超额涨价
```

## 复利路径 (v1.1: 更新为4+1路径)

```
路径A: OPM弹性型 (FICO) — 定价权→OPM持续扩张 → 68x
路径B: 资本效率型 (ROL) — 低CapEx+并购循环 → 7x
路径C: 密度×交叉销售型 (CTAS) — OPM温和扩张+增长 → 14x
路径D: 网络效应+物理壁垒型 (CPRT) — OPM先扩后稳+Rev增长 → 10x
路径E: 股息复利型 (FAST) — OPM平坦+高派息 → 3.4x(+股息≈5x总)

路径E特征:
  T5a: <1.0x (零操作杠杆)
  OPM: 平坦, ~20%
  FCF部署: 80%派息, 极少回购/并购
  回报构成: Rev增长7% + 股息2% + P/E扩张(不确定) ≈ 9-15%
  适用场景: 低风险配置, 收入型投资者
  不适用: 追求超额回报的成长型投资者

路径E vs 路径B对比:
  同为OPM平坦~20%, 但FCF部署不同:
  路径B(ROL): FCF→tuck-in M&A→倍数套利(3-5x买入 vs 35x交易)→回报7x
  路径E(FAST): FCF→80%股息→无倍数套利→回报3.4x(+股息)
  → 资本循环 >> 股息 作为长期价值创造方式
  → ROL管理层的M&A纪律创造了额外回报
```
