# 选股品味框架 v1.0

> **起源**: 9成功案例(HEI/DHR/CSU/GE/FICO/Visa/IDXX/ROL/CTAS) + 5失败案例 + MSCI对标 + CPRT物理基础设施市场
> **v1.0核心升级**: CPRT"网络效应+物理壁垒"双重垄断模型 + 品质筛选CapEx质量修正 + 第四条复利路径 + 护城河网络效应维度首次满分 + OPM天花板7级分类
> **触发**: CPRT 11年10x(22% CAGR), 品质筛选Q1/Q2首次未通过但回报优秀。关键发现: 高CapEx可以是护城河投资而非资本消耗, 框架需要区分"好的CapEx"和"坏的CapEx"。

---

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.3-v0.9: (沿用)
v1.0: **不是所有高CapEx都是坏生意。CPRT CapEx/Rev=12%(远超框架5%门槛), 但ROIC=29%, 因为CapEx投入的是土地银行(升值+不可复制)而非折旧设备。品质筛选需要区分"护城河投资"和"资本消耗"。同时, CPRT是框架首个同时拥有数字网络效应(买家-卖家双边市场)和物理资产壁垒(300+自有场地)的公司 — 护城河得分20/30, 框架最高。**

### v1.0的认知升级

```
v0.9思维: "低CapEx = 好生意, 高CapEx = 避开"
v1.0思维: "CapEx质量比CapEx数量更重要
          → CPRT CapEx/Rev=12%, 但投向土地银行(升值+不可复制)
          → 维护性CapEx仅4.6%(≈D&A), 增长性CapEx 7.6%投向护城河
          → ROIC=29%证明每一美元CapEx都在创造价值
          → 品质筛选需要新增'CapEx质量'修正因子
          → 同理, FCF/NI=79%看似差, 但维护性FCF/NI=102%"

v0.9思维: "护城河=制度嵌入+规模+密度, 网络效应在框架里存在但从未满分"
v1.0思维: "CPRT的双边网络效应是最强的护城河类型
          → 更多买家→更高ASP→更多卖家→更多车辆→更多买家
          → 这是正反馈循环, 随时间自我强化
          → 与FICO的制度嵌入不同: FICO靠规则垄断, CPRT靠价值垄断
          → 买家选择CPRT因为价格最高, 不是因为法规要求
          → 这种垄断更'自然', 也更难打破"

v0.9思维: "OPM扩张公司=好(FICO/CTAS), OPM平坦=也行(ROL)"
v1.0思维: "OPM有两阶段周期: 扩张期和稳定期
          → CPRT: 23.6%→42.2%(7年)→36.5%(4年回落)
          → Phase 1(平台转型): OPM爆发式扩张, T5a>2.0x
          → Phase 2(成熟运营): OPM回落至天花板下方, 靠Rev驱动
          → 最佳投资时机=Phase 1早期(识别平台转型+网络效应萌芽)
          → 当前Phase 2: 回报率回归13-15%(仍然很好, 但不再是22%)"
```

### T5详细分析

```
T5a(操作杠杆):
  完整周期 (FY2014→FY2025, 11Y):
    Rev CAGR: (4647/1163)^(1/11) - 1 = 13.4%
    OI CAGR:  (1697/275)^(1/11) - 1 = 18.0%
    T5a = 18.0% / 13.4% = 1.34x → 得分=1.5分

  分阶段:
    Phase 1 (FY2014→FY2021):
      Rev CAGR 12.8%, OI CAGR 22.4% → T5a = 1.75x (爆发期)
    Phase 2 (FY2021→FY2025):
      Rev CAGR 14.6%, OI CAGR 10.5% → T5a = 0.72x (压缩期)

OPM两阶段分析:
  Phase 1 (FY2014→FY2021): 23.6% → 42.2% (+1860bps)
    a. 线上拍卖转型: ~800bps (消除实体拍卖场地运营成本)
    b. 平台规模杠杆: ~400bps (SG&A/Rev从14.1%→7.7%)
    c. 网络效应成熟: ~400bps (更多买家→更高ASP→更高利润率)
    d. 国际初始贡献: ~260bps (早期高增长市场)

  Phase 2 (FY2021→FY2025): 42.2% → 36.5% (-570bps)
    a. 毛利率下降: ~470bps (车辆处理成本↑, 劳动力/燃料通胀)
    b. SG&A保持平坦: ~0bps
    c. 国际扩张前期拖累: ~100bps

  天花板估计:
    毛利率稳态: ~45% (FY2023-FY2025稳定)
    SG&A/Rev趋势: ~7.5% (持续缓慢下降)
    OPM天花板: ~37-38%
    → 当前36.5%已接近天花板, 剩余空间仅~1-2pp
    → 与FICO(天花板65%, 当前还在扩张)完全不同

  剩余弹性空间:
    当前OPM: 36.5%
    天花板: ~37-38%
    剩余弹性: (37.5-36.5)/36.5 = 2.7%
    → 极小弹性 → T5未来贡献趋近于0
    → 未来EPS增长 ≈ Rev CAGR + 温和回购 ≈ 13-15%

T5b(资本效率):
  CapEx/Rev=12.2% → 高(但CapEx质量好)
  FCF/NI=79% (维护性FCF/NI=102%) → 修正后正常
  Rev下降1次 → +0.5分
  T5b=0.5分

T5最终 = max(T5a→1.5分, T5b→0.5分) = 1.5分

CPRT T5=1.5分的含义:
  OPM扩张红利已大部分释放(23.6%→36.5%, 净+1290bps)
  未来操作杠杆有限(天花板~37-38%, 剩余~1-2pp)
  但Rev CAGR=13.4%仍然优秀(ADAS+国际+新品类三引擎)
  → CPRT从"利润+增长双驱"正在转变为"纯增长驱动"
```

### 护城河评分

| 维度 | CPRT评分 | 解释 |
|------|---------|------|
| 制度嵌入 | **3**(深度IT集成) | 保险公司理赔系统与CPRT API对接, 工作流深度嵌入; 但非法规强制 |
| 网络效应 | **5**(双边市场主导) | **框架首个满分**: 175K+全球买家→最高ASP→保险公司首选→更多车辆→买家更多。IAA(#2)被RB Global收购后份额持续流失。赢家通吃趋势明确 |
| 生态锁定 | 2(单一服务) | 主要做车辆拍卖, 无CTAS式多服务叠加锁定 |
| 数据飞轮 | **3**(定价智能) | 百万级拍卖历史数据→AI估价(IntelliSeller)→更准确定价→保险公司信任→更多委托 |
| 规模经济 | **4**(产能壁垒) | 300+自有场地+拖车车队, PPE $3.7B, 复制成本$3B+且需要5-10年 |
| 密度经济 | **3**(拖车半径优势) | 场地密度决定拖车时效(保险公司要求24-48h内拖走), 区域密度领先→成本更低+服务更快 |
| **总计** | **20/30** | **框架最高分** |

**CPRT护城河的独特性**: 唯一同时拥有"数字网络效应(5分)"和"物理规模壁垒(4分)"的公司。

```
护城河"双重垄断"模型:

  需求侧垄断(网络效应):
    175K+全球买家 → 竞争性出价 → ASP最高
    → 保险公司选择CPRT = 回收价值最大化
    → 新进入者无法提供同等买家密度 → 无法提供同等ASP
    → 护城河随买家数量增加而加深(正反馈)

  供给侧垄断(物理资产):
    300+自有场地(多数是购买而非租赁)
    → 土地稀缺(城市边缘工业用地, 需要环保/分区许可)
    → 复制需要$3B+资本 + 5-10年许可/建设时间
    → 新进入者即使有钱也无法快速获取足够场地
    → 护城河随土地积累而加深(先发优势)

  双重垄断互相强化:
    更多场地 → 更广地理覆盖 → 更多保险公司委托 → 更多车辆
    更多车辆 → 更多买家被吸引 → 更高ASP → 更多保险公司信任
    → 正反馈循环, 且两层都有物理壁垒/网络壁垒保护
```

### 攻击面与耐久性

```
攻击点1: RB Global (收购IAA后的#2)
  当前: IAA整合中, 管理层动荡, 份额流失给CPRT
  威胁: 中低 — 网络效应的赢家通吃特性 → 长期份额差距扩大
  关键: CPRT买家数量175K+ >> IAA, ASP差距意味着保险公司会持续转向CPRT

攻击点2: 保险公司自建/集体平台
  当前: 无任何迹象
  威胁: 极低 — 自建平台缺乏买家网络, ASP会大幅低于CPRT
  → 保险公司理性选择: 用CPRT获得最高回收价 >> 自建平台省佣金
  → Visa类比: 银行也曾想自建支付网络, 最终都回到Visa/MA

攻击点3: ADAS/自动驾驶减少事故
  实际效果: ADAS增加total loss率! (传感器/摄像头/LiDAR维修太贵 → 修不如赔)
  威胁: 5-10年内是利好; L4/L5(15-20年后)不确定
  数据: 2015年total loss率≈15% → 2024年≈22% → 趋势加速

攻击点4: 电动车(BEV)
  实际效果: BEV total loss率高于ICE(电池损坏→全车报废)
  威胁: 中性偏利好 — CPRT已投资EV专用处理设施

攻击点5: 经济衰退
  历史: FY2020 COVID → Rev仅+8%(增速放缓但未下降!)
  → 事故是刚需, 经济周期影响极小
  → FY2015 Rev -1.5%是唯一下降(特殊因素, 非经济衰退)

耐久性: A级 — 双重垄断(网络+物理) + 攻击面多为利好
```

## 品质筛选框架修正 (v1.0新增: CapEx质量因子)

```
v0.9规则:
  Q1: CapEx/Rev <5% → 通过
  Q2: FCF/NI 5Y avg >80% → 通过
  (一刀切, 不区分CapEx性质)

v1.0修正:
  Q1原始判断: CapEx/Rev <5%
  Q1修正判断: 如果不通过, 检查以下CapEx质量条件:
    a. CapEx主要投向升值/不可替代资产? (土地/网络基础设施)
    b. ROIC > 20%? (证明CapEx创造价值)
    c. 维护性CapEx(≈D&A)/Rev < 8%? (剔除增长投资后可接受)
    → 三项全部满足 → Q1"CapEx质量豁免", 标注通过*

  Q2原始判断: FCF/NI 5Y avg >80%
  Q2修正判断: 如果不通过, 计算维护性FCF:
    维护性FCF = OCF - 维护性CapEx(≈D&A)
    维护性FCF/NI >80%? → Q2"CapEx质量豁免", 标注通过*

  CPRT验证:
    Q1: CapEx/Rev=12.2% → 不通过 → 检查:
      a. 土地银行(升值+不可复制) ✓
      b. ROIC=29% ✓
      c. 维护性CapEx/Rev=4.6% ✓ → 三项全通过 → Q1通过*
    Q2: FCF/NI=73% → 不通过 → 维护性FCF/NI=102% → Q2通过*

  框架意义:
    "低CapEx≠好生意, 高CapEx≠坏生意"
    关键是CapEx创造了什么: 折旧资产(坏) vs 升值护城河(好)
    CPRT每年投入$350M+买土地 → 土地升值+场地不可复制 → 护城河加深
    ROL每年CapEx仅$30M → 但ROL的护城河来自密度+品牌, 不需要物理资产
    → 不同商业模式有不同的"好CapEx"形态
```

## 复利路径四分法 (v1.0: 从三分法升级)

```
             路径A:               路径B:               路径C:               路径D:
           OPM弹性型           资本效率型          密度×交叉销售型      网络效应+物理壁垒型
          (利润驱动)           (增长驱动)          (利润+增长双驱)     (先利润后增长)

典型代表    FICO 2014           ROL                  CTAS                 CPRT
T5a         > 1.5x              ≈ 1.0x               ~1.5-1.8x            ~1.3x(全周期)
OPM天花板   60-70%              20-22%               25-28%               37-42%
OPM当前     65%(接近)          19%(已到)            23%(在扩张)          37%(接近)
CapEx强度   3-5%                < 1%                 3-5%                 10-15%
FCF/NI      80-100%             > 120%               90-100%              70-80%(维护性>100%)
增长来源    提价>>量增           量增+并购>>提价       交叉销售+密度+提价    TAM扩展+国际+新品类
OPM趋势    持续大幅扩张         平坦                  温和持续扩张          先爆发后稳定
回报潜力    极高(68x)           中高(7x)             高(14x)              高(10x)
可预测性    中(何时提价?)       高(极稳)             高(渗透率可追踪)      高(总损率趋势明确)
下行风险    中(监管)            低(刚需)             低(多服务锁定)        低(事故是刚需)
最优买点    市场未认知时          P/E压缩时             持续配置(长青型)      Phase 1早期(平台转型时)

路径D的独特特征:
  1. OPM两阶段周期: 先爆发式扩张(+1860bps/7年) → 再稳定/温和压缩
  2. 高CapEx但高回报: CapEx/Rev=12%但ROIC=29%, CapEx创造不可复制资产
  3. 双重垄断护城河: 网络效应(数字)+物理壁垒(土地), 互相强化
  4. 护城河随时间加深: 买家越多→ASP越高→卖家越多(网络效应) + 场地越多→覆盖越广(物理壁垒)
  5. 投资节奏: Phase 1买入最佳(识别网络效应萌芽), Phase 2仍好但回报率下降

最佳组合配置(v1.0更新):
  路径A(FICO型): 高赔率 — 找到下一个"未认知定价权期权"
  路径B(ROL型): 高胜率 — 极低风险的稳定复利
  路径C(CTAS型): 赔率+胜率均高 — 最优风险调整后回报
  路径D(CPRT型): 护城河最深 — 双重垄断+TAM世俗扩张, 但CapEx吃FCF
```

## OPM天花板分类 (v1.0: 从5级→7级)

```
Tier 1: 零边际成本-制度垄断(FICO/MSCI): 60-70%
Tier 2: 零边际成本-网络垄断(Visa/MA): 60-66% (受监管约束)
Tier 3: 物理基础设施市场(CPRT): 37-42% ← v1.0新增
Tier 4: 低边际成本-耗材型(IDXX/DCI): 35-42%
Tier 5: 中边际成本-可扩展收入(CTAS): 25-28%
Tier 6: 中边际成本-固定收入(ROL): 20-22%
Tier 7: 高边际成本(传统制造): 15-20%

CPRT(Tier 3)的天花板决定因素:
  上限: 毛利率~45%(车辆拖运/存储/检验有刚性物理成本)
  杠杆: SG&A可压缩至~7%(平台技术替代人力)
  → 天花板 ≈ 45% - 7% = ~38%, 实测峰值42%(COVID效率加成)

  vs Tier 1(FICO 60-70%): FICO几乎无物理运营成本
  vs Tier 4(IDXX 35-42%): 类似区间, 但CPRT靠网络效应而非安装基数
  vs Tier 5(CTAS 25-28%): CTAS有劳动密集的洗涤/配送成本, CPRT拍卖环节低成本

  关键: CPRT的天花板由"物理操作成本"决定, 不是由"定价权"决定
  → 与FICO不同(FICO天花板由"客户承受力"决定)
  → CPRT要提高天花板, 需要降低物理成本(自动化/AI), 而非提价
```

### 物理基础设施市场型: 完整模型 (v1.0新增)

```
商业模型:
  数字层: 双边拍卖市场平台(买家↔卖家)
  物理层: 300+自有场地(土地银行) + 拖车网络 + 车辆存储/检验
  两层互相强化: 更多场地→更广覆盖→更多保险公司委托→更多车辆→更多买家

增长引擎:
  1. TAM世俗扩张 (~5-8%/年)
     ADAS维修成本↑ → total loss率从15%→22%趋势性上升
     每年美国全损车辆: ~6M台 → 趋势↑
  2. 国际扩展 (~3-5%/年)
     欧洲(英德西芬兰巴林)市场仍处早期
     亚洲/拉美几乎未触及
  3. 新品类 (~1-2%/年)
     Purple Wave: 建筑/农业设备拍卖
     PowerSports: 摩托车/水上摩托
  4. 定价/费率提升 (~2-3%/年)
     买家溢价率逐年温和提升
  合成: 12-15% Rev CAGR + ~1.0x操作杠杆 = 12-15% EPS CAGR (Phase 2)

网络效应飞轮:
  保险公司委托车辆 → CPRT存储/检验/拍卖
  → 175K+全球买家竞价 → ASP最大化
  → 保险公司回收价值最高 → 更多委托
  → 更多车辆 → 更多买家被吸引
  → 正反馈循环, 竞争对手难以复制

  vs Visa网络效应的区别:
    Visa: 商户接受→持卡人使用→更多商户接受 (信息流)
    CPRT: 保险公司委托→买家竞价→更多保险公司委托 (实物流+信息流)
    → CPRT多了物理层约束(车辆必须存储在实体场地)
    → 这个约束既是成本(CapEx高)也是壁垒(不可绕过)

物理基底五层防御:
  L1: 物理必须(车辆必须实体存储/运输, 不可数字化)
  L2: 土地稀缺(城市边缘工业用地+环保许可+分区审批)
  L3: 规模壁垒(300+场地, PPE $3.7B, 复制需$3B+且5-10年)
  L4: 密度优势(场地密度→拖车时效→保险公司服务水平要求)
  L5: 升值资产(土地长期升值, 不像设备折旧→资产价值递增)

OPM两阶段周期:
  Phase 1(平台转型期, 5-10年):
    线下→线上拍卖 → 成本骤降 → OPM爆发式扩张
    CPRT: 23.6%→42.2% (+1860bps, 7年)
    → 投资时机: Phase 1早期识别(平台转型信号+网络效应萌芽)
    → 回报: 可能超过20% CAGR

  Phase 2(成熟运营期, 长期):
    OPM稳定在天花板附近 → 靠Rev增长驱动EPS
    CPRT: 42.2%→36.5% (回落, 但稳定在~36-38%)
    → 投资时机: 估值压缩时(如当前P/E 24x, 近52周低点)
    → 回报: 约13-15% CAGR (Rev CAGR + 温和回购)

投资含义:
  CPRT当前处于Phase 2, OPM扩张红利已释放
  未来回报 ≈ Rev CAGR 13% + 回购 1% = ~14%
  但: 当前P/E=24x, 远低于历史均值35-40x
  → 如果估值回归均值(30x): 年化+5-8% → 总回报可能19-22%
  → 这是"Phase 2价值+均值回归"的投资逻辑, 不是"Phase 1增长"逻辑
```
