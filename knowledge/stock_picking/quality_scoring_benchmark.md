### 3. 核心教训总结

```
① 品质是门票, 商业模型决定回报
   FAST(品质7/7, B=22) → 5x  vs  FICO(品质7/7, B=35) → 68x

② 非周期性比高OPM更重要
   IHG(真实OPM 65%, 强周期) → 4x  vs  FAST(OPM 20%, 弱周期) → 5x

③ 护城河类型比护城河深度更重要
   FICO(C=18, 制度嵌入) → 68x  vs  CPRT(C=20, 网络+物理) → 10x
   → FICO的制度嵌入创造了不可替代性+定价权, 这是分数捕捉不到的非线性

④ B4(定价权)是最强的单一预测因子
   B4=5(FICO) → 68x | B4=4(CTAS/IDXX) → 9-14x | B4=3(CPRT/ROL/Visa) → 7-10x
   B4=1.5(FAST) → 5x | B4=2.5(IHG) → 4x
   → 定价权每降1分, 回报近似折半

⑤ CPRT证明: 加权分最高不等于回报最高
   CPRT(55.6) > FICO(53.0), 但回报10x << 68x
   → 加权分预测"区间", 定价权期权(B4=5)创造"非线性爆发"

⑥ AVGO证明: 并购驱动回报vs有机品质的脱钩(新增)
   加权分36.1(应预期7-15x) vs 实际~45x(含并购)
   → 加权分只捕捉"有机品质", 并购整合能力(eta=1.37)创造额外回报
   → 但并购回报不可线性外推(需持续找到优质标的)

⑦ AVGO证明: SBC是跨维度隐性税(新增)
   SBC 11.8%跨越B1/B5/B6/B7四个维度, 合计减分-3.25
   → SBC正常化至7%: B从29.5→32.75, 触碰"强偏好"门槛
   → AVGO与FICO的品质差距(29.5 vs 35): SBC解释了60%

⑧ AVGO vs FICO: "切换太贵"vs"不可替代"(新增)
   AVGO C=18.0(切换太贵: 生态锁定4+规模4)
   FICO C=18.0(不可替代: 制度嵌入5+数据排他5)
   → 同分但结构完全不同: "太贵"在长期可被替代品侵蚀, "不可替代"不会
   → 护城河分数相同时, 必须看护城河来源的持久性

⑨ NVDA证明: B3(收入经常性)是加权分最被低估的维度(新增)
   NVDA B=33, C=21 → 品质维度全面领先多数基准公司
   但B3=3.0(硬件销售)严重拖低总分: 若B3=5(如FICO), B=35, 加权分42.0(+4.2)
   → 经常性收入不只提高可预测性, 更根本地改变了公司估值范式
   → 这就是为什么NVDA(B=33)的加权分(37.8)仅略高于CTAS(B=33, 加权分39.9但D1=0.85)

⑩ NVDA vs AVGO: 同赛道品质对比的三个关键差距(新增)
   NVDA B=33/C=21 vs AVGO B=29.5/C=18.0
   差距1: 定价权来源 — CUDA生态(不可替代性) vs ASIC锁定(切换太贵), NVDA B4=4.0 vs AVGO 3.5
   差距2: SBC纪律 — NVDA 3-5%/覆盖率6.3x vs AVGO 11.8%/回购填坑, NVDA B6=4.0 vs AVGO 3.5
   差距3: 治理透明度 — Jensen虽有继任风险但战略沟通清晰 vs Hock Tan信息控制, NVDA B8=4.0 vs AVGO 3.25
   → NVDA品质全面高于AVGO, 但AVGO的VMware软件缓冲使D1更好(0.76 vs 0.70)
```

### 新增8家关键发现

```
⑪ VRSN证明: "完美收费站"的TAM天花板
   B=32, C=18 → 加权分50.0(全系列第三)
   但B7=2.0(TAM最低档)揭示核心局限: 没有量的增长, 只有价的增长
   → 加权分高是因为存量品质极致, 但增长天花板是硬约束

⑫ V(报告版) vs Visa(基准版): 深度报告后评分上调
   B从29→31.5(+2.5), C从20→21(+1): Token化锁定+VAS引擎+FCF分析深化
   → 深度报告比基准更精确, 但方向不变(偏好级)

⑬ ADBE的品质-估值矛盾是CRM的2倍版
   品质3.02/5(中等偏上)但Forward PE 9.6x(最低档)
   → 护城河迁移中(偏好型→制度型), 成功概率50-55%
   → 如果Content Credentials制度化 → PE应从10x→17x+

⑭ UNH证明: D1周期性是加权分的"压缩器"
   B=24, C=17 → B+C=41(与CTAS 47接近)
   但D1=0.55(全系列最低) → 加权分仅22.6(倒数第三)
   → MCR每100bps=$2.96 EPS的极端敏感性压低D1

⑮ CRM vs PTC: 同层SaaS的估值对比
   CRM(B27+C13.5=40.5) ≈ PTC(B27+C14.5=41.5)
   加权分几乎相同(34.4 vs 35.3) → 但CRM Forward PE 14.7x, PTC 19.4x
   → PTC更贵是因为ARR增速更低? 不是, PTC的制度嵌入(C1=3.5>CRM 2.0)更深

⑯ PYPL的"身份折价"量化
   B=22.5, C=10.5 → 加权分28.1(低于FAST 27.2)
   ROIC 33%(远超多数基准公司), FCF yield 14.3%
   → 加权分28 vs ROIC 33% = 加权分系统性低估"混合身份"公司
   → 身份明确化是PYPL估值修复的必要条件

⑰ 8家新增公司的B4(定价权)分布
   VRSN(3.5) > V(3.5) > PTC(3.5) > CRM(3.0)/ADBE(3.0)/LULU(3.0) > UNH(2.0)/PYPL(2.0)
   → 定价权与PE的正相关在新增8家中同样成立
   → UNH/PYPL的低定价权解释了为什么高收入规模+高ROIC≠高估值
```
