## 二、Visa vs FICO: 框架最大的认知升级

### 两种完全不同的护城河结构

```
FICO:  制度嵌入(5) + 数据(3) = 12分
       攻击面 = 0 → 耐久性S级
       OPM从20%→47%(巨大扩张空间)
       定价权未兑现→阶段1→68x回报

Visa:  网络效应(5) + 规模经济(5) + 制度(4) + 数据(4) = 21分
       攻击面 = 2 → 耐久性A级
       OPM已在65%(无扩张空间)
       定价权受监管约束(EU上限, Durbin)
```

**核心发现: 深度和耐久性真的是两回事**

FICO深度12但耐久性S级 → 2014年P/E 20x → 严重低估
Visa深度21但耐久性A级 → 2026年P/E 33x → 合理定价

市场**对**了——Visa的33x P/E反映了"很好但不是永恒"。
市场对FICO 2014的20x P/E是**错**的——因为它没识别出S级耐久性。

**这验证了v0.5矩阵的核心预测: 右下角(浅但永固)最容易被低估。**

### 定价权的两种形态

```
FICO型定价权: "未开封" → 可以释放 → OPM爆发 → 利润弹性2.7x
  特征: 历史低定价, 客户价值>>价格, 无监管约束
  投资机会: 巨大(市场不知道利润会爆发)

Visa型定价权: "受约束" → 被监管限制 → OPM高位稳定 → 利润弹性1.4x
  特征: 费率受政府监管(EU上限/Durbin), 无法自主激进提价
  投资机会: 有限(利润已经反映在股价中)
```

**新增概念: "受约束的定价权"不等于"没有定价权"**
- Visa可以通过增值服务(VAS)绕过监管约束提价
- VAS收入增速>网络费增速 → 定价权的"边门"
- 但这不如FICO的"正门"(直接对核心产品提价)那么强

## 三、新发现: "吞噬式防御"

Visa揭示了v0.5未包含的护城河防御模式:

```
v0.5之前认为的护城河防御:
  城墙式: 靠制度/法律挡住攻击者(FICO)
  → 攻击面=0, 永久有效

Visa展示的第二种防御:
  吞噬式: 让攻击者在自己的基础设施上运行
  → Stripe在Visa轨道上运行
  → BNPL用Visa虚拟卡
  → Apple Pay用Visa tokenization
  → 稳定币成为Visa的结算介质
  → 攻击面存在但被不断吸收

吞噬式防御的优劣:
  优: 迫使公司持续进化(vs FICO可以躺赚)
  劣: 每次吞噬都可能让出部分利润(跨境费率压缩)
  净效果: 护城河不会突然崩塌, 但会缓慢侵蚀

投资含义:
  城墙式(FICO): 可以长期持有30年不担心
  吞噬式(Visa): 可以持有10年, 但需要持续监控吞噬是否还在生效
```

## 四、框架v0.5的进化教训

### 教训1: 需要新增"支付网络型"复利原型

现有7种原型都无法准确描述Visa:

```
算法垄断型: Visa有物理网络(商户终端), 不是纯算法
平台型:     Visa不拥有数据(银行拥有), 不是数据平台
密度型:     Visa的密度来自网络效应不是路径密度
安装基数型: Visa没有"设备→耗材"循环

新增原型: 支付网络型 (Payment Network)
  代表: Visa, Mastercard, 支付宝, 微信支付
  核心引擎: 双边网络效应 × 规模经济 × 跨境溢价
  可研究性: 高 — 追踪交易笔数×每笔费率×跨境占比
  特殊性: 护城河最深(21/25)但受监管约束(定价权被限制)
```

### 教训2: FP1需要从二分法扩展为更精细的分类

```
v0.5 FP1: 法律强制=2, 行业标准=2, 品牌/物理网络=1, 信息不对称/专利=0

问题: Visa的制度嵌入是4分(行业标准+合约), 但定价权被监管限制
→ 高制度嵌入 + 低定价自由度 = 框架当前无法表达的状态

FICO: 高嵌入 + 高定价自由度 → 可以提价 → OPM爆发
Visa: 高嵌入 + 低定价自由度 → 不能提价 → OPM稳定

框架应区分: "嵌入深度"(能不能被替代) 和 "定价自由度"(能不能提价)
这是两个独立维度, 不应混为一谈
```

### 教训3: 攻击面需区分"市场力量"和"国家力量"

```
v0.5: 攻击面 = 能被打破的路径数量

Visa揭示的细化:
  市场力量攻击(Stripe/BNPL/Apple): Visa可以通过商业手段防御(吞噬)
  国家力量攻击(UPI/PIX/FedNow): Visa无法防御(你不能和国家竞争)

这意味着:
  攻击面不只是数量, 还要看"攻击者的性质"
  国家力量攻击 → 在特定市场不可逆(印度/巴西已证明)
  市场力量攻击 → 通常可被吞噬(Stripe/BNPL已被吞噬)

  对Visa: 全球耐久性A级, 但特定大国市场已有不可逆结构损失
```

### 教训4: "受约束的定价权"是独立的估值考量

```
FICO: 未兑现定价权 → 阶段1→2的OPM爆发 → P/E从20x→56x
Visa: 受约束定价权 → OPM高位稳定 → P/E维持在30-35x区间

投资含义完全不同:
  FICO型: 寻找阶段1买点(P/E低+OPM将爆发) = 10倍机会
  Visa型: 利润已充分反映, 回报来自"稳定复利"(EPS 12-15%+股息) = 2-3倍/10年

  两者都是好公司, 但"好公司"的投资逻辑完全不同
  框架需要明确区分这两种逻辑
```

## 五、Visa的投资结论

```
品质: 极高 (7/7硬指标, 22/28品味, 深度21/25)
护城河: 最深(21)但非最持久(A级, 非S级)
估值: 合理偏贵 (P/E 33x, FCF Yield 3.3%, PEG 2.2)
三引擎: 双引擎(收入11%+回购2.2%), OPM引擎熄火
定价权: 受约束(监管限制), 通过VAS绕行
攻击面: 2个实质(UPI/PIX, 稳定币), 3个已被吞噬(Stripe/BNPL/Apple)

预期回报: EPS CAGR 12-15% → 5年目标$500-550(含P/E小幅压缩) → 年化8-10%
风险: 跨境费率压缩($3.8B营收, ~10%总收入面临侵蚀)

v0.5框架判定: 好公司, 合理价格, 但不是"市场看错了"的机会
  vs FICO 2014: FICO是"市场看错了"(S级耐久性+未兑现定价权被忽视)
  vs Visa 2026: Visa是"市场看对了"(A级耐久性+受约束定价权被正确定价)
```

### 最大模式

```

35%+ CAGR: FICO(35%), GE(40%), CSU(33%)
  → 全部"市场看错了"——耐久性或利润弹性被严重低估
  → P/E在买入时都偏低(9-22x)

20-30% CAGR: HEI(29%), DHR(20%)
  → "市场部分看错了"——并购纪律被低估
  → P/E在买入时合理(16-29x)

8-10%: Visa(预期)
  → "市场看对了"——估值合理反映了品质和风险
  → P/E 33x已定价了大部分增长

关键筛选启示:
  框架的最高价值不在于找"好公司"(Visa显然是好公司)
  而在于找"市场看错了的好公司"(FICO 2014)
  区别在于: 护城河耐久性和利润弹性是否被正确定价
```
