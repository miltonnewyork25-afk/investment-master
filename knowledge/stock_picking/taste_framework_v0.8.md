# 选股品味框架 v0.8

> **起源**: 7成功案例(HEI/DHR/CSU/GE/FICO/Visa/IDXX) + 5失败案例(Valeant/WU/Xerox/IBM/Kodak) + MSCI对标 + ROL密度型
> **v0.8核心升级**: 密度型复利模型(ROL案例) + 资本效率复利公式 + OPM天花板四级分类 + T5操作杠杆校准 + 密度经济学护城河维度
> **触发**: ROL分析揭示——T5(操作杠杆)≈1.0x的公司靠什么复利? 答案: 极致资本效率(0.7% CapEx) × 高FCF转化(96%) × 10% Rev CAGR = 不靠OPM扩张的复利机器

---

## 核心理念

**寻找"靠自身力量持续增长的被低估公司"。**

v0.3: 增长引擎必须可观察、可追踪、可预测
v0.4: 增长≠收入增长。利润增长率可以是收入增长率的2-3倍
v0.5: 护城河≠永恒。定价权有来源、阶段和有效期。框架必须同时回答"为什么能赢"和"怎样会输"
v0.6: 嵌入深度≠定价自由度。最深的护城河(Visa 21/25)可能定价权反而受限。投资含义取决于"能不能加价"而非"护城河多深"。
v0.7: OPM天花板高度决定复利量级。IDXX和FICO同样OPM~32%起步, 但天花板40% vs 65% → 回报9x vs 68x。物理基底给护城河一个不可消除的下限(FP3>=1)。
v0.8: **复利不只一条路。ROL OPM天花板~21%(T5≈1.0x), 但年化回报17-18%, 12年7x。秘密: 0.7% CapEx强度 × 96% FCF转化 × 10% Rev CAGR = 资本效率型复利。框架必须同时评估"OPM弹性"和"资本效率"两条复利路径。**

### T5 v0.8升级: 操作杠杆 + 资本效率双检查

> **v0.7问题**: T5只看OPM弹性(剩余弹性空间)。但ROL揭示——OPM天花板仅21%(T5操作杠杆≈1.0x), 却年化回报17-18%, 12年7x。原因: 0.7% CapEx强度让10% Rev CAGR几乎全部变成可分配FCF。T5必须同时检查两条复利路径。

**T5双检查流程**:

```
Step 1: 操作杠杆检查 (沿用v0.7)
  T5a = EPS CAGR / Rev CAGR (5年)
  > 1.5x → OPM弹性型 (FICO, MSCI) → 检查剩余弹性空间(v0.7)
  1.0-1.5x → 温和弹性 (IDXX) → 天花板受限但仍有
  < 1.0x → 无操作杠杆 → 进入Step 2

Step 2: 资本效率检查 (v0.8新增)
  T5b = CapEx强度 × FCF质量 × 增长韧性

  CapEx强度 = CapEx/Revenue
    < 1% → 极致资本效率 (ROL 0.7%) → +1分
    1-3% → 优秀 (IDXX 2.9%) → +0.5分
    3-5% → 正常 → +0分
    > 5% → 资本密集 → -0.5分

  FCF质量 = FCF/NI (5年平均)
    > 120% → 卓越现金转化 (ROL 123%) → +1分
    100-120% → 良好 → +0.5分
    80-100% → 正常 → +0分
    < 80% → 差 → -0.5分

  增长韧性 = 过去10年Revenue下降次数
    0次 → 免疫衰退 (ROL: 含COVID) → +1分
    1次 → 强韧性 → +0.5分
    2次 → 正常 → +0分
    > 2次 → 周期性 → -0.5分

  T5b = 三项之和 (范围 -1.5 到 +3)
  T5b >= 2.0 → "资本效率型复利" → T5得分=1.5分(不低于OPM弹性型)
  T5b 1.0-2.0 → "正常资本效率" → T5得分=1分
  T5b < 1.0 → "资本效率不足" → T5得分按T5a打分

Step 3: T5最终得分 = max(T5a打分, T5b打分)
  → 两条路径取高者, 防止单一维度遗漏
```

**ROL的T5双检查**:
- T5a: 操作杠杆 ≈ 1.0x (OI CAGR 9.9% ≈ Rev CAGR 10.1%) → T5a得分=1分
- T5b: CapEx 0.7%(+1) + FCF/NI 123%(+1) + 0次衰退(+1) = **3.0分** → 满分 → T5得分=1.5分
- T5最终 = max(1.0, 1.5) = **1.5分**

**对比验证**:
| 公司 | T5a(操作杠杆) | T5b(资本效率) | T5最终 | 实际回报 |
|------|-------------|-------------|--------|---------|
| FICO 2014 | 2.0x → 2分 | 2.0分 | **2分** | 68x (最高) |
| IDXX 2014 | 1.5x → 1.5分 | 2.5分 | **2分** | 9x |
| ROL 2014 | 1.0x → 1分 | **3.0分** | **1.5分** | 7x |
| Visa 2014 | 1.0x → 1分 | 2.0分 | **1.5分** | 8x |

→ T5双检查正确区分了四种公司: FICO(双高)>IDXX(中高)≈ROL(低+极高)≈Visa(低+高)

## 第三层: 估值框架

### 3.1 基础估值 (沿用v0.4)

| 指标 | "好价格" | "合理" | "贵" |
|------|---------|--------|------|
| FCF Yield | > 5% | 3-5% | < 3% |
| EV/EBITDA vs 增长 | < CAGR*2 | CAGR*2-3 | > CAGR*3 |

**ROL当前估值**: FCF Yield 2.1%(贵), EV/EBITDA 35x vs CAGR*3=30(贵)。P/E 55x。

### 3.2 PEG计算 (v0.8: 资本效率型公司的PEG修正)

```
纯收入增长型: PEG = P/E / Revenue CAGR (IDXX, CPRT)
利润弹性型:   PEG = P/E / EPS CAGR    (FICO, CTAS, 回购+提价型)
资本效率型(v0.8新增): PEG = P/E / (EPS CAGR × 资本效率系数)
  资本效率系数 = (FCF/NI - 1) × 0.5 + 1.0
  → FCF/NI = 123% → 系数 = 0.115 + 1.0 = 1.115
  → ROL调整后PEG = 55 / (13.8% × 1.115) = 55 / 15.4% = 3.57
  → 未调整PEG = 55 / 13.8% = 3.99

不确定时:     PEG = P/E / max(RevCAGR, EPS_CAGR*0.7)
```

### 3.3 定价权阶段判断系统 (v0.5, 沿用)

**ROL不适用阶段判断系统** — ROL不是算法垄断型/定价权驱动型。ROL是密度型, 增长来源不是"提价"而是"铺密度+温和提价+并购"。阶段系统设计用于FICO/MSCI型公司, 对ROL会产生误导。

### 3.4 定价权类型矩阵 (v0.8: +密度定价权)

```
类型1: 未行使定价权 (Unexercised Pricing Power)
  代表: FICO 2014 → 利润弹性型

类型2: 受限定价权 (Constrained Pricing Power)
  代表: Visa/MA → 嵌入深+监管约束

类型2b: 天花板受限定价权 (Ceiling-Capped Pricing Power) — v0.7
  代表: IDXX → 可自由提价但物理成本天花板

类型2c: 密度定价权 (Density Pricing Power) — v0.8新增
  特征: 温和提价(3-5%/年)但从不激进; 定价权来自"你是本区域唯一有密度的服务商"
  代表: ROL (19-21% OPM, 3-5%年提价, 10%总增长中只有30-40%来自提价)
  投资逻辑: 提价是增长引擎的一部分但不是主引擎 → 复利主要靠密度+并购+资本效率
  与类型1区别: FICO的提价是"释放隐藏的利润弹性"; ROL的提价是"日常涨价, 温和持续"
  与类型2区别: Visa受监管约束; ROL不受约束但自选节制(3-5%/年 vs 客户价值<0.3%)
  阶段判断: 不适用3.3 — 增长引擎是多元的(密度+提价+并购), 非单一定价权

类型3: 已释放定价权 (Exercised Pricing Power)
  代表: FICO 2025

类型4: 滥用定价权 (Abused Pricing Power)
  代表: Valeant
```

## 第四层: 三重增长引擎分解 (v0.8: +密度型引擎组合)

```
EPS增长 = 收入增长 * OPM杠杆 * 回购效应

v0.8新增: 密度型引擎组合 (ROL案例)

ROL的三引擎:
  引擎1: Revenue CAGR = 10.1% (9年)
    来源拆解:
    - 有机定价: 3-5%/年 (~35%)
    - 有机客户量增: 2-4%/年 (~25%) ← 密度填充
    - Tuck-in并购: 2-4%/年 (~35%)
    - 服务mix升级: ~0.5-1%/年 (~5%) ← 商业/白蚁增速>住宅

  引擎2: OPM趋势 → 稳定(17-21%窄幅波动) → 引擎2≈0
    OPM天花板 ~21-22% (劳动密集型, 每次服务需技师上门)
    10年OPM从~19.7%到~19.4% → 无趋势性扩张
    引擎2对EPS贡献: 约0pp

  引擎3: 回购 → 极弱(年回购/FCF比例极低)
    股数变动(3年): -2.01%
    回购收益率: 0.06%
    引擎3对EPS贡献: 约0.7pp/年

  合成: EPS CAGR ≈ 10.1%(引擎1) + 0%(引擎2) + 0.7%(引擎3) + 3%(税改一次性) ≈ 13.8%
  但税改效应消化后, 长期可持续EPS CAGR ≈ 10-11%

  → 2026指引: 7-8%有机 + 2-3%并购 = 9-11% Rev growth
  → 管理层目标: 25-30%增量利润率 → OPM从19%缓慢爬向20-21%
  → 可持续EPS CAGR ≈ 10-12%

v0.8洞察: 密度型复利的"第四引擎" — 资本循环效率

  传统三引擎框架遗漏了ROL最重要的特征: 极致资本效率

  引擎4: 资本循环效率 (Capital Cycling Efficiency)
    CapEx/Revenue = 0.7% (全框架最低)
    FCF/NI = 123%
    FCF margin = 17.3% (几乎=OPM 19.4%)

    含义: 每$1收入中$0.17变成FCF → 投入tuck-in M&A(3-5x EBITDA) →
    被Rollins整合后按35x EV/EBITDA交易 → 10x价值创造 →
    新增客户进入路线密度飞轮 → 更多收入 → 更多FCF → 循环

  这不是传统三引擎中的任何一个, 而是一个独立的价值创造循环:
  FCF → 低价并购 → 密度整合 → 利润率提升 → 更多FCF → 循环
```

### OPM天花板分类 (v0.8: 从三级扩展为四级)

```
零边际成本 (FICO/MSCI/MCO): 天花板 60-70%
  纯软件/算法, 增量收入几乎零成本
  引擎2提供: 10-15年OPM扩张

低边际成本 (IDXX/DCI): 天花板 35-42%
  仍需制造/物流, 但有规模效应
  引擎2提供: 5-8年OPM扩张

中边际成本 (ROL/CTAS): 天花板 20-28% ← v0.8新增
  劳动密集但资本极轻; 密度效应在局部区域创造高利润率(28-32%)
  但全国平均被低密度区域拉低至~20-22%
  引擎2几乎不提供增长(OPM窄幅波动)
  补偿机制: 引擎4(资本循环效率)替代引擎2的角色

高边际成本 (传统制造/物流): 天花板 15-20%
  引擎2几乎不提供额外增长
  且通常缺乏引擎4(高CapEx消耗FCF)

已达天花板 (Visa/FICO 2025): 天花板已到
  引擎2耗尽 → EPS CAGR回落至Revenue CAGR + 回购效应
```

## 第五层: 护城河深度量化体系 (v0.8: +密度经济维度 + ROL评分)

### 5.1 护城河的六种底层机制 (v0.8: +密度经济)

```
机制1: 制度嵌入 (Institutional Embedding) — 沿用
机制2: 网络效应 (Network Effects) — 沿用
机制3: 生态锁定 (Ecosystem Lock-in) — 沿用
机制4: 数据飞轮 (Data Flywheel) — 沿用
机制5: 规模经济 (Scale Economics) — 沿用

机制6: 密度经济 (Density Economics) — v0.8新增
  在地理区域内客户越多 → 每客户服务成本越低 → 价格优势越大 → 赢更多客户
  特征: 非线性成本下降(8客户/路$18站 → 10客户/路$2站)
  代表: ROL(害虫), CTAS(制服), Waste Management(废物)
  与规模经济区别: 规模经济是全国性的(总量); 密度经济是局部性的(区域浓度)

  密度经济的独特优势:
  - 创造"局部垄断": 在高密度区域(25%+份额)竞争者无法盈利进入
  - 自我强化: 密度→低成本→赢客户→更高密度 (飞轮)
  - 可叠加: 品牌+密度双重锁定(竞争者即使匹配密度, 仍需匹配品牌)

  密度经济的限制:
  - 地理受限: 不能远程"密度化", 必须逐城市/逐区域建立
  - 增长上限: 本区域饱和后必须进入新区域(从低密度重新开始)
  - 难以量化: 公司通常不披露路线密度KPI
```

### 密度型: 增长特征 + 复利模型 (v0.8新增)

```
增长特征:
  1. 有机增长为主(67-75%): 定价3-5% + 新客户2-4%
  2. 补充性并购(25-33%): tuck-in为主, 3-5x EBITDA买入
  3. 物理基底防御: FP3=2, 核心服务不可数字化/AI化
  4. 经常性收入: 75%为定期服务合同
  5. 低客户价值占比: 年费$500-800 vs 房产$300K+ → FP2=2

OPM天花板分析:
  天花板~20-22% (劳动密集, 每次服务=1技师×物理上门)
  高密度区域(25%+份额) EBITDA margin 28-32% → 理论天花板存在
  但全国平均被低密度区域(新进入/郊区/农村)拖至~20%
  T5(操作杠杆) ≈ 1.0x → 引擎2几乎不贡献增长

复利模型 — "资本循环飞轮":

  传统三引擎: 引擎1(10% Rev) × 引擎2(~0 OPM杠杆) × 引擎3(~0 回购) = ~10-11% EPS
  资本循环补偿:
    CapEx/Rev = 0.7% → FCF ≈ EBITDA × 75%
    FCF → 55%分红 + 45%再投资(tuck-in M&A)
    Tuck-in买入价: 3-5x EBITDA → Rollins整合后: 35x EV/EBITDA → 7-10x价值创造
    整合流程: 买入 → 合并路线 → 减30-40%技师冗余 → 18月内利润率+800-1200bps

  → 这个资本循环不需要OPM扩张就能创造持续增长
  → 类似"低价收购+运营提升"的PE模型, 但更轻、更持续、风险更低

  长期增长天花板:
  - 美国害虫控制市场~$22B, 年增长~8%
  - ROL份额~24% → 仍有巨大密度填充+份额增长空间
  - 全球扩张潜力(ROL目前以北美为主)
  - 20年内不会撞天花板

投资节奏:
  密度型不像剃刀-刀片型有明确的"投资期/收获期"周期
  ROL是"持续投入持续收获"型: 每年并购20-40家小公司 + 持续有机增长
  最佳买入时机: 宏观恐慌导致P/E从55x压缩至35-40x(历史下限)
  当前估值: P/E 55x, FCF Yield 2.1% — 贵, 但增长质量支撑溢价
```

### 复利路径对比矩阵 (v0.8新增)

```
                   OPM弹性                   资本效率
                  (利润驱动)                 (增长驱动)

典型代表      FICO 2014                    ROL/CTAS
T5            > 1.5x                       ≈ 1.0x
OPM天花板     60-70%                       20-28%
CapEx强度     3-5%                         < 2%
FCF/NI        80-100%                      > 120%
增长来源      提价 > 量增                   量增+并购 > 提价
回报潜力      极高(68x/11年可能)            高(7x/12年)
可预测性      中(何时开始提价不确定)         高(增长极稳)
下行风险      中(监管可能打断)              低(需求极刚性)
最优估值时机  市场未认知定价权期权时          宏观恐慌导致P/E压缩时

结论:
  - OPM弹性型 → 赔率更高(10倍+可能), 但需要"认知差"窗口
  - 资本效率型 → 胜率更高(极少亏钱), 但可能永远不便宜(P/E 40-60x常态)
  - 最佳组合: 两种类型各配置一个 → 高赔率+高胜率互补
```

## 实筛校准发现 (v0.8更新)

### 校准5 (v0.8新增): T5实筛再校准 — ROL不是0.9x

```
v0.5实筛结论: ROL T5=0.9x (无弹性)
v0.8校准: T5计算窗口敏感

  9年(2016→2025): EPS CAGR 13.8% / Rev CAGR 10.1% = 1.37x ← 含税改
  7年(2018→2025): EPS CAGR 12.8% / Rev CAGR 10.9% = 1.17x
  5年(2020→2025): EPS CAGR 15.1% / Rev CAGR 11.7% = 1.29x
  操作层面:        OI CAGR 9.9% / Rev CAGR 10.1%  = 0.98x ← 真实操作杠杆

  v0.5的0.9x可能使用了2018-2022窗口(OPM从20.7%降至18.3%)

  修正:
  - T5的正确用法: 看操作杠杆(OI CAGR / Rev CAGR), 而非含税改/回购的EPS CAGR
  - ROL操作杠杆 = 0.98x ≈ 1.0x → OPM无趋势性扩张, 确认
  - 但EPS CAGR(13.8%)显著>OI CAGR(9.9%) → 税改+回购贡献了~4pp
  - 框架应该: 先看T5a(操作杠杆), 再看T5b(资本效率), 不要混淆
```
