# CQI评分公式 v1.0 — 固化评分系统
> 目标: 可重复、可审计、动态可校准。消除"每次靠Agent估分+人工校准"的不稳定性。
> 适用: 所有新增公司评分 + 现有公司季度更新
> 关联: `moat_analysis_framework_v3.1.md`(护城河框架) + `quality_scoring_benchmark.md`(详细评分卡)

---

## 一、CQI计算公式

```
CQI = round((加权分 - 10) / 55 × 100)

加权分 = (B小计 + C小计) × D1 × T

其中:
  B小计 = B1+B2+B3+B4+B5+B6+B7+B8 (每项0-5分, 满分40)
  C小计 = C1+C2+C3+C4+C5+C6 (每项0-5分, 满分30)
  D1 = 周期乘数 (0.40-1.20)
  T = 趋势乘数 (0.90-1.10, v4.0新增)
```

## 二、B维度评分标准 (商业模型, 8×5=40分)

### B1 收入引擎清晰度 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | ≥3个可追踪引擎 + 收入CAGR≥12% + 各引擎独立可量化 |
| 4 | 2-3个引擎 + CAGR 8-12% + 多数可追踪 |
| 3 | 1-2个引擎 + CAGR 5-8% + 清晰但不惊艳 |
| 2 | 单引擎 + CAGR 3-5% + 增速放缓 |
| 1 | 引擎不清晰 或 CAGR<3% 或 依赖单一客户/事件 |

### B2 客户锁定深度 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | 制度/标准锁定: 监管要求使用，客户无替代选择(FICO) |
| 4 | 运营/生态锁定: 多层叠加，切换成本>5x年付费(CTAS, IDXX, PTC) |
| 3 | 网络/合同锁定: 双边网络或长期合同(CPRT, V, IHG) |
| 2 | 渠道/习惯锁定: 可比价，切换成本<2x年付费(FAST) |
| 1 | 无实质锁定: 客户可随时离开(餐饮/零售) |

### B3 收入经常性 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | 自动触发收入: 每笔交易/每次查询自动收费，近零边际成本(FICO, V) |
| 4 | 订阅/耗材复购: 月度/年度自动续约或消耗品(CTAS, IDXX, SaaS) |
| 3 | 事实经常性: 非合同但统计稳定(CPRT拍卖, 日常消费) |
| 2 | 周期性重复: 升级周期或合同期(半导体设备, 硬件) |
| 1 | 一次性/项目制: 每次销售是新决策 |

### B4 定价权证据 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | 10年+连续超通胀提价，客户零流失(FICO) |
| 4 | 近垄断定价，3年+持续提价，流失率<2%(ASML, NVDA训练) |
| 3 | 中等定价权: 年提3-5%，受竞争约束(CTAS, IDXX, CPRT) |
| 2 | 弱定价权: 跟随通胀或受监管(V, IHG) |
| 1 | 无定价权: 价格由市场/竞争/大宗商品决定(FAST, 餐饮) |

### B5 利润弹性 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | OPM 11年扩张>2000bps，T5a>2.0x(FICO) |
| 4 | OPM扩张>800bps 或 T5a>1.3x(CPRT, CTAS, NVDA) |
| 3 | OPM温和扩张300-800bps(AVGO) |
| 2 | OPM平坦或已达天花板(V OPM~66%, ROL) |
| 1 | OPM零扩张或收缩(FAST) |

### B6 资本配置纪律 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | η>1.0 + SBC/Rev<2% + 并购ROI>WACC + 零稀释 |
| 4 | 大量回购/分红 + SBC合理 + 并购纪律好(CTAS, V) |
| 3 | 回购为主但η<1.0，或并购纪律一般(IDXX, CPRT) |
| 2 | 高SBC(>8%) 或 回购仅填SBC坑 或 激进杠杆(AVGO, FICO) |
| 1 | 价值毁灭: 高位增发/溢价收购/SBC>12% |

### B7 TAM与增长跑道 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | TAM>$500B + 渗透率<30% + 结构性增长(V全球支付, NVDA AI) |
| 4 | TAM扩大中(ADAS/国际/新品类) + 渗透率<50%(CPRT, CTAS) |
| 3 | TAM稳定 + 增速≈GDP+2-3%(IDXX, IHG) |
| 2 | TAM饱和或增速≈GDP(FAST, VRSN域名) |
| 1 | TAM收缩 或 市场份额在下降 |

### B8 管理层质量 (0-5)
| 分数 | 标准 |
|:----:|------|
| 5 | 创始人/长期CEO + A-Score≥8 + 内部人净买入 + 战略+执行双强 |
| 4 | 内部培养CEO + 文化延续 + A-Score 7-8(CPRT, CTAS) |
| 3 | 职业经理人 + 执行力强但愿景有限 + A-Score 6-7 |
| 2 | 新CEO(<2年) 或 战略不清 或 A-Score 5-6 |
| 1 | 管理层动荡 或 治理问题 或 A-Score<5 |

## 三、C维度评分标准 (护城河, 6×5=30分)

| 维度 | 5分 | 3分 | 1分 | 0分 |
|------|-----|-----|-----|-----|
| **C1制度嵌入** | 法规直接引用+独占合同(VRSN, FICO) | 行业标准+合同嵌入(SPGI) | 弱制度关联 | 无制度嵌入 |
| **C2网络效应** | 强双边/多边+自增强(V三方) | 中等单边或区域性(CPRT) | 弱/本地网络 | 无网络效应 |
| **C3生态锁定** | 系统+数据双锁定(MSFT) | 单层锁定(流程或数据) | 习惯锁定 | 无锁定 |
| **C4数据飞轮** | 30年+独占数据+持续积累(FICO) | 数据优势但非独占 | 数据可替代 | 无数据优势 |
| **C5规模经济** | 零边际成本+规模壁垒(软件/评级) | 规模优势但有竞争(半导体设备) | 线性规模 | 负规模经济 |
| **C6物理壁垒** | 不可复制物理资产(CPRT土地, ASML光刻) | 高资本密集+许可证 | 可复制但昂贵 | 无物理壁垒 |

## 四、D1周期乘数标准

| D1值 | 分类 | 标准 | 代表 |
|:----:|------|------|------|
| 1.15-1.20 | 反脆弱 | 衰退时收入/利润反而增长 | CPRT(1.10) |
| 1.00-1.10 | 弱周期/防御 | 衰退时收入下降<5% | FICO, CTAS, 消费必需品 |
| 0.85-0.95 | 中周期 | 衰退时收入下降5-15% | 科技平台, SaaS, V |
| 0.70-0.80 | 强周期 | 衰退时收入下降15-30% | 半导体, 工业 |
| 0.50-0.65 | 极强周期 | 衰退时收入下降>30% 或 MCR/信贷风险 | 邮轮(RCL), 银行, UNH |
| 0.40-0.50 | 周期+监管双重 | 强周期+监管压缩利润 | 酒店(IHG) |

## 五、T趋势乘数 (v4.0新增)

| T值 | 趋势 | 标准 |
|:---:|------|------|
| 1.10 | ↑结构性加宽 | 物理定律/行业结构不可逆加深护城河 |
| 1.05 | ↗执行性强化 | 公司主动加深，依赖执行力 |
| 1.00 | →稳定 | 无重大变化 |
| 0.95 | ↘结构性收窄 | 监管/替代品在结构性侵蚀 |
| 0.90 | ↓主动侵蚀 | 具体竞争对手在主动打开护城河 |
| 0.85 | ⇊全面崩塌 | 多线同时蒸发 |

**趋势乘数的效果**: CQI自动反映护城河方向。LULU(品牌侵蚀↓)会被×0.90压低，KLAC(结构性加宽↑)会被×1.10提升。解决Agent 2发现的"只评绝对值不评方向"问题。

## 六、校准规则

### 6.1 新公司评分流程
1. 完成Tier 3报告后，用本公式逐项打分(B1-B8, C1-C6, D1)
2. 计算加权分和CQI
3. **插入排名检查**: 新公司CQI必须在排行榜中找到合理的邻居(±3分内的公司)，逐一对比确认
4. 如果插入位置不合理(如LULU=62排在AMZN=56之上)，回溯检查打分是否虚高
5. 所有评分附带DM锚点(来自报告的具体数据支撑)

### 6.2 季度更新规则
- **触发**: 季报发布后，如果B1/B4/B5/D1相关指标变化>10%
- **范围**: 只更新变化的维度，不重评全部
- **趋势T**: 每季度重评趋势方向(可能从→变为↘)
- **记录**: 每次调整记录在leaderboard更新日志中

### 6.3 跨报告一致性检查
- 同行业公司(如CRM vs PTC)的B2/C1/C3不应差距>2分(除非有明确证据)
- 趋势相反的公司(如ANET↑ vs PTC↘)即使当前CQI相同，下次更新应拉开差距

## 七、示例计算

### VRSN (CQI=83)
```
B: B1=3(TAM小)+B2=5(独占合同)+B3=5(100%经常性)+B4=3.5(合同定价7%/年)
   +B5=4(OPM 67.7%)+B6=3.5(回购为主)+B7=2(TAM饱和)+B8=3(职业经理人)
   = 29/40

C: C1=5(独占型ICANN)+C2=4(1.61亿域名网络效应)+C3=4(路径依赖锁定)
   +C4=3(DNS数据)+C5=5(零边际成本)+C6=0(纯软件)
   = 21/30

D1=1.0(弱周期, 域名续约不受经济影响)
T=1.0(→稳定)

加权分 = (29+21) × 1.0 × 1.0 = 50.0
CQI = round((50-10)/55×100) = round(72.7) = 73

但截图基准CPRT=82, SPGI=74。VRSN护城河>SPGI(独占vs标准型)，财务>CPRT(OPM 67% vs 35%)。
校准调整: 加权分50→实际排名应在74-82之间 → CQI映射为83(高于公式的73)

差距原因: 公式未充分反映"独占合同"和"OPM 67.7%"的极端值。
校准方法: 对B4合同定价权上调至4.5(合同保障vs市场博弈), C1独占型上调至5.0(无替代品资格)
调整后: B=30, C=21, 加权分=51 → CQI=75。仍低于校准值83。

结论: 纯公式需要"品质溢价因子"——当OPM>60%+FCF margin>60%时额外+5-8分。
```

### 品质溢价规则 (解决极端财务质量公司)
- OPM≥55% 且 FCF/NI≥100%: 加权分+3
- OPM≥65% 且 FCF/NI≥100%: 加权分+5
- 适用: VRSN(+5), CME(+5), MCO(+3), FICO(+3)
