# CQI评分公式 v3.0 — 44因子框架的可执行版本
> **权威标准**: `docs/company_quality_scoring.md` v1.4 (44因子完整定义, 含C7自维持性)
> **本文件**: 该标准的执行手册——明确分数线+CQI换算+校准流程
> **关系**: 本文件不创造新标准，只固化执行规则。如有冲突以原始框架为准。

## 一、CQI计算公式

```
加权分 = (B小计 + C小计 + D3被忽视度) × D1周期 × T趋势

CQI = round((加权分 - 10) / 60 × 100)  # v1.4: 分母55→60(C从30→35)

品质溢价: OPM≥55%+FCF/NI≥100% → 加权分+3; OPM≥65% → +5
```

### 组成部分(44因子框架, v3.0)

| 层 | 内容 | 满分 | 因子数 | 来源 |
|:--:|------|:----:|:------:|------|
| **A** | 品质门控 | 7项Pass/Fail | 7 | QG-1~QG-7(入场券，不计入加权分但FAIL影响评级) |
| **B** | 商业模型 | 8×5=40 | 8 | B1收入引擎~B8管理层 |
| **C** | 护城河 | **7×5=35** | **7** | C1制度嵌入~C6物理壁垒+**C7自维持性(v1.4新增)** |
| **D1** | 周期乘数 | ×0.40~1.20 | 1 | 反脆弱/反周期/非周期/弱周期/混合/强周期/监管压缩 |
| **D2** | 收入纯度 | 标注 | 1 | 低纯度(<50%)必须还原真实OPM |
| **D3** | 被忽视度 | +3/+1.5/0/-1.5 | 1 | 加入B合计前调整 |
| **T** | 趋势乘数 | ×0.85~1.10 | 1 | ↑/↗/→/↘/↓/⇊ |
| | | | **合计44** | 7(A) + 8(B) + 7(C) + 4(D1/D2/D3/T) + 行业加权×18 |

## 二、A品质门控(7项，FAIL不阻止评分但标注)

| # | 指标 | 通过标准 | 修正规则 |
|---|------|---------|---------|
| QG-1 | CapEx/Rev | <15% | 不可替代物理资产(CPRT)放宽至25% |
| QG-2 | FCF/NI(5Y均值) | >80% | 排除一次性项目年份 |
| QG-3 | Rev CAGR(11Y或5Y) | >7% | 收入纯度<50%用费用收入计算 |

| QG-7 | 净债务/EBITDA | <3.0x | 反周期型允许至3.5x |

## 三、B维度评分标准(继承原始框架，明确分数线)

| 维度 | 5分 | 4分 | 3分 | 2分 | 1分 |
|------|-----|-----|-----|-----|-----|
| **B1收入引擎** | 有机>10%+引擎可追踪 | 有机8-12%+多引擎 | 有机5-8%+清晰 | 单引擎+3-5% | <3%或模糊 |
| **B2客户锁定** | 标准/制度锁定(无替代) | 运营/生态锁定(切换>5x) | 网络/合同锁定 | 渠道/习惯锁定(<2x) | 无实质锁定 |
| **B3收入经常性** | 合同/订阅月度自动 | 消耗品季度复购 | 事实经常性(统计稳定) | 升级周期/合同期 | 一次性/项目制 |
| **B4定价权** | 5年+超通胀+零流失 | 近垄断+3年+持续 | 年提3-5%+受竞争约束 | 跟随通胀/受监管 | 价格接受者 |
| **B5利润弹性** | OPM扩>500bps+T5a>2x | OPM扩>300bps+T5a>1.3x | OPM温和扩张 | OPM平坦/天花板 | OPM收缩 |
| **B6资本配置** | 回购+息>80%FCF+SBC<1% | 回购+息>60%+SBC<2% | 合理但SBC>2% | 高SBC>8%/激进杠杆 | 价值毁灭 |
| **B7 TAM** | >$100B+渗透<20%+结构性 | TAM扩大+渗透<50% | 稳定+GDP+2-3% | 饱和/≈GDP | 收缩/份额下降 |
| **B8管理层** | 创始人+A-Score≥8+内部人买 | 内部培养+文化延续+7-8 | 职业经理人+6-7 | 新CEO<2年/5-6 | 动荡/<5 |

**行业加权(继承原始框架)**:
- 半导体: B5×1.5(周期中OPM弹性关键)
- 消费品: B4×1.5(品牌定价权核心)
- 生态科技: B7×1.5(TAM决定性强)
- 金融: B2+B4×1.5(粘性+定价)

## 四、C维度评分标准(继承原始框架)

| 维度 | 5分 | 3分 | 1分 | 0分 |
|------|-----|-----|-----|-----|
| **C1制度嵌入** | 监管强制/独占合同(FICO/VRSN) | 行业标准非强制(SPGI) | 弱制度关联 | 无 |
| **C2网络效应** | 强双边/多边+自增强(V) | 中等单边/区域(CPRT) | 弱/本地 | 无 |
| **C3生态锁定** | 系统+数据双锁定(MSFT) | 单层(流程或数据) | 习惯锁定 | 无 |
| **C4数据飞轮** | 30年+独占+持续积累(FICO) | 有优势但非独占 | 可替代 | 无 |
| **C5规模经济** | 零边际成本+规模壁垒 | 规模优势有竞争 | 线性规模 | 负规模 |
| **C6物理壁垒** | 不可复制(CPRT土地/ASML光刻) | 高资本+许可证 | 可复制但贵 | 无 |
| **C7自维持性** | **5分**: 停止投入护城河永不消失(VRSN/CME/CPRT/SPGI/MCO) | **3分**: 混合型5-10年(MSFT/ASML) | **2分**: 创新依赖2-5年(NVDA/ANET) | **1分**: 内容消耗型<1年(Netflix) |

**C7评分标准详解(44因子核心新增)**:
- **5分(永续型)**: 制度/合同/物理资产保护，停止创新护城河也不消失。验证: R&D→0后3年收入下降<5%。代表: VRSN(.com合同)、CME(清算垄断)、CPRT(土地银行)
- **4分(自增强型)**: 网络/数据自然积累强化护城河。验证: (CapEx+R&D)/FCF < 40%。代表: FICO(30年信用数据)、V(支付网络)、COST(会员习惯)
- **3分(混合型)**: 部分自维持+部分需投入。代表: MSFT(Office锁定+Azure需CapEx)、ASML(EUV独家+需R&D维持代差)
- **2分(创新依赖型)**: 护城河仅靠持续产品创新维持。验证: (CapEx+R&D)/FCF > 60%。代表: NVDA(下代GPU)、ADBE(AI竞赛)、APP(AXON引擎)
- **1分(内容消耗型)**: 护城河完全依赖持续内容/创意产出。代表: Netflix、游戏公司

**行业加权**:
- 半导体: C1×1.5+C4×1.5(IP+数据壁垒)
- 消费品: C3+C5×1.2(品牌+规模)
- 生态科技: C2×2.0(网络效应核心)
- 金融: C1×2.0(监管壁垒核心)

### ★ C维度升级 v1.6 (EVO-MRVL, 2026-03-30)

**C1锁定方向标签** (EVO-MRVL-002): C1评分增加方向标签, 格式`C1=X/方向`
| 标签 | 含义 | 代表 |
|------|------|------|
| ↑↑ | 强递增: 每代锁定加深(代际兼容/数据积累) | MRVL光学DSP, NVDA CUDA |
| ↑ | 弱递增 | FICO(数据积累), V(网络效应) |
| → | 稳定 | AVGO Google TPU, CPRT |
| ↓ | 弱衰减: 竞品追赶/IP到期 | ARM(RISC-V威胁) |
| ↓↓ | 强衰减: 竞标机制/IP可许可 | MRVL Custom Silicon, INTC |

同一公司不同业务线C1方向可能相反→标注"C1方向分裂"→自动触发MDI检查。

**IP可许可性降级** (EVO-MRVL-003, 试行): C3/C6评分前检查:
- 核心IP可从第三方许可(如Synopsys SerDes)→ C3/C6 **cap at 3.0**
- 核心IP部分可许可(核心不可, 辅助可)→ cap at 4.0
- 核心IP完全独占(CUDA/EUV)→ 不受限

**护城河离散度MDI** (EVO-MRVL-001, P0): 多业务线公司必须计算:
```
MDI = max(业务线护城河) - min(业务线护城河)

MDI < 2.0: 低离散 → CQI单一数字有效
MDI 2.0-3.5: 中离散 → CQI有效但标注
MDI > 3.5: ★高离散 → CQI失效 → 必须分部评分+SOTP
```
触发条件: 收入占比>15%的业务线≥2条且护城河评分差>3.5。
代表: MRVL(MDI=4.5, 光学7.5 vs ASIC 3.0), GOOG(MDI~4.0, Search vs Cloud)

**增长侵蚀护城河预警** (EVO-MRVL-004, 试行): CQI评分后检查:
- 增速最快的业务线(>公司均值1.5倍)的护城河低于公司加权均值→触发预警
- FY2028E加权护城河 < 当前 > 0.5点→标注"增长侵蚀护城河(mix shift)"
- 代表: MRVL(Custom Silicon增速+100%但护城河3.0, 低于均值5.0)

## 五、D回报修正因子(完整继承)

### D1周期乘数

| D1 | 分类 | 标准 | 代表 |
|:--:|------|------|------|
| 1.15-1.20 | 反脆弱 | 危机时收入>正常2倍 | CME |
| 1.10 | 反周期 | 衰退时需求温和上升 | CPRT |
| 1.00 | 非周期 | 与经济脱钩 | FICO, VRSN, IDXX |
| 0.85 | 弱周期 | 温和波动无亏损 | CTAS, ROL, V, FAST, SaaS |
| 0.70-0.85 | 混合周期 | 多业务线加权 | AVGO(0.76), NVDA(0.70) |
| 0.50-0.65 | 强周期 | 收入下降>30%或MCR风险 | IHG(0.50), UNH(0.55), 邮轮 |

### D2收入纯度
- 高(>70%): 直接使用报告数据
- 中(50-70%): 标注，B5用费用收入
- **低(<50%): 必须还原真实OPM** (IHG报告23%→真实65%)

### D3被忽视度
- 显著忽视(市值<$5B+分析师<5): +3分
- 轻度忽视: +1.5分
- 充分覆盖: +0
- 过度关注(散户热门): -1.5分

## 七、评分流程

### 新公司评分(Tier 3报告完成后)
1. **A门控**: 逐项QG-1~QG-7检查，标注Pass/Fail
2. **B打分**: B1-B8逐项，用报告DM锚点支撑每一分，行业加权
3. **C打分**: C1-C6逐项，标注C1嵌入性质+C3锁定载体(v3.1)，行业加权
4. **D评估**: D1周期+D2纯度+D3被忽视度
5. **T趋势**: 评估当前护城河方向
6. **计算**: 加权分 = (B+C+D3) × D1 × T → CQI
7. **品质溢价**: 检查OPM/FCF是否触发+3或+5
8. **校准**: 插入排名检查——与±3分邻居逐一对比确认

### 季度更新
- **触发**: B1/B4/B5/D1相关指标变化>10%
- **范围**: 只更新变化维度
- **T趋势**: 每季重评
- **记录**: leaderboard更新日志

### 跨报告一致性
- 同行业B2/C1/C3差距不应>2分(除非有明确证据)
- 趋势相反的公司(ANET↑ vs PTC↘)下次更新应拉开差距
