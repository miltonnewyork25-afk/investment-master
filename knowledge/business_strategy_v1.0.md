> **核心资产**: CQI评分体系 + 护城河框架v3.1 + 35份深度报告的校准知识
> **日期**: 2026-03-15
> **状态**: 战略框架，待验证

## 一、诚实的自我评估

### 1.1 用我们自己的框架给自己打分

| 维度 | 当前 | 目标(3年) | 差距分析 |
|------|:----:|:---------:|----------|
| C1 制度嵌入 | 0 | 1.5 | 无人被要求使用CQI → 目标: 行业会议/媒体引用CQI作为品质参考 |
| C2 网络效应 | 0 | 1.0 | 纯单向输出 → 目标: 用户社区(机构投资者)间引用和讨论CQI |
| C3 生态锁定 | 0 | 2.5 | 读完即弃 → 目标: 结构化数据API嵌入投资者工作流 |
| C4 数据飞轮 | 2.5 | 4.0 | 35份报告的交叉知识在积累 → 目标: 100家覆盖，4,950对跨公司连接 |
| C5 规模经济 | 1.5 | 2.5 | 复合学习飞轮降低边际成本 → 目标: 行业模块复用率>60% |
| C6 物理壁垒 | 0 | 0 | 纯信息产品，不追求物理壁垒 |
| **CQI估算** | **~18** | **~40** | 从"内容提供者"进化到"数据基础设施" |

### 1.2 残酷的现实

当前产品本质是**内容**——和卖方研报、深度长文没有结构性区别:
- 读完即弃，零锁定
- 竞争者可以用同样的AI写出类似的东西
- 没有定价权(内容定价权的天花板极低)

### 1.3 什么不是我们的护城河

- **不是AI能力** — 任何人都能用Claude/GPT写研报
- **不是报告长度** — 500K字符不等于500K价值
- **不是覆盖公司数量** — 卖方分析师覆盖更多公司

## 二、护城河来源分析

### 2.1 我们真正独特的三样东西

**资产1: 校准后的判断系统 (C4飞轮核心)**

35份报告不是35篇文章——是35次框架校准:
- FICO报告 → C1五层结构 + B4双维拆分 + 定价权阶段模型
- KLAC报告 → 信念反演方法论(全系列最强洞见)
- MSCI报告 → 等待成本量化 + D4双半衰期
- LRCX报告 → 温水煮青蛙情景分析
- 每份报告让框架更精确，这个积累不可速成

新竞争者要重走35份×10天=350天的路径，且必须犯同样的错误并修复。框架v3.1的42个子因子，每一个都经过至少3-5家公司的实战校准。

**资产2: 跨公司组合知识 (C4飞轮产出)**

当我们说"MCO的MIS周期性和NVDA类似(D1应该<1.00)"，这个洞见来自同时深度理解NVDA和MCO。

| 覆盖家数 | 跨公司连接对数 | 知识密度 |
|:--------:|:------------:|---------|
| 35 | 595 | 当前 |
| 50 | 1,225 | 阶段1目标 |
| 100 | 4,950 | 阶段2目标 |

连接数以n²增长——这是指数级增长的组合知识资产。

**资产3: 诚实的品牌 (信任资本)**

我们的报告有三个别人不做的事:
1. **承认能力边界** — AI深挖区/诚实区声明(报告不装全知)
2. **评级量化触发** — 期望回报>+30%=深度关注，而非主观"买入"
3. **A/B文档分离** — 不给散户仓位建议(合规+负责任)

信任是最难复制的资产——也是MCO/SPGI 51年评级历史告诉我们的。

### 2.2 类比验证: 信息服务垄断的共同路径

| 公司 | 看起来卖什么 | 实际卖什么 | 垄断源 |
|------|------------|-----------|--------|
| MSCI | 指数研究 | **市场定义权**(什么是"新兴市场") | 被动资金跟踪=制度嵌入 |
| SPGI | 信用评级 | **信用准入证**(没有评级不能发债) | Basel III强制=监管嵌入 |
| FICO | 信用评分 | **信贷语言**(银行用FICO分沟通) | 30年风控模型校准=运营嵌入 |
| Bloomberg | 金融数据 | **交易员操作系统**(离开Terminal不会工作) | 肌肉记忆+社交=系统+人力锁定 |
| **我们(目标)** | 深度研报 | **复利品质评分标准**(CQI=护城河的"FICO分") | 框架校准+数据嵌入=C3+C4 |

**共同规律**: 没有一家靠"内容"建立垄断。它们的C1从0→5的路径，都是让产品变成行业基础设施的一部分。

## 三、产品演化路径

### 阶段1: 标准建立期 (现在 → 覆盖50家)

**核心任务**: 让CQI成为可引用的标准

**产品动作**:
- CQI排行榜公开发布 — **免费**，让投资者开始引用"CQI 82的CPRT"、"CQI 48的NVDA"
- 这是MSCI 1969年的策略: 先把指数免费给人用，等大家都在用了再收费
- 每季度更新一次，保持活性
- Content Engine持续产出利他型分析文章 → 引流至CQI排行榜

**框架动作**:
- 覆盖50家后CQI本身就是一个有意义的筛选工具
- 每份新报告校准框架 → v3.1→v4.0→v5.0
- 行业模块标准化(消费品R1已完成，金融R1待MCO后建立)

**C4飞轮启动**: 每多覆盖一家公司 → CQI排行榜参考价值+1 → 跨公司对比更有说服力 → 框架校准更精确 → 吸引更多关注 → 更多公司分析需求

**里程碑**:
- 50家CQI覆盖
- ≥3个行业模块标准化
- CQI被≥5家外部媒体/博主引用

### 阶段2: 工具嵌入期 (50家 → 100家)

**核心任务**: 从"你读我的报告"变成"你用我的数据"

**产品矩阵**:

| 产品层 | 内容 | 定价 | 锁定机制 |
|--------|------|------|---------|
| **免费层** | CQI排行榜 + 简评 + Content Engine文章 | $0 | 品牌认知(L5) |
| **专业层** | 完整报告(A文档) + 护城河趋势仪表盘 | 订阅制 | 分析深度依赖 |
| **机构层** | Strategy Card(B文档) + Moat Data Card API + 结构化数据feed | 高价订阅 | **系统嵌入(C3)** |
| **定制层** | 特定公司深度分析 + 战略咨询 | 项目制 | 关系锁定 |

**关键转变**: 机构层不是卖报告PDF——是卖**结构化数据feed**:
- Moat Data Card (YAML) → API endpoint
- CQI实时评分 → 数据feed
- Kill Switch触发状态 → 预警服务
- 护城河趋势仪表盘 → 季度更新推送

当基金经理把CQI分数、护城河趋势仪表盘、Kill Switch触发状态导入他的Excel/Python模型后，切换成本就产生了。这就是Bloomberg Terminal的逻辑——不是内容有多好，是嵌入工作流后拔不出来。

**里程碑**:
- 100家CQI覆盖
- 机构层API上线
- ≥3家机构付费使用结构化数据
- 美股周期表v1.0发布(私有领先经济指标)

### 阶段3: 标准垄断期 (100家+)

**核心任务**: CQI成为"复利品质"的事实标准

**类比路径**:
- MSCI定义了"什么是新兴市场" → 我们定义"什么是高品质复利公司"
- FICO定义了"什么是信用好的人" → 我们定义"什么是护城河深的公司"

**当投资者说"这家公司CQI多少？"时，护城河就建立了。**

**高级产品**:
- **美股周期表** — 用覆盖公司的运营KPI构建私有领先经济指标系统 → 机构级独家产品
- **CQI指数产品** — 如果CQI排行榜被验证跑赢SPY → AUM挂钩收入 → MSCI模式
- **护城河变化预警系统** — KS触发/趋势仪表盘变化时自动通知 → SaaS订阅

## 四、美股周期表: 独家数据产品

### 4.1 概念

用覆盖公司的微观运营KPI，构建宏观市场温度信号系统。

### 4.2 六层传感器架构

| 层 | 传感器类型 | 领先时间 | 代表公司 | 核心KPI |
|----|-----------|:--------:|----------|---------|
| 1 | 信用周期 | 3-12月 | MCO/SPGI/FICO | 发行量/评级活动/贷款发放 |
| 2 | 消费体温 | 1-8周 | Visa/COST/SBUX/CMG/PG | 支付流量/同店销售/量价拆分 |
| 3 | 商旅信心 | 4-8周 | HLT/MAR/IHG/RCL | RevPAR/预订趋势 |
| 4 | 投资周期 | 8-18月 | ASML/KLAC/ETN/MSFT | 设备订单/backlog/云支出 |
| 5 | 风险偏好 | 实时 | MSCI/GOOGL/META | ETF流入/广告CPM/ESG留存 |
| 6 | 就业工业 | 同步 | CTAS/FAST/CPRT | 制服stops/紧固件日销/事故车量 |

### 4.3 竞争优势

- 宏观数据(PMI/CPI/就业)告诉你"经济怎么样"(滞后2-3个月)
- 我们的周期表告诉你"经济里的人在做什么"(领先1-18个月)
- 数据源全部来自上市公司公开披露 → 合规无风险
- 但解读层(哪些KPI组合=什么信号)是我们的独家校准

### 4.4 覆盖缺口

| 缺失板块 | 为什么重要 | 候选公司 | 优先级 |
|----------|-----------|---------|:------:|
| 保险 | 保费=风险定价的晴雨表 | PGR/AIG/BRK | 中 |
| 消费金融 | 信用卡违约率=消费者财务健康 | AXP/DFS/COF | 高 |
| 交易所 | 衍生品成交量=恐慌/贪婪 | CME/CBOE | 高 |
| 房地产数据 | 美国最大资产类别 | CSGP/ZG | 中 |

## 五、竞争定位与差异化

### 5.1 竞争格局

| 竞争者类型 | 代表 | 他们的优势 | 我们的差异 |
|-----------|------|-----------|-----------|
| 卖方研报 | 高盛/摩根 | 品牌+渠道+分析师团队 | 深度10x+量化框架+无利益冲突 |
| 独立研究 | Morningstar/CFRA | 覆盖广+评级体系 | 护城河量化精度+跨公司校准 |
| AI研报新势力 | 各种GPT产品 | 速度+成本 | 35份报告校准的判断系统(不可速成) |
| 数据平台 | Bloomberg/Capital IQ | 数据完整性+工具嵌入 | 分析深度+CQI独家评分 |

### 5.2 真正的护城河不是AI

任何人都能用AI写研报。但:

| 可复制的 | 不可复制的 |
|---------|-----------|
| 用AI生成公司分析 | 35份报告积累的框架校准 |
| 财务数据收集 | 跨公司组合洞见(n²连接) |
| 估值模型运行 | CQI体系的行业校准基准 |
| 报告排版和输出 | "诚实研究"的品牌信任 |

**我们的AI使用方式本身就是差异化**: 不是用AI替代分析师，而是用AI做分析师做不到的事(200K+字符的深度、42子因子的系统校准、35家公司的交叉验证)。

## 六、收入模型

### 6.1 三层收入结构

```
免费层 (获客)
├── CQI排行榜 (品牌建设)
├── Content Engine文章 (引流)
└── 季度护城河趋势摘要
    ↓ 转化
专业层 (ARR基础)
├── 完整报告(A文档): $X/份 或 $Y/年全库订阅
├── 护城河趋势仪表盘: 季度更新
└── 新报告优先阅读权
    ↓ 升级
机构层 (高价值)
├── Strategy Card(B文档): 入场纪律+估值+KS
├── Moat Data Card API: 结构化数据feed
├── 美股周期表信号: 领先指标预警
└── 定制分析: 项目制
```

### 6.2 定价逻辑

- **免费层**: CQI排行榜免费 = MSCI 1969年策略(先让人用起来)
- **专业层**: 对标Morningstar Premium (~$35/月) 但更深
- **机构层**: 对标Capital IQ/Bloomberg的垂直领域替代(按席位/API调用)
- **定制层**: 对标McKinsey/Bain行业专项(按项目$50K-200K)

### 6.3 单位经济学优势

每份新报告的边际价值递增:
- 第1份报告: 纯成本(建框架)
- 第10份: 框架成熟，边际成本下降50%
- 第35份(现在): 行业模块复用，边际成本下降70%
- 第100份(目标): 大部分分析可半自动化，边际成本下降85%

同时每份新报告增加的收入潜力递增(CQI覆盖更广→排行榜更有价值→API更多数据→更多订阅)。

## 七、风险与诚实域

### 7.1 核心风险

| 风险 | 概率 | 影响 | 应对 |
|------|:----:|:----:|------|
| AI民主化削弱深度分析的稀缺性 | 高 | 中 | 加速从内容→数据的转型，内容可被复制但校准系统不可 |
| CQI排行榜无法获得行业认可 | 中 | 高 | 先在中文投资社区建立口碑，再扩展到英文市场 |
| 覆盖速度太慢(每份报告10天) | 中 | 中 | AI效率持续提升+行业模块复用+框架成熟降低边际成本 |
| 评分错误导致信任受损 | 低 | 极高 | A/B分离+不给买卖建议+量化触发器(非主观判断) |

### 7.2 诚实域声明

**我们能做的**:
- 比任何卖方分析师更深地理解一家公司的商业模式
- 用量化框架系统比较跨行业、跨公司的护城河品质
- 识别护城河变化的早期信号(趋势仪表盘+KS)

**我们不能做的**:
- 预测股价(我们明确拒绝这样做)
- 替代专业投资者的判断(我们提供数据，不提供决策)
- 保证CQI高分=好投资(品质≠估值≠回报)
