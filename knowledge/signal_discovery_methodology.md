# 信号发现方法论 v1.0

> **核心发现**: 投资信号不是被"设计"出来的，而是标准工具失效后被"迫"出来的。
> **来源**: 20家公司(7 SaaS+12半导体+1转型)预期差分析的元反思
> **日期**: 2026-03-27

---

## 一、信号发现六步法

```
Step 1: 用标准指标跑 → 注意"反直觉"结果
  "P/E 438x但公司收入+28%且FCF在增长?" → 反直觉=调查起点

Step 2: 问"什么指标不反直觉?" → 找到消除反直觉的新指标
  P/FCF 44x → "这才合理" → P/FCF是SaaS的真实估值锚

Step 3: 问"为什么标准指标失效?" → 找到根因
  P/E失效因为SBC使NI人为偏低 → SBC是根因

Step 4: 跨3+家公司验证 → 确认系统性
  7家SaaS中P/FCF排序与质量排序相反 → 系统性板块错误

Step 5: 量化差距 → 新指标vs旧指标的alpha
  ADBE回购580%+缩股5%/yr vs DDOG零回购+稀释4.8%/yr → 15pp/yr差距

Step 6: 泛化 → 什么其他行业/周期适用?
  SBC扭曲P/E适用于所有高SBC行业(科技/生物医药)
  周期峰值PE陷阱适用于所有强周期行业
```

## 二、真信号 vs 假信号的判别标准

### 真信号的四个特征

| 特征 | 检验方法 | 实例 |
|------|---------|------|
| **因果机制** | "为什么这个指标能预测未来?" 有清晰答案 | Insider cluster: 内部人有信息优势 |
| **跨周期持续** | 不同市场环境下都有效 | PEP-006(周期峰值溢价): 每个周期重复 |
| **抗套利** | "如果所有人都知道,还有效吗?" | Insider buying: 有效(信息不对称是结构性的) |
| **反面可证伪** | 能明确说"什么条件下失效" | NRR<100%=增长质量警告(可验证) |

### 假信号的三个特征

| 特征 | 表现 | 实例 |
|------|------|------|
| **只有相关性** | 无法解释"为什么" | Rule of 40: 描述估值而非预测回报 |
| **矛盾证据** | 不同数据集结论相反 | FCF Yield: 一项研究正相关,一项反相关 |
| **数据源依赖** | 数据源消失则信号消失 | B/B Ratio: SEMI 2016年停止发布 |

### 判别决策树

```
新指标 →
  Q1: 有因果机制? → 否 → 可能是假信号(需更多验证)
                    → 是 ↓
  Q2: 跨3+公司验证? → 否 → 可能是个案(需扩大样本)
                      → 是 ↓
  Q3: 跨周期持续?   → 否 → 可能是当前环境特有(标注适用条件)
                      → 是 ↓
  Q4: 抗套利?       → 否 → 可能会被市场效率消除(时效性信号)
                      → 是 → ★真信号
```

## 三、已验证的信号强度排序

### 按学术证据+实证验证排序

| 排名 | 信号 | 因果机制 | 年超额回报 | 跨周期 | 来源 |
|:---:|------|---------|:--------:|:---:|------|
| 1 | **Insider Cluster买入** | 信息不对称(结构性) | +20.9% | ✅ | Lakonishok&Lee 2002, 30年数据 |
| 2 | **NRR间接推断** | 客户行为→收入预测 | 未量化 | ✅ | 我们的发现+SaaS Capital |
| 3 | **SBC覆盖率/净缩股率** | 真实股东价值创造 | ~15pp差距 | ✅ | 7家SaaS验证 |
| 4 | **周期PE位置(PEP-006/007)** | 均值回归+商品周期 | 变动大 | ✅ | 12家半导体+4个历史周期 |
| 5 | **FCF Yield(行业内相对)** | 现金生成能力 | 情境依赖 | 部分 | 我们的发现(SaaS内有效,跨行业矛盾) |
| 6 | **品质基金建仓** | 深度调研后的判断 | 未量化 | 可能 | INTU验证(Norges/Fundsmith) |
| 7 | **P/FCF排序反转** | 行业一刀切定价 | 情境依赖 | 否 | SaaS 2026板块恐慌特有 |

## 四、"间接推断不可得数据"框架

> **最有价值的信号=间接推算市场看不到的东西**

### 原理

```
当公司停止披露某个指标 → 该指标大概率在恶化(披露偏差)
能间接推算该指标 → 你比市场多知道一件事
这个信息差 = 预期差的来源
```

### 已建立的间接推算方法

| 隐藏数据 | 间接推算方法 | 适用行业 |
|---------|------------|---------|
| **NRR(不公开时)** | (收入增速 - 新客户贡献) = 存量扩展率 ≈ NRR | SaaS |
| **GRR分层(Cohort级)** | 总GRR稳定但早期Cohort GRR下降 = 被后期Cohort掩盖 | SaaS(WDAY发现) |
| **真实Owner PE** | 市值 / (NI - SBC + 净回购) | 高SBC行业 |
| **隐含增速(Reverse DCF)** | 从价格反推市场相信的增速 | 通用 |
| **地缘折价量化** | 同质量公司PE差距 = 地缘折价(TSM vs ASML) | 有地缘暴露的公司 |
| **存储周期位置** | CapEx/D&A + DIO + 现货价三信号组合 | 存储半导体 |

### 待开发的间接推算(下一步方向)

| 隐藏数据 | 可能的推算方法 | 适用行业 | 状态 |
|---------|-------------|---------|------|
| **客户集中度(不公开)** | 最大客户收入贡献变化推断:如果收入增速突然波动加大→可能客户集中 | 通用 | 待验证 |
| **定价权变化** | 收入增速分解:价格贡献 vs 量贡献(如果价格贡献下降→定价权减弱) | SaaS/消费品 | 待验证 |
| **AI替代速度** | 跟踪per-seat合同续约率(如果续约时seat数减少→AI正在替代) | SaaS | 待验证 |
| **设备库存周期位置** | 跟踪fab客户的DIO变化(不是设备商自己的DIO) | 半导体设备 | 有历史验证 |
| **管理层信心(非言辞)** | 回购加速/减速 vs 管理层言辞乐观/悲观的一致性 | 通用 | 有验证(CRM) |

## 五、信号发现的元规则

### 规则1: 异常优先于假设
```
不要从"我认为X指标应该有效"开始(假设驱动)
而要从"这个结果为什么反直觉?"开始(异常驱动)
→ P/FCF不是因为"我认为FCF更好"而发现的
→ 是因为"P/E 438x明显不对"而发现的
```

### 规则2: 跨公司验证 > 单公司发现
```
在一家公司发现的异常可能是噪音
在3+家公司重复的异常大概率是信号
→ P/FCF在7家SaaS全部呈现"排序反转"→确认是系统性的
```

### 规则3: 信号强度 ∝ 信息不对称程度
```
所有人都能看到的 → 已被定价 → 无alpha
少数人能算出的  → 部分定价 → 有alpha
需要间接推断的  → 未被定价 → 最大alpha
→ NRR间接推算 > 公开的P/E
→ Cohort级GRR > 公司报告的平均GRR
```

### 规则4: 真信号在反面也成立
```
如果"X高→股价涨"是真信号
则"X低→股价跌"也应该成立
→ Insider cluster买入(+20.9%) + Insider cluster卖出(-3.4%) → 双向验证=真信号
→ FCF Yield高(一项研究涨,另一项跌) → 单向不一致=假信号
```

### 规则5: 最好的信号是"不需要你聪明,只需要你有数据"
```
如果信号需要复杂判断→不可复制→不是好信号
如果信号是纯数据驱动(SBC覆盖率=回购/SBC)→可复制→好信号
→ 因此最终要转化为可计算的公式,不是"分析师判断"
```

## 六、应用框架: 在新行业发现信号的步骤

```
进入一个新行业时:

1. 跑5-7家公司用标准指标(P/E, P/FCF, EV/EBITDA等)
2. 找出"反直觉"的结果(PE看起来很贵/很便宜但基本面不支持)
3. 调查根因(什么会计/商业模式因素扭曲了标准指标?)
4. 找到"不被扭曲"的替代指标
5. 跨公司验证替代指标的排序是否与基本面质量一致
6. 如果排序一致→确认为行业适用指标
7. 如果排序反转→可能发现了板块定价错误

示例:
  SaaS → P/E被SBC扭曲 → P/FCF不被扭曲 → P/FCF排序反转=板块错误
  半导体设备 → P/E在峰值"便宜" → Mid-cycle PE不受周期扭曲 → 发现PEP-006
  存储 → P/E在峰值最低 → 反转动态发现 → PEP-007
  消费品(待做) → P/E可能被____扭曲 → ____不被扭曲 → 待发现
```
