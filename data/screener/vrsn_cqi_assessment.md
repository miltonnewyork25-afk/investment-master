## 关键发现

### 发现1: VRSN是护城河最纯净的公司之一

C1=5.0(制度嵌入满分) + C5成本优势=2.0(边际成本为零) = 护城河品质与FICO/SPGI同源。
但护城河总分17.5低于FICO(18.0)，因为VRSN缺乏数据飞轮(C4=2.0 vs FICO=5.0)。

### 发现2: 增长是唯一短板但也是最大短板

B7=1.5意味着VRSN是一台"确定的印钞机"但印的钞票增长很慢。
11Y收入CAGR 4.6% → EPS CAGR 12.1%(回购加速)。
如果2027年开始每年+7%提价 → 收入CAGR可能升至7-9% → B7可升至2.5-3.0 → CQI升至63-65。

### 发现3: ICANN提价权松绑是最重要的催化剂

2024年续约合同: 2027起允许+7%/年。
如果充分行使 → 到2030年每域名从$10.26→$13.42(+31%)。
这相当于FICO 2018-2022年的定价权释放起点 → B4可能从3.5升至4.0-4.5。

## 结论

```
CQI: 60 → 排行榜 #7 (ASML和COST之间)
护城河类型: 制度嵌入型(ICANN) — 与FICO/SPGI同源
核心优势: C1满分(5.0) + GM88% + 11年零收入下降 + FCF利润率65%
核心短板: B7=1.5(增长跑道最窄) + SBC/Rev 4.2%(偏高)
催化剂: 2027年+7%/年ICANN提价权松绑 → CQI可能升至63-65

建议: 加入CQI排行榜v4.1(第40家), 排名#7-8区间
```
