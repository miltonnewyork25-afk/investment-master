# 附录B: 框架参考指南——8个框架一页摘要

---

## B.1 McKinsey SCR (Situation-Complication-Resolution)

**用途**: Part IV每份CEO备忘录的结构骨架
**核心**: 结论先行→支撑证据→MECE分支。"你从底部往上思考，但从顶部往下呈现。"
**本报告应用**: Ch12-15每份备忘录均遵循S→C1-C5→R结构

## B.2 Brandenburger-Nalebuff Co-opetition (PARTS)

**用途**: Ch6价值网分析
**核心**: P(Players)-A(Added Value)-R(Rules)-T(Tactics)-S(Scope)五维度映射竞合关系
**本报告应用**: 6对竞争互动的合作%/竞争%量化; TEL外卡分析

## B.3 BCG Advantage Matrix

**用途**: Ch1/Ch4战略定位
**核心**: 优势大小×路径数量→专精型/规模型/碎片型/僵持型
**关键发现**: 半导体设备=专精型行业; AMAT试图用规模型策略获胜=战略不匹配

## B.4 Porter Five Forces (量化版)

**用途**: Ch4行业结构分析
**核心**: 新进入者+供应商+买方+替代品+竞争→行业利润率决定因素
**关键发现**: 行业吸引力8.7/10; 进入壁垒全球最高之一; 替代品威胁反而增加设备需求

## B.5 Playing to Win (Lafley/Martin)

**用途**: Ch1/Ch12-15/Ch19战略一致性测试
**核心**: 赢的志向→在哪里赢→如何赢→核心能力→管理系统; 五层必须形成强化循环
**关键发现**: ASML 48/50(教科书级); AMAT 30/50(结构性不匹配)

## B.6 McKinsey Five Big Moves + Power Curve

**用途**: Ch8/Ch20资本配置与战略杠杆
**核心**: 程序化M&A+动态资源重配+超越投资+生产率+差异化; 需2+杠杆≥8分
**关键发现**: AMAT是唯一零杠杆≥8的公司→Power Curve上升概率仅8%

## B.7 Bain Profit Pool + Installed Base

**用途**: Ch3利润池分析 + Ch10安装基数
**核心**: 收入集中≠利润集中; 安装基数是最不可颠覆的资产; 剃刀-刀片飞轮
**关键发现**: KLAC每$1收入利润产出1.56x行业均值; LRCX CSBG $35B估值地板

## B.8 Real Options Framework

**用途**: Ch9 S曲线分析
**核心**: 增长期权+切换期权+放弃期权+学习期权; 传统NPV低估技术赌注
**本报告应用**: ASML High-NA($10B+期权链) + AMAT EPIC($5B平台期权)
