> *"战略的本质不是计划——而是对手可能的反应。"*

## 7.1 场景设计逻辑

每位CEO有3个关键战略决策点。对于每个决策，我们用序贯博弈分析推演：你的行动→竞争对手最可能的反应→你的最优回应→均衡结果。

**时间窗口**：所有场景设定在2026-2028年。

## 7.1b 博弈论基础——三个支付矩阵

在展开12个场景之前，先建立三个核心博弈的形式化分析。

### 博弈1: R&D军备竞赛（囚徒困境）

半导体设备行业的R&D投入遵循囚徒困境结构——双方都"被迫"重度投资，即使合作(同时降低R&D)对双方更好。

**LRCX vs TEL 刻蚀R&D博弈:**

| | **TEL重度投入R&D (¥300B)** | **TEL维持R&D (¥150B)** |
|--|:---:|:---:|
| **LRCX重度投入 ($2.5B+)** | LRCX: 维持份额, 利润率-1pp / TEL: 维持份额, 利润率-1pp | **LRCX: 扩大领先 / TEL: 失去路线图位置** |
| **LRCX维持R&D ($2.1B)** | **LRCX: 路线图落后2年 / TEL: 低温刻蚀加速渗透** | LRCX: 份额稳定, 利润率+0.5pp / TEL: 份额稳定, 利润率+0.5pp |

**Nash均衡**: (重度投入, 重度投入) — 双方都选择重度投入，即使(维持, 维持)对利润率更好。**因为单边削减R&D的惩罚(路线图落后2年)远大于双方加码的成本(利润率-1pp)。**

这解释了为什么设备行业R&D强度(12-17%)结构性高于大多数资本商品行业(3-5%)——R&D军备竞赛的Nash均衡锁定了高投入。[参阅: Ch8资本配置]

### 博弈2: 封装设备标准战（Stackelberg领导博弈）

先进封装设备市场正在从碎片化向专精化演进。ASML(XT:360)进入封装光刻 = Stackelberg领导者的先行承诺。

**ASML vs AMAT 封装博弈:**

| | **AMAT加大封装投资** | **AMAT维持现有水平** |
|--|:---:|:---:|
| **ASML积极推广XT:360** | ASML: 定义光刻标准, +$2-3B / AMAT: 材料差异化, +$1-2B | **ASML: 定义标准+抢占材料边界 / AMAT: 份额被侵蚀** |
| **ASML缓慢推进** | **AMAT: 封装材料主导 / ASML: 错失窗口** | 双方: 市场碎片化持续, 都赚不到溢价 |

**均衡**: ASML已选择积极推广(Stackelberg领导者先行)→AMAT的最优反应是加大封装投资(跟随者最佳回应)。**结果: 双方都在封装加码, 但ASML有先行者优势定义光刻标准。**

### 博弈3: CSBG定价博弈（寡头定价均衡）

服务定价遵循寡头定价均衡——LRCX(CSBG)和AMAT(AGS)不会互相打价格战，因为服务市场的切换成本确保了"各自装机基数各自服务"的稳定均衡。

**LRCX CSBG vs AMAT AGS:**

| | **AMAT提高AGS价格** | **AMAT维持AGS价格** |
|--|:---:|:---:|
| **LRCX提高CSBG价格** | 双方: ARPU+$5-8K, 利润率各+1-2pp | LRCX: ARPU+$5-8K / AMAT: 份额不变 |
| **LRCX维持CSBG价格** | LRCX: 份额微增 / AMAT: 价格被客户回推 | 双方: 稳定, ARPU持平 |

**均衡**: (提高, 提高) — 因为服务市场的切换成本足够高，客户不会因为5-10%价格上涨而更换服务供应商。**这就是为什么CSBG ARPU可以从$72K增长到$85-95K而不丢客户——服务定价博弈支持稳定的价格上涨均衡。** [参阅: Ch10安装基数]
