## 半导体制造术语

| 术语 | CEO级解释 |
|------|---------|
| **WFE** | Wafer Fabrication Equipment — 晶圆制造设备总市场。2026E约$145B。 |
| **EUV** | Extreme Ultraviolet — 13.5nm波长光刻技术。ASML独家。用于制造<7nm芯片。 |
| **High-NA EUV** | 0.55数值孔径EUV — 下一代光刻，分辨率8nm。~€350-400M/台。 |
| **DUV** | Deep Ultraviolet — 193nm波长光刻。成熟但仍大量使用。 |
| **GAA** | Gate-All-Around — 晶体管架构。从FinFET升级，增加25-38%工艺步骤。 |
| **FinFET** | 鳍式场效应晶体管 — 当前主流晶体管架构，正在被GAA取代。 |
| **BSPDN** | Backside Power Delivery Network — 背面供电。Intel PowerVia首创。全新设备品类。 |
| **CFET** | Complementary FET — 下下代晶体管(2030+)。堆叠NMOS+PMOS。 |
| **HAR Etch** | High Aspect Ratio Etch — 高纵横比刻蚀。3D NAND关键工艺。LRCX核心优势。 |
| **ALD** | Atomic Layer Deposition — 原子层沉积。GAA关键工艺。ASM International领先。 |
| **CVD** | Chemical Vapor Deposition — 化学气相沉积。最大的沉积子市场。 |
| **PVD** | Physical Vapor Deposition — 物理气相沉积。AMAT ~85%份额。 |
| **CMP** | Chemical Mechanical Planarization — 化学机械平坦化。AMAT ~65%份额。 |
| **CoWoS** | Chip-on-Wafer-on-Substrate — TSMC先进封装技术。AI芯片供应瓶颈。 |
| **HBM** | High Bandwidth Memory — 高带宽存储。堆叠DRAM芯片。AI训练/推理关键。 |
| **TSV** | Through-Silicon Via — 硅通孔。3D芯片堆叠的垂直连接。 |
| **POR** | Process of Record — 量产工艺认证。工具被客户正式认可用于量产。 |
| **Node / 节点** | 制程代际标识(如3nm, 2nm)。更小=更先进。 |
| **Fab / 晶圆厂** | 半导体制造工厂。前沿fab成本$10-20B+。 |

## 商业/财务术语

| 术语 | CEO级解释 |
|------|---------|
| **CSBG** | Customer Support Business Group — LRCX的服务业务。$7.2B/年。 |
| **AGS** | Applied Global Services — AMAT的服务业务。~$6B/年。 |
| **ARPU** | Average Revenue Per Unit — 每台设备/腔体的年均服务收入。LRCX: $72K/腔体。 |
| **EPIC** | Equipment & Process Innovation Center — AMAT $5B研发中心。2026春开业。 |
| **A-Score** | 11维度加权护城河评分(0-10)。ASML 8.12, KLAC 7.66, LRCX 7.02, AMAT 5.42。 |
| **B/B Ratio** | Book-to-Bill — 订单/出货比。>1.0=需求增长, <1.0=需求收缩。 |
| **ROIC** | Return on Invested Capital — 投入资本回报率。ASML 135.6%(含预付款扭曲)。 |
| **FCF Yield** | Free Cash Flow Yield — 自由现金流收益率。四家公司28bp极窄价差=定价异常。 |
| **HHI** | Herfindahl-Hirschman Index — 市场集中度指数。>2500=高度集中(DOJ标准)。 |
| **Stackelberg** | 序贯博弈领导者 — TSMC在设备采购中的主导地位。 |

## 战略框架术语

| 术语 | CEO级解释 |
|------|---------|
| **Co-opetition** | 竞合 — 同时存在合作和竞争。Brandenburger-Nalebuff框架。 |
| **PARTS** | Players-Added Value-Rules-Tactics-Scope — Co-opetition分析五维度。 |
| **Playing to Win** | 五层战略选择瀑布 — 志向→赛场→方法→能力→系统。 |
| **Power Curve** | 经济利润的幂律分布 — 顶部20%赚30x于平均。McKinsey框架。 |
| **SCR** | Situation-Complication-Resolution — 麦肯锡结构化沟通框架。 |
| **BCG Advantage Matrix** | 优势大小×路径数→4种行业类型。半导体设备=专精型。 |
| **温水煮青蛙** | 渐进衰退——每季度"可控"但5年累计不可逆。本报告识别4条路径。 |
| **Kill Switch** | 触发重大战略调整的阈值信号。SEMI_EQUIPMENT报告注册17个。 |
