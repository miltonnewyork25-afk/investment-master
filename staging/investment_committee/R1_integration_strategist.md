## 一、现有框架拓扑速览

在分析介入点之前，先画清楚现有流程的信息流向和决策节点:

```
Phase -1    知识库检索 (零LLM, 脚本)
Phase -0.5  文献侦察 (5路WebSearch)
Phase 0     数据基础 + 温度 + SGI + DM初始化
Phase 0.5   市场注意力雷达 + CQ注册
Phase 0.75  核心矛盾结晶 (异常狩猎 -> 约束碰撞 -> 非共识假说)
  ---- 以上为"认知构建层" ----
Phase 1     公司定位 + 产业链 + CEO沉默分析
Phase 2     财务 + Reverse DCF + 承重墙脆弱度
Phase 3     竞争 + 护城河 + A-Score + PtW + 五引擎
Phase 3.5   AI深度评估
  ---- 以上为"分析层" ----
Phase 4     红队对抗 (RT-1~7 + 纠错回流)
  ---- 以上为"挑战层" ----
Phase 5     综合产出 + KS + 评级
Phase 5.5   Complete组装
  ---- 以上为"综合层" ----
```

**关键观察**: 现有框架是"单一分析师"模型——一个Agent贯穿所有Phase，用不同工具/skill扮演不同角色。投资委员会的引入意味着从"单人多工具"转向"多视角单决策"。这是架构性变化，不是功能性加法。

## 二、5个介入点深度分析

### 介入点A: Phase 0.75后 (核心矛盾结晶后)

**时机**: 非共识假说H1/H2已登记，报告叙事锚已锁定，但Phase 1-3的深度分析尚未开始。

**适合做什么**:
- 大师们评估核心矛盾的"类型归属": 这是周期性问题(德鲁肯米勒)、结构性问题(巴菲特)、还是范式变革(Cathie Wood)？
- 约束分类(M3)目前由assumption-audit执行，但分类依据偏形式化。大师视角可以提供"直觉校准"——一个经历过多轮周期的投资者，对"这像什么"的判断比纯逻辑推演更快。
- Bear检察官可以在此处对H1/H2做初步"可攻击性评估"——这个假说是否有明显的证伪路径？

**信息输入**: thesis_crystallization.md + shared_context.md(DM v1.0) + lit_recon_memo.md
**信息输出**: 矛盾类型标签 + 优先分析视角建议 + H假说初步攻击面

**优势**:
1. 最早的"方向校准"——在投入大量token做Phase 1-3之前，确保方向正确
2. 不同大师对同一矛盾的分类差异本身就是有价值的信息(分歧=高不确定性信号)
3. 与Phase 0.75的30-60分钟时间窗适配，不需要大量数据

**劣势**:
1. 数据不足——此时只有Phase 0的基础数据，大师们的判断缺少深度财务/竞争分析支撑
2. 过早锁定视角可能引入锚定偏差——如果巴菲特说"这是周期问题"，后续Phase 1-3可能不自觉地寻找确认证据
3. Token消耗在数据稀疏阶段，ROI偏低

**Token估计**: ~3K-5K (7引擎各300-500字简评)
**边际质量贡献**: +0.1-0.2分 (方向校准价值，但数据不足限制深度)

### 介入点B: Post-Phase 3 (A-Score/PtW完成后)

**时机**: 公司定位(P1)、财务分析(P2)、竞争分析+A-Score+PtW(P3)全部完成。这是分析层到挑战层的交界。

**适合做什么**:
- **巴菲特/芒格**: 护城河质量审判——A-Score给出了数字，但巴菲特关心的是"这个护城河是在变宽还是变窄"？PtW给出了战略一致性评分，芒格会问"管理层是否理解自己的能力圈"？
- **李录**: 如果是新兴市场公司或有中国业务——文明演进视角对消费品(SBUX中国、NKE中国)至关重要。这是框架当前缺失的维度。
- **阿克曼**: 催化剂识别——Phase 3的五引擎分析已完成，阿克曼可以评估"什么事件能解锁价值"，特别是治理改善/资本配置优化。
- **德鲁肯米勒**: 宏观叠加——Phase 3的行业分析是自下而上的，德鲁肯米勒可以叠加宏观维度(利率周期/消费周期/美元周期)，这些在消费品v28.0的"消费周期扫描"中只做了初步处理。
- **Cathie Wood**: 颠覆威胁评估——对消费品尤其重要。SBUX面临的不只是瑞幸/Manner的直接竞争，更是"第三空间"概念是否被数字化体验颠覆的范式问题。
- **Bear检察官**: 做空论文初稿——有了完整的P1-3分析，Bear检察官可以构建一份有数据支撑的做空论文，为Phase 4红队提供"对手方"。

**信息输入**: Phase 1-3全部staging文件 + shared_context.md(DM完整版) + A-Score + PtW评分 + thesis_crystallization.md
**信息输出**: 多视角评审纪要(每引擎1-2个关键洞察) + Phase 4红队预设靶标 + 补充分析建议

**优势**:
1. **数据充分**: Phase 1-3产出了大量结构化分析，大师们有足够素材发表有深度的意见
2. **正好在红队前**: 大师视角可以直接喂入Phase 4——Bear检察官的做空论文可以作为RT-3"空头钢人"的起点
3. **与PtW/A-Score互补**: 大师视角是"定性直觉"，PtW/A-Score是"定量评分"，两者交叉验证价值最高
4. **消费品v28.0适配好**: 模块A(意愿x能力)、模块C(文化可衡量性)、模块E(品牌弹性半径)的评估结果，正好是巴菲特(品牌护城河)和李录(文化驱动力)最擅长评判的领域

**劣势**:
1. Token消耗高——需要消化P1-3全部产出(通常50-70K字符)
2. 可能产生"信息过载"——7个引擎各自提出不同关注点，Phase 4需要额外effort整合
3. 时间成本——在已经很长的分析流程中再增加一个步骤

**Token估计**: ~8K-15K (7引擎各1-2K深度评论)
**边际质量贡献**: +0.3-0.5分 (这是信息最充分、ROI最高的介入点)

### 介入点C: Phase 4替代/增强

**时机**: 与红队七问(RT-1~7)同时或替代执行。

**方案C1: 替代红队** — 用7个大师引擎替代RT-1~7

映射关系:
```
RT-1 承重墙测试     <- 巴菲特(安全边际) + Bear检察官(叙事解构)
RT-2 认知偏差审计   <- 达里奥(全天候思维减少偏差) + 芒格(多元思维模型)
RT-3 空头钢人       <- Bear检察官(做空论文) + 阿克曼(激进价值反面)
RT-4 数据质量审计   <- Bear检察官(欺诈检测)
RT-5 黑天鹅压力测试 <- 达里奥(债务周期极端) + 德鲁肯米勒(宏观黑天鹅)
RT-6 时间框架挑战   <- 德鲁肯米勒(择时) + Cathie Wood(颠覆时间线)
RT-7 替代解释       <- 李录(逆向思维) + Cathie Wood(范式解释)
```

**C1判断: 不推荐替代，推荐增强。**

理由:
1. RT-1~7是**结构化、可重复、可量化**的检查清单——这正是"纵深防御"哲学的体现。大师引擎的评论是"非结构化直觉"，二者互补而非替代。
2. 当前红队的phase_sentinel.sh自动验证依赖RT结构化输出(QG-10检查每个RT≥200字)。替代后sentinel失效。
3. 历史数据: RCL 4.2分时红队发现8-16pp悲观偏差，这种定量纠偏是大师叙事做不到的。

**方案C2: 增强红队** — 大师引擎作为RT-1~7的"第二意见"

执行模式:
- RT-3(空头钢人)由Bear检察官独立构建做空论文 → 与Agent原始RT-3对比 → 取并集
- RT-5(黑天鹅)由达里奥/德鲁肯米勒从宏观维度补充 → 可能捕获Agent遗漏的系统性风险
- RT-7(替代解释)由李录/Cathie Wood提供"完全不同的叙事框架" → 检验解释的唯一性

**Token估计**: C1 ~12K (替代), C2 ~6K-10K (增强3个RT)
**边际质量贡献**: C1 -0.1分(结构化退化), C2 +0.2-0.3分(互补增强)

### 介入点D: Post-Phase 5 (评级确定后)

**时机**: 评级(深度关注/关注/中性关注/审慎关注)已确定，KS已注册，Complete组装前。

**适合做什么**:
- **评级校准**: 巴菲特问"在这个价位我愿不愿意买整家公司"；德鲁肯米勒问"现在是最佳时机吗"；Bear检察官问"评级是否被最近的数据点锚定"
- **KS优先级排序**: 15个KS中哪3个最值得跟踪？不同大师会给出不同答案
- **遗漏扫描**: 相当于现有omission-scanner的"人格化版本"——不是检查CQ是否闭环(机械检查)，而是"一个真正的投资者看完这份报告后，第一个想问的问题是什么"

**优势**:
1. 全部分析已完成，可以做"全局审视"
2. 评级校准防止系统性偏差(当前rating_calibration.sh只做同行业机械对比)
3. 补充omission-scanner的"人味"

**劣势**:
1. 太晚了——如果大师们发现重大遗漏，需要回退到P1-3补充，成本极高
2. "橡皮图章"风险——到了这个阶段，沉没成本效应使得否定评级的心理门槛极高
3. 对Complete质量的边际贡献递减(此时报告已基本定型)

**Token估计**: ~4K-8K (全局审视，焦点明确)
**边际质量贡献**: +0.1-0.15分 (锦上添花，无法雪中送炭)

## 三、"教练组"类比的实现

### 核心理念: 阵型随对手变化

足球教练组不是所有教练每场比赛都发言——是主教练(Chief Strategist)根据对手特点决定"这场谁的战术优先"。

### 公司类型 -> 引擎权重矩阵

```
                 巴菲特  李录  阿克曼  德鲁肯  达里奥  Wood  Bear
消费品(SBUX/NKE)   5     3      2      3      2     2     3    = 20
科技平台(GOOG)     3     2      2      3      2     4     4    = 20
半导体(NVDA)       2     1      2      4      3     4     4    = 20
金融(JPM/SOFI)     3     2      3      2      5     2     3    = 20
新兴市场(BABA)     2     5      2      3      4     2     2    = 20
困境反转(INTC)     2     1      5      3      2     1     5    = 19
颠覆创新(TSLA)     1     2      2      3      2     5     5    = 20
```

(权重1-5, 5=该引擎对此类公司最有发言权)

### 实现机制: Engine Selection Protocol

```python
# 伪代码 — 引擎选择协议
def select_engines(company_type, pw_score, a_score, industry):
    """
    根据公司类型选择3-5个主力引擎(权重>=3的)
    全部7个引擎只在"全员辩论"模式(PW>=7)下同时激活
    """
    weights = ENGINE_WEIGHT_MATRIX[company_type]

    if pw_score >= 7:  # 发现系统 — 可能性空间太大，需要全部视角
        active = all_engines  # 7/7
        mode = "full_debate"
    elif pw_score >= 4:  # 混合模式
        active = [e for e in engines if weights[e] >= 3]  # 通常4-5个
        mode = "focused_panel"
    else:  # 传统框架
        active = top_3_by_weight(weights)  # 3个
        mode = "expert_counsel"

    return active, mode
```

### 三种辩论模式

| 模式 | 引擎数 | Token | 适用 |
|------|--------|-------|------|
| **Expert Counsel** | 3 | ~6K | PW 0-3, 传统估值公司 |
| **Focused Panel** | 4-5 | ~10K | PW 4-6, 混合模式公司 |
| **Full Debate** | 7 | ~18K | PW 7-10, 发现系统公司 |

### 消费品示例: SBUX v3.0如果有投资委员会

SBUX: PW=5.4(混合) → Focused Panel模式 → 选择权重>=3的引擎:
- **巴菲特(5)**: "SBUX的品牌护城河在中国市场是否真正存在？瑞幸用价格战+密集网点已经证明中国消费者的品牌忠诚可以被便利性打败。第三空间的文化溢价在外卖占比40%+时已经稀释。"
- **李录(3)**: "中国咖啡市场的文明演进阶段——从'身份消费'到'日常消费'的转变意味着SBUX的溢价定位正在从结构性优势变为结构性劣势。但Tea的转型可能是被低估的。"
- **德鲁肯米勒(3)**: "美国消费者正在经历实际可支配收入压缩。SBUX的ASP提价策略在2024-2025已经触顶——交易量下降不是暂时的,是弹性测试的结果。宏观时机不利于78x P/E。"
- **Bear检察官(3)**: "Brian Niccol的'回归咖啡'叙事掩盖了一个核心问题: SBUX的OPM从30%掉到14.4%不是因为偏离咖啡,而是因为劳动力成本结构性上升+中国补贴竞争。CEO换人不改变成本曲线。"

**不激活的引擎**:
- 阿克曼(2): SBUX不是激进价值/治理改善标的
- 达里奥(2): 债务周期对SBUX影响有限(净债务可控)
- Cathie Wood(2): SBUX不是颠覆创新公司(Deep Brew的AI应用不改变范式)

## 四、与现有工具的关系矩阵

### 4.1 Bear检察官 vs red-team-suite

| 维度 | red-team-suite (现有) | Bear检察官 (新增) |
|------|----------------------|------------------|
| **结构** | RT-1~7固定问题, 每个>=200字 | 自由格式做空论文 |
| **驱动力** | 检查清单驱动(覆盖度优先) | 论文驱动(说服力优先) |
| **优势** | 可重复、可自动验证(sentinel) | 发现非结构化的叙事漏洞 |
| **弱点** | 可能形式化("回答问题"而非"真正挑战") | 难以自动验证质量 |
| **历史教训** | 41K字符净效果0pp=表演性(铁律5) | -- |

**关系: 增强，不替代。**

具体实现:
1. Bear检察官在Post-P3产出"做空论文v1"(~2K字符)
2. 做空论文作为RT-3"空头钢人"的**输入材料**(而非替代)
3. Phase 4 Agent在回答RT-3时，必须逐点回应Bear做空论文——这迫使RT-3从"表演性"变为"对抗性"
4. 质量门控: Bear做空论文必须包含>=3个量化论点(有数字)，否则退回重写

**铁律5回溯**: "5K有效>50K表演"——Bear检察官的2K做空论文+RT-3的3K回应，总共5K但每个字都在对抗。这比目前RT-3常见的"列3个空头论点→逐一反驳→结论:风险可控"的5K表演性回答有效得多。

### 4.2 巴菲特护城河评估 vs assumption-audit信念反演

| 维度 | assumption-audit M1 (现有) | 巴菲特引擎 (新增) |
|------|---------------------------|------------------|
| **方法** | Reverse DCF -> 隐含信念集 -> 脆弱度排序 | "我愿不愿意买整家公司并持有10年" |
| **输出** | B1-B6信念表 + 一致性矩阵 + Top 3脆弱信念 | 定性判断: 护城河在变宽/窄 + 管理层能力圈 |
| **优势** | 系统化、可量化、可追踪 | 直觉穿透——"数字都对但感觉不对"的检测器 |
| **弱点** | 可能遗漏无法量化的质性变化 | 不可重复、无法自动验证 |

**关系: 互补，解决不同层面问题。**

assumption-audit回答"市场在赌什么"(定量); 巴菲特引擎回答"这个赌注合理吗"(定性)。

具体实现:
1. Phase 2: assumption-audit M1照常执行，产出信念表
2. Post-P3: 巴菲特引擎读信念表，标注每个信念的"直觉合理度"(高/中/低/感觉不对)
3. "感觉不对"的信念 -> Phase 4 RT-1承重墙测试时重点验证
4. **消费品v28.0特化**: 巴菲特对品牌护城河(模块E品牌弹性半径)的直觉判断，叠加A-Score的量化评分。如果A-Score说8/10但巴菲特说"护城河在收窄"——这种矛盾本身就是有价值的警示信号。

### 4.3 达里奥风险评估 vs risk-topology

| 维度 | risk-topology v2.0 (现有) | 达里奥引擎 (新增) |
|------|--------------------------|------------------|
| **范围** | 公司级风险(8 KS + 3危险组合 + 1温水场景) | 系统级风险(债务周期+经济机器+地缘格局) |
| **方法** | 风险节点提取 -> 协同/反协同矩阵 -> 路径排序 | 宏观框架映射 -> 当前周期位置 -> 公司级传导链 |
| **输出** | 风险拓扑图(Mermaid) + 温水煮青蛙场景 | 宏观叙事 + 传导路径 + 历史类比 |
| **优势** | 结构化、可复用、支持KS标准化 | 捕获公司级分析遗漏的系统性风险 |
| **弱点** | 风险节点来源偏向公司内部 | 宏观预测本身不可靠(AI弱项) |

**关系: 互补，覆盖不同层级。**

risk-topology是"微观风险系统化"，达里奥引擎是"宏观风险具象化"。

具体实现:
1. Phase 4: risk-topology照常执行MVP模式(8+3+1)
2. 达里奥引擎在Post-P3提供**2-3个宏观风险节点**(如"美联储在2026H2被迫降息→消费品估值重估"或"长期债务周期进入去杠杆阶段")
3. 宏观风险节点**注入**risk-topology的风险节点清单(R9, R10...)
4. 协同矩阵中测试宏观风险与公司风险的交互(如"利率上行R9"+"SBUX劳动力成本R3"是否协同)
5. **关键约束**: 达里奥的宏观判断标注为"诚实区"(AI弱项)，在KS中标注低置信度

## 六、质量-效率权衡量化

### Token消耗 vs 质量贡献矩阵

| 介入方案 | Token增量 | 占报告总量% | 预估质量提升 | ROI(质量/Token) |
|---------|----------|------------|------------|----------------|
| A: P0.75后 | ~4K | 1.5% | +0.1-0.2 | 中 |
| **B: Post-P3** | **~12K** | **4.5%** | **+0.3-0.5** | **高** |
| C1: 替代P4 | ~12K | 4.5% | -0.1 | 负 |
| **C2: 增强P4** | **~8K** | **3%** | **+0.2-0.3** | **高** |
| D: Post-P5 | ~6K | 2.3% | +0.1-0.15 | 低 |
| **B+C2 (推荐)** | **~20K** | **7.5%** | **+0.4-0.6** | **最高** |

### 基线参考

- 当前Tier 3报告典型总量: 250K-540K字符
- Phase 4典型消耗: 15K-25K字符
- 20K增量约等于新增一个小Phase的工作量
- 质量0.5分提升 = RCL(4.2) -> IHG(4.3)级别的跨越，或SBUX v2(3.8) -> SBUX v3(4.0)的提升

### 成本控制机制

1. **Engine Selection Protocol**: PW低的公司只激活3个引擎(~6K)，不是每次都7个(~18K)
2. **Single-Pass原则**: 委员会评审一轮，不做多轮辩论(多轮辩论token爆炸且边际递减)
3. **结构化输出模板**: 每个引擎有固定输出模板(500-2000字)，防止发散
4. **Bear论文复用**: Bear做空论文直接流入RT-3，不是额外产出

## 七、推荐方案总结

### 最优集成: B+C2 (Post-P3评审 + Phase 4红队增强)

**Phase位置**: 新增 Phase 3.75 "投资委员会评审"

```
Phase 3 完成
  -> QG-07~09 PASS
  -> Phase 3.5 AI深度评估
  -> QG-09.5 PASS
  -> [Phase 3.75] 投资委员会评审 (NEW)
  -> QG-10.5 PASS (NEW: 评审纪要+Bear论文质量检查)
  -> Phase 4 红队 (增强: RT-3/5/7注入委员会产出)
```

**为什么放在3.5之后而非之前**: Phase 3.5的AI深度评估产出L*S坐标和AI调整估值，这是Cathie Wood引擎的核心输入。没有3.5的AI评估，Wood的颠覆创新视角缺少量化锚点。

### 实施优先级

| 阶段 | 内容 | 复杂度 |
|------|------|--------|
| **v1.0 MVP** | 仅Bear检察官 + 巴菲特引擎(2引擎) | 低 |
| **v1.5** | +达里奥宏观风险注入 + Engine Selection | 中 |
| **v2.0** | 全部7引擎 + 教练组权重矩阵 + QG-10.5 | 高 |

**建议**: 从v1.0 MVP开始，在下一份消费品Tier 3报告中验证Bear检察官+巴菲特两个引擎的实际效果。如果质量提升可验证(scorecard D7/D8维度)，再扩展到v1.5和v2.0。

### 风险与缓解

| 风险 | 缓解 |
|------|------|
| 大师引擎变成"表演性角色扮演" | 每个引擎必须输出>=1个可量化的判断 |
| Token预算超支 | Engine Selection Protocol硬限制 |
| 与现有RT冲突/重复 | Bear论文明确作为RT-3输入，不是平行产出 |
| 增加会话复杂度 | Phase 3.75在Phase 3同会话执行(不新开会话) |
| 引擎间矛盾无法调和 | "分歧度"本身作为不确定性指标纳入评级 |
