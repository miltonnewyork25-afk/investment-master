## T4-14: 库存质量与减值风险深度分析

### 库存构成分析 (基于可得信息)
- **总库存价值**: $1,194M (2025年，占总资产27%)
- **主要构成**: 
  - 450+ CFM56发动机
  - V2500发动机相关库存
  - USM (Used Serviceable Materials) 零件库存
- **估算拆解原料**: 按每架飞机15-20个模块计算，当前库存可支持数年运营

### 库存周转质量恶化
- **DIO趋势**: 120天 → 146天 → 172天 → 252天 (4年+132天恶化)
- **周转次数**: 从3.0x降至1.4x
- **恶化原因**: 业务快速扩张期积极备货 vs 需求实际增长时差

### 减值风险评估
```
潜在减值风险因素:
1. CFM56退役加速 (2030年后风险)
2. 经济衰退导致航空业需求下降
3. 新技术替代 (如电动或氢燃料航空)
4. 库存老化和技术过时

保护因素:
1. CFM56在2030年前仍为主导机型
2. 维修需求相对稳定 (存量机队)
3. 公司专业化管理和处置能力
4. USM相对于新零件的成本优势
```

### 库存估值政策 (信息缺口)
- ❌ **估值方法**: FIFO vs LIFO vs 成本或市价孰低法未明确
- ❌ **减值准备**: 历史减值损失记录和当前准备金水平
- ❌ **库存分层**: 活跃 vs 呆滞库存的分层管理政策
