## Part 3: Gap Analysis -- Missing Capabilities for McKinsey/BCG-Caliber Strategic Advisory

### 3.1 Critical Gaps (Must Build)

#### GAP-1: Industry Structure Analysis (Porter's Five Forces + Value Chain)
**Current State**: The framework has `competitive-benchmarking` (peer comparison) and `ecosystem_risk_framework` (platform risk), but no systematic industry structure analysis tool.
**What's Missing**:
- Porter's Five Forces quantification (bargaining power of suppliers/buyers, threat of substitutes/new entrants, competitive rivalry) with data-driven scoring
- Value chain decomposition: identify which segments capture value, where margins pool, profit pool migration analysis
- Industry lifecycle positioning (embryonic -> growth -> maturity -> decline)
- Value chain reconfiguration analysis under technology disruption
**Priority**: CRITICAL -- this is the foundation of every strategic advisory engagement
**Buildable from**: Partially from `competitive-benchmarking` (competitive landscape) + `ecosystem_risk_framework` (5-layer mapping)

#### GAP-2: Competitive Game Theory Analysis
**Current State**: `competitive-benchmarking` compares financials and products but does not model competitive dynamics as games.
**What's Missing**:
- Competitive response modeling: "If we do X, how will competitor Y respond?"
- Pricing game analysis (Bertrand/Cournot models adapted for specific industries)
- Capacity commitment games (critical for semiconductors, airlines, commodity chemicals)
- Signaling and commitment strategy analysis
- Co-opetition framework (simultaneous cooperation and competition)
- Multi-player strategic interaction mapping
**Priority**: HIGH -- differentiates strategic advisory from descriptive analysis
**Buildable from**: `risk-topology` (relationship matrix methodology) + `deductive_analysis.md` (causal chain reasoning)

#### GAP-3: Technology S-Curve and Disruption Analysis
**Current State**: `deductive_analysis.md` covers causal chain reasoning for paradigm shifts. `paradigm_research_framework.md` handles high-uncertainty companies. But no systematic technology disruption toolkit.
**What's Missing**:
- S-curve identification and phase positioning for specific technologies
- Disruption vulnerability assessment (Christensen framework: are you being disrupted from below?)
- Technology adoption lifecycle analysis (innovators -> early adopters -> early majority -> etc.)
- Innovation portfolio management framework (core / adjacent / transformational)
- Technology readiness level (TRL) assessment for R&D portfolio
- Build vs Buy vs Partner decision framework for technology capabilities
**Priority**: HIGH -- essential for tech/semiconductor strategy
**Buildable from**: `paradigm_research_framework.md` (possibility width) + `deductive_analysis.md` (causal chains) + `constraint-classifier` (structural vs cyclical)

#### GAP-4: Capital Allocation Optimization
**Current State**: Investment framework evaluates capital allocation as an input to valuation. No tool for optimizing capital allocation from the operator's perspective.
**What's Missing**:
- Strategic portfolio matrix (GE/McKinsey 9-box, BCG matrix adapted with modern metrics)
- Capital allocation decision framework: organic growth vs M&A vs buyback vs dividend vs debt paydown
- Return on Invested Capital (ROIC) tree decomposition by business unit
- Marginal return on capital analysis: where does the next $1B generate the highest return?
- M&A value creation framework: synergy quantification, integration risk assessment, cultural compatibility
- Divestiture analysis: which businesses should be sold/spun off to unlock value?
**Priority**: CRITICAL -- capital allocation is the #1 CEO decision
**Buildable from**: `optionality_valuation.md` (Core vs Option separation) + `valuation-independence-audit` (assumption overlap detection)

#### GAP-5: Organizational Capability Assessment
**Current State**: No organizational analysis capability at all. The framework treats companies as financial entities, not organizational systems.
**What's Missing**:
- Capability maturity model: assess current organizational capabilities against strategic requirements
- Organization design analysis: structure follows strategy assessment
- Talent/skills gap analysis for strategic priorities
- Culture assessment framework (innovation culture, execution culture, risk culture)
- Change management readiness assessment
- Operating model design: centralized vs federated vs platform models
- Decision rights and governance mapping (RACI for strategic decisions)
**Priority**: HIGH -- strategy without organization = wishful thinking
**Buildable from**: Very little existing foundation. Would need to be built from scratch.

#### GAP-6: Strategic Options / Real Options Framework
**Current State**: `optionality_valuation.md` covers financial real options for investor valuation. But no strategic real options framework for management decision-making.
**What's Missing**:
- Strategic option identification: what options does the company hold? (growth options, flexibility options, abandonment options, switching options)
- Option exercise timing analysis: when to commit vs when to preserve optionality
- Staged investment / real options approach to R&D and market entry
- Portfolio of options management: balance option creation (R&D) with option exercise (commercialization)
- Irreversibility analysis: which decisions are reversible (preserve optionality) vs irreversible (require commitment)?
- Strategic flexibility valuation: quantify the value of keeping options open
**Priority**: MEDIUM-HIGH -- critical for tech companies making large bets
**Buildable from**: `optionality_valuation.md` (OVM-1 Core vs Option) + `paradigm_research_framework.md` (possibility space mapping)

#### GAP-7: Scenario Planning Methodology
**Current State**: The framework uses scenario analysis within valuation (bull/base/bear) but has no rigorous scenario planning methodology for strategic decision-making.
**What's Missing**:
- Scenario development methodology (2x2 matrix of critical uncertainties)
- Scenario narrative construction: internally consistent, plausible futures
- Wind-tunneling: test each strategic option against each scenario
- Signpost identification: early indicators of which scenario is unfolding
- Adaptive strategy design: strategies robust across multiple scenarios
- Scenario quantification: financial models for each scenario
- Dynamic scenario monitoring: update probabilities as signposts fire
**Priority**: MEDIUM-HIGH -- existing scenario work is valuation-focused, not strategy-focused
**Buildable from**: `risk-topology` (risk cluster analysis, boiling frog scenarios) + `assumption-audit` M1 (belief set extraction) + `red-team-suite` RT-5 (black swan probability table) + existing bull/base/bear infrastructure

## Part 6: Key Insight -- The Investment Framework's Strategic DNA

The investment framework already contains ~60% of the analytical DNA needed for CEO-level strategic advisory. The key insight is that **the best investment analysts think like operators** -- they ask "what must management believe?", they stress-test assumptions, they map risk interdependencies, they challenge narrative with data, and they model causal chains.

The critical gaps (Five Forces, game theory, org capability, capital allocation optimization) represent the flip from **evaluating** a strategy (investor perspective) to **designing** a strategy (operator perspective). The existing framework excels at answering "Is this strategy likely to succeed?" -- the gap is in answering "What strategy should they pursue?"

**Strongest transferable assets**:
1. **Assumption Audit framework** -- the best single tool in the entire system for strategic advisory
2. **Risk Topology with Boiling Frog** -- CEOs are systematically blind to gradual deterioration
3. **Constraint Classifier (S/C/I)** -- forces strategic clarity on what can vs cannot be changed
4. **Competitive Benchmarking (both modes)** -- already strategic-grade competitive intelligence
5. **Deductive Analysis** -- causal chain reasoning is the language of strategy

**Weakest area**: Organizational/operational capabilities -- the framework treats companies as financial entities, not human organizations. This is the largest single gap for strategic advisory.
