## 4. Bucket D · 重要 null finding

**Gate 1.5 要求 Bucket D ≥2 候选** → 通过 (5 个候选)。
**但全部候选经 Gate 2 + Gate 4 后无一进入 top 10**:

- NICE / HUBS → Gate 4 disruptee
- CRM → Gate 4 borderline (bridge 成立度弱) + Gate 2
- CRWD / S / PLTR / SNOW / MDB → Gate 2 (Diffusion 已超前)
- GTLB → Gate 2 + 规模

**结论**: 当前 US-listed workflow-shift 主题中, 真 disruptor + R > D + 规模足 的候选几乎不存在。这是**信息性的 null** — 不是 universe 构造错, 而是这一轮 D 桶的最佳玩家要么自身是 disruptee, 要么已被市场充分 priced。

**对策**: 持续 watch **outcome-priced 新兴玩家 IPO** (2026-27 可能候选: Anthropic / Databricks / OpenAI 上市 → 重新评估 D 桶 ranking)
