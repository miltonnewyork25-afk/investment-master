# Sector / Theme Expectation-Gap Scan v1
**Date**: 2026-04-19
**Method**: Mode A (sector-expectation-gap-scanner) — 宽 universe 起点, FROG 四测 triage, 按 gap type 分桶后排名
**Constitution**: Articles I–X (demand-in) + 跨层硬规则 6–9 (financials verify not decide / diffusion asymmetry / size-gated purity / causal distance limit)
**Scope**: Global wide universe, desk research, data cutoff ~2026 Q1. MCP 实时验证将在 top 10 定稿后追加。

---

## 0. 方法口径 (一次性说清, 后文不重复)

**FROG 四测** — 每主题四位 Pass/Borderline/Fail:
- **F** (Forced demand): 需求强制性 — 强制开支 / 必维护 / 监管驱动 > 可选消费
- **R** (Restricted node): 受限节点 — 瓶颈 / 认证壁垒 / 稀缺产能 > 宽泛受益者
- **O** (Owner clarity): 所有权清晰 — Revenue/Profit/Return 三层 owner 可识别
- **G** (Gap in expectations): 市场预期差 — realization 领先 diffusion / 错层定价

**Gap 桶型** — 跨桶混排需警告 (SKILL Step 7):
- **[A] Structural owner gap** — 强制需求 × 结构性 chokepoint (长期 compounding)
- **[B] Cyclical re-rating gap** — 供给紧张 × 资产重估 (时机敏感, 需求端不强制)
- **[C] Policy/regulation gap** — 政策 / 监管 / 标准催化
- **[D] Long-duration optionality** — 期权价值, diffusion clock 未启动

**Hot-theme 惩罚** (Article IV.3 + SKILL §4): AI compute leader 等 crowded 主题若无"表达层更优 / 预期未完成 / 广度好于注意力"三条之一 → 降级为"good business, more discovered"。

**Financial-as-verify 硬规则** (跨层硬规则 6): 不用 PE / 52w return / margin 驱动排名。财务仅确认"因果链有没有断"。

## 4. Top 10 Ranking (桶分后排名)

> **警告** (SKILL §7.3): 跨桶排名**风险**。A 桶 (structural owner) 与 B 桶 (cyclical re-rating) 不可直接同尺度比较 — structural 是 long-duration compounding, cyclical 是 timing-sensitive one-shot。以下排名**先按 A 桶内排序**, 再穿插 B/C 桶。

### 桶 A — Structural owner gap (长期 compounding)

**#1. 核燃料循环 — conversion + 浓缩层** (FROG: PPPP)
- **Forced**: SMR MOU (Amazon/Google/Meta 2024–25 多起, 拉动 front-end demand 时钟从"10 年后"到"5 年内") + legacy reactor relicense + 中国新堆
- **Restricted**: US 2024 年禁俄罗斯 LEU 进口 → 美国境内浓缩产能仅 Centrus / URENCO ~合计 <5M SWU, 需求 ~18M SWU (缺口 70%)
- **Owner**: Centrus (LEU) / Cameco (UUUU conversion) / Orano (欧洲) — 3 家分占。CCJ profit 层 = fuel services arm (非 uranium price)
- **Gap**: 市场把核主题 = "uranium price", 忽略 cycle 的其他层 (conversion / enrichment 服务费 = 非商品化、契约化)
- **Kill**: 俄罗斯 LEU waiver 扩大 / SMR 商业化延迟 5+ 年 / 浓缩中间厂商大规模扩产批准

**#2. 商用航空售后 (aftermarket)** (FROG: PPPP)
- **Forced**: FAA / EASA 强制 maintenance interval + engine TBO cycle (不飞也要 check)
- **Restricted**: OEM PMA 认证 (TDG 32,000+ 件 proprietary parts, 90%+ sole-source) + FAA 型号证书
- **Owner**: TDG / HEI / RTX Pratt aftermarket / GE Aerospace (GE 分拆后变纯). TDG 已 priced, HEI 次级, RTX spare-parts 拆开看是 hidden monopoly
- **Gap**: 市场按"工业股"估值 (PE ~25x), 实际是 monopoly aftermarket (TDG LT IRR ~15%). GE Aerospace 分拆是 2024 事件, diffusion 尚未完成
- **Kill**: 全球民航运力大幅下降 (COVID-like) / PMA 法规松绑让 3rd-party 进入

**#3. 先进封装上游 — HBM 测试 / 中段设备** (FROG: PPBP)
- **Forced**: AI 芯片 HBM 堆叠 → 每片 stack 测试量比 logic 多 10x; CoWoS / SoIC 中段 bonding 需要专用设备
- **Restricted**: Onto Innovation / Camtek (HBM wafer probe) + ASMPT (hybrid bonder) + Kulicke & Soffa (TC bonder) — 4 家分占
- **Owner**: 上述 4 家 US/HK-listed. Onto / Camtek 已 re-rated 但 ASMPT 相对低调 (HK-listed discount)
- **Gap**: 市场买 NVDA/AVGO/TSM + ASML, 忽略 HBM stack 专用测试 / bonding 设备。CoWoS 扩产翻倍靠这些设备
- **Kill**: HBM4 采用 16-hi 后单位 HBM 价值量上升但测试量不成比例 / TSM 内化测试

**#4. AI 电力基建 — transformer + gas turbine OEM 层** (FROG: PPPB)
- **Forced**: Hyperscaler CapEx $300B+/年 + 电网互联时间 5-7yr → 推动 behind-the-meter gas peaking + transformer 紧张
- **Restricted**: Large power transformer 交期 2–3 yr (美国产能 Hyundai/HICO/GE 合计年产 ~1,500 台, 需求 ~3,000+); gas turbine OEM 3 家 (GE/SIEGY/MHI) 排产到 2029
- **Owner**: GEV (已涨) / SIEGY ADR / HUBB / ETN. 隐藏 owner: PCC (Berkshire 子公司, 合金叶片专供 3 家 OEM — 但已 private). HWM (Howmet Aerospace) 是 US-listed 合金层, 市场主要按 aerospace 看, aerospace+power 双轮未充分 priced
- **Gap**: 市场买生产层 (CEG/VST 电力公司), owner clarity 在工业层 (HWM / HUBB) 更纯
- **Kill**: Hyperscaler CapEx 下调 >30% / AI 训练 vs 推理 shift → 推理对地面电力更友好但 aggregate 增量放缓

**#5. 美国电网 T&D 上游层 — 特钢 / switchgear** (FROG: PPPB)
- **Forced**: 电网更新 (平均龄 40 年) + AI 负荷 + reshoring 制造业 + EV
- **Restricted**: Transformer 核心铁 (GO steel — AK/Cleveland-Cliffs 少数产能) + 特种铝缆 (ATKR cable 特钢) + switchgear (EATON/Schneider)
- **Owner**: ETN 已 priced, HUBB 次级 / ATKR / CLF specialty 层是向上游追
- **Gap**: ETN 买满后, 上游合金 / 特钢 / 铜合金更纯, 注意力未到
- **Kill**: 变压器国产化进口替代放松 / 电网 CapEx plateau

**#6. GLP-1 CDMO / peptide capacity** (FROG: PPBP)
- **Forced**: NVO/LLY 产能不足 × 适应症扩张 (cardiovascular/NASH/addiction) + Medicare 覆盖 — 订单已 forced 出
- **Restricted**: Peptide synthesis 产能 (global ~100 tons/yr, 缺口 ~2x) + fill-finish 专用线 + API 层
- **Owner**: Catalent 已被 NVO 买下 (tell). 独立玩家: Bachem (Swiss) / Samsung Bio / Evotec / Lonza (Swiss) + US: 规模玩家少 (Siegfried? NO - Swiss)。**US-listed purity 差** — 可投性是弱点
- **Gap**: 市场聚焦 NVO/LLY 终端药品股, 忽略 2025–27 的外包 CDMO 扩产。GLP-1 不是"已经完成的故事", 是 mid-diffusion
- **Kill**: NVO/LLY 内化产能更快 / 口服 GLP-1 取代注射减少 peptide 需求

### 桶 B — Cyclical re-rating gap (时机敏感)

**#7. Uranium mining — 现货 / LT 合约价 gap** (FROG: BBPP)
- **Cyclical not forced**: 需求真但可延后 (vs 燃料循环是已签合约)
- **Setup**: 现货 $105 / LT $80 / 生产 all-in ~$50-60。生产商恢复需 3-5 yr, 当前合约市场已紧张
- **Owner**: CCJ (blue chip) / Kazatomprom (geopolitical) / UEC (US domestic) / ISR 玩家
- **Gap**: 市场已注意到 (UUUU 大涨), 但 LT 合约价追上现货还有空间 (历史周期 LT 最终 lag 现货 ~60-70%)
- **Kill**: 哈萨克斯坦产能恢复快于预期 / Kazatomprom 扩产 / 去库存周期结束

### 桶 C — Policy / regulation gap

**#8. 防火 / 建筑规范升级** (FROG: PPBP)
- **Forced**: IBC 2024 + 数据中心锂电站火灾 (多起 2024-25 事件) + 高层建筑翻新周期
- **Restricted**: FM Global / UL 认证 + intumescent coating 专利 (PPG / Sherwin / AkzoNobel)
- **Owner**: JCI (Johnson Controls — fire suppression) / Carlisle (building envelope) / Tyler tech 建规数据 + coating 专利玩家。分散
- **Gap**: 数据中心消防 spec 升级 2024 后 (液冷 + 大 battery room 配套) 刚传导到订单, 市场未分层看
- **Kill**: 保险理赔数据好于预期 → 监管更新放缓

### 桶 A (续) — 回到 structural

**#9. LNG 出口链 — 上游 gas processing / pipeline** (FROG: PPBB)
- **Forced**: 2027 US LNG 出口 +80%, 长期合约已签满 (欧洲 + 亚洲 energy security)
- **Restricted**: Liquefaction train 建设 3-4 yr / Permian gas processing 产能紧 / takeaway pipeline 瓶颈
- **Owner**: LNG (Cheniere 终端) 已 priced; EQT (产气) / KNTK (中游处理) / WMB (管道) 更错层
- **Gap**: 市场看 LNG 是 commodity 价格股, 实际 gas processing 是"quasi-infrastructure return"
- **Kill**: 欧洲需求快速回落 (天气 + 核电重启) / 日韩 long-term 合约重谈

**#10. 核燃料循环 — 后端乏燃料管理 (long-duration optionality)** (FROG: PBPB)
- **Forced — 但 diffusion clock 慢**: 乏燃料临时干储 (ISFSI) 需求已 forced (各州立法) + SMR 新堆将产生新类燃料
- **Restricted**: cask 制造 (Holtec + NAC) 认证 + 最终处置地 (Yucca Mountain 的替代方案)
- **Owner**: Holtec (private, 遗憾) / Energy Fuels 有一部分 / 整体市场碎片化
- **Gap**: 市场几乎忽略, 但真 US-listed 纯玩家少 — **承认可投性是弱点**
- **Kill**: 联邦级最终处置地立法突破 (low base rate)
