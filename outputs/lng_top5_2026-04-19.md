# 详细条目 (Top 5)

## #1 · GTLS · Chart Industries

**Action**: `Initiate`

**Why this action**:
- **Chokepoint + Bridge 双属性**: 低温换热器 + Howden 压缩平台横跨 LNG / 氢 / CCUS / 工业气体 / 一般压缩维护 五条 **trigger 独立** 的需求 (地缘 ≠ 政策补贴 ≠ 碳价 ≠ 制造业 ≠ 设备到期)
- **v2.1 Bridge 硬测试**: 若 LNG 归零, 剩 H2 + CCUS + 工业气体 + maintenance ≈ 55-65% revenue; 若 H2 政策反转 (IRA 回滚), 剩 LNG + 工业 + maintenance ≈ 70-75%. 任一 chain 崩 ≥55% resilience, 远超 30% 门槛
- **Duration**: 已装 heat exchanger + 压缩机服役 20-30 年, 服务 / spare parts 长尾, ratio ~4-7x
- **G (expectation gap)**: 2023-2024 Howden 整合阶段 margin 波动 + 债务消化拖低 multiple; generalist 把它当 cyclical industrial, 未充分定价 multi-trigger 结构
- **Less-crowded vs LNG/KMI**: 市值 ~$15B, sell-side 覆盖远少于 LNG 终端, 符合 scanner rule #7 的多样性要求

**Upgrade signal (Initiate → Add)**:
- Backlog 持续扩 (连续 2 季度 book-to-bill >1.2 且 LNG + H2 + CCUS 每条 line 都在扩)
- Howden 整合后 organic EBITDA margin 回升到 pre-merger 22%+
- 大额 LNG train design win (e.g. 下一个 US 终端选 GTLS 供 IPSMR 流程)

**Downgrade signal (Initiate → Trim)**:
- 连续 2 季度 book-to-bill <1 且某 segment (典型 H2) 订单显著减
- GAAP FCF 转负持续 2 季度 (需 MCP verification — 整合期 working capital 波动正常但须有上限)
- Multiple 推到 25x+ forward EPS → 不加仓

**Break condition (Exit)**:
- Howden 整合失败 (永久性 OPM structural 低于收购 thesis)
- LNG 终端建设大面积取消 / 延期 (低概率但高尾风险)
- 技术被替代 (低温换热器被新工艺 — 低概率)

**⚠ 财务 verification**: 当前 backlog 精确值 / book-to-bill / Howden segment margin / FCF conversion

## #2 · LNG · Cheniere Energy

**Action**: `Track Position` (持仓者; 新建仓等 -10%+ 回调, hot-theme penalty 启用)

**Why this action**:
- **Textbook duration owner**: Sabine Pass 6 trains + Corpus Christi 3 trains 大部分 20 年 SPA 固定费合同 (take-or-pay), 合同对手方是 Shell / BP / Total / 中石化 / KOGAS 等顶级买家
- **Duration 硬测试**: 终端建设 5-7 年 vs SPA 20 年, ratio 3-4x; 切换成本 = 20 年合同加终端独占, 对手方违约成本极高 (Shell 在 2022 选择履约而非 waiver)
- **Hot-theme penalty 触发** (rule #4): LNG 2022 re-rate 后 generalist 充分持有; 保留 Top 理由是 **2026-2030 Corpus Christi Stage 3 (Train 1 刚 commissioned, Train 2-7 分阶段) + Sabine Stage 6 建设中 + 管理层 capital return (减债 → 增股回购 + 分红) 的 cadence 可能未被完全 price in**
- 但当前股价不 cheap, 新建仓应等 event-driven 回调

**Upgrade signal**:
- Corpus Christi Stage 3 的 SPA 合同化进度超预期 (剩余 ~20% 非合同 volume 签约)
- 管理层公布新终端 FID 或 Sabine Stage 7 规划
- Shareholder return 上调超出 $20B 2025-2027 框架

**Downgrade signal**:
- Henry Hub 与 LNG 亚洲/欧洲现货差价压缩导致 margin on marketed volume 腰斩 (对合同 volume 影响小, 但对非合同 part 大)
- FID 新终端被迫延迟 (Greenfield project 执行风险)

**Break condition (Exit)**:
- 美国 LNG 出口政策重大反转 (2024 拜登政府 LNG export 审批暂停是预警, 后续政策走向)
- SPA 对手方大规模违约 (低概率, 对手方质量高)

**⚠ 财务 verification**: 当前 PE / EV/EBITDA / FCF run rate / 回购节奏

## #3 · KMI · Kinder Morgan

**Action**: `Initiate`

**Why this action**:
- **纯 Bridge 中游**: 5 条独立 trigger 的天然气需求共振 (LNG 出口 + DC 发电 + 工业 + 供暖 + 墨西哥出口). FY24-25 LNG feedgas 合同占比显著上升 (从 ~8-10 Bcf/d 向 15+ Bcf/d 过渡)
- **Bridge 硬测试**: LNG feedgas 若归零 → 剩 DC + 工业 + 供暖 + 墨西哥 ≈ 75-85%; DC 若归零 → 仍 75%+. 任一 chain 崩 resilience 强
- **Duration via fee-based contracts**: 90%+ revenue 是 long-term take-or-pay / minimum volume commitment, 合同 10-20 年
- **Expectation gap**: market 习惯把 KMI 当 "利率 proxy" 定价, 忽略了 LNG feedgas + DC 需求的结构性增量. 这是**慢变量叠加的复合增长**, generalist 忽视

**Upgrade signal**:
- 新 pipeline 扩产 FID (e.g. 从 Permian 到 Gulf Coast 新气管)
- DC hyperscaler 锁定 direct gas supply 合同 (新 trend, 2025-2026 刚开始)
- Adjusted EBITDA growth 超 4-5% YoY (突破稳态)

**Downgrade signal**:
- 联邦 permitting 进一步收紧 (2024 Chevron deference 案后 permitting 环境复杂化)
- Distribution payout ratio 恶化或 CapEx/D&A ratio 结构性下降

**Break condition (Exit)**:
- 美国天然气出口政策彻底逆转
- 与主要 shipper 重大合同失败续签

**⚠ 财务 verification**: 当前 DCF payout / leverage / LNG feedgas commitment cadence

## #5 · FLNG · FLEX LNG

**Action**: `Initiate (light)` (小市值 + 挪威治理, 仓位控制)

# v2.1 Framework 验证观察 (累积到 v2.2 补丁清单)

**1. Bridge 硬测试在 LNG 多 sub-theme 应用顺利, 无新缺口**:
- GTLS (4 条 trigger 独立): LNG / H2 / CCUS / 工业气体 / maintenance, 任一崩 resilience 55-75%
- KMI/WMB (5 条 trigger 独立): LNG / DC / 工业 / 供暖 / 墨西哥, 任一崩 resilience 75-85%
- 两家都严格通过 v2.1 trigger-independence + ≥30% resilience, 无需文字修正

**2. Duration 硬测试在 "长资产 vs 短合同" 场景下暴露一个次要问题** (不紧急):
- KMI/WMB pipeline 资产本身 30-50 年寿命, 但 fee-based 合同 10-20 年
- 严格按 v2.1 ratio = monetization_window / deployment_cycle 算, 应看**合同期** (monetization lock-in) 而不是资产寿命
- 结果 ~1-2x, 似乎 borderline, 但 pipeline 合同 renewal 率极高 (历史 >95%), 实质锁定 30+ 年
- 问题: 如何在硬测试中表达 "合同 renewal 概率" 这种 soft 延续性? 当前硬测试文字不含此 scenario
- 建议: **v2.2 补丁候选 #4** — 若 monetization window 名义 < 2x deployment 但 renewal rate >80% 历史数据, 实质窗口应按 lifetime 扩展. 待再一个案例出现后加入

**3. Hot-theme penalty 在 LNG 首次正式触发**:
- LNG (Cheniere) 按纯质量应为 #1 (duration 最强 + owner 最完整), 但 scanner rule #4 + v2.1 expression selector hot-theme 判据降至 #2
- Expression type 的实际最佳 = **"less-crowded 表达层"** GTLS, 而不是 textbook duration leader. 这验证了 rule #4 + rule #7 (diffusion asymmetry) 组合的 framework 价值

**4. Commodity E&P 的 bucket 分离纪律有效**:
- CRK / EQT 虽然是 "LNG feedgas" 供应, 但 commodity bet 的 alpha 结构与 structural owner 完全不同 (价格敏感 vs 合同稳定)
- 按 skill rule #2 分离 bucket, 避免混入 Top 5 污染
