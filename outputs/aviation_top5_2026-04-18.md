# Quick Reference · 排序规则 + 8 名单全局

## 排序规则(6 条, 按优先级从高到低)

1. **FROG 先过关** — F(Forced demand)/ R(Restricted node)/ O(Owner clarity)/ G(Gap in expectations)四测任一 Fail = 自动 Watch/Avoid,不进 Top 5(Article IX)
2. **Active catalyst > Steady-state** — 同等 Owner quality 下,活跃并购 / 新制度事件 / 新合同 > 稳态执行
3. **Pace gap 大小** — realization 领先 diffusion 的距离决定相对位置
4. **Owner 三层完整度** — Revenue / Profit / Return 三层全通 > 只通过两层
5. **Alpha category 纯度** — 结构性稀缺 owner 放 Top 5,周期性错价单列 Observation(不混排)
6. **财务 verify, 不 decide** — PE / FCF / 52w return / margin **不驱动排名**,只验证因果链未断 + 决定仓位规模

## #1 · FTAI · FTAI Aviation

**Action**: `Initiate`(带止盈纪律,不作 buy-and-hold)

**Why this action**:
- Forced demand: Boeing 月产硬盖 + LEAP/GTF 问题 → 737NG / A320ceo 被迫继续飞 → CFM56 售后需求不是可选
- Chokepoint (scale-based): 独立 MRO 最大的 CFM56 模块/件存量 + CFM 官方 2026-01-22 多年协议背书,把 FTAI 抬到"半体制内"位置
- Owner 三层全通: Aerospace Products Adjusted EBITDA +76% YoY 是已兑现,不是叙事
- Gap: 特别股结构 + Fortress spin 历史 → generalist 覆盖偏少,与同等经营兑现速度公司对比 diffusion 最浅

**Upgrade signal (Initiate → Add)**:
- 与 CFM / Safran 协议再升级(如指定某类模块独家)
- 连续 2 季度 Aerospace Products EBITDA YoY ≥ 50%
- 新 hub 产能开通且**首季度利用率 ≥70%**

**Downgrade signal (Initiate → Trim)**:
- Boeing 月产**稳定 ≥42 连续 2 季度**(不是单月爬到)
- 任一主要 MRO 公开宣布 **≥$200M CapEx** 投入 CFM56 独立模块服务 或 与 OEM 签 CFM56 模块独家协议
- 管理层**FY 指引下调 ≥10%**
- 重大 M&A 偏离核心模式

**Break condition (Exit)**:
- 独立 MRO 竞争者规模匹配(存量+修理网络同量级)
- 全球 CFM56 退役速度 +2σ(LEAP 替换突然加速)
- 重大航司客户破产或支付能力恶化
- 全球 RPK YoY < 3% 持续 2 季度(运营杠杆反向)

## #2 · AIR · AAR Corp

**Action**: `Initiate`

**Why this action**:
- Forced demand: 同 FTAI 需求源,落在另一层 — airframe 重维修 / parts distribution / repair cycle
- Chokepoint (cert + scale hybrid): MRO 槽位的 3-5 年起步障碍(FAA cert + 技师培训 + 工具)比一般估值高;HAECO Americas 收购后 AAR 成为 US MRO 产能集中化 consolidator
- Owner: $850M 多年合同**把新增产能卖满在开工前** → 利润能见度高;Q3 FY2026 销售 +25% / EBITDA +26% 已兑现
- Gap: 比 FTAI 略浅(AAR 更广泛被关注),但仍未按"capacity owner"定价,多数投资者仍视为传统 MRO

**Upgrade signal (Initiate → Add)**:
- HAECO 整合 synergies **兑现早于原指引 1+ 季度**
- 新多年合同(**单笔 ≥ $200M** 或涉及新客户)
- 新 hangar 认证 / 扩能进度超预期

**Downgrade signal (Initiate → Trim)**:
- 整合摩擦(**margin 低于 ramp 期指引 ≥100bps**)
- 新进入者宣布 US MRO 扩能(Lufthansa Technik US / SIA Engineering 进入 US)
- **单季度 book-to-bill < 1.0**

**Break condition (Exit)**:
- 全球 RPK YoY < 3% 持续 2 季度
- 重大客户削减维护强度(加速退役)
- 整合成本实质损伤 FY2027 FCF
- 主要航司决定自建 MRO(低概率但监控)

## #3 · HEI · HEICO(v2 上调, 从 v1 的 #5 提升到 #3)

**Action**: `Initiate`(light)

**Why this action (causal-first)**:
- Active catalyst(决定排名的关键理由): **Wencor 整合 tail 仍在走** — 2023 收购, 2026 FSG 仍在吸收 cost synergies 和交叉销售, **不是 steady-state 被动复利**, 是**活跃的 transmission 事件**
- Chokepoint (true cert): FAA / PMA 认证件 + 维修 / 分销网络 — cert-based owner
- Owner 真实: FSG 收入 +15% / OP margin 24.5% / operating income +21% — Wencor transmission 在 segment 级数字上的实锤, 不是叙事
- **比 HWM 排得高的原因**: 同等 Owner quality 下, HEI 有活跃并购 catalyst, HWM 只有稳态执行。**Active catalyst 权重 > steady-state quality**

**Upgrade signal (Initiate → Add)**:
- 单季度 FSG 增速加速到 **≥18%**(Wencor synergies 超指引)
- Wencor cost synergies 兑现早于原指引 1+ 季度
- 板块整体 -15%+ 回调带出 HEI 同幅下跌

**Downgrade signal (Initiate → Trim)**:
- FSG 增速降至 **<10% 持续 2 季度**(Wencor tail 耗尽)
- 重大新收购 deal 溢价过高(破坏历史纪律)
- FSG OP margin 环比下降 ≥100bps 或 YoY 下降 ≥50bps

**Break condition (Exit)**:
- FAA 对 PMA 定价 / 审批重大规则变化(低概率但关键)
- 航司集体绕过 HEI 分销层做直采
- Wencor 整合财务事故(失败概率低)

**财务 verification(不驱动排名)**:
- FSG +15% / +21% OP income 一致性 → 因果链未断
- 50x+ PE 不判断"买不买", 仅判断"仓位多大" → Initiate **light**

## #4 · HWM · Howmet Aerospace(v2 下调, 从 v1 的 #3 降到 #4)

- **无新 active catalyst**: 兑现处于稳态(OEM 爬产按计划 + shop visit 线性), 不是并购 / 新制度事件
- **排在 HEI 后的原因**: 结构性强于 HEI, 但**少一个活跃催化器** — 稳态不等于 Initiate 理由
- 组合定位: FTAI/AIR 若因周期信号 Trim,HWM 合约锁定 + 防务 offset 使其成为**周期转弱时的 anchor**

**Upgrade signal (Track → Initiate)**:
- 新长期 LTA 官方披露(与主要引擎 OEM 客户)— 这是 active catalyst 出现
- 新产能扩张**提前**投产 + 首季度利用率达标
- 股价从当前水平 **-15%+ 回调**(仅作为次级触发, 因果已满足时)

**Downgrade signal (Track → Watch)**:
- Engine Products 单季度 YoY revenue growth <10% 持续 2 季度
- GE 或 RTX 管理层公开讨论延长 engine overhaul 周期
- Engine Products EBITDA margin 环比下降 ≥100bps

**Break condition (Exit)**:
- 新材料/增材制造对 Ti/Ni 结构件规模化替代(需要 5 年+,但盯 GE/Rolls R&D 路线图)

**财务 verification(不驱动排名)**:
- Fwd PE 45x / 52w +115% 不是 disqualifier, 是"等新催化"的理由

## #5 · ATI · ATI Inc.(v2 降级, 从 v1 的 #4 Initiate 降到 #5 Watch)

**Action**: `Watch`(不 Initiate) — **等因果澄清**

**Why this action (causal-first)**:
- Chokepoint 真实: aerospace-grade 钛 + 高温合金熔炼,专用熔炉 + 多年合格 — 与 HWM 同性质但再上游一层
- Owner 结构正面: A&D 占整体 68% / HPMC 内部 91% A&D → 是航空防务材料 pure-play
- **但有一个需要因果解释的现象**: Rev YoY +0.4%(组内最弱), 而 52w 股价 +272%(组内最强) — 股价兑现远跑在 business 兑现之前, 存在两种可能:
  - (a) 容量受限,chokepoint 自身把增长堵住 → thesis 反而成立
  - (b) 终端需求疲软 → thesis 破
  - (c) 周期时差(deferred volumes) → thesis 中性
- **没有因果澄清前,不是 Initiate 对象,是 Watch 对象** — 这是财务 verify 的正确用法(不下结论,flag 追问)

**Upgrade signal (Watch → Initiate 小仓)**:
- 管理层或电话会议明确解释 +0.4% 是**容量约束**(产能利用率 >95%, backlog 增长)
- Rev growth 回到 **≥10% YoY 连续 2 季度**
- HPMC EBITDA margin 超指引 ≥200bps(证明是"量被堵价上涨")

**Downgrade signal (Watch → Avoid)**:
- 管理层承认终端需求疲软
- Rev growth 连续 2 季度 <0%
- Margin 扩张停滞 + backlog 下降

**Break condition**:
- Ti spot pricing 暴跌 + 供应链常态化 2 年以上
- 主要客户重大 mix 转换(远离 Ti/Ni 特种合金)
- aerospace 周期见顶 + 扩能超产 → 价差压缩

**财务 verification 角色说明**:
- Rev +0.4% + 52w +272% 的 divergence **不用来直接淘汰**, 用来**触发因果追问**。追问结果决定升 Initiate 还是降 Avoid。这是 CLAUDE.md 跨层硬规则 #6 的正确应用。

## Observation List(active watch, 3 picks)

  - aftermarket 季度 organic growth(保持 ≥8% = Owner quality 仍在)
  - 并购 deployment cadence(历史纪律是否维持)

### Obs-2 · GE · GE Aerospace — "Market-known leader, 等 rotation"

- **不入榜原因**: Services growth 26% + $190B backlog 是市场共识叙事,Gap 在 leader 层已收敛

- **Watch metric**:
  - CES shop visit volume YoY trajectory
  - services backlog 环比
  - capital return rate(buyback + dividend pace)

### Obs-3 · AER · AerCap — "不同 alpha category, 独立纪律"

- **不入榜原因**: 周期性资产错价(book value reset),不是结构性 chokepoint owner。**持有逻辑 / 退出纪律与 Top 5 不兼容**,混排会误导读者用同一套纪律看不同 alpha
- **Upgrade path**: **不迁入 Top 5** —— 作为独立 cyclical opportunity,触发另一张表(待建)
- **Watch metric**(优先级从高到低):
  - Boeing 月产(稳定 ≥42 = Trim / ≥48 = Exit)
  - 二手机价值指数 YoY
  - 租赁利率 spread(新签 vs. 到期)
  - AER 自身 buyback 相对 BV 的折价幅度
