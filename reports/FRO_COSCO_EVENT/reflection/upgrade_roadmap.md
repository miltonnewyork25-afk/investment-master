### 质量趋势诊断

```
IHG(4.3) → NVDA(4.0) → SBUX v4(4.05) → HLT(3.9) → SPGI(3.55) → MSCI(3.8) → FRO(3.92)
         ↓-0.3           ↑+0.05          ↓-0.15      ↓-0.35        ↑+0.25     ↑+0.12
```

**诊断**: IHG后质量波动(±0.35), 但没有持续下降趋势。SPGI是异常值(0.44 DM密度=历史最低)。FRO/COSCO(3.92)验证了新框架(EDAF)可以在首作达到合理质量。

**健康信号**: 3.55(SPGI)是底部, 近3份均>3.8 → 质量企稳。
