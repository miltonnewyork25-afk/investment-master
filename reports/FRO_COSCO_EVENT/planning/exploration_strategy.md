# P4: "Unknown Unknowns" 探索策略

> 用户明确要求: "探索unknown unknowns分析区间 — 进入无人引导的agent自主探索模式"
> 这意味着: 不仅回答已知问题(CQ1-8)，还要发现我们不知道自己不知道的东西

---

## 1. 为什么需要Unknown Unknowns探索?

传统分析框架(包括我们的Tier 3)有一个根本局限: **你只能分析你想到的问题**。

事件驱动分析尤其危险，因为:
- 地缘政治的非线性 → 最大的风险/机会往往来自"没想到"的方向
- Zoltan框架本身就是一种"已知已知" → 如果我们只验证/反驳Zoltan，我们就被他的框架限制了
- 真正的alpha来自**Zoltan没提到的东西**

## 2. 五条探索路径

### 路径A: 历史不类比 (Anti-Analogy)

**方法**: 不找"类似"事件，找"看起来类似但结果完全不同"的事件
**问题**:
- 1987两伊战争中的油轮战(Tanker War) → 为什么运价影响远小于预期?
- 2003伊拉克战争 → 霍尔木兹封锁恐慌 → 实际没封 → 运价如何反应?
- **关键**: 市场对"霍尔木兹封锁恐惧"的免疫力有多强? 过去30年cry wolf太多次了?

### 路径B: 二阶受益者搜索 (Second-Order Winners)

**方法**: 不看油运公司，看**因为油运变化而受益/受损的非显然公司**
**探索方向**:
- 战争险保险商: 保费12-40x → 谁是最大的战争险承保商? 利润如何?
- 替代航线受益者: 好望角绕道 → 南非港口公司? 加油站(bunker)供应商?
- LNG替代: 霍尔木兹封LNG → 美国LNG出口商(Cheniere)受益?
- 造船厂: 订单暴增 → 但2028前无法交付 → 韩国造船(HD韩国造船)?
- **石油储备**: 各国动用SPR → SPR股/期权?

### 路径C: 反面情报 (Counter-Intelligence)

**方法**: 主动搜索"为什么这个投资会失败"的信号
**搜索目标**:
- 做空FRO的机构: 谁在空? 为什么? 空头论点是什么?
- 中远海能的卖方报告: 有没有降级的? 理由?
- 航运分析师中的contrarian: 有没有人说"运价已见顶"?
- 预测市场: Polymarket上伊朗停火/谈判的赔率

### 路径D: 制度裂缝 (Institutional Cracks)

**方法**: 寻找"系统设计者没想到"的制度裂缝
**探索方向**:
- **旗国套利**: FRO挂百慕大旗 → 能不能换旗? 换什么旗能保持P&I又获东方通行?
- **保险创新**: 有没有新的保险产品正在被创造? (区块链/P2P/参数化保险?)
- **船舶租赁**: FRO能不能把船租给中远? (跨阵营合作的可能性)
- **管道替代**: 如果霍尔木兹长期封锁 → 管道替代(East-West pipeline)的经济性?
- **数字货币结算**: 影子船队用什么结算? USDT? 人民币? 黄金? 这对crypto有什么含义?

### 路径E: 时间错配 (Temporal Mismatch)

**方法**: 寻找"市场看的时间框架"和"事件实际时间框架"的错配
**探索方向**:
- 期货曲线: 运价远期 vs 现货 → 折价幅度=市场的"不信"程度
- 期权隐含波动率: FRO的IV → 市场对未来波动的定价
- 分析师预测更新: 冲突后卖方有没有调整FRO目标价? 调了多少? → 如果调得不够=机会
- **"钝感"指标**: 哪些市场参与者还在用"冲突前"的模型? → 他们被迫调整时会创造价格压力

## 4. "Unknown Unknowns"检测信号

怎么知道我们发现了一个真正的unknown unknown?

**信号特征**:
1. **第一反应是"这不可能"** → 然后发现有数据支持
2. **Zoltan完全没提到** → 不在他的6条逻辑链中
3. **改变概率赋值** → 让某个情景的概率移动≥10pp
4. **创造新的投资标的** → 不是FRO/中远，是完全意想不到的受益者

**历史案例**: 2022俄乌冲突中的unknown unknown = 影子船队的速度
- 没有人预测到12个月内能建立一支978艘的影子船队
- 这改变了制裁效力的底层假设
- 类似的，2026伊朗冲突可能有我们现在看不到的结构性变化
