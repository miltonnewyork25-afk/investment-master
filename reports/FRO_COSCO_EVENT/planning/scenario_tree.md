# P6: 情景树设计 — ≥4情景 × 概率 × 时间路径

> 事件驱动情景树 vs 传统情景分析的区别:
> 传统: 牛/基/熊 (同一时间框架, 不同增长率)
> EDAF: 不同**事件路径** × 不同**时间框架** × 不同**系统状态**

---

## 1. 四大情景定义

### S1: 快速降级 ("Cry Wolf Again")
**概率**: 20% | **时间框架**: 3-6个月

```
路径:
  美军护航成功 → IRGC军事能力被显著削弱
    → 霍尔木兹通行逐步恢复
    → P&I保险6个月内恢复承保
    → 运价从$423K回落至$80-120K/天
    → 影子船队部分回归合规体系

FRO影响:
  收入: Q1-Q2高位 → Q3-Q4回落 → FY2026 EPS ~$4-5
  估值: PE从12.8x压缩至8-10x (因为EPS是"最后一波")
  Fair Value: $32-50 → 但之后回落至$20-25
  → 如果现在$31买入 → 短期+60% → 长期-20% → 时机关键

中远影响:
  "东方通行证"价值消失 → 回归正常运营
  估值: 回到PB 1.0-1.1x → HK$16-18
  → 如果现在HK$19.55买入 → -10-15%
```

**S1核心假设**:
- 美军有能力恢复通行 (军事假设)
- 伊朗IRGC没有持续作战能力 (军事假设)
- 市场过去30年对霍尔木兹恐慌的免疫力 (市场假设)

**S1反面**: 但2026不同于过去cry wolf — 这次真的发生了(21次攻击+零通行)

---

### S2: 持续对峙 — 新常态 ("New Normal")
**概率**: 35% | **时间框架**: 6-18个月

```
路径:
  美伊军事僵持 → 护航部分成功但不完全
    → 霍尔木兹通行恢复至50-70%
    → P&I保险部分恢复(政府担保部分)
    → 运价从$423K回落至$150-250K/天(新均衡)
    → 双轨体系初步形成(合规船+影子船)
    → 类似红海胡塞的长期化

FRO影响:
  收入: TCE稳定在$120-180K/天(vs FY2025 ~$40K均值)
  估值: 如果市场认可"新常态" → PE压缩至7-9x但EPS大幅上升
  EPS: $5-8/年 → Fair Value: $35-72
  → 范围很宽, 取决于市场是否认可持续性

中远影响:
  "东方通行证"价值持续但非垄断(西方也部分恢复)
  运价高位 + 中国航线独占溢价
  估值: PE压缩至10-12x, EPS上调20-30%
  → H股 HK$22-28 (+12-43%)
```

**S2核心假设**:
- 军事僵持是稳态 (这是最大争议点)
- 运价不会完全回落因为保险永久变贵 (制度性假设)
- 影子船队扩张不会完全替代合规运力 (供给假设)

**S2的关键验证**: 红海胡塞先例 — 2023年12月开始，至2026年3月仍在持续 → 证明"新常态"是真实可能的

---

### S3: 全面升级 ("Strait Closed")
**概率**: 15% | **时间框架**: 1-6个月(事件) + 长尾

```
路径:
  冲突升级 → 伊朗正式宣布关闭霍尔木兹
    → 布雷 + 反舰导弹 + 无人机全覆盖
    → 所有商业通行停止(包括东方船)
    → 全球石油供给减少15-20Mb/d
    → Brent $150-200+/桶
    → 全球衰退 + 通胀危机

FRO影响:
  矛盾! 运价理论上无上限, 但:
  → 如果波斯湾完全不能进 → FRO的VLCC去哪? → 非ME航线争夺
  → 西非/美洲/北海运价暴涨 → FRO仍受益但不如S4
  → 系统性风险: 金融危机→运价也可能崩(2008 BDI -94%)
  Fair Value: 极度不确定 → $15-80范围(取决于金融系统是否崩溃)

中远影响:
  "东方通行证"失效(全面封锁=不区分东西方)
  → 但中国战略石油储备+陆路管道(中缅/中俄) → 部分对冲
  → 中远LNG船可能被政府征用
  → H股: 可能暴跌(全球risk-off) → 但A股可能受保护
```

**S3核心假设**:
- 伊朗有能力全面封锁(军事假设 — 有争议)
- 全面封锁不会在1周内被美军破解(军事假设)
- 金融系统能承受油价$200(金融假设 — 2008前例说不一定)

**S3为什么概率只有15%**: 全面封锁也损害伊朗盟友(中国的石油进口) → 伊朗更可能选择S4(选择性)

---

### S4: 选择性封锁长期化 — Zoltan基准 ("Two Universes")
**概率**: 30% | **时间框架**: 18个月-5年+

```
路径:
  Zoltan的70%基准情形 → 但我们给30%(Zoltan高估了)
    → 伊朗维持选择性封锁: 只拦西方旗/西方保险船
    → "东方G7"建立独立物流+保险+结算体系
    → 全球大宗商品市场永久分裂
    → 运价结构性重估: 西方运力永久短缺
    → 布雷顿森林III的开始

FRO影响:
  复杂! FRO在"西方宇宙"中:
  → 西方运力短缺 → 运价结构性高位($200-350K/天)
  → 但波斯湾航线永久关闭 → 运输距离变长
  → FRO可能成为"西方运力垄断者"之一
  → EPS: $6-10/年 持续 → PE重估至10-12x
  → Fair Value: $60-120 (当前$31 = 93-287%上行)

中远影响:
  "东方通行证"= 核心资产 → 独享ME-China航线
  → 但也承担了"东方体系"的全部风险(制裁/脱钩)
  → 如果中国保险体系成熟 → 中远的竞争优势固化
  → PB重估至1.5-2.0x → H股HK$25-33 (+28-69%)
  → A/H溢价可能收窄(H股追赶)
```

**S4核心假设**:
- 伊朗有持续5年选择性封锁的能力(军事+经济)
- 中国真的会建立独立体系(外交假设)
- 美国不会对伊朗使用核武器级别的军事手段(政治假设)
- 全球经济能在分裂状态下持续运转(经济假设)

## 3. 情景概率的敏感性

概率赋值是最主观的判断。测试不同概率下的结论:

| 概率组合 | S1 | S2 | S3 | S4 | FRO EV | 中远 EV | 结论变化? |
|---------|----|----|----|----|--------|---------|---------|
| 我们的基准 | 20% | 35% | 15% | 30% | $53.4 | HK$23.3 | — |
| 偏乐观 | 10% | 30% | 15% | 45% | $65.2 | HK$25.6 | FRO更好 |
| 偏悲观 | 35% | 35% | 15% | 15% | $39.9 | HK$20.6 | FRO仍有+28% |
| 极端悲观 | 50% | 30% | 10% | 10% | $31.9 | HK$19.0 | 接近fair, 不做 |

**关键发现**: 除非S1>50%(极端悲观), FRO都有正期望 → 风险收益比偏正

## 5. 情景间的不独立性

```
S1和S4互斥(不能同时发生) → P(S1)+P(S4)≤100% ✓
S2和S4部分重叠(S2可能演变为S4) → 需要考虑路径依赖
S3可能是临时状态(全面升级→然后降级或固化)

路径依赖:
  现在→6个月: S1(20%) / S2(50%) / S3(15%) / S4(15%)
  6个月→18个月: S2中30%可能变成S4 → 终态S4权重上升
  → 持有期越长, S4的概率越高 → 长期持有偏FRO
```
