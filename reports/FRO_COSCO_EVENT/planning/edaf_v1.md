# EDAF v1.0 — 事件驱动分析框架
# Event-Driven Analysis Framework

> **设计目的**: 传统Tier 3框架假设business-as-usual + 周期波动，不适用于地缘冲突触发的非线性事件。
> EDAF补充三个传统框架缺失的维度: **时间衰减** / **情景分叉** / **双向不对称性**。

---

## 1. EDAF vs 传统框架 — 核心区别

| 维度 | 传统Tier 3 | EDAF事件驱动 |
|------|-----------|-------------|
| **时间假设** | 5-10年DCF, 平滑增长 | 事件信号有半衰期, 6个月-3年窗口 |
| **估值锚点** | 内在价值(DCF/SOTP) | 情景加权 × 时间衰减 |
| **核心问题** | "值多少钱?" | "这个价格在赌什么? 赌对了吗?" |
| **风险维度** | 业务风险+估值风险 | + 事件路径风险 + 时间框架风险 |
| **对标方式** | 同行业可比 | **对立方对标**(西方船队 vs 东方船队) |
| **胜率分析** | 正/中/负三情景 | **情景树**(≥4分支 × 概率 × 时间路径) |
| **退出策略** | 长期持有 | 事件信号衰减=退出信号 |

## 2. EDAF五层分析架构

```
Layer 1: 事件解剖 (Event Anatomy)
  ├── 触发事件 → 传导链 → 受益者/受损者
  ├── 事件的"保质期" — 市场需要多久消化?
  └── 信号 vs 噪音 — 哪些是结构性变化, 哪些是恐慌定价?

Layer 2: 传导链映射 (Transmission Mapping)
  ├── 一阶效应: 军事冲突 → 霍尔木兹封锁 → 运价spike
  ├── 二阶效应: P&I取消 → 西方船不能进 → 运力分割
  ├── 三阶效应: 影子船队扩张 + 东方通行证 → 双轨物流体系
  └── N阶效应: 货币体系重构? 布雷顿森林III?

Layer 3: 市场定价审计 (Pricing Audit)
  ├── 逆向拆解: 当前股价隐含什么假设?
  ├── FRO $31.30 @ PE 12.8x → 隐含运价回落至$XX/天
  ├── 中远海能 HK$19.55 → 隐含什么?
  └── 运价期货曲线 vs 现货 → 远期折价多少?

Layer 4: 情景树 + 概率 (Scenario Tree)
  ├── S1: 快速降级(3-6月) — 运价回落
  ├── S2: 持续对峙(6-18月) — 新常态运价
  ├── S3: 升级(全面封锁) — 运价无上限 + 系统性危机
  └── S4: 选择性封锁长期化(Zoltan 70%基准) — 双轨体系固化

Layer 5: 对立方分析 (Adversarial Comparison)
  ├── FRO(西方船队): 在哪些情景下受益? 受损?
  ├── 中远海能(东方船队): 同上
  ├── 交叉点: 有没有两者同时受益/受损的情景?
  └── 投资选择: 哪个是"更好的赌注"? 还是做pair trade?
```

## 3. 时间衰减模型 (Event Signal Half-Life)

事件驱动投资的核心困境: **"方向对 + 时间错 = 亏钱"**

### 三种时间形态

```
形态A: 脉冲型 (Pulse)
  运价spike → 3-6个月回落 → 均值回归
  → 对应S1情景
  → 投资含义: 如果你没有在spike前买入, 现在追高=接盘

形态B: 阶梯型 (Step-change)
  运价上一个台阶 → 新常态 → 不完全回落
  → 对应S2情景
  → 投资含义: 新均衡运价是多少? FRO在新均衡下PE压缩多少?

形态C: 体制型 (Regime-change)
  全球物流体系永久分裂 → 运价结构性重估
  → 对应S3/S4情景(Zoltan的基准情形)
  → 投资含义: 传统估值框架失效, 需要用"新世界"估值
```

### 历史参照

| 事件 | 形态 | 运价影响 | 持续时间 |
|------|------|---------|---------|
| 2008金融危机 | 脉冲(反向) | BDI跌94% | 6个月spike→18个月谷底 |
| 2020 OPEC+战争 | 脉冲 | VLCC TCE $300K→$50K | 3个月 |
| 2022俄乌冲突 | 阶梯 | 运价+50-100%, 未完全回落 | 影子船队建立=结构性 |
| 2023红海胡塞 | 混合 | 苏伊士绕道好望角, 运价+100% | 12+个月, 仍在持续 |
| **2026伊朗冲突** | **?** | **VLCC $423K ATH** | **进行中** |

**关键判断**: 2026伊朗冲突是脉冲(A)还是阶梯(B)还是体制(C)?
- 如果A → FRO当前价已包含大部分上行 → 谨慎
- 如果B → FRO在新均衡下被低估 → 关注
- 如果C(Zoltan的赌注) → FRO和中远海能都只是开始 → 深度关注

## 4. 对立方分析框架 (Adversarial Comparison)

这是EDAF区别于传统横向对标的核心创新: 两家公司不是在同一赛道竞争, 而是分别代表**两个平行系统**的受益者。

### 四象限矩阵

```
                 FRO受益        FRO受损
中远受益    [双赢: 运价暴涨   [东方通行:
             但两个体系都     伊朗只封西方
             缺船]            中远独享波斯湾]

中远受损    [西方主导:        [双输: 和平
             美军护航成功     协议→运价暴跌
             西方恢复通行     但脉冲已过]
             中远OFAC风险]
```

### 维度对标

| 维度 | FRO | 中远海能 | EDAF特有 |
|------|-----|---------|---------|
| 运价beta | 高(纯VLCC play) | 中(更多元化) | 传统维度 |
| 保险通行权 | 受限(伦敦P&I) | 可能双体系 | **EDAF: 制度性分割** |
| 客户锁定 | 西方石油巨头 | 中国炼化 | **EDAF: 客户被事件重塑** |
| 制裁风险 | 低 | 高(OFAC先例) | **EDAF: 政策风险非对称** |
| 船队灵活性 | 中(Fredriksen交易能力) | 低(国企决策慢) | 传统维度 |
| 股息对运价弹性 | 极高(TCE直连) | 中(国企稳定分红) | 传统维度 |
| "东方通行证"价值 | 无 | **核心差异化资产** | **EDAF独有** |
| 做空保护 | 差(可做空) | 强(涨停+受限) | **EDAF: 市场微观结构** |

## 5. 框架局限性声明

EDAF v1.0是首次尝试, 已知局限:
1. **没有事件驱动航运分析的先例报告** — 框架未经验证
2. **地缘政治概率赋值主观性高** — 没有可靠的base rate
3. **数据时效性极强** — 军事局势每天变化, 写报告时的数据可能很快过时
4. **中远海能数据获取困难** — 港股/A股, FMP覆盖不完整, 中文信息源需要
5. **pair trade执行复杂** — 两个市场(NYSE vs HKEX), 做空限制不同

## 6. EDAF对报告结构的要求

传统Tier 3: Phase 1(业务) → Phase 2(护城河) → Phase 3(估值/风险) → Phase 4(红队) → Phase 5(组装)

**EDAF调整**:
- Phase 1 = **事件解剖 + 传导链** (替代传统"业务理解")
- Phase 2 = **双公司深度 + 对立方对标** (替代传统"护城河")
- Phase 3 = **情景树估值 + 时间衰减** (替代传统"估值")
- Phase 4 = **红队** (保留, 但加入"Zoltan框架红队")
- Phase 5 = **组装** (保留)

新增:
- **Phase 0.5: Zoltan框架深度审计** — 6条逻辑链逐一验证/推翻
- **Phase 2.5: 保险通道分析** — P&I/战争险/影子船队专章
