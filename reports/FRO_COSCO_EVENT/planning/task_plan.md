## Zoltan框架核心提取 (Phase S产出)

### 6条主线

1. **大宗商品负担 (Commodity Encumbrance)**
   - 战争给大宗商品加上"地缘政治负担"
   - 霍尔木兹海峡封锁 = 全球抵押品链断裂
   - 纸原油 vs 物理原油脱钩

2. **物流双轨制 (Shadow Fleet)**
   - 西方船队: 受G7合规+P&I保险限制
   - 非西方船队(影子船队): 用主权信用担保, 不受伦敦保险约束
   - 全球有效运力被分割 → 结构性运费上涨

3. **吨海里爆发 (Ton-Mile Explosion)**
   - 西方需要绕道更远的距离获取替代能源
   - 航线拉长 = 有效运力减少 = 运价非线性上涨
   - 造船产能不足(过去10年ESG/去碳化抑制) → 运价无天花板

4. **央行困境 (Fed Put已死)**
   - 加息→金融系统流动性危机(Margin Call)
   - 降息/QE→美元信用崩溃(因为印的钱买不到物理封锁的原油)
   - 美联储"无路可走" → 被迫成为DoLR(最后交易商)

5. **货币治国 (Currency Statecraft)**
   - 俄罗斯提供情报+技术, 消耗美国高成本军事资产
   - 中国建立不受西方制裁和保险管道约束的"影子物流+结算网"
   - 加速人民币/金砖币/黄金替代美元结算

6. **选择性封锁 (Selective Blockade)**
   - 伊朗不是全面关闭海峡, 是只对西方船只封锁
   - "东方G7"能源安全不受影响
   - 全球大宗商品市场被切割为"西方宇宙"和"东方宇宙"
