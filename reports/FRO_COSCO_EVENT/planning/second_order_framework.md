## 核心原则

**传导链**: 大趋势 → 一阶龙头赚钱/扩产 → 资本开支/采购/配套需求 → 二阶公司受益

**在本案中的传导链**:
```
伊朗冲突(大趋势)
  → 一阶: 油价上涨(Brent $65→$103)
  → 一阶: 运价爆发(VLCC $40K→$601K ATH)
  → FRO/中远海能: 看起来是一阶，但需要验证
  → 二阶: 战争险保险商/LNG替代/造船厂/管道/南非港口
```

## 对FRO/中远海能的"真伪验证"（用框架反审自身标的）

### 第一层: 相关性是否真实 ✅ → 通过

| 问题 | FRO | 中远海能 |
|------|-----|---------|
| 公司到底卖什么? | VLCC/Suezmax运力 | VLCC/LNG运力 |
| 产品是否真的用于这个主题? | 是，油轮直接运中东原油 | 是 |
| 收入占比多大? | ~100%(纯油运) | ~80%油运+~20% LNG |
| 是存量还是新增? | 存量业务但运价暴涨=新增利润 | 同上+东方通行证=新增独占 |

**结论**: 不是"概念沾边"，是直接受益。但需注意FRO波斯湾航线占比 → 如果大部分收入来自非ME航线，受益逻辑可能不同于市场叙事。

### 第二层: 传导是否能兑现 ⚠️ → 需验证

| 问题 | FRO | 中远海能 |
|------|-----|---------|
| 下游客户有无真实扩产? | N/A(不依赖客户capex) | N/A |
| 运价到收入的滞后? | 即时(现货市场) | 即时 |
| 需求一次性还是持续? | **核心问题=CQ1** | 同上 |
| 传导链哪里可能断? | P&I恢复→运价回落/和平协议→运价暴跌 | OFAC制裁→东方通行证作废 |

**FRO传导断裂风险**:
1. 冲突突然降级 → 运价脉冲结束 → 已在$31买入=接盘
2. P&I在政府担保下恢复 → 西方船重回波斯湾 → 运力不再稀缺
3. 影子船队扩张 → 替代合规运力 → 超额利润被侵蚀

**中远海能传导断裂风险**:
1. OFAC制裁 → 2019重演 → H股暴跌30-50%
2. 伊朗改变"东方通行证"政策 → 要求更多回报/政治条件
3. 人民币结算要求 → 中国炼化商接受度? 额外成本?

### 第三层: 公司是否拿得到钱 ⚠️ → 关键区分

| 问题 | FRO | 中远海能 |
|------|-----|---------|
| 产业链位置关键? | 是(VLCC稀缺资产) | 是(更稀缺: 能通行的VLCC) |
| 份额提升? | 否(船队固定) | 可能(独占ME-中国航线) |
| 议价权? | 极强(供不应求) | 更强(垄断特定航线) |
| 被替代/压价? | 短期不会(无新船) | 短期不会 |

**但FRO的关键悖论**:
- 运价暴涨 → 但FRO的VLCC能不能进波斯湾?
- 如果不能进 → FRO只在非ME航线受益(间接运价溢出)
- **FRO可能是"看起来是一阶，实际上是二阶"** → 真正的一阶是能进波斯湾的中远海能
- FRO的受益是"运力被挤到其他航线 → 其他航线也涨价" → 这是二阶传导!

### 第四层: 市场是否已充分定价 ⚠️ → FRO可能已过度定价

| 指标 | FRO | 中远海能 |
|------|-----|---------|
| YTD涨幅 | +106% | 两次涨停(~20%+) |
| 当前PE vs 历史 | 22.3x TTM(高位) | 13.6x(正常) |
| 分析师共识 | 100% Buy, 目标$32 ≈ 当前价 | 覆盖偏少 |
| 估值反映多少乐观? | Q4年化PE 7.7x但市场给22.3x=不信持续 | PB 1.2x=几乎零战争溢价 |

**关键判断**:
- FRO: 市场已给了106%涨幅 + 分析师目标=$32≈当前价 → **共识已到**
- 中远海能: 只涨了~20% + PB 1.2x历史低位 → **预期差更大**
- 这验证了Planning阶段的初步判断但加了一个维度: **FRO可能是"一阶外衣下的二阶"**

## 对UU二阶受益者的评估框架

对于我们搜索的二阶公司(战争险保险商/LNG/造船/港口)，用以下打分:

| 维度 | 问题 | 权重 |
|------|------|------|
| **真实性** | 收入中多少%来自这个主题? ≥20%才算真二阶 | 30% |
| **传导确定性** | 传导链有几个环节? ≤2环=确定, ≥4环=脆弱 | 25% |
| **利润弹性** | 运营杠杆多大? 增量毛利率? | 20% |
| **定价程度** | 股价已反映多少? 估值分位? | 15% |
| **持续性** | 一次性还是持续? 周期还是结构? | 10% |

**最容易踩的三个坑(在本案中)**:
1. **"伊朗概念股"≠真受益**: 很多航运股会被贴标签但实际波斯湾暴露为零
2. **运价spike≠利润spike**: 战争险成本+燃油成本+绕航成本吞噬大部分运价增量
3. **"强周期伪装成长"**: FRO的Q4 EPS $1.02 → 年化$4.08看起来像成长 → 但本质是周期峰值

1. **Ch9 "FRO在冲突中"** 必须回答: FRO的波斯湾航线暴露到底多少? 它是一阶还是二阶?

4. **Ch20 "Pair Trade"** 的核心逻辑被强化: 如果FRO是二阶而中远是一阶 → pair trade方向更清晰
5. **新增或扩展**: 对每个二阶受益者候选，用上述四层验证框架逐一检验

## 一句话总结

> **谁先花钱？钱怎么传下来？传到它这里时，还剩多少利润？**
>
> 在本案中: 伊朗花军事成本封锁 → 运价暴涨(价值创造) → 能通行的船东拿到最多(中远=一阶) →
> 被挤到其他航线的船东拿到溢出(FRO=可能是二阶) → 保险商/造船商/港口拿到配套利润(三阶)
