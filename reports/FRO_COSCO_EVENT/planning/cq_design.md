# CQ设计 — 8个核心问题 + 假说

> 事件驱动CQ与传统CQ的区别: 传统CQ围绕"这个公司值多少钱"，
> EDAF的CQ围绕"这个事件会怎么演变 × 谁受益 × 市场定价了多少"。

---

## CQ1: 霍尔木兹封锁是脉冲还是体制变革?

**问题本质**: 时间形态判断 — 这是最重要的单一判断，决定后续所有分析的基础

**初始假说**: 阶梯型(B) — 不会完全回归(红海胡塞先例)，但也不会达到Zoltan的布雷顿森林III(C)

**验证路径**:
- 历史类比: 1980两伊战争8年→航运适应; 2022俄乌→影子船队18个月建立
- 美军护航效力: Guardian Aegis行动的实际通行恢复率
- 伊朗军事持续力: IRGC装备损耗 vs 补给(中俄支持?)
- 影子船队扩张速度: 当前978艘→能否快速再扩100-200艘?
- 保险市场反应: P&I是否会在政府担保下恢复承保?

**CQ1对估值的影响**:
- A(脉冲): FRO fair value ~$22-25 (回归均值) → 当前$31高估
- B(阶梯): FRO fair value ~$30-38 (新均衡PE 8-10x) → 接近合理
- C(体制): FRO fair value $50+ (估值体系重建) → 显著低估
- **离散度极大** — 这是事件驱动分析的本质特征

## CQ2: 当前股价已经Price-in了多少?

**问题本质**: 逆向估值 — FRO $31.30在赌什么运价假设?

**初始假说**: 市场pricing S1-S2中间(运价高位但不持续)，PE 12.8x暗示市场预期2026H2运价回落

**验证路径**:
- Reverse DCF: 当前市值$6.97B隐含的TCE和持续时间
- 运价期货曲线: 远期运价 vs 现货$423K/天 → 折价幅度=市场的时间预期
- FRO管理层指引: Q4财报电话会议对2026展望
- 分析师一致预期: 卖方在给什么目标价? 用什么运价假设?
- 横向参照: 其他VLCC股(INSW/STNG/DHT)的PE → 如果都12-13x则市场统一定价

**CQ2对投资决策的影响**:
- 如果market consensus=S1(脉冲) → 而你判断S2/S3 → 存在定价错误 → 做多
- 如果market consensus已经=S2(阶梯) → 需要S3/S4才有上行 → 风险更高
- **关键: 分清"运价已涨"和"股价已涨"** — Q4后FRO已+106%，但PE从5x涨到12.8x说明EPS也在涨

## CQ3: FRO vs 中远海能 — 哪个是更好的赌注?

**问题本质**: 在"选择性封锁"情景下的西方/东方船队不对称性

**初始假说**: 情景依赖 —
- S1(脉冲): FRO更好(纯运价beta+西方流动性+高股息)
- S2(阶梯): 两者都好但逻辑不同
- S3/S4(体制): 中远海能更好("东方通行证"=结构性竞争优势)

**验证路径**:
- FRO船队在波斯湾的实际暴露: 多少比例航线经过霍尔木兹?
- 中远海能是否真的有"东方通行证"? 有没有被拒绝的案例?
- OFAC制裁风险: 2019先例→中远被制裁概率和影响
- 估值差异: FRO $7B vs 中远~$17B但PE接近 → 中远有中国折价?
- 流动性差异: NYSE vs HKEX → 对散户的可操作性

**CQ3的框架创新**: 这不是传统的"两个竞争者谁更强"，而是"两个平行系统各自的受益者谁更有alpha"

## CQ4: 保险通道是不是比军事封锁更重要?

**问题本质**: Zoltan的核心洞见 — "不需要打沉船，只需要打爆保险管道"

**初始假说**: 是。P&I保险取消是比军事攻击更有效的封锁手段，因为:
- 没有P&I的船无法合法运营(旗国要求/港口要求/融资条件)
- P&I是伦敦高度集中的市场(5大Club) → 单点脆弱
- 即使美军护航成功，保险商可能仍不恢复承保

**验证路径**:
- P&I取消的历史: 之前有没有在军事护航后恢复的先例?
- $20B Chubb计划: 政府担保保险是否足以替代P&I?
- 自保(self-insurance): 大型船东能否自保? FRO有没有这个能力?
- 影子船队保险: 东方船用什么保险? 中国PICC? 中再?

**CQ4为什么重要**: 如果保险通道无法恢复 → 即使军事冲突降级，西方船运仍受限 → S2的概率上升

## CQ5: 影子船队扩张会不会侵蚀FRO/中远的超额利润?

**问题本质**: 供给端适应速度 — 2022俄乌后影子船队6-12个月就建立了

**初始假说**: 短期不会(12个月内)，长期会(18-36个月)
- 当前978艘影子船中~430艘专注伊朗 → 已饱和
- 但$423K/天的运价吸引更多老旧船加入 → 供给弹性
- OFAC制裁去除46%影子运力 → 短期供给收紧
- 新造船2028年前无法交付 → 供给刚性窗口

**验证路径**:
- 影子船队扩张曲线: 2022→2026速度
- 老旧船(15-20年)存量: 能改装成影子运营的有多少?
- OFAC制裁效力: 被制裁的船真的停了还是换旗继续?
- FRO/中远的船龄优势: 年轻船队在保险恢复时有竞争优势

## CQ6: Zoltan的70%概率是否可信?

**问题本质**: 对框架本身的红队 — 我们的分析基于Zoltan框架，但框架可能是错的

**初始假说**: 70%过高。Zoltan是sell-side macro strategist，有incentive夸大极端情景。
但他的逻辑链内部是自洽的，问题在于前提假设:
- 假设1: 伊朗能有效维持选择性封锁 → 需要验证军事持续力
- 假设2: 中国会明确站队东方 → 需要验证中国外交实际行为
- 假设3: 美联储没有工具应对 → 需要验证2022俄乌时美联储的实际操作

**验证路径**:
- Zoltan过去预测准确率: 布雷顿森林III(2022)→4年后实际进展?
- 其他宏观策略师的看法: 有没有系统性反驳Zoltan的框架?
- 预测市场(Polymarket等): 伊朗冲突走向的市场定价
- 历史base rate: 类似地缘冲突持续时间的分布

## CQ7: "两个平行宇宙"对中国投资者意味着什么?

**问题本质**: 报告读者是中国投资者 → 需要回答"我该怎么操作"

**初始假说**: 中国投资者有独特优势 —
- 可以直接买入中远海能(A股/H股) ← 外资受限
- 理解"东方通行证"逻辑 ← 西方分析师可能忽视
- 但也有独特风险: OFAC制裁可能波及中远海能→港股暴跌

**验证路径**:
- 中远海能A/H溢价: 同一公司两个价格 → 哪个更有alpha?
- 港股通持仓变化: 南向资金在买还是卖?
- 中国航运政策: 政府是否在推动建立独立保险体系?
- FRO可操作性: 中国投资者买FRO的渠道和限制

## CQ8: 什么信号意味着"事件结束" — 即退出时机?

**问题本质**: 事件驱动投资的退出策略 — 这是传统分析不需要但EDAF必须回答的

**初始假说**: 三个退出信号 —
1. **P&I恢复承保** → 保险通道修复 = 运价正常化的前奏
2. **美伊谈判启动** → 类似JCPOA → 运价可能暴跌30-50%
3. **影子船队>1200艘** → 供给适应完成 → 超额利润消失

**反面**: 也有"不退出"的情景 —
- 如果Zoltan的体制变革成真 → 这不是事件驱动而是结构性重估 → 长期持有

**验证路径**:
- 历史先例中的退出信号: 2022俄乌→运价什么时候见顶?
- 谈判可能性: 美国大选年对伊政策方向
- 影子船队增速: 如果月增50艘 → 12个月达到1200阈值

## CQ优先级和分组

**第一优先级(决定方向)**:
- CQ1(脉冲vs体制) + CQ2(定价审计) → 决定"有没有机会"

**第二优先级(决定标的)**:
- CQ3(FRO vs 中远) + CQ4(保险通道) → 决定"买哪个"

**第三优先级(风险管理)**:
- CQ5(影子船队) + CQ6(Zoltan可信度) → 决定"风险多大"

**第四优先级(执行)**:
- CQ7(中国投资者视角) + CQ8(退出信号) → 决定"怎么买/什么时候卖"

## CQ之间的依赖关系

```
CQ1(时间形态) ─→ CQ2(定价审计): 不同形态下的fair value完全不同
       │
       ├──→ CQ3(FRO vs 中远): 脉冲→FRO, 体制→中远
       │
       └──→ CQ8(退出信号): 形态决定退出策略

CQ4(保险) ──→ CQ1: 保险恢复速度决定形态
       │
       └──→ CQ5(影子船队): 保险体系影响影子船队增速

CQ6(Zoltan红队) ──→ 所有CQ: 框架可信度影响概率赋值
```
