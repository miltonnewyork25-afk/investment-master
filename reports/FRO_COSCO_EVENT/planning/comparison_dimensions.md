## 2. 核心分化因子深度 (Top 3)

### 分化因子#1: 保险体系 (B2)

```
FRO路径:
  伦敦P&I取消 → 波斯湾不能去
    → 选项A: 等美政府$20B Chubb计划 → 未知时间
    → 选项B: 只跑非波斯湾航线(WAF/Americas) → 运价高但吨海里减少
    → 选项C: Fredriksen自保? → 资本要求极高
    → 净效果: 运价↑但可运航线↓ → 不确定

中远路径:
  如果中国PICC独立承保:
    → 波斯湾仍可进入 → 独享中东-中国航线
    → 但保费可能极高 → 利润被侵蚀?
    → OFAC风险 → 如果被制裁, PICC保险也废了
    → 净效果: 航线优势但风险集中
```

### 分化因子#2: 东方通行证 (B5)

```
验证问题:
  1. 伊朗IRGC是否明确宣布/执行了"中国船通行"?
  2. 有没有中国旗船被攻击/拦截的案例?
  3. 中远海能管理层有没有公开表态?
  4. 如果通行证存在 → 是否可撤销? 条件是什么?

价值量化:
  如果东方通行证 → 中远VLCC可运ME原油
    → 假设30艘VLCC × $400K/天 × 180天 = $2.16B额外收入
    → vs 无通行证(所有VLCC绕道WAF) = 吨海里减少30%
    → 差值 = 每年$0.6-0.8B → 对$17B市值=4-5% yield uplift
    → 但这已经被两次涨停(~20%+)price-in了一部分
```

### 分化因子#3: OFAC制裁 (B4)

```
2019先例:
  - 中远海运(COSCO Tankers) 2019年9月被OFAC制裁
  - 原因: 运输伊朗石油
  - 影响: VLCC运价全球spike(因为中远船退出市场)
  - 2020年1月解除(4个月)

2026风险评估:
  - 如果中远海能利用"东方通行证"运伊朗油 → OFAC重新制裁概率高
  - 但2026 vs 2019:
    - 中美关系更差 → 制裁阈值更低
    - 但中国反制裁能力更强 → 效果可能更弱
  - 制裁影响: H股可能-30-50% → 但A股可能被保护(国内投资者)

  → 这是中远海能的"东方通行证"期权的隐含成本
  → 期权价值 = 通行证收益 - OFAC制裁期望损失
```

## 4. 对标的核心结论预判 (待验证)

**初步假说**: 这不是"谁更好"的问题，而是"哪个情景你更信"的问题:
- 信S1(脉冲) → 买FRO(纯运价beta, 高流动性, Fredriksen交易能力)
- 信S3/S4(体制) → 买中远海能(东方通行证, PB 1.2x折价, LNG加持)
- 信S2(阶梯) → Pair trade(做多中远+对冲FRO的波斯湾暴露)
- 不确定 → 等待(但"等待成本"=运价继续涨时的机会成本)

**这个结论是否成立，取决于Phase 0-3的数据验证。**
