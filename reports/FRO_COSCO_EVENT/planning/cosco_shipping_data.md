## 8. 吨海里需求 (Ton-Mile)

### 正面因素
- **航线拉长**: 俄罗斯原油替代→美湾/中东长距离运输增加 → 吸收更多运力
- **中国多元化采购**: 中国炼厂分散进口来源 → 吨海里增长
- **OPEC+增产预期**: 2026年原油过剩→低价刺激远距离套利采购
- **浮仓需求**: 低油价+contango结构→增加浮仓 → 减少可用运力

### 负面/归一化因素
- **吨海里增速放缓**: 过去几年超越运量和运力增长, 现进入归一化阶段
- **非OPEC+增产减速**: 2026年增产放缓
- **中东增产**: 沙特/阿联酋增产→更多短途Middle East→Asia, 减少长途VLCC需求
- **霍尔木兹危机特殊因素**: 如危机持续, 中东油出不来 → 吨海里可能反而下降 (运力闲置) 但剩余可运航线的单位运价暴涨

## 9. 影子船队 (Shadow Fleet / Dark Fleet)

### 规模
| 指标 | 数值 |
|------|------|
| 乌克兰政府目录 | 1,337艘 (截至2026年2月) |
| Windward识别 | >1,900艘暗船 (截至2025 Q3) |
| VLCC中被制裁 | ~100艘正式 + ~100艘灰色 |

### 近期执法
- **2026-01-07**: 美国海军+海岸警卫队在北大西洋扣押俄籍油轮 Marinera
- **2026-03-01**: 比利时在北海扣押俄罗斯影子油轮
- **OFAC 1月10日制裁**: 158艘油轮 → 影子船队运力削减~46%

### 影响
- 制裁执法加强 → 影子船队运力收缩 → 正规船东受益 (运力更紧)
- 老旧影子船减少拆解量 → 全球船队总数虚高
- 中远海能作为中国国企, 在伊朗通航特权+合规运营之间需要平衡
