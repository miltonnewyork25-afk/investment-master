## Chapter 29: 双引擎SOTP估值

### 29.1 为什么需要双引擎SOTP？

Phase 1确认Adobe是**AI分裂体**: Consumer CC(受害, -8)和Enterprise/Document/Firefly(受益, +5~+13)在AI冲击下方向相反。用单一倍数估值(市场当前做法)必然错误——因为10x倍数对Consumer太高(应该7-8x), 对Enterprise太低(应该20-25x)。

**双引擎SOTP逻辑**: 将Adobe拆分为两个"虚拟实体"分别估值, 然后合并:

| 虚拟实体 | 包含业务 | FY2025E收入 | 特征 |
|----------|---------|-----------|------|
| **Consumer Engine** | CC消费/SMB + Express | ~$5.0B | 高竞争/AI受害/低增长 |
| **Enterprise Engine** | CC专业 + Firefly + DC + DX | ~$18.8B | 企业黏性/AI受益/中高增长 |

### 29.2 Consumer Engine估值

| 指标 | 数值 | 理由 |
|------|------|------|
| FY2025 收入 | ~$5.0B | CC消费$4.5B + Express $0.5B |
| 增速 | +5-8% | 面临Canva/AI-native压力, 增速低于公司平均 |
| OPM | ~30-35% | 低于公司平均(竞争+Express投入) |
| EBITDA | ~$1.75B | $5.0B × 35% |
| **合理倍数** | **8-12x EV/EBITDA** | 可比: Canva估值~25-30x(高增长溢价), 但Consumer引擎增速低→折价。参考低增长SaaS(8-12x) |
| **Consumer EV** | **$14-21B** | 中值$17.5B |

### 29.3 Enterprise Engine估值

| 指标 | 数值 | 理由 |
|------|------|------|
| FY2025 收入 | ~$18.8B | CC专业$9.5B + DC$3.5B + DX$5.5B + Firefly$0.3B |
| 增速 | +12-15% | DM ARR +12.6%, DX >30%, DC +16% |
| OPM | ~50-55% | 高于公司平均(高端客户+低销售成本) |
| EBITDA | ~$9.8B | $18.8B × 52% |
| **合理倍数** | **18-24x EV/EBITDA** | 可比: ServiceNow(~30x, +22%), Salesforce(~22x, +11%), ADSK(~25x, +12%)。Adobe Enterprise增速12-15%+50%+OPM→18-24x |
| **Enterprise EV** | **$176-235B** | 中值$205B |

### 29.4 SOTP合并

| 项目 | 低端 | 中值 | 高端 |
|------|------|------|------|
| Consumer Engine EV | $14B | $17.5B | $21B |
| Enterprise Engine EV | $176B | $205B | $235B |
| **合并EV** | **$190B** | **$222B** | **$256B** |
| 减: 净债务 | -$1.2B | -$1.2B | -$1.2B |
| **合并市值** | **$189B** | **$221B** | **$255B** |
| 当前股数 | 411M | 411M | 411M |
| **每股价值** | **$460** | **$538** | **$620** |
| vs当前$252 | **+82%** | **+113%** | **+146%** |

**SOTP中值$538 vs 当前$252 = 上行113%**

**关键洞察**: 市场用~$107B(10.8x EV/EBITDA)给整个Adobe定价, 但Enterprise Engine单独就值$176-235B。**市场在"免费赠送"Consumer Engine的同时, 还对Enterprise Engine打了40-50%的折扣。**

### 29.5 SOTP敏感性

| Consumer倍数 \ Enterprise倍数 | 16x | 20x | 24x |
|------------------------------|-----|-----|-----|
| **6x** | $371 | $468 | $565 |
| **10x** | $395 | $492 | $589 |
| **14x** | $419 | $516 | $613 |

即使对Enterprise最保守(16x), 对Consumer也最保守(6x), SOTP仍为$371 → **vs当前$252仍有+47%上行**。

### 30.4 概率加权估值

```
概率加权EV = $614B×15% + $413B×35% + $284B×25% + $162B×20% + $74B×5%
           = $92.1B + $144.6B + $71.0B + $32.4B + $3.7B
           = $343.8B

概率加权每股价值 = $343.8B / 390M(加权平均股数)
                 = $882

vs 当前市值$107B / 股价$252
上行空间: +221% (概率加权)
```

**但这个$882看起来过于乐观**。让我们做一个更保守的交叉验证:

### 30.5 保守交叉验证: 永续FCF模型

```
FY2026E FCF: ~$10.5B (管理层指引隐含)
假设FCF CAGR: 7% (低于收入增速, 扣除AI投资)
Terminal Growth: 3%
WACC: 10% (高于行业平均, 反映AI风险溢价)

Gordon Growth: FCF_1 / (WACC - g) = $10.5B×1.07 / (0.10 - 0.03) = $160B

每股: $160B / 411M = $389
vs 当前$252 = +54%上行
```

**方法收敛区间**: $341-538, 中值**$420-440**

### 30.7 估值离散度分析

| 离散度来源 | 类型 | 贡献 |
|-----------|------|------|
| Enterprise倍数选择(16x vs 24x) | 方法离散 | 最大($176-235B差距) |

**最大离散来源是Enterprise Engine的估值倍数** — 这取决于GenStudio/Foundry能否证明企业级黏性。如果GenStudio保持>25%增速, 20x+倍数合理; 如果降至<15%, 可能只值15x。

## Chapter 31: 条件评级

### 31.1 评级框架 (PW=6.5混合模式)

PW=6.5处于传统和发现系统的过渡区域。我们给出**主评级+条件评级**:

### 31.2 主评级

**概率加权期望回报**:
- 概率加权EV: ~$344B (五情景)
- 保守EV: ~$160B (永续FCF)
- 方法收敛中值: ~$180B
- 当前市值: $107B

期望回报 = ($180B - $107B) / $107B = **+68%**

**按评级标准**: >+30% = **深度关注**

### 但红队修正后需附加条件:

### 31.3 条件评级矩阵

| 条件 | 评级 | 期望回报 | 概率 |
|------|------|---------|------|
| **如果Enterprise增长持续(>25% GenStudio, >12% DM ARR)** | **深度关注** | >+100% | 35% |
| **如果渐进转型(Enterprise稳, CC消费缓降)** | **关注** | +40-70% | 35% |
| **如果分裂体僵局(受益≈受害)** | **中性关注(偏关注)** | +10-30% | 20% |
| **如果温水煮青蛙或更差** | **中性关注(偏审慎)** | -10% ~ +10% | 10% |

### 31.4 最终评级

**关注 (偏深度关注)**

- 期望回报: +68% (概率加权)
- 置信度: 60% (红队修正后)
- 条件: Enterprise Engine增长是核心验证变量
- 时间窗口: 12-18个月(观察FY2026 2-3个季度的数据)

**评级理由**:
1. Forward PE 9.6x定价了FCF零增长 → 过于悲观(高确定性)
2. 但"过渡期折价"部分合理(CEO交接+商业模式转型)
3. 四种估值方法收敛于$341-538 → 当前$252处于底部
4. **最大的潜在催化剂**: 新CEO确定(尤其如果是AI-native背景) + 2个季度Enterprise数据验证
5. **最大的下行风险**: CC seat转负(KS-01) + GenStudio减速(KS-09) → 评级下调至中性
