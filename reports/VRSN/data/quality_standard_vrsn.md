# VeriSign (VRSN) 深度报告评估标准 v1.0

> **设计原则**: 这是VRSN报告的完整评分手册。每个Phase完成后对照评分, Phase内发现不达标即时补强, 不等Phase 5再修。
> **目标**: 4.4分/5.0 = 总分≥88/110 | 无致命缺陷(D1/D3/D5≥5)
> **特殊性**: VRSN是"极简垄断"——单一产品+政府授权+巴菲特持仓。评估标准需要同时检测"简单中的深度"和"确定性中的风险"。

---

## 第一部分: 8项硬门控 (G1-G8)

> 全部PASS才能提交Complete。任一FAIL=阻断。

| 门控 | 阈值 | VRSN特殊说明 | 检查命令 |
|------|------|-----------|---------|
| **G1 字符** | **≥250K** (用户要求) | 商业模式极简→深度密度要极高, 否则会重复 | `wc -m` |
| **G2 DM密度** | **≥2.0/千字** | 目标500+ DM (合同条款/巴菲特13F/域名数据是独特DM源) | `grep -c 'DM-'` / `wc -m` × 1000 |
| **G3 DM总数** | **≥500** | 250K × 2.0 = 500 | `grep -c 'DM-'` |
| **G4 Mermaid** | **≥30** | 合同时间线/巴菲特持仓/收费站经济学需大量可视化 | `grep -c 'mermaid'` |
| **G5 因果密度** | **≥7.0/万字** | 标杆KLAC(9.28)/MSCI v3.0(9.93), VRSN目标≥7.0 | 因果关键词grep |
| **G6 Python** | **必须** | 收费站DCF + 回购η函数 + 域名增长敏感性 | 脚本存在且执行通过 |

**VRSN必须回答的8个核心问题**:
1. 推定续约是否真的不可打破?(合同风险)
2. 7%/年提价权是否触发反身性?(FICO类比)

### D3: 分析密度 (0-10)

**VRSN特殊要求**: "简单生意"需要"不简单的分析"——每个看似显而易见的结论都需要深挖反面

| 分数 | 标准 |
|:----:|------|

| 9 | 因果密度≥7.0/万字 + 每个核心论点3层证据链 + ≥3个跨报告类比 |

| 7 | 因果密度≥4.0/万字 + 大部分论点有推理 |
| 6 | 因果密度≥3.0/万字 |
| **≤5** | **致命缺陷线** — 断言替代推理 |

**VRSN关键因果链(必须深入展开)**:
1. **收费站经济学因果链**: ICANN合同→独家运营权→100%市占率→定价权(7%/年)→收入公式(域名数×价格)→OPM扩张→FCF→回购→EPS复利
2. **反身性因果链**: 定价权释放(7%/年)→利润飙升(OPM 68%)→政治注意(Warren/DOJ)→制度松动风险→定价权侵蚀?
3. **巴菲特因果链**: 合同确定性(2012买入)→穿越恐慌(2016不卖)→定价权释放(2018坐享)→估值到位(2025减仓)→纪律性退出
4. **域名增长因果链**: 互联网渗透率↑→网站数↑→.com域名↑ BUT AI搜索/App经济→直接搜索不打网址→.com需求增速↓?

### D4: 估值严谨 (0-10)

**VRSN特殊要求**: 收费站模型=高确定性→估值应该更精确(离散度<20%)

| 8 | ≥3种方法 + Python + 离散度<25% |
| 7 | ≥2种方法 + Python + 离散度<30% |
| 6 | ≥2种方法 + 离散度<30% |

**VRSN估值必须包含**:
1. **Reverse DCF**: 当前$241隐含什么增速/提价/域名增长?
2. **收费站DCF**: 域名数×价格×OPM→FCF→永续增长→公允价值(Python验证)
3. **OEY锚定**: FCF Yield 4.8% + g → 所有者总回报
4. **巴菲特隐含估值**: 2025年$285-290减仓→巴菲特认为公允在哪?(反推)
5. **情景树**: 提价权保持/提价权被限制/合同被打破 三路径概率加权
6. **与MSCI对比**: 同为金融基础设施垄断, 但PE 27x vs 36x——差异来自哪里?
