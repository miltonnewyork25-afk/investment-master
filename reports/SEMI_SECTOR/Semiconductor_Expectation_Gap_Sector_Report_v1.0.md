# 半导体板块预期差横向报告 v1.0

> **分析日期**: 2026-03-27
> **覆盖公司**: 13家(NVDA/TSM/ASML/AMD/AVGO/KLAC/LRCX/AMAT/MU/ARM/SMCI/VRT/INTC)
> **分析框架**: 预期差识别器 v2.1 + 信号发现方法论 v1.0 + 穿越周期框架
> **核心问题**: 在AI驱动的半导体"超级周期"中，哪些是真正的结构性变化，哪些是被景气期掩盖的周期性风险？

---

## 1. 核心判断

**一句话**: 半导体板块正在经历一次"周期与范式的叠加定价"——AI需求是真实的结构性变化(范式)，但市场在景气周期的第3年给了所有公司历史最高估值(周期)。结果是：**设计/制造垄断被温和低估(Forward PE 15-24x对30-65%增速)，设备/存储被严重高估(峰值PE是历史区间的2-4倍)**——同一个"AI利好半导体"叙事，在链条的不同位置产生了方向相反的定价错误。

**板块级结论**:
- 4/13家显示"温和低估"(NVDA/TSM/AVGO/AMD) → 市场定价了过快减速
- 6/13家显示"过度乐观"(KLAC/LRCX/AMAT/MU/ARM/INTC) → 周期峰值+估值极端
- 3/13家"基本合理"(ASML/VRT/SMCI) → 品质被正确识别或问题被正确定价
- **最危险的不是"看不到的风险"，而是"看到了利好但忽视了周期"**

### 2.2 两个故事的核心矛盾

```
故事A(多头): "AI是一次性技术革命，半导体需求将结构性上移"
  证据: $470B+ AI基础设施投资 / NVDA $1T管线 / TSM +33% / 半导体趋向$1T
  含义: 所有半导体公司都受益 → 当前估值合理

故事B(空头/周期派): "半导体仍然是周期行业，AI只是延长了周期但不消除周期"
  证据: WFE从未3年连续>7%增长不回调 / 设备PE是历史2-4倍 / MU毛利率74%=峰值
  含义: 设计层可能脱钩周期但设备/存储不行 → 当前设备估值危险

我们的判断: 两者都对一半
  → AI改变了需求结构(故事A在设计/制造层成立)
  → 但没有改变供给周期(故事B在设备/存储层成立)
  → 关键区分: "需求永续"≠"供给不过剩"
```

## 3. 价值链分层：AI利好如何沿供应链衰减

这是本报告最重要的框架发现——**AI利好不是均匀分布在半导体价值链中的**。它从"需求端"(GPU/芯片设计)到"供给端"(设备/材料)逐层衰减，且在每一层面临不同类型的风险。

### 3.1 AI利好衰减模型

```
Layer 1: 芯片设计 (NVDA/AMD/AVGO/ARM)
  AI利好传导: 直接 — "AI需要芯片"
  利好衰减度: 0%(无衰减, 需求直接作用)
  周期敏感度: 低(管线$1T+, 需求可见18个月)
  核心风险: 竞争(ASIC vs GPU) — 不是"有没有需求"而是"谁吃到需求"
  估值锚: Forward PE(增速较可预测)

Layer 2: 芯片制造 (TSM)
  AI利好传导: 直接 — "所有AI芯片都需要制造"
  利好衰减度: ~5%(微量衰减——TSM有定价权但CapEx占比高)
  周期敏感度: 低-中(产能满载但$56B/yr CapEx是刚性成本)
  核心风险: 地缘(台海) — 不是商业风险而是政治风险
  估值锚: Forward PE + 地缘折价调整

Layer 3: 设备 (ASML/KLAC/LRCX/AMAT)
  AI利好传导: 间接 — "AI→更多芯片→更多fab→更多设备"
  利好衰减度: ~30-50%(显著衰减——fab扩产有周期性,设备订单有波动)
  周期敏感度: 高(WFE周期从未被打破,设备是CapEx,不是OpEx)
  核心风险: 周期(PEP-006) — "fab扩产完成后设备订单悬崖式下降"
  估值锚: Mid-cycle PE(必须周期调整,不能用峰值PE)

Layer 4: 存储 (MU)
  AI利好传导: 间接+商品化 — "AI→更多HBM→但HBM产能可以快速扩张"
  利好衰减度: ~50-70%(大幅衰减——存储是商品,产能过剩是历史常态)
  周期敏感度: 极高(收入可跌50%,毛利率可从+74%变-10%)
  核心风险: 产能过剩(PEP-007) — 低PE=峰值信号
  估值锚: 反转PE逻辑(低PE时卖,高PE时买)

Layer 5: 基础设施 (VRT/SMCI)
  AI利好传导: 间接 — "AI→更多数据中心→更多电力/散热/服务器"
  利好衰减度: 取决于IP — VRT ~10%(有IP,有定价权) vs SMCI ~60%(无IP,纯组装)
  周期敏感度: 高(与Hyperscaler CapEx同步)
  核心风险: 有IP者赚钱,无IP者被挤压 — 同一趋势完全不同结局
  估值锚: P/E + 毛利率(区分IP型和组装型)

Layer 6: 转型/挑战者 (INTC)
  AI利好传导: 高度不确定 — "AI可能利好(CPU复兴)也可能利空(GPU替代)"
  利好衰减度: 不可估(取决于转型成功与否)
  周期敏感度: N/A(转型驱动不是周期驱动)
  核心风险: 催化剂金字塔(PEP-005) — 技术可行≠商业可行
  估值锚: SOTP(产品部门+代工期权分开估值)
```

### 3.2 衰减模型的投资含义

```
规则1: 在价值链靠近需求端投资(Layer 1-2), 远离供给端(Layer 3-4)
  因为: AI需求是结构性的但供给扩张是周期性的
  具体: NVDA/TSM > ASML/KLAC > MU

规则2: 同一层内选有定价权的(垄断>竞争)
  因为: 垄断者可以提价消化成本, 竞争者只能降价抢份额
  具体: NVDA(CUDA锁定) > AMD(价格竞争) | ASML(唯一EUV) > LRCX(刻蚀有竞品)

规则3: AI基础设施层选有IP的
  因为: 同一趋势中有IP的赚钱(VRT毛利率34%), 没IP的被挤压(SMCI毛利率6%)
  具体: VRT >> SMCI

规则4: 对周期暴露做时间对冲
  因为: 设计层可以一直持有, 设备/存储层需要择时
  具体: NVDA/TSM=长期持有 | KLAC/MU=周期交易(在谷值PE买,峰值PE卖)
```

## 5. 三种定价错误模式在半导体的具体表现

### 5.1 PEP-005: 催化剂验证金字塔 (INTC)

```
INTC的$220B市值建立在一系列未验证的催化剂上:

  Level 1: 技术可行 — 18A达HVM ✅(已验证)
  Level 2: 经济可行 — 良率支撑盈利 ❓(未验证)
  Level 3: 商业可行 — 客户愿意付钱 ❓(零规模外部客户)
  Level 4: 规模可行 — 支撑$10B+收入 ❓(IFS季度亏损$2.5B)

  市场在Level 1验证后按Level 3-4定价
  = 希望跳过验证 = $220B中~$90B是纯期权价值

  对照组: TSM在Level 4(验证完毕), 年NI $53B > INTC整个市值的24%
```

### 5.2 PEP-006: 周期峰值增长溢价 (KLAC/LRCX/AMAT)

```
三家设备公司PE vs 历史区间:

  KLAC: 49x | 历史 15-30x | 当前位置: 区间上沿的163% → ★极端
  LRCX: 51x | 历史 12-25x | 当前位置: 区间上沿的204% → ★极端
  AMAT: 38x | 历史 12-22x | 当前位置: 区间上沿的173% → ★极端

  市场的隐含假设: "AI超级周期打破了传统3-4年WFE周期"
  历史的反面证据: WFE从未连续3年增速>7%不回调(当前第3年)

  如果周期回调(-20% WFE):
    KLAC: EPS ~$27(谷值) × 15x = $405 (vs当前$1,451, 下行72%)
    LRCX: EPS ~$2.65(谷值) × 15x = $40 (vs当前$212, 下行81%)
    AMAT: EPS ~$6.75(谷值) × 15x = $101 (vs当前$339, 下行70%)

  ★核心教训: 在周期股上"看起来便宜"(低PE)恰恰可能是最贵的时候
    因为低PE = 峰值EPS → 当EPS回归均值 → PE会"便宜地"飙升到40x+
```

### 5.3 PEP-007: 反转PE陷阱 (MU)

```
存储股PE动态与所有正常股票相反:

  正常股票: 低PE → 便宜 → 买入信号
  存储股:   低PE → 峰值利润 → 卖出信号!

  MU当前: PE 21x, 毛利率74%, FQ2 NI $14B(创纪录)
  MU FY23: PE 负(亏损$5.8B), 毛利率-9%
  → 从-9%到74%的毛利率波动 = 这不是"增长"而是"周期"

  HBM例外?:
    支持"这次不同": 绑定长期合同+仅3家供应商+5年战略协议
    支持"周期重演": 每次存储公司都说"这次不同",但产能总是过剩
    关键信号: CapEx/D&A(目前0.98x=纪律好,如果突破1.2x=过度扩产开始)
```

## 6. 半导体独有的结构性发现

### 6.1 "地缘折价"是可量化的——TSM vs ASML

```
TSM vs ASML基本面对比:
  OPM:   TSM 50.8% > ASML 34.6% (+16pp)
  增速:  TSM +33%  > ASML +16%  (+17pp)
  ROIC:  TSM 56%   > ASML ~25%  (+31pp)
  Forward PE: TSM 23.4x < ASML 31.4x (-8pp)

  TSM在每个维度都优于ASML, 但PE低26%
  → 差距只能用一个因素解释: 台湾地缘风险
  → 地缘折价 ≈ 8个PE点 ≈ $100-150/股 ≈ 市值~30%

  Arizona fab良率92%+4座全满订+$165B投资 → 地缘风险在实质性降低
  但PE折价未收窄 → 市场对地缘风险的定价有"粘性"(改变慢)
  → 这可能是一个缓慢修复的预期差(不是事件驱动,是信心渐进恢复)
```

### 6.2 "ASIC vs GPU"不是零和——AVGO的双赢定位

```
市场叙事: "ASIC替代GPU = NVDA输,AVGO赢"
实际分析: AVGO在两种场景都受益:

  场景A: GPU继续主导
    → 更多GPU数据中心 → 更多AVGO网络设备(Tomahawk/Jericho)
    → AVGO收入增长

  场景B: ASIC崛起
    → 更多定制芯片设计 → AVGO是ASIC设计合作伙伴(60-80%份额)
    → AVGO收入增长

  → AVGO是半导体中罕见的"路径不可知"投资(不需要赌GPU还是ASIC)
  → 唯一共享风险: AI CapEx整体减速(两条路径同时熄灭)
```

### 6.3 "有IP vs 无IP"决定同一趋势中谁赚钱

```
VRT vs SMCI: 同一个AI数据中心趋势, 完全相反的结局

  VRT: 电力+散热(工程产品,有IP,有定价权)
    毛利率34% | ROIC 42% | FCF margin 26% | 订单+252%
    → $96.6B市值, 品质被正确识别

  SMCI: 服务器组装(无IP,无定价权,买NVDA芯片组装)
    毛利率6.3%(崩塌中!) | FCF不稳 | 治理危机
    → $13.3B市值, 跌-64%

  同一趋势, 7.3倍的市值差距:
  → 决定因素不是"在不在AI趋势中"而是"在价值链中有没有定价权"
  → 没有IP的组装商 = 为上游(NVDA)和下游(客户)打工
  → 有IP的工程商 = 提供不可替代的功能 → 定价权 → 利润

  泛化: 在任何趋势中, 先问"这家公司有定价权吗?"再问"趋势好不好?"
```

### 6.4 ARM的"平台变竞争者"风险

```
ARM宣布做自己的芯片(AGI CPU) = 从中立平台变成客户的竞争者

  历史先例:
    Amazon推出自有品牌 → 第三方卖家开始找替代平台
    Google做Pixel手机 → 三星/华为减少Android定制合作
    Intel做自己的通信芯片 → 客户转向ARM方案

  ARM的情况:
    ARM做AGI CPU → Qualcomm/MediaTek可能加速RISC-V投资
    → 短期: ARM收入增加(芯片收入>版税)
    → 长期: 版税基础被侵蚀(客户转向RISC-V)
    → 净效应: 收入可能从$4B→$25B但利润率从95%→70%

  投资含义: ARM的140x PE不仅定价了6x收入增长,
  还隐含着"客户不会反抗"的假设 — 历史上这个假设每次都错
```

## 8. 与SaaS板块的对比：两个板块，两种定价错误

| 维度 | SaaS板块 | 半导体板块 |

## 10. 本报告的方法论贡献

### 10.1 AI利好衰减模型(半导体独有)

**从本次分析中发现**：AI对半导体的利好不是均匀的——它从需求端(芯片设计)到供给端(设备/材料)逐层衰减。在Layer 1(NVDA)几乎无衰减，在Layer 4(MU)衰减50-70%。这个模型解释了为什么"同一个AI利好叙事"在NVDA上产生"温和低估"但在LRCX上产生"严重高估"。

**可泛化**: 任何行业的"主题投资"(AI/EV/新能源)都应该问"利好在价值链中如何分布?"——通常靠近需求端>靠近供给端，有定价权>无定价权。

### 10.2 穿越周期的估值锚体系(已固化到patterns.yaml)

| 公司类型 | 正确估值锚 | 错误估值锚 | 原因 |
|---------|----------|----------|------|
| 设计垄断(NVDA/TSM) | Forward PE + PEG | Trailing PE | 增速稳定,forward更有预测力 |
| 设备(周期型) | Mid-cycle PE | Trailing PE(峰值) | 峰值PE欺骗性低(PEP-006) |
| 存储(超强周期) | 反转PE逻辑 | 任何PE | PE在存储上信号反转(PEP-007) |
| 重CapEx(TSM) | EV/EBITDA | P/FCF | CapEx扭曲FCF |
| IP/版税(ARM) | P/S + 版税率趋势 | P/E | 140x PE无意义,需看收入增速 |
| 高SBC科技 | Owner PE | GAAP PE | SBC使NI失真 |

### 10.3 "有IP vs 无IP"法则

**VRT vs SMCI是本报告最有教育价值的对比**——同一个AI数据中心趋势，VRT(有IP,毛利率34%)赚钱，SMCI(无IP,毛利率6%)不赚钱。市值差7.3倍。

**法则**: 在判断一个公司是否受益于某个趋势之前，先问"它在价值链中有定价权吗?"。没有定价权的公司在趋势中只是"过手"——收入通过它但利润留不下来。

## 风险与局限性

1. **AI CapEx急刹风险**: 如果Hyperscaler的AI投资ROI不达标 → 整个半导体需求下台阶 → 本报告所有"温和低估"判断翻转
2. **WFE"超级周期"可能真的不同**: 如果AI确实让WFE永不低于$120B → 设备股的PEP-006可能过度悲观
3. **地缘黑天鹅**: 台海冲突是不可建模的二元事件 → TSM持仓需要接受这个不可对冲的尾部风险
4. **样本期限制**: 我们的分析基于当前周期高位的数据,没有"在谷底做过预期差分析"的经验 → 框架在谷底是否同样有效待验证
5. **ASIC竞争速度**: 如果ASIC在2-3年内(而非5-7年)实质性替代GPU推理 → NVDA的Forward PE 15.4x不再便宜
