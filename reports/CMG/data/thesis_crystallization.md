# CMG 核心矛盾结晶 (Phase 0.75)
> 日期: 2026-03-04 | 框架: v18.0 | PW: 4.2 (混合模式)

## 1. 异常狩猎 (Anomaly Hunt)

### A-1: P/E历史异常 — "Niccol折价"可量化

| 数据点 | 值 | 预期值 | 偏差 | 来源 |
|--------|:--:|:------:|:----:|------|
| 当前P/E | 32.1x | ~52x(5年均值) | **-38%** | FMP |
| SBUX报告中CMG P/E | 48x | — | — | SBUX v2.0 DM-P3-B01 |
| P/E从48x→32x时间 | ~12个月 | — | — | FMP时间序列 |
| Niccol离任日CMG跌幅 | -7.5% | — | — | SBUX v2.0 DM-P1-A120 |

**异常**: CMG P/E从48x降至32x(-33%)发生在Niccol离任(2024.08)+comp转负(-1.7% FY2025)双重打击后。但同期EPS仅从$1.11→$1.14(+2.7%)。P/E压缩幅度(33%)远超EPS增速放缓幅度(从+25%→+2.7%)。

**分解**: 32x = 52x(历史均值) × (1 - 16x Niccol折价) × (1 - 4x comp负增长折价)
→ Niccol折价贡献~16个P/E点, comp折价贡献~4个P/E点
→ **如果comp恢复(Niccol折价不变): P/E→36x, 股价→$41(+11%)**
→ **如果Niccol折价也修复(Boatwright证明能力): P/E→48-52x, 股价→$55-59(+49-60%)**

### A-2: 回购超FCF — 隐藏的信号?

| 数据点 | 值 | 预期值 | 偏差 | 来源 |
|--------|:--:|:------:|:----:|------|
| FY2025回购 | $2.43B | ≤FCF $1.45B | **+67%超额** | FMP CashFlow |
| FY2024回购 | $1.00B | ≤FCF $1.51B | 正常 | FMP CashFlow |
| 现金变化 | $1.42B→$1.05B | 稳定 | **-$0.37B** | FMP Balance |

**异常**: 管理层在comp转负、EPS增速放缓时**加速**回购(FY2024 $1.0B→FY2025 $2.43B, +143%)，且超出FCF消耗现金储备。

**三种解读**:
1. **信号解读(看多)**: 管理层认为股价被严重低估，利用低价积极回购→内部人行为支持看多
2. **绝望解读(看空)**: 没有更好的资本配置方案(没有并购目标/新增长引擎)→回购是最后手段
3. **惯性解读(中性)**: 加速回购是Niccol时代留下的授权计划惯性执行

**判断**: 需检查Q1 FY2026回购节奏是否延续。如果Boatwright主动减速回购→"绝望解读"弱化。如果继续加速→强化信号但也增加现金耗尽风险。

### A-3: ROIC上升 vs comp下降 — 矛盾信号

| 数据点 | FY2024 | FY2025 | 方向 |
|--------|:------:|:------:|:----:|
| ROIC | 17.6% | 18.9% | ↑ |
| Comp | +7.4% | -1.7% | ↓ |
| OPM | 16.9% | 16.8% | ≈ |
| 资产周转 | 1.23x | 1.33x | ↑ |

**异常**: Comp转负但ROIC反升。驱动力: 资产周转提升(新店扩张)+权益缩小(回购)。
**含义**: ROIC上升是**数学驱动而非运营驱动**。如果去除回购的权益缩小效应，真实运营ROIC可能已见顶。

### A-4: HEEP "数百bps" — 未量化的催化剂

| 数据点 | 值 | 可验证性 | 来源 |
|--------|:--:|:--------:|------|
| HEEP门店comp vs 非HEEP | "数百bps更高" | **不可量化**(定性表述) | IR Q4'25 |
| HEEP当前覆盖 | 350/4,056 (9%) | H | IR |
| 2026年底目标 | 2,000 (50%) | H | IR |
| 每店HEEP投资成本 | **未披露** | L | IR |
| 精确ROI | **未披露** | L | IR |

**异常**: 管理层将HEEP定位为核心增长催化剂，但关键数据(每店成本、精确ROI)均未披露。"数百bps"的comp提升如果是真实的(假设+300bps)，2,000店全部HEEP化→系统comp贡献+1.5%(=2000/4056 × 3%)。但如果"数百bps"包含选择偏差(先在高流量店部署)，实际增量可能远低。

## 2. 约束碰撞测试 (Constraint Collision Test)

### CC-1: 门店扩张数学 vs comp恢复

**共识隐含**: FY2025-2030 收入CAGR 10.3%, EPS CAGR 14.2%

拆解:
- 门店增长: 4,056→~6,000(+48%, CAGR ~8.0%)
- 需要comp: 10.3% - 8.0% = **+2.3%/年**
- 但FY2025 comp = **-1.7%**

**碰撞**: 从-1.7%到+2.3%需要+400bps的comp反转。2026指引comp "约flat" → 2026年就无法达标。要达到共识5年CAGR，2027-2030需comp平均+3%以上。

**历史参照**: FY2016-2019(E.coli恢复期)comp路径: -20.4%→+4.8%→+6.1%→+11.1% — 恢复用了3年。但当时问题是品牌信任(可恢复)，现在问题是宏观+竞争(可能是结构性)。

**结论**: 共识EPS CAGR 14.2%隐含了comp快速恢复假设。如果comp在FY2026-2027保持flat-to-negative，共识必须下修→当前P/E 32x可能进一步压缩。

### CC-2: 回购数学 vs 现金约束

FY2025节奏:
- FCF: $1.45B
- 回购: $2.43B
- 差额: -$0.98B (消耗现金)
- 剩余现金: $1.05B

如果FY2026保持同速回购:
- 预计FCF: ~$1.5B (假设门店扩张+CapEx增加)
- 回购$2.43B → 现金将降至~$0B
- **物理约束**: 现金耗尽后必须减速回购或首次举债

**碰撞**: CMG的"零负债"身份是估值溢价来源之一。如果为维持回购而举债→失去"资本结构简洁优势"→估值逻辑需重构。

**判断**: 最可能结果是FY2026回购减速至≤FCF($1.5B)，保持零负债身份。但这意味着EPS增长中的回购贡献将显著下降。

### CC-3: OPM 16.8%可持续性 vs 关税+工资

FY2025 OPM路径: Q1 16.7% → Q2 18.3% → Q3 15.9% → Q4 14.8%
→ 趋势下行(Q2旺季除外)

2026新增压力:
- 25%墨西哥牛油果关税→+60bps成本
- 最低工资上涨(加州$16→预期$18+)→+50-100bps
- HEEP设备部署CapEx→短期D&A上升→+20-30bps

**碰撞**: 管理层承诺"尽可能不提价" → 关税+工资+HEEP折旧~130-190bps成本压力全部由OPM吸收 → FY2026 OPM可能降至15.0-15.5%。但共识预计OPM持平或改善 → 预期差。

## 3. 非共识假说登记 (Non-Consensus Hypothesis Registration)

### H1: "Niccol折价过度定价" — CMG的16个P/E点折价中，≥10个将在24个月内修复

| 字段 | 内容 |
|------|------|
| **假说** | 市场对CMG的Niccol离任折价(~16个P/E点)过度反应。Boatwright的运营能力+HEEP部署将在24个月内证明CMG的体系优于个人依赖，修复≥10个P/E点 |
| **共识观点** | CMG从"Niccol溢价公司"退化为"普通快休闲公司"，P/E从50x回落至30-35x是合理重定价 |
| **我的假设** | CMG的运营体系(数字渗透、供应链、"Restaurateurs"文化)已高度制度化，CEO更换的影响被Niccol的明星效应放大。HEEP是体系的产物(非Niccol个人)，其全面部署将是结构性提升 |
| **异常来源** | A-1(P/E压缩33% vs EPS变化+2.7%)、A-3(ROIC继续上升)、A-4(HEEP部署加速) |
| **证伪条件** | FY2026 H1 comp ≤ -3% AND HEEP门店comp增量<100bps AND Boatwright在earnings call中无创新叙事 |
| **EV影响** | +30-50%(如P/E从32x→42-48x) |
| **Google可搜?** | 否 — "Niccol折价可量化为16个P/E点"的精确分解不在公开分析中 |

### H2: "回购加速=管理层看多信号" — FY2025超FCF回购预示12个月内comp反转

| 字段 | 内容 |
|------|------|
| **假说** | 管理层在comp转负时加速回购143%至超FCF水平，是基于内部数据(HEEP效果、新菜单测试、客流趋势)的看多信号，暗示2026 H2 comp将回正 |
| **共识观点** | 回购加速是缺乏增长投资机会的被动行为，或是惯性执行Niccol时代的授权计划 |
| **我的假设** | 零负债公司管理层选择消耗现金储备回购(而非保留现金应对不确定性)，说明对未来现金流有较强信心 |
| **异常来源** | A-2(回购$2.43B超FCF 67%)、CC-2(现金约束将迫使FY2026决策) |
| **证伪条件** | FY2026 Q1回购金额 < $400M(减速50%+) OR 管理层宣布新增信贷额度(为回购举债) |
| **EV影响** | +10-15%(如果comp确实在2026 H2回正) |
| **Google可搜?** | 部分 — 回购数据可查，但"超FCF回购=看多信号"的分析不常见 |

### H3: "CMG的估值简洁优势被市场忽视" — 零负债公司不应获得与负权益公司相同的风险折扣

| 字段 | 内容 |
|------|------|
| **假说** | 市场将CMG视为"增长放缓的快休闲股"统一降权，但忽略了CMG的资本结构在同业中的独特性：零金融负债+正权益。在利率上升/信用紧缩环境中，CMG应获得结构性溢价(相当于1-3个P/E点) |
| **共识观点** | 估值由增长驱动，资本结构是次要因素 |
| **我的假设** | 在MCD/SBUX/WING/YUM/DPZ全部负权益的行业中，CMG的零负债=隐性看涨期权(经济下行时不面临信用降级/被迫削减分红/被迫减速扩张的风险) |
| **异常来源** | E(资本结构简洁优势)、竞对对比(9家中8家负权益或高杠杆) |
| **证伪条件** | CMG宣布举债回购/举债收购 → 失去零负债身份 |
| **EV影响** | +5-10%(结构性P/E溢价1-3x) |
| **Google可搜?** | 否 — "CMG零负债在全负权益行业中的估值含义"不在公开分析中 |
