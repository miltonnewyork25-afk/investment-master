## 教训 1: Reverse DCF的"承重墙-级联失效"架构是最有决策价值的分析链条

**在ASML报告中的表现**: ASML报告构建了从Reverse DCF到承重墙(LBW)到级联失效路径的三层分析链条。Ch08 Reverse DCF从市价反推隐含假设(15-18% CAGR维持10年、35%+利润率、40x终值倍数)，Ch09将这些假设具象化为7个承重墙(LBW-1到LBW-7)，每个承重墙都标注了3年/5年/10年失效概率和估值影响百分比。最关键的是级联失效路径分析(L6980-7001)：识别出"地缘政治恶化 -> 中国技术追赶加速 -> EUV垄断削弱 -> 利润率下降"的连锁反应，概率35%，估值影响叠加至40-50%。这一链条让读者不只看到单个风险，而是理解风险之间如何相互放大。

**迁移到RDDT的方法**: Reddit的Reverse DCF同样需要反推市场隐含假设，然后将假设转化为承重墙。RDDT的承重墙可能包括：(1)广告ARPU持续增长假设，(2)用户增长未到天花板假设，(3)AI数据授权收入持续增长假设，(4)社区治理不会导致用户流失假设。级联失效路径例如："AI内容泛滥 -> 内容质量下降 -> 高质量用户流失 -> 广告价值降低 -> ARPU下行"。关键操作：每个承重墙必须标注定量失效概率和估值影响，避免沦为定性描述。

**核心原则**: Reverse DCF的价值不在于反推本身，而在于将隐含假设具象化为可监控的承重墙，并分析承重墙之间的级联关系。

## 教训 2: DM锚点系统按功能域分类(DM-TECH/COMP/RDCF/OVM/LBW/ILI/CQ)实现了数据可追溯性的结构化

**在ASML报告中的表现**: ASML报告包含484个DM锚点，按功能域严格分类。DM-TECH(22+个)锚定EUV技术细节如光源功率500W(DM-TECH-01)和零件数量14万(DM-TECH-04)；DM-COMP(17+个)锚定竞争对手数据如Canon退出EUV(DM-COMP-01)；DM-RDCF(20个)锚定Reverse DCF的每一步推导；DM-OVM(19个)锚定期权估值的每个组件；DM-LBW(21个)锚定承重墙分析的每个假设。这种分类使得审计变得精确：例如质疑估值结论时只需检查DM-RDCF系列，质疑竞争分析时只需检查DM-COMP系列。484个锚点意味着平均每873个字符就有一个数据锚定点。

**迁移到RDDT的方法**: RDDT的DM锚点域可以设计为：DM-USER(用户指标：DAU/MAU、session时长、留存率)、DM-AD(广告指标：ARPU、填充率、CPM)、DM-CONTENT(内容指标：帖子量、评论量、版块活跃度)、DM-AI(AI业务：数据授权收入、API调用量)、DM-COMP(竞争：vs Twitter/X、TikTok、Discord)、DM-RDCF(Reverse DCF推导)、DM-OVM(期权估值)。关键：每个DM锚点必须标注数据来源类型(硬数据/推断/估算)，这是ASML报告中隐含但执行到位的实践。

**核心原则**: DM锚点的价值在于功能域分类，而非单纯的数量。分类使审计可定向、可分层。

## 教训 3: OVM期权树的Core/Option分离+TAM Ceiling比较是最强的高估值公司分析工具

**在ASML报告中的表现**: ASML的OVM(Ch10)首先将业务分离为Core(EUV Systems + DUV Systems + 服务 = 每股491欧元)和Option(High-NA + Hyper-NA + 新兴市场 + 汽车半导体)。每条期权路径都有完整的TAM -> 市占率 -> 利润率 -> PE -> 成功概率 -> 折现因子的计算链(见L7306-7347的High-NA期权计算)。最有决策价值的输出是三个数字的对比：OVM Full Value 756欧元 vs 当前股价1407欧元 vs TAM Ceiling 908欧元。TAM Ceiling表示"即使所有Bull情景全部实现"的理论最大值，而当前股价超出TAM Ceiling 55%(Optionality利用率155%)，意味着市场定价已经超越了理性期权估值的上限。这个"期权解释缺口30%"(265欧元期权价值 vs 916欧元隐含期权价值)是报告最具杀伤力的发现之一。

**迁移到RDDT的方法**: RDDT的OVM分离：Core = 广告业务(当前主要收入)，Option = (1)AI数据授权(已有Google/OpenAI合同但规模小)，(2)电商/社交商务(Reddit Marketplace潜力)，(3)国际化扩张(非英语市场)，(4)订阅/Premium(Reddit Premium/Collectible Avatars)。对每条期权路径执行TAM -> 市占率 -> 利润率 -> 成功概率 -> 折现的完整计算。最终比较OVM Full Value vs 市价，计算期权解释缺口。如果RDDT市价 > TAM Ceiling，则和ASML一样存在投机性溢价。

**核心原则**: OVM的杀手级输出不是"期权值多少"，而是"期权能否解释当前股价与基本面的差距"。TAM Ceiling是对市场乐观预期的硬约束。

## 教训 4: KS注册表按CQ对应+分级(A/B/C/D/X)并附量化阈值，实现了风险监控的可操作性

**在ASML报告中的表现**: ASML的12个KS(L18624-18635)按严重程度分为五级：A级立即执行(KS-1地缘政治/KS-2技术垄断突破/KS-3客户流失)、B级警戒(KS-4 AI需求/KS-5竞争/KS-6供应链)、C级监控(KS-7财务/KS-8技术延迟)、D级趋势(KS-9市场份额/KS-10客户集中度)、X级特殊(KS-11台海黑天鹅/KS-12管理层)。更重要的是Kill Switch关联表(L292-301)将每个KS与对应的CQ绑定，并给出定量触发阈值：如CQ2对应"AI CapEx增速连续2季度YoY负增长"、CQ3对应"Polymarket概率>30%"、CQ5对应"ASP下降>10%"。这使KS不是抽象的风险清单，而是可以实际监控的仪表盘。

**迁移到RDDT的方法**: RDDT的KS注册表设计：A级(论文毁灭性)：KS-1 DAU连续3季度环比下降、KS-2 广告ARPU连续2季度YoY负增长、KS-3 AI数据授权合同被主要客户终止；B级(需要重估)：KS-4 内容审核争议导致品牌安全危机、KS-5 竞争平台(如Threads Communities)用户增速超过RDDT；C级(长期关注)：KS-6 监管(Section 230改革)、KS-7 管理层变动。每个KS必须附带定量阈值(如"DAU连续3季度环比下降>3%")和对应CQ编号，否则无法操作。

**核心原则**: KS的价值在于"可操作性"=分级优先级+定量触发阈值+CQ绑定。没有阈值的风险清单是空话。

## 教训 5 (反面): ASML报告存在v9.0规范违反 -- 数字评分/推荐指数/仓位建议出现在正文中，削弱了框架一致性

**问题描述**: ASML报告作为v10.0框架的最新实践(2026-02-13)，在多处违反了v9.0铁律中的"硬禁止"条款：

1. **数字评分泛滥**: 报告中使用了大量X/10和X/100评分体系。L18608-18615出现"技术垄断强度: 9.2/10"、"估值吸引力: 4.2/10"等9个维度评分。L453-456出现"技术垄断信心指数: 85/100"等4个X/100评分。L1123-1125出现"技术壁垒强度：9/10"。L8172-8181的Ch11竞争分析中出现完整的10分制评分卡对比5家公司6个维度。这些直接违反v9.0的"数字评分->定性评估(强/中/弱+置信高/中/低)"规则。

2. **推荐指数/排序**: L8200-8223出现"推荐指数: 8.7/10"等5家公司的推荐排序，接近于投资建议。L8225的DM-COMP-17虽然附带了免责声明但并未改变实质。

3. **仓位建议**: L15104出现"将ASML在投资组合中的权重从>5%降至<2%"，直接违反v9.0"零仓位建议"铁律。L15105-15106出现"对冲策略"和"分散化"建议，同样越界。

4. **VP编码体系残留**: L18600-18604出现"VP-001至VP-035"的Verification Point编码，而v9.0已将VP替换为TS(追踪信号)。虽然Ch19有完整的TS系统，但VP残留暗示报告在框架合规性上存在盲区。

**对RDDT的警示**: RDDT报告必须在Phase 0就明确执行v9.0/v10.0的硬禁止清单。具体防范措施：(1)禁止任何X/10或X/100评分，统一用强/中/弱+置信度表述；(2)禁止"推荐指数"或公司排序，改用条件性估值区间；(3)禁止仓位百分比建议，只说"论文含义"；(4)使用TS编码，不使用VP编码。在Complete组装时增加合规检查：`grep -n "/10\|/100\|推荐指数\|仓位.*%\|权重.*%" report.md` 逐一审查。

**核心原则**: 框架合规性不能依赖自律，必须在流程中嵌入自动化检查。最新报告出现规范违反说明"越新越合规"的假设不成立，需要显式执行。
