## DM-SGI: 专才-通才光谱诊断

### SGI计算

| 维度 | 评分 | 理由 |
|------|:----:|------|
| HHI_rev (Top-1品类收入占比) | **10** | ARM 100%收入来自芯片IP授权(版税+授权), 单一品类 |
| R&D_conc (核心品类R&D集中度) | **10** | 全部R&D投入ARM架构/IP设计 |
| MarketPos (核心品类市场份额) | **9** | ARM在移动AP >99%, 服务器20-23%, 嵌入式~60%+ |
| SwitchCost (客户锁定强度) | **7** | 软件生态锁定强(数十年代码基础), 但RISC-V存在=非绝对锁定 |
| BrandClarity (一句话说清) | **10** | "芯片IP授权" — 5个字说清 |

**SGI = 0.30×10 + 0.25×10 + 0.20×9 + 0.15×7 + 0.10×10 = 3.0 + 2.5 + 1.8 + 1.05 + 1.0 = 9.35**

### SGI路由决策
- **SGI = 9.35 → 专才模型** (SGI ≥ 7)
- 关注: **单点故障风险**(RISC-V替代) + **品类天花板**(IP授权TAM上限) + **渗透率上限**(数据中心/PC扩展)
- **估值预期锚**: SGI 8-10 → 预期P/E溢价30-60% vs 行业中位数
  - 半导体行业中位P/E ~50x → 预期P/E 65-80x
  - 实际P/E 140x = **远超SGI预期锚** → 标记"定价异常", Phase 4重点验证
