# ARM Holdings (ARM) — CQ路由表 v1.0
> Phase 0.5 | 2026-02-25

## Core Questions (5个)

### CQ-1: 版税经济学终态 — ARM的"税基"能扩大多快、多远?
- **核心矛盾**: v9提价+CSS渗透 = 短期最优策略, 但加速RISC-V采用 = 长期自杀式定价?
- **AI优势分类**: 深挖(版税率×出货量建模) + 呈现(历史数据趋势)
- **模块**: M01(商业模式) + M03(财务) + 行业版税建模
- **权重**: 30%

### CQ-2: 数据中心征途 — 从10%到50%的路径是否可信?
- **核心矛盾**: 管理层预期DC超越移动 vs DC份额仅20-23% vs Phoenix与被授权方竞争
- **AI优势分类**: 深挖(NVIDIA Grace分离+CSS渗透建模) + 呈现(竞争格局)
- **模块**: M02(行业) + M05(竞争) + 行业数据中心分析
- **权重**: 25%

### CQ-3: SoftBank双面刃 — 控股股东是保护者还是风险源?
- **核心矛盾**: $200亿保证金+30%关联授权+双重豁免 = 系统性治理风险 vs SoftBank "永不卖" + AI愿景加持
- **AI优势分类**: 深挖(关联交易分离+保证金触发建模) + 诚实(治理评估主观性)
- **模块**: M07(治理) + 风险拓扑 + 行业特殊风险
- **权重**: 20%

### CQ-4: RISC-V定价天花板 — "不需要赢, 只需要存在"?
- **核心矛盾**: RISC-V性能平价已达成+软件差距2027-28追平 vs ARM生态锁定+切换成本
- **AI优势分类**: 深挖(RISC-V渗透建模) + 诚实(长期预测不确定性)
- **模块**: M05(竞争) + M02(行业) + 行业RISC-V分析
- **权重**: 15%

### CQ-5: Arm China减速 — 19%收入的可持续性?
- **核心矛盾**: $749M/+7.5% vs 集团+24% = 中国业务已在结构性减速?
- **AI优势分类**: 呈现(数据趋势) + 诚实(地缘政治不可预测)
- **模块**: M07(治理) + M02(行业) + 地理风险
- **权重**: 10%
