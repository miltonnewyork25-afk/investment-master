# MOG.A (Moog Inc.) — Phase -0.5 文献侦察备忘录

**日期**: 2026-04-09 | **用途**: 供 Phase 0.75 核心矛盾结晶使用 | **来源**: 7 路 WebSearch (2025-2026 窗口)

---

## A. 市场把 MOG.A 当成什么？第一变量？

市场当前把 Moog 定位为**中型 A&D 精密运动控制执行器供应商**——Parker/Woodward/HEI/TDG 梯队里的"次级同业"，纯 A&D 度高于 Parker 但缺少 TDG 的 IP 定价力、HEI 的 PMA 利基。Q1 FY26 (2026-01-30) 记录级业绩——收入 +21% YoY 至 $1.1B、adj EPS $2.63 击败 19%、12-month backlog +30% YoY 至 $3.3B——触发 re-rating。市场默认第一变量已从"周期性 Industrial 拖累"切换为"**A&D backlog 增速 + adj OM 扩张 (FY26 guide 13.4%)**"。Consensus Buy, 2 analyst mean target $222.5 (StockAnalysis), 但股价已显著超出 target。[来源: BusinessWire 2026-01-30; StockAnalysis MOG.A forecast 2026]

## B. 四个分部占比与利润率，谁是真驱动？

FY25 (结束 2025-09) 实际数据:
- **Commercial Aircraft**: $904M (~23%), +15% YoY (aftermarket + widebody ramp)
- **Military Aircraft**: $888M (~23%), +9%, adj OM **14.1%** (+210bps, MV-75 + 新生产项目)
- **Space & Defense**: $1.1B (~29%), +9%, adj OM **15.1%** (+190bps) ← **最高 margin 分部**
- **Industrial**: $956M (~25%), **−4%** (剥离), adj OM 13.9% (+70bps)

FY25 合计 ~$3.86B，整体 adj OM **11.6%** → FY26 guide **13.4%**。真驱动 = **S&D + Military Aircraft 两段** (合计 ~52% 收入，margin 最高且增速最强，margin 扩张贡献最大)。Industrial 是"正在降低权重的结构性拖累"，Commercial Aircraft 是 cycle 顺风。[来源: Moog Q4 FY25 supplemental 2025-11-21; Morningstar/BusinessWire]

## C. Backlog / F-35 / Hypersonics / Space 暴露

12-month backlog: FY25 末 $3.0B → **Q1 FY26 $3.3B (+30% YoY, record)**。部分报道提及 total backlog 超 $5B (Q1 FY26)。S&D Q1 FY26 收入 **+31% 至 $324M**，驱动来自 (i) 导弹控制 (tactical / hypersonic / ballistic) (ii) 卫星组件 (iii) 欧洲地面车辆控制。**Hypersonics 具体项目**: Moog 为 Leidos Black Arrow Small Cruise Missile (USSOCOM) 供 fin Control Actuation System shipsets; SDA 跟踪层持续 follow-on。**F-35 具体数据不可得**——搜索结果中 Moog 未单独披露 F-35 收入占比/content per plane，需在 Phase 0 从 10-K MD&A 提取。MV-75 项目是 Military Aircraft 增长的主要新产品抓手。[来源: Moog Q1 FY26 transcript; Shephard SDA; moog.com/markets/defense]

## D. 双类股结构与家族控制 → 治理折价？

**结构源自 1980**: MOG.A (Class A) = **1/10 票**, MOG.B (Class B) = **1 票**。Class A 只选 25% 董事, Class B 选 75%。截至 **2025-12-12**: 流通股 **28.85M A 股 / 4.62M B 股** (A 股占经济权益 ~86% 但董事投票权 <30%)。B 股高度集中于 Moog 家族/内部人, 源自 1951 年 Bill Moog/Art Moog/Lou Geyer 创立的技术导向治理。CII 将其列入 dual-class 名单。**折价量化数据不可得** (WebSearch 未返回 vs TDG/HEI 的 multiple gap 历史分位), Phase 1 需用可比 EV/EBITDA 分位数反推——这是治理维度的**硬数据缺口**。[来源: SEC DEF 14A 2025-12; CII dual-class list; moog.com investor FAQ]

## E. FCF 转化率 / 营运资金

**结构性营运资金吞噬 = 当前 thesis 的关键裂缝**。FY25 全年 FCF **仅 $128M** (NI→FCF 转化率明显低于 60%), 因 (i) Q1 FY25 营运资金净流出 **$165M** (存货备货 + 应收时点 + 薪酬支付) (ii) 全年为支持 record sales 的 working-capital 投入。Q4 FY25 单季 FCF 反弹至 **$199M record** (客户预收驱动)。管理层 FY26 guide **FCF conversion 60%**, 长期目标 **75–100%**。AInvest 2025-11 的 contradiction note 直接把 FCF conversion 列为 bear case 之一。Trade NWC 结构性 destocking 是多年工程, 不是一次性事件。[来源: Moog Q4 FY25 PR 2025-11-21; Q1 FY25 transcript; AInvest contradiction analysis]

## F. 最近 12 月重大事件

- **Industrial 剥离**: FY25 初完成 (Industrial −4% YoY 主因)
- **M&A push**: 2025-12 起管理层明确释放并购信号 (SahmCapital)
- **MV-75** 新军机项目产能爬坡 → Military Aircraft +9% 主驱动
- **关税**: Q4 FY25 transcript 多次提及为 margin 逆风, 管理层声称 mitigation 进展中
- **重大诉讼 / 管理层变动**: 搜索未发现
[来源: SahmCapital 2025-12; Moog Q4 FY25 transcript; AInvest]

## G. 可比估值分位数

**具体 multiple 数据不可得** (搜索未返回 Parker/WWD/HEI/TDG/CW 并列 multiple 表)。定性梯队 (来自 BrandHopper / PortersFiveForces 竞品分析): **TDG** (proprietary IP, 历史 ~25x+ EBITDA) > **HEI** (PMA 利基) > **WWD ≈ Parker** (integrated 运动控制) > **Moog ≈ CW**。Moog 历史上因 dual-class 折价 + 低 FCF 转化 + Industrial 拖累交易在同业折价区间。**Q1 FY26 record beat + backlog +30% 后 re-rating 是否已收窄折价 = Phase 1 首要验证**。Safran 吸收 Collins 的 flight controls、Woodward 接手 Safran 北美 actuator——平台 content 正被 re-deal, 程序密度 consolidation 是同业共同题。EBITDA ~$551M, 当前 margin ~13.31% (StockAnalysis)。[来源: BrandHopper TDG competitor 2025; PestelAnalysis TDG; StockAnalysis MOG.A]

## Phase 0.75 核心矛盾候选 (供结晶用)

1. **Backlog-to-FCF 转化裂缝** — 订单 +30% vs FCF conversion 60% (目标 75–100%)。order book 记账 vs 现金回收 lag, 是 A&D OE 项目的结构性特征
2. **"纯化 A&D" re-rating 是否已被 price in** — Industrial 剥离后 Q1 FY26 股价已显著超 consensus target, 隐含的 multiple 扩张 vs 历史治理折价的对冲
3. **双类股治理折价 vs 家族长期稳定性** 的双刃特征——既是折价来源也是周期穿越的 anchor
4. **S&D 15.1% margin 的可持续性** — 导弹/卫星/欧洲地面车辆三引擎是否存在需求透支或集中度风险

## 数据缺口 (Phase 0 必须补齐)

- F-35 / MV-75 具体 content per plane + 收入占比
- 双类股历史 EV/EBITDA vs 同业分位 (Phase 0 FMP)
- Q1 FY26 total backlog $5B 的严格口径 (12m vs total)
- S&D 分部内部 hypersonics / space / missile 三细分收入拆分
- Moog 家族 + 内部人 Class B 具体持股比例
