## 关键发现 — **对 v1.0 "估值过高/审慎关注" thesis 的打击**

### 发现 1: MOG 的 EV/EBITDA 15.1x 是 **7 个 peer 中最低**

| 指标 | 排名 | 含义 |
|---|---|---|
| EV/EBITDA | **#1 最低** (15.1x vs 次低 PH 18.2x) | 按 EBITDA 基础,MOG 是这个 basket 最便宜 |
| EV/Sales | **#1 最低** (1.9x vs 次低 WWD 4.2x) | 按收入基础,MOG 更便宜 2x+ |
| PE | 中段 (27.6x, 仅 PH 25.4x 更低) | 按净利润基础中游 |
| P/FCF | 中段 (50.5x, PH 最低 26.8x) | FCF 基础贵 |

**v1.0 "审慎关注" 的致命漏洞**: 如果 MOG 真的"贵"到 -39% ER,那么 CW/HWM/HEI 这些 EV/EBITDA 30-38x 的公司按同一框架应该 -70% ER。但这些公司继续上涨。**v1.0 用错了 peer 对标或估值锚**,导致范畴错配。

### 发现 2: MOG 的质量指标 **也是 peer 中最低**

| 指标 | MOG | Peer 中位 | Gap |
|---|---|---|---|
| Gross Margin | 27.4% | ~37% | **-10pp** |
| Operating Margin | 10.6% | ~20% | **-10pp** |
| ROIC | 9.3% | ~13% | **-4pp** |
| ROE | 11.8% | ~19% | **-7pp** |
| P/FCF | 50.5x | 42x | 贵 |

**所以 MOG 确实质量差, 但市场给的倍数折扣 (EV/EBITDA -50% vs peer median) 已经部分反映了这个 gap**。问题变成: **质量 gap 是在收窄 (margin 追赶) 还是永久 (结构性低端)?**

### 发现 3: TDG 是不同动物, 不能硬对标

TDG: GM 60.1%, OPM 47.6%, PE 37x, EV/EBITDA 22.8x — 这是 aerospace aftermarket parts 垄断商 (专注售后替换件,不做 OEM)。**把 TDG 拉来对标 MOG (primarily OEM supplier) 本身就是范畴错误**。v1.0 如果这样做,错上加错。

真正可比: **PH (最近)** + WWD + CW (次近)。PH 是最佳镜像 — 同样是 diversified motion control, 同样做 aerospace + industrial, 规模 9x 大。**PH PE 25.4x / EV/EBITDA 18.2x → 给 MOG 一个 natural 上限参考**。

### 发现 4: HWM/HEI 的"aftermarket 溢价"范畴

HWM (57x P/FCF, 35x EV/EBITDA) 和 HEI (52x, 38x) 享受 premium 是因为 aerospace aftermarket 业务比例高 (HWM 结构件 + HEI parts 分销/PMA 许可)。MOG 没有可比的 aftermarket 业务 — MOG 主要是装机 OEM + long-cycle 军用。**不能期望 MOG 走到 HWM/HEI 的倍数**。但也不能说 MOG "过高" 当它明显低于 CW (更小的 defense peer)。

## 对 Phase 0.75 default_map_audit 的种子

**v1.0 的 "估值过高/审慎关注" frame 为什么错**:
- 拿 MOG 的 PE 27x 与历史自身对比 (MOG 历史 PE 15-20x) → 说"贵"
- 忽略整个 A&D sector 2024-2026 的 rerating (CW 从 ~20x → 42x, HWM 从 25x → 55x)
- 没有给 peer-relative frame → 错过了 "MOG 其实是 peer set 最便宜的一个"

**默认看法 (市场现在怎么看 MOG) 的候选假说**:
1. **H1 (Catch-up 假说)**: MOG 是 A&D sector rerating 的"落后补涨者", 质量最低所以最后被买, 但也正在买。
2. **H2 (Margin 追赶假说)**: Q1 FY26 OPM +100bps 是 margin 追赶 peer 开始的信号, 未来 OPM 从 10% → 13-15% 的路径能支撑 EV/EBITDA 从 15x → 20x 的再评级。
3. **H3 (Defense 供应链 chokepoint 假说)**: 地缘张力 + F-35 MQ-25 导弹产能紧张 → MOG 作为唯一 pure-play precision motion control 的不可替代性增加 → 订价权上升 → 未来 GM 可以往 peer median 30%+ 修复。
4. **H4 (周期顶点假说, 相反的)**: 20% 收入增速是 FY26 一次性爆发 (管理层指引), 2027-2028 分析师已经预期增速回落到 7% → 现在买的是周期峰值, PE 应该是 **13-15x on peak earnings**, 真实公允价值其实在 $150-180 附近 (与 v1.0 一致)。

**Phase 0.5 + 0.75 的任务**: 挑战 H1-H3 和 H4 之间选一个作为默认看法, 然后寻找 **≥2 个解释不通的具体事实**。
