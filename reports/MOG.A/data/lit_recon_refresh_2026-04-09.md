## 3. 宏观 / 产业背景 (fresh 2026-04)

### 3a. 美国国防预算: **FY26 budget $838.7B — 低于 FY25 $895.2B**

> **⚠️ v1.0 未捕获的重要事实**: 美国 FY2026 国防拨款 $838.7B, **较 FY25 $895.2B 下降约 6%**。
> 这直接**挑战**"美国国防支出持续加速"的 naive 叙事。

**含义**: 市场 rerating A&D sector 的逻辑 **不是** 建立在美国 base budget 增长上, 而是建立在:
- 欧洲 rearmament (德国 €377B/2026, ReArm Europe €800B+)
- 导弹量产大跳跃 (多数通过 supplemental 或 FMS, 不走 base budget)
- 现有 backlog 转化率提升 (FY25→FY26)

如果 MOG thesis 主要建立在 "美国国防上行周期", 那这是一个 fragility 点。

### 3b. 导弹量产 (对 S&D 分部关键)

| 武器 | 旧产能 | 新目标 | 倍数 |
|---|---:|---:|---:|
| Patriot PAC-3 MSE | 600/yr | **2000/yr** | **3.3x** |
| Javelin | 2400/yr | 3960/yr | 1.65x |
| LRASM/JASSM | 1100/yr | 2200-3300/yr | **2-3x** |

MOG 是导弹转向控制 (guidance vane / fin actuator) 的供应商。产能翻倍 = 收入直接 leverage (high-precision actuators 是 chokepoint 件)。

### 3c. 飞机生产 (对 CA + MA 分部关键)

- **F-35**: 2025 交付 191 架 (**历史新高**), FY26 目标维持, Lot 18/19 共 296 架
- **Bell V-280 (FLRAA)**: 2026 首次交付 (关键里程碑), 2030 fielding
- **737 MAX**: 当前 42/月 FAA cap → 目标 47/月 end 2026 → 53/月 FY27
- **787**: 7 → 8/月 2026 → 10/月 end 2026

**Commercial 修复路径确认** — 但 737 MAX 每月增加 5 架 (+12%) 相对 backlog 的 $3.26B 规模影响有限。**真正的 leverage 在军用部分的 rate increase + 欧洲需求**。

### 3d. 欧洲防务 (结构性催化)

- 德国 2026 国防预算 **€377B** (历史最高, 3.5% GDP by 2029)
- ReArm Europe 动员 **€800B+**
- MOG 在欧洲地面装甲车 (Puma, Leopard 2, Boxer) 控制系统有份额 — FY25 Q1 提到 "欧洲地面装甲需求" 为 S&D 驱动之一

## 4. 公司治理 / 股权结构

### Dual-Class 实际情况

- **Voting ratio**: Class A 1/10 vote, Class B 1 vote → **10:1 结构** (B 强)
- Class A 选举 ≥25% 董事会, Class B 选举其余 7 席
- **Moog Stock Employee Compensation Trust (ESOT)**: 527,425 股 Class B = **11.5% of Class B 流通**
- ESOT trustee: **Robert T. Brady** (自 2017-09-05)
- **无活跃的"Moog family"具体持股披露** — 这是个**重要发现**: prior 叙事"family-controlled"可能已经不准, 真正的 dual-class 控制权在 **ESOT (员工福利信托)** 而非家族
- 2024-2026 **无 consolidation proposal**, **无 activist**
- DEF 14A 2025-12-19 提交, 年会 2026-02-10, 无股东提案
