## 一、v1.0规划的5个致命缺陷

### 缺陷1: M10管理层/治理模块完全缺失 [致命]

**问题**: ADSK在FY2022-FY2025花了$2.25B做收购(FY2022 $1.25B + FY2025 $825M)，Goodwill占总资产34.5%。但v1.0规划**没有任何章节**评估CEO Andrew Anagnost的决策质量、收购ROIC、或治理历史。

**更严重的是**: ADSK在2019-2020年遭SEC调查(early renewal practices)——这是治理红旗，完全未提及。

**教训来源**: CRM v2.0用11章(Ch3-Ch11)深潜业务，其中M&A/管理层是独立CQ。

**修复**:
- 新增**CQ9: 管理层资本配置能力**(权重8%，从CQ4/CQ7各减4%)
- 新增**Ch13.5: 管理层审计——Anagnost的$2.25B收购ROIC + SEC调查遗产**

### 缺陷2: 财务数据有4个重大空洞 [致命]

| 空洞 | 影响 | 阻断的章节 |
|------|------|-----------|
| **5年OpEx分项(R&D/S&M/G&A)缺失** | 无法计算Magic Number、S&M效率、R&D强度趋势 | Ch7, Ch14, Ch18 |
| **NM↓(18.1→15.5%) vs OPM↑(22.1→24.9%)矛盾未解** | OI增长$440M但NI仅增$10M — $430M消失在哪？ | Ch14, Ch15, 所有估值章节 |
| **GAAP→Non-GAAP桥未构建** | 13pp差距(25% vs 38%)不知由SBC/摊销/重组各占多少 | Ch15三层盈利 |
| **FY2025 $590M Goodwill跳升——收购标的未识别** | v1.0猜测"Paylocity"——这几乎肯定错误(Paylocity是HCM公司,与ADSK无关) | Ch17 M&A, 有机增速计算 |

**修复**: Phase 0 data-prefetch必须从10-K逐项拉取。这4个空洞任何一个未解决=Phase 1禁止开始。

### 缺陷3: 国际化暴露完全缺失 [重大]

ADSK约35-40%收入来自国际市场。v1.0规划**无CQ、无章节、无数据**涉及地理分布。对Beta=1.467的公司，FX可能是$200-400M级别的收入摆动因子。

**修复**:
- Ch4"业务解构"扩展为**Ch4: 业务解构+地理拆解: AEC/MFG/M&E × Americas/EMEA/APAC**
- 在Ch14财务全景中加入FX影响量化

### 缺陷4: Construction Platform低估 [中等]

Autodesk Construction Cloud (ACC)/Build是战略重注，但被塞进Ch5"AEC深潜"的一个小节。Procore作为纯竞争对手完全未提及。建设科技TAM>$15B。

**修复**: Ch5拆为**Ch5a: AEC设计端(Revit BIM) + Ch5b: 建设科技(ACC vs Procore vs Oracle)**

### 缺陷5: NRR分析缺乏时序和分层视角 [中等]

v1.0只计划"NRR间接推断"，但未规划：
- NRR轨迹(季度，≥2年)——区分定价提升一次性效应 vs 持续扩展
- 分层NRR(企业 vs 中端 vs SMB)——ADSK连续提价+取消折扣后，低端NRR可能<100%
- NRR与Deferred Revenue波动的交叉验证

**教训来源**: NOW v2.0发现公布NRR(125%) vs 推断NRR(119%)有6pp差距，CRM v2.0因NRR全缺被M2评0分。

**修复**: Ch7扩展，加入季度NRR轨迹+分层推断+DR交叉验证

### 5.2 Phase 1逐章质量标准

#### Part I: 市场信仰翻译 (3章, ≥28K)

**Ch1: Reverse DCF (≥9K, DM≥15)**
```
质量标杆: CRM v2.0 Ch1 — "$194隐含5Y CAGR=3.7%"

ADSK Ch1必须产出:
  (1) $239隐含的5年收入CAGR (预期区间: 8-12%)
  (2) 隐含的终端OPM (预期: 30-35% Non-GAAP?)
  (3) 隐含的终端FCF倍数 (预期: 15-20x?)
  (4) WACC ±100bps的全景敏感性
  (5) "市场在赌什么"一句话总结 — 锚定P1叙事方向

因果链示例(必须达到的深度):
  "$239定价 → Reverse DCF → 隐含有机CAGR=X%
   → 但FY2026含计费转型追赶(+3-5pp) → 真实隐含有机CAGR=X-3~5%
   → 如果X-5% < FY2027 guidance 12% → 市场偏悲观(未计入全部增长)
   → 如果X-5% ≈ 12% → 市场已充分定价(零安全边际)
   → 结论: Bull case需要证明'市场低估了Y因素'"

禁止:
  - 先得出"低估/高估"结论再找支持数据
  - 跳过计费转型剥离直接用FY2026报告增速
```
