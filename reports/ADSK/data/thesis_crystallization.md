## 一、异常狩猎 (数据中的5个反直觉信号)

### 异常1: "最赚钱的SaaS之一,但估值最低之一"

**事实**: ADSK Non-GAAP OPM 38%(仅次ADBE 47%), FCF Margin 33%, 但Forward PE仅19x — 在SaaS cohort中仅高于CRM(16x)。

**反直觉**: 高盈利能力通常→高估值。为什么ADSK盈利接近ADBE但PE折价24%?

**可能解释**:
- (a) SEC调查残留折价 — 市场仍不信任管理层FCF数据
- (b) 有机增速实际只有12-13%(扣除转型追赶)→低于ADBE的12%(ADBE是纯有机)
- (c) 国际占比56%(SaaS最高)→FX风险溢价
- (d) 重组$216M+裁员16% → 市场担心"砍成本式增长"不可持续
- (e) 全部以上

**核心矛盾#1**: **$239定价了"所有已知利空"(SEC/重组/转型噪声), 但是否过度定价了?**

### 异常2: "NRR提升但Net Adds减速"

**事实**: NRR从100-110%升至>110%(FY2026), 但Net Adds从785K降至516K(-34%)。

**反直觉**: 如果NRR在改善(存量客户花更多钱), 为什么新客户获取在放缓?

**可能解释**:
- (a) NRR提升来自提价(非自然扩展)→可持续性存疑
- (b) NRR提升来自计费转型机械效应(管理层承认) → FY2027将消失
- (c) Net Adds减速因为TAM渗透见顶(全球100M+用户)→增长转向ARPS
- (d) Magic Number仅0.54x → S&M效率低 → 获客成本过高,主动放缓

**核心矛盾#2**: **增长引擎正在从"新客户"切换到"存量提价" — 这是成熟信号还是增长瓶颈?**

### 异常3: "裁员16%但guidance上调"

**事实**: FY2026裁员2,350人(16%), FY2027 guidance: 收入+12-13%, Non-GAAP OPM +50-100bps, EPS +18-20%。

**反直觉**: 裁员16%是衰退信号, 但guidance说增长加速(EPS +18-20%)?

**可能解释**:
- (a) 真正的结构性重组 → 从续约型GTM转向新客开拓+AI/Cloud → OPM结构性提升
- (b) 表面文章 → 砍成本冲短期EPS → 中长期产品力/客户满意度下降
- (c) SEC调查后的"新政" → 新CFO推动纪律性增长 vs 旧CFO的激进达标

**核心矛盾#3**: **裁员是"瘦身健体"还是"慌不择路"? 答案决定OPM 38%是底部还是顶部。**

### 异常4: "DWG垄断40年,但APS平台几乎无数据"

**事实**: DWG格式40年垄断(数十亿文件), 但APS(新平台层)不披露开发者数/应用数/API量。

**反直觉**: 如果平台战略是护城河迁移的关键, 为什么不展示进展?

**可能解释**:
- (a) APS确实早期(数据太小不值得披露) → 护城河迁移<15%
- (b) APS数据不好(开发者少/应用少) → 不披露是信号
- (c) Autodesk不认为APS是独立增长故事, 只是内部基础设施

**核心矛盾#4**: **旧护城河(DWG)半衰期>20年但不可永续, 新护城河(APS)几乎不可见 — 中间有多大缺口?**

### 异常5: "CEO 8卖0买 + $2B收购 + PlanGrid失败"

**事实**: Anagnost 5年8次卖出0次买入, 同期花$2B+做收购, 其中PlanGrid($875M)40%团队流失。

**反直觉**: CEO对自家股票无conviction, 但用股东的钱激进收购?

**可能解释**:
- (a) CEO薪酬结构(PSU+RSU) → 自然行权卖出, 非看空信号
- (b) 收购是帝国建设(empire-building) → PlanGrid整合失败是证据
- (c) 近18个月无卖出 → 可能因SEC调查期间限制交易

**核心矛盾#5**: **管理层是"资本配置优秀但不买自家股票", 还是"资本配置平庸且不信任自家估值"?**

## 二、约束碰撞 (矛盾间的相互作用)

### 碰撞1: 矛盾#1 × 矛盾#3

"估值最低" + "裁员但guidance上调" → 如果重组是真的结构性转型(非砍成本), 那么低估值是错误的。如果重组是表面文章, 低估值是正确的。

**验证方法**: 比较R&D员工保留率 vs S&M裁员比例。如果裁的是S&M(GTM重组)而R&D不变→真重组。如果R&D也大幅裁→砍成本。

### 碰撞2: 矛盾#2 × 矛盾#4

"增长靠提价" + "新护城河不可见" → 如果增长完全靠提价但护城河在衰退, 提价终将反噬(客户叛逃)。但如果DWG半衰期>20年(2D), 提价空间可能比市场想象的大。

**验证方法**: 对比Flex溢价(2.7x)和订阅提价率(3-5%/年)。如果Flex用户持续增长→说明低频用户愿意付溢价→DWG锁定仍强。

### 碰撞3: 矛盾#1 × 矛盾#5

"PE最低" + "CEO 0买" → 如果CEO认为股票便宜应该买。不买可能说明CEO认为$239不便宜, 或者有其他原因(限制/税务)。

**验证方法**: 检查其他高管(VP/SVP)是否有买入。如果全员0买→系统性低信心。如果只是CEO习惯性行权卖出→信号弱。

## 三、非共识假说登记

### 假说H1: "ADSK是被SEC折价的优质SaaS" (看多)

**核心论点**: SEC调查已结案(无处罚), 新CFO上任, 重组完成后Non-GAAP OPM将达39%+, 但市场仍给SEC折价→当折价消退, PE从19x→22-25x = +15-30%↑。

**所需证据**: FY2027 Q1/Q2 clean quarters(无重组, 正常ETR~20%, FCF如期) → 信任重建

**反面**: 如果FY2027出现新的会计问题 / FCF再次miss guidance → 折价永久化

### 假说H2: "ADSK的提价之路比市场想象的长" (看多)

**核心论点**: DWG/Revit锁定(20+年半衰期) + BIM mandate(20+国家) + Flex溢价(2.7x) = 每年3-5%提价可持续10年+。市场定价的10.9% CAGR可以仅靠提价+低速seat增长达成,不需要AI爆发。

**所需证据**: NRR持续>105%(扣除转型) + 无大规模客户叛逃事件

**反面**: 如果开源CAD(FreeCAD+ODA)质量突破 / 重大客户公开转向BricsCAD → 提价天花板到来

### 假说H3: "Neural CAD是特洛伊木马" (看空)

**核心论点**: Neural CAD声称"自动化80-90%设计流程"→如果成功,企业需要的CAD seat数量下降50%+。ADSK自己的AI产品蚕食自己的核心收入。这是CRM飞轮悖论的ADSK版本。

**所需证据**: Neural CAD实际商业化 + 客户开始减少seat

**反面**: 如果Neural CAD只在Fusion中落地(19%收入)而非AutoCAD(25%)/Revit(50%)→蚕食范围有限

### 假说H4: "M&A ROIC将拖累长期回报" (看空)

**核心论点**: $2B+收购中PlanGrid($875M)几乎失败, Innovyze($1B)无增长加速证据。如果未来继续高价收购(传闻收购PTC)→资本毁灭。

**所需证据**: Innovyze仍在~$100-150M收入(无增长) + 新的大型收购公告

**反面**: 如果BuildingConnected/Payapps整合成功 + Innovyze订阅转型完成后收入加速 → M&A能力在改善

## 四、Phase 1组织原则

**围绕5个核心矛盾组织Phase 1, 每个矛盾在报告中必须有明确的"判决"**:

| 矛盾 | 判决章节 | 判决标准 |
|------|---------|---------|
| #1 PE折价是否过度 | Ch1+Ch2 | Reverse DCF vs PTC对标 → 折价>15%=过度 |
| #2 增长引擎切换 | Ch7+Ch10 | NRR间接重构>105%(扣转型)=健康 / <100%=瓶颈 |
| #3 裁员性质 | Ch14+Ch15 | R&D保留+S&M重组=真转型 / R&D也裁=砍成本 |
| #4 护城河缺口 | Ch11+Ch12 | APS进展(开发者/应用增长)=缩小 / 停滞=扩大 |
| #5 管理层信心 | Ch14 | M&A ROIC>WACC(任意一笔)=有能力 / 全部<WACC=帝国建设 |
