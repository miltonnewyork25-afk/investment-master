# FORM Phase 4: 红队对抗审查 + 双向校准

> **日期**: 2026-04-17 | **Phase 4 目标**: 对抗性审查Phase 1-3结论, 检测确认偏差, 精炼Kill Switch
> **CQ覆盖**: CQ1-CQ8 全部概率更新
> **偏差检测结果**: Phase 1-3对Technoprobe DRAM威胁概率赋值偏高 (40-55% → 下修至25-35%)

---

## RT-1: 最强反方论点 — "如果HBM需求比我们预期更强呢?"

### Bull最强单一论点

**Q1 FY2026指引non-GAAP GM 45% ±1.5%是结构性拐点, 不是周期高点。**

证据链:
1. **数据**: Q4 FY2025 non-GAAP GM 43.9% (+290bp QoQ), 管理层称2/3来自结构性改善(良率/周期时间/人员再部署)[DM-RT-001]。Q1指引45%进一步加速, 如果兑现, 将是FORM历史最高季度毛利率
2. **机制**: Farmers Branch产线H2 2026 ramp → 产能利用率提升 → 固定成本摊薄 → GM进一步扩张。同时HBM4 ASP溢价($500K+ vs DDR5 $15-25K)持续, SK Hynix 2026年HBM 100% sold out [DM-RT-002]
3. **含义**: 如果GM稳定在43-45%, FY2025的ROIC 4.9%计算基础改变。假设$900M收入 × 44% GM × 15% OPM (扣除OpEx) → $135M NOPAT → $135M/$600M投入资本 ≈ 22.5% ROIC — 远超WACC。我们的核心"ROIC<WACC"论点在这个情景下断裂
4. **反面**: 但这要求GM 43-45%持续≥4个季度。FORM历史上从未维持GM>42%超过2个季度[DM-FIN-004]。单季度高点≠新常态。FY2021 GM 41.9%也曾被认为是"新水平", 随后下降至39.0%

**Bull论点评估**: 7/10 威胁度。如果5月11日Analyst Day给出FY2027 target model (GM 44-46%, OPM 20%+, FCF $120-140M), 且Q1实际交付GM≥44%, 我们的bearish thesis需要重大修正。

## RT-2: 最弱自方论点 — 我们论证链中最薄弱的环节

### 弱点1: Technoprobe DRAM进入概率被高估

Phase 3赋予Technoprobe进入DRAM概率40-55%。但新搜索发现:
- **无硬证据**: 没有任何公开记录显示Technoprobe获得Samsung/SK Hynix/Micron DRAM探针卡认证[DM-RT-003]
- **Technoprobe CMD 2025语言**: "plans to broaden its footprint in memory chip testing by entering the HBM segment" — 前瞻性意向, 非确认
- **FORM SK Hynix Best Partner Award 2024**: 供应商关系稳固[DM-RT-004]
- **Dresden fab方向**: 面向欧洲逻辑fab(TSMC Dresden/Infineon/GlobalFoundries), 非存储器[DM-RT-005]

**修正**: Technoprobe DRAM进入概率从40-55%下修至**25-35%** (2年窗口内)。
- 历史基准率: 探针卡行业跨品类扩张(Logic→DRAM或反向), 过去10年成功案例约3/10 [DM-RT-006]
- 反例条件: 需要客户主动拉动+技术验证+产能建设, 约18-24个月周期
- 自然实验: Technoprobe从2019年至今已在Logic领域大幅扩张(TSMC 2nm 30%份额), 但尚未进入DRAM, 说明跨品类壁垒真实存在

### 弱点2: "收入翻倍但EPS下降"叙事忽略了投资周期

Phase 1-2强调FY2023→FY2025 EPS从$1.05降至$0.69(-34%)。但这个对比有问题:
- FY2023 EPS含$73M一次性其他收益(投资收益)[DM-RT-007]
- 剔除一次性后, 正常化EPS约$0.70 → FY2025 $0.69, 基本持平
- FY2025是Farmers Branch重投资年(CapEx $104M vs 正常$30-40M)
- **如果用"正常化EPS持平但收入+18%"来描述, 投资者理解为"利润暂时被投资期压缩", 而非"结构性低效"**

**修正**: 保留"增长方向和利润方向结构性相反"的核心判断, 但增加注脚: 如果Farmers Branch FY2027 ramp成功, FY2025是投资谷底, 不是常态。两种叙事都有证据支持, 不应偏向一方。

## RT-3: 假设审计 — 确认偏差检测

### 检测方法: 列出Phase 1-3所有核心假设, 标注偏差方向

| 假设 | 偏差方向 | 偏差程度 | 修正 |
|------|---------|---------|------|
| Technoprobe DRAM进入概率40-55% | **偏空** | 高 | 下修至25-35%, 缺硬证据 |
| HBM content per wafer 1.3-1.6x (非2x) | 中性 | 低 | 保持, 基于SPHBM4标准+客户自研测试 |

**偏差诊断**: Phase 1-3有3/6假设偏空。最大偏差是Technoprobe DRAM概率(从概率锚分析, 应为25-35%而非40-55%)。整体thesis方向(高估)仍有效, 但程度需要校准。

## RT-4: "如果我完全错了" — 最具毁灭性的反论证

**情景: FORM成为下一个Broadcom (HBM版)**

如果以下三个条件同时成立:
1. HBM4/5需求持续3年以上(非2年周期)
2. FORM Farmers Branch产线在FY2027达到>75%利用率
3. GM稳定在44-47%(结构性改善确认)

则: FY2027 收入$1B+ × OPM 20% = $200M EBIT → EPS $2.50+ → PE 50x = $125目标价

**这个情景下$128几乎合理, 不是高估。**

但概率评估:
- 条件1概率: 65% (Hyperscaler CapEx仍在加速, $640-700B, +36% YoY)[DM-RT-008]
- 条件2概率: 55% (管理层H2 2026目标, 但新产线ramp有执行风险)
- 条件3概率: 40% (FORM历史从未维持GM>42%超过2Q; Q1指引45%需验证)
- 联合概率: 65% × 55% × 40% = **14%**

14%联合概率 ≠ 支撑$128的基础。即使Hyperscaler CapEx确定强劲, GM持续性是最不确定的一环。

## RT-6: 双向校准 — Bull最强 vs Bear最强

### Bull Case最强3个论点 (排序)

**B1**: Q1 GM指引45%如果兑现 = FORM历史最高, 且Farmers Branch ramp将在H2 2026进一步推高利用率 → 利润拐点确认 → ROIC>WACC变得可能 [威胁度: 8/10]

**B2**: Hyperscaler AI CapEx $640-700B (+36% YoY) + HBM4量产 + SK Hynix 2026 100% sold out → DRAM探针卡需求2-3年可见性 [威胁度: 7/10]

**B3**: 5月11日Analyst Day是催化剂 — 如果管理层给出FY2027 target model (rev $1B+ / OPM 20%+ / FCF $120-140M), 当前估值变得可argue [威胁度: 6/10]

### Bear Case最强3个论点 (排序)

**E1**: 5种估值方法全部指向高估 (EV/Sales 12.7x vs WFE median ~7x; Forward PE >70x on FY25 EPS; Reverse DCF隐含$1B+ rev + 45%+ GM) — 即使bull case全部兑现, 当前股价的margin of safety为零 [强度: 9/10]

**E2**: F&L结构性萎缩(-15%, FY21→25)被HBM增长完全掩盖; 如果HBM增速放缓, 双线失速 → 总收入可能下滑 [强度: 7/10]

**E3**: 5年EPS CAGR -10.2%且ROIC 4.9%<WACC~9% — 公司在投入资本的每一年都在毁灭价值。即使"投资周期"解释成立, 价值创造能力未被证明 [强度: 7/10]

### 校准结论

**Bear thesis 维持, 但强度从"确定性高估"调整为"高概率高估, 低概率合理"**

| 情景 | 概率 | 公允价值 | vs $128 |
|------|------|---------|---------|
| **Bear (基准)**: HBM增速放缓, GM回落至40%, ROIC仍<WACC | 35% | $55-70 | -45% to -57% |
| **Base**: HBM持续2-3年, GM 42-44%, ROIC接近WACC | 40% | $80-100 | -22% to -38% |
| **Bull**: HBM超强, GM 45%+, Farmers Branch满产, FY27 FCF $120M+ | 20% | $110-130 | -14% to +2% |
| **Extreme Bull**: 上述+F&L反弹+新品类(SiPho/Cryo)贡献 | 5% | $140-160 | +9% to +25% |

**概率加权公允价值**: $55×0.35 + $90×0.40 + $120×0.20 + $150×0.05 = $19.25 + $36 + $24 + $7.5 = **$86.75**

$128 vs $86.75 = **高估47.5%**

## RT-7: Kill Switch精炼 (5红 / 3黄 / 2绿)

### 红灯 (Thesis断裂条件)

**KS-R1**: Hyperscaler AI CapEx增速降至<+10% YoY (当前+36%)
→ 检测: 季度earnings call (GOOGL/MSFT/META/AMZN)
→ 机制: CapEx减速 → GPU采购减速 → HBM需求减速 → DRAM CapEx减速 → 探针卡需求延迟6-12个月传导

**KS-R2**: FORM连续2季度GM<38% GAAP (当前39.5%年化, Q4 42.8%)
→ 检测: 季报
→ 机制: GM下滑 → 利润率改善叙事破灭 → ROIC路径推迟 → 估值重心下移

**KS-R3**: Technoprobe获得SK Hynix或Samsung DRAM探针卡量产订单 (概率25-35%)
→ 检测: Technoprobe季报 + 行业新闻
→ 机制: 第二供应商确认 → FORM定价权削弱 → ASP溢价收窄 → GM压力

**KS-R4**: FORM FY2027 ROIC仍<WACC (~9%)
→ 检测: FY2026/2027年报
→ 机制: 2年后仍不创造价值 → "投资周期"叙事变成"结构性低效" → 估值重估

**KS-R5**: HBM技术路线变化 — 硅光子/非MEMS方案替代传统探针卡
→ 检测: TSMC/SK Hynix路线图公告, 行业会议
→ 机制: 如果HBM测试绕过探针卡 → FORM核心TAM缩小

### 黄灯 (需密切关注)

**KS-Y1**: Q1 FY2026 GM<43% (指引45% ±1.5%, 下限43.5%)
→ 意味着利润率改善叙事失速, 但单季度miss不构成thesis断裂
→ 行动: 等Q2确认趋势

**KS-Y2**: Farmers Branch产线延迟超3个月 (目标H2 2026 ramp)
→ 意味着CapEx回收周期延长, FCF拐点推迟
→ 行动: 跟踪管理层更新, 但不改变核心判断

**KS-Y3**: DRAM价格Q3 2026下跌>10% (Gartner预警14%回调可能[DM-RT-009])
→ 意味着周期转折信号, 但价格回调≠需求消失
→ 行动: 区分价格周期vs需求结构变化

### 绿灯 (上修条件)

**KS-G1**: FORM连续3季度GM>44% + ROIC>12%
→ 意味着结构性改善确认, "周期股"标签需重新评估
→ 行动: 上修base case公允价值至$100-115

**KS-G2**: Technoprobe明确退出DRAM战略 或 DRAM认证失败
→ 意味着FORM DRAM据点壁垒高于预期, 竞争威胁下降
→ 行动: 上修DRAM段长期增速假设

## Phase 4核心结论

1. **Thesis维持但校准**: FORM在$128高估, 概率加权公允价值$86.75 (下行47.5%)。但"确定性高估"表述过强 — 修正为"高概率高估(75%), 低概率合理(20%), 极低概率低估(5%)"

2. **最大偏差修正**: Technoprobe DRAM进入概率从40-55%下修至25-35%。FORM在DRAM的竞争据点比我们初始估计更稳固(SK Hynix Best Partner Award + 无竞品硬证据)

3. **关键验证窗口**: 
   - **4月29日Q1财报**: GM是否≥44%? 如果miss, bear case加固
   - **5月11日Analyst Day**: 是否给FY2027 target model? 如果给出且credible, base case需上修

4. **评级方向**: 基于概率加权, 预期为**审慎关注** [贵×方向未确认×有催化(Analyst Day)]。但需等Q1+Analyst Day两个数据点后最终定评级。
