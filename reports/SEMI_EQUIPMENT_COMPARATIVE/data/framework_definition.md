# 半导体设备对比分析框架定义 v1.0

> **创建日期**: 2026-02-24
> **适用范围**: AMAT / LRCX / ASML / KLAC 横向对比分析
> **设计目标**: 可审计、可复用的统一评分框架，半导体设备行业专精化

---

## 1. 框架总览

本框架由两大模块组成:

| 模块 | 维度 | 功能 | 输出 |
|------|------|------|------|
| **A-Score** (护城河) | A1-A11 | 评估竞争优势的深度与持久性 | 0-10分 × 11维 = 加权总分 |
| **B-Score** (经济/估值) | B1-B5 | 评估经济质量与估值合理性 | 定量指标 + 定性判断 |

**评分统一**: 全部使用 **0-10** 整数尺度。历史报告转换规则:
- KLAC 原始 /10 → 直接沿用
- LRCX 原始 /5 → ×2 转换
- ASML 原始 /100 → ÷10 转换
- AMAT 原始定性 → 本框架新评

**置信度标注**: 每个维度评分附带置信度 [H/M/L]
- **H (High)**: 有硬数据支撑，2个以上独立来源交叉验证
- **M (Medium)**: 有数据支撑但来源单一，或需逻辑推导
- **L (Low)**: 主要依赖定性判断，数据支撑不足

---

## 2. A-Score: 护城河评估框架 (A1-A11)

### A1: 输入要素自主权 (Supply Chain Autonomy)

**定义**: 关键投入要素(零部件、原材料、IP)的自主可控程度。被"卡脖子"风险有多大？

**半导体设备代理指标**:
- 关键供应商集中度 (CR3)
- 单源依赖组件数量与比例
- 自研/垂直整合程度
- 关键零部件 lead time
- 替代供应商培育周期

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 核心组件严重依赖单一供应商，lead time > 12个月，无替代方案 |
| 3-4 | 多数组件有替代来源，但1-2个关键组件存在单源依赖 |
| 5-6 | 关键组件有双源策略，自研比例 30-50%，lead time可控 |
| 7-8 | 核心技术大部分自研，供应链冗余充足，能在6个月内切换供应商 |
| 9-10 | 完全自主可控，或作为唯一供应商反向"卡脖子"他人 |

**权重**: 8% (半导体设备行业供应链复杂度高，但不是核心差异化因素)

---

### A2: 切换成本 / 数据重力 (Switching Cost / Data Gravity)

**定义**: 客户从本公司产品切换到竞品的全口径迁移代价。包括直接成本、时间成本、风险成本。

**半导体设备代理指标**:
- $/fab 切换成本 (工具替换 + 重新qualification + 良率爬坡)
- Qualification 周期 (月)
- 工艺配方 (recipe) 迁移复杂度
- 工程师再培训成本
- 整合工具链 (suites) 锁定效应

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 切换成本 < $10M/fab，qualification < 3个月，竞品直接替代 |
| 3-4 | 切换成本 $10-50M/fab，qualification 3-6个月 |
| 5-6 | 切换成本 $50-100M/fab，qualification 6-12个月，需工艺重新开发 |
| 7-8 | 切换成本 $100-250M/fab，qualification 12-18个月，良率风险高 |
| 9-10 | 切换成本 > $250M/fab，qualification > 18个月，或实质上不可切换 (如EUV) |

**权重**: 12% (半导体设备行业最核心的护城河之一)

---

### A3: 边际盈利杠杆 (Marginal Profit Leverage)

**定义**: 增量收入转化为增量利润的效率。规模经济与经营杠杆的强度。

**半导体设备代理指标**:
- 增量毛利率 (incremental gross margin)
- 固定成本占比 (R&D + 折旧)
- 经营杠杆倍数 (ΔOI% / ΔRev%)
- 服务收入占比 (高毛利来源)
- 收入规模 vs 盈亏平衡点距离

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 增量毛利率 ≤ 公司平均，无规模经济，变动成本主导 |
| 3-4 | 轻微规模经济，经营杠杆 < 1.2x |
| 5-6 | 经营杠杆 1.2-1.5x，高毛利服务业务占比 20-30% |
| 7-8 | 经营杠杆 > 1.5x，增量毛利率显著高于均值，服务占比 > 30% |
| 9-10 | 极强规模经济 (如软件/IP授权模式)，增量毛利率 > 80% |

**权重**: 8%

---

### A4: 壁垒↔利润池匹配度 (Barrier-Profit Pool Alignment)

**定义**: 是否牢牢卡在半导体价值链中客户 ROI 最高的环节？壁垒是否恰好保护了最肥的利润池？

**半导体设备代理指标**:
- 高端节点 (≤5nm) 收入占比变化
- 高价值工序 (EUV光刻/ALD/高精度检测) 市场份额
- 客户 CapEx 中本公司设备占比
- 工具单价 vs 客户产出价值比
- "必须有"(must-have) vs "可选"(nice-to-have) 定位

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 主要在边缘/低价值环节竞争，利润池薄且壁垒低 |
| 3-4 | 在某些高价值环节有存在，但份额不稳定或面临蚕食 |
| 5-6 | 在1-2个高价值环节有稳固份额，但不是"必须有" |
| 7-8 | 在多个高价值环节领先，客户将其视为关键供应商 |
| 9-10 | 垄断最高价值环节(如ASML EUV)，100%渗透率，无替代 |

**权重**: 12% (决定了护城河的"含金量")

---

### A5: 技术半衰期 / 可复制性 (Tech Durability / Replicability)

**定义**: 技术领先优势能维持多久？竞争对手追赶需要多少时间和资本？

**半导体设备代理指标**:
- 技术代差 (年): 竞品达到当前性能水平的估计时间
- 累积专利数量与关键专利质量
- 竞争对手追平所需资本投入
- 关键隐性知识 (tacit knowledge) 密度
- 新进入者成功案例频率

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 技术代差 < 2年，竞品已有可替代方案 |
| 3-4 | 技术代差 2-5年，但追赶路径清晰 |
| 5-6 | 技术代差 5-8年，追赶需 $5B+ 投入，成功概率中等 |
| 7-8 | 技术代差 8-12年，追赶需 $10B+ 且依赖隐性知识积累 |
| 9-10 | 技术代差 > 15年，实质不可复制 (如ASML EUV 25年+累积) |

**权重**: 12%

---

### A6: 经常性收入质量 (Recurring Revenue Quality)

**定义**: 持续"收租"的能力。一次性设备销售之外，有多少可预测的经常性收入？

**半导体设备代理指标**:
- 服务/订阅/授权收入占比
- 合同续约率 / 留存率
- 装机基数 × ARPU
- 长期服务协议 (LTSA) 覆盖率
- 服务收入增长率 vs 系统收入增长率

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 经常性收入 < 15%，客户按需采购，无粘性 |
| 3-4 | 经常性收入 15-25%，有基本服务但合同短期 |
| 5-6 | 经常性收入 25-35%，有LTSA但attach率中等 |
| 7-8 | 经常性收入 35-45%，attach率高，ARPU稳步增长 |
| 9-10 | 经常性收入 > 45%，类SaaS模式，装机基数飞轮成熟 |

**权重**: 10%

---

### A7: 网络效应 / 生态厚度 (Network Effect / Ecosystem Thickness)

**定义**: 用户越多、产品越好用的正反馈循环。在半导体设备领域表现为: 工艺开发生态、合作伙伴网络、数据积累。

**半导体设备代理指标**:
- 联合开发合作伙伴数量 (JDP数)
- 与leading-edge客户的排他/优先关系
- 工艺参考设计库规模 (recipe library)
- 行业标准制定参与度
- 培训认证工程师网络规模

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 无网络效应，产品价值不随用户增加而增长 |
| 3-4 | 轻微生态效应，有少量JDP但非排他 |
| 5-6 | 中等生态厚度，3-5个深度JDP，recipe库有差异化 |
| 7-8 | 强生态网络，与Top 3客户均有深度合作，标准制定参与者 |
| 9-10 | 极强(受限于设备行业特性上限约8分): 技术路线图依赖其平台 |

**权重**: 6% (半导体设备行业网络效应天然受限)

---

### A8: 跨界吞噬 / 平台包抄风险 (Cross-Border Encroachment)

**定义**: 被竞争对手通过bundling、平台扩张、相邻品类入侵而蚕食的风险。

**半导体设备代理指标**:
- 竞争事件时间线 (近5年被入侵/主动入侵记录)
- 主要竞争对手产品线重叠度
- 捆绑销售 (suite selling) 比例与抗拒能力
- 客户对单一供应商集中的容忍度
- 相邻品类进入壁垒

**评分锚点** (注: 分数越高=风险越低=越好):

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 核心品类被多个竞争对手积极入侵，市场份额持续流失 |
| 3-4 | 面临1-2个强劲竞争对手的品类扩张威胁 |
| 5-6 | 竞争格局基本稳定，偶有小规模份额波动 |
| 7-8 | 核心能力不可替代，竞品难以通过bundling入侵 |
| 9-10 | 垄断地位，无有效竞争者存在 (如ASML EUV) |

**权重**: 8%

---

### A9: 范式迁移风险 (Paradigm Shift Risk)

**定义**: 底层技术范式变化导致现有护城河失效的风险。

**半导体设备代理指标**:
- 新产品/新技术收入占比
- R&D路线图多样性 (覆盖几条技术路径)
- 跨范式技术转移能力 (如从平面→3D→GAA)
- 颠覆性技术监控投入
- 历史范式转变中的适应表现

**评分锚点** (分数越高=风险越低=越好):

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 单一技术路线，如果范式变化将完全失效 |
| 3-4 | 主要依赖1条技术路线，有初步探索但投入不足 |
| 5-6 | 覆盖2-3条技术路线，新产品收入占比 10-20% |
| 7-8 | 多路线覆盖，新产品收入 > 20%，历史适应记录良好 |
| 9-10 | 技术路线不可知论者，任何范式都需要其产品 (如检测/量测) |

**权重**: 8%

---

### A10: 分销 / GTM复利 (Distribution / Go-to-Market Compounding)

**定义**: 获客成本是否随规模下降？存量客户扩张是否形成飞轮？

**半导体设备代理指标**:
- 存量客户扩张率 (same-customer revenue growth)
- 服务 attach 率趋势
- 每客户钱包份额变化
- 销售效率 (收入 / SG&A)
- 新产品交叉销售成功率

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | 客户获取成本随规模上升，无交叉销售 |
| 3-4 | 获客成本稳定，服务attach率 < 30% |
| 5-6 | 获客成本轻微下降，attach率 30-50%，初步交叉销售 |
| 7-8 | 明显渠道飞轮，attach率 > 50%，存量客户持续扩张 |
| 9-10 | 极强分销复利，"一次进入，终身扩张"模式成熟 |

**权重**: 6%

---

### A11: 合规 / 可靠性门槛 (Compliance / Reliability Threshold)

**定义**: 认证和可靠性要求构成的隐性壁垒有多高？

**半导体设备代理指标**:
- Qualification 周期 (新工具进入客户fab)
- 事故成本 (一次故障导致的晶圆损失 $)
- 合规/出口管制影响
- 可靠性达标率 (uptime guarantee)
- 安全/环境法规门槛

**评分锚点**:

| 分数 | 特征描述 |
|------|---------|
| 1-2 | qualification < 3个月，故障成本低，易于新进入 |
| 3-4 | qualification 3-6个月，故障成本中等 |
| 5-6 | qualification 6-12个月，故障成本 $1-10M/事件 |
| 7-8 | qualification 12-18个月，故障成本 > $10M/事件，高可靠性要求 |
| 9-10 | qualification > 18个月 + 政府出口管制 + 寡头认证，新进入近乎不可能 |

**权重**: 10%

## 3. B-Score: 经济与估值框架 (B1-B5)

### B1: 周期位置 / 需求可见度 (Cycle Position / Demand Visibility)

**定义**: 当前处于WFE周期的什么位置？未来12-18个月需求可见度如何？

**半导体设备专化方法**:

```
WFE六层雷达 (源自LRCX报告框架):
├── L1: 终端需求 (AI/HPC/Mobile/Auto/IoT)
├── L2: 芯片厂CapEx指引 (TSMC/Samsung/Intel/中国)
├── L3: WFE总量预测 ($B, 同比增速)
├── L4: 设备品类分布 (刻蚀/光刻/沉积/检测占比)
├── L5: 订单/积压/递延收入趋势 (B2B ratio)
└── L6: 库存消化 vs 补库周期
```

**输出格式**: 定性判断 (周期早期/中期/晚期/衰退) + 定量指标表

### B2: 单位经济学 / FCF质量 (Unit Economics / FCF Quality)

**定义**: 通过UVD/UDC框架理解真实盈利能力，评估FCF的质量与可持续性。

**半导体设备专化方法**:
- **UVD** (Unit Value Delivered): 每单位产品/服务交付的客户价值
- **UDC** (Unit Delivery Cost): 交付每单位价值的全口径成本
- **毛利"真相"**: 系统 vs 服务毛利率分拆
- **FCF转化率**: OCF/NI + FCF/OCF
- **经营杠杆**: 上行周期 vs 下行周期的利润弹性

> UVD/UDC详细定义见 `uvd_udc_definitions.md`

**核心指标对比** (2026-02-24快照):

| 营业利润率 (TTM) | 29.1% | 33.8% | 34.6% | 42.4% |
| FCF利润率 (TTM) | 22.0% | 32.4% | 34.2% | 34.4% |
| OCF/NI (TTM) | 1.11x | 1.15x | 1.39x | 1.05x |

- 大型投资项目爬坡风险 (如AMAT EPIC Center $5B)

### B4: 估值 / 隐含预期 (Valuation / Implied Expectations)

**定义**: 市场当前定价隐含了什么增长假设？这些假设合理吗？

**核心方法: Reverse DCF优先**
1. 反推市场隐含的WFE增速、市场份额、利润率假设
2. 与B1周期位置交叉验证
3. 用周期调整P/E (mid-cycle EPS) 补充验证

## 4. 框架交叉验证设计

### A-Score与B-Score的关系

```
A-Score (护城河深度)          B-Score (经济质量+估值)
┌────────────────────┐      ┌────────────────────┐
│ A1-A11 定性+定量评分│ ──→  │ B2 能解释为什么      │
│                    │      │   毛利率/ROIC高?     │
│ 加权总分 = 护城河宽度│ ──→  │ B4 护城河宽度应匹配   │
│                    │      │   估值溢价大小       │
└────────────────────┘      └────────────────────┘
           │                           │
           └──────── 交叉验证 ──────────┘

一致性检查:
- 高A-Score + 高估值 → 合理 (优质资产溢价)
- 高A-Score + 低估值 → 机会 (被错杀)
- 低A-Score + 高估值 → 危险 (过度乐观)
- 低A-Score + 低估值 → 中性 (估值匹配)
```

### 评分冲突解决机制

当不同来源报告对同一公司同一维度评分存在差异时:

1. **以统一框架新评为准** (本报告评分)
2. **记录历史评分作为参考**: `[历史: KLAC报告评LRCX 6.30/10, LRCX自评8.76/10当量]`
3. **说明差异原因**: 不同框架、不同数据时点、不同分析师视角
4. **标注置信度**: 差异大的维度标注 [L]

## 5. 跨行业骨架声明

本框架设计为**可复用骨架**。A1-A11和B1-B5的定义层面是行业中性的，半导体设备专化仅体现在:
- 代理指标的选择
- 评分锚点的具体描述
- 权重分配

**复用到其他行业时需修改**:
- A维度代理指标 (如消费品行业: A2切换成本 → 品牌忠诚度/habits)
- 评分锚点 (具体分值对应的行业特征)
- 权重 (如消费品A7网络效应权重应提高)
- B1周期工具 (WFE雷达 → 行业特定周期指标)
- UVD/UDC定义 (完全行业特定)

**不需修改的部分**:
- A1-A11, B1-B5 维度定义
- 评分尺度 (0-10)
- 置信度系统 (H/M/L)
- EC注册体系
- 交叉验证逻辑
