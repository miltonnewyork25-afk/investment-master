### 2.2 毛利率趋势
```
Q1 FY25: 67.1% → Q1 FY26: 66.5%
Q2 FY25: 66.8% → Q2 FY26: 67.5%
Q3 FY25: 65.9% → Q3 FY26: 67.8%
Q4 FY25: 66.2% → Q4 FY26: 66.8%
```
**关键信号**: 毛利率在67%左右稳定, 低于DDOG(80%)和NOW(81%)。这是consumption-based云数据平台的结构性特征——底层计算/存储成本更高。

### 2.3 ★ 财务剪刀差 (GAAP亏损 vs FCF正)
```
TTM数据:
  GAAP Net Income: -$1.33B
  Operating Cash Flow: +$1.22B
  Free Cash Flow: +$1.12B
  差距: ~$2.45B

差距来源:
  SBC: ~$1.16B (推算, OCF/SBC=1.05)
  递延收入变化: ~$384M净增
  折旧摊销: ~$162M
  其他非现金: ~$550M
```
**核心剪刀差问题**: GAAP看极贵(PE为负), FCF看尚可(~46x P/FCF)。三PE对比:
- **GAAP PE**: 负值 (无意义)
- **Owner PE**: 负值 (FCF $1.12B - SBC $1.16B ≈ -$40M → Owner FCF≈0)
- **P/FCF**: ~46x ($52B / $1.12B)

**这是SNOW最核心的估值矛盾**: SBC≈FCF → Owner FCF≈0 → 股东真实回报接近零

## 八、核心矛盾初步识别 (Phase 0.75 种子)

### CQ1: AI Data Cloud是真实增量TAM还是consumption转移?
- **如果增量**: SNOW增速维持25-30%→RPO持续增长→估值justified
- **如果转移**: 增速最终回落至15-18%→P/FCF压缩至30x→$90-100/股
- **验证**: AI相关workload占比趋势 + total consumption per customer

### CQ2: Databricks是否正在实质性侵蚀SNOW的护城河?
- **牛方**: SNOW仍是cloud data warehouse领导者, Databricks在lakehouse
- **熊方**: lakehouse架构正在统一warehouse+lake→SNOW的分离存储护城河被侵蚀
- **验证**: Win rate趋势 + 大客户切换案例 + 增速对比

### CQ3: CEO转型(Slootman→Ramaswamy)的战略影响?
- Slootman: 执行效率大师, 激进增长
- Ramaswamy: Google前AI高管, 产品/AI导向
- **关键**: 战略从"数据仓库"转向"AI数据平台"是对还是错?

### CQ4: 员工效率革命是可持续还是一次性?
- 员工减68%+收入增30% = 效率飙升4x
- **如果可持续**: OPM改善路径清晰, SBC将大幅收敛
- **如果不可持续**: 人才流失→产品创新放缓→竞争力下降

### CQ5: Consumption模型的估值方法论?
- 传统SaaS: NRR×seat数=可预测
- Consumption: workload×单价=高度波动
- **核心**: 如何给consumption模型合理定价? DDOG/SNOW/MDB的共同挑战

### Rule of 40 (三口径)
```
FCF basis: 30% + 24% = 54% (优秀) ← 但FCF含SBC加回
Non-GAAP: 30% + 10.5% = 41% (良好)
GAAP: 30% + (-31%) = -1% (差!) ← 反映真实经营状况
```

### ★★★ Owner FCF转正时间线
```
FY25: SBC 41%, Owner FCF = -$617M ← 深度负
FY26: SBC 34%, Owner FCF = -$468M ← 改善但仍负
FY27E: SBC 27%, Owner FCF = -$170M ← 接近零
FY28E: SBC ~20%(推算), Owner FCF ≈ +$270M ← 首次转正!

转正条件: SBC/Rev < FCF Margin(24%) → 需SBC降至~24%以下
预计转正: FY2028 (2027年底)
```
**这是SNOW估值的关键时间锚**: Owner FCF预计FY2028转正。在此之前,SNOW对股东的真实现金回报为零。投资者买的是2年后的盈利能力。
