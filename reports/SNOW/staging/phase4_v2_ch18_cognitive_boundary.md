# Chapter 18: 认知边界评估 (G9门控)

> **核心结论**: 本报告对SNOW的分析存在显著的认知边界——可推演度54/100，业务复杂度68/100，覆盖度62/100，黑箱比例38%。最大的认知盲区是: (1)Databricks的真实财务状况(私募未审计数据)，(2)AI workload的规模化速度(2.3%太早无法外推)，(3)Iceberg的企业级全面采用时间线(调研样本偏差)。这些盲区直接影响了P3竞争分析和P4估值的置信度——**本报告的评级"审慎关注"应被理解为"在认知边界内的最佳判断"，而非"高置信度的确定性结论"**。

## 18.1 可推演度评估 (54/100)

可推演度衡量"分析者能多准确地预测公司未来动态"。

| 维度 | 评分 | 判断依据 |
|------|------|---------|
| **收入增速** | 65/100 | 财报数据充分(12季度趋势)+管理层指引(FY27 21%)+RPO前瞻($9.77B)。但consumption模型的波动性使精确预测困难 |
| **SBC收敛** | 55/100 | 有6家先例(Ch8)+管理层承诺(mid-teens)。但公司特异性高(34%起点是先例中最高)+人才市场不可控 |
| **竞争格局** | 45/100 | Databricks是私募公司(数据有限)+Fabric是Microsoft分部(不单独报告)+开源采用率调研有偏差 |
| **AI规模化** | 35/100 | 2.3%消费占比=几乎没有数据外推基础。0→1阶段的增长曲线高度非线性且不可预测 |
| **护城河迁移** | 50/100 | 有开放标准先例(4个, Ch13)但Iceberg是第一个在数据平台领域的开放表格式→无直接先例 |
| **估值** | 60/100 | 5种方法交叉验证(Ch17)提供了方向一致性。但离散度32%偏高→精确定价困难 |
| **加权平均** | **54/100** | |
[DM-CB-001-EST]

**54/100意味着**: 本报告能"大致正确地判断方向"(审慎关注 vs 深度关注)，但**不能精确定价**(FV $134的±20%误差范围=$107-161)。在这个误差范围内，$154(市价)是可能的"合理值"——评级的边界性质反映了认知边界的现实 [DM-CB-002-EST]。

## 18.2 业务复杂度评估 (68/100)

| 维度 | 评分 | 理由 |
|------|------|------|
| **收入引擎数** | 1.2 | 1个主引擎(consumption计费)+0.2个萌芽引擎(AI/Cortex) → 简单但AI引入不确定性 |
| **护城河异质性** | 高 | 旧护城河(数据锁定)在被侵蚀，新护城河(AI平台)未建立 → 处于迁移中间态=最高复杂度 |
| **竞争维度** | 3层 | Databricks(功能)+Fabric(分发)+开源(价格) → 三维竞争比单维更难分析 |
| **SBC-估值耦合** | 强 | 四口径分裂(GAAP/Non-GAAP/FCF/Owner FCF) → 估值结论高度依赖口径选择 |
| **CEO转型** | 中 | Slootman→Ramaswamy = 从销售型→产品型 → 增加了战略方向的不确定性 |
| **综合** | **68/100** | |
[DM-CB-003-EST]

**68/100意味着**: SNOW的业务复杂度在SaaS中偏高——主要因为"护城河迁移中间态+三层竞争+四口径估值分裂"三重复杂性叠加。对比: NOW(业务复杂度~45, 单一ITSM护城河+无直接竞争者), DDOG(~55, 多产品但竞争更清晰) [DM-CB-004-EST]。

## 18.4 黑箱比例 (38%)

**定义**: 业务动态中无法被当前分析覆盖的比例。

| 领域 | 可见度 | 黑箱部分 |
|------|--------|---------|
| 收入/财务 | 85% | 15% (consumption细分不透明) |
| SBC/人才 | 70% | 30% (AI vs非AI SBC分配不公开) |
| **竞争** | **45%** | **55%** (DBR私募+Win Rate+Fabric细分) |
| **AI战略** | **35%** | **65%** (AI消费/ARPU/转化率全不公开) |
| 护城河 | 55% | 45% (Iceberg渗透+迁移成本=推算) |
| 估值 | 75% | 25% (终端倍数+概率=假设) |
| **加权黑箱比例** | | **38%** |
[DM-CB-007-EST]

**38%黑箱意味着**: 本报告的分析基础覆盖了约62%的业务动态。剩余38%是分析者的"推测区域"——这些推测建立在逻辑和先例上，但缺乏直接数据验证。

**竞争(55%黑箱)和AI(65%黑箱)是最大的盲区**——恰好是本报告最核心的两个判断维度(CQ2竞争+CQ1 AI)。这意味着: **本报告的两个最重要结论(竞争恶化+AI未规模化)建立在最薄弱的数据基础上** [DM-CB-008-EST]。
