# 附录B: 原创方法论技术笔记

本报告包含三个原创分析方法论。此附录记录其技术细节、核心假设、已知局限和跨报告迁移价值，供后续研究复用和改进。

## B.1 NUG弹性函数 (Net Unit Growth Elasticity Function)

### 核心问题

市场对酒店管理公司的估值溢价高度依赖净客房增长率(NUG)。NUG减速1个百分点，估值倍数会压缩多少？

### 公式定义

```
ε(NUG) = ΔP/E / ΔNUG
```

其中:
- `ΔP/E` = 市盈率变化量(倍)
- `ΔNUG` = 净客房增长率变化量(百分点)

### 数据与回归

截面样本(FY2024数据):

| 公司 | NUG (%) | Trailing P/E (x) |
|------|---------|-------------------|
| HLT  | 6.7     | 50.2              |
| MAR  | 5.0     | 35.0              |
| IHG  | 4.5     | 27.6              |
| H    | 3.5     | 23.0              |

OLS回归结果:

```
P/E = β × NUG + α
β  = 7.04 (斜率: NUG每+1pp → P/E +7.04x)
α  = 2.85 (截距)
R² = 0.90
n  = 4
```

**核心含义**: NUG每减速1个百分点，P/E压缩约7倍。HLT若NUG从6.7%降至5.0%，隐含P/E从50x降至38x——对应约24%的市值蒸发。

### 假设与局限

1. **样本量极小**: n=4的OLS回归t统计量受限，β的置信区间宽。严格来说不满足统计推断条件，应视为"方向性指引"而非精确系数
2. **线性假设**: 实际关系可能非线性——NUG从7%降至5%的P/E冲击可能远大于从5%降至3%，因为前者打破"高增长"叙事
3. **截面≠因果**: 四家公司同一时点的相关性不等于"NUG变化→P/E变化"的时序因果。需要面板数据(多年×多公司)才能建立因果关系
4. **遗漏变量**: 品牌溢价、管理层叙事能力、回购缩股速度、资本配置历史等因素可能同时影响NUG和P/E，造成伪相关
5. **幸存者偏差**: 仅选取四大上市酒店管理公司，未包含已退市或被并购的样本

### 迁移价值

**迁移谱系**: ARM-CDS弹性函数(版税率弹性) → HLT-NUG弹性函数(增长率弹性)

**可推广场景**:
- NVDA: AI CapEx增速弹性 — CapEx增速每降1pp对P/E的冲击
- COST: 会员增速弹性 — 净新增会员增速与P/E的关系
- 任何"增长溢价公司": 核心增长指标减速时的估值脆弱性量化

**改进方向**: 扩展至10年面板数据(2015-2024)，加入固定效应控制公司异质性。

## B.2 RevPAR纯度分解 (RevPAR Purity Decomposition, RPPD)

### 核心问题

RevPAR增长是酒店行业的核心指标，但"增长5%"的含义可能截然不同——是真正的定价权驱动，还是通胀被动传导？RPPD将RevPAR增长分解为四个组分，测量增长的"纯度"。

### 分解框架

```
ΔRevPAR = ΔRevPAR(ADR纯度) + ΔRevPAR(入住率) + ΔRevPAR(结构升级) + ΔRevPAR(通胀传导)
```

各组分定义:

| 组分 | 定义 | 质量评级 |
|------|------|----------|
| ADR纯度 | 同店同品牌同房型的实际房价提升(剔除通胀) | 最高——真正的定价权 |
| 入住率恢复 | 入住率提升对RevPAR的贡献 | 中——有天花板(~75%) |
| 结构升级 | 品牌组合向高端迁移的RevPAR提升 | 中——一次性效应 |
| 通胀传导 | CPI驱动的被动提价 | 最低——非定价权 |

### HLT实证结果

HLT RevPAR增长组分演变(估算):

| 时期 | ADR纯度 | 入住率 | 结构升级 | 通胀传导 |
|------|---------|--------|----------|----------|
| FY2022 (疫后) | ~60% | ~15% | ~5% | ~20% |
| FY2024 (当前) | ~20% | ~30% | ~15% | ~35% |

**核心发现**: ADR纯度从60%骤降至20%。表面上RevPAR仍在增长，但增长质量严重恶化——35%来自通胀传导(被动)，仅20%来自真正的定价权。这意味着通胀回落时，RevPAR增长将大幅失速。

### 假设与局限

1. **估算依赖**: HLT未单独披露四个组分，分解依赖间接推算。不同假设(如CPI调整方法)可能改变比例分配±5-10个百分点
2. **结构升级的归因**: 品牌升级(如从Hampton到Waldorf Astoria的pipeline倾斜)对RevPAR的贡献难以精确剥离
3. **入住率天花板效应**: 当系统入住率接近75%时，该组分贡献趋近于零，剩余增长全部落在ADR和通胀上
4. **地域混合效应**: 全球RevPAR受汇率和区域周期影响，未做地域分解

### 迁移谱系

**源头**: RCL-YPD收益纯度分解(邮轮票价纯度) → HLT-RPPD(酒店房价纯度)

**可推广场景**:
- MAR/IHG/H: 同业对标——谁的ADR纯度更高？
- SBUX: 同店销售纯度分解(价格×流量×附加率×通胀)
- 任何"同店增长"指标: 分解真实定价权 vs 被动因素

## B.3 回购效率边际递减函数 (Buyback Efficiency η Curve)

### 核心问题

HLT累计回购超过$280亿，负权益达$-116亿。在高P/E环境下，举债回购的每一美元是否仍在创造价值？η曲线量化回购效率随估值膨胀的衰减路径。

### 公式定义

```
η = E/P - D × r_d × (1 - t)
```

其中:
- `E/P = 1/P_E` = 盈利收益率(市盈率的倒数)
- `D` = 债务融资比例(回购超出FCF的部分占总回购的比例)
- `r_d` = 加权平均债务成本(HLT约4.5%)
- `t` = 有效税率(HLT约22%)

**经济含义**: η衡量每一美元回购的净收益率——用盈利收益率减去债务融资的税后成本。η>0时回购创造价值，η<0时回购毁灭价值。

### HLT实证结果

| 财年 | Trailing P/E | E/P (%) | D (%) | 债务成本r_d | η (%) | 判定 |
|------|-------------|---------|-------|------------|-------|------|
| FY2022 | 27x | 3.70 | 10 | 4.5% | 3.59 | 高效区 |
| FY2023 | 38x | 2.63 | 25 | 4.5% | 2.31 | 效率下降 |
| FY2024 | 50x | 2.00 | 40 | 4.5% | 1.42 | 低效区 |
| FY2025E | 55x | 1.82 | 50 | 4.5% | 0.80 | 临界区 |

**毁灭阈值计算**:

```
η = 0 → E/P = D × r_d × (1 - t)
假设D=50%, r_d=4.5%, t=22%:
E/P = 0.50 × 0.045 × 0.78 = 1.76%
对应P/E = 1/0.0176 ≈ 57x

假设D=60%, r_d=5.0%(利率上行):
E/P = 0.60 × 0.050 × 0.78 = 2.34%
对应P/E = 1/0.0234 ≈ 43x (更近!)
```

当前HLT Trailing P/E约50x，距离57x的毁灭阈值仅一步之遥。若债务比例或利率上行，阈值还会进一步下移。

### 红队修正

红队指出Trailing P/E可能高估了回购低效程度(因为trailing包含一次性低盈利)。使用Forward P/E(约35x)重算:

```
η_forward = 1/35 - 0.40 × 0.045 × 0.78 = 2.86% - 1.40% = 1.46%
```

Forward η仍为正但已显著低于FY2022水平。红队修正不改变"效率递减"的结论，但将毁灭阈值从P/E 57x推远至P/E 84x(以Forward计算)。报告正文采用两者区间。

### 假设与局限

1. **P/E选择敏感性**: Trailing vs Forward P/E显著影响η值，报告采用区间表述
2. **信号价值未计入**: 回购具有"管理层对未来有信心"的信号价值，以及维持EPS增长叙事的功能——这些非财务价值未反映在η公式中
3. **线性税盾假设**: 实际中债务增加可能触发评级下调，导致r_d非线性跳升
4. **增量vs存量**: 公式衡量的是边际回购效率，不评判历史低P/E时期回购的累积价值

### 迁移价值

**原创方法论**: 未见同类量化框架(常见讨论多为定性)。

**高迁移性目标**: 所有高P/E+负权益+持续回购的公司:
- SBUX: 负权益$-78亿，Trailing P/E ~78x → η可能已为负
- DPZ: 负权益$-40亿，Trailing P/E ~33x → η仍为正但在下降
- MAR: 负权益$-36亿，Trailing P/E ~35x → 与DPZ类似
- 低P/E回购公司(如银行): η远大于0，回购效率高

**改进方向**: 加入ROIC约束——当回购η低于新投资ROIC时，资本应转向有机增长而非回购。构建η-ROIC决策矩阵。

## B.4 三方法论协同

三个方法论并非孤立使用，而是构成完整的估值脆弱性诊断:

```
NUG弹性函数 → 增长减速时P/E会压缩多少？
    ↓
RPPD纯度分解 → 当前增长中多少是真实的？(通胀退潮时的失速风险)
    ↓
η回购效率曲线 → P/E压缩后，回购还能托住EPS吗？
```

**链式推演**: RPPD显示ADR纯度仅20%(增长质量弱) → 通胀回落时RevPAR失速 → NUG若同步减速(开发商融资困难) → NUG弹性函数预测P/E压缩约7x/pp → P/E下行使η趋近零 → 回购无法再托住EPS → 螺旋下行风险。

这一链式逻辑是本报告"审慎关注"评级的核心定量支撑。
