# DDOG Baggers Summary

> **来源**: baggers_summary MCP | **日期**: 2026-03-24

## 公司概况

- **公司**: Datadog, Inc. (NASDAQ: DDOG)
- **行业**: SaaS / Cloud Infrastructure Monitoring / Observability
- **总部**: New York, NY
- **成立**: 2010 | **IPO**: 2019
- **员工数**: ~6,800+
- **客户数**: 47,431+

## 核心业务

Datadog提供统一的云监控和安全平台，覆盖:
- **Infrastructure Monitoring**: 服务器/容器/云资源监控
- **APM (Application Performance Monitoring)**: 应用性能追踪
- **Log Management**: 日志收集/分析/归档
- **Security Monitoring**: 云安全态势管理(CSPM) + 工作负载安全
- **AI Observability**: LLM监控/AI Agent追踪 (新增长点)

产品数量: 20+ (统一平台策略，cross-sell驱动NRR)

## 商业模式

- **收入模式**: 使用量计费(consumption-based) + 订阅混合
- **定价**: 按主机/日志量/APM span等多维度计费
- **合同**: 年度订阅为主，部分多年期
- **毛利率**: ~80% (稳定)
- **递延收入**: $1.26B (收入可见性良好)

## 增长驱动因素

1. **产品扩张**: 20+产品，land-and-expand策略，4+产品客户占比持续提升
2. **AI Observability**: LLM监控/Bits AI/Agent Monitoring — 绑定AI基础设施增长
3. **安全扩展**: Cloud SIEM/CSPM进入$30B+安全市场
4. **国际化**: 30%收入来自美国以外，欧洲/亚太增长空间
5. **大客户渗透**: $100K+ ARR客户数持续增长
