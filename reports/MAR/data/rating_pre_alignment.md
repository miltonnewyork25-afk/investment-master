### 直接可比: IHG vs MAR

| 维度 | IHG | MAR | 含义 |
|------|-----|-----|------|
| P/E | 29x → **27.7x**(实时) | **35.4x** | MAR溢价28% |
| 评级 | 关注 (+13.5%) | **?** | MAR应该≤IHG评级 |
| ROIC | 22.6% | 15.6% | IHG效率更高 |
| NUG | ~4.7% | 4.3% | IHG略快 |
| 杠杆 | 2.86x | 3.73x | MAR更高 |
| FCF Yield | 4.0% | 3.1% | IHG更好 |
| 品牌质量 | ACSI 79 | ACSI 78 | 接近 |

**校准结论**: MAR在几乎所有维度(P/E更高、ROIC更低、杠杆更高、FCF yield更低)都不如IHG，但规模更大(1.78M vs 1.01M rooms)。**MAR评级应低于IHG的"关注"**。

### 与DPZ对比 (同为特许经营模式)

| 维度 | DPZ | MAR | 含义 |
|------|-----|-----|------|
| P/E | 23x | 35.4x | MAR溢价54% |
| 评级 | 中性关注(偏关注) +9.4% | **?** | 高P/E应获更低评级 |
| ROIC | 高(负权益幻觉) | 15.6% | 不可比(负权益) |
| 增速 | 同店+3% | RevPAR+2%+NUG4.3% | 可比 |
| 杠杆 | 5.5x | 3.73x | DPZ更高 |

**校准结论**: MAR P/E 35.4x >> DPZ 23x，但MAR增速+规模溢价+品牌组合更广。**MAR评级应不优于DPZ的"中性关注(偏关注)"**。

### 与SBUX/CMG对比

- SBUX P/E 46x → 审慎关注(-12%~-24%): MAR 35.4x < SBUX 46x → MAR不应比SBUX更审慎
- CMG P/E 32x → 中性关注(-7%): MAR 35.4x ≈ CMG 32x → MAR可能在同一区间

## 三、MAR评级约束矩阵

| 约束来源 | 约束条件 | 含义 |
|---------|---------|------|
| **IHG对比** | MAR P/E 35.4x > IHG 28x, 且ROIC/杠杆/FCF均不如IHG | MAR评级 ≤ IHG(关注) |
| **DPZ对比** | MAR P/E 35.4x >> DPZ 23x | MAR评级 ≤ DPZ(中性关注偏关注) |
| **SBUX对比** | MAR P/E 35.4x < SBUX 46x | MAR评级 ≥ SBUX(审慎关注) |
| **CMG对比** | MAR P/E 35.4x ≈ CMG 32x | MAR评级 ≈ CMG(中性关注) |
| **跨行业中位** | P/E 30-40x → 中位评级中性关注 | MAR评级 ≈ 中性关注 |
| **FMP DCF** | 公允价值$216 vs $336 (-36%) | 偏向审慎 |
| **分析师共识** | 平均PT $343 ≈ 当前 (+2%) | 偏向中性 |

### 预设评级区间

**中性关注 (偏审慎)** — 期望回报约 -5% ~ -15%

**理由**:
1. P/E 35.4x高于IHG(28x)+DPZ(23x)两个直接可比 → 不支持"关注"
2. FMP DCF暗示-36%但标准假设可能低估brand/franchise价值 → 实际折价可能~-10-20%
3. 品类之王地位+271M会员+信用卡费增长 → 不至于"审慎关注"
4. 与CMG(32x, 中性关注-7%)高度可比 → 中性关注是锚点
5. 内部人卖出+管理层换代+US RevPAR停滞 → "偏审慎"修正

### 需Phase 1-3验证的关键假设

- 如果逆向DCF暗示的增长假设合理(~5% revenue CAGR + NUG提速) → 中性关注
- 如果NUG提速到5%+ 且 信用卡费增长可持续 → 上调至中性关注(偏关注)
- 如果杠杆继续加速 或 品牌质量恶化 → 下调至审慎关注

## 四、已知异常解释义务 (校准脚本检测)

| 异常 | 解释 |
|------|------|
| **IHG(29x, 关注) > RCL(20x, 中性偏审慎)** | IHG是asset-light特许模型(应享高P/E), RCL是重资产邮轮(高周期性+巨额债务)。商业模式根本不同, P/E不可比。IHG按特许经营估值(25-35x合理), RCL按重资产周期股估值(15-25x合理) |
| **IHG(29x, 关注) > DPZ(23x, 中性偏关注)** | IHG报告时间(2/27)DPZ(3/5)不同, 且IHG期望回报+13.5% > DPZ +9.4%。两者差距在评级区间内合理(关注下限 vs 中性关注上限)。DPZ体量溢出+可读性3.5拖累质量 |
| **COST(55x, 中性) > SBUX(46x, 审慎)** | COST会员制防御性消费(PE稳定在45-55x是常态), SBUX正在转型期+OPM压缩+CEO新上任。SBUX的审慎来自转型不确定性而非PE高低 |
