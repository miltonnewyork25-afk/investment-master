# KLAC Key Assumptions Register
> Phase 0初始化 | P1-P3验证更新 | 2026-02-17 | 传统框架(PW=2.2)

## 核心假设 (Phase 1-3验证状态)

### KA-1: 检测垄断持久性
- **假设**: KLAC检测份额63%可维持5年以上(数据网络效应+光学技术壁垒)
- **支持**: 过去15年从50%→63%持续扩张; 装机基地数据网络效应; 检测复杂度随3D/GAA指数增长
- **反驳**: AMAT e-beam进攻; Hitachi高端e-beam; 中国SiCarrier/东方晶源
- **P1验证**: 份额63%确认(FMP+baggers数据); e-beam互补非替代(检测量增长>份额转移); EUV物理垄断(双重曝光=双倍检测需求)
- **P3验证**: AMAT e-beam对KLAC影响上限仅-3~4%(Agent B竞争分析); 护城河评分8.40/10 Wide; Hitachi在高端e-beam确有优势但CD-SEM份额仅15-20%(非45%)
- **当前置信度**: 72% | ↑+7pp(P0→P3) | **状态**: 高置信度,已验证

### KA-2: 估值天花板
- **假设**: P/E 42.5x可通过EPS增长消化(Forward P/E降至31.6x)
- **支持**: FY2027E EPS $46.38 (+27.1% YoY); 回购推动EPS>收入增速
- **反驳**: 历史P/E中位数~25x; WFE周期见顶时P/E压缩至20x; Forward DCF $691 vs $1,464(53%溢价)
- **P2验证**: Forward DCF仅$691/sh(Agent C), SOTP $117.9B = -38.7%折价; 承重墙BW-4(P/E)脆弱度最高-17.6%; Reverse DCF隐含15% FCF CAGR(市场预期激进)
- **P3验证**: 调整后DCF $751-769仍远低于市价; 五引擎分析支持8-10%基准增速但不支持15%
- **当前置信度**: 40% | ↓-5pp(P0→P3) | **状态**: 唯一持续下降的假设,估值风险最大
- **P4重点**: 这是报告核心矛盾——基本面优秀但估值过高

### KA-3: 先进封装增量
- **假设**: 先进封装检测从$560M→$950M(CY2025)可持续增长
- **支持**: CoWoS/HBM产能扩张; KLAC份额从10%→50%
- **反驳**: 低基数效应; TAM实际$8-10B(非管理层暗示的$12B); AMAT/Hitachi竞争进入
- **P1验证**: Phase 1 Agent A确认$925M(接近$950M目标); 先进封装占总收入~7%
- **P3验证**: Agent B共识解构TAM从$12B修正至$8-10B(去重互连检测+封装检测重叠); Agent C NVDA桥梁确认放大系数60-240x但集中在少数客户
- **当前置信度**: 60% | ↑+5pp但P3小幅下修 | **状态**: 增长确认但TAM天花板比预期低

### KA-4: 中国收入风险可控
- **假设**: 中国收入$300-350M直接风险+国产替代永久丢失风险,但可被其他地区增长补偿
- **支持**: 管理层表示中国收入已部分调整; 非管制产品仍可出口
- **反驳**: 出口管制可能进一步收紧; SiCarrier替代进度超预期; 中国收入占比25-28%
- **P1验证**: Agent B建立三情景框架(S1温和/S2严格/S3极端); 台湾集中度风险(TSMC 30%+收入)未充分纳入
- **P2验证**: S1/S2/S3概率加权完成; $300-350M影响已量化
- **当前置信度**: 52% | ↑+12pp(三情景框架降低不确定性) | **状态**: 风险已框架化但台湾集中度是遗漏项
- **P4重点**: 台湾地理集中度风险需独立评估

### KA-5: WFE周期不会2027见顶
- **假设**: WFE市场有结构性增长支撑(AI/先进封装),2027不会大幅回调
- **支持**: AI CapEx持续; 先进制程继续推进; 多元化终端需求; 服务缓冲6-8pp
- **反驳**: 历史WFE周期平均4-5年; FY2025已是第3年上升; 库存积累信号
- **P2验证**: WFE传导模型完成; 服务缓冲6-8pp降低周期敏感性
- **P3验证**: 五引擎分析支持基准增速8-10%即使WFE零增长——但Agent B WFE零增长场景给出-3~-8%衰退(方向性矛盾)
- **当前置信度**: 55% | 从P2的68%下调至55% | **状态**: 关键矛盾待P4调和
- **P4重点**: Agent A "8-10%即使WFE零增长" vs Agent B "-3~-8%在WFE零增长" 是最大方向性矛盾

### KA-6: 服务业务经常性收入质量
- **假设**: 52Q连续增长的服务业务是真正的经常性收入(非一次性)
- **支持**: 装机基地持续扩大; 75%订阅+95%续约(Agent B P1); AMAT AGS对比显示KLAC服务质量更高
- **反驳**: 服务收入分类可能含一次性升级; 续约率未独立验证; AMAT AGS"假经常性"教训
- **P1验证**: Agent B确认75%订阅+95%续约率; 独立DCF $19.7B验证服务业务价值
- **P3验证**: AMAT对比完成,KLAC服务质量确认优于AMAT AGS; 但绝对验证仍缺第三方数据
- **当前置信度**: 68% | ↑+13pp | **状态**: 定性验证通过,定量验证受限于披露不足
