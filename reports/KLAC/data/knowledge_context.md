# KLAC Knowledge Context (Phase -1)
> 来源: 5份半导体规划档案(LRCX/AMAT/TSM/MU/AMD) | 2026-02-17

## 直接相关教训

### LRCX (PW=3, 传统, 470K) — 最相似
- **传统框架最高效**: PW=3直接给条件估值范围, 无需发现系统/OVM → KLAC同为PW=2.2
- **CSBG服务收入分析**: 服务/安装基地收入是周期缓冲器 → KLAC服务业务52Q连续增长同理
- **标注密度44.4/万创纪录**: 半导体硬数据天然密集 → KLAC检测数据同样密集
- **中国限制政策不确定性**: 数据有效期短 → KLAC也面临中国出口管制风险

### AMAT (PW=3, 传统, 304K) — 对称分析目标
- **广度vs深度护城河框架**: "不败≠胜利", 8产品线#2-3无#1 → KLAC是"深度#1"的对称案例
- **AGS vs CSBG横向对比**: 服务业务独立估值发现~50%埋没折价 → KLAC服务业务需独立估值
- **L4生态验证**: 4份半导体报告交叉发现4个FLAG → KLAC是第6份,需验证前5份KLAC相关数据
- **DM锚点前缀预分配**: Agent间前缀复用导致去重 → KLAC需Agent前预分配前缀
- **NVDA桥梁设计**: 12个DM-BRIDGE锚点预埋 → KLAC先进封装检测→TSMC CoWoS→NVDA

### TSM (PW=3, 传统, 451K)
- **TSM是KLAC最大客户(~25%)**: 客户集中度需验证 → KLAC需量化Top 5客户依赖
- **地缘政治中性表述**: 台海冲突/台海危机 → KLAC中国风险同适用
- **CapEx→设备传导链**: TSM CapEx→设备订单5阶段传导 → KLAC收入领先/滞后TSM CapEx

### MU (PW=3, 传统, 179K)
- **HBM扩产需要更多检测**: 存储检测需求增长 → KLAC存储收入占比需量化
- **内存周期三重验证(价格+库存+产能利用率)**: 周期信号 → KLAC WFE周期定位参考

### AMD (PW=5, 混合, 349K)
- **三源交叉验证矩阵**: 减少单源数据风险 → KLAC APIC-SBC必须多源交叉
- **CQ下调=P4对抗成功**: ≥30%CQ下调是健康信号 → KLAC P4目标
