## 2. Core Questions提取 (6个CQ)

### CQ1: AI投资能否产生超额回报，还是开源模式陷阱？ [Heat: 10]
- **本质**: BABA投入$53B做AI基础设施+开源Qwen模型，但开源=免费→如何变现？云+AI是第二曲线还是烧钱无底洞？
- **约束分类**: **结构性** — 开源vs闭源的商业模式是底层架构选择，不可逆
- **隐含假设**: 市场定价云=零值(SOTP分析) → 隐含假设AI投资净现值<0
- **模块映射**: CT05(AI生态) + TP03(云) + M14(Reverse DCF信念反演)
- **初始假设**: AI投资正NPV，云+AI将成为¥300B+收入引擎(FY2029)
- **证伪条件**: 连续4Q云增速<15% 且 AI产品收入增速放缓至<50%

### CQ2: 电商份额流失何时/在何处企稳？ [Heat: 8]
- **本质**: 淘天从52%(2021)→40-44%(2025)，核心问题不是"会不会止跌"而是"在哪里止跌"——35%？30%？还是更低？
- **约束分类**: **周期性+结构性混合** — 抖音直播电商天花板=周期性止跌，但社交电商本身=结构性转变
- **隐含假设**: 市场可能已定价淘天份额降至30-35%的稳态
- **模块映射**: CT03(竞争矩阵) + M03(护城河) + M07(增长分析)
- **初始假设**: 份额将在37-42%企稳(品牌电商优势+货架电商回归)
- **证伪条件**: FY2027淘天GMV份额<35% 或 CMR连续2Q YoY负增长

### CQ3: 中国折价的理性边界在哪里？ [Heat: 8]
- **本质**: BABA交易在20x PE而JD 9x/PDD 11x — 但如果按"中国折价"统一调整，BABA应该交易在多少倍？VIE折价在收窄还是扩大？
- **约束分类**: **制度性** — VIE法律框架+中美关系=制度层面，单个公司无法改变
- **隐含假设**: 当前定价隐含中国折价30-50%
- **模块映射**: CT01(VIE) + CT02(监管温度) + CT04(双币估值) + M14
- **初始假设**: 合理中国折价=15-25%(港股双重主要上市+PCAOB合规减缓风险)
- **证伪条件**: VIE法规重大变化 或 ADR退市实质化

### CQ4: 隐藏资产释放的催化剂和时间表？ [Heat: 7]
- **本质**: 蚂蚁33%权益(~$34B) + T-Head芯片(~$10-20B) + 投资组合(¥568B) = 市场当前几乎全部定价为零。释放机制是什么？
- **约束分类**: **制度性+周期性混合** — 蚂蚁IPO需监管批准(制度性)，T-Head IPO受芯片周期影响(周期性)
- **隐含假设**: 市值≈淘天单独估值 → 云+蚂蚁+国际+T-Head+现金=隐含负值
- **模块映射**: CT06(集团结构) + M14(SOTP) + M10(催化剂日历)
- **初始假设**: 2026-2027至少1个催化剂触发(概率>60%)
- **证伪条件**: 蚂蚁IPO+T-Head IPO均推迟至2028年后

### CQ5: FCF何时恢复，CapEx周期多长？ [Heat: 7]
- **本质**: FY2025 FCF从¥151B→¥78B，Q2 FY2026单季FCF-¥21B。这是3年投资周期(FY2025-27)还是永久性CapEx上升？
- **约束分类**: **周期性** — AI基础设施建设有周期，但规模和持续时间不确定
- **隐含假设**: 当前FCF yield约3.5% → 如果FCF恢复到¥150B+，yield将>6%
- **模块映射**: M05(FCF分析) + CT05(AI投资链) + M14(Reverse DCF)
- **初始假设**: CapEx在FY2027达峰，FY2028开始回落，FY2029 FCF回到¥140-160B
- **证伪条件**: FY2027 CapEx > FY2026 CapEx 且 管理层指引不减

### CQ6: 通才折价vs生态溢价 — BABA PE溢价合理吗？ [Heat: 6]
- **本质**: SGI=3.2(通才), 但BABA PE 20x > JD 9x / PDD 11x / BIDU 12x。市场是给了AI/云期权溢价，还是纯粹错误定价？
- **约束分类**: **结构性** — 多业务组合的估值方法论选择
- **隐含假设**: BABA的溢价=云+AI期权价值+蚂蚁权益+品牌溢价
- **模块映射**: CT06(集团) + M14(SOTP vs整体估值) + SGI框架
- **初始假设**: 溢价部分合理(云/AI期权)但程度可能过度(20x vs 应有的14-16x)
- **证伪条件**: 如果剔除云/蚂蚁估值后，核心电商PE<8x(低于JD)
