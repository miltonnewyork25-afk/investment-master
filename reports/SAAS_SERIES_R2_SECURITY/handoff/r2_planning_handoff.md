## 2. 母结构构思 (待验证)

### 母裂缝
三家都被市场贴"AI受益者"标签(PE 30-60x), 但AI同时让攻击成本暴跌. Claude Code/ChatGPT让任何人都能写exploit, 代码量指数增长→漏洞指数增长. 市场只给"AI防御"定价, 没给"AI让攻击面爆炸"定价.

### 母变量
"AI对安全行业是攻防对称还是攻防不对称" — 如果AI让攻击者效率+10x但防御者只+2x, 安全支出必须大幅增加(利好incumbents). 如果攻防对称, 现有架构可能被AI-native颠覆.

### 母命名候选
**"AI是安全公司的军火商"** — AI两边卖, 但只有防御者付费. 攻击者免费用Claude Code写exploit, 防御者付费给CRWD/PANW/FTNT买防护. 军火商两边供货, 一边付钱.

## 4. Claude Code / ChatGPT 专章要点

核心论证链:
1. AI编程工具让代码生成速度+5-10x
2. 更多代码 = 更多攻击面 (每1000行代码平均15-50个bugs)
3. AI生成代码有系统性漏洞模式 (训练数据中的不安全pattern)
4. 安全审查速度没有同步提升
5. 结果: 攻击面指数增长, 防御能力线性增长 = 结构性不对称
6. 转化为安全支出的强制增长 → CRWD/PANW/FTNT结构性利好

博弈论视角: 攻防不对称的重复博弈, 防御者必须持续投资维持均衡, CISO最佳回应是增加预算.
