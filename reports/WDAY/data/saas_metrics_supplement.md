|--------|---------|-----|---------|

*Owner PE计算: NI$693M为已扣SBC后。Owner Earnings = NI + SBC × (1-tax rate) = $693M + $1,570M × 0.75 = $1,871M → PE = 18.0x
*或: FCF-SBC = $2,777M - $1,626M = $1,151M → P/(FCF-SBC) = 29.3x

**关键洞察**:
- Non-GAAP PE 13.9x 看起来很便宜,但这完全忽略了$1.6B SBC
- P/FCF 12.1x 更客观,因为FCF包含了SBC(非现金)的正面效应
- 但FCF-SBC(扣除真实稀释成本)= 29.3x → 不算便宜
- **核心tension**: 回购$2.9B > SBC$1.6B → 净缩股=SBC正在被真金白银偿还

## 3. SaaS单位经济学 (M2模块)

### NRR间接推断法 (完整建模)
```
已知数据:
- FY2026 订阅收入增速: +14.5%
- GRR: 97% (Q4), 98% (Q1-Q3平均)
- 管理层: "约60%增长来自存量客户"

推算:
存量客户贡献 = 14.5% × 60% = 8.7%增速
→ NRR = GRR + 存量扩展 = 97% + 8.7% = ~106%

交叉验证:
- 新客贡献 = 14.5% × 40% = 5.8%增速
- 新客ARR ≈ $8,833M × 5.8% / (1+14.5%) = ~$448M 新增ARR
- 这与AI ACV>$100M(Q4)+传统新签约一致

结论: NRR ~105-106% (低于CRM~110%, 远低于NOW~120%)
```

### 为什么NRR偏低?
1. **HCM是核心**: HCM按per-employee定价 → upsell空间有限(员工数不大涨)
2. **FM渗透不足**: FM交叉销售是主要upsell路径,但F500中FM渗透仅<15%
3. **定价模式限制**: per-employee-per-month → 不随usage增长(vs NOW的模块化upsell)
4. **对比**: NOW产品线多(ITSM+ITOM+CSM+HR+Security)→ upsell路径多 → NRR 120%+

### Magic Number
```
Magic Number = 季度净新ARR × 4 / 前季度S&M支出

FY2026 近似计算:
- 订阅收入增量: $8,833M - $7,716M (FY2025) = $1,117M 净新ARR
- FY2025 S&M支出: $2,432M (注: FMP数据显示FY2026 S&M $3,862M可能有重分类)
- 使用FY2025 S&M: Magic Number ≈ $1,117M / $2,432M = 0.46

对比:
- DDOG: ~0.8-1.0 (高效)
- CRM: ~0.5-0.6 (中等)
- NOW: ~0.6-0.7 (中等偏高)
- **WDAY: ~0.46 (偏低)**
```

### Rule of 40
```
Rule of 40 = 收入增速 + FCF Margin
= 13.1% + 29.1% = 42.2% ✓ (超过40底线)

SBC-adjusted Rule of 40 = 增速 + (FCF-SBC)/Revenue
= 13.1% + ($2,777M - $1,626M)/$9,552M
= 13.1% + 12.0% = 25.1% ✗ (低于40!)

对比:
- 标准: 42.2% (合格)
- SBC-adjusted: 25.1% (不合格! SBC严重侵蚀增长质量)
```

### S&M效率
```
S&M Efficiency = 净新ARR / S&M支出
= $1,117M / $2,432M (FY2025 S&M) = 0.46x

趋势:
- FY2024: ~$1,040M / $2,139M = 0.49x
- FY2025: ~$1,187M / $2,432M = 0.49x
- FY2026: ~$1,117M / $2,432M = 0.46x ← 下降!

结论: S&M效率微幅恶化(0.49→0.46),可能反映:
1. 增速减速(分子下降)
2. 国际扩张成本上升(分母增加)
3. AI产品初期推广成本
```

## 4. 回购效率分析 (η计算)

```
FY2026回购:
- 回购金额: $2,895M
- 回购股数: 12.8M shares
- 平均回购价: $2,895M / 12.8M = $226.17/share
- 当前股价: $127.07
- 回购浮亏: ($127 - $226) / $226 = -43.8%

η (回购效率) = (EPS增厚 × 价值覆盖) / (杠杆风险 × 机会成本)
简化: η = 回购收益率 / WACC = (FCF Yield) / WACC = 8.5% / 10% = 0.85

结论: η = 0.85 < 1.0 → 在当前价格回购效率尚可
但FY2026回购均价$226远高于当前$127 → 管理层在高位回购了大量(毁灭价值)
如果在当前$127价继续回购: η = FCF Yield 8.5% / 10% = 0.85 (仍<1但接近合理)
```
