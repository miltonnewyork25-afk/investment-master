**GRR下降时间点**: Q2 FY2026(2025年7月) — 恰好是Elliott 9月披露持仓前2个月。

### NRR推断(更新版,含AI贡献)
```
已知:
- 订阅增速: 14.5% (FY2026)
- GRR: 97% (Q2-Q4)
- 60%增长来自存量客户
- AI贡献: ARR增速中的1.5+pp

推算:
存量贡献 = 14.5% × 60% = 8.7%
→ NRR = 97% + 8.7% = ~105.7%

其中AI贡献:
- AI贡献1.5pp在14.5%中 → AI占增速的10.3%
- AI在存量vs新客的分配未知,假设50/50
→ 非AI NRR ≈ 97% + (8.7% - 0.75%) = ~104.9%
→ AI增强NRR ≈ ~105.7%

结论: NRR ~105-106%(其中AI贡献~0.75pp)
```
