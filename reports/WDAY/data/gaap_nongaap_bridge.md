## 5. Owner Economics精确计算

```
方法1: GAAP NI调整法
Owner Earnings = GAAP NI - SBC税后成本
= $693M - $1,626M × (1 - 0.19 tax shield)
= $693M - $1,317M
= **-$624M** (NEGATIVE)
→ Owner EPS = -$624M / 268M shares = **-$2.33/share**

方法2: FCF调整法(更客观)
FCF-based Owner Earnings = FCF - SBC
= $2,777M - $1,626M
= **$1,151M**
→ FCF-SBC per share = $1,151M / 268M = **$4.29/share**
→ P/(FCF-SBC) = $127 / $4.29 = **29.6x**

方法3: 净缩股调整(考虑回购抵消)
Net SBC cost = SBC - Buyback = $1,626M - $2,895M = **-$1,269M (净回报!)**
→ 在FY2026,回购完全覆盖SBC并额外返还$1.27B
→ 如果回购持续: Owner Earnings = FCF = $2,777M
→ P/FCF = $127 × 263M / $2,777M = **12.0x** ← 最乐观但需假设回购持续
```

**三种Owner PE视角总结**:
| 方法 | Owner Earnings | Owner PE | 含义 |
|------|---------------|---------|------|
| 方法1 (严格) | -$624M | **无意义** | SBC>NI, 不可持续 |
| 方法2 (FCF-SBC) | $1,151M | **29.6x** | 扣除稀释的真实现金回报 |
| 方法3 (含回购) | $2,777M | **12.0x** | 假设回购持续抵消SBC |

**关键判断**: 方法3的12.0x最乐观但需要回购持续($2.9B/年)。剩余授权$2.1B仅够~0.7年。如果回购缩减到$1B/年(覆盖SBC但不净缩股)→ Owner PE回到方法2的~30x。
