## 1. 上游 (Suppliers)

### 1.1 关键原材料
- **超级合金 (Nickel-based)**: 用于燃油喷嘴/燃油泵高温部件 — 主要供应商: ATI Specialty Metals, Haynes International, Carpenter Technology
- **钛合金**: 作动器/阀门壳体 — 主要供应商: ATI, Titanium Industries, Sierra Alloys, TIMET
- **精密铸件**: Howmet Aerospace (HWM) 等少数寡头, 是关键卡位
- **特种锻件**: PCC (Berkshire子公司), Allegheny Tech
- **电子元件**: 用于FADEC/速度控制系统 — 一般工业级 + 航空级双源

### 1.2 上游议价力 (POKA-YOKE 风险)
- **集中度高**: 超级合金/精铸寡头(Howmet/PCC)定价权强 → WWD毛利受原材料周期影响
- **历史信号**: FY22毛利率仅22.0% (vs FY25 26.8%) — 供应链通胀+利用率低双杀
- **当前**: 管理层承认"supplier challenges + factory hard capacity constraints"将持续到2026后期

## 3. 关键JV: Woodward-GE Aviation Fuel Systems JV (Wood-GE)
- **成立**: 2016年1月正式运营
- **结构**: 50/50, 设计/开发/采购/供应/服务**GE全部大型商飞引擎的燃油系统(从inlet到nozzle)**
- **覆盖**: GE90 / GEnx / GE9X / 未来全部
- **关键**: WWD是JV的"preferred supplier" → JV采购→WWD制造→WWD收入入账双重受益(母公司收入 + 50%运营利润分成)
- **战略意义**: 锁定**最大商飞引擎家族至少30年生命周期**, 是WWD护城河的"承重墙"

**关键洞察:**

2. WWD最像谁? **结构上像Curtiss-Wright** (双业务+独立+利基), **不像HEICO/TDG** (后者纯航空AM专卖店)
3. **ROIC 11%在comp中偏低** (Howmet 17%, Curtiss 14%, HEICO 15%) — 资本效率有改善空间

## 5. TAM & 行业规模

### 5.1 航空 (WWD Aero ~$2.2B FY25)
- **全球Aircraft Fuel System市场**: $10.3B (2025) → $17.9B (2034), CAGR **6.3%**
- **Aircraft Engine Fuel System (狭义)**: $2.0B → $3.0B (2034), CAGR ~4%
- **Engine MRO总市场**: $42.7B (2025) → $58.2B (2030), CAGR **6.4%**
- **2026商飞AM总规模**: $139B, **engine spend占53%** (~$74B)
- **WWD份额**: 在狭义engine fuel system中是top-3之一(估), 通过JV锁定GE全部大型商发→**渗透率头部**

### 5.2 工业 (WWD Industrial ~$1.4B FY25)
- **数据中心备电(reciprocating engine)**: $7.9B (2026) → $9.8B (2031), CAGR 4.6% (保守) ~ 19.7B (2030, AI驱动情景)
- **大型双燃料发动机**: 增长来自能源转型 (氢/氨/甲醇)
- **WWD在大型发动机控制**: 独立供应商no.1, 但高马力市场被CAT/CMI/RR垂直整合

## 6. 关键预期差信号 (Phase 0.75预热)

### 6.1 信号A: 估值不极端但质量不匹配
- WWD PE 47x在同行不算异常, 但**EBITDA margin 19% / ROIC 11%是comp中后段** → "高估值溢价 vs 中等质量"= **质量溢价错配**
- TransDigm/HEICO享受高PE的根本: **EBITDA margin 30-50% + ROIC 15-20% + 80%+ AM业务**. WWD: 19% / 11% / ~40% AM → 不在同一quality bucket

### 6.2 信号B: 上下游普遍乐观但单点风险被低估
- 几乎所有客户(GE/CAT/CMI/Lockheed/RR)都在扩产
- **但Spirit AeroSystems Q1 2026 fuselage delivery减速** = Boeing 737 MAX爬坡的真实瓶颈
- WWD aero OE +14%的可持续性绑定在Boeing执行上 — **集中度风险被市场打平**

### 6.3 信号C: GE JV是承重墙但市场未完全定价
- 50/50 JV锁定LEAP/GE9X的"30年AM现金流" — 这是WWD护城河中**最强的部分**, 但财务披露分散在JV + 母公司
- 真实"穿透到WWD"的JV价值需要拆解 (Phase 2 R-1财务归因任务)

### 6.4 信号D: Industrial Q1 +30%的真实结构
- 管理层承认"supplier challenges + capacity constraints"
- 但同时收入Q1 +30% → **要么客户提前下单/补库存 (sell-in > sell-out), 要么真需求溢出**
- 数据中心叙事强但真实$占比未披露 — Phase 1需挖

### 6.5 信号E: 1Y +113.5%涨幅 + Sell-side TP低于现价
- 卖方平均TP $352 vs 现价 $372 → **共识已"跟不上市场"**, 这是顶部信号 OR 卖方落后?
- 类似1990年代/2017年GE/2021年HXL等"周期股触顶估值"模式
