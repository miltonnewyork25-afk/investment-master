## Part 1: 模块定位矩阵 (模板B)

### M1 品牌身份与定位

| 维度 | 评估 |
|------|------|
| **当前状态** | 全球Top 6品牌(Interbrand), 95%+美国认知度, 但Gen Z "酷感"流失中, 中国市占从42%降至34.2% |
| **vs CMG** | CMG品牌窄但深(健康快餐唯一=定位锐利), SBUX品牌宽但正在模糊(第三空间vs便利外卖的身份冲突) |
| **vs MCD** | MCD品牌覆盖全球更广(39,000+门店), 本地化能力更强, SBUX在品牌授权深度上远逊MCD(Nestle协议vs MCD自主体系) |
| **最易误判** | 1) "品牌认知度高"被等同于"定价权强" -- 但Ch5实证弹性从-0.6恶化至-2.0, 品牌力与定价权脱钩; 2) 中国品牌价值被JV "保留"的假设 -- JV后品牌控制力实质让渡 |
| **缺失证据** | Gen Z品牌偏好迁移的定量追踪(BROS vs SBUX年龄段渗透率时间序列); Interbrand品牌价值5年趋势 |
| **KS状态** | KS-08(BROS 2000店)部分覆盖, 但缺独立的品牌价值衰减KS |

### M2 定价权与价格弹性

| 维度 | 评估 |
|------|------|
| **当前状态** | 弹性系数从-0.6恶化至-2.0, 正Veblen效应(+0.33)仅在高收入客群成立, 价格溢价vs Dunkin +85%, 但溢价接受度从75%→67% |
| **vs CMG** | CMG定价权更强(Food with Integrity叙事+品类独特性), 弹性系数估计-0.3~-0.5; SBUX面临更多低价替代(7-Eleven/Dunkin/家庭咖啡) |
| **vs MCD** | MCD主动降价换量(Value Menu策略), SBUX被迫提价维持margin -- 两种截然不同的定价哲学, MCD更可持续 |
| **最易误判** | 1) Veblen效应被泛化至全客群 -- 实际上仅32%的象限I客户呈正弹性, 68%客户价格敏感; 2) "ticket +1%"看似温和, 但冷饮占比增(25%→40%)是隐性提价 |
| **缺失证据** | 按区域/收入层的弹性系数分布; 竞品实际价格差距跟踪(BROS/Dunkin vs SBUX逐年) |
| **KS状态** | 无独立定价权KS, 被嵌入KS-01(comp)和KS-08(BROS), 建议新增 |
