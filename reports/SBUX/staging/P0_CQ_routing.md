## 3. CQ注册表 (5个核心矛盾问题)

### CQ1: 78x P/E隐含什么？信念互斥是否成立？
- **矛盾类型**: 结构性 (估值框架内禀矛盾)
- **核心张力**: 市场同时定价两个逻辑互斥的信念:
  - 信念A: EPS恢复$3.50+ → 需维持自营高收入贡献(55%+ co-op)
  - 信念B: 估值倍数25-30x → 需提高特许化比例→放弃自营收入
  - 两者不可同时为真: 特许化↑ → EPS基数↓ → 需更高倍数补偿
- **初始假说**: 市场在赌"Niccol能在不特许化的情况下恢复OPM至15%"，这比信念互斥更朴素但也更脆弱
- **置信度**: 45% (数据不足以判断市场真正在赌什么)
- **Phase目标**: Phase 2 Reverse DCF量化隐含假设集

### CQ2: Niccol = CMG 2.0还是Schultz 3.0？转型速度够快吗？
- **矛盾类型**: 周期性 (CEO转型的有限窗口期)
- **核心张力**: Niccol在CMG的成功(2Q comp转正→6年2x)是否可复制到SBUX？
  - 差异1: CMG比SBUX小5x(门店数)——规模阻力更大
  - 差异2: SBUX有工会问题，CMG没有
  - 差异3: SBUX中国业务CMG没有的复杂度
  - Q1 FY2026交易量+3% = 积极信号，但需3Q连续确认
- **初始假说**: Niccol的"简化菜单+聚焦体验"战略在方向上正确，但执行速度受制于工会+627家关店的摩擦成本
- **置信度**: 50% (一个季度正向数据不足)
- **Phase目标**: Phase 1 CEO评分卡 + CMG/MCD/DPZ类比矩阵

### CQ3: 中国$4B JV是战略撤退还是价值解锁？
- **矛盾类型**: 结构性 (资产所有权vs品牌授权的本质选择)
- **核心张力**:
  - 看多: 以$13B总估值(60%给Boyu=$4B)解锁中国风险溢价，International OPM→高teens/20%+
  - 看空: 放弃中国8000+门店直营=承认无法与瑞幸/库迪竞争，品牌控制力下降
  - Q1 FY2026 BS变化: Goodwill $3.37B→$1.31B, PP&E $17.8B→$15.6B = 已deconsolidate
- **初始假说**: 中国JV是被迫的"体面撤退"——市场份额从42%→14%是不可逆的结构性溃败，但$13B估值对标YUM China $9.8B IPO仍合理
- **置信度**: 55% (JV条款已公布，可验证)
- **Phase目标**: Phase 1 Ch6中国JV拆解 + Phase 3 NZRE隔离定价

### CQ4: 负$8.4B权益 + ROIC<WACC = 回购摧毁价值？
- **矛盾类型**: 制度性 (资本配置策略的内在逻辑)
- **核心张力**:
  - 2019-2023年回购$19B >> 同期NI $9B = 融资回购
  - FY2025 ROIC 8.5% vs WACC ~9-10% = 回购是价值摧毁
  - Niccol暂停回购(FY2025 $0) = 隐性承认问题
  - 但Dividend payout >100% NI (FY2025: $2.77B div / $1.86B NI = 149%)
- **初始假说**: 负权益是前任管理层的遗产，Niccol暂停回购正确但dividend仍不可持续(FCF $2.44B - Div $2.77B = -$0.33B)
- **置信度**: 60% (FCF/Div数据清晰)
- **Phase目标**: Phase 2 Ch10 NEP负权益估值框架

### CQ5: 35.5M Rewards会员 = 增长引擎还是天花板？
- **矛盾类型**: 周期性 (增长曲线拐点判断)
- **核心张力**:
  - Rewards占US交易57%→接近饱和？还是从57%→75%的增长空间？
  - Investor Day新三层会员(Green/Gold/Reserve) → 货币化升级 vs 复杂度增加
  - 预存卡浮存金$1.87B + 年breakage $208M = 独立估值标的
  - 但: 瑞幸/MCD/BROS都有类似程序，Rewards不是护城河只是表赌注
- **初始假说**: Rewards是运营效率工具而非增长引擎——57%渗透率接近美国成熟品牌天花板(MCD ~30%, NKE ~55%)
- **置信度**: 40% (需更多渗透率数据)
- **Phase目标**: Phase 1 Ch4 DFFV估值 + Phase 2 Ch11 CSSPD纯度分解

## 4. 方法论路由决策

### A-Score v2.0 校准
- **行业基准**: QSR/Coffee → 品牌权重20%(vs 消费品标准15%)
- **特殊调整**: 负权益公司→传统ROE/ROIC维度需替换为"调整后资本回报率"
- **A-Score预估**: ~6.5-7.0 (品牌强但资本效率恶化)

### PtW战略一致性 (v18.0)
- **预判最薄弱层**: L2 "在哪里赢"(Where to Win)
  - 美国: 16,000+店=饱和，关闭627家承认过度扩张
  - 中国: 出售60%给Boyu=战略撤退
  - 其他国际: 特许化覆盖但增长有限
- **PtW预估**: ~35/50 (战略方向清晰但"在哪里赢"缺乏新增长极)

### CEO沉默分析 (v18.0 QG-01.5)
- **预设扫描域**:
  1. 工会合同谈判进展 (Workers United, 12,000+员工投票)
  2. 门店蚕食效应 (627家关店暗示)
  3. OPM恢复具体时间表 (只有FY2028目标，无中间路径)
  4. 负权益/资本结构可持续性
  5. 中国JV后续经济条款细节 (royalty rate?)
  6. 菜单简化对短期收入的负面影响
- **Phase 1执行**: 扫描Q4 FY2025 + Q1 FY2026 earnings call transcripts

### Kill Switch预设 (v18.0)
- **KS-01**: Q2 FY2026美国comp sales回负 → 信念A失败
- **KS-02**: FY2027E EPS共识下调>15% → 市场放弃转型叙事
- **KS-03**: Niccol离职/被替换 → 转型故事崩塌
- **KS-04**: 工会全面罢工>1周 → 运营中断+品牌损害
- **KS-05**: 中国JV估值减记>30% → 隐含中国"永久失去"
