# 第一章 执行摘要与身份界定

## 1.1 一句话定位

Vertiv是全球数据中心电力与热管理基础设施的双寡头之一(与Schneider Electric并列)，也是NVIDIA AI服务器液冷解决方案的首选供应商。公司2025财年营收$102亿，其中约85%来自传统UPS/配电/空调业务，约15%来自快速增长的液冷和AI相关产品。

## 1.2 核心身份矛盾

市场以**PE 46倍**为Vertiv定价，这是一个显著高于传统工业品同行(Eaton 31倍、Schneider 28倍)的估值。这意味着市场将Vertiv视为"AI基础设施公司"而非"工业品制造商"。但营收结构告诉我们一个更复杂的故事：

| 业务类型 | 估计营收占比 | 增长属性 | 估值锚定 |
|---------|:----------:|---------|---------|
| **传统业务**(UPS/配电/精密空调/服务) | ~85% | 稳定增长(10-15%) | 工业品 25-30x PE |
| **AI增量**(液冷CDU/高密度电力/模块化DC) | ~15% | 爆发增长(50-100%+) | 科技基础设施 40-60x PE |
| **合计** | 100% | +28% FY26E | 市场给予46x PE |

这个矛盾是理解VRT投资论文的起点：**15%的AI业务驱动了100%的估值溢价**。如果液冷增长不及预期或竞争侵蚀份额，估值的"AI溢价"将快速消退。反之，如果AI业务占比在3年内升至30-40%，当前估值可能被证明是合理的。

# 第二章 业务架构拆解

## 2.1 Vertiv是做什么的

Vertiv的核心业务可以用一句话概括：**为数据中心提供电力和冷却**。

数据中心是互联网经济的物理基础，而每个数据中心都需要两个核心基础设施系统：
1. **电力系统** — 确保服务器获得不间断、高质量的电力供应
2. **热管理系统** — 将服务器运算产生的热量高效排出

Vertiv在这两个领域都是全球前两名的供应商。具体产品线包括：

### 电力管理产品
- **UPS(不间断电源)** — Vertiv的传统核心，确保电力中断时数据中心持续运行。品牌Liebert。全球份额#2(仅次于Schneider)
- **配电设备** — 开关柜、母线槽、PDU(电力分配单元)
- **电池与储能** — 锂电池系统、电池监控
- **电力调节** — 变压器、整流器、逆变器

### 热管理产品
- **精密空调(CRAC/CRAH)** — 传统数据中心风冷方案，Vertiv全球冷却市场份额#1(23.5%，Omdia数据)
- **液冷CDU(冷却液分配单元)** — 新一代AI服务器核心冷却方案。旗舰产品Liebert XDU 1350。VRT在NVIDIA GB200首批CDU出货中占70%+份额
- **行级冷却/热通道遏制** — 高密度部署方案
- **MegaMod HDX** — 2026年1月发布的模块化液冷基础设施方案，支持高达10MW、100+kW/机架

### 集成方案与服务
- **模块化数据中心** — 预制集装箱式数据中心(电力+冷却+IT机架一体化)
- **DCIM软件** — 数据中心基础设施管理，品牌Vertiv Intelligence
- **生命周期服务** — 预防性维护、远程监控、应急响应、备件。全球300+服务中心，4,400+现场工程师

# 第三章 数据中心基础设施产业链定位

## 3.1 产业链全景

数据中心基础设施可以分为四层：

```
┌─────────────────────────────────────────────────────────────┐
│                    应用层 (Application)                       │
│         AI训练/推理 → 云计算 → SaaS → 流媒体                  │
│     [用户: Microsoft, Google, Meta, Amazon, 企业客户]         │
├─────────────────────────────────────────────────────────────┤
│                    IT设备层 (Compute)                         │
│          GPU/CPU → 内存 → 存储 → 网络                         │
│     [NVDA, AMD, INTC, MU, ANET, AVGO]                       │
├─────────────────────────────────────────────────────────────┤
│  ★ 基础设施层 (Infrastructure) — VERTIV的战场               │
│      电力(UPS/配电/变压器) + 冷却(空调/液冷/CDU)              │
│     [VRT, Schneider, Eaton, ABB, nVent]                     │
├─────────────────────────────────────────────────────────────┤
│                    建筑层 (Facility)                          │
│         土建 → 电力接入 → 光纤 → 安全                         │
│     [地产商, 公用事业, 光纤供应商]                              │
└─────────────────────────────────────────────────────────────┘
```

Vertiv处于**基础设施层**——位于IT设备(GPU/CPU)和建筑外壳之间。这个位置的战略意义在于：
- **必要性**: 每一台服务器都需要电力和冷却，没有例外
- **随GPU算力增长而放大**: AI GPU功耗从传统服务器的300W→NVIDIA B200的1000W+，电力和冷却需求成倍增长
- **长寿命**: 基础设施使用寿命15-20年，远长于IT设备(3-5年)，带来长期服务收入

## 3.2 AI驱动的功率密度跃升

AI对数据中心基础设施的影响可以用一个数字概括：**功率密度**。

| 时代 | 典型功率密度 | 冷却方案 | VRT产品 |
|------|:----------:|---------|---------|
| 传统DC (2000-2020) | 5-15 kW/机架 | 风冷(CRAC/CRAH) | Liebert精密空调 |
| 早期AI (2023-2024) | 40-60 kW/机架 | 混合(风冷+行级液冷) | 行级冷却+CDU |
| 当前AI (2025-2026) | 70-132 kW/机架 | 直接液冷(DLC/冷板) | **Liebert XDU 1350** |
| 下一代AI (2027-2028) | 240-600 kW/机架 | 全液冷+HVDC | **MegaMod HDX** |
| 远期 (2029-2030) | 1 MW/机架 | 800V HVDC+SiC SST | **颠覆性变革** |

**关键传导链**：GPU算力↑ → 功耗↑ → 散热需求↑ → 从风冷转向液冷 → VRT液冷业务爆发

每一代AI芯片的功率提升都直接转化为数据中心基础设施的升级需求：
- **NVIDIA H100** (700W) → 传统风冷勉强可用
- **NVIDIA B200** (1000W) → 液冷成为必须
- **NVIDIA Rubin Ultra** (2027E, 1200W+) → 全液冷+高压直流

这就是Vertiv从"传统工业品公司"向"AI基础设施公司"转变的物理基础。

# 第四章 液冷：从边缘业务到核心引擎

## 4.1 为什么液冷是AI时代的必需品

传统数据中心用风冷(把冷风吹过服务器)来散热。这在5-15kW/机架的功率密度下工作良好。但当NVIDIA B200 GPU将单机架功耗推升至70kW以上时，风冷的物理极限被突破——空气的热容量不足以带走如此密集的热量。

液冷(尤其是直接液冷DLC)通过将冷却液直接流过芯片表面来散热，冷却效率比风冷高10-20倍。这不是一个"更好"的选择，而是**唯一的选择**。

| 冷却方式 | 散热能力 | 适用密度 | 能效(PUE) | 状态 |
|---------|:------:|:------:|:-------:|------|
| 风冷(CRAC) | 低 | <15kW/rack | 1.4-1.6 | 传统/成熟 |
| 行级冷却 | 中 | 15-40kW/rack | 1.3-1.4 | 过渡方案 |
| 直接液冷(DLC/冷板) | 高 | 40-200kW/rack | 1.05-1.15 | **当前主力** |
| 浸没式液冷 | 极高 | 200kW+/rack | 1.02-1.08 | 早期/长期方向 |

## 4.2 Vertiv在液冷中的地位

**旗舰产品**：Liebert XDU 1350 CDU(冷却液分配单元)
- 单价约$150,000-200,000/台
- 为NVIDIA GB200 NVL72机架提供液冷支持
- VRT在GB200首批CDU出货中占**70%+**份额

**NVIDIA合作**：
- 共同开发GB200 NVL72完整电力+冷却参考架构
- 这意味着VRT的产品成为NVIDIA生态系统的"默认选择"
- 一旦进入参考架构，切换成本极高(重新认证+重新集成)
- **这是VRT最强的护城河来源**

**新产品**：MegaMod HDX (2026年1月发布)
- 模块化液冷基础设施方案
- Compact版：13个机架/1.25MW
- Combo版：144个机架/10MW
- 针对下一代更高功率密度(100+kW/架)设计

**CDU产能扩张**：
- 2024年CDU产能扩大45倍
- 新工厂：马来西亚柔佛(2026 Q1投产)、美国南卡Pelzer(扩建)
- 积极收购：2025年底完成PurgeRite收购(~$10亿)，增强液冷流体管理能力

## 4.3 液冷市场竞争态势

Vertiv虽然目前领先，但竞争正在快速加剧：

| 竞争对手 | 液冷动作 | 威胁等级 | VRT的优势/劣势 |
|---------|---------|:------:|------------|
| **Schneider Electric** | 收购Motivair + 与NVIDIA联合设计**GB300**液冷参考架构 | ★★★★★ | Schneider可能在下一代(GB300/Rubin)取代VRT的首选地位 |
| **Eaton** | $95亿收购Boyd Thermal Management(液冷) | ★★★★ | Eaton具备规模和渠道，Boyd补齐技术短板 |
| **nVent Electric** | 已部署1GW+液冷，与NVIDIA合作 | ★★★ | 更专注于机柜/连接器层面，与VRT产品线重叠度有限 |
| **CoolIT Systems** | NVIDIA早期合作伙伴，冷板液冷技术 | ★★★ | 私营企业，规模有限但技术领先 |

# 第五章 800V HVDC：颠覆者还是被颠覆者

## 5.1 800V HVDC架构是什么

传统数据中心的电力架构是：

```
电网(高压交流) → 变压器 → UPS(交流→直流→交流) → PDU → 服务器电源(交流→直流)
```

每一次交直流转换都会损失2-5%的能量。UPS是这条链中最大的能量消耗点之一。

**800V HVDC(高压直流)**架构的革命性在于：

```
电网(高压交流) → SiC固态变压器 → 800V直流母线 → 直接供电给服务器
```

这意味着：
- **消除UPS**——直流供电不需要交直流转换
- **消除传统PDU**——800V直流直接分配
- **效率提升~5%**——减少多次转换损耗
- **维护成本降低70%**——更少的机械部件
- **占地面积减少30-40%**——消除UPS机房

## 5.2 NVIDIA正在推动这个转变

- **2026H2**: NVIDIA Kyber/Rubin Ultra平台计划采用800V HVDC供电
- **2027目标**: 1MW/机架，需要全新电力架构
- **VRT自身参与**: 计划2026H2发布800V DC架构产品组合，与NVIDIA联合开发

## 5.3 对VRT的双面影响

**被颠覆面**：
- UPS是VRT最大的单一产品线，估计贡献$4B+年营收
- 如果800V HVDC在2028-2030年标准化，传统UPS在AI数据中心的需求将大幅萎缩
- 但传统数据中心(非AI)和电信/企业客户仍需要UPS——基数不会归零

**颠覆者面**：
- VRT正在主动开发800V产品，试图将"被颠覆"变为"自我进化"
- 800V电力管理(SiC SST + HVDC配电)的单位价值可能高于传统UPS
- VRT的电力管理专业知识在架构转换中仍然有价值——从"UPS供应商"变为"电力架构供应商"

**时间线评估**：

| 阶段 | 时间 | 800V渗透率(AI DC) | 对VRT UPS的影响 |
|------|-----|:----------------:|--------------|
| 试点阶段 | 2026-2027 | <5% | 几乎为零 |
| 早期采用 | 2028-2029 | 10-20% | 边际影响(-5%~-10%) |
| 规模化 | 2030-2032 | 30-50% | 显著影响(-15%~-25%) |
| 标准化 | 2033+ | 50%+ | 结构性替代 |

**关键判断**: 800V HVDC对VRT的真正影响在2030年之后才会显著。在此之前，VRT有3-5年窗口期来完成从"UPS公司"到"电力架构公司"的转型。这个转型的成败将决定VRT的长期投资价值。

## 5.4 功率半导体上游视角

800V HVDC架构的核心器件是SiC(碳化硅)功率半导体：

| 市场 | 2025规模 | CAGR | 主要供应商 |
|------|---------|:----:|----------|
| SiC功率器件(全球) | $27亿 | 25% | STMicro(33%), onsemi, Infineon |
| 其中DC应用 | ~$5亿 | 30%+ | — |

**对VRT的意义**：SiC器件成本是800V HVDC方案的主要瓶颈。随着SiC成本下降(预计2028-2030年降40-50%)，800V方案的经济性将显著改善，加速对传统UPS的替代。
