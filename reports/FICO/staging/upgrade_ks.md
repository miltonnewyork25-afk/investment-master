### KS-FICO-11: 回购η效率

| 字段 | 内容 |
|------|------|
| **定义** | η(eta)回购效率 = 股数减少% / (回购金额/市值), 衡量每$1回购对EPS的实际贡献效率; η>100%=回购价低于均价(好), η<100%=回购价高于均价(差) |
| **当前值** | FY2025 η=61.8%(回购$1,415M, 市值~$42B, 股数减少-2.1%); FY2024 η=114.3% |
| **数据源** | FICO 10-K/10-Q(回购金额+股数) + 市值数据(市场报价) |
| **频率** | 季度(回购数据季度披露) |
| **升级触发** | η>100%连续2季 且 ND/EBITDA<2.5x: 回购效率高+杠杆安全=资本配置合理 |
| **降级触发** | η<60% 且 ND/EBITDA>3.0x: 在高估值+高杠杆下低效回购=管理层资本配置能力存疑; 每$1回购对EPS贡献持续递减 |
| **CI关联** | CI-02(定价权期权时间衰减 — η递减意味着回购驱动的EPS增长引擎在失效) |
| **R关联** | R4(杠杆风险 — FY2025回购$1,415M超过FCF $770M, 缺口$650M靠举债填充) + R5(PE压缩 — 若EPS增长主要靠回购而非有机增长, PE溢价难以维持) |
| **滞后性** | 滞后指标 — 反映已执行的回购效率; 但趋势变化对未来EPS增速有前瞻含义 |
| **可信度** | ★★★★☆ — 回购金额和股数是审计数据; η计算中的"平均市值"使用简化估计, 可能有轻微偏差 |
| **交叉验证** | 与FCF覆盖率交叉(回购/FCF比率: FY2025=1.84x, 超过FCF→举债回购); 与ND/EBITDA趋势交叉(回购融资来源); 与EPS增长拆解交叉(有机增长 vs 回购驱动占比) |
| **历史范围** | FY2014 η=31.5% → FY2018 η=60.0% → FY2022 η=90.9% → FY2024 η=114.3% → FY2025 η=61.8%; 趋势: 非线性, FY2024高峰后FY2025骤降 |

### KS-FICO-12: 政治注意力指数

| 字段 | 内容 |
|------|------|
| **定义** | 衡量FICO定价行为引发的政治/监管关注密度: 国会听证/议员公开信 + DOJ调查/行动 + CFPB行动/报告 的季度加权事件计数 |
| **当前值** | 中等(4/10): Senator Hawley两次呼吁调查(未获DOJ响应) + FHFA已采取行动(VantageScore获批) + CFPB瘫痪(Trump任期) + DOJ调查已关闭 |
| **数据源** | 国会记录(Congress.gov) + DOJ新闻稿 + CFPB行动公告 + FHFA公告 + 行业协会(MBA/CHLA/ICBA)公开信/声明 |
| **频率** | 季度汇总(事件驱动的即时关注+季度趋势评估) |
| **升级触发** | 指数降至2/10以下: CFPB持续瘫痪+国会注意力转移+无新诉讼=政治天花板远离, C1更安全 |
| **降级触发** | 指数升至7/10以上: DOJ开启新调查 或 国会听证FICO定价 或 CFPB复活后发布定价管制提案 = 政治天花板逼近, C1加速侵蚀 |
| **CI关联** | CI-01(制度垄断自我加固悖论 — 定价权释放引发政治反弹的反身性循环) |
| **R关联** | R1(VS份额 — 政治压力是VS获得制度支持的催化剂) + R3(反垄断 — 政治注意力与法律行动正相关) |
| **滞后性** | 领先指标 — 政治注意力上升通常领先于实际监管行动6-18个月(Hawley呼吁→FHFA行动用了约12个月) |
| **可信度** | ★★☆☆☆ — 事件计数客观, 但"注意力强度"评分包含主观判断; 需标准化评分方法 |
| **交叉验证** | 与FICO版税提价时间线交叉(提价→政治反应的滞后期); 与行业协会声明频率交叉; 与FICO 10-K Risk Factors章节变化对照(新增风险因素=公司自身也在关注); 与历史先例(Visa/MC反垄断、LIBOR改革)政治注意力曲线对照 |
| **历史范围** | 低: 1/10(2014-2019, 零政治关注); 转折点: 2020(Senator Hawley首次关注); 高: 5/10(2025.7, FHFA+Hawley+诉讼同时爆发); 当前: 4/10(CFPB瘫痪部分对冲) |

## 使用说明

1. **季度必检(KS-01/02/03/04/10/11)**: 每个FICO earnings后48小时内更新
2. **事件驱动(KS-05/06/07/09/12)**: 设Google Alerts/PACER通知, 事件发生后24小时内评估
3. **半年度(KS-08)**: 征信局年报/半年报后更新VS定价趋势
4. **触发联动**: 任一KS触发降级时, 检查关联KS是否协同恶化(如KS-01↑ + KS-12↑ + KS-09降级 = 三重恶化, 需重新评估评级)
5. **评级校准**: 3个以上KS同时触发降级 → 评级从"审慎关注(偏中性)"降至"审慎关注(强)"
