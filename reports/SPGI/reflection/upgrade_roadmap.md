## 进化提议 (EVO-SPGI-xxx)

### EVO-SPGI-001: 地理分析强制模块 (M7)
- **问题**: 国际收入>30%的公司缺地理分析 = 结构性遗漏
- **修复**: Phase 1 QG增加检查项: "国际收入>30% → Ch必须含地理拆分表"
- **影响**: 所有国际化公司(SPGI/MCO/MSCI/ASML/TSM)
- **优先级**: P1(下份金融报告前实施)

### EVO-SPGI-002: 续约率硬数据门控
- **问题**: "推断95%+"反复引用但无硬数据 → 投资论文建立在未验证假设上
- **修复**: Phase 0数据预取增加: earnings call关键词搜索("retention"/"renewal"/"churn"), 如无结果则在报告中标注"[数据不可得: 续约率]"而非推断
- **影响**: 所有订阅模式公司
- **优先级**: P1

### EVO-SPGI-003: 扩写DM同步规则
- **问题**: 多会话扩写加叙述不加DM锚点 → DM密度从Phase 4的正常水平骤降
- **修复**: 每次扩写≥1K字符时, 必须同时增加≥2个DM锚点(硬规则, 可在sentinel中检测)
- **影响**: 所有报告的Phase 5组装
- **优先级**: P0(立即实施)

### EVO-SPGI-004: R&D量化标准化
- **问题**: AI讨论定性充分但R&D/Rev这个基本指标缺失
- **修复**: Phase 0 data-prefetch的MCP调用增加R&D字段提取; shared_context.md增加DM-FIN-xxx R&D锚点
- **影响**: 所有科技/AI相关公司
- **优先级**: P2

### EVO-SPGI-005: 去重检查清单
- **问题**: 5个话题各出现3次, 约15-20K冗余(占10-12%)
- **修复**: Phase 5组装检查清单增加"重复话题扫描": grep高频短语(商誉/ROIC/Nash/被动投资/定价权), 如>2处则合并
- **影响**: 所有报告的Phase 5
- **优先级**: P2

## 总结: SPGI v1.0的定位

**一句话**: 金融行业首份Tier 3, 原创洞见密度高(4个可迁移框架), 但体量不足+数据密度低+结构缺口(M7/M6)限制了整体品质。

**v2.0是否值得?**: **不建议**。理由:
1. SPGI不是投资组合核心标的(期望回报+10.3%, 评级稳定性LOW)
2. 缺口可通过补证据(Top 3任务)修复, 无需全文重写
3. v2.0的ROI低于将时间投入FICO反思或下份报告

**下份金融报告(FICO或其他)的改进清单**:
1. Phase 0强制地理分析(EVO-001)
2. 续约率硬数据门控(EVO-002)
3. 扩写DM同步(EVO-003)
4. 目标字符≥250K(SPGI 160K不够)
5. 模块门控目标≥80%(当前67.3%)
