## CQ注册表

### CQ1: AI电力溢价的持续性与隐含增长率
**核心问题**: 当前30-36x P/E vs 10年均值23x = 30-55%溢价。市场隐含ETN需要维持什么增长率多长时间来正当化当前估值？
- **约束类型**: 周期性(P/E倍数均值回归) + 结构性(数据中心电力需求是否为长期secular shift)
- **分析路径**: Reverse DCF → 隐含增长率 → 信念反演 → 历史P/E周期对比
- **关键数据**: FMP ratios历史序列 + 管理层7-9%有机增长指引 + 分析师EPS共识($13.38→$15.28→$17.26→$20.47, FY26-29)
- **初始置信度**: 35% — 估值偏高但AI叙事有实质收入支撑(数据中心订单+200%)，不确定性在持续性
- **承重墙关联**: CI-SEMI-01(AI需求), CI-SEMI-04(数据中心)

### CQ2: Boyd $9.5B收购 — 战略远见还是周期顶部的代价？
**核心问题**: 22.5x EBITDA收购液冷资产。是为下一代数据中心(1MW机架/800VDC)做必要布局，还是在hyperscaler CapEx峰值期支付了不可回收的溢价？
- **约束类型**: 资本配置 + 周期性(液冷需求曲线)
- **分析路径**: 交易估值分析(vs历史工业并购倍数) → Boyd独立财务 → 整合协同估算 → 周期压力测试
- **关键数据**: Boyd $1.5B收入 + EBITDA~$420M(隐含) + 预计2026Q2关闭 + Cooper Industries 2012对标
- **初始置信度**: 40% — 战略逻辑(Grid-to-Chip→Chip-to-Ambient)清晰，但价格风险显著
- **VRT对标**: VRT已完成液冷分析可复用

### CQ3: Mobility分拆的价值释放 vs 集中度风险
**核心问题**: 2027Q1税免分拆后，纯化的"电气+航空"公司($24B/~26%利润率)应获得什么估值？分拆消除了反周期对冲缓冲——集中度风险被定价了吗？
- **约束类型**: 估值(SOTP重构) + 结构性(业务组合纯化)
- **分析路径**: Pre-spin vs Post-spin SOTP → 同业倍数映射 → 集中度溢价/折价测试
- **关键数据**: Mobility ~$3B收入/~13%利润率 | 核心 ~$24B/~26%利润率 | 分拆消除~$3B低利润率拖累
- **初始置信度**: 55% — 分拆逻辑清晰，利润率提升可量化，但市场可能已部分定价
- **DM需求**: 分部间交叉销售/共享成本数据

### CQ4: $15.3B积压的质量与周期韧性
**核心问题**: 积压从2019年$2.8B增至$15.3B(5.5x)，9年指定供应商积压。这是深护城河还是周期繁荣的幻觉？如果hyperscaler放缓，积压可取消性多高？
- **约束类型**: 竞争(护城河质量) + 周期性(积压耐久性)
- **分析路径**: 积压构成分析(合同vs意向) → 历史取消率 → Peer积压对比(ABB/Schneider) → 周期压力测试
- **关键数据**: 积压$15.3B + B2B 1.2x + 数据中心订单+200% + mega项目管线$3T(Eaton赢得~40%)
- **初始置信度**: 50% — 积压规模令人印象深刻但周期性取消风险不可忽视
- **特异性测试**: TS-SEMI-04(周期位置判断), TS-SEMI-05(产能过剩风险)

### CQ5: Smart Money身份分歧信号
**核心问题**: Capital International完全退出$637M + JPM减持24% + MFS减持$569M(传统工业基金撤退) vs Coatue增持Top-10(科技基金涌入)。市场在争论ETN是"工业公司@23x P/E"还是"AI基础设施公司@35x P/E"？
- **约束类型**: 市场定价(身份框架竞争)
- **分析路径**: 机构持仓变动分析 → 隐含身份倍数 → VRT"双重身份估值张力"框架复用
- **关键数据**: 13F数据(详见smart_money_13f.json) + 期权活动(50%看跌 vs 33%看涨)
- **初始置信度**: 45% — 身份重估是真实的分歧，不是噪音
- **VRT对标**: VRT报告中"双重身份估值张力=估值张力冠军"可直接复用

## PW评估确认
- **PW = 3** (传统框架)
- 理由: 成熟工业公司+可预测现金流+明确可比公司(ABB/Schneider/HON/VRT)
- 方法: SOTP + DCF + 相对估值 → 目标价 + 4档评级
- AI/数据中心是增量叙事但不改变公司本质(数据中心占比~28%，非主导)

## 估值方法预选
1. **SOTP** — 按5个板块(post-spin 3个)分别估值
2. **Reverse DCF** — 反推隐含增长率，测试CQ1
3. **相对估值** — vs ABB/Schneider/HON/VRT/GEV同业倍数
4. **DCF** — 10年FCFF模型(需Python验证)
5. **(可选) Boyd协同NPV** — 单独测试CQ2
