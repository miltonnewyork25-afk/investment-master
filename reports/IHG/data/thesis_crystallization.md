## 2. 异常狩猎 (6个信号)

### 异常A: 估值折价层级不连续

全球酒店特许经营巨头估值呈现明显的"阶梯":
```
HLT: P/E 52x, EV/EBITDA 29x  ←── "溢价之王"
MAR: P/E 37x, EV/EBITDA 22x  ←── 规模最大
-------- 断裂层 --------
IHG: P/E 29x, EV/EBITDA 19x  ←── 全球第三
WH:  P/E 19x                 ←── 中端品牌纯度
CHH: P/E 13x                 ←── 规模最小
```

**异常**: IHG的operating margin(23.1%)实际上**高于**HLT(22.4%)和MAR(15.8%), 但P/E却远低于两者。如果估值纯粹反映盈利质量,IHG不应如此折价。

**可能解释**:
1. 规模差距(房间数: MAR 1.75M >> HLT 1.25M >> IHG 1.03M)
2. 增长差距(HLT Rev +7% > MAR +4.2% > IHG +2.7%)
3. 品牌认知差距(奢华品牌深度: MAR > IHG)
4. 管线差距(MAR 596K > HLT 515K > IHG 342K)
5. 上市地折价(LSE主板 + NYSE ADR)
6. 投资者基地差异(美国机构偏好本土上市公司)

### 异常B: 收入口径断裂

```
FY2022: Revenue $3.892B, Gross Margin 28.0%
FY2023: Revenue $3.728B, Gross Margin 52.0%  ←── 毛利率突然翻倍?
FY2024: Revenue $4.923B, Gross Margin 29.6%  ←── 收入暴增32%, 毛利率回落?
FY2025: Revenue $5.189B, Gross Margin 31.9%
```

**假说**: FY2023的高毛利率意味着当年收入以净额(Fee收入)报告;FY2024起system fund以总额并入收入→收入膨胀但利润率被摊薄。这**不是**业务变化,而是**会计呈现**变化。

**含义**: 直接对比FY2023 vs FY2024收入增长率(+32%)会严重误导。真实"可比"增长需剔除口径变化。

### 异常C: FCF/Net Income持续>1.0x

IHG FCF质量异常优秀:
```
FY2021: FCF/NI = 2.20x (疫后D&A>CapEx)
FY2022: FCF/NI = 1.46x
FY2023: FCF/NI = 1.08x
FY2024: FCF/NI = 1.03x
FY2025: FCF/NI = 1.15x
```

5年均值1.38x。这意味着:
- 会计利润保守(D&A > CapEx, 即资产在账面上折旧比实际磨损更快)
- 特许经营模型几乎无实体资产维护需求
- **估值含义**: P/E可能高估了IHG的"贵",P/FCF是更准确的估值锚

### 异常D: 回购超过FCF

```
FY2025: FCF = $870M, 回购+分红 = $1,177M → 缺口$307M
FY2024: FCF = $646M, 回购+分红 = $1,063M → 缺口$417M
FY2023: FCF = $811M, 回购+分红 = $1,035M → 缺口$224M
```

3年累计缺口~$950M, 由新发债填补。结果:
- 总债务: $3.6B(FY2023) → $4.6B(FY2025), +$1.0B
- 净权益: -$2.0B → -$2.7B, 恶化$0.8B

**约束碰撞**: 如果利率上升+RevPAR下降同时发生 → 回购空间收窄 → EPS增长引擎之一熄火。这是管理层12-15% CAGR指引中最脆弱的假设。

### 异常E: 美国RevPAR背离

```
全球RevPAR: +1.8% (FY2025)
美国RevPAR: -1.6% (FY2025)  ←── 最大市场负增长
大中华区:   -1.6%            ←── 第二弱势区域
2026指引:   +0.6% - 0.9%    ←── 历史低位
```

美国占IHG收入~55%。美国RevPAR负增长意味着:
1. 酒店供给增速>需求增速(新建酒店多)
2. 或者IHG美国品牌竞争力相对弱化
3. 2026展望仅+0.6%意味着管理层也不乐观

### 异常F: HLT杠杆>IHG但估值>IHG

```
HLT: Net Debt/EBITDA = 5.1x, P/E = 52x
IHG: Net Debt/EBITDA = 2.6x, P/E = 29x
```

**悖论**: HLT杠杆几乎是IHG的2倍,但P/E是IHG的1.8倍。正常情况下,高杠杆应导致更低估值(更高风险溢价)。

**解释**: 市场对HLT的信任极高 — 相信HLT的增长能力和现金流稳定性足以支撑高杠杆。这意味着**市场对IHG的不信任不仅是基本面**,而是**品牌信任度**差距。

## 3. 约束碰撞分析

### 碰撞1: 回购引擎 × 利率上升

管理层EPS CAGR 12-15%分解:
```
系统增长: 4-5% (房间增长)
RevPAR:   1-2% (价格+入住率)
费率提升: 2-3% (信用卡/品牌住宅)
回购:     5-7% (股份减少)
= 合计: 12-17%
```

但**回购5-7%**依赖于:
- FCF稳定 ($800-900M)
- 借贷成本稳定 (目前~4.3%利率)
- 没有重大CapEx需求

如果利率上升100bps → 新借贷成本+$46M/年 → 回购空间缩小$46M → 影响回购收益率~0.2pp

如果RevPAR下降2% → EBITDA可能下降$80-100M → FCF下降类似金额 → 回购进一步缩小

**两者同时发生**: 回购贡献从5-7%降至3-4%, EPS CAGR从12-15%降至9-12%。

### 碰撞2: RevPAR下降 × 系统增长放缓

如果RevPAR持续负增长, 加盟商ROI下降 → 新加盟意愿降低 → 管线转化率下降 → 系统增长从4.7%降至3-3.5%。

**历史验证**:
- 2008-2009: RevPAR暴跌20-30%, 系统增长接近停滞
- 2020: RevPAR暴跌50%+, 系统增长为负(关店>开店)
- **结论**: 这两个引擎高度相关,不独立

### 碰撞3: 估值折价 × 回购效率

IHG以P/E 29x回购 vs HLT以P/E 52x回购:
- IHG $1回购 = 消除$29估值的EPS稀释
- HLT $1回购 = 消除$52估值的EPS稀释
- **IHG的回购效率是HLT的1.8倍**(同样的钱减少更多的EPS稀释)

**反直觉含义**: 如果IHG确实被低估, 当前回购是最优资本配置。但如果IHG折价是合理的, 回购只是在维持现状而非创造价值。

## 4. 信念反演 (Reverse DCF 框架)

### 市场隐含假设反推

当前: EPS $4.87, 股价 $143.06, P/E 29.4x

如果5年后P/E仍为29x (假设估值不变):
```
需要EPS CAGR约X%才能支撑Y%年化回报:

目标年化回报 | 需要EPS CAGR | 2030E EPS
10%         | ~8%          | $7.15
12%         | ~10%         | $7.85
15%         | ~13%         | $8.89

分析师共识: 2030E EPS $8.49 → CAGR ~11.8% → 隐含年化回报~14%

如果P/E从29x收敛到35x (部分折价修复):
  2030E EPS $8.49 × P/E 35x = $297 → 5年年化回报~16%

如果P/E从29x收缩到25x (折价扩大):
  2030E EPS $8.49 × P/E 25x = $212 → 5年年化回报~8%
```

### 市场隐含的信念集

以当前P/E 29x倒推, 市场隐含:
1. **RevPAR增长不超过2%** (vs管理层指引2-3%)
2. **系统增长维持3-4%** (vs实际4.7%加速)
3. **估值折价不会修复** (永久性折价)
4. **利率不会显著下降** (维持高借贷成本)

### 最脆弱信念

**信念#3(永久性折价)是最脆弱的**:
- 如果IHG特许经济学持续改善(信用卡费翻倍, 品牌住宅增长)
- 如果IHG管线加速接近HLT/MAR比例
- 如果市场重新评估英国上市ADR的折价
→ P/E从29x向35x收敛 = 额外20%上行空间

## 5. 非共识假说正式登记

### NH-1: "IHG的43%折价中, 15-20pp来自制度性因素而非基本面"
- **检验**: 对比同类英国ADR(BP, AZN, SHEL, LSEG)在美国市场的估值折价
- **影响**: 如果成立, IHG"真实"基本面折价仅23-28%, 接近合理估值

### NH-2: "IHG的EPS增长4引擎实际上只有1个底层驱动 — 宏观旅游需求"
- **检验**: 2008/2020回测 — 4引擎是否同时失效
- **影响**: 如果成立, 管理层12-15% CAGR指引的风险远高于呈现

### NH-3: "IHG的特许经营纯度正在非线性提升, 3年后盈利质量接近HLT"
- **检验**: 信用卡费/品牌住宅收入增速 + 自有酒店出售进度
- **影响**: 如果成立, 当前P/E 29x显著低估3年后的盈利质量

### NH-4: "全球RevPAR已进入结构性减速, 2014-2019周期不会重演"
- **检验**: 全球酒店管线/GDP增速比 + Airbnb替代效应量化
- **影响**: 如果成立, 管理层RevPAR+2%的假设过于乐观
