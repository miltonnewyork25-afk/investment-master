# IHG Literature Reconnaissance Memo
> Phase -0.5 | 5路WebSearch + MCP数据 | 2026-02-27

## D1: 深度分析覆盖

**核心发现**: IHG FY2025业绩强劲 — 调整后收入$2.47B(+6.8%), 净系统增长4.7%(连续4年加速), 443家新酒店开业(创纪录), EPS增长16%。管理层指引中期调整EPS复合增长12-15%。

**分析师评级**: 2025年底以来2次上调至Buy(Jefferies/Berenberg), 多个目标价上调。Deutsche Bank维持Hold。共识:偏正面但估值争议仍存。

**关键数据**: 信用卡费收入自2023翻倍, 目标2028年三倍。品牌住宅(Branded Residences)是新增长引擎。

## D2: 熊案/风险

**RevPAR减速**: 美国RevPAR Q3-2025同比-1.6%, 全球仅+1.8%。大中华区-1.6%。2026展望: 全球RevPAR增长预期仅+0.6%-0.9%。

**利息费用上升**: 2026年$230-250M(vs 2025年$200M), 因更高平均净债务和借贷成本。

**供给超需求**: 2026年酒店供给增速可能超需求。低价酒店承压更大(通胀挤压低收入消费者)。

**负权益**: 总权益-$2.74B, 激进回购侵蚀股东权益至负值。

## D3: 竞争对比

**规模差距**: MAR 1,754K rooms >> HLT 1,251K >> IHG 1,026K。管线: MAR 596K >> HLT 515K >> IHG 342K(IHG为MAR的57%)。

**估值层级**: HLT P/E 51.8x >> MAR 36.9x >> IHG 29.4x >> WH 19.4x。IHG折价显著: vs HLT折价43%, vs MAR折价20%。

**RevPAR表现**: MAR +2.0% > IHG全球+1.8%, 但IHG美国-1.6%显著弱于MAR美国+0.7%。

**资产轻转型**: 三巨头都在推进franchise-heavy模型, IHG转型进度介于MAR(较早)和HLT(最彻底)之间。

## D4: 管理层/行业专家

**CEO Elie Maalouf**: 2023年9月接任CEO, 前IHG Americas负责人。推动品牌简化+技术投资+中端市场扩张(avid/atwell)。

**战略重心**: (1)费收入增长(信用卡/品牌住宅/忠诚度) (2)中端市场加速(Holiday Inn Express主力) (3)大中华区恢复 (4)资本回报($1.2B/年回购+分红)。

**行业结构变化**: 后疫情时代出现"分布式需求"结构性转变 — 从集中/季节性需求转向分散/数据驱动市场, 二线/新兴目的地跑赢传统门户城市。

## D5: 估值/模型参考

**IHG特许经营经济学**: 特许费约为酒店收入的5-7%, 品牌方边际利润率~60%。IHG ROIC 544%(因投入资本极低)。这是典型的"负权益高回报"模型。

**KO类比适用**: IHG特许经营层=KO浓缩液层(高倍数15-20x); IHG自有/管理酒店层=KO成品层(低倍数8-12x)。SOTP需要分层估值。

**FCF质量优异**: FCF/净利润=1.12x, 资本支出/折旧=0.19x(极低资本密度), 回购收益率7.61%。

**RevPAR可持续性是估值核心**: 行业2026展望仅+0.6%, 但IHG管理层指引中期EPS 12-15% CAGR → 隐含增长假设 = 系统增长(4-5%) + 费率提升 + 回购(7-8%)。

## 关键异常/信号

1. **估值折价谜题**: IHG P/E 29.4x vs HLT 51.8x(折价43%) — HLT更资产轻? 更高增速? 还是市场非理性?
2. **收入口径突变**: FY2023 $3.7B → FY2024 $4.9B (+32%) → FY2025 $5.2B (+5.4%) — 2024年大幅跳升原因需查明(收购?会计变更?system fund整合?)
3. **毛利率波动**: 2023年52% → 2024年30% → 2025年32% — 与收入口径突变相关, 可能是system fund费用的分类方式变化
4. **负权益+激进回购**: 2025年回购收益率7.61%, 同时净权益-$2.74B — 杠杆回购策略的可持续性?
5. **RevPAR分化**: 全球+1.8%但美国-1.6% — IHG在美国(最大市场)的竞争力问题?
