## 9. 非共识假说

### H1: ADR系统性折价假说 (主假说)
**共识**: IHG折价反映品牌/规模劣势
**反假说**: 折价部分来自英国上市ADR的制度性因素 — 流动性折价+分析师覆盖差距+指数权重低+投资者基地差异
**检验方法**: 对比IHG在LSE vs NYSE的成交量/估值, 对比其他英国ADR(BP, AZN, SHEL)的折价模式

### H2: 特许经营纯度低估假说
**共识**: IHG盈利质量与HLT类似
**反假说**: IHG特许经营收入占比正在快速提升(信用卡费翻倍, 品牌住宅增长), 3-5年后盈利质量将更接近HLT → 当前估值未price in转型进度
**检验方法**: 分拆特许层vs物业层利润率趋势, 对比HLT特许比重演进

### H3: RevPAR已过峰值假说
**共识**: RevPAR温和增长1-2%
**反假说**: 美国RevPAR -1.6%不是暂时的, 是供给超需求的开始 → 2026-2027 RevPAR可能持续负增长
**检验方法**: 全球酒店管线增速 vs 旅游需求增速, 历史RevPAR周期

```
IHG商业模式 = 品牌授权 + 管理协议 + 忠诚度系统 + 信用卡费

收入结构 (估计, 需Phase 1确认):
├── 特许费/管理费 (~$1.6B, ~30% of adjusted rev)
├── System Fund Revenue (~$2.5B, pass-through)

├── 信用卡/忠诚度 (~$300M+, 快速增长)
└── 其他 (~$400M)

利润结构:
├── 特许层: EBIT margin ~55-65% (类KO浓缩液)
├── System Fund: 名义break-even (实际有品牌投资价值)
├── 自有酒店: EBIT margin ~15-25% (低利润)
└── 综合: EBIT margin ~23% (被system fund和自有酒店拉低)

SOTP含义:
├── 特许层 → 15-20x EBITDA (类MAR/HLT fee-based)
├── 自有酒店层 → 8-12x EBITDA (类资产重酒店)
└── 混合倍数取决于特许占比演进
```
