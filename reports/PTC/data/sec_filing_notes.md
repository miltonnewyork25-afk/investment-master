### 6. ARR定义与方法论

**PTC的ARR定义 (Annual Run Rate, 非Annual Recurring Revenue)**:

> ARR = 截至报告期末，所有**活跃**订阅软件、SaaS、托管及支持合同的**年化价值**

**关键方法论细节**:
1. **活跃合同认定**: 从产品/服务合同期限开始日(start date)计入，到使用权终止日(expiration date)截止。即使合同已签署但尚未开始，不计入ARR
2. **阶梯价格处理**: 对于合同价值随时间变化的合同，ARR只包含计算日期时被视为"活跃"的组成部分的年化价值，**不包含未来已承诺但尚未生效的价格增长**
3. **与ASC 606收入的区别**: ARR**不是**年化经常性收入，不基于已确认收入或未赚收入计算。不受ASC 606收入确认时点(特别是on-premises订阅许可一次性确认)的影响
4. **这意味着**: ARR是一个前瞻性运营指标，比GAAP收入更平滑，但可能低估实际合同价值(因为不含deferred ARR)

**FY2025 ARR**: $2,478M (报告值, +10% YoY) / $2,446M (恒定汇率, +8.5% YoY)

## 三、API不易获取的关键洞察

### 1. 单一运营分部 — 分析需自行推算
PTC按单一运营分部报告，不披露CAD/PLM/SLM/ALM各自的利润率。Q3 FY2025数据显示PLM:CAD收入比约63:37。分析师需通过季度趋势自行推算各产品组增速。

### 2. ARR ≠ 收入 — 理解偏差来源
PTC的ARR是"run rate"(运行速率)而非年化确认收入。关键偏差:
- On-premises订阅许可在ASC 606下可能一次性确认大部分收入 → GAAP收入>ARR暗示值
- Deferred ARR(已签约未开始)不计入ARR → ARR可能低估合同总价值
- 汇率影响: 报告ARR vs 恒定汇率ARR差异达$54M (FY2025: $2,478M vs $2,446M)

### 3. ServiceMax整合风险
- 收购价$1.45B，是PTC史上最大收购
- 持续churn = 客户对SLM产品粘性不如PLM/CAD
- 管理层强调cross-sell策略(Windchill→ServiceMax)，但效果待验证
- 若churn持续，商誉减值风险需关注

### 4. IoT剥离后的"纯净"PTC
- 剥离Kepware+ThingWorx后，PTC聚焦CAD+PLM+ALM+SLM四大产品组
- 核心ARR(剔除IoT): $2,341M, 增速9.0%(优于含IoT的8.4%)
- 说明IoT业务拖累了整体增速
- 剥离收益$365M全部用于回购，对EPS增厚效果显著

### 5. 债务已大幅降杠杆
- 净债务从~$1,566M(FY2024) → ~$1,013M(FY2025) → 进一步下降
- Net Debt/EBITDA约0.8x-1.0x，非常健康
- 2028年集中到期风险: $500M notes + $301M revolver需再融资
