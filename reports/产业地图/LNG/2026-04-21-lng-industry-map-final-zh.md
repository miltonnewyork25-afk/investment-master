# 2026-04-21 LNG 产业地图：四层系统图、模块母表、三榜决策清单与上游卡点追溯

副标题：  
一份面向投资者的 LNG 产业研究稿，覆盖上游气源、液化、运输、接收、回流商业化，重点追溯上游真正卡点——包括往往被市场忽视的低温换热设备、膜式液货舱技术、液化工艺许可、9% 镍钢、主冷剂压缩机等隐藏 pick-and-shovel 机会。

## 执行摘要：如果只有三页时间

LNG 不是一个"天然气生意"，它是一张由**长期合同 + 液化产能 + 船舶 + 接收终端 + 上游气源**组成的重资本基础设施闭环。当前全球 LNG 正在经历 2023–2028 年这一轮新产能大规模投产期——美国墨西哥湾、卡塔尔 North Field East/South、莫桑比克重启，预计 2028 年前全球 LNG 供应增加约 50%。

### 一、现在最该看哪三层

1. **液化工艺和冷箱设备层**（不是液化公司本身）——代表：`GTLS`（Chart Industries 冷箱/储罐）、`BKR`（Baker Hughes 主冷剂压缩机）、`APD`（Air Products 液化工艺许可）。这些公司在每个新 LNG 项目中都"过路收费"，不承担商品价格风险。
2. **韩国大型 LNG 船造船厂 + GTT 膜技术层**——代表：`329180.KS`（HD 现代重工）、`010140.KS`（三星重工）、`042660.KS`（韩华海洋）、`GTT.PA`（GTT，膜式液货舱技术近乎独家）。每艘新船都要向 GTT 付约船价 5% 的专利许可费——典型隐藏 pick-and-shovel。
3. **美国 LNG 托管模式出口商**——代表：`LNG`（Cheniere）、`VG`（Venture Global）。长期合同 take-or-pay 结构，类似收过路费的基础设施资产。

### 二、现在最不该追的三层

1. **国际综合 E&P 巨头的 LNG 业务**——`XOM / CVX / SHEL / BP / TTE` 的 LNG 利润被综合业务稀释，很难享受到 LNG 纯表达的估值溢价。
2. **二线美国 LNG 开发商**——`TELL`（Tellurian 已被 Woodside 收购）、`NEXT`（NextDecade）这类未完成 FID 或 FID 时间表脆弱的名字，高估值叠加执行风险。
3. **高 beta 纯 LNG 运输船现货表达**——`FLNG / CLCO` 在运费高位时看起来便宜，但长期 TCE 会随新船交付压回均值，交易层而非核心。

### 四、三条最关键触发器

1. **FERC 或 DOE 再次冻结美国 LNG 非 FTA 出口许可** — 切断新项目 FID 管道，直接冲击 `GTLS / BKR / APD / LNG / VG` 的增长曲线。
2. **卡塔尔 North Field South 首船交付延迟或产量指引下调** — 改变 2027–2029 供给曲线，影响 LNG 全球定价与 TCE 预期。
3. **中国 / 欧洲 LNG 年度采购合同签署规模显著低于预期** — 预算源萎缩，整条链重定价。

### 五、三个最可能打脸的风险

1. **2027–2028 年全球 LNG 产能集中投产叠加欧洲需求见顶** — 现货 LNG 价格崩塌会把 `FLNG / CLCO` 等高 beta 表达先去杠杆；长期合同型 `LNG / VG` 受影响较小但估值倍数会被压缩。
2. **中国 Hudong-Zhonghua 国产膜式 LNG 船加速量产** — 削弱 GTT 专利许可垄断，也分流韩国船厂订单；GTT 目前单一路径估值可能被重估。
3. **美国 Haynesville / Permian 相关天然气价格长期低迷（Henry Hub <$2.50）** — 上游 E&P 纪律松动，利润转移到 LNG 出口商和气体基础设施。

## 零、阅读指南：这份报告如何使用

### 0.1 LNG 不是"天然气生意"，而是重资本基础设施闭环

LNG 产业不应被看成"上游气井 → 液化厂 → 船 → 下游用户"的横向清单。  
更准确的理解是：**它是一张由长期合同预算、液化产能、运输槽位、接收终端与上游气源组成的重资本基础设施闭环。**

这张网络可以拆成四层：

1. **结构层** — 系统里到底有什么关键事物（预算源、液化能力、运输能力、接收能力、气源）
2. **约束层** — 什么在真正限制扩张（FID 周期、造船槽位、长协合同、电力接入、膜技术许可）
3. **时钟层** — 每个模块按什么节奏兑现（FID→投产 5-10 年；造船 3-5 年；长协 15-20 年；现货即时）
4. **定价层** — 哪些适合长期研究，哪些适合交易观察

### 0.2 LNG 的四层系统串联关系

- 结构层回答"里面有什么" → 约束层回答"什么卡住它" → 时钟层回答"什么时候兑现" → 定价层回答"现在该拿哪一块"

### 0.3 四层系统与正文各章对应

- **结构层** — 主链全图 / 三榜决策清单 / 中国链条
- **约束层** — 液化 FID 约束 / 造船槽位约束 / 膜技术许可约束 / 利润分配
- **时钟层** — FID 时钟 / 造船时钟 / 长协时钟 / 现货价格时钟
- **定价层** — 拥挤度与持有人脆弱性 / 估值框架分层 / 去杠杆压力 / 回调动作

## 二、先给结论：LNG 不是一条线，而是三层结构 + 一层上游卡点

### 1. 最核心的"液化和造船主链"

这一层决定：
- 全球 LNG 供给总量
- 运输能力能否匹配
- 下游能否接收

代表：
- 液化项目开发商：`LNG`（Cheniere）、`VG`（Venture Global）、`QatarEnergy`（非公开）
- 液化工艺许可 + 冷箱设备：`APD`（Air Products）、`GTLS`（Chart Industries）、`Linde`（LIN）

- 膜式液货舱技术：`GTT.PA`（GTT）

### 2. 第一圈扩散链

- 上游气源 E&P：`EQT`（Expand Energy）、`RRC`（Range Resources）、`AR`（Antero Resources）、`COG`（Coterra）
- 管道与中游：`WMB`（Williams）、`KMI`（Kinder Morgan）、`EPD`（Enterprise Products）、`ET`（Energy Transfer）、`OKE`（ONEOK）
- LNG 运输船：`FLNG`（Flex LNG）、`CLCO`（Cool Company）、`GLNG`（Golar LNG）、`EE`（Excelerate Energy）

### 3. 外围商业化层

- LNG 贸易与交易：`JERA`（日本，未独立上市）、`MUTOH`等日本综合商社（`8058.T` 三菱商事、`8031.T` 三井物产、`8001.T` 伊藤忠、`1605.T` INPEX）
- 下游燃气分销：各国燃气公用事业

### 4.（新增）上游真正卡点层

这一层在传统 LNG 报告里经常被忽视，但往往是利润和议价权最深的地方：

- **特殊超合金**：主冷剂压缩机热端部件 — `Precision Castparts`（`BRK.B` 子公司）、`Haynes International`、`Allegheny Technologies`（ATI）
- **大口径 LNG 管线**：`U.S. Steel`（X）、`Nippon Steel`、`TMK`
- **大型船用慢速柴油机 / LNG 双燃料发动机**：`MAN Energy Solutions`（Volkswagen 子）、`Wärtsilä`（WRT1V.HE）

## 三、怎么判断一个环节是不是"核心"

对读者来说，记住三条：

### 1. 它是不是不可绕开的关键环节

例如：
- 液化工艺许可
- 膜式液货舱技术
- 主冷剂压缩机
- 9% 镍钢
- 低温冷箱

### 2. 它是不是"每个新项目都要付过路费"的节点

- `GTT.PA` — 每艘 LNG 船付 5% 许可费
- `APD` — 每个新液化装置付工艺许可费
- `GTLS` — 几乎每个新项目都采购冷箱和低温储罐
- `BKR` — 主冷剂压缩机市占超 50%

这些"过路费"型节点不承担商品价格风险，是 LNG 扩张周期最干净的表达。

### 3. 它的供给是不是难以快速补上

- 韩国造船厂 LNG 船位（2026-2028 基本订满）
- 9% 镍钢高等级板材（全球仅三家具备规模化供货能力）
- GTT 膜技术（中国 Hudong-Zhonghua 正在追赶，但仍有 5-10 年差距）
- 大型低温换热器（Chart Industries 约 24 个月 lead time）

## 二点五、合同与交付架构：决定谁是 toll road、谁是周期放大器

在 LNG 里，真正决定一个名字"是收过路费还是扛商品风险"的，不是它在产业链哪个位置，而是**它签的合同和负责交付到哪一环**。这一章先把合同架构讲清楚，后面的估值和榜单才能站得住。

### 2.5.1 LNG 合同四维分类

LNG 合同至少要从四个维度区分——改动任一维度，利润归属就会完全不同。

| 维度 | 分类 | 含义 | 谁承担风险 |
|---|---|---|---|
| **交付条款** | FOB（卖方装船完即交货） | 卖方只对船前负责 | 买方承担运输 + 卸货风险 |
|  | DES / DAT / DAP（卖方负责送到接收站） | 卖方管到卸货港 | 卖方承担运输风险 |
| **定价机制** | Henry Hub linked | 价格 = HH × 115% + 液化费 | 买方扛 HH 波动；卖方扛液化成本 |
|  | Brent linked（13-14% 斜率） | 价格 = Brent × 系数 + 常数 | 买方扛油价；卖方享油气挂钩 |
|  | JKM / TTF spot | 实时现货 | 双方共担，贸易商套利空间大 |
|  | Hybrid | 部分 HH + 部分 Brent + 部分 spot | 风险分段 |
| **合同承诺** | Take-or-pay | 买方不取也要付钱（通常覆盖液化 CapEx） | 卖方拿容量租金，零产量风险 |
|  | Merchant（现货） | 随行就市 | 卖方完全扛价格 + 产量风险 |
|  | Strip sales / 混合 | 长协 + 现货混合 | 分层 |
| **Destination flexibility** | 目的地锁定（老式长协） | 买方不能转卖 | 买方灵活性低，卖方控盘 |
|  | Destination free（US 新合同普遍） | 买方可全球套利 | 买方灵活，交易利润留买方 |

### 2.5.2 典型长协结构解读

- **卡塔尔老式长协**（典型到日韩）：**DES + Brent linked + take-or-pay + 目的地锁定**——卖方(QatarEnergy)几乎零风险，买方扛运输 + 油价 + 不灵活，价差收益全归卖方。
- **美国 Cheniere/VG 新型合同**：**FOB + Henry Hub×115% + take-or-pay 液化费 + destination free**——卖方只收液化费(tolling)，买方扛 HH 波动 + 运输 + 全球套利权归买方。**这是典型的"toll road"结构**。
- **欧洲/南美 Hybrid**：FOB + JKM-linked merchant 现货——全球套利型贸易商(`SHEL / TTE / BP` 交易部门 + 日本商社)的利润池。

### 2.5.3 合同结构 → 公司利润性质的映射

这是本章最重要的一张表——它决定了为什么 `LNG / VG` 不是"天然气价格股"、`FLNG` 只是"交易层"、`GTT.PA` 是"完美 toll road"：

| 公司 | 合同位置 | 商品价格风险 | Toll road 属性 | 真实利润性质 |
|---|---|---|---|---|
| `LNG`（Cheniere） | FOB + HH×115% + take-or-pay 液化费 | **转嫁给 off-taker** | **强** | 液化费 toll road,基础设施资产 |
| `VG`（Venture Global） | 同 Cheniere + 早期 merchant 套利 | 长协后转嫁;早期自留 | **中强**(被长协纠纷削弱) | 长协 toll + 争议中的自营套利 |
| `QatarEnergy` | DES + Brent linked + 目的地锁定 | 卖方自留(但有 Brent 对冲) | 中 | 油气挂钩的综合套利 |
| `GTT.PA` | 每艘新船 5% 专利许可费 | **零** | **极强** | **纯 IP 过路费,跨周期稳定** |
| `APD` | 工艺许可 + 冷箱设备一次性 | **零** | 强（但偏 CapEx 周期） | CapEx 周期受益的 toll |
| `GTLS / BKR` | 设备一次性 + 维护 | **零** | 中强 | 设备 CapEx 放大器 |
| `FLNG / CLCO` | LNG 船 TCE 现货 / 短期租约 | **高**（TCE 波动大） | 弱 | **典型周期放大器** |
| `EQT / RRC` | 井口 HH 敞口 | **极高** | 无 | 上游 E&P 商品 beta |
| `SHEL / TTE / BP` | 一体化,含贸易部门 | 复杂(部分对冲 + 部分套利) | 中（贸易部门） | 综合商 + 套利收益 |
| `8058.T / 8031.T`（日本商社） | 长协持有 + 现货套利 | 中(部分对冲) | 中 | 资产 + 贸易复合 |
| `NFE` | FSRU + 分布式 LNG 分销 | 中高 | 弱 | 执行 + 金融复合 |

### 2.5.4 一句话带走

**在 LNG 里，合同结构比产业位置更决定利润性质**。两家都在"液化"环节，take-or-pay FOB 和 merchant DES 的利润性质是完全两种生意。判断一家 LNG 公司前，先看它的合同结构——而不是先看它在哪个模块。

## 四点六、模块证据卡

### 4.6.1 液化工艺许可（`APD`）

- **支持 1**：AP-C3MR 与 AP-X 工艺在全球大型液化装置中市占约 80%，包括卡塔尔 North Field East/South、俄罗斯 Yamal / Arctic LNG、澳大利亚 Gorgon/Wheatstone 等。
- **支持 2**：APD 同时提供冷箱设备，形成"工艺 + 核心设备"双重卡位。
- **支持 3**：APD 长期合同模式 + 稳定现金流 + 高 ROIC，是 LNG 受益股中财务韧性最高的一家。
- **削弱 1**：Cheniere 自研 Cascade 工艺用于自家 Sabine Pass / Corpus Christi，绕开 APD；Linde 的 MFC 工艺也在部分新项目中被选用。
- **削弱 2**：APD 业务过半数来自工业气体，LNG 暴露被稀释，纯度上不如 GTLS / BKR。
- **关键图**：预算—订单—收入—现金瀑布图（APD 处于液化 CapEx 的第一级受益层）。
- **失效触发**：AP-C3MR / AP-X 在新项目中市占跌破 50%。
- **最优表达**：`APD`（全球 LNG 液化工艺最稳的长期持有标的之一）。
- **最危险错法**：把 APD 当纯 LNG 表达——它本质是工业气体公司，LNG 业务占比约 10-15%。

### 4.6.2 低温冷箱与储罐（`GTLS`）

- **支持 1**：Chart Industries 的 brazed aluminum 冷箱与低温储罐在全球 LNG 项目中市占极高，订单 backlog 持续攀升。
- **支持 2**：额外暴露于氢能、碳捕集、工业气体，LNG 只是其增长曲线之一。
- **支持 3**：2024-2025 订单增长显著，管理层多次上调 FY 指引。
- **削弱 1**：竞争者包括 Linde Engineering 和 APD，且 GTLS 毛利率历史波动较大。
- **削弱 2**：GTLS 并购 Howden 后资本结构偏重，债务水平需要持续盯。
- **关键图**：利润池 × 供给刚性二维图（GTLS 处于右上象限：利润池深 + 供给弹性低）。
- **失效触发**：订单环比下降 >20% 或 Howden 并购整合出现重大执行问题。
- **最优表达**：`GTLS`（LNG + 氢能双向受益）。
- **最危险错法**：把 GTLS 当纯 LNG beta——氢能和工业气体组合意义更大。

### 4.6.3 主冷剂压缩机（`BKR`）

- **支持 1**：Baker Hughes 的 LNG 压缩机业务（继承自 GE Oil & Gas）全球市占约 60-70%，是主流新项目必选供应商之一。
- **支持 2**：LNG 设备订单披露透明，backlog 可见性高。
- **支持 3**：配合大型 LNG 涡轮（LM6000、LMS100）形成系统级卡位，而非单一部件供应。
- **削弱 1**：Siemens Energy 的 SGT-750 与 MHI 的涡轮也在部分项目中中标，非完全独家。
- **削弱 2**：BKR 主营业务中 LNG 仅为 OFS 业务中的一个板块，纯度被稀释。
- **关键图**：预算—订单—收入—现金瀑布图。
- **失效触发**：BKR 季度 LNG 设备订单同比转负。
- **最优表达**：`BKR`（综合 OFS + LNG 设备双引擎）。
- **最危险错法**：以为 BKR 只是个油服公司——它的 LNG 设备业务是纯 CapEx 型高毛利段，值得拆分看。

### 4.6.4 膜式液货舱技术（`GTT.PA`）

- **支持 1**：GTT 持有 Mark III 与 NO96 两套膜式液货舱专利系统，全球 95%+ 新建 LNG 船使用这两套之一。
- **支持 2**：每艘新船支付约船价 5% 的专利许可费（约 $10-12M/艘），完全"过路收费"模式，零 CapEx、零生产风险。
- **支持 3**：韩国大三造船厂、中国 Hudong-Zhonghua、日本川崎重工都是 GTT 的被许可方。
- **削弱 1**：中国 Hudong-Zhonghua 正在推进国产膜式液货舱（LNT A-Box），如果量产成熟，10 年内可能分流 30-40% 订单。
- **削弱 2**：GTT 单一产品线、单一业务模式，估值波动大——若新船订单周期转弱，股价先行回调。
- **关键图**：利润池 × 供给刚性二维图（GTT 处于极右上：利润池极深 + 供给完全刚性，是最典型的隐藏 pick-and-shovel）。
- **失效触发**：中国 LNG 船订单使用 LNT A-Box 超过 10 艘。
- **最优表达**：`GTT.PA`（欧洲小盘股，约 €4-5B 市值，纯 LNG 运输船 beta + 零 CapEx）。
- **最危险错法**：把 GTT 当"科技公司"——它更像"LNG 船每艘过路费收费员"，估值应按 LNG 船新建周期而非科技周期。

### 4.6.5 LNG 船造船（韩国大三）

- **支持 1**：`329180.KS` / `010140.KS` / `042660.KS` 三家合计承接全球 75-80% 新建 LNG 船订单；2026-2028 槽位基本订满。
- **支持 2**：LNG 船单价从 2020 年 $180M 上升至 2024 年 $260M+，毛利率正在修复。
- **支持 3**：韩国造船厂在双燃料 / 氨动力等新技术上同时领先，防御中国追赶的护城河仍在扩大。
- **削弱 1**：中国 Hudong-Zhonghua 国产膜式 LNG 船 2023 年起交付加速，2026-2028 可能占全球 25-30%。
- **削弱 2**：韩国造船厂历史上 ROE 波动大，估值拉升后需要谨防盈利周期反转。
- **关键图**：模块周期钟（韩国造船厂处于经营前中段 × 定价中高）。
- **失效触发**：新 LNG 船订单同比下降 >30% 或中国市占跃升至 40%+。
- **最优表达**：`329180.KS`（HD 现代重工，业务最综合）+ `010140.KS`（三星重工，LNG 纯度最高）。
- **最危险错法**：把韩国造船厂当纯 LNG beta——它们的订单组合还包括大型集装箱船、海工、军舰，周期共振不完全。

### 4.6.6 美国 LNG 出口商（`LNG / VG`）

- **支持 1**：Cheniere 运营 Sabine Pass + Corpus Christi，总产能约 45 MTPA，长期合同 take-or-pay 结构，现金流稳。
- **支持 2**：Venture Global 的 Calcasieu Pass + Plaquemines 以模块化建设方式加速投产，资本效率领先。
- **支持 3**：美国本土 Henry Hub 天然气成本结构 + 液化费差异明显，出口竞争力全球最强。
- **削弱 1**：DOE 2024 年 1 月暂停非 FTA 出口许可，虽 2024 年年底解除，但监管风险仍在。
- **削弱 2**：Venture Global 近期与长期合同买家（BP、Shell 等）产生商业纠纷，商誉与信任度受损。
- **关键图**：模块周期钟（Cheniere 处于稳态兑现期；VG 处于扩产高速期）。
- **失效触发**：DOE 再次冻结非 FTA 许可，或任一长期合同买家正式违约退出。
- **最优表达**：`LNG`（最稳）+ `VG`（高弹性但高执行风险）。
- **最危险错法**：把美国 LNG 出口商当"天然气价格敏感股"——它们本质是 toll 基础设施，价格风险转嫁给 off-takers。

### 4.6.7 9% 镍钢（隐藏卡点）

- **支持 1**：LNG 储罐与 LNG 船液货舱必须使用 9% Ni 钢（-162°C 低温强度要求）。全球具备规模化 9% Ni 钢生产能力的企业仅约 3-4 家：`Nippon Steel`、`POSCO`、`Industeel`（ArcelorMittal 子）、部分 `JFE Steel`。
- **支持 2**：每艘 LNG 船约需 1,000-1,200 吨 9% Ni 钢，2025-2028 全球 LNG 船交付约 400 艘，9% Ni 钢需求结构性增长。
- **支持 3**：陆上液化储罐（160,000 立方米级）同样依赖 9% Ni 钢，新建 LNG 项目直接拉动。
- **削弱 1**：9% Ni 钢只是综合钢铁企业的细分产品，纯度稀释严重，投资 Nippon Steel 或 POSCO 需接受整体钢铁周期暴露。
- **削弱 2**：部分 LNG 储罐开始采用膜式结构，可能绕开传统 9% Ni 钢大口径罐体需求。
- **关键图**：上游卡点追溯图（见四点七）。
- **失效触发**：LNG 项目 FID 节奏显著放缓，或膜式储罐替代率提升。
- **最优表达**：**`5401.T`（Nippon Steel，日本高端钢）+ `005490.KS`（POSCO，韩国高端钢）** — 两家合计约 60%+ 全球 9% Ni 钢产能。
- **最危险错法**：以为 9% Ni 钢业务等同于整家钢铁公司 — 它只是细分产品，影响体量有限，需要关注公司披露 LNG 相关板材占比。

- **事物节点**：LNG 船大型低温液货舱的膜式建造技术（替代 Moss 球型）
- **上游一跳**：只需 GTT 总部的工艺 know-how + 专利保护 + 被许可方培训体系
- **跨行业等价节点**：无（LNG 专用）
- **为什么是真正卡点**：
  - 下游（韩国大三 + 中国 Hudong + 日本川崎）无法绕开 — 替代方案 Moss 球型效率低 20-30%，基本被淘汰
  - 替代方案极少且慢 — 中国 LNT A-Box 仍在早期商业化
  - 资格认证周期长 — 任何新膜技术需要经过 ABS/DNV/BV 等船级社长期验证
  - 供给完全不会扩张（是专利而非产能）
  - 控制良率 / 可靠性 / 合规 — 直接关系到低温密封性与运输安全
  - 价值捕获完全保持在 GTT — 5% 船价永续许可费
- **映射公开表达**：
  - 最纯表达：`GTT.PA`（欧洲 Euronext，约 €4-5B 市值）
  - 高质量复利：`GTT.PA`（同一家）
  - 周期弹性：`GTT.PA`
  - 中国表达：无直接上市（Hudong-Zhonghua 属于中船集团国企）
  - **隐藏 pick-and-shovel**：`GTT.PA` — 本身就是最经典的 hidden pick-and-shovel
- **Kill switches**：
  - 中国 LNT A-Box 实船订单 >10 艘
  - 任一主要买家（如 JERA）正式要求放弃 GTT 膜技术转向国产方案
  - 俄罗斯 / 中东新 LNG 出口方开发独立膜技术

#### 终端节点 B：AP-C3MR / AP-X 液化工艺许可

- **事物节点**：将天然气液化为 -162°C LNG 的工艺设计与许可
- **上游一跳**：APD 的工艺专利 + 工程 know-how + 长期服役数据
- **跨行业等价节点**：空分工艺（APD / Linde / 液化空气均在做，技术有交叉）
- **为什么是真正卡点**：
  - 下游（新 LNG 项目）需要工艺许可 — 替代方案有 Linde MFC、Cheniere Cascade，但 AP-X 占大型 train 优势
  - 资格认证周期长 — 新液化工艺需要 10 年以上现场验证
  - 供给完全刚性（专利）
  - 价值捕获部分保持上游 — 工艺许可 + 关联冷箱销售 + 技术服务
- **映射公开表达**：
  - 最纯表达：`APD`（但 LNG 业务被工业气体稀释）
  - 高质量复利：`APD`
  - 隐藏 pick-and-shovel：`APD`（LNG 业务占比 ~10-15%，纯度不如 GTT）
- **Kill switches**：
  - Cheniere Cascade 被外部项目采用
  - Linde MFC 大型 train 份额突破 20%

#### 终端节点 C：Chart 冷箱与低温储罐（GTLS）

- **事物节点**：超低温 brazed aluminum 换热器 + 低温储罐
- **上游一跳**：铝合金冶炼 + 高精度 brazing 工艺 + 9% Ni 钢
- **跨行业等价节点**：空分冷箱 + 氢液化冷箱（相同技术）
- **为什么是寡头卡点**：
  - 下游难以绕开 — 主要竞争者 Linde Engineering + APD，全球仅 3 家
  - 供给弹性低 — 24 个月 lead time，产能扩展周期长
  - 利润捕获深 — 毛利率 25-35%
- **映射公开表达**：
  - 最纯表达：`GTLS`（LNG + 氢能 + CCS 三重驱动）
  - 隐藏 pick-and-shovel：`GTLS`（同时受益于 LNG 扩产与氢能产业化）
- **Kill switches**：订单环比下降 >20%，或 Linde Engineering 取得大型订单突破。

#### 终端节点 D：Baker Hughes 主冷剂压缩机（BKR）

- **事物节点**：大型离心压缩机（Main Cryogenic Compressor），推动冷剂循环
- **上游一跳**：Precision Castparts 等超合金 + 轴承（SKF / Schaeffler）+ 变频驱动
- **跨行业等价节点**：燃气管道压缩机 + 炼油装置压缩机
- **为什么是寡头卡点**：
  - BKR 继承 GE Oil & Gas 的 LNG 压缩机业务，市占 60-70%
  - Siemens Energy、MHI 为主要竞争者
  - 供给弹性低 — 30+ 个月 lead time
- **映射公开表达**：
  - 最纯表达：`BKR`
  - 高质量复利：`BKR`
  - 周期弹性：`SE.DE`（Siemens Energy）
- **Kill switches**：LNG 设备订单同比转负；Siemens Energy 或 MHI 在新项目中份额突破 40%。

#### 终端节点 E：9% 镍钢（Nippon Steel / POSCO / Industeel）

- **事物节点**：-162°C 低温强度 9% Ni 钢板材
- **上游一跳**：高纯度镍原料 + 真空熔炼 + 控轧控冷工艺
- **跨行业等价节点**：航空航天级镍基合金（同样需镍 + 真空冶炼）+ 核电低温设施
- **为什么是寡头卡点**：
  - 全球具规模化 9% Ni 钢能力 4 家以下
  - 认证周期长（船级社 + LNG 项目工艺认证）
  - 供给弹性低 — 产能扩张需 3-5 年
  - 利润捕获中等（钢铁业毛利率上限有限）
- **映射公开表达**：
  - 最纯表达：无纯标的（均为综合钢铁厂的细分产品）
  - 质量复利：`5401.T`（Nippon Steel）+ `005490.KS`（POSCO）
  - 中国表达：宝钢（600019.SH，部分 9% Ni 钢能力但主要出口需国际认证）
  - **隐藏 pick-and-shovel**：`5401.T`（Nippon Steel 的 LNG 相关业务在其披露中可追踪）
- **Kill switches**：LNG 项目 FID 节奏显著放缓，或膜式储罐替代率提升。

#### 终端节点 F：特殊超合金（PCC / ATI / Haynes）

- **事物节点**：LNG 主冷剂压缩机驱动燃气轮机（LM6000/LMS100）热端单晶叶片与高温合金
- **上游一跳**：单晶生长工艺 + 真空熔炼 + 精铸
- **跨行业等价节点**：航空发动机（完全等价）+ 地面燃机
- **为什么是寡头卡点**：
  - PCC（Precision Castparts，`BRK.B` 子公司，无法直接投资）
  - `ATI`（Allegheny Technologies）+ `HAYN`（Haynes International）为公开市场表达
  - 下游完全无法绕开
  - 供给弹性低 — 单晶精铸产能全球极稀缺
- **映射公开表达**：
  - 最纯表达：`HAYN`（Haynes International，耐热合金纯度最高）
  - 高质量复利：`BRK.B`（间接通过 PCC，但业务占比极低）
  - 隐藏 pick-and-shovel：`ATI / HAYN`（同时受益于航空航天 + LNG 扩产）
- **Kill switches**：航空航天需求下降挤压 LNG 交付 lead time。

## 三十一点五、场景化利润瀑布（替代静态利润分配表）

静态利润分配只回答"平均分配"。真实世界里三种场景会让每一层的利润捕获率完全不同。

### 31.5.1 场景 A：紧供给期（2022-2023 European crisis, JKM >$30/MMBtu）

| 层 | 利润捕获 | 核心原因 |
|---|---|---|
| 上游 E&P | **30-35%** | HH 翻倍,产量纪律下现金流井喷 |
| 液化出口商 | 20-25% | take-or-pay 保底 + merchant 窗口套利 |
| 交易/贸易 | **25-30%** | JKM-HH spread 极端,贸易商主导利润 |
| LNG 运输(现货) | 10-15% | TCE 冲到 >$200K/day |
| 设备 / 工艺许可 | 3-5% | CapEx 周期启动中,贡献未完全释放 |
| 材料(9% Ni 钢 + 超合金) | 1-2% | 订单加速但价格锁定 |
| GTT 许可费 | ~1-2% | 订单激增但量未放量 |

### 31.5.2 场景 B：平衡期（2024-2025,本报告当前基准）

| 层 | 利润捕获 | 核心原因 |
|---|---|---|
| 上游 E&P | 20-25% | HH 中性,产量纪律 |
| 液化出口商 | **25-30%** | 新产能投放,take-or-pay 主导 |
| 交易/贸易 | 10-15% | spread 收窄 |
| LNG 运输(现货) | 8-12% | TCE 从顶部回落 |
| **设备 / 工艺许可** | **6-8%** | **CapEx 周期高峰,`APD / GTLS / BKR` 主场** |
| 材料(9% Ni 钢 + 超合金) | 3-5% | 订单放量,价格稳 |
| **GTT 许可费** | **4-5%** | **新船下单创纪录,过路费激增** |

### 31.5.3 场景 C：Oversupply 压力期（2027-2028 预期）

| 层 | 利润捕获 | 核心原因 |
|---|---|---|
| 上游 E&P | 15-18% | HH 承压,部分产量退出 |
| 液化出口商 | **30-35%** | take-or-pay 保底,merchant 窗口关闭但基础设施估值稳 |
| 交易/贸易 | 5-8% | spread 压缩 |
| LNG 运输(现货) | **<5%** | 新船交付淹没市场,TCE 崩 |
| 设备 / 工艺许可 | 4-6% | CapEx 周期尾部,新订单放缓 |
| 材料 | 2-3% | 订单放缓 |
| GTT 许可费 | 3-4% | 订单周期回落,但存量船的过路费保留 |

### 31.5.4 场景化结论

- **跨场景最稳**:`LNG / VG`(take-or-pay toll)、`GTT.PA`(存量过路费 + 新订单弱化但不归零)。
- **跨场景最波动**:`FLNG / CLCO`(现货运输)、`EQT / RRC`(上游 HH beta)。
- **有明确窗口期**:`APD / GTLS / BKR`——2024-2027 CapEx 高峰是最佳窗口,2028+ 新订单回落前应关注 backlog 转折。
- **跨场景不匹配**:`NFE`——三种情景下财务韧性都是短板,它的问题从来不是"合同结构",而是资本结构与执行。

## 三十三、一句话总结

真正值得长期盯住的 LNG 链，不是"最大的 LNG 出口商"，而是：

- **每个新项目都要付过路费的液化工艺 + 核心设备 + 膜技术节点**（`APD / GTLS / BKR / GTT.PA`）
- **资格认证难以复制、供给极度刚性的上游卡点**（9% Ni 钢 + 超合金）
- **订单饱和但估值尚未完全反映扩产周期的韩国造船厂**
- **toll-based 长期合同型美国出口商**（`LNG / VG`）

三张清单：

- **结构核心池**：`GTT.PA / APD / GTLS / BKR / LNG`
- **当前研究优先池**：`329180.KS / 010140.KS / VG / WMB / EQT`
- **交易回调池**：`NFE / FLNG / CLCO`

**隐藏 pick-and-shovel 附加研究池**（v3.2 新增交付物）：`HAYN / ATI / 5401.T / 005490.KS / WRT1V.HE / LIN` — 它们在传统 LNG 报告里被忽视，但属于"跨行业穿透"后才能发现的真正卡点。

如果只记住一件事：**GTT.PA 是当前 LNG 产业链里最典型的"隐藏 pick-and-shovel"——每艘新 LNG 船都必须向它付 5% 船价，零 CapEx、零商品价格风险**。唯一需要盯的反转风险是中国 LNT A-Box 国产化时间表。
