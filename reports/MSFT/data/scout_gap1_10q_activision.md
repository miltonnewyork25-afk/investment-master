## 3. Goodwill减值风险评估

### 3.1 Goodwill构成与Activision Purchase Price Allocation

| 收购代价项目 | 金额 | 占比 |
|-------------|------|------|
| Total acquisition cost | ~$75.4B | 100% |
| Goodwill | $51.0B | 67.6% |
| Intangible assets | $22.0B | 29.2% |
| Cash acquired | $13.0B | 17.2% |
| Other net assets | ~($10.6B) | -14.0% |

**Intangible Assets by Type (Activision, FY2024 10-K)**:

| 类型 | 金额(估算) |
|------|-----------|
| Technology-based (游戏引擎/IP) | ~$14B |
| Marketing-related (品牌/商标) | ~$6B |
| Customer-related | ~$2B |
| **Total** | **~$22B** |

- 摊销: FY2025 Net intangibles $22.6B → Q2 FY26 $20.3B (年化消耗~$2.7B/年)

### 3.2 减值触发条件评估

| 因素 | 状态 | 风险等级 |
|------|------|---------|
| Gaming收入趋势 | Q2 FY26 -9% YoY | **高** |
| MPC营业利润 | Q2 FY26 $3.8B (-2.9% YoY) | 中 |
| Game Pass增长 | 停滞在35-37M | 中 |
| CoD系列表现 | 销量-60%(报道) | **高** |
| 硬件销售 | -32% YoY | **高** |
| 已确认减值 | Q2 FY26有减值费用(金额未披露) | **已触发** |
| 历史减值 | 累计$11.3B (主要来自Nokia时代) | 有前例 |
| 年度减值测试 | 每年5月1日执行，最近通过(May 2024) | 下次May 2026 |

### 3.3 减值概率与金额估算

**定性评估**:
- Q2 FY26已确认Gaming相关减值费用(嵌入MPC OpEx +6%中)，但金额未单独披露
- Gaming收入-9%、硬件-32%、内容&服务-5%构成"触发事件"信号
- 但MPC整体仍盈利($3.8B OI)，且Goodwill测试在reporting unit层面而非Gaming单独层面
- MPC包含Windows+Gaming+Search，Windows和Search的利润大幅缓冲Gaming亏损

**关键数学**:
- MPC Goodwill: $64.0B (其中Activision $51.0B)
- MPC年化Operating Income: ~$15B (Q2 $3.8B x 4)
- Implied MPC EV at 15x OI: ~$225B >> $64B Goodwill → **大幅富裕，短期减值概率低**
- 但若Gaming持续恶化+Windows受AI PC周期影响+Search被AI搜索冲击 → 长期风险上升

**量化场景**:

| 场景 | 概率 | Goodwill减值金额 |
|------|------|-----------------|
| 无减值(MPC稳定) | 65% | $0 |
| 小额减值(Gaming intangibles) | 25% | $1-5B |
| 中等减值(Activision goodwill) | 8% | $5-15B |
| 大额减值(类Nokia事件) | 2% | $15-30B |
| **概率加权** | — | **$1.1-2.5B** |

### 3.4 历史参考

- **Nokia减值(2015)**: MSFT对Nokia收购计提$7.6B减值(goodwill + intangibles)
- **aQuantive减值(2012)**: $6.2B goodwill全额减值
- **累计减值**: $11.3B (截至FY2024)
- **Activision风险**: 若Gaming持续-10%+以上3-4个季度，May 2026年度测试可能触发

## 6. 分析师备注

### Activision收购回报评估框架

**收购成本**: ~$75.4B (含现金$13B，实际净成本~$62.4B)
**年化Gaming收入增量**: ~$4.2B (FY2025)
**年化成本节省**: ~$1B (裁员10K人)
**增量EBITDA贡献**: 估算$1-2B/年 (revenue $4.2B x 低利润率 + $1B成本节省)
**隐含回收期**: 31-62年 (净成本$62.4B / EBITDA $1-2B)
**至IRR > 10%所需**: Gaming年增长>15%且margin扩张至25%+

**结论**: 以当前轨迹(Gaming -9% YoY)，Activision收购的价值回收远落后于计划。但MSFT的战略目标可能不是财务回报最大化，而是生态锁定(Game Pass+Xbox Cloud+Windows)。问题是：这个生态锁定策略是否奏效？Game Pass增长停滞(35-37M)提供了否定信号。

### 折旧悬崖风险

- FY26 H1 D&A: $22.3B ($13.1B Q1 + $9.2B Q2)
- PP&E净值: $286B (Q2 FY26)，资产平均年龄比32.4%（偏年轻）
- 年化D&A: ~$40-45B，占Revenue ~14%
- 未来2-3年GPU/Server折旧加速 → D&A可能升至$50-60B/年
- 这将压缩Operating Margin 2-3个百分点

### OpenAI会计风险

- Q2 FY26 GAAP净利润含$7.6B OpenAI投资收益 → non-GAAP调整后$30.9B
- 投资按公允价值计量(mark-to-market) → 未来季度可能出现大幅波动
- OpenAI收入分成从20%→10% (2030) → MSFT从OpenAI获得的直接现金流将缩减
- 但$250B Azure承诺 → 间接收入保障(按Azure margin ~50%，贡献~$125B毛利)
