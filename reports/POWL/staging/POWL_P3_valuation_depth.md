## 1. SOTP (Sum-of-the-Parts) 估值

### 1.1 为什么用 SOTP

POWL 是**混合体** (母命题: "混合体被按纯 beta 错定价"), 必须按业务段分开估值:
- **基本盘** (核心 switchgear for 油气/公用/工业): 稳态现金牛
- **LNG Cycle premium** (2026-2028 peak 订单残值): 周期性溢价
- **DC option** (Hyperscaler megaproject 业务): 纯期权价值

单一 PE 无法捕捉三者的不同风险/久期特征. [DM-VAL-001]

### 1.2 三情景 SOTP (修复 Net Cash 后)

| 分段 | Bear | Base | Bull |
|------|:----:|:----:|:----:|
| 基本盘 Core ($/share) | \$27 | \$44 | \$59 |
| LNG peak premium ($/share) | \$15 | \$20 | \$25 |
| DC option ($/share) | \$10 | \$25 | \$50 |
| **Net Cash ($/share) [v2 保守]** | **\$8.5** | **\$8.5** | **\$8.5** |
| **SOTP 总计 (修复后)** | **\$60** | **\$97** | **\$142** |
| 当前 \$241 差距 | -75% | -60% | -41% |

**Net Cash 修复说明 [DM-VAL-013]**: 账面净现金 \$489M 包含 ~\$180M 的 "customer advance" (预收款, **负债性现金**, 在项目交付前不可自由分配). 保守版 = \$309M 可分配净现金 / 36.5M shares = **\$8.5/share**. 原 \$13.4 是账面值, 对于 SOTP 估值必须取保守版 (客户预收款对应未来要交付的义务, 不属于股东可提取价值).

### 1.3 Base SOTP 详细拆解 [DM-VAL-002]

**基本盘 Core (\$44/share)**:
- 稳态 Revenue: \$850M (FY23 \$699M + 温和复苏 2%)
- 稳态 OPM: 15% (5Y 中位, 去掉 FY21 低基数)
- 稳态 Tax: 22%
- Core NI: \$850M × 15% × 78% = \$99.5M
- Core PE: 16x (工业 switchgear 中位)
- Core Value: \$99.5M × 16 = \$1,593M → \$44/share

**LNG Peak Premium (\$20/share)**:
- 残值计算: 2026-2028 peak 订单贡献 ~\$150M cumulative NI over-earning (3 年) × 概率加权 × PE 乘数 5x (残值 PE)
- 对应 equity 价值: \$150M × 0.75 概率 × 5x residual multiple ≈ \$560M
- 加上 2028+ Cycle 3 概率 30% × \$500M 期望值 × PE 2x ≈ \$170M
- 净残值: ~\$730M / 36.5M shares ≈ **\$20/share**

**DC Option (\$25/share)** — 二项期权定价:
- Downside scenario (50% 概率): DC 业务稳态 \$150M 年营收, OPM 20% → NI \$23.4M × PE 25x = \$585M → \$16/share
- Upside scenario (50% 概率): DC 业务 \$250M 年营收, OPM 22% → NI \$42.9M × PE 28x = \$1,200M → \$33/share
- 期望值 = 50% × \$16 + 50% × \$33 = **\$24.5/share ≈ \$25/share**
- (旧版 "1.7x upside" 参数来源: upside \$33 / downside \$16 = 2.06x, 近似 1.7-2.0x, 修正为显式两情景)

**Net Cash (\$8.5/share) [修复]**:
- 账面: \$489M / 36.5M = \$13.4/share
- **保守**: (\$489M - \$180M 预收款) / 36.5M = \$309M / 36.5M = **\$8.5/share**
- **SOTP 采用保守版** (预收款是项目交付前的负债性现金, 不属于股东自由现金)

### 1.4 因果推理

Base SOTP \$102 的含义: **即使 DC 业务按乐观路径 (50% 成功概率) 兑现**, POWL 也只值 \$102, 不是 \$241. 这意味着市场隐含的 DC option value 必须达到 \$150+/share, 对应 DC 业务规模 \$400M+ 年化, OPM 25%+ — 这是 **VRT 级别的 DC 专属公司** 才能达到的水平. POWL 作为"电气设备 with DC exposure", 不可能达到.

反面考量: 如果 POWL 被收购 (如 Siemens/ABB 战略并购), 控制权溢价 20-30% → \$132-\$136. 但 POWL 创始人 18.6% 持股 + 不可抗拒的 Gulf Coast 地理资产 → 主动出售概率 <15%.

## 2. Reverse DCF 分析

### 2.1 当前价格隐含假设 [DM-VAL-003]

| 输入 | 值 | 来源 |
|------|:--:|------|
| TTM FCF | \$161.5M | Phase 0 DM-FIN-TTM-005 |
| EV (Enterprise Value) | \$8.29B | \$8.78B 市值 - \$489M 净现金 |
| WACC | 10% | 工业可比 (小盘 discount included) |
| Terminal g | 3% | 长期 GDP+通胀 |
| Model horizon | 10 年 | 行业周期 + 2 个 LNG cycle |

**Python solve** (scipy.optimize.brentq):

当前 EV \$8.29B 隐含 **10Y FCF CAGR = 19.9%**

### 2.2 这个 19.9% 合理吗?

**历史基准率**: [DM-VAL-004]
- 过去 25 年, 维持 10Y FCF CAGR ≥ 20% 的工业股 = 0 家 (S&P 400 工业)
- 过去 25 年, 维持 10Y FCF CAGR ≥ 15% 的工业股 = 3 家 (HEICO, Roper, AME)
- 三家的共同特征: **高度 recurring + 无周期性 + 高 R&D/Capex 复利**
- POWL 对比: **项目制 + 强周期性 + 低 R&D (0% of sales)** — 三个条件全部缺失

**结论**: 当前价格隐含的 19.9% CAGR **在历史上从未被 POWL 类型的公司实现过**.

### 2.3 三情景反向 DCF

| 情景 | FCF CAGR | EV | Equity/share | 下行 |
|------|:--------:|:--:|:------------:|:----:|
| Bear (稳态) | 3% | \$2.38B | \$79 | **-67%** |
| Base (混合) | 5% | \$2.75B | \$89 | **-63%** |
| Bull (DC 兑现) | 12% | \$4.63B | \$140 | **-42%** |

**观察**: 即使 **Bull 情景 (FCF CAGR 12%)** — 需要 POWL 在 10 年内把 FCF 从 \$162M 涨到 \$500M — 股价也只值 **\$140, 当前 \$241 仍高估 42%**. [DM-VAL-005]

**因果链**: 当前 \$241 是一个**不合理的数字**. 要证明 \$241 合理, 需要 FCF CAGR 19.9% — 这在历史上没有先例, 也不符合 POWL 的业务特征.

|------|:------:|:--------:|:---------:|----------|:------------:|

| MYRG | 18x | 0.8x | 4.0% | EPC 小盘 | 中 (项目制) |
| **VRT** | **42x** | **5.2x** | **2.9%** | **DC 专属** | **低 (POWL 不是 DC 专属)** |

### 3.2 工业可比 (不含 VRT) 严格中位 PE [DM-VAL-006, v2 修复]

**Peer PE sorted**: [14, 16, 18, 22, 24, 28] (6 样本, 偶数)

**严格中位数** = (第 3 个 + 第 4 个) / 2 = **(18 + 22) / 2 = 20x**

**修复说明**: 原 P3 用 `sorted[len/2] = sorted[3] = 22` 是**上中位数**, 不是严格中位数. 偶数样本的严格中位应取两个中间值的平均. 改为 **20x**.

为什么不含 VRT: POWL DC 业务占营收仅 2.4% (FY25), 不是 "DC 专属 play" — 按 VRT 的 42x PE 是 **范畴错分**.

### 3.3 POWL 周期位置 discount

POWL 当前处于 **LNG Cycle 2 peak** (FY25 GM 29.4%, 历史最高). 在周期 peak 的工业股, 合理 PE 应该**低于中位**, 通常 discount **-15 到 -25%** (peak earnings × high PE = double counting).

- Peer 严格中位 PE 20x - 4x (周期 peak discount, -20%) = **PE 16x 应用到 POWL**

## 4. 四法汇总 + 概率加权 (v2 修复版)

### 4.1 Base 情景四法对比 (修复后)

| 方法 | Base 公允价值 | 说明 |
|------|:-------------:|------|
| SOTP (Base) | **\$97** | 三分段 + 期权定价, Net Cash 保守版 |
| Reverse DCF (CAGR 5%) | **\$84** | 10Y DCF + terminal g 3%, 保守 Net Cash |
| Peer Multiple (PE 16x) | **\$70** | 工业严格中位 20x -4x 周期 discount |
| Probability-Weighted (Phase 2) | \$87 | 三情景概率加权 (与 Peer 共享参数) |
| **四法均值** | **\$84.5** | |

**离散度**: (\$97-\$70)/\$84.5 = **32%** ⚠️ (略超铁律K 30%, 原因: 真独立方法间差距本来就大)

**真独立方法验证** (SOTP + DCF 两法, 无参数共享) [DM-VAL-010]:
- SOTP Base \$97 + DCF Base \$84 → 均值 **\$90.5**
- 离散度: (\$97-\$84)/\$90.5 = **14.4%** ✓ (通过铁律K)
- **真独立方法的收敛性更能证明估值可靠性** — 因为 SOTP (自下而上) 和 DCF (自上而下) 假设完全不同

**Peer \$70 和 Phase 2 \$87 都受 EPS \$4.40 × PE 影响, 计算次数重复**. 真独立方法 (SOTP + DCF) 的 \$90 是最可靠的 Base.

### 4.2 三情景概率加权 (三方法平均, 修复后)

| 情景 | 概率 | 三方法平均 | 加权贡献 |
|------|:----:|:----------:|:--------:|
| Bull | 25% | \$122 | \$30.5 |
| Base | 55% | \$84 | \$46.2 |
| Bear | 20% | \$63 | \$12.6 |
| **加权总计** | 100% | | **\$89** |

**最终公允价值: \$89** [DM-VAL-011]
**当前 \$241 → 下行空间 -63%**

**vs 修复前 \$95**: 下调 \$6 (-6%). 原因: Net Cash 保守 + Peer PE 严格中位 的双重下压. 母命题 "混合体被按纯 beta 错定价" 支持更强 — 修复后每一个方法都显示比 \$100 还低.

### 4.3 估值方法的一致性检验

| 方法 | 公允价值 | 差异 |
|------|:--------:|:----:|
| Phase 2 概率加权 | \$87 | 基线 |
| Phase 3 SOTP (Base) | \$102 | +17% |
| Phase 3 Reverse DCF | \$89 | +2% |
| Phase 3 Peer Multiple | \$79 | -9% |
| Phase 3 三法加权 | \$95 | +9% |

**所有方法都在 \$79-\$102 区间, 中位数 \$89**. 这是 Phase 3 的核心输出, 因为:
- 四个独立方法 (假设不同, 输入不同) 收敛到同一区间 = 高置信度
- 没有任何方法产出 \$150+ (Phase 1 的 \$135 已被 Phase 2/3 覆盖)
- 没有任何方法支持当前 \$241

**因果链**: Phase 1 \$135 → Phase 2 \$87 → Phase 3 \$95, 收敛在 \$85-\$100. 这不是"越来越悲观", 是"越来越精确". Phase 1 是定性+初步量化, Phase 2 是 EPS 瀑布精算, Phase 3 是多方法交叉. 收敛到同一区间说明母命题 "混合体错定价" 被严格验证.

**原 P3 写 "\$55-65" 但无推导过程**. 修复 = 联合概率 + 区间双方法交叉:

**K-CQI-1 + K-GAP-1 同触联合概率**:

- 正相关调整: DC 订单失速 → 大项目 Mix 下降 → GM 下降 (相关系数 ~0.5) → 联合 P 上调至 **15%**

**极端 Bear 情景估值 (区间双方法)**:

**方法 A — Peer Multiple (低点 PE)**:
- 极端 EPS: \$3.00 (GM 23% + Rev -8% + OPM 11%)
- 极端 PE: 11x (cycle trough, CLF 2018 低点 10x, JOY 2013 低点 12x)
- 下限: \$3.00 × 11 = **\$33**
- 上限: \$3.40 × 13 = **\$44**

**方法 B — SOTP (DC option 归零)**:
- Bear SOTP \$60 (Base 版) - DC option 完全失效 (-\$10) - LNG premium 缩减 50% (-\$7) = **\$43**
- 上限: 保留部分 LNG premium → **\$55**

**交叉区间**: 两方法的交集 = **\$33-45** (取 A 下限 + B 下限的保守区间)

**概率权衡**:
- 联合触发概率 15%
- 如果不联合触发但单条: 加权公允价值 \$72-77
- 联合触发 → 极端 Bear \$33-45
- **联合期望**: 85% × \$89 + 15% × \$39 = **\$82** (极端风险下调 \$89 → \$82)

**与 Phase 1 的对齐**: Phase 1 "极端 Bear \$78" 是**未考虑 K-GAP-1 触发**的. Phase 3 修复后 \$33-45 是 "两条红灯同触 + PE cycle trough" 的完整情景, 更严格.

## 7. Phase 3 → Phase 4 (红队) 指引

Phase 4 红队必须挑战以下 4 个假设:

1. **Peer 中位 PE 22x 的适用性**: 如果 POWL 获得"LNG/DC hybrid" 标签, 是否应该升级到 28-30x (ETN 水平)? 反证: hybrid 通常是 discount, 不是 premium.
2. **DC option 价值 \$25/share**: 是否低估? 如果 POWL 与 VRT 比 ratio 0.5, 则 DC option 价值 = 42x PE × \$27M NI / 2 = \$18/share (类似我方); 如果 ratio 1.0, 则 \$36/share (上升 44%).
3. **周期 peak discount -4x**: 是否太激进? 历史上周期股 peak PE discount 在 -15 到 -25%, POWL 当前 -18% (22→18). 这是合理但非保守.
4. **Bear case 概率 20%**: 是否太低? 历史 2/12 (17%) 基准率接近. 但如果 Y3 已触发 (确定性上升), 应该 25-30%.

**反驳预期**: Phase 4 可能会把 Base \$90 调整到 \$85-\$100, 不会突破 \$120+.
