## 2. POWL 订单窗口 (ISD-24m 逻辑)

**行业常识**: LNG EPC 承包商在终端 in-service 前 18-30 个月集中采购电气设备 (开关柜 / MCC / 继电保护)。POWL 的订单 → 交付 → 确收周期 12-24 个月。

| 订单年 | 项目数 | mtpa 加权 | 代表项目 |
|--------|-------|----------|---------|
| **2024** | **3** | **34.6** | **Plaquemines + Corpus Stage 3 + Golden Pass** |
| 2025 | 3 | 18.7 | Rio Grande T1 + Golden Pass T3 + CP2 引子 |
| 2026 | 3 | 10.4 | Rio Grande T2/T3 + CP2 主合同 |
| 2027 | 1 | 9.9 | Louisiana LNG |

**关键观察**:
- 2024 是订单密集年 (34.6 mtpa 加权) → 对应 FY25-FY26 确收 (= POWL FY25 营收 +9%, backlog +16% 的主因)
- 2025-2026 订单强度 mtpa 加权掉到 18.7 / 10.4 → **2027-2028 营收增速减缓**
- 2027 订单仅靠 Louisiana LNG 单项目 → **2029+ 新订单真空期**

**这解释了管理层口径矛盾**:
- 乐观侧: "strong and extended cycle across the back half of this decade" (2026-2030 LNG 强周期) [DM-MGMT-001]
- 现实侧: FY26 backlog 60% 会在 FY26 确收 → **只有 40% 留给 FY27+** [DM-BL-002]
- Jacintoport 扩建 "predominantly for FY26 LNG projects" → **2026 是 peak 单点, 不是 plateau** [DM-CAPEX-002]

## 3. 历史周期对照 (POWL 油气营收响应)

### 周期 1 (2016-2020): Sabine + Cameron + Freeport + Corpus T1-T3
- 美国 LNG 产能 0 → ~10 Bcf/d (+10 Bcf/d)
- POWL 油气营收: $260M → $310M (**仅 +19%**)
- 理由: 同期页岩油价崩盘, 常规油气设备投资萎缩抵消了 LNG 驱动

### 周期 2 (2021-2025): Calcasieu Pass + Corpus T1-3 + Plaquemines P1
- +~7 Bcf/d
- POWL 油气营收: $280M → $575M (**+105%**)
- 理由: 常规油气弱恢复 + LNG 集中爆发 + 供给紧张期定价权

### 当前周期 (2026-2030): Plaquemines P2 + Corpus Stage 3 + Golden Pass + Rio Grande + CP2 + ...
- +~13 Bcf/d (**历史最大单轮扩张**)
- POWL 指引: 后半段 10 年代 LNG 强周期
- Jacintoport +62% yard area 预备 2026-2028

**关键差异**:
- 周期 2 的 LNG 订单密度 (7 Bcf/d 历时 5 年) ≈ **1.4 Bcf/d/年**
- 当前周期订单密度 (13 Bcf/d 历时 4-5 年) ≈ **2.6-3.2 Bcf/d/年** (2x 历史)
- 但 **订单密度集中在 2024-2026**, 2027-2029 逐渐稀释
- 常规油气: 上次是恢复期, 本次已进入下行 (石化 FY25 -19% YoY)

## 4. LNG 下行拐点信号 (Kill Switch 触发表)

### 信号 1: 新 FID 节奏 (最早)
- **阈值**: 2026-2027 单年新 FID < 15 mtpa (历史 2024-2025 均值)
- **现状**: 2025 已 FID 33.5 mtpa (CP2+Corpus M8-9+Louisiana) → 暂时强
- **风险**: Trump admin 2025 解除 Biden LNG pause → FID 加速, 但 2027+ 依赖全球需求
- **跟踪**: 季度 FERC 批准报告 + EPC 招标公告

### 信号 2: POWL book-to-bill (中期)
- **阈值**: 季度 book-to-bill < 1.0 持续 2 个季度
- **现状**: Q1 FY26 订单 $439M / 确收 $251M = **book-to-bill 1.75** (强)
- **风险**: FY26 后半 book-to-bill 若回落到 1.2-1.3 → 2028 营收有缺口
- **跟踪**: POWL 每季度 earnings release 披露新增订单 vs 确收

### 信号 3: Jacintoport 利用率 (领先 12 个月)
- **阈值**: 2027 上半 yard 利用率 < 70% (相对 2024 基线)
- **现状**: 管理层'2026 predominantly LNG' → 暗示 2027 回落
- **风险**: 2027 若产能空置 → 订单强度不及预期 → 定价权 3.5pp GM 开始压缩
- **跟踪**: POWL Q3-Q4 FY26 earnings call 对 Jacintoport 利用率的措辞

### 信号 4: 竞争格局扩产 (同步-滞后)
- **阈值**: Eaton Omaha $30M 扩产 2027H1 投产
- **含义**: 2027-2028 市场供给增加 → POWL 周期性定价权 3.5pp GM 贡献压缩
- **跟踪**: Eaton, ABB, Siemens T&D 板块季度 CapEx 披露

## 5. LNG 在 POWL 营收中的定位 (量化)

```
FY25 总营收 $1,104M
├── 油气板块 37% ($408M)
│   ├── LNG 直接 ~55% ($225M) = 20% 总营收
│   └── 常规油气 ~45% ($184M) = 17% 总营收
├── 石化板块 14% ($155M) ← FY25 YoY -19%, Q4 -25%
├── 公用事业 25% ($276M)
├── 商业/工业 16% ($177M) ← 含 DC $26M ≈ 2.4%
├── 其他 / 铁路 8% ($88M)
```

**核心观察**:
- LNG 直接 ~22% 营收 + 石化 14% ≈ **25-30% 纯 LNG 驱动** (真正的基本盘)
- DC 仅 ~2.4% 营收 (15% backlog 等比例换算) → **期权, 不是主干**
- 市场把'短 DC 尾巴'估值到 47x PE → **范畴错分: 实际是 LNG 周期股 + DC 期权, 不是 AI 平台股**

## 6. 2026-2030 营收情景

| 情景 | FY26 | FY27 | FY28 | FY29 | FY30 |
|------|------|------|------|------|------|
| Bull (全部项目按时 + 新 FID) | $1,303M (+18%) | $1,459M (+12%) | $1,576M (+8%) | $1,655M (+5%) | $1,704M (+3%) |
| Base (管理层指引 upper end) | $1,236M (+12%) | $1,335M (+8%) | $1,402M (+5%) | $1,430M (+2%) | $1,402M (-2%) |
| Bear (2027 新 FID 缺口 + 供给扩) | $1,192M (+8%) | $1,216M (+2%) | $1,155M (-5%) | $1,063M (-8%) | $935M (-12%) |

**Base 情景 = 管理层的口径** (FY26 +12%, FY27+ 减缓, FY30 开始衰退):
- 对应 FY25-FY30 CAGR **4.9%**
- 结合 GM 从 29.4% 回落到 27% (周期性 2pp 消失) → EPS CAGR ~3-4%
- 当前 Reverse DCF 隐含 10Y FCF CAGR **19.9%** → 按 Base 情景 **估值 overshoot 3-4x**

**Bull 情景 = 管理层最乐观口径** (2029-2030 新 FID 再启动一轮):
- 对应 FY25-FY30 CAGR **9.1%**
- EPS CAGR ~8-10%
- 仍然 < 当前隐含 19.9% → **即使 Bull 情景, 当前估值仍 overshoot ~2x**

**Bear 情景 = 2027 新 FID 缺口 + Eaton 扩产压价**:
- 对应 FY25-FY30 CAGR **-3.3%**
- EPS 可能腰斩 (GM 回落 4pp + 营收 -16%)
- 对应公允价值 < $100

## 8. 对 Phase 1-5 的输入

### 8.1 对 Phase 1 (护城河/竞争) 的输入
- **护城河本质**: POWL 在 LNG 开关柜领域是 **Top 4 中的 small-cap 纯 switchgear**, 不是 ABB/Siemens/Eaton 的多元化基因
- **切入点**: POWL 靠 **Jacintoport 地理位置 (Gulf Coast 近所有 LNG 终端) + 模块化制造 + Bechtel EPC 关系**, 不是技术壁垒
- **定价权来源**: 供给紧张 + 大项目认证门槛 → **周期性, 非结构性**
- **风险**: Eaton Omaha 2027 扩产 → 定价权 3.5pp GM 贡献压缩

### 8.2 对 Phase 2 (财务归因 + 剪刀差) 的输入
- **R-2 剪刀差 #1**: FY25 油气 +20% YoY vs 石化 -19% YoY → **同板块已经内部分化, 说明不是'油气周期'而是'LNG 单点'**
- **R-2 剪刀差 #2**: Q1 FY26 订单 +63% YoY (mega orders) vs 营收 +4% YoY → **Book-to-bill 超 1.7, 但 FY26 后是关键**
- **R-2 剪刀差 #3**: Jacintoport CapEx +62% vs FY25 CapEx 总额 $10.7M → **单一用途扩建, 2027+ 产能利用率风险**

### 8.3 对 Phase 3 (估值) 的输入
- SOTP 估值支持: LNG 驱动 ~25-30% 营收应用 **周期股 PE 12-18x** (类似 CAT/FLR 工程类)
- DC 期权 ~3-8% 营收应用 **期权定价** (概率加权而非线性外推)
- 公用事业 25% 应用 **效用股 PE 20-25x**
- 不能整体用 47x PE → **范畴错分**

### 8.4 对 Kill Switch 的新增
**K-LNG-1 (R4 阈值)**: 2026H2 book-to-bill < 1.0 持续 2 季 → FY27 营收缺口 → 公允价值下修 25%
**K-LNG-2 (R2 阈值)**: 2027 单年新 FID < 15 mtpa → 2029+ 订单真空 → 下行周期确认
**K-LNG-3 (U1 反转)**: 2027 新 FID > 30 mtpa (如亚洲长约重启) → LNG 周期延长 → 上修公允价值 15%
