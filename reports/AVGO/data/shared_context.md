## Phase 1 核心发现摘要

### 1. 公司身份 (Agent A)
**三层嵌套的基础设施收费站**:
- Layer 1: AI基础设施"定制军火商" — ASIC(60-70%) + 网络(90%) + CPO(Gen3) 的全栈co-design能力，不可拆分
- Layer 2: 企业软件"收费站" — VMware VCF, 77% OPM, 但+1% YoY暗示提价红利耗尽
- Layer 3: Hock Tan"资产优化平台" — η=1.37均值, 但SPOF+73岁+无继任

**SGI = 4.5 (通才偏混合)**: 9+产品线横跨半导体+软件, 但AI ASIC+网络有极深技术纵深
**D1 = ×0.78**: AI半导体42%×0.65 + 网络15%×0.80 + 传统8%×0.70 + 软件35%×0.95
