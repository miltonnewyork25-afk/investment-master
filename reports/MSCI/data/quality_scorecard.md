**加权分50.4 → 预期10x+区间** (50分门槛刚好跨过)

但需要两个重要修正:
1. **AUM β折价**: 比FICO多承担市场β风险(26%收入随市场波动), 这已反映在D1=0.90中
2. **ESG半衰期折价**: ESG分部(11%收入)半衰期仅10-15年(vs Index >50年), 加权半衰期被拖低

### 复利路径

**Path A: OPM弹性** — 与FICO同路径

但MSCI处于**Stage 1.7(近天花板)**: OPM 54.7% vs 天花板57%, 剩余弹性仅2pp。而FICO 2015年时OPM~34%(剩30pp弹性)。

**这意味着**: MSCI的OPM弹性复利引擎即将耗尽。未来增长必须来自收入端(AUM增长+新产品), 而非利润率扩张。这是估值压缩的根本原因——市场已经从"定价OPM弹性"转为"定价收入增速"。

### OPM天花板参考

**T1: 零边际成本** — OPM天花板60-70%

MSCI当前54.7%, 理论天花板~57-60%(受R&D 5.7%+SBC 3.6%制约)。如果R&D效率提升或AI替代部分人力, 可能推向60%+, 但概率<30%。

## ★ 卖出信号框架 (用户特别要求)

> 基于MSCI"2年震荡"的教训, 构建可量化的早期预警系统

### 信号1: 估值过热指标 (PE/中位数比)

```
PE_ratio = 当前PE / 10年中位PE

< 0.8  → 深度低估 (当前: 34.1/39.7 = 0.86 ← 接近)
0.8-1.2 → 合理区间
1.2-1.5 → 开始警惕
> 1.5  → 危险区 (2021: 73.4/39.7 = 1.85 ← 巨大红旗)
> 2.0  → 卖出信号
```

**2021年教训**: PE/中位数比=1.85, 远超1.5阈值。即使MSCI基本面完美, 买入点决定了4年零回报。

### 信号2: OPM天花板距离 (剩余弹性)

```
OPM_headroom = OPM天花板 - 当前OPM

> 15pp → 弹性充足 (FICO 2015: 34% vs 70% = 36pp)
5-15pp → 弹性收窄
< 5pp  → 弹性耗尽警告 (MSCI 当前: 57%-54.7% = 2.3pp ← 红旗)
< 2pp  → 增长必须100%来自收入端
```

**当弹性<5pp时**: 市场会重新定价——从"利润率扩张故事"变为"收入增速故事"。PE通常压缩20-40%。

### 信号3: 留存率趋势 (护城河健康度)

```
Retention_trend = 当季留存率 vs 4Q均值

> +0.5pp → 加速锁定
±0.5pp → 稳定
< -0.5pp → 松动信号
< -1.0pp → 卖出预警 (客户开始探索替代品)
< -2.0pp → 强烈卖出 (Vanguard 2012级别事件可能重演)
```

**当前**: 整体94.4%(vs Q1 95.3%), 有轻微下滑但在季节性范围内。需持续监控。

### 信号4: AUM费率加速下降

```
Fee_rate_change = 当季费率 vs 4Q前费率 (bps)

> -0.05bps → 正常压缩
-0.05~-0.10bps → 加速压缩
< -0.10bps → 客户谈判筹码增强, 定价权被侵蚀
```

**当前**: 2.41bps, 趋势下降但速度稳定。BlackRock 2035合同每次续约-0.1bp是已知的。

### 信号5: 内部人卖出/买入反转

```
2021 Q3-Q4: 53 disposed / 3 acquired → 大规模内部人抛售 (股价见顶)
2024-2026:  净买入主导, CEO 23笔增持@$524 → 内部人认为低估
```

**历史验证**: 2021年内部人大量卖出精确对应股价峰值。这是最可靠的单一信号之一。
