## ★ 攻守兼备仓位策略 (不依赖后视镜)

> **设计原则**: 我们不知道未来PE会到多少, 不知道OPM何时见顶, 不知道ESG走向。
> 我们需要的不是"精确卖在顶部"的幻觉, 而是"在多种未来下都不会大错"的仓位管理系统。
> **核心理念**: 模糊正确 > 精确错误。不错过主升浪 + 不在极端高估时满仓 = 攻守兼备。

### 策略设计: 核心仓位 + 估值弹性仓位

```
总仓位 = 核心仓位(永不卖) + 弹性仓位(随估值调整)

核心仓位: 总仓位的50-60%
  — 只要商业品质未恶化(留存率>92%, 收入正增长), 永远不卖
  — 享受长期复利, 不受短期估值波动干扰
  — 卖出条件唯一: 护城河出现结构性裂缝(非估值原因)

弹性仓位: 总仓位的40-50%
  — 在估值区间内渐进调整, 不做全进全出
  — 越贵越轻, 越便宜越重, 但永远不满仓也永远不空仓
```

### 弹性仓位调整矩阵 (不需要知道未来)

> 关键: 不是"PE=73x该卖"(后视镜), 而是"当PE处于历史分布的哪个位置时,
> 我愿意持有多少弹性仓位"(概率思维)。

```
PE历史百分位:        弹性仓位目标:    动作:
  <20% (极便宜)        100%           加满弹性仓位 — 别人恐慌时贪婪
  20-40% (偏便宜)       80%           维持偏重仓 — 不急着卖
  40-60% (合理)         60%           标准配置 — 享受复利
  60-80% (偏贵)         40%           开始减仓 — 每升一档减20%
  80-95% (贵)           20%           只留观察仓 — 大部分利润已锁定
  >95% (极贵)           0-10%         几乎清空 — 但核心仓位不动

MSCI当前: PE 34.1x, 10年范围26.3x-80.6x
→ 百分位 ≈ (34.1-26.3)/(80.6-26.3) = 14.4% → <20% → 弹性仓位满配区间
```

**为什么这个框架不依赖后视镜**:
1. 不需要知道"正确"PE是多少 — 只需要知道当前PE在历史分布中的位置
2. 不需要判断市场方向 — 渐进调整意味着涨了你还有仓位, 跌了你有弹药
3. 不追求卖在顶部 — 在PE从60%百分位涨到95%的过程中, 你从60%仓位减到10%, 捕获了大部分涨幅
4. 允许犯错 — 即使在"偏贵"时减仓后PE继续涨到更贵, 核心仓位(50-60%)仍然参与

### 护城河健康度监测 (核心仓位的唯一卖出条件)

> 核心仓位只在商业品质恶化时卖出, 不因估值卖出。
> 但"恶化"如何定义? 需要一个不依赖后视镜的监测框架。

**季度检查清单 (每次财报后执行)**:

| 指标 | 健康 | 注意 | 警告 | 数据来源 |
|------|------|------|------|---------|
| 留存率趋势 | >94% 且稳定 | 93-94% 或连续2Q下降 | <93% 或单Q下降>1.5pp | 财报 |
| 有机收入增速 | >7% | 5-7% | <5% 连续2Q | 财报 |
| 新产品贡献 | 有新收入来源上线 | 产品管线正常 | 无新产品+核心放缓 | 财报+投资者日 |
| 内部人行为 | 净买入或中性 | 少量计划性卖出 | 多人大额非计划卖出 | SEC Form 4 |
| 竞争信号 | 无重大客户流失 | 个别边缘客户切换 | Tier-1客户启动评估 | 行业新闻 |

**动作规则**:
- 全部"健康": 核心仓位不动, 继续复利
- 1-2个"注意": 记录但不行动 — 单季度波动不代表趋势
- ≥2个"警告": **启动深度复查** — 这不是自动卖出, 是触发你花2-3小时重新评估论文
- ≥3个"警告"持续2个季度: 核心仓位减半 — 这已经是商业品质恶化的强信号

**为什么不设自动卖出**: 因为你不知道"警告"是暂时的还是结构性的。
2022年MSCI留存率短暂下降到93%→2023年回升到95%。如果自动卖出, 你会在最差时刻出局。
所以"警告"触发的是**复查**, 不是**卖出**。

### 估值弹性的实际操作 (MSCI具体案例)

```
假设你在2026年3月建仓MSCI, 总仓位$100K:

核心仓位: $55K (55%) — 不卖, 除非护城河裂缝
弹性仓位: $45K (45%) — 当前PE百分位14% → 满配

场景A: 12个月后PE从34x回升到45x (百分位~35%)
  → 弹性仓位目标从100%降到80% → 卖出弹性的20% = ~$9K
  → 总仓位从$100K降到~$91K + 留$9K现金等下次机会
  → 你参与了34x→45x的涨幅(+32%), 只减了9%的仓位

场景B: 12个月后PE继续压缩到28x (百分位~3%)
  → 弹性仓位目标仍然100% → 不卖, 如果有闲钱反而加仓
  → 浮亏~18%, 但核心仓位+弹性仓位都完整, 等待均值回归

场景C: 24个月后PE飙到60x (百分位~62%, 偏贵)
  → 弹性仓位目标从100%降到40% → 卖出弹性的60% = ~$27K
  → 你参与了34x→60x的大部分涨幅(+76%), 已锁定60%弹性利润
  → 核心仓位继续持有, 如果PE继续涨到80x你仍有55%仓位参与

场景D: 留存率连续2Q降到92% + 有机增速<5%
  → 护城河警告触发 → 深度复查 → 若确认结构性恶化 → 核心仓位减半
  → 这是唯一触发核心减仓的条件, 与PE无关
```

### 这个框架的本质

**不追求精确, 追求存活**:
- 在MSCI PE=73x时, 你不会满仓(弹性仓位只剩10-20%)
- 在MSCI PE=34x时, 你不会空仓(核心+弹性全配)
- 在任何PE水平, 你都有仓位参与上涨, 也都有现金缓冲下跌
