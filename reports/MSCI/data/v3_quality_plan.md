### G1细则: 字符≥300K
- `wc -m` ≥ 300,000
- 不包含纯空白行/纯格式行
- 每Phase产出目标: P1≥120K, P2≥60K, P3≥90K, P4≥35K, P5≥30K = 335K(留15%缓冲)
- **验证命令**: `wc -m reports/MSCI/MSCI_Complete_v3.0.md`

### G2细则: DM密度≥1.5/千字
- DM格式: `DM-{Phase}-{序号}` 或 `[DM-{ID}]`
- H级(10-K/FMP/官方)占比≥60%
- 每个影响估值>$10/股的数据点必须有DM锚点
- **验证命令**: `echo "scale=2; $(grep -c 'DM-' report) * 1000 / $(wc -m < report)" | bc`

### G3细则: DM总数≥450
- 不计重复引用(同一DM-ID在不同位置引用只算1次, 但grep会重复计数——按grep结果≥450)
- 分布: P1≥160, P2≥90, P3≥120, P4≥40, P5≥40
- **验证命令**: `grep -c 'DM-' report`

### G4细则: Mermaid≥25
- 每章至少1个Mermaid图或数据表格
- 类型多样: pie/graph/xychart/quadrant/gantt/journey, 不允许全是同类型
- 目标实际产出≥40(争取IHG级92)
- **验证命令**: `grep -c '```mermaid' report`

### G5细则: 因果密度≥5.0/万字
- 计数标记: `因为|因此|这意味着|这解释了`
- 目标≥8.0(KLAC级), 争取≥10.0(v2.0已证明可达)
- 每个核心论点必须完整3层: 数据(DM) → 因果推理(因为→所以) → 反面考量(但是/反面/如果不成立)
- **验证命令**: `echo "scale=2; $(grep -c '因为\|因此\|这意味着\|这解释了' report) * 10000 / $(wc -m < report)" | bc`

### G6细则: Python验证必须
- SOTP各分部EBIT × 倍数的加总必须Python计算
- Reverse DCF的隐含增长率反推必须Python求解
- 敏感性矩阵的每个单元格必须Python填充
- **验证**: `python tests/verify_dcf_arithmetic.py MSCI` → PASS

### G7细则: 估值离散度≤30%
- 离散度 = (最高方法结果 - 最低方法结果) / 中位方法结果
- 3方法(SOTP/OEY/PE)的基准值离散度≤30%
- 如果超30%, 必须回查假设一致性(通常是某方法的增速/倍数假设偏离)
- **验证**: 手动计算并记录

### G8细则: CQ标记CQ1-CQ8
- 从v2.0的4个CQ扩展到8个
- CQ1-CQ4: 保留v2.0核心假说(双重上限/ESG保险化/垄断悖论/回购幻觉)
- CQ5-CQ8: 新增4个子假说(从v2.0分析中衍生)
  - CQ5: PA optionality — Burgiss能否成为第二个Index? (从Ch17衍生)
  - CQ6: BlackRock跨维度杠杆 — 客户+竞争者双身份的影响? (从Ch06衍生)
  - CQ7: 利率路径依赖 — Rf→2%时MSCI是否被低估? (从RT-6/7衍生)
  - CQ8: 被动化天花板 — 70%+被动化是否触发监管反弹? (从Ch22衍生)
- 每个CQ必须有: 定义+初始置信度+Phase演化+最终裁决+闭环
- **验证命令**: `grep -oE 'CQ[0-9]+' report | sort -u | wc -l` ≥ 8
