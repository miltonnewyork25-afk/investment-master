## Part 1: 模块门控评分

### 评分标准
- **0分** = 纯叙事(无指标/验证/KS)
- **1分** = 有指标但缺一致性检验或KS
- **2分** = 可验证 + 一致性检验 + KS

## Part 2: Top 10补证据任务清单

按影响度排序(对评分/CQ/估值的边际贡献):

### T01: M5 分部留存率面板 [影响: CQ-1/CQ-5, 估值±15-20%]
**当前状态**: 仅ESG有留存率(93.2%, Q4=91.0%), Index/Analytics/PA缺硬数据
**补证据路径**:
1. 10-K搜索"retention rate"/"renewal rate"/"run rate"分部披露
2. 如无直接披露 → 用(期初ACV + 新签 - 流失 = 期末ACV)隐含反推
3. 财报电话会搜索管理层口头披露的分部留存
**产出**: 4×5年留存率趋势表(Index/Analytics/ESG/PA)
**M5得分提升**: 1.0 → 1.5-2.0

### T02: E4 信息垄断统一KPI面板 [影响: CQ-4, 估值±10-15%]
**当前状态**: I×L双轴(19×21)和C1五层散布在Ch02/Ch03, 但缺统一的E4制度嵌入量化
**补证据路径**:
1. 汇总: 监管嵌入深度评分(1-5, 分Index/ESG/Analytics/PA)
2. 新增: 合同平均剩余期限(Annual Report搜索"contract"/"backlog")
3. 新增: ACV增速(Organic Subscription Run Rate增速, 10-K有)
4. 定义: E4专属KS(监管改革取消强制使用的概率估计)
**产出**: E4 KPI面板(1页) + KS注册
**E4得分提升**: 1.0 → 1.5-2.0

### T03: M6 增量OPM + DOL精确计算 [影响: H1验证, CQ-1, 估值±15-20%]
**当前状态**: OPM天花板55-57%基于定性推断(C级数据), 缺增量margin硬数字
**补证据路径**:
1. 计算: 3年增量OPM = ΔOp.Income(FY23-25) / ΔRevenue(FY23-25)
2. 分部拆分: Index增量OPM vs Analytics vs ESG vs PA
3. DOL = %ΔOp.Income / %ΔRevenue (5年)
4. 一致性检验: OPM扩张+Rev增速放缓+员工增速 → 是否三者一致?
**产出**: 增量OPM面板 + DOL系数 + 天花板验证结论
**M6得分提升**: 1.0 → 1.5-2.0

### T04: M7 AI替代ESG评级定量场景 [影响: CQ-3, 估值±8-12%]
**当前状态**: Ch24定性分析AI对四引擎的影响, 但ESG替代的定量场景缺
**补证据路径**:
1. 估算: LLM覆盖8,500家公司ESG评级的成本(tokens×公司×维度)
2. 对比: MSCI ESG评级团队成本(~$150-200M/yr估计)
3. 时间线: AI质量达到"机构可接受"标准需多少年? (参考信用评级AI模型进展)
4. 场景: AI替代ESG评级10%/30%/50%对MSCI ESG收入的影响
**产出**: AI替代ESG定量场景(3情景×5年)
**M7得分提升**: 1.0 → 1.5

### T05: M9 回购η按年份拆分 + ROIC ex-goodwill [影响: CQ-7, 框架价值]
**当前状态**: η=1.05-1.10是综合数字, 缺年份拆分; ROIC因负权益无意义但未计算ex-goodwill版本
**补证据路径**:
1. 回购η: 按年份(FY2019-2025)计算回购价格 vs 12个月后股价超额收益
2. ROIC ex-goodwill = NOPAT / (Total Assets - Cash - Goodwill - Intangibles)
3. 对标: SPGI/MCO/ICE的ROIC ex-goodwill比较
**产出**: η年度表 + ROIC ex-goodwill 5年趋势 + 同业对标
**M9得分提升**: 1.5 → 2.0

### T06: M10 Direct Indexing替代率估计 [影响: CQ-4, 长期估值]
**当前状态**: Direct Indexing作为品类替代风险被提及但未量化
**补证据路径**:
1. Direct Indexing当前AUM(~$500-800B估计, Parametric/Aperio等)
2. vs 标准指数追踪AUM($17T MSCI)的比例
3. 5年增速预测(行业研报)
4. 场景: 如果DI从1%→5%→10%对MSCI指数AUM挂钩费的影响
**产出**: DI替代率场景(3档×5年)
**M10得分提升**: 1.5 → 2.0

### T07: M4 ESMA ESG评级监管框架影响 [影响: CQ-3, 估值±8-12%]
**当前状态**: Ch22提到ESMA正建立ESG评级监管, 但仅一句
**补证据路径**:
1. WebSearch: "ESMA ESG ratings regulation 2025 2026"最新进展
2. 分析: 类NRSRO监管对MSCI ESG的影响(壁垒升级 vs 合规成本)
3. 先例: NRSRO体系如何巩固了MCO/SPGI的双寡头(可迁移)
**产出**: ESMA影响分析(+/-情景各一)
**M4得分提升**: 1.5 → 2.0

### T08: M3 杠杆极限利率压力测试 [影响: CQ-7, 风险评估]
**当前状态**: FY2028-29触及4.0x假设单一利率路径, 缺分叉
**补证据路径**:
1. 3情景: 利率不变 / +100bps / +200bps 对利息成本的影响
2. 每个情景下Debt/EBITDA达到4.0x的时间点
3. 对应的EPS增速变化(回购空间缩小→EPS放缓)
**产出**: 杠杆极限×利率情景矩阵(3×3)
**M3得分提升**: 1.5 → 2.0

### T09: M1 经常性收入穿透(合同条款) [影响: 收入质量评估]
**当前状态**: 71%经常性收入未穿透合同条款(多年期vs年度续约)
**补证据路径**:
1. 10-K搜索"multi-year"/"contract term"/"cancellation"
2. 财报电话会搜索管理层对合同期限的表述
3. 同业对比: SPGI/Verisk的合同期限分布(如有披露)
**产出**: 合同期限分布估计(1年/2-3年/3年+占比)
**M1得分提升**: 1.5 → 2.0

### T10: M8 收入Beta精确计算 [影响: 防御性估值锚点]
**当前状态**: Beta 0.82(股价), 收入Beta~0.8x GDP仅估算
**补证据路径**:
1. 用MSCI YoY Rev增速 vs 名义GDP增速做5年回归
2. 分部Beta: Index(高, 含AUM) vs Subscription(低, 纯订阅)
3. 对标: SPGI/MCO/ICE的收入Beta
**产出**: 收入Beta精确值 + 分部拆分 + 同业对标
**M8得分提升**: 2.0(维持, 但锚点更强)

## 升级路线图总结

### 快速升级(v1.1, 1个会话可完成)
执行T01+T02+T03 = 3个核心模块补证据
- **预期门控率**: 65.9% → **~75-78%**
- **预期得分提升**: +6-9K字符, M5/E4/M6各升0.5-1.0分
- **总分**: 14.5 → ~17.0 / 22

### 完整升级(v2.0, 2-3个会话)
执行T01-T10全部
- **预期门控率**: 65.9% → **~85-90%**
- **预期总分**: 14.5 → ~19.5-20.0 / 22
- **体量增加**: +15-20K → ~240K
- **预期质量评分**: 3.7-3.8 → **4.0-4.2**

### 不建议升级的部分
- **体量扩充**(222K→320K目标): 纯体量增加不提升质量, SPGI 160K证明密度比体量重要
- **M2信用风险/E1利率/E2支付/E3保险**: 不适用MSCI, 正确跳过
- **重复删减**: ~10-12K重复可在v2.0中清理, 但不是升级优先级

```
仍有差距。核心差距在M5/E4/M6三个模块。
```
