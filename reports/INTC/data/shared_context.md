## 10. 杜邦分解 (FY2025)

```
ROE = 净利率 × 资产周转率 × 权益乘数
    = 0.37% × 0.26x × 1.85x
    = 0.19%

ROIC = NOPAT / 平均投入资本
     = -$63M / $118.4B
     = -0.05%
```

DM-044 (baggers_summary, 2026-02-25)

**杜邦诊断**:
- **净利率 0.37%**: 盈利能力近乎消失
- **资产周转率 0.26x**: 重资产效率极低($211B总资产只产$53B收入)
- **权益乘数 1.85x**: 杠杆适中, 非主要驱动因素
- **核心问题**: 净利率和资产周转率双低 → 重资产+低利润 = 经典的"产能过剩重工业"模式
