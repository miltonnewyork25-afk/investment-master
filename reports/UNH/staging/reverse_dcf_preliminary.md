# UNH Reverse DCF 初步分析 (Phase 0.75)
> 目的: 翻译"市场在赌什么" — 铁律O前置
> 数据截止: 2026-03-19 | 价格: $284.33

## 1. 当前估值隐含假设

### 基本参数
- 市值: ~$258B (910M shares × $284.33)
- EV: ~$312B (市值 + 净债务$54B)
- FY2025 EBITDA: $23.1B → EV/EBITDA = 13.5x
- FY2025 FCF: $16.1B → FCF Yield = 6.2%
- FY2025 EPS: $13.23 → P/E(TTM) = 21.5x
- FY2027E EPS: $19.80 → Forward P/E = 14.3x (on 2027 consensus)

### Reverse DCF: 市场隐含了什么?

**假设**: WACC 9.0%, 终端增长率 3%, 10年DCF
- 当前EV = $312B
- FY2025 FCFF ≈ $19.0B (EBIT×(1-tax) + D&A - CapEx - ΔWC)
- 要让DCF = $312B，隐含FCFF CAGR = **约5-6%**

这意味着市场在赌:
1. **利润率会恢复但不会回到历史高点** — OPM从4.2%恢复到~7%(非8.7%)
2. **收入增速放缓** — 从10年CAGR 10%降至5-6%
3. **永久性的监管/复杂度折价** — P/E从20-25x区间永久下移到14-16x

### 与历史估值的对比
| 时期 | P/E | 市场定价的是什么 |
|------|-----|----------------|
| 2017-2023 | 20-25x | "高质量复利机器，低周期性" |
| 2024 | 33x | "暂时性盈利下降，会恢复" (过度乐观) |
| **2025当前** | **21.5x(TTM)/14.3x(FWD)** | **"恢复不确定，可能有结构性问题"** |

### 隐含信念集 (市场正在定价的5个信念)
1. **MLR不会回到82%以下** — 2020-2023的82-83% MLR可能是历史异常(COVID抑制利用率)
2. **Optum不能完全抵消UHC的MLR压力** — 协同故事被质疑
3. **监管环境结构性恶化** — PBM审查+MA费率压力+反垄断
4. **CEO换人=战略不确定性** — Hemsley回归意味着什么?
5. **医疗利用率正常化是永久性的** — 不是暂时性catch-up

### 关键反问 (Phase 1需要回答)
- 如果MLR真的在正常化(而非恶化)，合理OPM是多少? 6%? 7%? 8%?
- 如果OPM恢复到7%，EPS≈$24，P/E 18x → 股价$432 (上涨52%)
- 如果OPM永久停留在5%，EPS≈$17，P/E 14x → 股价$238 (下跌16%)
- **这是一个二元性很强的赌注**: OPM恢复→大幅低估 vs OPM结构性下降→合理定价

## 2. 市场标签错误分析

### 当前标签: "盈利恶化的大型保险公司"
- P/E 21.5x → 保险公司通常8-15x
- 但UNH仍有溢价 → 市场还没有完全按"纯保险"定价
- **标签正在从"平台"向"保险"迁移中** — 这个过程可能还没结束

### 可能的正确标签
1. **"暂时受损的健康基础设施平台"** → 恢复后值$400-500
2. **"结构性恶化的复杂集团"** → 进一步下跌到$200-250
3. **"正在被监管解构的纵向垄断"** → 分拆价值可能更低

### 标签→估值映射
| 标签 | 适用方法 | 隐含P/E | 隐含价值 |
|------|---------|---------|---------|
| 保险公司 | 行业P/E | 12-15x | $200-250 |
| 健康基础设施平台 | SOTP+平台溢价 | 18-22x | $350-450 |
| 复合成长股(历史模式) | DCF+成长溢价 | 22-28x | $440-560 |
| 被监管解构的集团 | NAV折价 | 10-14x | $170-230 |

## 3. 初步Thesis候选

### Thesis A (偏牛): "暂时性盈利低谷 + 标签错配"
- 2025是MLR正常化+一次性事件叠加的最坏年份
- Optum的平台价值被UHC的保险波动掩盖
- 一旦利用率稳定+Q4 charges不再重复，EPS可回到$20+
- 当前$284定价了永久恶化，但恢复概率>50%

### Thesis B (中性): "结构性利润率下移 + 合理定价"
- MLR从82%→85%+是正常化，不会逆转
- 监管压力(PBM+MA+反垄断)将持续压缩利润空间
- 当前P/E 14x(FWD)反映了合理的风险溢价
- 不便宜也不贵，关键看2026-2027执行

### Thesis C (偏熊): "复杂度成本+监管解构"
- 纵向整合(保险+PBM+医疗+数据)正在被反垄断瞄准
- Change Healthcare事件暴露了系统脆弱性
- Q4利润崩塌可能只是冰山一角
- 分拆后各部分独立价值之和可能<当前市值

### 初步倾向: Thesis A/B之间 (偏A)
**理由**:
- 全行业OPM崩塌(ELV/CI/HUM都跌)→不是UNH独有问题
- FCF仍$16.1B→现金创造能力未崩塌
- Forward P/E 14.3x在UNH历史上从未如此便宜
- 但Q4几乎零利润需要解释——如果是一次性则bullish，如果是趋势则bearish

## 4. 三条证伪路径 (Phase 1-4需要验证)

### 证伪路径1: MLR是结构性恶化
- 如果2026Q1-Q2 MLR继续>85% → Thesis A证伪
- 关键指标: MCR趋势、利用率数据、同业比较

### 证伪路径2: 监管将解构商业模式
- 如果FTC强制Optum Rx从UNH剥离 → 协同故事崩塌
- 关键指标: FTC/DOJ行动进展、国会PBM立法

### 证伪路径3: 管理层失控
- 如果Hemsley无法在2026恢复利润率→管理层可信度崩溃
- 关键指标: 2026 guidance、insider buying/selling、board变动

## 5. CQ0初步回答

**"UNH到底处在什么时刻?"**

这是一家在2016-2023年被定价为"防御性成长平台"(P/E 20-25x，Beta 0.38)的公司，在2024-2025年经历了:
1. 行业系统性MLR恶化 (全行业)
2. Change Healthcare网络攻击 (公司特定)
3. CEO更换 (公司特定)
4. 可能的一次性charges (Q4 2025, Q1 2024)
5. 监管环境收紧 (行业+公司特定)

**核心问题不是"UNH是不是便宜"，而是"过去8年的盈利能力是正常水平还是异常水平"**

- 如果2016-2023的OPM 7-9%是正常水平，那2025的4.2%是暂时低点 → 显著低估
- 如果2020-2023的MLR 82%是COVID异常，真实MLR是85%+，那OPM 4-5%才是新常态 → 合理定价
- 这是CQ7(主控变量)的核心: **MLR的均衡水平到底是多少?**
