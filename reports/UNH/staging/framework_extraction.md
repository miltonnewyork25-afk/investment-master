## F1: 制度嵌入五层结构 (源自FICO Ch11)

### 原始框架结构

FICO的C1五层模型将制度嵌入分解为五个不同深度的层级, 每层有独立的替换难度和时间表:

| 层级 | 定义 | 替换时间 |
|------|------|---------|
| L1 基础设施层 | IT系统/API集成 | 1-2年 |
| L2 监管层 | 法规强制使用 | 3-5年 |
| L3 合同层 | 合同条款引用 | 5-10年 |
| L4 操作层 | 风险模型校准/业务流程 | 5-15年 |
| L5 认知层 | 消费者/市场心智 | 10-20年 |

**核心洞见**: 五层不是独立的, 而是形成自我强化循环。打破循环需要从最高层(监管)切入, 然后逐层向下松动。每层"被打开"都有独立的条件、时间表和先例参考。

**量化方法**: C1 = 各层嵌入深度(0-5) x 权重 → 总分 → 每降1分的估值影响($xx/股)

### UNH适配方案

UNH的制度嵌入至少存在于两个维度: **UHC支付端** + **Optum服务端**

**UHC支付端五层嵌入**:

| 层级 | UNH对应 | 嵌入深度(初估) | 替换难度 |
|------|---------|-------------|---------|
| L1 基础设施 | 医院计费系统/EDI接口/Optum IT平台与医疗机构对接 | 4.0 | 高 — 医院EHR系统深度集成UHC审批流程 |
| L2 监管 | Medicare Advantage合规资质/州级保险牌照/CMS星级评定体系 | 4.5 | 极高 — MA计划审批需3-5年; ACA框架强化大型保险商地位 |
| L3 合同 | 雇主团险合同(3-5年期)/PBM药品合同/医疗网络协议 | 4.0 | 高 — Fortune 500雇主切换保险商=全公司重新入网 |
| L4 操作 | 精算模型(30年理赔数据)/风险调整模型/Medicare Stars质量管理体系 | 5.0 | 极高 — 精算模型校准需完整疾病周期数据 |
| L5 认知 | "UnitedHealthcare"品牌在雇主HR部门的认知锚定 | 3.5 | 中 — 品牌忠诚度弱于FICO(员工不选保险, HR选) |

**Optum端五层嵌入**:

| 层级 | UNH对应 | 嵌入深度(初估) | 替换难度 |
|------|---------|-------------|---------|
| L1 基础设施 | OptumInsight IT系统嵌入医院收入周期管理 | 4.5 | 极高 — 医院RCM系统迁移=6-18个月停摆风险 |
| L2 监管 | OptumRx PBM监管合规/DEA牌照/州级药房牌照 | 4.0 | 高 — PBM监管趋严反而加固在位者 |
| L3 合同 | OptumHealth诊所网络租约/医生雇佣合同/PBM药品回扣协议 | 4.5 | 高 — 长期合同锁定+违约金条款 |
| L4 操作 | OptumInsight数据湖(1.5亿+被保人理赔数据)/AI诊断辅助模型 | 5.0 | 极高 — 数据积累不可复制 |
| L5 认知 | "Optum"在医院CFO中的品牌(IT供应商→利润改善伙伴) | 3.0 | 中 — 品牌仍在建立中 |

**关键自我强化循环 (UNH特有)**:
```
UHC承保更多会员 → Optum获得更多理赔数据 → OptumInsight模型更精准 →
Optum诊所效率更高 → UHC理赔成本更低 → UHC可以定更低保费 →
UHC承保更多会员 (闭环)
```

**这个UHC-Optum数据飞轮是UNH的"第六层"嵌入 — FICO没有的跨业务互锁。**

### CQ映射

- **CQ候选: "UNH的垂直整合(支付+服务)是否创造了不可逆的制度嵌入, 还是监管拆分风险正在松动L2?"**
- 与DOJ反垄断调查/FTC PBM审查直接相关
- C1评分的变化路径 = UNH估值的最高杠杆变量

## F2: "两个生意"经济利润分解 (源自SPGI Ch2.7 + CQ-1)

### 原始框架结构

SPGI被拆解为两种截然不同的生意:
- **收费公路** (Ratings 61% OPM + Indices 66% OPM): 贡献63%利润, 应得32-37x P/E
- **数据服务** (MI 19% OPM + Mobility 16% OPM): 贡献30%利润, 应得18-22x P/E

**方法论**:
1. 按分部列出: 收入 / OPM / 经营利润 / 利润占比 / 合理P/E锚
2. 计算加权SOTP应得P/E vs 当前统一P/E → 识别混合折价/溢价
3. 推演"分拆后残余公司"的P/E重估幅度
4. 诊断低利润分部的利润率差距(结构性 vs 可优化)

**核心洞见**: 市场用统一P/E定价时, 可能同时低估了"收费公路"部分和高估了"数据服务"部分。

### UNH适配方案: "两个UNH"

UNH同样是两种截然不同的生意共存于一个壳中:

| 分部 | 收入(2024E) | OPM | 经营利润 | 利润占比 | P/E锚 |
|------|-----------|-----|---------|---------|--------|
| **UHC (保险)** | ~$300B | ~4-5% | ~$13-15B | ~55% | 13-16x (保险同行) |
| **Optum (服务+科技)** | ~$110B | ~8-9% | ~$9-10B | ~40% | 20-28x (医疗IT/服务) |
| **消除/Corp** | — | — | ~-$1B | ~-5% | — |
| **合计** | ~$400B | ~6% | ~$23B | 100% | ~17x(当前) |

**"两个UNH"的估值张力**:

- UHC作为保险商: 同行Cigna 11x / Humana 15x / Elevance 12x → 合理12-15x
- Optum作为医疗服务+IT平台: 同行Veeva 45x / Evolent 40x / Accenture Health 22x → 合理20-28x
- 加权SOTP: 55% x 14x + 40% x 24x = 7.7 + 9.6 = **17.3x** → 接近当前, 但隐含信息是: 如果Optum独立, 估值可能远高于当前被保险拖累的水平

**核心检验**: Optum利润率8-9% vs 纯科技对标20%+ → 差距是结构性(服务业务天然低)还是可优化(OptumInsight可以独立放大)?

### CQ映射

- **CQ候选: "Optum独立估值vs嵌入UNH的估值差额有多大? 垂直整合的协同价值是否补偿了混合折价?"**
- 直接关系到: 如果DOJ要求拆分, UNH总估值是上升(释放Optum)还是下降(失去数据飞轮)?

## F3: 身份溢价量化框架 (源自ETN Ch20)

### 原始框架结构

ETN的双重身份估值框架五步法:

1. **确定两极锚点** — 选择最能代表两种身份的peer group倍数
2. **独立估值** — 对每种身份分别用多个倍数(P/E, EV/EBITDA, P/FCF)估值
3. **隐含权重反推** — 当前市价 = w x AI身份价格 + (1-w) x 工业身份价格 → 解出w
4. **缺口量化** — 隐含权重w vs 实际业务占比 → 差值 = "身份溢价"(ETN: 66.5% vs 28% = 38.5pp)
5. **合理性检验** — 三种解释: (A)前瞻定价 (B)期权定价 (C)叙事泡沫

**核心公式**:
```
身份溢价 = 隐含身份权重 - 实际业务占比
          = (市价 - 传统锚) / (新锚 - 传统锚) - 实际新业务收入占比
```

### UNH适配方案: "保险公司"→"医疗健康平台"

UNH正在经历一场身份重估: 从"最大的健康保险公司"(保险P/E 12-15x)向"垂直整合医疗科技平台"(科技/平台P/E 20-30x)的转变。

| 身份 | 代表公司 | P/E锚 |
|------|---------|-------|
| **传统保险** | Cigna(11x), Elevance(12x), Humana(15x) | 12-15x |
| **医疗科技平台** | Veeva(45x), HIMS(35x), Accenture Health(22x), Evolent(40x) | 22-30x |

**隐含权重反推** (假设当前P/E ~17x):
- 17 = w x 26 + (1-w) x 13.5
- w = (17 - 13.5) / (26 - 13.5) = 3.5 / 12.5 = **28%**

市场隐含Optum的"平台身份权重"约28%, 而Optum实际利润占比约40%。

**这意味着UNH的身份溢价可能是负值(-12pp)** — 市场还没有给予Optum应有的平台估值, 反而用保险P/E拖累了整体。这与ETN的正溢价(+38.5pp)形成对比。

**身份转变的催化剂清单**:
- [ ] Optum独立财务披露增加透明度
- [ ] OptumInsight AI产品线独立定价
- [ ] 科技基金(如ARK/Coatue)开始建仓UNH
- [ ] 分析师将UNH从"保险"重分类至"医疗科技"

**身份临界点**: Optum利润占比需达到什么水平才能触发身份重估?
- 当前~40% → 市场仍视为"保险+附属业务"
- >50% → 可能触发"混合身份"重估(类似ETN当前)
- >60% → 可能触发"平台身份"确立

### CQ映射

- **CQ候选: "UNH是否存在'反向身份溢价'(平台被保险标签压制)? 如果市场重新分类UNH, P/E从17x升至20-22x的概率有多大?"**
- 这是纯估值维度的CQ, 不依赖业绩改善, 只依赖市场认知转变

## F4: 四层证据链方法论 (源自KLAC Ch24)

### 原始框架结构

KLAC报告实现了全系列最高的因果推理密度(9.28/万字), 核心模式是每个影响估值的论点都有四层证据链:

```
KLAC标杆模式:
论点: "KLA在下行周期中有定价权保护"
├── 层1 硬数据: 检测设备占fab CapEx仅5-7% [DM-BIZ-001]
├── 层2 因果逻辑: 不买检测的代价(良率崩塌) >> 检测成本 → 经济不对称
├── 层3 历史验证: WFE下行周期中检测削减幅度 < 沉积/刻蚀
└── 层4 推理→结论: 经济不对称 → 客户不敢砍 → 定价权 → 下行Beta<1
```

**信念反演框架** (KLAC Ch24.2-24.4):
1. Reverse DCF → 市场隐含N个信念集(B1-B5)
2. 每个信念评估: 脆弱度(1-10) + 失败概率(10Y) + 失败影响
3. 信念间关联性分析 → 识别独立信念cluster
4. 评级翻转阈值 — 最少几个信念失败改变投资结论?
5. 承重墙交叉验证 — 从"公司财务结构"而非"市场假设"出发

### UNH适配方案

**UNH核心论点的四层证据链模板**:

**示例论点: "UNH的垂直整合创造了不可复制的成本优势"**

| 层级 | 内容 | 数据需求 |
|------|------|---------|
| 层1 硬数据 | Optum诊所理赔成本 vs 外部诊所理赔成本(需10-K拆解) | MCR差异数据 |
| 层2 因果逻辑 | 自有诊所 → 控制诊疗路径 → 减少不必要检查 → 理赔成本↓ → MCR↓ → 利润↑ | 诊疗路径对比 |
| 层3 历史验证 | 2018-2025 Optum Care扩张 vs UHC MCR趋势 — MCR是否随Optum扩张改善? | 时序回归 |
| 层4 推理→结论 | 如果MCR改善幅度 > 同行(Cigna/Elevance), 且改善时间与Optum扩张同步 → 垂直整合因果链成立 | 同行对照 |

**信念反演适配** — UNH市场隐含的信念集(初步框架):

| 信念 | 内容 | 初估脆弱度 |
|------|------|----------|
| B1 | MA会员增长持续(CMS不大幅削减报销率) | 中高(6/10) — CMS政治风险 |

## F5: 估值折价三层归因 (源自IHG Ch12.8 + Ch17.3)

### 原始框架结构

IHG vs HLT存在43% P/E折价, 通过五因素归因模型分解:

| 类别 | 因素 | 占比 | 性质 |
|------|------|------|------|
| **结构性折价** | 规模差距(31%) + 品牌组合(20%) | 51% | 基本面, 短期不可逆 |
| **可争议折价** | 增长差距(16%) + 制度性折价(18%) | 34% | 部分基本面+部分非基本面 |
| **可修复折价** | 残差/市场情绪(15%) | 15% | 非基本面, 催化剂可触发 |

**方法论要点**:
1. 先锚定折价总量(P/E差异百分比)
2. 逐项量化每个因素的贡献(用P/E倍数差值而非百分比)
3. 区分"合理折价 vs 可争议折价 vs 待修复折价"三层
4. 计算"可修复折价修复一半"的目标价 → 给出保守的上行空间

**IHG的深层创新**: 增加了"制度性折价专题"(ADR上市/分析师覆盖/指数权重), 将非基本面因素从情绪折价中分离出来单独量化。

### UNH适配方案

UNH当前P/E ~17x, 如果对标医疗科技平台(25-30x), 存在约40-50%的"折价"。但这个折价需要分层归因:

**UNH vs "应有估值"折价归因模型**:

| 因素 | P/E折价贡献 | 占比 | 性质 | UNH特有证据 |
|------|-----------|------|------|------------|
| **保险标签拖累** | ~4-5x | ~35% | 认知性 | 保险板块P/E中位数13x拖累整体 |
| **MCR波动风险** | ~2-3x | ~20% | 基本面 | 医疗通胀周期性侵蚀利润率 |
| **监管/政治风险折价** | ~3-4x | ~25% | 制度性 | DOJ反垄断+PBM立法+MA报销率 |
| **规模溢价抵消** | +1-2x | ~-10% | 基本面(正向) | 最大规模=最强议价=最低MCR |
| **垂直整合争议** | ~2-3x | ~15% | 可争议 | 利益冲突叙事 vs 效率叙事 |
| **情绪/近期事件** | ~1-2x | ~15% | 可修复 | CEO事件/DOJ传闻/短期MCR上行 |

**可修复折价**: 保险标签(35%) + 情绪(15%) = **~50%折价可争议**

**关键差异 vs IHG**: IHG的折价是"同行业内的定位差异", UNH的折价是"跨行业身份错分" — 如果市场将Optum视为独立实体, 折价结构会根本性改变。

### CQ映射

- **CQ候选: "UNH 17x P/E中, 多少是合理的保险折价(MCR风险), 多少是可修复的标签折价(Optum被低估)?"**
- 与F3(身份溢价)形成互补: F3量化"身份权重缺口", F5量化"折价中每个因素的具体贡献"

## F6: Excellence Catalog Top 5 可迁移框架

基于excellence_catalog.yaml中37个冠军条目, 按对UNH的适用性排序:

### 排名1: 假设独立性检验 (IHG Ch18, 4.1分)

**方法**: 管理层增长公式拆解 → 历史同时失效验证 → 有效独立引擎数 → 增长预期折扣

**UNH适用性**: 极高。UNH管理层声称4个增长引擎(MA会员增长 + Optum收入扩张 + 定价权 + 回购), 但这4个引擎是否共享底层驱动(如"美国医疗支出总量增长")? 如果经济衰退时4个引擎同时失速, 有效独立引擎数可能从4→1.5。

**CQ映射**: "UNH的四引擎增长中, 有几个是真正独立的?"

### 排名2: 承重墙联合概率 (INTC Ch15, 4.2分)

**方法**: 识别N个必须同时成功的因素 → 单因素概率 → 联合概率(含相关性调整)

**UNH适用性**: 高。UNH的牛案需要: (1)MA报销率不大幅削减 AND (2)DOJ不要求拆分 AND (3)PBM立法温和 AND (4)MCR可控 AND (5)Optum AI变现。5个各60%概率的因素联合成功 = 7.8%(独立时), 实际可能15-20%(正相关)。

**CQ映射**: "UNH牛案所需的5个条件联合实现的概率?"

### 排名3: CDS定价权弹性函数 (ARM Ch14A, 4.4分)

**方法**: 定价弹性 = f(替代品渗透率), 三参数可校准, 配有敏感性分析

**UNH适用性**: 高。OptumRx PBM面临Mark Cuban Cost Plus Drugs等颠覆者。定价权弹性 = f(透明定价替代品渗透率)。当替代品渗透率从5%→20%, PBM回扣模式的定价权如何衰减?

**CQ映射**: "PBM透明定价替代品的渗透率达到什么水平, OptumRx的利润模式被根本性改变?"

### 排名4: 双层SOTP (IHG Ch2+Ch12, 4.2分)

**方法**: 特许经营层(高倍数) + 物业层(低倍数) → 混合倍数随资产轻转型动态变化

**UNH适用性**: 中高。UNH可拆为: 保险层(低倍数, 资本密集, 受监管) + 科技平台层(高倍数, 轻资产, 数据驱动)。随着Optum利润占比上升, 混合倍数应该上移 — 类似IHG从"物业重"向"特许经营轻"转型推动估值倍数提升。

**CQ映射**: "Optum利润占比每上升5pp, UNH混合P/E应上移多少?"

### 排名5: AI焦虑税量化 (SPGI冠军候选, 8.0/10)

**方法**: 量化"AI投资期"对短期利润率的压制 → 市场过度反应的放大系数

**UNH适用性**: 中。UNH在OptumInsight上的AI投资可能压制短期利润率, 市场可能将"投资期利润率压缩"误判为"结构性恶化"。SPGI的3.3x放大系数(市场对指引miss的过度反应)可以作为UNH类似情景的参考。

**CQ映射**: "OptumInsight AI投入如果压制FY2026 Optum OPM 50bps, 市场会过度反应多少?"
