# Quick Reference

## Minimal Flow

1. Match prototype
2. Run BSM on report-date structure
3. Fill 8 invariants in four passes
4. Apply `I1 PS/EE` and `I8 Scope+Stage`
5. Run four gates
6. Add overlays
7. Compare against two anchors
8. Assign Alpha type from structure, not just score

## Most Important Rules

- `I1 >= 9/11` requires the economic engine to be meaningfully `outcome / take-rate / expert-backed`
- `I5 = 9/9` requires structural budget inevitability
- `I8` must specify both `Scope` and `Stage`
- completed divestitures do not remain in active BSM
- unverified allegations normally affect `S`, not `C/M`

## Red Flags

- scoring before BSM
- using only company sources for high scores
- treating feature launches as proof of new control
- treating high margins as proof of durable moat
- letting a prototype force the answer when `PS/EE` or `I8 Stage` clearly disagree
