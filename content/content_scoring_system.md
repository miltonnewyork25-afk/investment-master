# 内容评分系统 v2.0

> 对每篇传播内容进行全方位量化评分。满分100分，5大维度+21个子项。
> 每篇文章完成后立即打分，分数+逐项依据一起存档，用于迭代改进。
>
> **v2.0变化** (源自HLT+SBUX两篇文章4轮迭代):
> - A3 burstiness标准从σ>12提升到σ>18
> - B3 数据密度新增"每段≤3个数字"硬约束
> - C5 合规新增"数字人话化"+"术语本地化"检查
> - 新增"自评诚实"铁律：禁止自评95+分
> - 标杆文章基线：v3 SBUX≈86, v3 HLT≈87

---

## A. 真实感与反AI (25分)

> 核心问题：一个真人会这么写吗？读者的镜像神经元能被激活吗？

| # | 子项 | 分值 | 评分标准 |
|---|------|:----:|---------|
| A1 | **生活质感** | 5 | 有具体的时间/地点/感官细节（不是"一家咖啡店"，是"drive-thru排了六七辆车"）。0=无场景 / 1=泛泛提及 / 3=有一个具体场景 / 5=多个层次的感官细节（视觉+触觉+情绪），场景不可互换（只能发生在这个人身上） |
| A2 | **情绪颗粒度** | 5 | 有微妙的、非表演性的情绪。不是"我很震惊"，是"脑子里会快速闪过一下"。0=无情绪 / 2=有但套路化（震惊/感叹） / 4=微妙真实 / 5=情绪有变化弧线（从犹豫→好奇→不舒服） |
| A3 | **Burstiness** | 5 | 句子长度标准差。量化方法：随机抽10句，计算字数标准差。σ<10=AI味重(0分) / σ 10-14=及格(2分) / σ 14-18=自然(4分) / σ>18=优秀(5分)。好文章有2字句("负的。")也有70字长句。v3标杆≈σ20+ |
| A4 | **不完美信号** | 5 | 承认不确定、自我修正、跑题但有价值、留下未解决的问题。0=全知全能口吻 / 2=有一处"我不知道" / 4=有思考过程暴露+至少一处自我质疑 / 5=不完美本身推动了叙事（"我不知道答案"不是结尾点缀而是核心张力） |
| A5 | **环境嵌入** | 5 | 通胀感受、消费压力、社区变化——不是数据引用，是**活在里面的人的体感**。0=无 / 2=提到但像新闻摘要 / 4=有具体的人（邻居/朋友/家人）的行为变化 / 5=环境变化与投资论点有因果关系（Sarah的法压壶→occasional customer流失→SSS下降） |

## B. 认知价值与深度 (25分)

> 核心问题：读完之后，读者的思维框架是否被不可逆地改变了？

| # | 子项 | 分值 | 评分标准 |
|---|------|:----:|---------|
| B1 | **范畴重分配** | 6 | Hofstadter核心操作——把公司从旧范畴移入新范畴。0=无（纯信息搬运） / 2=有类比但是近距离（酒店vs酒店） / 4=有效的范畴重分配（酒店→收租公司） / 6=重分配制造了认知不可逆性（看完之后回不去了）+残余被说明 |
| B2 | **概念晶体** | 5 | 是否产出了一个可以一句话转述的核心洞见。0=无 / 2=有总结但不够锐利 / 4=有清晰的晶体（"4分钟悖论"/"ε=7.04"） / 5=晶体具备模因传播力（读者会在自己的对话中复用这个词） |
| B3 | **数据密度** | 5 | 关键数字的使用——不是堆砌，是"压缩了故事的数字"。**硬约束：每段≤3个数字**。0=无数据或数据轰炸(一段5+数字) / 1=有但像百科 / 3=数字有叙事功能+人话化("效率降了四分之三"非"降78%") / 5=数字本身就是论点+全部人话化(无精确百分比) |
| B4 | **因果链完整性** | 5 | 从观察到结论的推导链是否可追溯。0=断言式 / 2=有推理但跳步 / 4=完整因果链（NUG减速→P/E压缩→回购效率下降→飞轮反转） / 5=因果链有意外性（读者能跟着走但猜不到终点） |
| B5 | **认知落差** | 4 | |我们的结论 - 市场共识| × 证据密度。0=和共识一致（无增量信息） / 2=小落差有数据 / 3=大落差有数据 / 4=落差大+证据链完整+读者能独立验证 |

## C. 声音与可信度 (20分)

> 核心问题：读者是否相信这是一个真实的、有能力的人在说话？

| # | 子项 | 分值 | 评分标准 |
|---|------|:----:|---------|
| C1 | **团队感** | 5 | 是否自然地传达了"背后有专业团队"的信号，而不是个人英雄叙事。0=全程"我"视角像独立博主 / 2=提到团队但生硬 / 4=团队自然嵌入（"我们团队的分析师"/"我们内部叫它"） / 5=团队感增强了可信度（频繁发帖不会显得可疑） |
| C2 | **专业-通俗平衡** | 4 | 术语使用恰当——不过度解释（读者不傻），也不故弄玄虚。0=全术语或全白话 / 2=有切换但生硬 / 3=自然混用（throughput、takt time不解释，但关键概念用人话翻译） / 4=术语选择本身传递了身份信号（"如果这是一条生产线..."） |
| C3 | **第一人称节制** | 3 | 第一人称是工具不是拐杖。按文章类型：名人交叉文20-30% / 分析深度文30-40% / 消费者日记60-70%。0=第一人称过载（每段都"我"） / 1=太少（冷漠） / 2=比例合适 / 3=比例合适+切换自然（从"我"到"我们"到客观陈述无缝衔接） |
| C4 | **反表演** | 4 | 没有做作的成分——不贩卖焦虑、不炫耀、不马后炮、不流量标题。0=有明显表演痕迹 / 2=干净但平淡 / 3=干净+有温度 / 4=粗糙边缘本身建立信任（"味道没什么特别的"——这种诚实不服务于分析但让人信任） |
| C5 | **合规** | 4 | 不推荐、不预测、不指导。新增检查：①数字人话化(35%→快三分之一) ②术语本地化(10-K→报表, Ritz-Carlton→丽思卡尔顿) ③无目标价/评级。0=有"买入/卖出"/目标价 / 1=有精确百分比或疏离术语 / 2=合规但结论暗示太强 / 3=合规+数字人话化+术语本地化 / 4=全部通过+免责声明+只摆矛盾不给答案 |

## D. 结构与传播力 (20分)

> 核心问题：这篇文章能不能被分享、被讨论、被记住？

| # | 子项 | 分值 | 评分标准 |
|---|------|:----:|---------|
| D1 | **Hook力度** | 5 | 前3句话能否留住读者。0=学术式开头("本文将分析...") / 2=有场景但不够抓人 / 4=有认知悬念或预测误差 / 5=读者在第3句话时已经无法关闭页面（"$6.45加税。三年前同样的东西$4.95"——读者立刻开始算自己的咖啡钱） |
| D2 | **节奏感** | 4 | 信息密度的波动——有密有疏，有紧有松。0=均匀平铺 / 2=有变化但不够大 / 3=密集数据段之后有呼吸空间 / 4=节奏本身创造了阅读体验（数字轰炸→场景切换→安静结尾） |
| D3 | **4拍Aha** | 4 | 是否遵循Beat 1(确立显然)→Beat 2(引入异常)→Beat 3(跨域异常)→Beat 4(读者自己连接)的结构。0=直给结论 / 2=有铺垫但不够 / 3=4拍完整 / 4=Beat 4成功——结论不是作者说的，是读者自己想到的 |
| D4 | **金句密度** | 3 | 可截图/可转发的句子。0=无 / 1=有一句 / 2=有2-3句 / 3=有3句以上且分布在不同段落（不集中在结尾） |
| D5 | **复用效率** | 4 | 这篇内容从深度研报中提取了多少独特价值？是否为后续文章留下了接口？0=与研报重复度>70%（直接缩写） / 2=有角度选择但未最大化 / 3=清晰的角度切割+为后续篇留了钩子 / 4=单篇独立完整+明确引出≥2篇后续可能（定价权弹性篇、CMG对比篇等） |

## E. 平台适配 (10分)

> 核心问题：这篇文章在目标平台上是否会被算法和读者同时青睐？

| # | 子项 | 分值 | 评分标准 |
|---|------|:----:|---------|
| E1 | **长度适配** | 3 | 是否在目标平台的最佳区间。雪球2000-5000字 / 微信8000-15000字 / Twitter 5-15条 / Substack 3000-8000词。0=严重超出或不足 / 2=在区间内 / 3=在区间内+信息密度匹配平台调性 |
| E2 | **互动钩子** | 4 | 是否包含能引发评论/讨论的开放问题。0=无（读完即走） / 2=有一个问题但封闭式 / 3=有开放式问题引发讨论（"是他们错了，还是市场还没反应过来？"） / 4=问题本身就是争议点+读者有足够信息形成自己的立场 |
| E3 | **系列感** | 3 | 是否让读者感知到"这是一个持续输出的团队"。0=孤立文章 / 1=提到"我们的研究"但无后续暗示 / 2=有清晰的后续钩子（"下次聊CMG..."） / 3=建立了内容宇宙感——读者知道还有更多、想看更多、但每篇独立完整 |

## 评分汇总

| 维度 | 满分 | 权重说明 |
|------|:----:|---------|
| **A. 真实感与反AI** | 25 | 最高权重——如果读者觉得是AI写的，其他全部归零 |
| **B. 认知价值与深度** | 25 | 并列最高——没有深度就是噪音 |
| **C. 声音与可信度** | 20 | 信任是长期资产 |
| **D. 结构与传播力** | 20 | 好内容传不出去=树倒无人听 |
| **E. 平台适配** | 10 | 技术层面，容易调整 |
| **总计** | **100** | |

### 分级

| 等级 | 分数 | 含义 | 行动 |
|------|:----:|------|------|
| **S** | 90+ | 标杆级——可作为后续文章的参考模板 | 立即发布+存入模板库 |
| **A** | 80-89 | 优秀——有1-2项突出,无明显短板 | 发布,记录亮点 |
| **B** | 70-79 | 合格——完成度够但缺乏记忆点 | 可发布,但需反思哪个维度拖后腿 |
| **C** | 60-69 | 需改进——有明显短板或AI感 | 修改后重评,不直接发布 |
| **D** | <60 | 不合格——重写 | 分析失败原因,从选题/角度重来 |

### 自评诚实铁律 (v2.0新增)

**禁止自评95+分。** 自评100分=严重造假。

理由：
- v3标杆文章(经4轮用户迭代)约85-88分，仍有改进空间
- 自评膨胀会导致迭代停滞——以为已经很好就不会再改
- 每次自评必须找到≥2个具体扣分点，用一句话说明为什么扣
- 如果找不到扣分点，说明评价不够严格，需要重新审视
