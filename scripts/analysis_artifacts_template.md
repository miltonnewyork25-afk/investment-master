# 分析Artifact模板 v1.0

> **用途**: 每次Tier 2+分析时,在reports/{TICKER}/data/下生成以下3个artifact文件
> **来源**: Anthropic Harness "artifact-first"设计——跨session靠工件不靠记忆
> **触发**: Phase 0创建 → 每Phase更新 → Phase 5完成时由skeptic审计

---

## Artifact 1: question_tree.md

```markdown
# {TICKER} 分析问题树

> 创建: {DATE} | 最后更新: {DATE}
> 当前Phase: {PHASE}

## 核心问题 (本次分析必须回答)

| # | 问题 | 状态 | 回答 | 证据等级 | Phase |
|---|------|:---:|------|:-------:|:-----:|
| Q1 | 市场当前在定价什么? | ✅/❓/❌ | [简要回答] | fact/inference | P1 |
| Q2 | 企业真实趋势方向? | | | | |
| Q3 | 最可能被错定价的变量? | | | | |
| Q4 | 当前该做什么(动作)? | | | | |
| Q5 | 什么会推翻当前判断? | | | | |

## 衍生问题 (分析过程中产生)

| # | 问题 | 来源 | 状态 | 优先级 |
|---|------|------|:---:|:-----:|
| Q6 | [过程中发现的新问题] | Phase X | | high/low |

## 待下次session回答的问题

- [什么还不知道+什么数据可以填补+预计何时可得]
```

## Artifact 2: evidence_registry.md

```markdown
# {TICKER} 证据注册表

> 每条关键证据必须注册。skeptic subagent直接审计此文件。

| ID | 证据描述 | 等级 | 支持判断 | 反驳什么 | 失效条件 | 来源 |
|----|---------|:---:|---------|---------|---------|------|
| E01 | [具体数据或事实] | fact | [Q几/哪个结论] | [排除了什么替代解释] | [什么情况下失效] | [FMP/10-K/WebSearch] |
| E02 | [逻辑推断] | inference | | | | |
| E03 | [类比/假设] | assumption | | | | |

## 证据强度分布

- fact级: X条 (可以强表达)
- inference级: X条 (适度表达)
- assumption级: X条 (★必须弱表达)
- unknown: X项 (见unknowns.md)

## 缺口 (需要但还没有的证据)

| 缺口 | 影响哪个判断 | 如何获取 | 优先级 |
|------|------------|---------|:-----:|
| [NRR数据] | [增长质量判断] | [间接推算或等财报] | high |
```

## Artifact 3: unknowns.md

```markdown
# {TICKER} 未知项注册表

> ★ 核心原则: 未知不补。不知道的东西必须显式列出,不得用叙事填平。
> skeptic审计时会检查: 正文中的判断是否依赖于此处列出的未知项。

## 当前未知 (无法判断方向)

| # | 未知项 | 影响哪个判断 | 需要什么来解决 | 预计何时可得 |
|---|--------|------------|-------------|-----------|
| U01 | [例: AI对per-seat定价的实际影响速度] | [gap_type判断] | [F500客户实际seat变化数据] | [12-18个月] |
| U02 | [例: 管理层真实信心(vs言辞)] | [insider信号解读] | [更多insider买入数据] | [下季度13F] |

## 已解决的未知 (曾经不知道,现在有答案)

| # | 曾经的未知 | 现在的答案 | 证据 | 解决日期 |
|---|-----------|----------|------|---------|
| R01 | [例: Arizona fab良率能否匹配台湾] | [92%,匹配] | [TSMC报告] | 2026-03 |

## 不可知项 (结构性无法判断)

| # | 不可知项 | 为什么不可知 | 如何处理 |
|---|---------|------------|---------|
| X01 | [例: 台海冲突概率] | [地缘政治二元事件] | [标注为约束,不赋概率] |
```
