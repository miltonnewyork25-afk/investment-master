# 品牌战略重塑 — 护城河评级定位 v2.0

> **核心洞察**: 我们不是"深度研究机构"(每家都这么说)。我们是**护城河评级机构** — 像标普给信用评级一样，我们给护城河评级。这是独一无二的定位。
> **v2.0升级**: 覆盖范围从39家扩展至51家(39已评级+12候选观察)，候选名单创造"即将揭晓"期待感

---

## 一、定位诊断 — 旧定位为什么失效

| 维度 | 旧定位 | 问题 |
|------|--------|------|
| 核心卖点 | "AI驱动的投资研究框架" | 泛泛，每家AI公司都这么说 |
| 差异化 | "164个数据点+100%回测" | 数字可信度低，像骗子广告 |
| 覆盖范围 | "19只半导体股" | 已过时(现在39家跨6行业) |
| 情感定位 | "恐惧时发现机会" | 逆向投资者是小众 |
| 真正的护城河 | 未体现 | **CQI评分系统+34份深度报告**完全没有出现 |

**根本问题**: 你在卖"工具"(框架/数据点/回测)，但投资者不买工具 — 他们买**判断**。

## 二、新定位 — 护城河评级机构

### 2.1 一句话定位

> **我们不荐股。我们给护城河评级。**

这是品牌的北极星。所有营销物料、landing page、广告、社媒都围绕这句话展开。

### 2.2 为什么这个定位有效

| 效果 | 原因 |
|------|------|
| **立刻可理解** | 每个投资者都懂"信用评级" — 护城河评级是同一个逻辑 |
| **立刻可信** | 42子因子+14维度+11年数据+51家公司覆盖 — 这不是观点，是系统 |
| **立刻可差异化** | 没有第二家在做量化护城河评级 |
| **反定位(anti-positioning)** | "不荐股"打破了投研行业最大的信任障碍 — "你到底在推销什么" |
| **高搜索意图** | "moat stocks"/"best moat companies"/"economic moat"是高频投资搜索词 |

### 2.3 类比锚定

| 他们做的 | 我们做的 |
|---------|---------|
| S&P给债券信用评级(AAA→D) | 我们给公司护城河评级(CQI 82→CQI 8)，51家覆盖 |
| Morningstar给基金评星(5星→1星) | 我们给护城河趋势评级(↑加宽→⇊崩塌) |
| J.D. Power给汽车质量评级 | 我们给商业模式复利品质评级 |
