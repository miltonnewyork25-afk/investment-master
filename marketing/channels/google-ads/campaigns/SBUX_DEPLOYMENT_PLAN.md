## PART 8: 优化决策树 (When to Do What)

```
每日检查 Search Terms
    ├─ 发现消费者搜索 (menu, order, app) → 加否定词
    ├─ 发现高相关新词 → 加为关键词
    └─ 发现竞品搜索 (Seeking Alpha, Motley Fool) → 观察 CTR

每周检查 (Friday)
    ├─ CTR < 2.0% on any ad group
    │   └─ 检查 Headlines, 换 Pin H1
    ├─ CPA > $300 on any ad group (2周+)
    │   └─ 暂停该 ad group
    ├─ Quality Score < 5 on any keyword
    │   └─ 检查 landing page relevance + ad copy alignment
    └─ Impressions = 0 on any keyword
        └─ 检查 bid vs estimated first page bid

每两周决策 (Bi-weekly)
    ├─ Total CPA < $170 + CVR > 2%
    │   └─ 扩量: 预算 +30%
    ├─ Total CPA $170-300 + CVR 1-2%
    │   └─ 维持: 优化 ad copy + landing page
    ├─ Total CPA > $300 + CVR < 1%
    │   └─ 告警: A/B test 新 landing page
    └─ Total CPA > $400 (连续2周)
        └─ 暂停 Campaign, 重新评估

月度回顾
    ├─ ROAS > 5:1 → 加预算 50%, 复制成功模式到其他 Campaign
    ├─ ROAS 3-5:1 → 维持, 继续优化
    ├─ ROAS 2-3:1 → 缩减预算, 聚焦最佳 Ad Group
    └─ ROAS < 2:1 → 暂停, 预算重分配到其他报告 Campaign
```

### Break-Even Analysis

```
Break-even = 1 Annual subscription ($999) per $999 ad spend
At avg CPC $5.50, need CVR = 1 / ($999 ÷ $5.50) = 1/182 = 0.55%
→ CVR > 0.55% = profitable
→ Our target CVR 2.0-2.5% = 3.6-4.5x above break-even
→ Significant margin of safety
```
