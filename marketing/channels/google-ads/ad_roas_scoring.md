# Google Ads ROAS 评估框架 — 报告投放潜力评分系统

> **用途**: 每份新报告完成后，运行此评分系统，决定是否值得投放+预估ROAS
> **评分脚本**: `python evaluate_report.py <TICKER>`

---

## 评分维度（7维度 × 0-10分，加权总分决定投放优先级）

### D1: 搜索量潜力 (权重 25%)

衡量该公司/话题在 Google 上的搜索需求量级。

| 分数 | 标准 | 典型公司 |
|:----:|------|---------|
| 9-10 | 全球 Top 10 搜索量个股 | NVDA, TSLA, AAPL |
| 7-8 | 高搜索量科技/消费龙头 | MSFT, GOOGL, META, AMZN, SBUX |
| 5-6 | 中等搜索量热门股 | AMD, INTC, PLTR, ARM |
| 3-4 | 细分行业龙头 | KLAC, LRCX, AMAT, ASML, ETN |
| 1-2 | 小众/低搜索量 | VRT, IHG, RCL, SMCI |

### D2: CPC 效率 (权重 15%)

衡量获取一次点击的成本效率。CPC越低，同等预算买到的注意力越多。

| 分数 | 预估CPC范围 | 典型公司 |
|:----:|:----------:|---------|
| 9-10 | $2-5 | 低竞争个股: INTC, MU, SOFI |
| 7-8 | $5-8 | 中等竞争: SBUX, ARM, AMD |
| 5-6 | $8-12 | 较高竞争: KLAC, ASML, PLTR |
| 3-4 | $12-18 | 高竞争: NVDA, TSLA, GOOGL |
| 1-2 | $18+ | 超高竞争: 金融服务通用词 |

### D3: Hook 争议强度 (权重 20%)

衡量报告核心洞见作为广告标题的点击吸引力。争议性观点CTR远高于共识。

| 分数 | 标准 | 例子 |
|:----:|------|------|
| 9-10 | 极端逆共识 + 可量化数字 | INTC "-72%", NVDA "最贵周期股" |
| 7-8 | 强争议 + 数学悖论 | ARM "盈利+137%回报-49%", SBUX "78x PE for 9.6% OPM" |
| 5-6 | 中等争议/独特角度 | KLAC "42x vs 20x历史中位" |
| 3-4 | 温和差异化 | 共识偏离不大的报告 |
| 1-2 | 无争议/共识观点 | 与卖方结论一致 |

### D4: 免费竞品密度 (权重 15%)

衡量市场上已有的免费深度分析数量。免费内容越少，你的付费内容CVR越高。

| 分数 | 标准 | 典型公司 |
|:----:|------|---------|
| 9-10 | 几乎无免费深度分析 | VRT, IHG, RCL, ETN |
| 7-8 | 少量但不深入 | ARM, KLAC, LRCX, SBUX(深度级) |
| 5-6 | 中等数量 | INTC, AMD, PLTR |
| 3-4 | 大量免费分析 | META, GOOGL, MSFT |
| 1-2 | 泛滥 | NVDA, TSLA, AAPL |

### D5: 受众付费意愿 (权重 10%)

衡量搜索该公司分析的投资者愿意为深度研究付费的概率。

| 分数 | 标准 | 典型公司 |
|:----:|------|---------|
| 9-10 | 机构/UHNW为主, 6-7位数持仓 | NVDA, ASML, KLAC |
| 7-8 | 混合：专业+高净值散户 | ARM, INTC(turnaround), SBUX(消费巨头) |
| 5-6 | 偏散户但有付费意愿 | AMD, PLTR, MU |
| 3-4 | 高散户占比，低付费意愿 | TSLA, RDDT, RBLX |
| 1-2 | 纯散户/投机客 | Meme stocks |

### D6: 报告质量 (权重 10%)

落地后的内容能否让用户觉得"值$999"。直接影响CVR和退订率。

| 分数 | 质量分 | 字符数 | 典型报告 |
|:----:|:------:|:------:|---------|
| 9-10 | ≥4.3 | ≥350K | KLAC 4.5, IHG 4.3, ETN 4.3 |
| 7-8 | 4.0-4.2 | 250-350K | ARM 4.2, RCL 4.2, NVDA 4.0, SBUX est.4.0+ |
| 5-6 | 3.7-3.9 | 200-250K | INTC 4.1(短), SMCI 3.9, ANET 4.0 |
| 3-4 | 3.4-3.6 | 150-200K | PLTR 3.6, SOFI 3.4 |
| 1-2 | <3.4 | <150K | MU 2.8 |

### D7: 时效性 (权重 5%)

报告发布时间距今的新鲜度。Google 对新鲜内容有质量分加成。

| 分数 | 标准 |
|:----:|------|
| 9-10 | ≤7天 |
| 7-8 | 8-14天 |
| 5-6 | 15-30天 |
| 3-4 | 1-2月 |
| 1-2 | >2月 |

## 综合评分 → 投放决策

```
ROAS Score = D1×0.25 + D2×0.15 + D3×0.20 + D4×0.15 + D5×0.10 + D6×0.10 + D7×0.05
```

| 总分 | 决策 | 预估月预算 | 预估ROAS |
|:----:|------|:--------:|:--------:|
| **≥7.5** | **立即投放** — 优先分配预算 | $500-800 | 5:1+ |
| **6.0-7.4** | **值得测试** — 小预算试水 | $300-500 | 3-5:1 |
| **4.5-5.9** | **条件性投放** — 仅在特定时间窗口 | $150-300 | 2-3:1 |
| **<4.5** | **不投放** — ROAS不足以覆盖成本 | $0 | <2:1 |

## ROAS 预估模型

### 公式

```
Monthly ROAS = (Subscribers × Avg Revenue) / Ad Spend

Where:
  Subscribers = Clicks × CVR
  Clicks = Budget / Avg CPC
  CVR = f(D3_hook, D4_competition, D6_quality)
  Avg Revenue = weighted(Annual $999 × 60%, Monthly $99 × 30%, Weekly $29 × 10%)
             = $999×0.6 + $99×0.3 + $29×0.1 = $632.1 blended
```

### CVR 估算表

| ROAS Score | 预估CVR | 理由 |
|:----------:|:-------:|------|
| ≥7.5 | 2.0-3.0% | 强hook+低竞品+高质量 |
| 6.0-7.4 | 1.5-2.0% | 中等组合 |
| 4.5-5.9 | 0.8-1.5% | 有短板拉低 |
| <4.5 | <0.8% | 不推荐投放 |
